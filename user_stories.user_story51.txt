Title: Multi-Warehouse Entity Support

User Story: As a system administrator I want to define and manage multiple warehouse entities So that operations can be segmented and reported by location

Acceptance Criteria:
Scenario: Creating a warehouse entity
Given I have admin access
When I add a new warehouse with location details
Then the warehouse should be available for assignment of users, assets, and policies

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Database schema, user management
- Notes: Support for hierarchical warehouse structures if needed.
