# User Story 8: Soft-Delete Employee Record

**Epic:** E02 - Employee Master Data (CRUD)

**Title:** Soft-Delete Employee Record

**User Story:** As an HR manager, I want to soft-delete employee records so that historical data is preserved for compliance.

**Acceptance Criteria (Gherkin):**
```
Given an employee record
When I DELETE the employee
Then the record is marked as inactive but not removed from the database

Given a soft-deleted employee
When I GET the employee list
Then the employee is excluded unless explicitly requested
```

**Additional Details:**
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Supports compliance.
