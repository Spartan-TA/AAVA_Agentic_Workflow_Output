Title: Create Employee Record

User Story: As an HR manager I want to create a new employee record with all required fields So that I can onboard new staff efficiently

Acceptance Criteria:
Scenario: Successful employee creation
Given I have valid employee data
When I submit a POST request to /employees
Then a new employee record is created and badgeId is unique
Scenario: Missing required fields
Given I have incomplete employee data
When I submit a POST request to /employees
Then the request is rejected with validation errors

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: All fields (name, badgeId, role, department, shiftGroup, hireDate, status) must be present.
