Title: List and Filter Employees via API

User Story: As an HR manager I want to list and filter employee records So that I can quickly find employees by department, role, or status

Acceptance Criteria:

Scenario: List Employees
Given employee records exist
When I GET /employees
Then the API should return a paginated list of employees

Scenario: Filter Employees
Given employee records exist
When I GET /employees?department=Shipping&status=Active
Then the API should return only active employees in Shipping

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation
- Notes: Filtering and pagination must be documented in OpenAPI
