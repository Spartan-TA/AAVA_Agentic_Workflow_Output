Title: Soft-Delete Employee Record

User Story: As an HR manager I want to soft-delete employee records So that historical data is retained while removing active access

Acceptance Criteria:
Scenario: Successful soft-delete
  Given an existing employee record
  When I DELETE to /employees/{id}
  Then the employee status should be updated to inactive and the record should not be permanently removed

Scenario: Attempt to delete non-existent employee
  Given no employee record exists for the given id
  When I DELETE to /employees/{id}
  Then the API should return a not found error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation
- Notes: Ensure soft-deleted records are excluded from active queries
