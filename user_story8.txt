Title: Create New Post
User Story: As a logged-in user I want to create a new post So that I can share content with other users
Acceptance Criteria:
Scenario: Successful post creation
  Given I am logged in
  When I fill in the post form with valid content and submit
  Then I should see my post published and receive a success notification
Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: Authentication module, Database module, Content management system
  Notes: Support rich text formatting.
