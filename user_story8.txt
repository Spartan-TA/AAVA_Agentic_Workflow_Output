Title: Admin - Deactivate User Account

User Story Narrative:
As an admin, I want to deactivate a user account so that I can restrict access for users who violate terms.

Acceptance Criteria (Gherkin):
Given I am logged in as an admin,
When I select a user and click "Deactivate",
Then the user's account is deactivated,
And the user cannot log in.

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Admin - View User List
- Notes: Deactivation should be reversible.
