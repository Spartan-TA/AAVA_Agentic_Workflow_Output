Title: Notification Preferences

User Story: As a user I want to set my notification preferences So that I only receive relevant alerts through my preferred channels

Acceptance Criteria:
Scenario: Updating notification preferences
Given I am on my profile settings page
When I select notification types and channels (email, SMS, in-app)
Then the system should save my preferences and deliver notifications accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: User profile, notification module
- Notes: Default preferences should be set for new users.
