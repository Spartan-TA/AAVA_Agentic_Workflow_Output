Title: Soft Delete Employee API

User Story: As an HR manager I want to soft-delete employee records So that I can retain historical data while removing inactive employees from active lists

Acceptance Criteria:
Scenario: Successful soft-delete
Given an existing employee record
When I submit a DELETE request to /employees/{id}
Then the employee record is marked as inactive but remains in the database for audit purposes

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Ensure soft-deleted employees are excluded from active queries.
