Title: Rate Limiting and Audit Logging for Notifications

User Story: As a system administrator I want to apply rate limits to notifications and log all notification actions for audit so that the system is not abused and all actions are traceable.

Acceptance Criteria:

Scenario: Rate limits applied to notifications
Given notification settings
When too many notifications are sent in a short period
Then the system enforces rate limits and queues or drops excess notifications

Scenario: Notification actions logged
Given notifications are sent, delivered, or failed
When I review the audit log
Then all actions are recorded with user, timestamp, and status

Scenario: Audit log exportable
Given audit entries exist
When I request an export
Then I receive a CSV file with all relevant audit data

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E03, E05, E06, E07
- Notes: Supports compliance and system stability.
