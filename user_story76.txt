Title: Audit Logging and Reporting for Onboarding/Offboarding

User Story: As a compliance officer I want all onboarding and offboarding actions to be logged and reported so that I can ensure all required steps are completed and compliance is maintained.

Acceptance Criteria:

Scenario: Onboarding/offboarding actions logged
Given onboarding or offboarding tasks are processed
When actions occur (account provision, asset assignment, access revocation)
Then audit entries are created with user, timestamp, and action

Scenario: Reporting on onboarding/offboarding status
Given onboarding/offboarding tasks exist
When I request a report
Then I receive a summary of completed and pending tasks by employee

Scenario: Audit log exportable
Given audit entries exist
When I request an export
Then I receive a CSV file with all relevant audit data

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Supports compliance and process improvement.
