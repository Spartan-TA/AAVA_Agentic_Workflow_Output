Title: Implement Employee CRUD REST APIs

User Story: As an HR user I want to manage employee records via REST APIs so that I can create, view, update, and delete employee information from the system.

Acceptance Criteria:

Scenario: Create employee via API
Given valid employee data
When I POST to /employees
Then a new employee is created and returned with a unique badgeId

Scenario: Update employee details
Given an existing employee
When I PUT or PATCH to /employees/{id}
Then the employee record is updated

Scenario: Soft-delete employee
Given an existing employee
When I DELETE /employees/{id}
Then the employee status is set to inactive and record is not physically deleted

Scenario: Pagination and filtering
Given multiple employees exist
When I GET /employees with query parameters
Then I receive paginated and filtered results

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: API must conform to OpenAPI schema with examples.
