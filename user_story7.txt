Title: Certification Tracking - Add Certification

User Story: As an HR I want to add certifications to employee profiles So that qualification records are up to date.

Acceptance Criteria:
Scenario: Add certification
Given an employee profile
When I add a certification with expiry date
Then it appears on the profile and is tracked for expiration

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Upload proof documents

Then I receive a notification

- Story Points: 2

Title: Certification Tracking - Block Unqualified Assignment

User Story: As a SCHEDULER I want to prevent assignment of tasks to employees with expired certifications So that compliance is enforced.

Acceptance Criteria:
Scenario: Block assignment
Given an employee with expired certification
When I attempt to assign them to a restricted task
Then the system blocks the assignment and shows an error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Applies to shift and asset assignment
