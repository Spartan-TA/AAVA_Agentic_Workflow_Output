Title: Employee Record Update and Patch
User Story: As an HR Manager I want to update employee records via PUT and PATCH So that employee information remains current and accurate
Acceptance Criteria:
Scenario: Full record update
Given the employee update API is available
When I PUT an updated employee record
Then the record is replaced and badgeId remains unique
Scenario: Partial record update
Given the employee patch API is available
When I PATCH specific fields (e.g., status or department)
Then only those fields are updated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Support both full and partial updates; validate badgeId uniqueness
