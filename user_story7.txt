Title: Employee Soft-Delete Support
User Story: As an HR manager, I want to soft-delete employee records so that historical data is preserved and can be restored if needed.
Acceptance Criteria:
Scenario: Soft-delete employee record
Given an employee record exists
When I send a DELETE request to /employees/{id}
Then the employee record is marked as deleted but not physically removed from the database
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Soft-deleted records should be excluded from default queries but retrievable via filter.
