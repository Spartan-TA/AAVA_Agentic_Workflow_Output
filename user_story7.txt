Title: Row-Level Security for Supervisors

User Story: As a SUPERVISOR I want to access only my team's employee records So that I cannot view or modify other teams

Acceptance Criteria:
Scenario: Supervisor Access
Given a supervisor user
When they GET /employees
Then only employees in their team are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role-Based Endpoint Security
- Notes: Team assignment logic required
