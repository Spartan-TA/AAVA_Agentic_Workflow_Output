Title: Document Project Setup in README

User Story: As a developer I want clear build and run instructions in the README So that new team members can quickly set up and contribute to the project

Acceptance Criteria:
Scenario: README includes setup steps
Given the project is initialized
When I open the README file
Then I see detailed build and run instructions
Scenario: README covers migration tool usage
Given the migration tool is configured
When I read the README
Then I see instructions for running database migrations

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project initialization, migration tool configuration
- Notes: README should be kept up to date with any changes to setup steps.
