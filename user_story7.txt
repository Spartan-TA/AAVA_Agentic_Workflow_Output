Title: Training & Certification Tracking

User Story: As a safety manager I want to track employee certifications and expirations So that only qualified staff are assigned to equipment-sensitive roles and compliance is maintained

Acceptance Criteria:
Scenario: Add certification
Given an employee profile exists
When I add a certification with expiry date
Then the certification is saved and alerts are set for expiry

Scenario: Block assignment to expired certification
Given a certification is expired
When a supervisor attempts to assign a task requiring that certification
Then the system blocks the assignment and notifies the supervisor

Scenario: Upload proof document
Given a certification is added
When I upload a proof document
Then the document is attached to the employee profile

Scenario: Certification expiry alert
Given a certification is nearing expiry
When the expiry is within 30 or 7 days
Then an alert is sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee Master Data CRUD APIs, Role Based Access Control (RBAC)
- Notes: Certification status visible on employee profile; scheduling checks block unqualified assignments.
