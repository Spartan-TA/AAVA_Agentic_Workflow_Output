Title: Audit Log Export

User Story: As a compliance officer I want to export audit logs for a specified period So that I can provide evidence for regulatory audits and investigations

Acceptance Criteria:
Scenario: Exporting audit logs
Given audit logs exist for the selected period
When I request an export
Then the system should generate a downloadable file containing all relevant log entries

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Logging module, export functionality
- Notes: Support for CSV and PDF export formats.
