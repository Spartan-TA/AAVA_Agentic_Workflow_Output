Title: Database Migration Setup with Flyway/Liquibase
User Story: As a developer, I want to enable Flyway/Liquibase for database migrations so that schema changes are versioned and repeatable across environments.
Acceptance Criteria:
  - Given the project, When I start the application, Then Flyway/Liquibase runs the baseline migration and creates the initial schema.
  - Given a new migration file, When I apply it, Then the database updates without errors and the migration history is tracked.
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: Project Scaffolding
  Notes: Ensures DB consistency for all modules.
