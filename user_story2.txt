Title: Employee Master Data (CRUD)

User Story: As an HR manager I want to manage employee records with CRUD operations so that I can maintain an accurate and up-to-date employee database.

Acceptance Criteria:
Scenario: Employee CRUD operations
Given I have HR access
When I create, update, delete, or view employee records
Then badgeId is unique, soft-delete is supported, pagination and filtering are available, and OpenAPI schemas include examples

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01)
- Notes: Ensure all required fields are validated and API documentation is complete.
