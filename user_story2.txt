Title: Configure Database Migration Tooling

User Story: As a developer I want to set up Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:

Scenario: Baseline Migration
Given a fresh database
When I run the migration tool
Then the baseline schema should be created and versioned

Scenario: Migration Execution
Given new migration scripts are added
When I build and run the project
Then the scripts should apply in order and errors should be logged

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project initialization
- Notes: Migration tool must be documented in README
