User Story 2
Title: Configure Database Migration Tool
User Story: As a developer, I want to set up Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable.
Acceptance Criteria (Gherkin):
  Given the project is running,
  When I start the application,
  Then Flyway/Liquibase should apply the baseline migration to the database.
  And the migration history should be visible in the DB.
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: User Story 1
  Notes: Ensures DB consistency across environments.
