Title: Create Employee Record
User Story: As an HR manager I want to create a new employee record with all required fields So that employee data is accurately captured in the system
Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details

Then a new employee record is created and badgeId is unique
