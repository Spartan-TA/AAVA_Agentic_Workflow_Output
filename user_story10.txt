Title: Method and Row-Level Security

User Story: As a supervisor I want security rules to restrict access to only my team's records So that sensitive data is protected and access is limited

Acceptance Criteria:
Scenario: Row-level access control
Given a supervisor is logged in
When they access employee records
Then only records for their team are visible and editable

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role-based endpoint security
- Notes: Security rules must be covered by automated tests
