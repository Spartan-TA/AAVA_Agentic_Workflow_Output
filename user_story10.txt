Title: Support Soft-Delete and Restoration of Employee Records

User Story: As an HR user I want to soft-delete and restore employee records so that terminated employees can be reactivated if rehired without losing historical data.

Acceptance Criteria:

Scenario: Soft-delete employee
Given an active employee
When I DELETE /employees/{id}
Then the employee status is set to inactive and record is not physically deleted

Scenario: Restore soft-deleted employee
Given an inactive employee
When I PATCH /employees/{id}/restore
Then the employee status is set to active and the record is available in active listings

Scenario: Soft-deleted employees excluded from active queries
Given employees with different statuses exist
When I GET /employees?status=active
Then only active employees are returned

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Ensures compliance and data retention for HR.
