Title: WMS Integration

User Story: As a system integrator I want to integrate with the Warehouse Management System (WMS) So that inventory and asset data are synchronized between platforms

Acceptance Criteria:
Scenario: Syncing with WMS
Given inventory changes in the WMS
When the integration job runs
Then the system should update local asset records to reflect the changes

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: WMS API, integration scheduler
- Notes: Support for bidirectional sync if required.
