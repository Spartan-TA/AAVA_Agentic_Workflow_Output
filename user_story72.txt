Title: Offline-Friendly PWA and Installable Manifest

User Story: As a warehouse worker I want the mobile app to work offline and be installable as a PWA so that I can clock in/out and view schedules even without network connectivity.

Acceptance Criteria:

Scenario: Offline queue for clock events
Given the app is offline
When I clock in or out
Then the event is queued and submitted when connectivity is restored

Scenario: Installable PWA manifest
Given I access the app on a mobile device
When I choose to install
Then the app is added to my home screen with an icon and splash screen

Scenario: Lighthouse PWA score
Given the app is audited
When I run a Lighthouse audit
Then the PWA score is 90 or above

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04, E05, E06, E12
- Notes: Improves reliability for frontline workers.
