Title: Export Attendance Reports

User Story: As a payroll specialist I want to export attendance data in CSV format So that I can process payroll accurately and meet compliance requirements

Acceptance Criteria:
Scenario: Attendance Report Export
Given attendance records exist for a period
When I request an export
Then a CSV file is generated with daily totals and corrections

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock in/out, corrections workflow
- Notes: Include shift association and approval status in export.
