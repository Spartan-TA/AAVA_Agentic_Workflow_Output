Title: Payroll Integration

User Story: As a payroll administrator I want to sync attendance and leave data with payroll systems So that salary calculations are automated and accurate

Acceptance Criteria:
Scenario: Payroll data sync
Given approved attendance and leave records
When payroll is processed
Then all relevant data is transferred to the payroll system

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Attendance, leave modules, payroll API
- Notes: Support for multiple payroll providers
