### E11: Payroll Export Integration

**User Story 1**
Title: Payroll File Generation

User Story: As a PAYROLL ADMIN I want to generate payroll-ready files from attendance and leave data So that payroll processing is automated.

Acceptance Criteria:
Scenario: Generate Payroll File
Given approved attendance and leave records
When I request a payroll export
Then the file matches provider schema

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Format configurable per provider

---

**User Story 2**
Title: Secure Payroll Delivery

User Story: As a SYSTEM I want to deliver payroll files securely via SFTP or API So that sensitive data is protected.

Acceptance Criteria:
Scenario: Secure Delivery
Given a payroll file
When I send via SFTP/API
Then delivery is logged and retried on failure

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Audit log for every export

---

**User Story 3**
Title: Payroll Export Reconciliation

User Story: As a PAYROLL ADMIN I want to reconcile payroll exports with attendance reports So that errors are minimized.

Acceptance Criteria:
Scenario: Reconcile Payroll
Given exported payroll and attendance data
When I compare totals
Then discrepancies are flagged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Automated reconciliation report
