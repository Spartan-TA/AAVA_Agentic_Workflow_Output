Title: Shift Template Management

User Story: As an ADMIN I want to create recurring shift templates and rotations So that scheduling is efficient

Acceptance Criteria:
Scenario: Create Template
Given valid shift details
When I POST to /shifts/templates
Then a new template is created

Scenario: Assign Rotation
Given a template
When I assign to employees
Then their schedules are updated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API, Role-Based Endpoint Security, Clock In/Out Event Capture
- Notes: Supports blackout dates
