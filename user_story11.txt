Title: Implement Role-Based Access Control (RBAC) with Spring Security

User Story: As a security administrator I want to configure roles (ADMIN, HR, SUPERVISOR, WORKER) in Spring Security so that only authorized users can access sensitive endpoints and data.

Acceptance Criteria:

Scenario: Unauthorized requests return 401
Given a user is not authenticated
When they access a protected endpoint
Then the response is 401 Unauthorized

Scenario: Forbidden actions return 403
Given a user is authenticated but lacks permission
When they access a restricted endpoint
Then the response is 403 Forbidden

Scenario: ADMIN can manage all records
Given a user with ADMIN role
When they access any endpoint
Then all operations are permitted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Foundation for all security-sensitive features.
