Title: Comment on Posts
User Story: As a logged-in user I want to comment on posts So that I can engage in discussions
Acceptance Criteria:
Scenario: Successful comment submission
  Given I am viewing a post
  When I enter a comment and submit
  Then my comment should appear below the post with my username and timestamp
Additional Details:
  Priority: High
  Story Points: 4
  Dependencies: Authentication module, Database module
  Notes: Implement comment moderation features.
