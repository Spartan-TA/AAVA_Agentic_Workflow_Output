Title: API Key/OAuth2 Authentication Toggle

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication So that the system can support different security requirements

Acceptance Criteria:
Scenario: Authentication method selection
Given the application configuration
When I set the authentication mode to API key or OAuth2
Then endpoints require the selected authentication method

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role-based endpoint security
- Notes: Document configuration steps and test both modes
