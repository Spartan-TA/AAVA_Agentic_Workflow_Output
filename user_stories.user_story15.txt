Title: Manage Warehouse Operation Calendars

User Story: As a scheduler I want to define blackout dates and operation calendars So that shift assignments respect warehouse closures and special events

Acceptance Criteria:
Scenario: Blackout Date Management
Given access to the scheduling module
When I add or remove blackout dates
Then shift assignments are updated and conflicts are prevented

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Shift templates, Employee CRUD
- Notes: Calendar changes reflected in shift assignment UI and reports.
