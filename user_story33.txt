Title: Certification CRUD and Status Visibility

User Story: As an HR user I want to create, update, and delete certifications and view certification status on the employee profile so that I can manage compliance efficiently.

Acceptance Criteria:

Scenario: Create certification
Given an employee
When I POST a new certification
Then the certification is added to the employee profile

Scenario: Update certification details
Given an existing certification
When I PATCH the certification
Then the details are updated

Scenario: Delete certification
Given an existing certification
When I DELETE the certification
Then it is removed from the employee profile

Scenario: Certification status visible
Given an employee profile
When I view the profile
Then all certifications and their status (valid/expiring/expired) are visible

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Enables full lifecycle management of certifications.
