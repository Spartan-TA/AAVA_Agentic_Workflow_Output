Epic E09 - Equipment & Asset Assignment

User Story 1
Title: Assign Equipment to Employee
User Story: As a supervisor I want to assign equipment (e.g., scanners, forklifts, PPE) to employees so that asset usage is tracked and accountability is maintained
Acceptance Criteria:
Scenario: Assigning equipment to an employee
Given an employee with valid certifications
When I assign an available asset to the employee
Then the asset is marked as checked out and linked to the employee's profile
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee Master Data, Certification Tracking
- Notes: Only employees with required certifications can be assigned certain equipment

User Story 2
Title: Prevent Assignment Without Valid Certification
User Story: As a supervisor I want the system to block asset assignment if an employee lacks the required certification so that only qualified staff operate equipment safely
Acceptance Criteria:
Scenario: Certification validation on assignment
Given an employee without a valid certification for the asset
When I attempt to assign the asset
Then the system displays an error and prevents assignment
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification Tracking
- Notes: Applies to forklifts and other regulated equipment

User Story 3
Title: Track Asset Check-In and Check-Out
User Story: As an asset manager I want to record check-in and check-out events for assets so that asset usage history is auditable
Acceptance Criteria:
Scenario: Asset check-in/out process
Given an asset assigned to an employee
When the employee returns the asset
Then the asset status updates to available and the event is logged
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Registry
- Notes: Overdue returns should trigger notifications

User Story 4
Title: View Asset Assignment History
User Story: As an administrator I want to view the assignment history of each asset so that I can audit usage and investigate incidents
Acceptance Criteria:
Scenario: Viewing asset history
Given an asset with prior assignments
When I access the asset's detail page
Then I see a chronological log of all check-in/out events and assigned employees
Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: Asset Registry
- Notes: Include timestamps and user IDs

User Story 5
Title: Report Overdue Asset Returns
User Story: As a supervisor I want to generate reports of overdue asset returns so that I can follow up with responsible employees
Acceptance Criteria:
Scenario: Overdue asset report
Given assets that have not been returned by the due date
When I generate the overdue report
Then I see a list of assets, assigned employees, and overdue duration
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Assignment, Reporting
- Notes: Report exportable as CSV
