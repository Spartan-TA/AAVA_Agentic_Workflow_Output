EPIC 09: EQUIPMENT & ASSET ASSIGNMENT

===========================================

Title: Asset Registry CRUD
User Story: As an asset manager I want to manage the registry of equipment and assets So that assignments and condition tracking are accurate
Acceptance Criteria:
Scenario: Asset CRUD operations
Given asset data
When I create, update, or delete an asset
Then the registry reflects the current state

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD, RBAC, Certification Tracking
- Notes: Include PPE, scanners, forklifts

---

Title: Asset Check-In/Out Endpoints
User Story: As a warehouse worker I want to check out and return assets So that usage is tracked and overdue returns are flagged
Acceptance Criteria:
Scenario: Asset check-in/out
Given a valid asset and employee
When I check out or return an asset
Then the event is logged and overdue status updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Registry CRUD
- Notes: Block if certification invalid

---

Title: Block Asset Use if Certification Missing
User Story: As a supervisor I want to prevent asset use if required certifications are missing So that safety is ensured
Acceptance Criteria:
Scenario: Certification check on asset use
Given an asset requiring certification
When an employee without valid certification attempts check-out
Then the system blocks the transaction

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Registry CRUD, Certification Tracking
- Notes: History log per asset and employee

---

Title: Asset History Log
User Story: As an asset manager I want to view the history log for assets and employees So that usage and condition are auditable
Acceptance Criteria:
Scenario: Asset history retrieval
Given asset and employee records
When I request the history log
Then all check-in/out events and condition changes are listed

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Asset Registry CRUD
- Notes: Include overdue reports
