Title: Asset Check-In/Check-Out Endpoints and Overdue Returns

User Story: As a warehouse worker I want to check in and check out assets via API endpoints so that asset usage is tracked and overdue returns are flagged.

Acceptance Criteria:

Scenario: Check out asset
Given an available asset
When I POST to /assets/check-out
Then the asset is assigned to the employee and due date is set

Scenario: Check in asset
Given an asset is checked out
When I POST to /assets/check-in
Then the asset is returned and status is updated

Scenario: Overdue returns flagged
Given an asset is not returned by the due date
When the system processes asset records
Then overdue returns are flagged and reported to the supervisor

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E07
- Notes: Ensures accountability and reduces asset loss.
