Title: Enforce Unique badgeId for Employees

User Story: As an HR ADMIN I want the system to enforce unique badgeId for each employee So that there are no duplicate employee records and badge assignments

Acceptance Criteria:
Scenario: Duplicate badgeId Prevention
Given an employee record exists with a badgeId
When I attempt to create another employee with the same badgeId
Then the system rejects the creation and displays an error

Scenario: badgeId Assignment
Given a new employee is created
When I assign a badgeId
Then the badgeId is unique across all employee records

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Validation must occur at both API and database levels
