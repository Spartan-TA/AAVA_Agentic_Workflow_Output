Title: Update Employee API

User Story: As an HR manager I want to update employee records So that I can keep employee information current and accurate

Acceptance Criteria:
Scenario: Successful employee update
Given an existing employee record
When I submit a PUT or PATCH request to /employees/{id} with valid changes
Then the employee record is updated and changes are reflected in the database

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Validate badgeId uniqueness and audit changes.
