Title: Generate Operational Reports (Attendance, Overtime, Leave)

User Story: As an operations manager I want to generate operational reports for attendance, overtime, and leave balances so that I can make data-driven staffing decisions.

Acceptance Criteria:

Scenario: Generate attendance report
Given attendance data exists
When I request a report
Then I receive a summary of attendance by date, department, and shift

Scenario: Generate overtime report
Given overtime data exists
When I request a report
Then I receive a summary of overtime hours and employees affected

Scenario: Generate leave balance report
Given leave data exists
When I request a report
Then I receive a summary of leave balances by employee

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Supports operational planning and compliance.
