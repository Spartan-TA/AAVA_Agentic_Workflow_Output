Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to scaffold a new Spring Boot project with standardized base packages So that all modules follow a consistent structure and onboarding is accelerated

Acceptance Criteria:
Scenario: Project scaffolding and build
Given I have cloned the repository
When I run the build command as documented in the README
Then the project builds successfully and runs on port 8080

Scenario: Base package structure
Given the project is built
When I browse the source code
Then I should see core modules for employee, scheduling, attendance, and safety under the base package

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include clear build and run instructions
