Title: Employee CRUD API Implementation
User Story: As an HR manager, I want to create, read, update, and delete employee records via API so that employee data is managed centrally and accurately.
Acceptance Criteria:
Scenario: Employee CRUD operations
Given the employee API is available
When I send POST, GET, PUT, PATCH, and DELETE requests to /employees
Then the corresponding employee records are created, retrieved, updated, and soft-deleted as expected
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: API should support pagination and filtering.
