# User Story 5: Create Employee Record

**Epic:** E02 - Employee Master Data (CRUD)

**Title:** Create Employee Record

**User Story:** As an HR manager, I want to create employee records with name, badgeId, role, department, shiftGroup, hireDate, and status so that all employee data is centralized.

**Acceptance Criteria (Gherkin):**
```
Given the employee creation API
When I POST valid employee data
Then a new employee record is created with a unique badgeId

Given the employee creation API
When I POST with a duplicate badgeId
Then the request is rejected with a validation error
```

**Additional Details:**
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Unique badgeId enforced.
