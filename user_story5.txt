Title: Implement Employee CRUD API Endpoints

User Story: As an HR user I want to create, read, update, and delete employee records via API so that employee data is accurate and up to date.

Acceptance Criteria:
Scenario: Employee record creation
Given valid employee data
When I POST to /employees
Then a new employee record is created and returned with a unique badgeId

Scenario: Employee record update
Given an existing employee
When I PUT or PATCH to /employees/{id}
Then the employee record is updated accordingly

Scenario: Employee record deletion
Given an existing employee
When I DELETE /employees/{id}
Then the employee record is soft-deleted and excluded from active queries

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: Support pagination, filtering, and OpenAPI schema documentation.
