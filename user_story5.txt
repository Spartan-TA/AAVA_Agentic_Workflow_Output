Title: Employee CRUD API - Read & Filter Employees
User Story: As an HR manager, I want to view and filter employee records so that I can quickly find relevant information.
Acceptance Criteria:
  - Given multiple employees, When I GET /employees with pagination, Then I see a paginated list of employees.
  - Given filter parameters (department, status), When I GET /employees, Then only matching employees are returned.
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: Employee CRUD
  Notes: Supports OpenAPI schemas.
