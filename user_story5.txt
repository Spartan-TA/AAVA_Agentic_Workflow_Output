Title: Implement RBAC for Sensitive Operations

User Story: As a system administrator I want to restrict access to sensitive endpoints based on user roles So that only authorized users can perform critical operations

Acceptance Criteria:
Scenario: Role-based access Given a user with ADMIN role When accessing sensitive endpoints Then access is granted; otherwise, 401/403 is returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee CRUD
- Notes: API key/OAuth2 toggle via config; security rules covered by tests
