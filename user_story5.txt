Title: Implement Employee CRUD APIs

User Story: As an HR admin I want to manage employees via CRUD APIs So that I can add, update, view, and delete employee records

Acceptance Criteria:
Scenario: Employee update
Given an employee exists
When I send a PUT/PATCH request with changes
Then the employee record is updated accordingly

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain model
- Notes: Support soft-delete and filtering
