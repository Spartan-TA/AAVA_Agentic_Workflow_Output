Title: Shift Management - Create Shift Template

User Story: As an ADMIN I want to create recurring shift templates So that scheduling is efficient and consistent.

Acceptance Criteria:
Scenario: Create shift template
Given valid shift details
When I POST to /shifts/templates
Then the template is saved and available for assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Supports rotations and overtime rules

Title: Shift Management - Assign Shifts

User Story: As a SUPERVISOR I want to assign shifts to employees in bulk So that staffing is managed quickly.

Acceptance Criteria:
Scenario: Bulk assign shifts
Given a list of employees and a shift template
When I assign the shift
Then all selected employees receive the assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Conflicts are detected and prevented

Title: Shift Management - Audit Shift Changes

User Story: As an ADMIN I want to audit all shift assignments and changes So that compliance and fairness are ensured.

Acceptance Criteria:
Scenario: Audit entry for shift change
Given a shift assignment is created or modified
When the change is saved
Then an audit entry is generated with actor, timestamp, and before/after values

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03, E04
- Notes: Audit entries are immutable
