Title: Provide Sample Configuration for Local Development

User Story: As a developer I want a sample configuration file for local development so that I can quickly set up and run the project on my machine.

Acceptance Criteria:

Scenario: Sample config file exists
Given the project repository
When I browse the config directory
Then I see a sample application.properties or application.yml file

Scenario: Environment variables documented
Given the project repository
When I open the README file
Then I see documentation for required environment variables

Scenario: Application runs with sample config
Given I copy the sample config to my local environment
When I start the application
Then the application starts successfully with default settings

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Reduces onboarding time for new developers.
