Title: Employee Record Creation
User Story: As an HR Manager I want to create new employee records with all required fields So that employee data is accurately captured and available for downstream processes
Acceptance Criteria:
Scenario: Successful employee creation
Given the employee creation API is available
When I POST a new employee with name, badgeId, role, department, shiftGroup, hireDate, and status
Then the employee is created and badgeId is unique
Scenario: Validation errors
Given the employee creation API
When I POST with missing or invalid fields
Then validation errors are returned
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Ensure badgeId uniqueness and required fields
