Title: Create README with Build and Run Instructions

User Story: As a DEVELOPER I want a README file with clear build and run instructions So that new team members can quickly set up and contribute to the project

Acceptance Criteria:
Scenario: README Availability
Given the project repository is cloned
When I open the README file
Then I see detailed steps for building and running the application

Scenario: README Accuracy
Given the README instructions are followed
When I build and run the application
Then the application starts successfully without errors

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project initialization
- Notes: README should include environment setup, dependencies, and troubleshooting tips
