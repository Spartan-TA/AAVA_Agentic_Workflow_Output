Title: Configure Role Management

User Story: As an administrator I want to assign and manage user roles So that I can control access to different system features

Acceptance Criteria:
Scenario: Role Assignment
Given an existing user
When I assign or change their role
Then their permissions are updated immediately and reflected in access control
