Title: Asset Registry

User Story: As an asset manager I want to maintain a centralized registry of all equipment and assets So that I can track ownership, location, and status

Acceptance Criteria:
Scenario: Registering a new asset
Given I have asset details
When I enter asset information and save
Then the asset should appear in the registry with a unique identifier

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Database schema, user authentication
- Notes: Registry must support search and filter by asset type and location.
