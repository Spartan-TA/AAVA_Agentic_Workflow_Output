Title: Unauthorized Access Handling

User Story: As a system administrator I want unauthorized requests to return 401 So that sensitive endpoints are protected from unauthenticated access

Acceptance Criteria:
Scenario: Unauthorized request
Given an unauthenticated user
When they attempt to access a protected endpoint
Then the API returns a 401 Unauthorized response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Ensure all protected endpoints enforce authentication.
