# Warehouse Employee Management Platform

A comprehensive Spring Boot application for managing warehouse employees, attendance, scheduling, and compliance.

## Prerequisites
- Java 17 or higher
- Maven 3.6+
- PostgreSQL 14+

## Build
```bash
mvn clean install
```

## Run
```bash
mvn spring-boot:run
```

## Test
```bash
mvn test
```

## API Documentation
Access Swagger UI at: http://localhost:8080/swagger-ui.html

## Modules
- Employee Master Data (E02)
- Time & Attendance (E04)
- Shift Management (E05)
- Leave Management (E06)
- Training & Certification (E07)
- Safety Incidents (E08)
- And 12 more modules...
