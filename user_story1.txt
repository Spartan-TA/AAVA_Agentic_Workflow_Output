Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot (Maven) project and configure base packages So that all modules have a standardized foundation for accelerated delivery and consistency.

Acceptance Criteria:
Scenario: Successful project initialization
Given I have access to the project repository
When I build and run the project
Then the application runs on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration setup
Given the project is initialized
When I run Flyway/Liquibase migrations
Then the baseline migration completes successfully

Scenario: Documentation
Given the project is set up
When I view the README
Then I see clear build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
