Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot (Maven) project with a standardized base package structure so that all modules can be developed consistently and efficiently.

Acceptance Criteria:

Scenario: Project builds and runs on default port
Given the project is cloned from the repository
When I run the build and start the application
Then the application starts successfully on port 8080

Scenario: Base package structure exists
Given the project is initialized
When I browse the source code
Then I see base packages for employee, scheduling, attendance, and safety modules

Scenario: README documents build/run steps
Given the project repository
When I open the README file
Then I see clear instructions for building and running the project

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Foundation for all other modules; must be completed first.
