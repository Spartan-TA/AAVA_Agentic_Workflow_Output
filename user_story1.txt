Title: Initialize Spring Boot Project

User Story: As a System Administrator I want to initialize a Spring Boot project with Maven So that the EMS foundation is standardized and ready for module development

Acceptance Criteria:
Scenario: Project Initialization
Given I have access to the repository
When I run the build and start the application
Then the project builds successfully and runs on port 8080

Scenario: Health Endpoint
Given the application is running
When I access the Actuator health endpoint
Then it returns UP status

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build and run steps; base package structure created; Flyway/Liquibase baseline migration enabled.
