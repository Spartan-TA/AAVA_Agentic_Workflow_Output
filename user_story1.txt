Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize the Spring Boot project with standardized base modules So that all teams can build features on a consistent foundation

Acceptance Criteria:

Scenario: Project Initialization
Given a new repository
When I run the build and start the application
Then the project should run on port 8080 and the Actuator health endpoint should return UP

Scenario: Base Package Structure
Given the project is initialized
When I inspect the source code
Then the base package structure for employee, scheduling, attendance, and safety modules should be present

- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps; Flyway/Liquibase baseline migration enabled
