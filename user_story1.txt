Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot project with standardized modules and database migration tools so that all teams have a consistent foundation for building and deploying features.

Acceptance Criteria:
Scenario: Project setup and verification
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP
  And the README should include build and run instructions
  And the base package structure should be present
  And Flyway/Liquibase should execute the baseline migration successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are scaffolded and database migration is automated.
