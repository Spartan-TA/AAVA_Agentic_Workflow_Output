Title: Project Scaffolding & Domain Setup - Spring Boot Initialization

User Story: As a developer I want to initialize a standardized Spring Boot project structure so that all modules follow consistent patterns and onboarding is accelerated.

Acceptance Criteria:
Scenario: Project setup and verification
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
  Given the project is running
  When I start the application
  Then Flyway or Liquibase should execute the baseline migration successfully

Scenario: Documentation
  Given the repository contains a README
  When I view the README
  Then it should include clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created for employee, scheduling, attendance, and safety modules.
