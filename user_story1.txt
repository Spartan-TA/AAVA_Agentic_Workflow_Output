Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot project and configure base packages so that all core modules are standardized and delivery is accelerated.

Acceptance Criteria:
Scenario: Successful project scaffolding
Given a clean repository
When I run the build and start the project
Then it should run on port 8080, the README should have build/run steps, the Actuator health endpoint returns UP, base package structure is created, and Flyway/Liquibase runs baseline migration.

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all modules (employee, scheduling, attendance, safety) are included in the base structure. Actuator and DB migration tools must be enabled.
