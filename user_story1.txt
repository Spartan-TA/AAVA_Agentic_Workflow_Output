Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project structure with core modules and database migration tools so that all teams can accelerate delivery and maintain consistency across the warehouse EMS platform.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given a new codebase
  When I build and run the project
  Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration setup
  Given the project is initialized
  When I run the application
  Then Flyway/Liquibase executes the baseline migration successfully

Scenario: Documentation availability
  Given the repository is cloned
  When I open the README
  Then I see clear build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
