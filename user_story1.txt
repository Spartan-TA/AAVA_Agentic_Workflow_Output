Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project structure so that all modules can be developed consistently and efficiently.

Acceptance Criteria:
Scenario: Project initialization and verification
  Given a new repository
  When I run the build and start the application
  Then the application should run on port 8080 and the Actuator health endpoint should return UP
  And the base package structure should be created
  And Flyway/Liquibase should run the baseline migration
  And the README should include build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are scaffolded and database migration is automated.
