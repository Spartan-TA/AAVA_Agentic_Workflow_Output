Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot project with Maven So that I have a standardized foundation for all modules

Acceptance Criteria:
Scenario: Successful project initialization
  Given I have access to the project repository
  When I run the Maven build command
  Then the project should build and run on port 8080

Scenario: Health endpoint verification
  Given the application is running
  When I access the Actuator health endpoint
  Then it should return UP

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure README contains build and run instructions
