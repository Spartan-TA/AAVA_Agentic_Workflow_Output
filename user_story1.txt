Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to scaffold a Spring Boot project with standardized base packages so that all modules follow a consistent structure and can be easily maintained.
Acceptance Criteria:
  - Given a new repository, When I run the provided build command, Then the project builds successfully and runs on port 8080.
  - Given the repository, When I open the README, Then I see clear build and run instructions.
  - Given the project, When I inspect the package structure, Then I see separate modules for employee, scheduling, attendance, and safety.
Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: None
  Notes: Foundation for all subsequent modules.
