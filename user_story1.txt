User Story 1
Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to scaffold a new Spring Boot project with Maven so that all modules have a consistent foundation for development.
Acceptance Criteria (Gherkin):
  Given I clone the repository,
  When I run 'mvn clean install' and 'mvn spring-boot:run',
  Then the application should build and start on port 8080.
  And the README should contain build and run instructions.
Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: None
  Notes: Base for all subsequent modules.
