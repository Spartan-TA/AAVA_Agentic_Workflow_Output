Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project with core modules and database migration tooling so that all teams can accelerate delivery and maintain consistency across the warehouse management system.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project
  Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration setup
  Given the project is built
  When I run the application
  Then Flyway/Liquibase applies the baseline migration successfully

Scenario: Documentation
  Given the repository is cloned
  When I open the README
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
