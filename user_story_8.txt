Title: Update Employee Record

User Story: As an HR Manager I want to update an existing employee record So that employee information remains current

Acceptance Criteria:
Scenario: Employee record update
Given I am viewing an employee's details
When I edit and save changes
Then the employee record should be updated and changes reflected in the system

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee record creation
- Notes: Track changes for audit purposes
