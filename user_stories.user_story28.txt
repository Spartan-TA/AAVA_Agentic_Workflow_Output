Title: Submit Performance Reviews

User Story: As a manager I want to submit performance reviews for my direct reports So that employee performance is formally documented and feedback is provided

Acceptance Criteria:
Scenario: Submitting a review
Given a review cycle is active and I have assigned reports
When I complete and submit a review form
Then the review should be saved and visible to HR and the employee

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Review cycle, user directory
- Notes: Support for both manager and self-reviews.
