Title: Enforce Unique Badge ID

User Story: As a system I want to enforce unique badgeId for each employee So that there are no duplicate employee records

Acceptance Criteria:
Scenario: Duplicate badgeId
Given an employee with badgeId X exists
When I try to create another employee with badgeId X
Then the system rejects the request with an error

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee CRUD APIs
- Notes: Validation at API and DB level
