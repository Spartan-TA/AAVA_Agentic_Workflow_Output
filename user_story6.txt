Title: Update Employee Record via API

User Story: As an HR manager I want to update employee records using a REST API So that changes in employee details are reflected accurately

Acceptance Criteria:

Scenario: Successful Employee Update
Given an existing employee record
When I PUT or PATCH updated data to /employees/{id}
Then the employee record should be updated and returned

Scenario: Invalid Update Data
Given an employee record
When I send invalid data (e.g., missing required fields)
Then the API should return a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation
- Notes: OpenAPI schema must include update examples
