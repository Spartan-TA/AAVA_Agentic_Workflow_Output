Title: Employee List Pagination and Filtering

User Story: As an HR manager I want to paginate and filter employee records So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Employee list management
Given a large number of employee records
When I use pagination and filtering options on /employees
Then only relevant records are displayed per page

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Support filtering by department, role, status, and shiftGroup
