Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Actuator health endpoint So that I can monitor the application's health status in real time

Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access the /actuator/health endpoint
Then the response should indicate status UP
Scenario: Health endpoint is secured
Given the application is running
When an unauthorized user accesses the /actuator/health endpoint
Then access is denied

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project initialized
- Notes: Health endpoint should be documented in README.
