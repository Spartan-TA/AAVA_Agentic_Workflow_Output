Title: Create Employee Entity and Repository

User Story: As a backend developer I want to define the Employee entity and repository so that employee records can be persisted and retrieved from the database.

Acceptance Criteria:

Scenario: Employee entity includes required fields
Given the Employee entity is defined
When I inspect the entity
Then it includes name, badgeId, role, department, shiftGroup, hireDate, and status

Scenario: Repository supports basic CRUD
Given the Employee repository is implemented
When I use the repository
Then I can create, read, update, and delete employee records

Scenario: Unique badgeId enforced
Given the Employee entity
When I attempt to save two employees with the same badgeId
Then the operation fails with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Foundation for all employee-related features.
