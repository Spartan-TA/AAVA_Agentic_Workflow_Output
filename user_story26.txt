Title: Request and Approve Leave (PTO, Sick, Unpaid)

User Story: As an employee I want to request PTO, sick, or unpaid leave and have my supervisor approve or deny the request so that my absences are properly tracked and managed.

Acceptance Criteria:

Scenario: Employee requests leave
Given an authenticated employee
When they submit a leave request
Then the request is created and pending supervisor approval

Scenario: Supervisor approves leave
Given a pending leave request
When the supervisor approves it
Then the employee's leave balance is updated and the schedule is flagged for coverage

Scenario: Supervisor denies leave
Given a pending leave request
When the supervisor denies it
Then the employee is notified and the request is marked as denied

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E05
- Notes: Foundation for compliant leave management.
