Title: Create and Manage Shift Templates

User Story: As an HR manager I want to create, update, and delete recurring shift templates so that I can standardize work schedules across the warehouse.

Acceptance Criteria:

Scenario: Create new shift template
Given valid shift details
When I POST to /shifts/templates
Then a new shift template is created and available for assignment

Scenario: Update existing shift template
Given an existing shift template
When I PUT or PATCH to /shifts/templates/{id}
Then the template is updated with new details

Scenario: Delete shift template
Given an existing shift template
When I DELETE /shifts/templates/{id}
Then the template is removed and cannot be assigned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Enables efficient scheduling and reduces manual entry.
