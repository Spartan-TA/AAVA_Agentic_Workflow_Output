# Warehouse Employee Management System

This project is a Spring Boot application for managing warehouse employees, their attendance, shifts, leaves, certifications, safety incidents, assets, performance reviews, audit logs, notifications, announcements, onboarding/offboarding tasks, tenants, schedule optimization, and self-service portal.

## Features
- Employee CRUD
- Attendance tracking
- Shift management
- Leave management
- Certification tracking
- Safety incident reporting
- Asset management
- Performance reviews
- Audit logging
- Notifications & announcements
- Onboarding & offboarding tasks
- Multi-tenancy support
- Schedule optimization
- Self-service portal

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway
- Docker

## Getting Started
1. Clone the repository
2. Build with Maven
3. Run with Docker Compose
