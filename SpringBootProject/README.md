# Warehouse Employee Management System

This is a Spring Boot 3.x application for managing warehouse employees, including attendance, scheduling, leave, certifications, safety, assets, performance, payroll, notifications, integrations, audits, reporting, and onboarding.

## Getting Started

- Java 17+
- Maven 3.8+

## Features
- Employee management
- Attendance tracking
- Shift scheduling
- Leave management
- Certification tracking
- Safety incident reporting
- Asset management
- Performance reviews
- Payroll
- Notifications
- Integrations
- Auditing
- Reporting
- Onboarding

## How to Run

1. Configure your database in `src/main/resources/application.yml`
2. Run database migrations
3. Start the application:

```bash
mvn spring-boot:run
```
