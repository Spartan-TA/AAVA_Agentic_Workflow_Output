# Spring Boot Social Platform

A production-ready social platform built with Spring Boot, implementing authentication, user management, posts, comments, likes, notifications, search, admin functions, moderation, analytics, and data export.

## Features
- JWT authentication & role-based authorization
- User registration, profile, password reset, email verification
- CRUD for posts, comments, likes
- Notifications & dashboard
- Search for users and posts
- Admin and moderation tools
- Analytics dashboard
- Data export (CSV)
- Swagger API documentation

## Getting Started
1. Clone the repository
2. Run `mvn clean install`
3. Start with `mvn spring-boot:run`

## API Documentation
Swagger UI: `/swagger-ui.html`

## Configuration
See `application.properties` for database, mail, JWT, and Swagger settings.
