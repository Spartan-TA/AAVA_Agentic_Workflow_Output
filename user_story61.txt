Title: Expose REST APIs for HRIS and WMS Integration

User Story: As a system integrator I want to expose REST APIs for HRIS (new hires/terms) and WMS (location/department) so that master data is synchronized across systems.

Acceptance Criteria:

Scenario: HRIS API creates/updates employees
Given a valid HRIS payload
When I POST to /api/hris/employees
Then the employee record is created or updated in the system

Scenario: WMS API links department/location
Given a valid WMS payload
When I POST to /api/wms/locations
Then the department and location are linked in the system

Scenario: APIs secured with JWT/OAuth2
Given an API request
When the request is authenticated
Then access is granted; otherwise, denied

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: Reduces duplicate entry and ensures data consistency.
