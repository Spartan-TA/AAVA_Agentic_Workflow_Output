Epic E04 - Time & Attendance (Clock In/Out)

User Story 1
Title: Implement Clock-In Endpoint
User Story: As a Warehouse Worker I want to clock in at the start of my shift So that my attendance is recorded
Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift
When I POST to /attendance/clock-in with valid data
Then my clock-in event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate against shift schedule

User Story 2
Title: Implement Clock-Out Endpoint
User Story: As a Warehouse Worker I want to clock out at the end of my shift So that my work hours are tracked
Acceptance Criteria:
Scenario: Successful clock-out
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out event is recorded and hours worked are calculated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Handle missed punches

User Story 3
Title: Handle Missed Punches and Corrections
User Story: As a Supervisor I want to review and approve corrections for missed punches So that attendance records are accurate
Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for the supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 2
- Notes: Track correction history

User Story 4
Title: Export Attendance Reports
User Story: As an HR Manager I want to export attendance data as CSV So that I can analyze and archive records
Acceptance Criteria:
Scenario: Attendance report export
Given attendance data exists
When I request a CSV export
Then the file is generated with correct totals and shift associations
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 2
- Notes: Support date range filters
