# Warehouse Employee Management Platform

This project is a Spring Boot application for managing warehouse employees, attendance, shifts, and more.

## Modules
- Employee Master Data
- Security
- Time & Attendance
- Shift & Schedule Management
- ...and more (20 epics)

## Build & Run

```
mvn clean install
java -jar target/wem-1.0.0.jar
```

See individual module documentation for details.
