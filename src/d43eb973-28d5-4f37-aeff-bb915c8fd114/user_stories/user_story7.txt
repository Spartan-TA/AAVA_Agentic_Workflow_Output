Title: Employee Record Deletion (Soft-Delete)
User Story: As an HR manager I want to soft-delete employee records so that historical data is preserved while inactive employees are hidden from active lists.
Acceptance Criteria:
Scenario: Soft-delete employee record
  Given the HR manager is authenticated
  When they send a DELETE request to /employees/{id}
  Then the employee status is set to inactive and the record is excluded from active queries
Additional Details:
Priority: High
Story Points: 3
Dependencies: Employee Record Creation
Notes: Deleted records must be retrievable for audit and reporting purposes.
