Title: Employee API OpenAPI Schema and Examples

Acceptance Criteria:
Scenario: OpenAPI schema available
  Given the API is deployed

  Then I see all Employee CRUD endpoints with request/response schemas and example payloads
Additional Details:
Priority: High
Story Points: 2

Notes: Examples must cover all fields and error cases.
