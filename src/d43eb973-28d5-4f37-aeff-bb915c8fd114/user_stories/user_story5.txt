Title: Employee Record Creation
User Story: As an HR manager I want to create new employee records with all required fields so that employee data is accurately captured in the system.
Acceptance Criteria:
Scenario: Create employee record
  Given the HR manager is authenticated
  When they submit a POST request to /employees with valid data
  Then a new employee record is created and badgeId is unique
Additional Details:
Priority: High
Story Points: 5
Dependencies: Project Scaffolding
Notes: Validation errors must be returned for missing or duplicate badgeId.
