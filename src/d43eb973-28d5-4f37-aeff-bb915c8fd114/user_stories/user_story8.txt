Title: Employee Record Retrieval with Pagination and Filtering
User Story: As an HR manager I want to retrieve employee records with pagination and filtering options so that I can efficiently manage large numbers of employees.
Acceptance Criteria:
Scenario: Retrieve employee records with filters
  Given the HR manager is authenticated
  When they send a GET request to /employees with query parameters for pagination and filtering
  Then the response contains only the matching records and includes pagination metadata
Additional Details:
Priority: High
Story Points: 5
Dependencies: Employee Record Creation
Notes: Filtering by department, status, and role must be supported.
