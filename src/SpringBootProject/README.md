# Warehouse Employee Management System (Warehouse EMS)

This project is a production-ready Spring Boot 3.x application for managing all aspects of warehouse employee operations, including:
- Employee master data
- Attendance and shift management
- Leave and certification tracking
- Safety, asset, and performance review modules
- Payroll, notifications, integrations, and more

## Build & Run

1. Ensure Java 17+ and Maven are installed.
2. Configure PostgreSQL database (see `application.yml`).
3. Build: `mvn clean install`
4. Run: `mvn spring-boot:run`

See the technical design document for full module and API details.
