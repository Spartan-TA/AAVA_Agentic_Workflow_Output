Title: OSHA Reporting

User Story: As a compliance officer I want to generate OSHA-compliant reports from recorded safety incidents So that the organization meets regulatory reporting requirements

Acceptance Criteria:
Scenario: Generating OSHA report
Given safety incidents are recorded in the system
When I select a reporting period and request an OSHA report
Then the system should generate a formatted OSHA report ready for submission

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Incident log, reporting module
- Notes: Ensure data formatting matches OSHA requirements.
