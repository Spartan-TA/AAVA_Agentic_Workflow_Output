Title: Enforce Unique Badge ID

User Story: As an HR manager I want to ensure each employee has a unique badge ID So that duplicate records are prevented

Acceptance Criteria:
Scenario: Badge ID uniqueness Given I create a new employee When I enter a badge ID that already exists Then the system should reject the entry with an error message

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD
- Notes: Validation required on POST/PUT
