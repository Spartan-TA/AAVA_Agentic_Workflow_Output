### E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint

User Story: As a WORKER I want to clock in via an endpoint So that my attendance is accurately recorded.

Acceptance Criteria:
Scenario: Clock-In Event
Given valid credentials and location
When I POST to /attendance/clock-in
Then my clock-in event is recorded and validated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence validation optional

---

**User Story 2**
Title: Clock-Out Endpoint

User Story: As a WORKER I want to clock out via an endpoint So that my shift hours are tracked.

Acceptance Criteria:
Scenario: Clock-Out Event
Given a clocked-in worker
When I POST to /attendance/clock-out
Then my clock-out event is recorded and hours are calculated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Device capture required

---

**User Story 3**
Title: Missed Punch Correction Workflow

User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records remain accurate.

Acceptance Criteria:
Scenario: Correction Approval
Given a missed punch request
When I review and approve
Then the correction is applied and logged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1, Story 2
- Notes: Approval task generated for supervisor

---

**User Story 4**
Title: Attendance Reporting

User Story: As an HR I want to export attendance reports in CSV So that payroll processing is streamlined.

Acceptance Criteria:
Scenario: Attendance Export
Given attendance data exists
When I request a CSV export
Then the report is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: All attendance stories
- Notes: Export must match payroll requirements
