Title: Employee CRUD API

User Story: As an ADMIN I want to create, read, update, and delete employee records So that employee data is managed centrally

Acceptance Criteria:
Scenario: Create Employee
Given valid employee data
When I POST to /employees
Then a new employee is created with a unique badgeId

Scenario: Update Employee
Given an existing employee
When I PATCH their data
Then the changes are saved

Scenario: Delete Employee
Given an active employee
When I DELETE the record
Then the employee is soft-deleted

Scenario: List Employees
Given multiple employees
When I GET /employees
Then results are paginated and filterable

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Scaffolding & Domain Setup
- Notes: OpenAPI schemas must be provided
