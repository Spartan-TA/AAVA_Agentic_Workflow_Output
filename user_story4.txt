Title: Employee CRUD API - Create Employee
User Story: As an HR manager, I want to create new employee records with all required fields so that onboarding is streamlined and accurate.
Acceptance Criteria:
  - Given valid employee data, When I POST to /employees, Then a new employee is created and a unique badgeId is assigned.
  - Given missing required fields, When I POST to /employees, Then I receive a validation error.
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: Project Scaffolding
  Notes: BadgeId must be unique.
