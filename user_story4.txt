Title: Document Project Build and Run Steps

User Story: As a developer I want a README file with clear build and run instructions So that new team members can quickly set up the project locally

Acceptance Criteria:

Scenario: README Availability
Given the repository is cloned
When I open the README file
Then it should contain step-by-step instructions for building and running the project

Scenario: Troubleshooting Section
Given a build or run error occurs
When I refer to the README
Then I should find troubleshooting tips or links to support resources

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project initialization
- Notes: README must be updated with every major setup change
