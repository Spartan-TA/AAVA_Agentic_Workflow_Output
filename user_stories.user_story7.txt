Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to restrict API endpoints based on user roles So that only authorized users can access sensitive operations

Acceptance Criteria:
Scenario: Endpoint Security
Given a user with a specific role
When they attempt to access a protected endpoint
Then access is granted or denied based on their role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee CRUD
- Notes: Cover ADMIN, HR, SUPERVISOR, WORKER roles; unauthorized requests return 401, forbidden actions return 403.
