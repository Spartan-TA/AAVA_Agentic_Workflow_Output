Title: Enable DB Migrations and Actuator

User Story: As a DevOps Engineer I want to enable database migrations and the Spring Boot Actuator So that the application can be managed and monitored in production

Acceptance Criteria:
Scenario: DB migration and actuator endpoints
Given the application is running
When I access the /actuator/health endpoint
Then I should see a healthy status and DB migrations should have run

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project initialization
- Notes: Use Flyway or Liquibase for migrations
