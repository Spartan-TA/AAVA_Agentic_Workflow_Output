Title: Offline Capability

User Story: As a mobile user I want to access key features of the application even when offline So that I can continue working without an internet connection

Acceptance Criteria:
Scenario: Using app offline
Given I lose internet connectivity
When I use supported features (e.g., view tasks, enter data)
Then the app should function and sync changes when reconnected

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Frontend framework, local storage
- Notes: Clearly indicate offline status and pending syncs to the user.
