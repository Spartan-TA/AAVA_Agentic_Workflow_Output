Title: Announcements

User Story: As an administrator I want to create and schedule announcements to all users So that important information is communicated efficiently

Acceptance Criteria:
Scenario: Creating an announcement
Given I am on the announcements admin page
When I enter announcement details and schedule delivery
Then the announcement should be sent to all users via their preferred channels

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Notification module, user directory
- Notes: Support for immediate and scheduled announcements.
