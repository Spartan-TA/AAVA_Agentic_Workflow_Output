Title: Metrics Endpoints for BI and Performance

User Story: As a business analyst I want metrics endpoints for BI tools and performance so that I can integrate operational data into dashboards and monitor KPIs.

Acceptance Criteria:

Scenario: Metrics endpoint available
Given metrics are tracked
When I access the metrics endpoint
Then I receive real-time data for attendance, overtime, leave, certifications, and safety KPIs

Scenario: Metrics endpoint access controlled
Given a user requests metrics data
When they lack the required role
Then access is denied

Scenario: Metrics endpoint performance
Given large data volumes
When I request metrics
Then the response time is under 10 seconds for up to 50,000 rows

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Supports BI integration and operational monitoring.
