Title: Report Export

User Story: As an operations manager I want to export reports in various formats So that I can share and analyze data outside the system

Acceptance Criteria:
Scenario: Exporting a report
Given a report is generated
When I select an export format (CSV, PDF, XLSX)
Then the system should generate and download the file in the selected format

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Reporting module, export library
- Notes: Exported files should include all applied filters and parameters.
