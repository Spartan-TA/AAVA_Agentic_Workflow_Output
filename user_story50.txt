Title: PDF Export and Immutable History After Sign-Off

User Story: As an HR user I want to export completed performance reviews as PDF and ensure the history is immutable after sign-off so that records are official and tamper-proof.

Acceptance Criteria:

Scenario: Export review as PDF
Given a review is completed
When I request an export
Then I receive a PDF file with all review details

Scenario: Review history is immutable
Given a review is signed off by both supervisor and employee
When I attempt to edit the review
Then the system prevents any changes

Scenario: Role-based access to reviews
Given a user requests a review
When they lack the required role
Then access is denied

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Supports compliance and dispute resolution.
