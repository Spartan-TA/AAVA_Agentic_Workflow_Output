Title: Create Employee API

User Story: As an HR manager I want to create new employee records with all required fields So that I can maintain an accurate and complete employee database

Acceptance Criteria:
Scenario: Successful employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record is created with a unique badgeId and all required fields

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Enforce badgeId uniqueness and validate required fields.
