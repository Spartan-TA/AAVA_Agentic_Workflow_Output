Title: Create Employee Domain and CRUD APIs

User Story: As an HR ADMIN I want to create, read, update, and delete employee records So that I can maintain accurate master data for all warehouse employees

Acceptance Criteria:
Scenario: Employee Creation
Given I have HR admin access
When I submit a new employee record with all required fields
Then the employee is created and assigned a unique badgeId

Scenario: Employee Update
Given an employee record exists
When I update the employee details
Then the changes are saved and reflected in the system

Scenario: Employee Deletion
Given an employee record exists
When I delete the employee
Then the record is soft-deleted and excluded from active lists

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: API must support pagination and filtering
