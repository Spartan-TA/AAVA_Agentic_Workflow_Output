Title: Create Employee Record

User Story: As an HR Manager I want to create a new employee record So that new hires can be onboarded into the system

Acceptance Criteria:
Scenario: Employee record creation
Given I am on the employee creation form
When I enter valid employee details and submit
Then a new employee record should be created and visible in the employee list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Validate required fields and unique identifiers
