Title: Support API Key/OAuth2 Security Toggle

User Story: As a system administrator I want to configure authentication mode (API Key or OAuth2) via configuration So that I can adapt security to organizational requirements

Acceptance Criteria:
Scenario: Security Mode Toggle
Given the application is deployed
When I change the security mode in configuration
Then the system enforces the selected authentication method for all endpoints

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role-based access control
- Notes: Document toggle process and test both modes.
