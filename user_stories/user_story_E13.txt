### E13 - Integration Layer (HRIS/WMS APIs)

**User Story 1**
Title: JWT/OAuth2-Secured REST APIs
User Story: As a Developer I want REST APIs secured with JWT/OAuth2 So that integrations are protected.
Acceptance Criteria:
Scenario: API Security
Given API endpoints
When accessed with valid token
Then data is returned securely

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Security config documented

**User Story 2**
Title: HRIS Sync Job for Employees
User Story: As an HR I want a sync job that creates/updates employees from HRIS So that master data is synchronized.
Acceptance Criteria:
Scenario: HRIS Sync
Given new hires/terms in HRIS
When sync job runs
Then employees are created/updated in EMS

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Idempotency enforced
