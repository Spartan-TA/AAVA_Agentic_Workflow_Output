### E13: Integration Layer (HRIS/WMS APIs)

**User Story 1: Secure REST APIs for HRIS/WMS**
- User Story: As an integration engineer, I want REST APIs for HRIS and WMS sync secured by JWT/OAuth2 So that external systems can synchronize data safely.
- Acceptance Criteria:
  - Scenario: Authenticated API call
    - Given a valid token
    - When I call the API
    - Then data is returned/updated as per OpenAPI spec
  - Scenario: Unauthorized API call
    - Given an invalid token
    - When I call the API
    - Then access is denied
- Priority: High
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: Idempotent webhooks.

**User Story 2: HRIS Sync Job**
- User Story: As a system admin, I want a scheduled job to sync new hires and terms from HRIS So that employee master data is up to date.
- Acceptance Criteria:
  - Scenario: New hire sync
    - Given a new hire in HRIS
    - When the sync job runs
    - Then the employee is created in EMS
  - Scenario: Termination sync
    - Given a terminated employee in HRIS
    - When the sync job runs
    - Then the employee is marked inactive in EMS
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: API documented in OpenAPI.
