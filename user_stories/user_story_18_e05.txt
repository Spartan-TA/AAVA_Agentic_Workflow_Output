Title: Detect Scheduling Conflicts

User Story: As a scheduler I want the system to detect scheduling conflicts So that I can resolve overlapping shifts or double-bookings before publishing the schedule

Acceptance Criteria:
Scenario: Scheduling conflict alert
Given an employee is already assigned to a shift
When I attempt to assign them to an overlapping shift
Then the system displays a conflict warning and prevents the assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Scheduling module, validation logic
- Notes: Include conflicts for time overlap and role mismatch.
