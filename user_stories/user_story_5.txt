Title: Create Employee Record via API

User Story: As an HR manager I want to create new employee records via API So that I can onboard staff efficiently and maintain accurate master data

Acceptance Criteria:
Scenario: Create employee
Given valid employee details
When I POST to /employees
Then a new employee record is created with a unique badgeId

Scenario: Duplicate badgeId
Given an existing badgeId
When I POST a new employee with the same badgeId
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: API must enforce uniqueness and return OpenAPI schema
