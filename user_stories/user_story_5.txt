Title: Create Employee Record via API

User Story: As an HR manager I want to create a new employee record using the API So that I can onboard staff efficiently and maintain accurate master data

Acceptance Criteria:
Scenario: Successful employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record is created and returned with a unique badgeId

Scenario: Duplicate badgeId prevention
Given an employee with a badgeId exists
When I attempt to create another employee with the same badgeId
Then the API returns a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Employee domain includes name, badgeId, role, department, shiftGroup, hireDate, status.
