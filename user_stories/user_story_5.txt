Title: Employee Data Retrieval API

User Story: As an HR administrator I want to retrieve employee records with pagination and filtering So that I can efficiently manage and review employee data

Acceptance Criteria:
Scenario: Retrieve paginated employee list
  Given I am authenticated as an HR administrator
  When I send a GET request to /employees with pagination parameters
  Then I receive a paginated list of employee records

Scenario: Filter employees by department
  Given multiple employees exist in different departments
  When I send a GET request to /employees with a department filter
  Then only employees from the specified department are returned

Scenario: OpenAPI schema availability
  Given the API is documented
  When I view the OpenAPI schema
  Then example requests and responses for employee retrieval are present

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Filtering should support department, role, status, and shiftGroup.
