Title: Update Employee Record

User Story: As an HR user I want to update existing employee records So that employee information remains accurate and up to date

Acceptance Criteria:
Scenario: Updating an employee
Given I am viewing an employee's details
When I edit fields (e.g., department, status) and save changes
Then the updated information is reflected in the system

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD (E02)
- Notes: Only authorized users can update records; changes are tracked for audit
