Title: Create Employee Record

User Story: As an HR Manager I want to create new employee records with name, badgeId, role, department, shiftGroup, hireDate, and status so that all warehouse employees are accurately tracked in the system.

Acceptance Criteria:
Scenario: Successful Employee Creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record should be created and returned with a unique badgeId

Scenario: Duplicate Badge ID
Given an employee with the same badgeId exists
When I attempt to create another employee with that badgeId
Then the system should reject the request with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: API must conform to OpenAPI schema and support web DTOs.
