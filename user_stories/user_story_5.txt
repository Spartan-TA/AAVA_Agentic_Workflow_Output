Title: Implement Role-Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions so that sensitive operations are restricted to authorized users.

Acceptance Criteria:
Scenario: Role-based access enforcement
Given a user with a specific role
When the user attempts an operation outside their permissions
Then the system returns 401 (unauthorized) or 403 (forbidden) as appropriate

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee domain model, project scaffolding
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER; security rules must be covered by tests.
