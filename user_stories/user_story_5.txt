Title: Employee List Pagination and Filtering

User Story: As an HR manager I want to paginate and filter employee lists by department, role, and status So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Paginated and filtered employee list
Given a large set of employee records
When I request employees with pagination and filters applied
Then the API returns only the relevant subset of employees with correct metadata

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Filtering must support department, role, status; pagination metadata must be included in response.
