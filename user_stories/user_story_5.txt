Title: Create Employee Record

User Story: As an HR user I want to create a new employee record with name, badgeId, role, department, shiftGroup, hireDate, and status So that all employee information is centrally managed

Acceptance Criteria:
Scenario: Employee creation
Given I have HR role access
When I submit a valid employee creation request
Then the employee is added to the system and assigned a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: user_story_1
- Notes: badgeId must be unique; validation errors must be returned for missing/invalid fields
