Title: Employee CRUD API
User Story: As an HR user I want to create, read, update, and delete employee records via API So that employee data is managed centrally and accurately.
Acceptance Criteria:
Scenario: Create employee
  Given valid employee data
  When I POST to /employees
  Then a new employee is created with a unique badgeId

Scenario: Update employee
  Given an existing employee
  When I PUT or PATCH to /employees/{id}
  Then the employee data is updated

Scenario: Delete employee (soft delete)
  Given an existing employee
  When I DELETE /employees/{id}
  Then the employee is marked as inactive (soft delete)

Scenario: List and filter employees
  Given multiple employees exist
  When I GET /employees with filters
  Then the response is paginated and filtered as requested

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: OpenAPI schema with examples required.
