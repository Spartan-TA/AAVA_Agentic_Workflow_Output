Title: Create Employee Record

User Story: As an HR manager I want to create a new employee record with all required fields so that new hires are accurately represented in the EMS.

Acceptance Criteria:
Scenario: Successful Employee Creation
  Given I have valid employee details
  When I submit a POST request to /employees
  Then a new employee record is created and returned with a unique badgeId

Scenario: Missing Required Fields
  Given I submit incomplete employee details
  When I attempt to create an employee
  Then the API should return a validation error specifying missing fields

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: All fields (name, badgeId, role, department, shiftGroup, hireDate, status) must be validated; OpenAPI schema must be updated.
