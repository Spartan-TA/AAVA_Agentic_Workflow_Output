Title: Upload and Manage Proof Documents for Certifications

User Story:
As an employee or HR manager, I want to upload and manage proof documents for certifications so that compliance can be verified and audits are streamlined.

Acceptance Criteria:
- Scenario: Upload proof document for certification
  Given a certification is being added or updated
  When a valid document is uploaded
  Then it is securely stored and linked to the certification record

- Scenario: View/download proof document
  Given a certification has a proof document
  When an authorized user views the certification
  Then they can view or download the document

Additional Details:
- Documents must be stored securely and access-controlled
- Only authorized roles (HR, supervisor, employee) can upload/view
- All uploads and downloads must be logged for audit
