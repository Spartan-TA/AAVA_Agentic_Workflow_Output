Title: Employee API Sorting
User Story: As an HR user I want to sort employee records by name, hire date, or department via API So that I can organize data for reporting
Acceptance Criteria:
Scenario: Sort by Name
Given employee records exist
When I GET /employees?sort=name,asc
Then employees are returned in ascending name order
Scenario: Sort by Hire Date
Given employee records exist
When I GET /employees?sort=hireDate,desc
Then employees are returned in descending hire date order
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Support multi-field sorting
