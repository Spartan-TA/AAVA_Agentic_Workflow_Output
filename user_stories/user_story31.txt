Title: Safety Metrics Dashboard

User Story: As a warehouse manager I want to view safety metrics and KPIs on a dashboard So that I can monitor trends and take proactive actions

Acceptance Criteria:
Scenario: Safety dashboard metrics
Given safety incidents are recorded
When I access the dashboard
Then I see metrics such as incident rate, severity, and resolution time

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Safety Incident Recording, Reporting & Analytics
- Notes: Dashboard should support filtering by date, location, and severity.
