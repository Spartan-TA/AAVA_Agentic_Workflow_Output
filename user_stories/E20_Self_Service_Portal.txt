## E20 - Self-Service Portal

### Story 1: Employee Self-Service Dashboard
- **User Story:** As a Worker, I want a self-service dashboard so that I can view my profile, schedule, leave balance, and certifications.
- **Acceptance Criteria:**
    ```
    Given I am logged in
    When I access the dashboard
    Then I see my profile, upcoming shifts, leave balance, and certifications
    ```
- **Additional Details:**  
    Priority: Medium  
    Story Points: 3  
    Dependencies: E02, E04, E05, E06, E07  
    Notes: Mobile-friendly.

### Story 2: Submit Requests via Portal
- **User Story:** As a Worker, I want to submit leave, correction, and asset requests via the portal so that I can manage my needs independently.
- **Acceptance Criteria:**
    ```
    Given the self-service portal
    When I submit a request
    Then it is routed to the appropriate workflow for approval
    ```
- **Additional Details:**  
    Priority: Medium  
    Story Points: 3  
    Dependencies: E06, E09  
    Notes: Track request status.

### Story 3: View Notifications and Announcements
- **User Story:** As a Worker, I want to view all my notifications and announcements in one place so that I stay informed.
- **Acceptance Criteria:**
    ```
    Given notifications and announcements
    When I access the portal
    Then I see all unread and past messages
    ```
- **Additional Details:**  
    Priority: Low  
    Story Points: 2  
    Dependencies: E12  
    Notes: Mark as read.
