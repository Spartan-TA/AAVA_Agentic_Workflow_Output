### E03: Role Based Access Control (RBAC)

#### Title: Implement Spring Security Roles
User Story: As a system admin I want to configure roles (ADMIN, HR, SUPERVISOR, WORKER) So that access to sensitive operations is restricted
Acceptance Criteria:
Scenario: Unauthorized access
Given I am not authenticated
When I access a protected endpoint
Then I receive a 401 Unauthorized

Scenario: Forbidden action
Given I am authenticated as WORKER
When I attempt to update employee data
Then I receive a 403 Forbidden

Scenario: ADMIN access
Given I am authenticated as ADMIN
When I access any endpoint
Then I can manage all records

Scenario: SUPERVISOR access
Given I am authenticated as SUPERVISOR
When I access team data
Then I can manage only my team

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Security rules covered by tests

#### Title: Method/Endpoint Security
User Story: As a developer I want to enforce security at method and endpoint level So that only authorized roles can perform actions
Acceptance Criteria:
Scenario: Endpoint security
Given endpoints are defined
When I access them with different roles
Then access is granted or denied per role
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Implement Spring Security Roles
- Notes: Include row-level constraints where applicable

#### Title: API Key/OAuth2 Toggle
User Story: As a DevOps engineer I want to toggle between API key and OAuth2 authentication via config So that integration partners can use preferred auth
Acceptance Criteria:
Scenario: Auth toggle
Given the config is set to API key
When I authenticate with API key
Then access is granted

Scenario: Auth toggle
Given the config is set to OAuth2
When I authenticate with OAuth2
Then access is granted

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Implement Spring Security Roles
- Notes: Document toggle in README
