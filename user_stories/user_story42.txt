Title: Audit Trail Logging

User Story: As a compliance officer I want all user actions to be logged in an audit trail So that I can review and investigate system activity for security and compliance

Acceptance Criteria:
Scenario: Logging user actions
Given a user performs an action in the system
When the action is completed
Then a detailed log entry should be created with timestamp, user, and action details

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Logging module
- Notes: Support for filtering and searching logs.
