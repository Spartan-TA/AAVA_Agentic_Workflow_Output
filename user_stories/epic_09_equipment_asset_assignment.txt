Title: Assign Equipment & Assets
User Story: As a supervisor I want to assign equipment and assets to employees So that accountability is maintained
Acceptance Criteria:
Scenario: Asset Assignment
Given asset registry
When I assign assets
Then check-in/out is tracked and history is logged
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee CRUD, RBAC, Certification tracking
- Notes: Prevent use if certification missing

Title: Block Asset Use for Invalid Certifications
User Story: As a supervisor I want to block asset use if certification is invalid So that only qualified employees use equipment
Acceptance Criteria:
Scenario: Certification Validation
Given an asset requiring certification
When an employee with expired certification attempts check-out
Then the system blocks the action
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment, Certification tracking
- Notes: Alert supervisor
