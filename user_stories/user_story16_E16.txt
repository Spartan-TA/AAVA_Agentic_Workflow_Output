### E16 - Mobile Access (PWA)

**Title:** Mobile Clock-In/Out
User Story: As a worker I want to clock in/out via mobile So that attendance is easy on shared or personal devices
Acceptance Criteria:
Scenario: Mobile clock-in
Given mobile device
When I access EMS
Then I can clock in/out
Scenario: Offline queue
Given no connectivity
When I clock in
Then event is queued and synced when online
Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E04, E05, E06, E12
- Notes: Conflict resolution required
