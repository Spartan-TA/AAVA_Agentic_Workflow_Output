Title: Enforce Permissions on Feature Access

User Story: As a system user I want to be restricted from accessing features outside my role So that I only see and use functionalities relevant to my responsibilities

Acceptance Criteria:
Scenario: Accessing a restricted feature
Given I am logged in with a role lacking certain permissions
When I attempt to access a restricted feature
Then I should receive an access denied message and be prevented from proceeding

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Roles and permissions assignment
- Notes: All unauthorized access attempts should be logged for security review.
