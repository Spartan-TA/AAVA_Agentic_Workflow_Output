Title: Leave Request and Approval
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my time off is tracked and approved according to policy.
Acceptance Criteria:
Scenario: Submit leave request
  Given sufficient accrual balance
  When I submit a leave request
  Then the request is created and pending approval

Scenario: Supervisor approval/denial
  Given a pending leave request
  When a supervisor reviews it
  Then they can approve or deny the request

Scenario: Accrual balance update
  Given an approved leave
  When the leave is taken
  Then my balance is reduced accordingly

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E05
- Notes: Integration hooks for scheduling and payroll.
