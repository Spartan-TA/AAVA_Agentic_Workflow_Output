Title: HRIS Data Sync via REST API
User Story: As an HR administrator I want to synchronize employee data with the HRIS system via REST API So that records remain consistent and up-to-date
Acceptance Criteria:
Scenario: HRIS sync
  Given new or updated employee data exists
  When I trigger HRIS sync
  Then the system should send data to the HRIS via REST API and confirm success
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: HRIS API, employee profile
- Notes: Error handling for failed sync
