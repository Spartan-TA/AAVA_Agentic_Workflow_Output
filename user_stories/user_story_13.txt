Title: View and Manage Permissions for Roles

User Story: As an admin I want to view and manage permissions for each role So that I can ensure roles remain up-to-date and secure

Acceptance Criteria:
Scenario: Permission management
Given I am on the roles management page
When I select a role and edit its permissions
Then the changes should be saved and reflected in the system

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Role assignment
- Notes: Permission changes should trigger notifications to affected users
