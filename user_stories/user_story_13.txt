Title: Restrict Feature Access by Role

User Story: As a user I want access to be restricted based on my assigned role So that I only see and use features relevant to my responsibilities

Acceptance Criteria:
Scenario: Accessing a restricted feature
  Given I am logged in with a specific role
  When I attempt to access a feature outside my permissions
  Then I should receive an access denied message
Scenario: Accessing an allowed feature
  Given I am logged in with a role that has permission
  When I access a permitted feature
  Then I should be able to use the feature without restriction

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role assignment, feature flagging
- Notes: UI should dynamically hide or disable features based on role.
