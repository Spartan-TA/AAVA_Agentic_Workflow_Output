### E09 - Equipment & Asset Assignment

#### User Story 1: Asset Registry CRUD
- **Title:** Asset Registry CRUD
- **User Story:** As an ADMIN, I want to create, read, update, and delete assets (scanners, forklifts, PPE) so that inventory is tracked.
- **Acceptance Criteria:**
    - Given an asset,
      When I create or update it,
      Then it is saved in the registry.
    - Given a delete request,
      When I delete an asset,
      Then it is removed if not assigned.
- **Priority:** Medium
- **Story Points:** 3
- **Dependencies:** E02, E03, E07
- **Notes:** Asset management.

#### User Story 2: Assign and Return Assets to Employees
- **Title:** Assign and Return Assets to Employees
- **User Story:** As a SUPERVISOR, I want to assign and track checkout/return of assets to employees so that accountability is maintained.
- **Acceptance Criteria:**
    - Given an available asset,
      When I assign it to an employee,
      Then the assignment is recorded.
    - Given a return,
      When the asset is checked in,
      Then the status is updated.
- **Priority:** Medium
- **Story Points:** 3
- **Dependencies:** E09-1
- **Notes:** Tracks usage.

#### User Story 3: Block Asset Assignment if Certification Invalid
- **Title:** Block Asset Assignment if Certification Invalid
- **User Story:** As a SYSTEM, I want to prevent assignment of assets if the employee lacks required certifications so that safety is enforced.
- **Acceptance Criteria:**
    - Given an employee without valid certification,
      When I try to assign a restricted asset,
      Then the system blocks the assignment.
- **Priority:** Medium
- **Story Points:** 2
- **Dependencies:** E09-1, E07
- **Notes:** Safety compliance.

#### User Story 4: Asset Condition Tracking
- **Title:** Track Asset Condition State
- **User Story:** As a SUPERVISOR, I want to record the condition of assets at checkout and return so that maintenance needs are identified.
- **Acceptance Criteria:**
    - Given an asset,
      When it is checked out or in,
      Then the condition is logged.
- **Priority:** Medium
- **Story Points:** 2
- **Dependencies:** E09-2
- **Notes:** Maintenance planning.

#### User Story 5: Overdue Asset Return Reports
- **Title:** Generate Reports of Overdue Asset Returns
- **User Story:** As an ADMIN, I want to generate reports of overdue asset returns so that follow-up actions can be taken.
- **Acceptance Criteria:**
    - Given asset assignment data,
      When I request a report,
      Then all overdue returns are listed.
- **Priority:** Medium
- **Story Points:** 1
- **Dependencies:** E09-2
- **Notes:** Accountability.
