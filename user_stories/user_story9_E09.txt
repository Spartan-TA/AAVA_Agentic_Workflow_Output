### E09 - Equipment & Asset Assignment

**Title:** Asset Registry CRUD
User Story: As an asset manager I want to add, edit, and remove assets So that all equipment is tracked
Acceptance Criteria:
Scenario: Add asset
Given valid asset data
When I POST to `/assets`
Then the asset is added to the registry
Scenario: Remove asset
Given an asset is retired
When I DELETE
Then the asset is removed
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Includes scanners, forklifts, PPE

---

**Title:** Asset Check-In/Check-Out
User Story: As a supervisor I want to assign and track asset check-in/out So that accountability is maintained
Acceptance Criteria:
Scenario: Check-out asset
Given an available asset
When I assign to an employee
Then the asset status updates to checked out
Scenario: Check-in asset
Given an asset is returned
When I mark as checked in
Then the asset status updates
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: History log per asset and employee

---

**Title:** Certification Block on Asset Assignment
User Story: As a supervisor I want asset assignment blocked if required certification is missing So that only qualified staff use equipment
Acceptance Criteria:
Scenario: Block assignment
Given an employee without valid cert
When I try to assign a forklift
Then the system prevents the assignment
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Certification check enforced

---

**Title:** Overdue Asset Return Report
User Story: As an asset manager I want reports of overdue asset returns So that lost or delayed equipment is tracked
Acceptance Criteria:
Scenario: Generate overdue report
Given assets checked out past due date
When I request a report
Then all overdue assets are listed
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Report visible to supervisors
