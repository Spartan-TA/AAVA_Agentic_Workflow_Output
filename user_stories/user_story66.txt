Title: Prometheus Metrics Endpoint and Health Checks

User Story: As a DevOps engineer I want metrics exported on /actuator/prometheus and health checks for DB and external APIs So that system health and performance are monitored proactively

Acceptance Criteria:
Scenario: Metrics and health check availability
Given the system is running
When I access the metrics endpoint or trigger a health check
Then metrics are exported and health checks validate DB and external API status

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E01
- Notes: Health checks must be documented and alert on failures
