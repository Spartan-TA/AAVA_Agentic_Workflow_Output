Title: Role-Based Dashboards and Metrics Endpoints

User Story:
As a supervisor or admin, I want to access dashboards and metrics endpoints filtered by my role so that I see only relevant data for my team or department.

Acceptance Criteria:
- Scenario: Supervisor views team dashboard
  Given a supervisor is authenticated
  When they access the dashboard
  Then only data for their team is displayed

- Scenario: Admin views all data
  Given an admin is authenticated
  When they access the dashboard
  Then data for all departments is displayed

- Scenario: Metrics endpoints are available for BI
  Given metrics endpoints are implemented
  When a BI tool queries the endpoint
  Then operational metrics are returned in a standard format

Additional Details:
- Dashboards must be mobile-friendly
- Access controls must be enforced in API and UI
- All dashboard and endpoint access must be logged
