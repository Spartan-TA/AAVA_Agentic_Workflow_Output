Title: Publish API Docs and Architecture Diagrams

User Story: As a developer I want API documentation (OpenAPI) and architecture diagrams published in the repository so that integration and onboarding are efficient

Acceptance Criteria:
Scenario: Publish docs and diagrams
  Given new APIs or architecture changes are made
  When I update the documentation
  Then the OpenAPI spec and diagrams are available in the docs/ directory

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E01 (Core), E19 (Testing/CI)
- Notes: Docs must be versioned and accessible to all developers
