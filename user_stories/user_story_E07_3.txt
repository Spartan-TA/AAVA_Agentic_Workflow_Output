Title: Block Assignment to Tasks Requiring Certification

User Story: As a supervisor I want the system to block assignment to tasks requiring certification if the employee lacks it So that compliance is maintained

Acceptance Criteria:
Scenario: Assignment with missing certification
Given a task requires a specific certification
When I attempt to assign an unqualified employee
Then the system should prevent the assignment and alert me

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Task assignment logic
- Notes: Support override with justification and audit entry.
