Title: Block Assignment to Tasks Requiring Expired Certifications

User Story: As a supervisor I want the system to prevent assignment of employees to equipment or tasks if their required certifications are expired so that safety and compliance are enforced

Acceptance Criteria:
Scenario: Prevent assignment with expired certification
Given an employee's certification is expired
When I attempt to assign them to a task or equipment requiring that certification
Then the system blocks the assignment and displays an error message

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, Equipment & Asset Assignment
- Notes: Error message must specify which certification is expired; override not permitted.
