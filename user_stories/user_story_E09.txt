### E09 - Equipment & Asset Assignment

**User Story 1**
Title: Manage Asset Registry
User Story: As an asset manager, I want to CRUD assets so that all equipment is tracked.
Acceptance Criteria:
Scenario: Asset CRUD
Given asset data
When I create, update, or delete an asset
Then the asset registry is updated
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Include asset type, condition, and assignment status.

**User Story 2**
Title: Assign and Return Assets
User Story: As a supervisor, I want to check out and return assets to employees so that usage is tracked.
Acceptance Criteria:
Scenario: Asset assignment
Given an available asset
When I assign it to an employee
Then the assignment is logged and asset status is updated
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Prevent assignment if certification is invalid.

**User Story 3**
Title: Block Asset Use Without Valid Certification
User Story: As a supervisor, I want to prevent asset use if the employee lacks required certification so that safety is enforced.
Acceptance Criteria:
Scenario: Certification check
Given an employee without a valid certification
When I assign a restricted asset
Then the system blocks the assignment
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Integrate with certification tracking.

**User Story 4**
Title: View Asset Assignment History
User Story: As an asset manager, I want to view the history of asset assignments so that accountability is maintained.
Acceptance Criteria:
Scenario: Assignment history
Given an asset
When I view its history
Then I see all check-in/out events with employee and timestamp
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Support filtering by date and employee.

**User Story 5**
Title: Report Overdue Asset Returns
User Story: As an asset manager, I want to report overdue returns so that lost or unreturned assets are flagged.
Acceptance Criteria:
Scenario: Overdue report
Given assets checked out past due date
When I generate a report
Then all overdue assets are listed with assigned employee
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Notify responsible employees.
