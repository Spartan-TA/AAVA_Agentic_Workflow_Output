EPIC E09 - EQUIPMENT & ASSET ASSIGNMENT

===========================================
User Story 1
===========================================

Title: Manage Asset Registry

User Story: As an asset manager I want to maintain a registry of equipment and PPE So that all assets are tracked

Acceptance Criteria:
Scenario: Asset CRUD
Given the asset module
When I add/edit/delete an asset
Then the registry is updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Asset types: scanners, forklifts, PPE

===========================================
User Story 2
===========================================

Title: Assign and Track Asset Check-In/Out

User Story: As a supervisor I want to assign assets to employees and track check-in/out So that accountability is ensured

Acceptance Criteria:
Scenario: Asset assignment
Given an available asset
When I assign it to an employee
Then the check-out is recorded and history updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E09
- Notes: Overdue returns flagged

===========================================
User Story 3
===========================================

Title: Block Asset Use Without Valid Certification

User Story: As a system I want to prevent asset use if required certification is missing So that safety is enforced

Acceptance Criteria:
Scenario: Certification check
Given an employee without valid cert
When they attempt to check out restricted equipment
Then the system blocks the action

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E09
- Notes: Applies to forklifts, etc.

===========================================
User Story 4
===========================================

Title: Maintain Asset Condition State

User Story: As an asset manager I want to record asset condition at check-in/out So that maintenance needs are tracked

Acceptance Criteria:
Scenario: Condition logging
Given an asset check-in/out
When condition is recorded
Then it is stored in the asset history

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E09
- Notes: Condition options: Good, Needs Repair, Out of Service
