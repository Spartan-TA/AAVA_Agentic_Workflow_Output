EPIC E09: Equipment & Asset Assignment

===========================================

Title: Manage Asset Registry
User Story: As an asset manager, I want to add, edit, and remove equipment records so that the asset registry is accurate.
Acceptance Criteria:
Scenario: Adding an asset
Given I am on the asset registry page
When I add a new asset with type, serial number, and condition
Then the asset is saved and visible in the registry
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Supports multiple asset types.

===========================================

Title: Assign Equipment to Employees
User Story: As a supervisor, I want to check out equipment to employees and track returns so that asset usage is accountable.
Acceptance Criteria:
Scenario: Checking out equipment
Given an asset is available
When I assign it to an employee
Then the assignment is recorded with timestamp and due date
Scenario: Returning equipment
Given an asset is checked out
When it is returned
Then the return is logged and condition updated
Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E07
- Notes: Tracks asset condition changes.

===========================================

Title: Block Asset Assignment Without Valid Certification
User Story: As a system, I want to prevent assignment of equipment requiring certification to unqualified employees so that safety is ensured.
Acceptance Criteria:
Scenario: Certification check
Given an employee lacks a valid certification
When I attempt to assign restricted equipment
Then the system blocks the assignment and displays an error
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E07
- Notes: Real-time validation required.

===========================================

Title: View Asset Assignment History
User Story: As an auditor, I want to view the history of asset assignments per asset and employee so that I can track accountability.
Acceptance Criteria:
Scenario: Viewing history
Given an asset or employee is selected
When I view the assignment history
Then all check-in/out events are listed with timestamps and actors
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E14
- Notes: Immutable history log.

===========================================

Title: Report Overdue Asset Returns
User Story: As an asset manager, I want to generate reports of overdue asset returns so that I can follow up with responsible employees.
Acceptance Criteria:
Scenario: Overdue report
Given assets are checked out
When the due date passes without return
Then the asset appears in the overdue report and notifications are sent
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E12
- Notes: Automated notifications preferred.
