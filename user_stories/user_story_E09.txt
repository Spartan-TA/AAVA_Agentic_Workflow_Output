### E09: Equipment & Asset Assignment

**User Story 1: Asset Registry and Assignment**
- User Story: As an asset manager, I want to assign equipment (scanners, forklifts, PPE) to employees and track check-in/out So that asset usage is accountable.
- Acceptance Criteria:
  - Scenario: Assign asset
    - Given an available asset
    - When I assign it to an employee
    - Then the asset is marked as checked out
  - Scenario: Return asset
    - Given a checked-out asset
    - When I check it in
    - Then the asset is marked as available
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E07
- Notes: Asset condition tracked.

**User Story 2: Certification Validation for Asset Use**
- User Story: As an asset manager, I want to prevent asset assignment if the employee lacks required certification So that only qualified employees use sensitive equipment.
- Acceptance Criteria:
  - Scenario: Certification check
    - Given an employee without valid certification
    - When I assign a restricted asset
    - Then the system blocks the assignment
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Overdue returns reportable.
