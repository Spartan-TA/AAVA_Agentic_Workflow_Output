### E09 - Equipment & Asset Assignment

#### User Story 1
Title: Asset Registry CRUD
User Story: As an ADMIN, I want to manage asset registry so that equipment and PPE are tracked.
Acceptance Criteria:
Scenario: Asset Management
Given asset records
When ADMIN performs CRUD operations
Then assets are added, updated, or removed
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Asset types include scanners, forklifts, PPE

#### User Story 2
Title: Asset Check-In/Check-Out
User Story: As a WORKER, I want to check in/out assets so that usage is tracked.
Acceptance Criteria:
Scenario: Asset Checkout
Given a WORKER with valid certification
When they check out an asset
Then the asset is assigned and history logged
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Blocks if certification invalid

#### User Story 3
Title: Block Asset Use Without Certification
User Story: As a SUPERVISOR, I want asset checkout to be blocked if certification is missing so that safety is enforced.
Acceptance Criteria:
Scenario: Certification Block
Given a WORKER without valid certification
When they attempt asset checkout
Then the operation is blocked
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E07
- Notes: Error message shown

#### User Story 4
Title: Asset Condition Tracking
User Story: As a WORKER, I want to update asset condition status so that maintenance needs are flagged.
Acceptance Criteria:
Scenario: Condition Update
Given an asset
When WORKER updates condition
Then status is recorded
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E07
- Notes: Condition history visible

#### User Story 5
Title: Overdue Asset Return Reporting
User Story: As an ADMIN, I want reports of overdue asset returns so that accountability is maintained.
Acceptance Criteria:
Scenario: Overdue Report
Given asset checkout records
When ADMIN requests report
Then overdue assets are listed
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E07
- Notes: Report format configurable
