### E09 - Equipment & Asset Assignment

**User Story 1**
- Title: Asset Registry CRUD
- User Story: As an asset manager, I want to create, update, and delete assets (scanners, forklifts, PPE) so that inventory is tracked.
- Acceptance Criteria:
  - Given the asset API is available,
    When I create/update/delete an asset,
    Then the registry is updated.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: Asset tracking.

**User Story 2**
- Title: Asset Check-In/Check-Out Endpoints
- User Story: As a supervisor, I want endpoints for asset check-in/out so that usage is tracked.
- Acceptance Criteria:
  - Given an asset exists,
    When I check it out/in,
    Then the event is recorded and linked to the employee.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: Usage tracking.

**User Story 3**
- Title: Block Asset Use if Certification Missing
- User Story: As a supervisor, I want asset use blocked if required certifications are invalid so that safety is enforced.
- Acceptance Criteria:
  - Given an asset requires certification,
    When the employee's cert is invalid,
    Then check-out is blocked and an error is shown.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: Safety enforcement.

**User Story 4**
- Title: Maintain Asset Condition State
- User Story: As an asset manager, I want to track asset condition so that maintenance needs are visible.
- Acceptance Criteria:
  - Given an asset is checked in,
    When condition is reported,
    Then the state is updated in the registry.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: Maintenance tracking.

**User Story 5**
- Title: Report Overdue Asset Returns
- User Story: As a supervisor, I want reports of overdue asset returns so that accountability is enforced.
- Acceptance Criteria:
  - Given assets are checked out,
    When return is overdue,
    Then the asset and employee are flagged in the report.
- Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E07, Notes: Accountability.
