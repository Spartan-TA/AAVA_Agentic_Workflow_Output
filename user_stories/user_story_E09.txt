### E09: Equipment & Asset Assignment

#### User Story 1
Title: Manage Equipment and Asset Registry
User Story: As an asset manager, I want to add, update, and remove assets so that inventory is accurate.
Acceptance Criteria:
Scenario: Asset management
  Given I am an asset manager
  When I create or update an asset
  Then it appears in the registry with type, condition, and assignment status
Additional Details:
Priority: Medium
Story Points: 5
Dependencies: E02, E03
Notes: Asset types include scanners, forklifts, PPE.

#### User Story 2
Title: Equipment Check-In/Check-Out
User Story: As a supervisor, I want to assign or collect equipment from employees so that usage is tracked.
Acceptance Criteria:
Scenario: Check-out
  Given an asset is available
  When I assign it to an employee
  Then the assignment is logged with timestamp
Scenario: Check-in
  Given an asset is checked out
  When it is returned
  Then the return is logged and condition is updated
Additional Details:
Priority: Medium
Story Points: 5
Dependencies: E07
Notes: Overdue returns should trigger alerts.

#### User Story 3
Title: Block Asset Assignment Without Valid Certification
User Story: As a supervisor, I want to prevent assignment of equipment to employees lacking required certifications so that safety is ensured.
Acceptance Criteria:
Scenario: Certification check
  Given an employee lacks a valid certification
  When I attempt to assign restricted equipment
  Then the system blocks the assignment and displays a warning
Additional Details:
Priority: High
Story Points: 3
Dependencies: E07
Notes: Applies to forklifts and other regulated assets.

#### User Story 4
Title: Asset Assignment and Condition History
User Story: As an asset manager, I want to view the history of asset assignments and condition changes so that I can track usage and maintenance.
Acceptance Criteria:
Scenario: View history
  Given an asset is selected
  When I view its history
  Then I see all assignments, returns, and condition updates
Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E15
Notes: History should be exportable.
