### E09 - Equipment & Asset Assignment

**User Story 1: Asset Registry CRUD**
- Title: Manage Asset Registry
- Narrative: As an asset manager, I want to create, update, and delete asset records so that inventory is accurate.
- Acceptance Criteria:
  ```
  Given asset data,
  When I perform CRUD,
  Then assets are managed in the registry.
  ```
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Asset tracking.

**User Story 2: Asset Check-In/Out Endpoints**
- Title: Asset Check-In/Out
- Narrative: As an employee, I want to check out and return assets so that usage is tracked.
- Acceptance Criteria:
  ```
  Given an asset,
  When I check out or return,
  Then the transaction is recorded and validated.
  ```
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1
- Notes: Accountability.

**User Story 3: Certification Validation for Asset Use**
- Title: Validate Certification for Asset Use
- Narrative: As a supervisor, I want asset use blocked if required certifications are missing so that safety is enforced.
- Acceptance Criteria:
  ```
  Given an asset requiring certification,
  When an unqualified employee attempts check-out,
  Then the system blocks the transaction.
  ```
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1, E07
- Notes: Safety.

**User Story 4: Asset History Log**
- Title: Asset Usage History Log
- Narrative: As an asset manager, I want a history log of asset usage so that audits are possible.
- Acceptance Criteria:
  ```
  Given an asset,
  When I view its history,
  Then all check-in/out events are listed.
  ```
- Priority: Medium
- Story Points: 1
- Dependencies: Story 2
- Notes: Auditability.

**User Story 5: Overdue Asset Return Reports**
- Title: Report Overdue Asset Returns
- Narrative: As a supervisor, I want reports of overdue asset returns so that assets are recovered promptly.
- Acceptance Criteria:
  ```
  Given asset check-out data,
  When assets are overdue,
  Then a report is generated listing them.
  ```
- Priority: Medium
- Story Points: 1
- Dependencies: Story 2
- Notes: Asset recovery.
