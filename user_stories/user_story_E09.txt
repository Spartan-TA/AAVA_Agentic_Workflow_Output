### E09 - Equipment & Asset Assignment

**User Story 1**
Title: Asset Registry CRUD
User Story: As an ADMIN I want to manage asset registry So that equipment and PPE are tracked.
Acceptance Criteria:
Scenario: Asset Management
Given asset details
When I create, update, or delete an asset
Then the registry reflects the changes

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Asset condition tracked

**User Story 2**
Title: Asset Check-In/Out Endpoints
User Story: As a SUPERVISOR I want to check assets in and out to employees So that usage is monitored.
Acceptance Criteria:
Scenario: Asset Checkout
Given an employee and asset
When I check out the asset
Then the assignment is recorded and blocked if certs are invalid

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: User Story 1
- Notes: Certification checks enforced

**User Story 3**
Title: Asset History Log
User Story: As an ADMIN I want to view asset history per asset and employee So that accountability is maintained.
Acceptance Criteria:
Scenario: Asset History Viewing
Given asset assignments
When I view asset history
Then all check-in/out events are displayed

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Log includes overdue returns

**User Story 4**
Title: Overdue Asset Return Reports
User Story: As a SUPERVISOR I want reports of overdue asset returns So that follow-up actions can be taken.
Acceptance Criteria:
Scenario: Overdue Report Generation
Given asset assignments
When I request overdue reports
Then all overdue assets are listed

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Report format configurable
