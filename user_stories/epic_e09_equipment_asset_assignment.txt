EPIC E09: Equipment & Asset Assignment

---

Title: Asset Registry CRUD

User Story: As an asset manager I want to manage the asset registry via CRUD So that equipment records are accurate

Acceptance Criteria:
Scenario: Asset CRUD
Given I have access
When I create, update, or delete assets
Then changes are reflected immediately

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee Master Data, RBAC, Training & Certification Tracking
- Notes: Scanners, forklifts, PPE

---

Title: Check-In/Out Endpoints

User Story: As a worker I want to check out and return equipment So that asset usage is tracked

Acceptance Criteria:
Scenario: Asset checkout
Given an asset is available
When I check it out
Then the asset is assigned to me

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Registry CRUD
- Notes: Return tracked

---

Title: Block Checkout When Certs Invalid

User Story: As an asset manager I want to block equipment checkout when certifications are invalid So that safety is ensured

Acceptance Criteria:
Scenario: Certification check
Given my forklift cert is expired
When I try to check out a forklift
Then the system prevents the checkout

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Check-In/Out Endpoints
- Notes: Certification validation

---

Title: History Log Per Asset and Employee

User Story: As an asset manager I want to view history logs per asset and employee So that usage is auditable

Acceptance Criteria:
Scenario: History view
Given an asset has been checked out
When I view its history
Then all checkout/return events are listed

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Check-In/Out Endpoints
- Notes: Immutable log

---

Title: Reports of Overdue Returns

User Story: As an asset manager I want reports of overdue returns So that assets are recovered

Acceptance Criteria:
Scenario: Overdue report
Given assets are overdue
When I generate the report
Then overdue items are listed with employee details

Additional Details:
- Priority: Low
- Story Points: 1
- Dependencies: Check-In/Out Endpoints
- Notes: Exportable CSV
