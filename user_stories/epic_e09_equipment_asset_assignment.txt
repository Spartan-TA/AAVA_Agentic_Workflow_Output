EPIC E09: EQUIPMENT & ASSET ASSIGNMENT

===========================================

Title: Asset Registry CRUD

User Story: As an asset manager I want to manage the asset registry So that all equipment and PPE are tracked

Acceptance Criteria:

Scenario: Add asset
Given asset details
When I POST to /assets
Then the asset is registered

Scenario: Edit asset
Given an asset exists
When I PUT/PATCH to /assets/{id}
Then the asset is updated

Scenario: Delete asset
Given an asset exists
When I DELETE /assets/{id}
Then the asset is removed

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data, Role-Based Access Control, Certification Tracking
- Notes: Track asset condition state

---

Title: Asset Assignment and Certification Check

User Story: As a supervisor I want to assign assets to employees and check certifications So that only qualified staff use equipment

Acceptance Criteria:

Scenario: Assign asset
Given an employee has valid certification
When I assign an asset
Then the assignment is successful

Scenario: Certification invalid
Given an employee lacks certification
When I assign an asset
Then the assignment is blocked

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Asset Registry CRUD
- Notes: History log per asset and employee

---

Title: Asset Checkout/Return and Overdue Reporting

User Story: As an asset manager I want to track asset checkout/return and report overdue returns So that accountability is maintained

Acceptance Criteria:

Scenario: Checkout asset
Given an asset is available
When an employee checks out
Then the event is logged

Scenario: Return asset
Given an asset is checked out
When it is returned
Then the event is logged

Scenario: Overdue report
Given assets are overdue
When I request a report
Then overdue assets are listed

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Asset Assignment and Certification Check
- Notes: Reports exportable
