Title: Support Pagination and Filtering in Employee API

User Story: As an HR Manager I want to paginate and filter employee records via API So that I can efficiently manage large datasets and quickly find relevant employees

Acceptance Criteria:
Scenario: Paginated and filtered results
Given a large set of employee records
When I request employees with pagination and filter parameters
Then the API returns the correct subset of employees with metadata for total count and pages

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Filtering by department, role, status, and hireDate must be supported
