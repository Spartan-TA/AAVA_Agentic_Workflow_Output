Title: Provide OpenAPI Documentation for Employee CRUD APIs

User Story: As a Developer I want comprehensive OpenAPI documentation for employee CRUD endpoints so that I can integrate and test the Warehouse EMS APIs efficiently.

Acceptance Criteria:
Scenario: OpenAPI Schema Availability
  Given the employee CRUD APIs are implemented
  When I access the API documentation endpoint
  Then I see detailed schemas, request/response examples, and error codes for each endpoint

Scenario: Example Payloads
  Given the OpenAPI documentation is available
  When I review the examples
  Then each endpoint includes realistic example payloads for requests and responses

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs (E02)
- Notes: Documentation must be updated with every API change and reviewed for completeness.
