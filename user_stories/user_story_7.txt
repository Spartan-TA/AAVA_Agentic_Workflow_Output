Title: API Key/OAuth2 Toggle via Configuration

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication via configuration So that I can adapt security to different integration requirements

Acceptance Criteria:
Scenario: Authentication method toggle
Given the application configuration is accessible
When I set the authentication method to API key or OAuth2
Then all endpoints enforce the selected method and unauthorized requests are blocked

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role-based endpoint security
- Notes: Configuration must be documented; automated tests must cover both authentication flows.
