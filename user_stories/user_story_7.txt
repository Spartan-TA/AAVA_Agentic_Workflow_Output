Title: Soft-Delete Employee Record via API

User Story: As an HR manager I want to soft-delete employee records So that terminated employees are excluded from active lists but historical data is retained

Acceptance Criteria:
Scenario: Soft-delete employee
Given an existing employee record
When I DELETE /employees/{id}
Then the employee status is set to inactive and record is excluded from active queries

Scenario: Restore employee
Given a soft-deleted employee
When I PATCH status to active
Then the employee is restored to active lists

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Soft-delete must not remove historical data
