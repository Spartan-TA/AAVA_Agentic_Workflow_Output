Title: List and Filter Employees

User Story: As an HR user I want to view a paginated and filterable list of employees So that I can quickly find and manage employee records

Acceptance Criteria:
Scenario: Listing and filtering employees
Given I am on the employee list page
When I apply filters (e.g., department, status) and navigate pages
Then the results update accordingly and only active employees are shown by default

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD (E02)
- Notes: Support pagination, filtering, and sorting; show soft-deleted employees only with explicit filter
