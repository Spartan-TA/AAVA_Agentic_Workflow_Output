Title: Delete Employee Record via API

User Story: As an HR manager I want to delete employee records using a REST API so that outdated or incorrect employee data can be removed from the system

Acceptance Criteria:
Scenario: Employee deletion
  Given an existing employee record
  When I send a DELETE request to /employees/{id}
  Then the employee record should be soft-deleted and excluded from active queries

Scenario: Deletion validation
  Given an employee record is soft-deleted
  When I query for active employees
  Then the deleted record should not appear in the results

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Soft-delete should retain record for audit purposes
