Title: Soft-Delete Employee Record

User Story: As an HR user I want to soft-delete employee records So that terminated employees are not shown in active lists but their history is retained

Acceptance Criteria:
Scenario: Employee soft-delete
Given an existing employee record
When I perform a delete action
Then the employee is marked as inactive and excluded from active queries, but data is retained for audit

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story_5
- Notes: Soft-delete must be reversible by ADMIN; deleted records visible in audit logs
