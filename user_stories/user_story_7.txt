Title: Soft-Delete Employee Record

User Story: As an HR Manager I want to soft-delete employee records So that terminated employees are excluded from active lists but historical data is retained

Acceptance Criteria:
Scenario: Employee Soft-Delete
Given an existing employee record
When I send a DELETE request to /employees/{id}
Then the employee status is updated to 'inactive' and record is excluded from active queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story_5.txt
- Notes: Ensure soft-delete is reversible and audit trail is maintained.
