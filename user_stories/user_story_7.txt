Title: Employee API OpenAPI Documentation

User Story: As a developer I want comprehensive OpenAPI documentation for all Employee CRUD endpoints So that integration and testing are straightforward and reliable

Acceptance Criteria:
Scenario: Documentation for all endpoints
  Given the Employee CRUD APIs are implemented
  When I view the OpenAPI documentation
  Then all endpoints (POST, GET, PUT, PATCH, DELETE) are documented with request/response examples

Scenario: Example payloads
  Given the OpenAPI schema is available
  When I review the documentation
  Then example payloads for each operation are present and accurate

Scenario: Schema validation
  Given the OpenAPI schema is used for validation
  When requests are made to the API
  Then invalid payloads are rejected according to the schema

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01
- Notes: Documentation must be kept up-to-date with API changes.
