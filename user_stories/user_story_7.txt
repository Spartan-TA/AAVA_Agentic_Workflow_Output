Title: Soft-Delete Employee Record via API

User Story: As an HR Manager I want to soft-delete employee records So that terminated employees are excluded from active lists but their history is retained for compliance.

Acceptance Criteria:
Scenario: Successful soft-delete
Given an active employee record exists
When I DELETE /employees/{id}
Then the employee status is updated to 'inactive' and the record is excluded from active queries

Scenario: Attempt to delete non-existent employee
Given no employee record exists for the provided id
When I DELETE /employees/{id}
Then the API returns a not found error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain, Project scaffolding
- Notes: Ensure soft-deleted records are retained for audit and compliance.
