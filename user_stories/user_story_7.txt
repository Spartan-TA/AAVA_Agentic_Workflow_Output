Title: Implement Role-Based Access Control (RBAC)

User Story: As a system administrator I want to implement role-based access control with Spring Security So that only authorized users can access sensitive employee management operations.

Acceptance Criteria:
Scenario: Unauthorized access attempt
  Given a user is not authenticated
  When they attempt to access a protected endpoint
  Then the system should return a 401 Unauthorized response
Scenario: Forbidden action by role
  Given a user is authenticated as SUPERVISOR
  When they attempt to manage records outside their team
  Then the system should return a 403 Forbidden response
Scenario: ADMIN role full access
  Given a user is authenticated as ADMIN
  When they access any employee management endpoint
  Then they should have full access
Scenario: Security rules test coverage
  Given security rules are implemented
  When automated tests are run
  Then all rules should be covered and pass

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project scaffolding, Employee CRUD APIs
- Notes: Include method/endpoint and row-level security constraints.
