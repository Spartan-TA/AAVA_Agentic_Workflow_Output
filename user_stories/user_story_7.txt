Title: Update Employee Record

User Story: As an HR manager I want to update employee details so that changes in role, department, or status are accurately reflected in the EMS.

Acceptance Criteria:
Scenario: Successful Update
  Given an existing employee record
  When I send a PUT or PATCH request with updated details
  Then the employee record is updated and returned

Scenario: Invalid Update
  Given an invalid update request (e.g., duplicate badgeId)
  When I attempt to update the employee
  Then the API should return a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Only authorized roles may update; audit log entry must be created for every update.
