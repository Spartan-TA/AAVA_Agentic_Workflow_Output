Title: Retrieve Employee Records

User Story: As an HR user I want to retrieve employee records with pagination and filtering So that I can efficiently manage and review employee data

Acceptance Criteria:
Scenario: Employee data retrieval
Given employee records exist in the system
When I send a GET request to /employees with pagination and filter parameters
Then the API should return the correct subset of employee records matching the criteria

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain
- Notes: Support filtering by department, role, status, and shiftGroup.
