## Epic E11: Payroll Export Integration

### US-E11-001
**Title:** Generate Payroll-Ready Export Files

**User Story:** As a payroll manager I want to export attendance and leave data in provider format So that payroll runs are automated

**Acceptance Criteria:**
Scenario: Payroll export
Given approved attendance and leave
When I generate an export
Then the file matches provider schema

**Additional Details:**
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Supports SFTP/API delivery

---

### US-E11-002
**Title:** Secure Delivery of Payroll Files

**User Story:** As a payroll manager I want payroll files delivered securely to providers So that sensitive data is protected

**Acceptance Criteria:**
Scenario: Secure delivery
Given a generated payroll file
When delivery is initiated
Then the file is sent via SFTP/API with encryption

**Additional Details:**
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Delivery failures retried with backoff

---

### US-E11-003
**Title:** Audit Payroll Export Activity

**User Story:** As an auditor I want all payroll exports logged So that I can trace data delivery

**Acceptance Criteria:**
Scenario: Export audit log
Given a payroll export
When the export is completed
Then an audit entry is created with timestamp and status

**Additional Details:**
- Priority: High
- Story Points: 1
- Dependencies: E04, E06
- Notes: Export log exportable by date

---

### US-E11-004
**Title:** Reconcile Payroll Totals with Reports

**User Story:** As a payroll manager I want to reconcile export totals with attendance/leave reports So that errors are detected early

**Acceptance Criteria:**
Scenario: Payroll reconciliation

When I compare totals

**Additional Details:**
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Automated checks with alerts
