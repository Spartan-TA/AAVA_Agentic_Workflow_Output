### E11: Payroll Export Integration

**User Story 1: Generate Payroll Export Files**
- Title: Generate Payroll Export Files
- User Story: As a payroll admin, I want to generate payroll-ready files from attendance and leave, so that payroll processing is automated.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Generate payroll export
    Given approved attendance and leave records exist
    When I request a payroll export
    Then a file is generated matching provider schema
    And totals reconcile with reports
  ```
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E04, E06
  * Notes: Supports multiple provider formats.

**User Story 2: Secure Delivery of Payroll Files**
- Title: Secure Delivery of Payroll Files
- User Story: As a payroll admin, I want payroll files delivered securely via SFTP or API, so that sensitive data is protected.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Secure payroll file delivery
    Given a payroll export file is generated
    When I configure SFTP/API delivery
    Then the file is sent securely
    And delivery status is tracked
  ```
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E04, E06
  * Notes: Delivery retries with backoff.

**User Story 3: Export Failure Handling**
- Title: Export Failure Handling
- User Story: As an admin, I want failed payroll exports to be retried automatically, so that errors are minimized.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Retry failed payroll export
    Given a payroll export delivery fails
    When the system detects failure
    Then retries are scheduled with exponential backoff
    And failures are logged in audit trail
  ```
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E04, E06
  * Notes: Alerts for repeated failures.

**User Story 4: Payroll Export Audit Logging**
- Title: Payroll Export Audit Logging
- User Story: As an auditor, I want every payroll export to be logged, so that compliance is maintained.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Audit payroll export
    Given a payroll export is generated or delivered
    When the event occurs
    Then an audit log entry is created with actor, timestamp, and status
  ```
- Additional Details:
  * Priority: High
  * Story Points: 1
  * Dependencies: E04, E06
  * Notes: Links to E14 audit trail.
