Title: Disaster Recovery - Automated Backups

User Story: As an IT admin I want automated daily database backups retained for 30 days so that data loss risk is minimized.

Acceptance Criteria:
Scenario: Daily backup job runs
Given the system is operational
When the backup schedule triggers
Then a backup is created and retained for 30 days

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Backup success monitored.
