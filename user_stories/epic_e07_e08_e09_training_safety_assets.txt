### EPIC E07 - Training & Certification Tracking

**User Story 1**
Title: Manage Employee Certifications

User Story: As a Safety Officer I want to CRUD employee certifications So that compliance and qualification records are maintained

Acceptance Criteria:
Scenario: Certification creation
Given valid certification data
When I POST to /certifications
Then a new certification is added to the employee profile

Scenario: Certification update
Given an existing certification
When I PATCH /certifications/{id}
Then the record is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support proof document uploads

**User Story 2**
Title: Alert on Expiring Certifications

User Story: As a Supervisor I want alerts for certifications expiring in 30/7 days So that renewals are not missed

Acceptance Criteria:
Scenario: Expiry alert
Given a certification expiring soon
When the system detects the expiry window
Then an alert is sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Integrate with notification system

**User Story 3**
Title: Block Assignment to Tasks Requiring Valid Certification

User Story: As a Scheduler I want to block assignment of employees to tasks if their certification is expired So that only qualified staff are assigned

Acceptance Criteria:
Scenario: Assignment block
Given an expired certification
When I assign a task requiring certification
Then the system prevents assignment and returns an error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Show certification status on employee profile
