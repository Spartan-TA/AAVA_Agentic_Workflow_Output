Title: Secure Payroll File Delivery
User Story: As a payroll administrator I want payroll files delivered securely via SFTP or API so that sensitive data is protected during transfer
Acceptance Criteria:
Scenario: Deliver payroll file via SFTP
Given a payroll file is exported
When I select SFTP delivery
Then the file is transferred securely to the provider
Scenario: Deliver payroll file via API
Given a payroll file is exported
When I select API delivery
Then the file is sent securely to the provider endpoint
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Delivery method configurable per provider
