Title: Retry Failed Payroll Deliveries

User Story: As a payroll administrator I want to retry failed payroll exports So that errors can be corrected and data delivered successfully

Acceptance Criteria:
Scenario: Retry payroll export
Given a payroll export failed
When I correct the error and retry
Then the system should attempt delivery again and log the outcome

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Payroll export, error logging
- Notes: Should notify on repeated failures.
