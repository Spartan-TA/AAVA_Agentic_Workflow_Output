Title: Employee Self-Assessment

User Story: As an employee I want to complete a self-assessment as part of my performance review So that I can reflect on my achievements and areas for improvement

Acceptance Criteria:
Scenario: Employee submits self-assessment
Given a performance review cycle is active
When I access my review form
Then I should be able to complete and submit my self-assessment for manager review

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data
- Notes: Self-assessment should be required before manager review.
