Title: Secure Delivery of Payroll Files

User Story: As a payroll administrator I want payroll export files to be delivered securely to external providers via SFTP or API so that sensitive payroll data is protected during transmission.

Acceptance Criteria:
Scenario: Delivering payroll file securely
Given a payroll file is ready for export
When I choose SFTP or API as the delivery method
Then the system should transmit the file securely and log the delivery status

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Delivery failures should trigger an alert and allow for retry.
