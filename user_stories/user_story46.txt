Title: Safety KPI Dashboard

User Story: As a safety manager I want to view key safety performance indicators (KPIs) on a dashboard So that I can monitor compliance and identify areas for improvement

Acceptance Criteria:
Scenario: Viewing safety KPIs
Given safety data is available
When I access the safety dashboard
Then I should see visualizations of KPIs such as incident rates and training completion

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Safety data module, dashboard UI
- Notes: Support for historical trends and export.
