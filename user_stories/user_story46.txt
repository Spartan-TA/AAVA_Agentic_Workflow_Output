Title: Manager Generates Leave Report
User Story: As a manager I want to generate leave reports for my team So that I can monitor absence patterns and plan coverage
Acceptance Criteria:
Scenario: Generate leave report
Given leave data is available
When I select the leave report option and specify a date range
Then a formatted leave report is generated and available for download
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Reporting engine, leave module
- Notes: Support CSV and PDF export formats.
