EPIC E20: CI/CD & Deployment Automation

---

Title: Set Up CI/CD Pipeline with GitHub Actions
User Story: As a developer I want a CI/CD pipeline using GitHub Actions So that builds, tests, and deployments are automated
Acceptance Criteria:
Scenario: CI/CD pipeline runs on push
Given I push code to the repo
When the pipeline runs
Then builds, tests, and deployments execute automatically

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Include build, test, and deploy stages

---

Title: Automate Database Migrations in CI/CD
User Story: As a developer I want database migrations to run automatically in CI/CD So that environments are consistent
Acceptance Criteria:
Scenario: Automated DB migrations
Given a new migration is added
When the pipeline runs
Then migrations are applied to the target environment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Fail build on migration error
