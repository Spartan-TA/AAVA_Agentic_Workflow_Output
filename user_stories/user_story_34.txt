Title: Create Performance Review Templates

User Story: As an HR administrator I want to create performance review templates So that managers can conduct standardized evaluations

Acceptance Criteria:
Scenario: Create review template
Given I am on the review template creation page
When I enter criteria and save the template
Then it should be available for future reviews

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Performance management module
- Notes: Support multiple review types and rating scales.
