Title: Capture Ratings and Comments in Reviews

User Story: As a supervisor I want to enter ratings and comments for each competency during a performance review so that feedback is specific and actionable.

Acceptance Criteria:
Scenario: Completing a review
Given a review template with defined competencies
When I enter ratings and comments for each section
Then the system should save the review and notify the employee for acknowledgement

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Comments should be required for any rating below expectations.
