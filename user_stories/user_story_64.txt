Title: Locale-Aware Date/Time Formats and Test Coverage

User Story: As a QA engineer I want date and time formats to respect the selected locale and have automated tests for both languages so that users see familiar formats and localization is reliable

Acceptance Criteria:
Scenario: Validate locale-aware formats and tests
  Given the UI is set to Spanish or English
  When I view dates and times
  Then they are formatted per locale and automated tests confirm correct display in both languages

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01 (Core), E02 (User Management), E05 (Attendance)
- Notes: Test cases must cover all date/time fields
