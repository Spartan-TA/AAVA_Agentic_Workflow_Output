Title: Enable Actuator Endpoints

User Story: As an operator, I want Actuator endpoints enabled so that I can monitor application health and metrics.

Acceptance Criteria:

Scenario: Actuator endpoints available
Given the application is running
When I GET `/actuator/health` and `/actuator/info`
Then both endpoints return 200

- Dependencies: None
