Title: Document Build and Run Steps in README

User Story: As a developer I want the README to include clear build and run instructions so that new contributors can quickly set up and run the project

Acceptance Criteria:
Scenario: README contains setup instructions
  Given a cloned repository
  When I open the README file
  Then I should see step-by-step instructions for building and running the application

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: README must be kept up to date with every major change
