## Epic E06: Leave & Absence Management

### User Story 1: Submit Leave Request
- **Title:** Submit Leave Request
- **User Story:** As an employee, I want to submit a leave request (PTO, sick, unpaid) so that my supervisor can review and approve my time off.
- **Acceptance Criteria (Gherkin):**
  ```
  Given I am logged in
  When I fill out and submit a leave request
  Then the request appears in my pending requests and notifies my supervisor
  ```
- **Additional Details:**
  - Priority: Medium
  - Story Points: 3
  - Dependencies: E02, E03, E05
  - Notes: Request types and date ranges must be validated.

### User Story 2: Approve/Deny Leave Request
- **Title:** Approve or Deny Leave Request
- **User Story:** As a supervisor, I want to approve or deny leave requests so that I can manage team availability.
- **Acceptance Criteria (Gherkin):**
  ```
  Given I have pending leave requests
  When I approve or deny a request
  Then the employee is notified and the request status updates accordingly
  ```
- **Additional Details:**
  - Priority: Medium
  - Story Points: 2
  - Dependencies: E02, E03
  - Notes: Approval/denial reasons optional.

### User Story 3: Leave Accrual Balances
- **Title:** View Leave Balances
- **User Story:** As an employee, I want to view my current leave balances so that I know how much time off I have available.
- **Acceptance Criteria (Gherkin):**
  ```
  Given I am on my profile
  When I view leave balances
  Then I see up-to-date accruals for each leave type
  ```
- **Additional Details:**
  - Priority: Medium
  - Story Points: 2
  - Dependencies: E02
  - Notes: Accrual policies configurable.

### User Story 4: Exclude Approved Leave from Scheduling
- **Title:** Flag Shifts for Coverage During Leave
- **User Story:** As a scheduler, I want approved leaves to automatically flag affected shifts for coverage so that I can ensure adequate staffing.
- **Acceptance Criteria (Gherkin):**
  ```

  Then their shifts are flagged for coverage and excluded from assignment
  ```
- **Additional Details:**
  - Priority: Medium
  - Story Points: 3
  - Dependencies: E05
  - Notes: Integration with shift management.

### User Story 5: Export Approved Leaves
