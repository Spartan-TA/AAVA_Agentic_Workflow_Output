# Warehouse Employee Management User Stories - Epics E06-E10

## E06: Leave & Absence Management

### User Story 6.1: Request Leave
- **Title:** Employee Leave Request
- **User Story:** As a WORKER I want to request PTO, sick, or unpaid leave so that my absences are tracked and approved.
- **Acceptance Criteria:**
  ```
  Scenario: Submit leave request
    Given I am logged in as a worker
    When I submit a leave request with dates and type
    Then the request is created and pending approval
  ```
- **Additional Details:**
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Leave types configurable.

### User Story 6.2: Approve or Deny Leave
- **Title:** Supervisor Leave Approval
- **User Story:** As a SUPERVISOR I want to approve or deny leave requests so that team coverage is maintained.
- **Acceptance Criteria:**
  ```
  Scenario: Approve leave request
    Given a leave request is pending
    When I approve or deny the request
    Then the employee and schedule are updated accordingly
  ```
- **Additional Details:**
  * Priority: Medium
  * Story Points: 2
  * Dependencies: User Story 6.1
  * Notes: Approval workflow with notifications.

### User Story 6.3: Update Leave Balances
- **Title:** Track Leave Accruals and Balances
- **User Story:** As an HR I want leave balances to update automatically so that accruals and usage are accurate.
- **Acceptance Criteria:**
  ```
  Scenario: Leave balance updates on approval
    Given an employee has a leave balance
    When a leave request is approved
    Then the balance is decremented by the approved amount
  ```
- **Additional Details:**
  * Priority: Medium
  * Story Points: 2
  * Dependencies: User Story 6.2
  * Notes: Supports different accrual policies.

### User Story 6.4: Exclude Approved Leave from Scheduling
- **Title:** Auto-Flag Scheduled Shifts for Leave
- **User Story:** As a SUPERVISOR I want scheduled shifts to be auto-flagged when an employee is on approved leave so that coverage can be arranged.
- **Acceptance Criteria:**
  ```
  Scenario: Scheduled shifts flagged for coverage
    Given an employee has approved leave
    When I view the schedule
    Then affected shifts are flagged for coverage
  ```
- **Additional Details:**
  * Priority: Medium
  * Story Points: 2
  * Dependencies: User Story 6.2, E05
  * Notes: Integration with scheduling module.

### User Story 6.5: Export Leave Data
- **Title:** Export Approved Leave Records
- **User Story:** As an HR I want to export approved leave records so that payroll and compliance are accurate.
- **Acceptance Criteria:**
  ```
  Scenario: Export leave data as CSV
    Given approved leave records exist
    When I request an export
    Then a CSV file is generated with all relevant leave data
  ```
- **Additional Details:**
  * Priority: Medium
  * Story Points: 1
  * Dependencies: User Story 6.2
  * Notes: Export includes employee, dates, type, and approval status.

## E07: Training & Certification Tracking

### User Story 7.1: Track Employee Certifications
- **Title:** CRUD for Certifications
- **User Story:** As an HR I want to manage employee certifications so that compliance and training records are up to date.
- **Acceptance Criteria:**
  ```
  Scenario: Add and update certifications
    Given an employee profile
    When I add or update a certification
    Then the certification is saved and visible on the profile
  ```
- **Additional Details:**
  * Priority: High
  * Story Points: 2
  * Dependencies: E02, E03
  * Notes: Includes certification type, issue, and expiry dates.

### User Story 7.2: Alert on Expiring Certifications
- **Title:** Certification Expiry Alerts
- **User Story:** As a SUPERVISOR I want to receive alerts before certifications expire so that renewals are not missed.
- **Acceptance Criteria:**
  ```
  Scenario: Alert 30 and 7 days before expiry
    Given a certification is expiring soon
    When the alert window is reached
    Then the supervisor and employee receive a notification
  ```
- **Additional Details:**
  * Priority: High
  * Story Points: 2
  * Dependencies: User Story 7.1
  * Notes: Alerts at 30 and 7 days.

### User Story 7.3: Block Assignment for Expired Certifications
- **Title:** Prevent Assignment to Unqualified Employees
- **User Story:** As a SUPERVISOR I want the system to block assignment to tasks requiring valid certifications so that only qualified employees are assigned.
- **Acceptance Criteria:**
  ```
  Scenario: Assignment blocked for expired certs
    Given an employee's certification is expired
    When I try to assign them to a restricted task
    Then the system prevents the assignment and shows an error
  ```
- **Additional Details:**
  * Priority: High
  * Story Points: 3
  * Dependencies: User Story 7.1, E05
  * Notes: Enforced at scheduling and asset assignment.

### User Story 7.4: Upload Proof of Certification
- **Title:** Upload Certification Documents
- **User Story:** As an HR I want to upload proof documents for certifications so that records are verifiable.
- **Acceptance Criteria:**
  ```
  Scenario: Upload and view certification proof
    Given an employee certification
    When I upload a document
    Then the document is stored and viewable from the employee profile
  ```
- **Additional Details:**
  * Priority: High
  * Story Points: 2
  * Dependencies: User Story 7.1
  * Notes: Supports PDF, JPG, PNG.

- **Acceptance Criteria:**
