### E06: Leave & Absence Management

**User Story 1: Employee Leave Request**
- Title: Employee Leave Request
- User Story: As an employee, I want to request PTO, sick, or unpaid leave, so that my absence is properly documented.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Submit leave request
    Given I am logged in as an employee
    When I submit a leave request
    Then my leave balance is checked
    And the request is sent for supervisor approval
  ```
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Leave types configurable.

**User Story 2: Supervisor Leave Approval**
- Title: Supervisor Leave Approval
- User Story: As a supervisor, I want to approve or deny leave requests, so that staffing is maintained.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Approve leave request
    Given a leave request is pending
    When I approve or deny the request
    Then the employee is notified
    And balances are updated accordingly
  ```
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Approval workflow tracked.

**User Story 3: Leave Accrual Balances**
- Title: Leave Accrual Balances
- User Story: As an HR manager, I want to view and update leave accrual policies, so that balances are accurate.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Update leave accrual policy
    Given I am an HR manager
    When I modify accrual rates
    Then employee balances are recalculated
    And reflected in leave requests
  ```
- Additional Details:
  * Priority: Medium
  * Story Points: 3
  * Dependencies: E02, E03, E05
  * Notes: Policy changes logged.

**User Story 4: Integration with Scheduling**
- Title: Integration with Scheduling
- User Story: As a scheduler, I want approved leaves to automatically flag scheduled shifts for coverage, so that absences are managed.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Flag shifts for coverage
    Given an employee has approved leave
    When the leave overlaps scheduled shifts
    Then affected shifts are flagged for coverage
    And supervisors are notified
  ```
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Links to E05 shift management.

**User Story 5: Leave Export for Payroll**
- Title: Leave Export for Payroll
- User Story: As a payroll admin, I want to export approved leaves, so that payroll hours are accurate.
- Acceptance Criteria in Gherkin format:
  ```
  Scenario: Export leave records
    Given I am a payroll admin

  ```
- Additional Details:
  * Priority: Medium
  * Story Points: 1
  * Dependencies: E02, E03, E05
