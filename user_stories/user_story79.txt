Title: Access Control for Reports and Exports

User Story: As a system administrator I want access to reports and exports to be controlled by user role So that sensitive data is protected and only authorized users can view or download reports

Acceptance Criteria:
Scenario: Access control enforcement
Given reports and exports are available
When a user requests access
Then the system checks user role and grants or denies access accordingly

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Access logs must be maintained for compliance.
