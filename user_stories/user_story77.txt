Title: Provide Role-Based Dashboards and Metrics Endpoints for BI

User Story: As a business analyst I want access to role-based dashboards and metrics endpoints So that I can visualize and analyze operational data for decision-making

Acceptance Criteria:
Scenario: Dashboard and metrics access
Given I have the appropriate role
When I access the dashboard or metrics endpoint
Then I see relevant data and can export or integrate with BI tools

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Metrics endpoints must support authentication and filtering.
