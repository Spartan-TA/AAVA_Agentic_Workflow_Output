Title: Assign Equipment to Employee
User Story: As a warehouse manager I want to assign equipment (scanners, forklifts, PPE) to employees So that asset usage is tracked and accountability is maintained
Acceptance Criteria:
Scenario: Equipment assignment
  Given an employee profile exists
  When I select equipment and assign it to the employee
  Then the assignment should be logged and visible in the employee's asset list
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Asset management module
- Notes: Equipment must be available for assignment

Title: Track Equipment Checkout and Return
User Story: As an employee I want to check out and return equipment So that asset usage is accurately recorded
Acceptance Criteria:
Scenario: Equipment checkout
  Given I am assigned equipment
  When I check out the equipment
  Then the system should record the checkout time and status
Scenario: Equipment return
  Given I have checked out equipment
  When I return the equipment
  Then the system should record the return and update availability
Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Asset management, employee profile
- Notes: Alerts for overdue returns

Title: Prevent Equipment Use if Certification Missing
User Story: As a safety administrator I want to prevent equipment assignment to employees lacking required certifications So that compliance and safety are ensured
Acceptance Criteria:
Scenario: Certification validation
  Given an employee lacks certification for specific equipment
  When I attempt to assign the equipment
  Then the system should block the assignment and display a warning
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification management, asset management
- Notes: Certification requirements configurable per asset type
