Title: Document Employee APIs with OpenAPI Schema

User Story: As a developer I want the employee CRUD APIs to be documented with OpenAPI schemas and examples so that integration and testing are streamlined

Acceptance Criteria:
Scenario: OpenAPI documentation
  Given the employee APIs are implemented
  When I view the API documentation
  Then each endpoint should have a schema, example request, and example response

Scenario: Schema accuracy
  Given the API documentation is available
  When I generate client code from the schema
  Then the client should interact with the API successfully

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Documentation should be updated with every API change
