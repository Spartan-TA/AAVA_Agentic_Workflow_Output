Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to restrict API endpoints based on user roles So that only authorized users can access sensitive operations

Acceptance Criteria:
Scenario: Unauthorized request
Given a user without credentials
When they access a protected endpoint
Then the system returns 401 Unauthorized

Scenario: Forbidden action
Given a user with insufficient role
When they attempt a restricted action
Then the system returns 403 Forbidden

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding, Employee CRUD
- Notes: Security rules must be covered by automated tests
