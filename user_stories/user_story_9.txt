Title: Configure Role Management UI

User Story: As an HR manager I want to assign and update roles for employees So that access permissions can be managed efficiently

Acceptance Criteria:
Scenario: Assigning a role to an employee
Given an employee exists in the system
When the HR manager selects a role and saves changes
Then the employee's access rights are updated immediately

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data
- Notes: UI must reflect all available roles and current assignments.
