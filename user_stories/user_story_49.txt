Title: Generate Operational Reports

User Story: As an operations manager I want to generate reports on attendance, overtime, leave balances, certification status, and safety KPIs so that I can monitor workforce performance and compliance.

Acceptance Criteria:
Scenario: Generating a report
Given I select a report type and date range
When I run the report
Then the system should display the results and allow export to CSV or PDF

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Reports should be filterable by location, department, and date.
