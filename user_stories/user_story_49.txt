Title: Configure Payroll Export Templates

User Story: As a payroll administrator I want to configure payroll export templates So that exported data matches the requirements of our payroll system

Acceptance Criteria:
Scenario: Payroll export template configuration
Given I am logged in as a payroll administrator
When I create or modify an export template
Then the template should be available for future exports

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Payroll export module
- Notes: Support for multiple template versions
