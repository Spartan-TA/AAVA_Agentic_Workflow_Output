Title: Expose Secure REST APIs for HRIS Integration

User Story: As a system integrator I want to access REST APIs secured with JWT/OAuth2 so that I can synchronize employee data from the HRIS system

Acceptance Criteria:
Scenario: Authenticating and accessing HRIS API
Given I have valid OAuth2 credentials
When I call the employee sync endpoint
Then the API authenticates my request and returns employee data in a secure manner

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Authentication service, HRIS connector
- Notes: API must be documented in OpenAPI format
