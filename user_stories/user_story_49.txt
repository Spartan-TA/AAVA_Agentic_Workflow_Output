Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all sensitive changes to employee, schedule, approval, and payroll data to be logged so that we can meet regulatory and audit requirements

Acceptance Criteria:
Scenario: Audit log entry for sensitive change
  Given a create, update, or delete action on sensitive data
  When the action is performed
  Then an audit log entry is created with actor, timestamp, before and after values

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03
- Notes: Log entries must be immutable and queryable by authorized users.
