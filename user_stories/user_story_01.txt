Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot Maven project with a standardized package structure so that all modules follow a consistent architecture.

Acceptance Criteria:

Scenario: Project builds successfully
Given I have cloned the repository
When I run mvn clean install
Then the project compiles without errors
And the application starts on port 8080

Scenario: Base package structure exists
Given the project is initialized
When I inspect the source code
Then packages for employee, scheduling, attendance, and safety exist

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Foundation for all modules
