Title: Configure Notification Preferences

User Story: As a user I want to opt-in or out of in-app, email, and SMS notifications for different event types so that I only receive relevant communications

Acceptance Criteria:
Scenario: Set notification preferences
  Given I am logged in
  When I update my notification preferences for each channel and event type
  Then my choices are saved and respected for all future notifications

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E03 (Scheduling), E05 (Attendance), E06 (Leave), E07 (Certifications)
- Notes: Quiet hours must be configurable
