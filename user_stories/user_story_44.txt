Title: SSO Integration

User Story: As an IT administrator I want to enable SSO for all users So that authentication is streamlined and secure

Acceptance Criteria:
Scenario: Log in with SSO
Given SSO is configured
When a user attempts to log in
Then they should be authenticated via the SSO provider and redirected to their dashboard

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Identity provider, authentication module
- Notes: Support SAML and OAuth2 providers.
