Title: Expose APIs for WMS Integration

User Story: As a system integrator I want to synchronize warehouse location and department data via APIs so that the workforce management system always reflects the latest organizational structure.

Acceptance Criteria:
Scenario: WMS location sync
Given a location or department is updated in the WMS
When the WMS calls the appropriate API endpoint
Then the system should update the corresponding records and log the change

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: API should support both full and incremental updates.
