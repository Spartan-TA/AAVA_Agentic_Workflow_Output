Title: Operational Reporting and Dashboards
User Story: As an operations manager I want to generate reports and view dashboards on attendance, overtime, leave, certifications, and safety So that I can make data-driven decisions.
Acceptance Criteria:
Scenario: Filter and export reports
  Given report filters (date, department, shift)
  When I generate a report
  Then results are filtered and exportable as CSV/PDF

Scenario: Role-based dashboard access
  Given my user role
  When I access dashboards
  Then I see only authorized data

Scenario: Metrics endpoints for BI
  Given BI integration
  When I call metrics endpoints
  Then data is available within 10 seconds for 50k rows

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Access controlled per role.
