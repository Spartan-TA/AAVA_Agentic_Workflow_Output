Title: Employee Views Leave Balance

User Story: As an employee I want to view my current leave balance So that I can plan my time off accordingly

Acceptance Criteria:
Scenario: Viewing leave balance
Given I am logged in as an employee
When I access my leave dashboard
Then I should see my available leave days by leave type (e.g., vacation, sick)

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave accrual and approval workflows
- Notes: Display leave balance in real time.
