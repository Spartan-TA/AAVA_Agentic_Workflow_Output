Title: Approve or Reject Leave Request

User Story: As a manager I want to approve or reject leave requests So that I can manage team availability and ensure adequate staffing

Acceptance Criteria:
Scenario: Manager reviews leave request
Given I have received a leave request notification
When I review the request and select approve or reject
Then the employee should be notified of the decision and the leave calendar updated accordingly

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notifications module, Calendar integration
- Notes: Approval workflow should support delegation in case of manager absence.
