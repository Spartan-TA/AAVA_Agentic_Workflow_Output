Title: Track Goals, Competencies, Ratings, and Comments

User Story: As a supervisor I want to track employee goals, competencies, ratings, and comments during performance reviews so that I can provide actionable feedback and monitor progress over time.

Acceptance Criteria:
Scenario: Review tracking
Given a review cycle is active
When I access an employee's review form
Then I should be able to enter ratings, comments, and update goal status, with changes saved and visible to both supervisor and employee

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data (E02), RBAC (E03)
- Notes: All entries must be timestamped and included in immutable review history.
