Title: Track Goals, Competencies, Ratings, and Comments

User Story: As a Supervisor I want to track employee goals, competencies, ratings, and comments during performance reviews so that I can provide comprehensive feedback and monitor progress over time.

Acceptance Criteria:
Scenario: Goal Tracking
Given an employee is undergoing a performance review
When I enter goals and competencies for the review period
Then the system should save and display these details for future reference

Scenario: Ratings and Comments
Given a review is in progress
When I assign ratings and add comments
Then the ratings and comments are stored and visible to both supervisor and employee

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: E02, E03
- Notes: Ratings should support multiple scales (numeric, descriptive) and comments should allow rich text.
