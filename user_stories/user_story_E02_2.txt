Title: E02-2 Retrieve Employee Records

User Story:
As an HR user,
I want to retrieve employee records via the API,
So that I can view and manage employee information efficiently.

Acceptance Criteria:
Given a valid API request,
When the endpoint is called without filters,
Then all active employee records are returned in a paginated list.

Given filter parameters (e.g., department, status, date range),
When the endpoint is called,
Then only records matching the filters are returned.

Given an invalid or unauthorized request,
When the endpoint is called,
Then an appropriate error message is returned and no data is exposed.

Additional Details:
- API must support pagination, sorting, and filtering.
- Sensitive fields (e.g., SSN) must not be exposed.
- API must be documented in OpenAPI spec.
- Audit log entry must be created for each access to employee records.
