Title: Employee Master Data (CRUD) - Retrieve Employee List

User Story: As an HR manager, I want to retrieve a paginated and filterable list of employees so that I can view and manage staff efficiently.

Acceptance Criteria:
Scenario: Retrieve paginated employee list
  Given multiple employees exist
  When I GET /employees with pagination parameters
  Then the response contains the correct page of employees

Scenario: Filter employees by department
  Given employees in multiple departments
  When I GET /employees?department=Shipping
  Then only employees in Shipping are returned

Additional Details:
Priority: High
Story Points: 3
Dependencies: Employee CRUD API
Notes: Filtering by department, role, status, etc.
