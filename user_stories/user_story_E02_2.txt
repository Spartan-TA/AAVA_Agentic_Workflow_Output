Title: Enforce Unique BadgeId and Support Soft-Delete

User Story: As an HR Manager I want employee badgeId to be unique and soft-delete functionality to be supported so that duplicate records are prevented and deleted employees can be recovered if needed.

Acceptance Criteria:
Scenario: Unique badgeId enforcement
Given an employee record exists with badgeId X
When I try to create another employee with badgeId X
Then the API returns a validation error

Scenario: Soft-delete employee
Given an active employee record
When I DELETE /employees/{id}
Then the employee is marked as deleted and excluded from active queries
And the record can be restored if needed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Ensure badgeId uniqueness is enforced at DB and API levels.
