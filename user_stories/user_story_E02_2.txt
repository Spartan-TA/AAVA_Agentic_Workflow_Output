Title: Enforce Unique Employee Badge ID

User Story: As an HR Manager I want the system to enforce unique badgeId for each employee So that duplicate badge assignments are prevented and records remain accurate

Acceptance Criteria:
Scenario: Badge ID uniqueness
  Given an employee is being created or updated
  When I submit a badgeId that already exists
  Then the system rejects the request with a validation error
Scenario: Badge ID assignment
  Given a new employee is created
  When I assign a badgeId
  Then the badgeId is unique and stored in the database

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02_1
- Notes: Validation must occur at both API and DB levels
