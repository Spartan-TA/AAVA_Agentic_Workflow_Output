Title: Set Up Database Migration Tool

User Story: As a developer I want to configure Flyway or Liquibase for database migrations so that schema changes are managed and versioned consistently across environments.

Acceptance Criteria:
Scenario: Baseline Migration
Given the migration tool is configured
When I run the application for the first time
Then the baseline migration should execute and the database schema should be created

Scenario: Migration Versioning
Given new migration scripts are added
When the application is started
Then migrations should apply in order and errors should be logged if any fail

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Document migration process in README.
