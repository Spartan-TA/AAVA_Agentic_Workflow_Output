Title: Create Employee Domain Model

User Story: As an HR manager I want to create and manage employee records with details like name, badgeId, role, department, shiftGroup, hireDate, and status so that we have a single source of truth for all warehouse employees.

Acceptance Criteria:
Scenario: Employee record creation
Given I have HR role access
When I submit a new employee record via the API
Then the employee is created with a unique badgeId and is retrievable via GET /employees

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: Supports pagination, filtering, and soft-delete; OpenAPI schemas must be provided.
