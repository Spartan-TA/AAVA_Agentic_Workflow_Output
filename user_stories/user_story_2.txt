Title: Implement Employee Master Data CRUD API

User Story: As an HR Manager I want to create, read, update, and delete employee records via APIs so that I can maintain accurate employee master data for the warehouse.

Acceptance Criteria:
Scenario: Create employee record
  Given I have valid employee data
  When I POST to /employees
  Then a new employee is created with a unique badgeId
Scenario: Update employee record
  Given an employee exists
  When I PUT/PATCH updated data to /employees/{id}
  Then the employee record is updated
Scenario: Delete employee record
  Given an employee exists
  When I DELETE /employees/{id}
  Then the employee is soft-deleted and excluded from active lists
Scenario: List and filter employees
  Given multiple employees exist
  When I GET /employees with filters
  Then I receive paginated, filtered results
Scenario: API documentation
  Given the API is available
  When I view OpenAPI schemas
  Then examples are present for all endpoints

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project scaffolding (E01)
- Notes: Ensure badgeId uniqueness and support for soft-delete.
