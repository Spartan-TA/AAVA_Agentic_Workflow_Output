Title: Configure Database Migration Tooling

User Story: As a Developer I want to set up Flyway/Liquibase for database migrations So that schema changes are versioned and applied consistently across environments.

Acceptance Criteria:
Scenario: Baseline migration applied
Given the project is initialized
When I start the application
Then Flyway/Liquibase runs the baseline migration and the database schema is created

Scenario: Migration failure handling
Given a migration script has an error
When I start the application
Then the application fails to start and logs the migration error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Ensure migration scripts are included in version control and documented in README.
