Title: Enable Actuator and Health Monitoring

User Story: As a system administrator I want to enable Actuator endpoints in the Spring Boot project So that I can monitor the health and metrics of the warehouse employee management system in real time.

Acceptance Criteria:
Scenario: Actuator health endpoint
  Given the application is running
  When I access /actuator/health
  Then the endpoint should return UP
Scenario: Metrics endpoint availability
  Given the application is running
  When I access /actuator/metrics
  Then system metrics should be visible
Scenario: Secure actuator endpoints
  Given the application is running
  When I access actuator endpoints without proper authorization
  Then access should be denied

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Ensure actuator endpoints are documented and secured.
