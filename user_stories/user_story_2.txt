Title: Set Up Database Migration Tool

User Story: As a System Administrator I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and applied consistently across environments

Acceptance Criteria:
Scenario: Baseline migration applied
Given a new database instance
When I run the migration tool
Then the baseline migration is applied and the schema is up to date
