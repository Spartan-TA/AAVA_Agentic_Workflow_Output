Title: Configure Database Migration Tool

User Story: As a developer I want to configure Flyway/Liquibase for database migrations so that schema changes are versioned and repeatable across environments.

Acceptance Criteria:
Scenario: Baseline Migration
  Given the EMS project is initialized
  When I start the application
  Then Flyway/Liquibase should apply the baseline migration to the database

Scenario: Migration Versioning
  Given new migration scripts are added
  When the application is restarted
  Then only unapplied migrations should execute in order

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Migration scripts should be stored in version control; errors must halt startup with clear logs.
