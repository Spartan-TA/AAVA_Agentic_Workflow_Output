Title: Configure Database Migration and Health Endpoints

User Story: As a System Administrator I want to configure Flyway/Liquibase for database migrations and enable Actuator health endpoints so that the Warehouse EMS can maintain reliable deployments and monitor system health.

Acceptance Criteria:
Scenario: Database Migration Configuration
  Given the project is initialized
  When I configure Flyway/Liquibase
  Then baseline migrations run successfully and errors are logged

Scenario: Health Endpoint Monitoring
  Given the application is running
  When I access the /actuator/health endpoint
  Then it returns status UP

Scenario: Migration Documentation
  Given the project is initialized
  When I open the README file
  Then it contains instructions for running and troubleshooting migrations

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Ensure migration scripts are versioned and rollback procedures are documented.
