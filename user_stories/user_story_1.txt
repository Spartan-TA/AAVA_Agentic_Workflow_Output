Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules So that the engineering team has a standardized foundation for further development.

Acceptance Criteria:
Scenario: Project scaffolding
  Given a new repository
  When I run the build command
  Then the project builds and runs on port 8080
Scenario: Health endpoint
  Given the application is running
  When I access /actuator/health
  Then the endpoint returns UP
Scenario: Baseline migration
  Given the database is empty
  When I start the application
  Then Flyway/Liquibase runs the baseline migration

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps; base package structure must be created.
