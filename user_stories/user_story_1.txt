Title: Initialize Spring Boot Project Scaffolding

User Story: As a developer I want to initialize a Spring Boot (Maven) project with base packages and core modules so that the team has a standardized foundation for further development.

Acceptance Criteria:
Scenario: Project scaffolding
  Given I have access to the repository
  When I run the build command
  Then the project should build and run on port 8080
Scenario: Base package structure
  Given the project is initialized
  When I inspect the source code
  Then the base package structure for employee, scheduling, attendance, and safety modules should be present
Scenario: Database migration setup
  Given the project is initialized
  When I run Flyway/Liquibase migrations
  Then the baseline migration should execute successfully
Scenario: Health endpoint
  Given the application is running
  When I access the Actuator health endpoint
  Then it should return UP
Scenario: Documentation
  Given the project is initialized
  When I open the README file
  Then it should contain build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all modules are stubbed and ready for further development.
