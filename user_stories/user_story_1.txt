Title: Initialize Spring Boot Project Structure

User Story: As a Developer I want to initialize a Spring Boot (Maven) project with the required base packages So that the team has a standardized foundation for all modules

Acceptance Criteria:

Scenario: Project scaffolding and build
Given I have cloned the repository
When I run the build command
Then the project should build successfully and run on port 8080

Scenario: Base package structure
Given the project is initialized
When I inspect the source code
Then I should see base packages for employee, scheduling, attendance, and safety modules

Scenario: Documentation
Given the project is built
When I open the README
Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: This is the foundation for all other modules; ensure Maven wrapper is included.
