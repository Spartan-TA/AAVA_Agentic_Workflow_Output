Title: Initialize EMS Project Scaffolding

User Story: As a System Administrator I want to initialize the Spring Boot project with standardized base packages and core modules so that future development is consistent and efficient.

Acceptance Criteria:
Scenario: Project scaffolding setup
  Given I have access to the project repository
  When I run the build and start the application
  Then the application should run on port 8080 and the base package structure should be present
Scenario: Database migration setup
  Given the project is initialized
  When I run Flyway/Liquibase migrations
  Then baseline migration should complete successfully
Scenario: Health endpoint verification
  Given the application is running
  When I access the Actuator health endpoint
  Then it should return UP
Scenario: Documentation
  Given the project is initialized
  When I open the README file
  Then it should contain build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all modules (employee, scheduling, attendance, safety) are present in the base structure.
