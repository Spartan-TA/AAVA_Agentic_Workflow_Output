Title: Initialize Spring Boot Project Scaffolding

User Story: As a System Administrator I want to initialize a Spring Boot project with standardized base packages and modules so that development teams can accelerate delivery and maintain consistency across the Warehouse EMS.

Acceptance Criteria:
Scenario: Project Initialization
  Given I have access to the project repository
  When I run the build and start the application
  Then the project builds successfully and runs on port 8080

Scenario: Base Package Structure
  Given the project is initialized
  When I inspect the source code
  Then the base package structure for core modules (employee, scheduling, attendance, safety) is present

Scenario: Database Migration Setup
  Given the project is running
  When I execute Flyway/Liquibase migrations
  Then the baseline migration completes without errors

Scenario: Health Endpoint
  Given the application is running
  When I access the Actuator health endpoint
  Then it returns status UP

Scenario: Documentation
  Given the project is initialized
  When I open the README file
  Then it contains build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all modules are stubbed and ready for further development; use Maven for dependency management.
