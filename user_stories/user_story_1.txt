Title: Initialize Spring Boot Project Scaffolding

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules and base packages So that the warehouse employee management system has a standardized foundation for accelerated delivery and consistency.

Acceptance Criteria:
Scenario: Project scaffolding setup
  Given I have access to the project repository
  When I run the build and start the application
  Then the application should run on port 8080 and the base package structure should be created
Scenario: Database migration setup
  Given the project is initialized
  When I run Flyway/Liquibase migrations
  Then baseline migration should execute successfully
Scenario: Health endpoint validation
  Given the application is running
  When I access the Actuator health endpoint
  Then it should return UP
Scenario: Documentation availability
  Given the project is initialized
  When I open the README file
  Then I should see build and run steps documented

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are included in the initial setup.
