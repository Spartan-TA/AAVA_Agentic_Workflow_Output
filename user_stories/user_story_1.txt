Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize the Spring Boot project with base packages and modules so that the EMS application has a standardized foundation for further development.

Acceptance Criteria:
Scenario: Project Initialization
  Given I have cloned the EMS repository
  When I run the build command
  Then the project should build successfully and run on port 8080

Scenario: Base Package Structure
  Given the project is initialized
  When I inspect the source code
  Then the base package structure for employee, scheduling, attendance, and safety modules should exist

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps; Actuator health endpoint should return UP; Flyway/Liquibase baseline migration should execute on startup.
