Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot (Maven) project with standardized base packages So that all modules follow a consistent structure and onboarding is accelerated

Acceptance Criteria:
Scenario: Project initialization
  Given I have cloned the repository
  When I run the build command
  Then the project should build successfully and run on port 8080

Scenario: Base package structure
  Given the project is initialized
  When I inspect the source code
  Then I should see base packages for employee, scheduling, attendance, and safety modules

- Notes: Follow company Java/Spring Boot conventions; ensure README includes build/run instructions
