Title: Initialize Spring Boot Project and Base Package Structure

User Story: As a developer I want to initialize a Spring Boot project with standardized base packages and modules So that all teams can build features on a consistent, maintainable foundation

Acceptance Criteria:
Scenario: Project builds and runs successfully
  Given the project repository is cloned
  When I run the build and start the application
  Then the application should start on port 8080 and display the default health endpoint as UP

Scenario: Base package structure is present
  Given the project is initialized
  When I browse the source code
  Then I should see core modules for employee, scheduling, attendance, and safety under the correct package hierarchy

Scenario: Documentation is available
  Given the project is initialized
  When I open the README file
  Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure Maven is configured, and the project is compatible with Flyway/Liquibase for DB migrations.
