Title: Initialize Project Structure
User Story: As a developer I want to scaffold the Spring Boot project with Maven and configure base packages So that all modules have a consistent foundation and onboarding is streamlined.
Acceptance Criteria:
Scenario: Project scaffolding and base package setup
  Given I have cloned the repository
  When I run 'mvn clean install'
  Then the project builds successfully and the base package structure is present

Scenario: Application startup and health check
  Given the application is built
  When I run 'mvn spring-boot:run'
  Then the app starts on port 8080 and the Actuator health endpoint returns UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run instructions.
