Title: Expose HRIS REST API

User Story: As a developer I want a REST API for HRIS data So that third-party systems can integrate and synchronize employee records

Acceptance Criteria:
Scenario: Access HRIS API
Given I have API credentials
When I make a GET request for employee data
Then the system should return the requested data in JSON format

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: HRIS data model, authentication
- Notes: Support CRUD operations and role-based access.
