Title: Track Equipment Status

User Story: As an equipment manager I want to track the status of all equipment So that I can manage maintenance schedules and replacements

Acceptance Criteria:
Scenario: Equipment status tracking
Given equipment is assigned and used
When I update equipment status (e.g., in use, maintenance, retired)
Then the system should reflect the current status and notify relevant parties

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Equipment assignment
- Notes: Support for automated maintenance reminders
