Title: WMS API Connector for Department/Location Sync

User Story: As an operations manager I want to link departments and locations from the WMS via API So that our workforce data is aligned with warehouse management

Acceptance Criteria:
Scenario: Department/location sync via WMS API
Given a department or location update in the WMS
When the connector syncs data
Then the corresponding records are updated in the system and changes are idempotent

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: API must be documented and support idempotent operations
