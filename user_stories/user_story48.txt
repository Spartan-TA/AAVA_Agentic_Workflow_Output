Title: Receive Push Notifications on Mobile

User Story: As a user I want to receive push notifications on my mobile device so that I am alerted to important events in real time

Acceptance Criteria:
Scenario: Receiving push notifications
Given I have enabled notifications in the PWA
When a relevant event occurs (e.g., shift change, announcement)
Then I receive a push notification on my device

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notification module, PWA
- Notes: Users should be able to manage notification preferences from mobile.
