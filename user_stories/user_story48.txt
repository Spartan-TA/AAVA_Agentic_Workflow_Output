Title: Employee Accesses Dashboard via Mobile
User Story: As an employee I want to access my dashboard from a mobile device So that I can manage my work on the go
Acceptance Criteria:
Scenario: Access dashboard via mobile
Given I have a mobile device and valid credentials
When I log in to the mobile app
Then I see my dashboard with key information
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Mobile app (PWA), authentication module
- Notes: Dashboard should be responsive and touch-friendly.
