Title: Request Paid Time Off (PTO)

User Story: As an employee I want to request paid time off through the system So that my supervisor can review and approve my leave efficiently

Acceptance Criteria:
Scenario: Submit PTO request
Given I am logged in as an employee
When I navigate to the leave request page and submit a PTO request with dates and reason
Then my supervisor should receive a notification and the request should appear in their approval queue

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02 (Employee Profiles), E03 (Scheduling), E05 (Attendance Tracking)
- Notes: PTO requests should update accrual balances and exclude approved leave from scheduling and payroll hours.
