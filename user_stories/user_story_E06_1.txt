Title: PTO and Sick Leave Request Submission

User Story: As a Warehouse Worker I want to submit PTO and sick leave requests through the system so that my absences are tracked and approved efficiently.

Acceptance Criteria:
Scenario: Submitting a leave request
Given I am logged into the portal
When I fill out and submit a PTO or sick leave request
Then the request is routed to my Supervisor for approval

Scenario: Viewing leave request status
Given I have submitted a leave request
When I view my leave history
Then I see the status (pending, approved, rejected) for each request

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave module, Notification service
- Notes: Requests must support attachments for sick leave documentation.
