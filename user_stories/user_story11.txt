Title: Payroll Export Integration

User Story: As a payroll administrator I want to generate payroll-ready export files from approved attendance and leave data so that payroll runs are accurate and efficient.

Acceptance Criteria:

Scenario: Generate export
Given approved attendance and leave records
When I generate a payroll export
Then the file matches the external provider's schema

Scenario: Delivery and retry
Given an export is generated
When delivery fails (SFTP/API)
Then the system retries with exponential backoff

Scenario: Audit log
Given payroll exports are generated
When I review the audit log
Then every export event is recorded with timestamp and status

Scenario: Totals reconciliation
Given exported data
When I compare with internal reports
Then all totals reconcile

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Time & Attendance (E04), Leave & Absence Management (E06)
- Notes: Secure delivery and audit log required; support for multiple provider formats.
