Title: Payroll File Generation

User Story: As a payroll administrator I want to generate payroll-ready files from attendance and leave data So that payroll runs are accurate and efficient.

Acceptance Criteria:
Scenario: Payroll export workflow
Given approved attendance and leave records
When I generate a payroll export
Then the file matches provider schema and totals reconcile

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: Secure delivery via SFTP/API; audit log for exports.

Title: Payroll Export Retry Logic

User Story: As a payroll administrator I want failed payroll exports to be retried automatically So that delivery issues are minimized.

Acceptance Criteria:
Scenario: Export retry process
Given a payroll export fails
When the system detects the failure
Then it retries with backoff and logs each attempt

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: All exports logged for audit.
