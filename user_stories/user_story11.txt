Title: Implement Time & Attendance Clock In/Out

User Story: As a warehouse worker I want to clock in and out via the system So that my working hours are accurately recorded

Acceptance Criteria:

Scenario: Clock-in event is recorded
Given I am a valid employee
When I POST to /attendance/clock-in
Then my clock-in time is recorded and associated with my shift

Scenario: Clock-out event is recorded
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out time is recorded and hours worked are calculated

Scenario: Geofence validation (optional)
Given geofencing is enabled
When I clock in from an allowed location
Then the event is accepted

Scenario: Device capture is logged
Given I clock in/out
When the event is recorded
Then the device ID is stored with the event

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee CRUD APIs, RBAC
- Notes: Support for mobile and web; handle timezones; log device info
