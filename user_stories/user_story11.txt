Title: Request Leave

User Story: As an employee I want to request PTO, sick, or unpaid leave so that my time off is tracked and approved

Acceptance Criteria:
Scenario: Requesting leave
Given I am logged in
When I submit a leave request
Then my supervisor should receive a notification to approve or deny

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee Master Data, RBAC, Scheduling
- Notes: Accrual balances and policies enforced

Title: Approve or Deny Leave Requests

User Story: As a supervisor I want to approve or deny leave requests so that staffing plans remain accurate

Acceptance Criteria:
Scenario: Approving leave
Given a leave request is pending
When I review and approve/deny
Then the employee's leave balance and schedule should update accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Leave Requests, Scheduling
- Notes: Scheduled shifts auto-flagged for coverage

Title: Update Leave Balances

User Story: As an HR manager I want leave balances to update automatically so that records remain accurate

Acceptance Criteria:
Scenario: Leave balance update
Given a leave request is approved
When the leave period starts
Then the employee's leave balance should decrease by the appropriate amount

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave Requests, Payroll Integration
- Notes: Integration hooks for scheduling and payroll
