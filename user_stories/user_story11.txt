Title: Payroll Export - Secure Delivery and Retry
User Story: As a payroll admin, I want payroll files delivered securely via SFTP/API and retried on failure so that data is transmitted reliably.
Acceptance Criteria:
Scenario: Secure delivery
  Given a payroll file is ready
  When I send it via SFTP/API
  Then delivery is logged and secure

Scenario: Retry on failure
  Given delivery fails
  When the system retries
  Then backoff is applied until success

Additional Details:
Priority: High
Story Points: 2
Dependencies: E04, E06
Notes: Ensures reliability
