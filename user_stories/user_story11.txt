Title: Employee Clock-In/Clock-Out

User Story: As an employee I want to clock in and out using the system so that my working hours are accurately recorded

Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift
When I clock in using the web or mobile app
Then my clock-in time is recorded and associated with my shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Geofence and device capture optional

Title: Handle Missed Punches and Corrections

User Story: As an employee I want to request corrections for missed punches so that my attendance record is accurate

Acceptance Criteria:
Scenario: Missed punch correction
Given I missed a clock-in or clock-out
When I submit a correction request
Then a supervisor is notified and can approve or deny the correction

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock-In/Out, Supervisor role
- Notes: Approval workflow required

Title: Calculate Hours Worked Per Shift

User Story: As a payroll administrator I want the system to calculate total hours worked per shift so that payroll processing is accurate

Acceptance Criteria:
Scenario: Calculating shift hours
Given an employee has clocked in and out
When the shift ends
Then the system computes the total hours worked and flags any anomalies

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock-In/Out events
- Notes: Handle overnight and split shifts

Title: Export Attendance Reports

User Story: As a supervisor I want to export attendance data as CSV so that I can analyze and share attendance records

Acceptance Criteria:
Scenario: Exporting attendance report
Given I have access to attendance data
When I request a report export
Then I receive a CSV file with attendance details for the selected period

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance data
- Notes: Include filters for date, employee, department

Title: Automatic Shift Association

User Story: As a system I want to automatically associate clock-in/out events with scheduled shifts so that attendance is linked to the correct shift

Acceptance Criteria:
Scenario: Auto-association of clock event
Given an employee clocks in
When the event is recorded
Then it is linked to the employee's scheduled shift for that day

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Shift schedules, Attendance
- Notes: Handle edge cases for overlapping shifts
