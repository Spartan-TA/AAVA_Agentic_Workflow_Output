### E11 - Payroll Export Integration

**Title:** Generate Payroll Export
**User Story:** As a payroll admin, I want to generate payroll-ready files from attendance and leave data so that payroll runs are accurate.
**Acceptance Criteria:**
Scenario: Payroll export
Given approved attendance and leave
When I export
Then the file matches provider schema and totals reconcile
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E04, E06, Notes: Secure delivery via SFTP/API.

**Title:** Retry Failed Payroll Deliveries
**User Story:** As a payroll admin, I want failed exports to retry with backoff so that delivery is reliable.
**Acceptance Criteria:**
Scenario: Export retry
Given a failed delivery
When the system retries
Then delivery is attempted with exponential backoff
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E04, E06, Notes: Audit log for every export.
