Title: Unauthorized and Forbidden Access Handling

User Story: As a system user I want unauthorized and forbidden actions to be blocked So that sensitive data and operations are protected

Acceptance Criteria:
Scenario: Unauthorized access attempt
Given I am not authenticated
When I try to access a protected endpoint
Then I should receive a 401 Unauthorized response

Scenario: Forbidden action attempt
Given I am authenticated but lack required role
When I try to perform a restricted action
Then I should receive a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC (E03)
- Notes: Security rules must be covered by automated tests.
