Title: Role-Based Access Control (RBAC) - Row-Level Security

User Story: As a supervisor I want to only access records for my team so that privacy and data segregation are maintained.

Acceptance Criteria:
Scenario: Row-level access
Given a supervisor
When they query employee data
Then only their team's records are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role Assignment
- Notes: Implement row-level constraints.
