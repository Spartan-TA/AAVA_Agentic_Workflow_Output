Title: Handle Missed Punch Corrections

User Story: As an employee I want to request corrections for missed clock in/out punches So that my attendance records are accurate

Acceptance Criteria:
Scenario: Missed punch correction request
  Given I missed a clock in or out
  When I submit a correction request
  Then my manager should be notified and able to approve or reject the correction

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Clock in/out endpoints, notification system
- Notes: Track correction history for audit purposes.
