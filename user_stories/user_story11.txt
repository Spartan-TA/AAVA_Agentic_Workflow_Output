EPIC E11 - Payroll Export Integration

===========================================

User Story 1: Generate Payroll-Ready Files
---------------------------------------------
Title: Generate Payroll-Ready Export Files

User Story: As a payroll manager, I want to generate files from attendance and leave so that payroll runs are accurate.

Acceptance Criteria:
Scenario: Payroll file generation
  Given approved attendance and leave
  When export is triggered
  Then files match provider schema

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Support multiple formats.

===========================================
