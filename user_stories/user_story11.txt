Epic: E11 - Payroll Export Integration

User Story 1: Payroll Export Generation
Title: Generate Payroll-Ready Files
User Story: As a payroll manager, I want to generate payroll-ready files from approved attendance and leave so that payroll runs are accurate.
Acceptance Criteria (Gherkin):
Given attendance and leave data,
When I generate export,
Then files match provider schema and totals reconcile.

Priority: High
Story Points: 2
Dependencies: E04, E06
Notes: Supports payroll integration.
