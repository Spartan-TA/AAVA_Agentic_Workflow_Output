### E11: Payroll Export Integration

#### 1. Generate Payroll-Ready Export Files
User Story: As a payroll admin I want to generate payroll-ready files from attendance and leave data So that payroll runs are accurate.
Acceptance Criteria:
Scenario: Generate export
Given approved attendance and leave data
When I generate the export
Then the file matches the provider schema
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Support multiple provider formats.

#### 2. Securely Deliver Payroll Files
User Story: As a system I want to deliver payroll files via SFTP or API So that data is transferred securely.
Acceptance Criteria:
Scenario: Secure delivery
Given a payroll file is generated
When I deliver it via SFTP/API
Then the transfer is encrypted and logged
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Export generation
- Notes: Retry failed deliveries.

#### 3. Reconcile Payroll Totals with Reports
User Story: As a payroll admin I want to reconcile export totals with attendance reports So that errors are caught.
Acceptance Criteria:
Scenario: Reconcile totals
Given an export and report
When I compare totals
Then they match or discrepancies are flagged
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance, Leave data
- Notes: Alert on mismatches.

#### 4. Audit Log for Payroll Exports
User Story: As a compliance officer I want audit logs for every payroll export So that all actions are traceable.
Acceptance Criteria:
Scenario: Log export
Given a payroll export occurs
When the file is generated or delivered
Then an audit entry is created with timestamp and user
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Audit module
- Notes: Include success/failure status.
