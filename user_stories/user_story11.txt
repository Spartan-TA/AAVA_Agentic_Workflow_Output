Title: Automated Security Rule Test Coverage

User Story:
As a QA engineer, I want automated tests to cover all role-based security rules so that unauthorized access is reliably prevented and compliance is demonstrated.

Acceptance Criteria:
- Scenario: Security tests for all endpoints
  Given a set of API endpoints with role restrictions
  When automated tests are run
  Then all endpoints are tested for 401/403/200 responses based on user role

- Scenario: Test coverage report includes security rules
  Given the test suite is executed
  When the coverage report is generated
  Then all security rules are shown as covered

Additional Details:
- Tests must be included in CI pipeline
- Coverage must be at least 90% for security-related code paths
- Tests must simulate all roles (ADMIN, HR, SUPERVISOR, WORKER)
