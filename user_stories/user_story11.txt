Title: Payroll Export Integration

User Story: As a payroll admin I want to export attendance and leave data in provider format so that payroll runs are accurate and automated.

Acceptance Criteria:
Scenario: Payroll export
Given approved attendance and leave data
When I generate an export
Then the file matches provider schema, totals reconcile, failed deliveries are retried, and an audit log is created

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Time & Attendance, Leave & Absence Management
- Notes: Secure delivery via SFTP/API
