# E11: Payroll Export Integration

## User Story 1
- Title: Generate Payroll Files from Attendance and Leave
- User Story: As a payroll admin, I want to generate payroll-ready files from attendance and leave data so that payroll runs are accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Payroll file generation
  Given approved attendance and leave records
  When I generate payroll files
  Then the files match the provider schema
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E04, E06
  * Notes: Support multiple provider formats

## User Story 2
- Title: Secure Delivery of Payroll Files
- User Story: As a payroll admin, I want payroll files delivered securely via SFTP or API so that data is protected.
- Acceptance Criteria in Gherkin format:
  Scenario: Secure delivery
  Given a payroll file
  When delivery is initiated
  Then the file is sent securely and delivery status is tracked
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Payroll file generation
  * Notes: Retry on failure

## User Story 3
- Title: Reconcile Payroll Totals with Reports
- User Story: As a payroll admin, I want payroll totals to reconcile with attendance and leave reports so that errors are detected.
- Acceptance Criteria in Gherkin format:
  Scenario: Payroll reconciliation
  Given payroll files and reports
  When reconciliation is performed
  Then totals match and discrepancies are flagged
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Payroll file generation, attendance reports
  * Notes: Automated checks

## User Story 4
- Title: Audit Log for Payroll Exports
- User Story: As a compliance officer, I want audit logs for every payroll export so that changes are tracked.
- Acceptance Criteria in Gherkin format:
  Scenario: Payroll export audit
  Given a payroll export
  When the export is performed
  Then an audit entry is created with actor, timestamp, and details
- Additional Details:
  * Priority: High
  * Story Points: 1
  * Dependencies: Payroll file generation
  * Notes: Immutable log
