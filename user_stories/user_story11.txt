Title: Shift Template Management
User Story: As an admin, I want to create and manage recurring shift templates so that scheduling is efficient and consistent.
Acceptance Criteria:
  Given the shift template UI,
  When I create/edit/delete a template,
  Then the changes are reflected in the schedule.

  Given a blackout date,
  When I assign a shift,
  Then the system prevents assignment.

Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: Attendance, Employee CRUD, RBAC
  Notes: Audit entries generated.
