Title: Shift & Schedule Management - Shift Template CRUD

User Story: As an HR user, I want to create, update, and delete shift templates so that standard shift patterns can be reused.

Acceptance Criteria:

Scenario: Create shift template
Given I am authenticated as HR
When I POST to /shifts/templates with valid data
Then a new shift template is created

Scenario: Update shift template
Given a shift template exists
When I PUT or PATCH /shifts/templates/{id}
Then the template is updated

Scenario: Delete shift template
Given a shift template exists
When I DELETE /shifts/templates/{id}
Then the template is removed

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD, RBAC, Attendance
- Notes: Templates should include start/end times, breaks, overtime rules.
