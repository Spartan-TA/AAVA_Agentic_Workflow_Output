Title: API Key/OAuth2 Security Toggle

User Story: As a system administrator I want to toggle between API key and OAuth2 security for endpoints So that I can choose the appropriate authentication method for different integration scenarios

Acceptance Criteria:
Scenario: Enable API key security
  Given the system is configured for API key authentication
  When an API request is made with a valid key
  Then access should be granted
Scenario: Enable OAuth2 security
  Given the system is configured for OAuth2 authentication
  When an API request is made with a valid token
  Then access should be granted
Scenario: Toggle security method
  Given I am in the admin settings
  When I select the desired authentication method
  Then all endpoints should enforce the selected method

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Authentication module
- Notes: Ensure endpoints are protected according to selected method
