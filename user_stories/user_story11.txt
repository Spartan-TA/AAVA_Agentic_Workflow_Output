Title: Support API Key/OAuth2 Toggle
User Story: As a system administrator I want to toggle between API key and OAuth2 authentication via configuration So that I can adapt security to different integration scenarios
Acceptance Criteria:
Scenario: Authentication toggle
Given the application configuration
When I set the authentication mode to API key or OAuth2
Then endpoints enforce the selected authentication method
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Role-based endpoint security (E03)
- Notes: Configuration must be documented and testable
