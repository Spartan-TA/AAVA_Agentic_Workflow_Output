Title: Shift & Schedule Management - Shift Template CRUD

User Story: As an HR user, I want to create, update, and delete shift templates so that recurring schedules are easy to manage.

Acceptance Criteria:
Scenario: Create Shift Template
Given valid shift details
When I POST /shifts/templates
Then a new template is created

Scenario: Update/Delete Template
Given an existing template
When I PUT/PATCH/DELETE /shifts/templates/{id}
Then the template is updated or deleted

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: E02, E03, E04
- Notes: Templates support rotations and overtime rules
