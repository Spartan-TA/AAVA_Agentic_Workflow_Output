Title: Configure Leave Policies

User Story:
As an HR Administrator, I want to configure leave policies (accrual rates, eligibility, carryover rules) so that the system enforces company and regulatory requirements for all employees.

Acceptance Criteria:
Scenario 1: Set accrual rates by employee type
  Given I am on the leave policy configuration page
  When I set accrual rates for full-time and part-time employees
  Then the system calculates leave balances accordingly

Scenario 2: Define carryover and expiration rules
  Given leave policies are configured
  When I set carryover limits and expiration dates
  Then employees are notified before balances expire

Scenario 3: Apply eligibility criteria
  Given eligibility rules are set
  When a new employee is onboarded
  Then their leave eligibility is determined automatically

Priority: Medium
Story Points: 8
Dependencies: E02, E03, E05
Notes: Policies must be auditable and support regulatory compliance.
