Title: Safety Incident Recording

User Story: As a safety officer I want to record safety incidents So that all workplace incidents are documented and tracked for compliance and improvement

Acceptance Criteria:
Scenario: Record safety incident
  Given I am authenticated as a safety officer
  When I submit a new incident report (date, location, description, involved parties)
  Then the incident should be saved and assigned a unique ID
Scenario: Edit incident report
  Given an incident report exists
  When I update its details
  Then the changes should be saved
Scenario: Delete incident report
  Given an incident report exists
  When I delete it
  Then it should be removed from the system

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Safety module
- Notes: Support for attachments and follow-up actions
