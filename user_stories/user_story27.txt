Title: Block Assignment for Expired Certifications

User Story: As a scheduler I want the system to prevent assignment of employees to tasks requiring certifications if their certification is expired so that we maintain safety and compliance.

Acceptance Criteria:
Scenario: Assignment blocked for expired certification
Given an employee's certification is expired
When I attempt to assign them to a task requiring that certification
Then the system blocks the assignment and displays a warning

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Must check certification status during scheduling and provide override only for admins.
