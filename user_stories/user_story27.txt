Title: Equipment Asset Registry CRUD

User Story: As an asset manager I want to create, read, update, and delete equipment asset records So that all assets are tracked and managed efficiently

Acceptance Criteria:
Scenario: Asset record creation
Given valid asset data
When I add a new asset
Then the asset should be saved and available for assignment

Scenario: Asset record update
Given an existing asset
When I update its details
Then the changes should be reflected in the registry

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Base package structure
- Notes: Support bulk import and export of asset data.
