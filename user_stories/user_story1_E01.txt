### E01 - Project Scaffolding & Domain Setup

**Title:** Spring Boot Project Initialization
User Story: As a developer I want to initialize a Spring Boot (Maven) project So that the EMS has a standardized foundation for all modules
Acceptance Criteria:
Scenario: Project builds and runs
Given the repository is cloned
When I run `mvn spring-boot:run`
Then the application starts on port 8080 and Actuator health endpoint returns UP
Scenario: Baseline migration runs
Given the database is empty
When I start the application
Then Flyway/Liquibase runs baseline migration successfully
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps
