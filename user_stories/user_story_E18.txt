### E18 - Localization & Multi-Tenant

**User Story 1**
Title: Tenant Isolation for Data and Config
User Story: As an ADMIN I want tenant isolation for data and config So that multiple warehouses/regions are supported.
Acceptance Criteria:
Scenario: Tenant Isolation
Given multiple tenants
When I access EMS
Then data and config are isolated per tenant

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02
- Notes: Tenant ID in all entities

**User Story 2**

Acceptance Criteria:
Scenario: Locale Configuration
Given tenant settings
When locale config is updated

Additional Details:
- Priority: Low
- Story Points: 2
