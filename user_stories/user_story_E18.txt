### E18 - Localization & Multi-Tenant

**User Story 1**
Title: Support Tenant Isolation
User Story: As an admin, I want all queries to include tenant ID so that data is isolated per warehouse/region.
Acceptance Criteria:
Scenario: Tenant isolation
Given multiple tenants
When I query data
Then only data for my tenant is returned
Priority: Low
Story Points: 3
Dependencies: E01, E02, E03
Notes: Enforce tenant context in all modules.

**User Story 2**
Title: Locale Configuration Per Tenant
User Story: As an admin, I want to configure locale settings per tenant so that date, time, and currency are correct.
Acceptance Criteria:
Scenario: Locale config
Given a tenant
When I set locale
Then all UI and data reflect the correct settings
Priority: Low
Story Points: 2
Dependencies: E01, E02, E03
Notes: Support timezones and currencies.

**User Story 3**
Title: Translate UI Strings
User Story: As a user, I want UI strings translated so that I can use EMS in my preferred language.
Acceptance Criteria:
Scenario: UI translation
Given a supported language
When I use EMS
Then all UI strings are translated
Priority: Low
Story Points: 2
Dependencies: E01, E02, E03
Notes: Use industry-standard i18n framework.

**User Story 4**
Title: Timezone-Aware Timestamps
User Story: As a user, I want all timestamps to be timezone-aware so that schedules and reports are accurate.
Acceptance Criteria:
Scenario: Timezone handling
Given a tenant in a different timezone
When I view schedules or reports
Then all times are shown in the tenant's timezone
Priority: Low
Story Points: 2
Dependencies: E01, E02, E03
Notes: Store timestamps in UTC, display in local.

**User Story 5**
Title: Test Tenant Isolation and Localization
User Story: As a QA, I want automated tests for tenant isolation and localization so that data and config do not leak.
Acceptance Criteria:
Scenario: Isolation tests
Given multiple tenants and locales
When tests are run
Then data and config are isolated and localized correctly
Priority: Low
Story Points: 2
Dependencies: E01, E02, E03
Notes: Include negative test cases.
