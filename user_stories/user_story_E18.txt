### E18: Localization & Multi-Warehouse

**User Story 1: Multi-Warehouse Support**
- User Story: As an admin, I want to configure multiple warehouses with distinct policies So that each location operates independently.
- Acceptance Criteria:
  - Scenario: Add warehouse
    - Given warehouse details
    - When I add a new warehouse
    - Then it appears as a selectable context for users
  - Scenario: Policy assignment
    - Given a warehouse
    - When I set policies
    - Then only that warehouse is affected
- Priority: Low
- Story Points: 5
- Dependencies: E01, E02, E05
- Notes: Policies include scheduling, leave, etc.

**User Story 2: UI Localization**
- User Story: As a user, I want the UI to be available in English and Spanish So that I can use the system in my preferred language.
- Acceptance Criteria:
  - Scenario: Language selection
    - Given a language preference
    - When I log in
    - Then the UI is displayed in the selected language
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02, E05
- Notes: All notifications and templates localized.
