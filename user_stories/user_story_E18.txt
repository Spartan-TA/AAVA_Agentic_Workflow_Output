### E18 - Localization & Multi-Tenant

**User Story 1: Tenant Isolation in Queries**
- Title: Support Tenant ID in All Queries
- Narrative: As a developer, I want tenant IDs supported in all queries so that data is isolated per warehouse.
- Acceptance Criteria:
  ```
  Given a multi-tenant setup,
  When querying data,
  Then only records for the current tenant are returned.
  ```
- Priority: Low
- Story Points: 3
- Dependencies: E01, E03
- Notes: Multi-tenancy.

**User Story 2: Locale Configuration for Date/Time/Currency**
- Title: Locale-Specific Configuration
- Narrative: As a user, I want date/time/currency formatted per locale so that information is clear.
- Acceptance Criteria:

  ```
  Given my locale,
  When viewing data,
  Then formats match my region.
  ```
- Priority: Low
- Story Points: 2
- Dependencies: Story 1
- Notes: Usability.
