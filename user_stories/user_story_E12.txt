### E12 - Notifications & Announcements

**User Story 1**
Title: Configure Notification Channels
User Story: As a user, I want to opt-in or out of email, SMS, and in-app notifications so that I control how I am notified.
Acceptance Criteria:
Scenario: Channel preferences
Given notification settings
When I update my preferences
Then only selected channels are used
Priority: Medium
Story Points: 2
Dependencies: E03, E05, E06, E07
Notes: Store preferences per user.

**User Story 2**
Title: Localize Notification Templates
User Story: As an admin, I want notification templates localized so that users receive messages in their preferred language.
Acceptance Criteria:
Scenario: Localized delivery
Given a user with locale set
When a notification is sent
Then the template is in the user's language
Priority: Medium
Story Points: 2
Dependencies: E03, E05, E06, E07
Notes: Support all supported locales.

**User Story 3**
Title: Track Notification Delivery Status
User Story: As an admin, I want to track delivery status of notifications so that failures are visible.
Acceptance Criteria:
Scenario: Delivery tracking
Given a sent notification
When delivery is attempted
Then the status is updated (delivered, failed, pending)
Priority: Medium
Story Points: 2
Dependencies: E03, E05, E06, E07
Notes: Retry failed notifications.

**User Story 4**
Title: Enforce Quiet Hours for Notifications
User Story: As a user, I want to set quiet hours so that I am not disturbed outside work hours.
Acceptance Criteria:
Scenario: Quiet hours
Given quiet hours configured
When a notification is triggered
Then it is delayed until quiet hours end
Priority: Medium
Story Points: 2
Dependencies: E03, E05, E06, E07
Notes: Allow override for urgent messages.

**User Story 5**
Title: Announcements on Dashboard
User Story: As a worker, I want to see company announcements on my dashboard so that I stay informed.
Acceptance Criteria:
Scenario: Dashboard announcements
Given an active announcement
When I log in
Then the announcement is visible on my dashboard
Priority: Medium
Story Points: 1
Dependencies: E03, E05, E06, E07
Notes: Mark announcements as read.
