### E08: Safety Incidents & OSHA Reporting

#### User Story 1
**Title:** Safety Incident Recording
**User Story:** As a SUPERVISOR I want to record safety incidents with details So that investigations can be tracked
**Acceptance Criteria (Gherkin):**
```
Given incident data (severity, location, description)
When I POST /safety/incidents
Then the incident is recorded and status set to Open

Given missing required fields
When I POST
Then I receive a validation error
```
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Near-miss support

#### User Story 2
**Title:** Incident Investigation Workflow
**User Story:** As an ADMIN I want to manage investigation status So that corrective actions are tracked
**Acceptance Criteria (Gherkin):**
```
Given an Open incident
When I update status to Investigating or Resolved
Then the workflow progresses and timestamps are logged

Given no status change
When I view the incident
Then current status is displayed
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Status workflow

#### User Story 3
**Title:** OSHA Summary Export
**User Story:** As an HR I want to export OSHA 300/300A summaries So that regulatory reporting is fulfilled
**Acceptance Criteria (Gherkin):**
```
Given incident data
When I request OSHA export
Then the file includes required fields for 300/300A

Given no incidents
When I export
Then the file is empty or shows no records
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Export endpoints
