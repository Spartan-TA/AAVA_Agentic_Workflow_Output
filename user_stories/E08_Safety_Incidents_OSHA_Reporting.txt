====================================================================
Epic E08: Safety Incidents & OSHA Reporting
====================================================================

User Story 1:
- Title: Record Safety Incidents and Near-Misses
- User Story: As a safety officer, I want to record incidents and near-misses with details so that safety data is captured.
- Acceptance Criteria:
  - Given the incident form, When I submit, Then severity, location, description, and involved employees are saved.
  - Given invalid data, When submitted, Then validation errors are shown.
- Additional Details: Priority: High, Story Points: 5, Dependencies: E02, E03, Notes: Core safety feature.

User Story 2:
- Title: Manage Incident Investigation Workflow
- User Story: As a safety manager, I want to track incident status (Open, Investigating, Resolved) so that follow-up actions are managed.
- Acceptance Criteria:
  - Given an incident, When status changes, Then the workflow is updated and audit logged.
- Additional Details: Priority: High, Story Points: 3, Dependencies: User Story 1, Notes: Workflow tracking.

User Story 3:
- Title: Generate OSHA Summary Reports
- User Story: As a compliance officer, I want to export OSHA 300/300A reports so that regulatory requirements are met.
- Acceptance Criteria:
  - Given incident data, When I request a report, Then OSHA fields are populated and exportable.
- Additional Details: Priority: High, Story Points: 3, Dependencies: User Story 2, Notes: Export as CSV/PDF.

User Story 4:
- Title: Provide Safety Metrics Dashboard
- User Story: As a manager, I want to view safety KPIs on a dashboard so that trends are visible.
- Acceptance Criteria:
  - Given incident data, When I access the dashboard, Then metrics are displayed with filters.
- Additional Details: Priority: High, Story Points: 2, Dependencies: User Story 1, Notes: For BI integration.
