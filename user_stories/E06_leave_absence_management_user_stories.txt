### E06: Leave & Absence Management

#### 1. Request Leave
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my absences are tracked and approved.
Acceptance Criteria:
Scenario: Submit leave request
Given I am authenticated
When I submit a leave request with dates and type
Then the request is created and routed to my supervisor for approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Validate accrual balances.

#### 2. Approve or Deny Leave Requests
User Story: As a supervisor I want to approve or deny leave requests So that staffing is managed.
Acceptance Criteria:
Scenario: Approve leave
Given a pending leave request
When I approve or deny it
Then the employee is notified and balances are updated
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Approval workflow required.

#### 3. Update Leave Balances
User Story: As an HR user I want leave balances to update automatically So that records are accurate.
Acceptance Criteria:
Scenario: Balance updates
Given a leave request is approved
When the leave dates pass
Then the employee's leave balance is reduced accordingly
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Support different accrual policies.

#### 4. Flag Scheduled Shifts for Coverage
User Story: As a scheduler I want scheduled shifts to be auto-flagged for coverage when leave is approved So that there are no staffing gaps.
Acceptance Criteria:
Scenario: Shift flagged
Given an employee has approved leave overlapping a shift
When the leave is approved
Then the shift is flagged for coverage and notifications are sent
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Integrate with notifications.

#### 5. Export Approved Leaves
User Story: As an HR user I want to export approved leave records So that I can reconcile with payroll.
Acceptance Criteria:
Scenario: Export leaves
Given approved leave data exists
When I request an export
Then a CSV file is generated with all relevant leave records
Additional Details:
- Priority: Low
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Include filters for date range, type, etc.
