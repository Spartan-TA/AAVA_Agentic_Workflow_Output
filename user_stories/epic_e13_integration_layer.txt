## User Story 1: Expose REST APIs for HRIS and WMS
**User Story:**  
As an integration engineer, I want REST APIs for employee and department data so that external systems can sync.

**Acceptance Criteria (Gherkin):**  
Given the API is running  
When HRIS/WMS calls endpoints  
Then data is returned securely

**Additional Details:**  
- Priority: High  
- Story Points: 2  
- Dependencies: E01, E02, E03  
- Notes: JWT/OAuth2 required

---

## User Story 2: HRIS Sync Job for New Hires and Terms
**User Story:**  
As an admin, I want a scheduled job to sync new hires and terminations from HRIS.

**Acceptance Criteria (Gherkin):**  
Given new data in HRIS  
When the sync job runs  
Then employees are created/updated/terminated in the system

**Additional Details:**  
- Priority: High  
- Story Points: 2  
- Dependencies: E13-1  
- Notes: Idempotent processing

---

## User Story 4: Webhooks for Key Events
**User Story:**  
As an integration engineer, I want webhooks for key events (new hire, leave approved) so that downstream systems are notified.

**Acceptance Criteria (Gherkin):**  
Given a key event  
When it occurs  
Then a webhook is sent to configured endpoints

**Additional Details:**  
- Priority: Medium  
- Story Points: 1  
- Dependencies: E13-1  
- Notes: Webhook retries on failure
