### E06 - Leave & Absence Management

**User Story 1**
Title: Request Leave (PTO, Sick, Unpaid)
User Story: As a WORKER I want to request leave for PTO, sick, or unpaid reasons So that my absence is properly recorded.
Acceptance Criteria:
Scenario: Leave Request Submission
Given a valid leave request
When I submit the request
Then it is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Accrual balances checked

**User Story 2**
Title: Approve/Deny Leave Requests
User Story: As a SUPERVISOR I want to approve or deny leave requests So that staffing is maintained.
Acceptance Criteria:
Scenario: Leave Approval Workflow
Given a pending leave request
When I approve or deny it
Then the employee's balance updates and scheduled shifts are flagged for coverage

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: User Story 1
- Notes: Approval history tracked

**User Story 3**
Title: Export Approved Leaves
User Story: As an HR I want to export approved leaves So that payroll and scheduling can be updated.
Acceptance Criteria:
Scenario: Leave Export
Given approved leave records
When I request an export
Then the file includes all approved leaves

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Export format configurable
