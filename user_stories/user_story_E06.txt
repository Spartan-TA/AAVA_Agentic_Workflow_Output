### E06 - Leave & Absence Management

**User Story 1**
Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my time off is tracked.
Acceptance Criteria:
Scenario: Submit leave request
Given I have available leave balance
When I request leave
Then the request is created and pending approval
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Validate leave type and balance.

**User Story 2**
Title: Approve or Deny Leave Requests
User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria:
Scenario: Approve leave
Given a pending leave request
When I approve or deny
Then the employee is notified and balances are updated
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Track approval status.

**User Story 3**
Title: Update Leave Balances
User Story: As an employee, I want my leave balance to update automatically so that I know how much time off I have left.
Acceptance Criteria:
Scenario: Balance update
Given an approved leave
When the leave is taken
Then my balance decreases accordingly
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Support accrual policies.

**User Story 4**
Title: Auto-Flag Scheduled Shifts for Coverage
User Story: As a scheduler, I want scheduled shifts to be flagged when an employee is on leave so that coverage can be arranged.
Acceptance Criteria:
Scenario: Shift auto-flag
Given an approved leave overlapping a shift
When the schedule is viewed
Then the shift is flagged for coverage
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Integrate with scheduling module.

**User Story 5**
Title: Export Approved Leaves
User Story: As an admin, I want to export approved leaves so that payroll and compliance reporting is accurate.
Acceptance Criteria:
Scenario: Export leaves
Given approved leave records
When I export data
Then a file is generated with all approved leaves
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E05
Notes: Support CSV format.
