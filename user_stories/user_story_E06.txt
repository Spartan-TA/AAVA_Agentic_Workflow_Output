### E06: Leave & Absence Management

**User Story 1: Employee Leave Request**
- User Story: As an employee, I want to request PTO, sick, or unpaid leave So that my time off is tracked and approved.
- Acceptance Criteria:
  - Scenario: Submit leave request
    - Given available leave balance
    - When I submit a leave request
    - Then the request is pending supervisor approval
  - Scenario: Insufficient balance
    - Given no available leave
    - When I submit a request
    - Then the system rejects it
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Accrual policies enforced.

**User Story 2: Supervisor Leave Approval**
- User Story: As a supervisor, I want to approve or deny leave requests So that staffing levels are maintained.
- Acceptance Criteria:
  - Scenario: Approve leave
    - Given a pending request
    - When I approve it
    - Then the employee's leave balance is updated and scheduled shifts are flagged for coverage
  - Scenario: Deny leave
    - Given a pending request
    - When I deny it
    - Then the employee is notified and no changes are made to schedule
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Approved leaves exported for payroll.
