### E06: Leave & Absence Management

**User Story 1: Leave Request Submission**
Title: Submit Leave Requests
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my absences are tracked and approved
Acceptance Criteria:
Scenario: Submit leave request
Given I have available leave balance
When I POST a leave request
Then the request is created and pending approval
Scenario: Insufficient balance
Given I have no PTO left
When I request PTO
Then the request is rejected
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Leave types and policies configurable

**User Story 2: Supervisor Approval Workflow**
Title: Approve or Deny Leave Requests
User Story: As a supervisor I want to approve or deny leave requests So that staffing levels are maintained
Acceptance Criteria:
Scenario: Approve leave
Given a pending request
When I approve
Then the employee's leave balance is updated and shift coverage is flagged
Scenario: Deny leave
Given a pending request
When I deny
Then the employee is notified
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Approval history tracked

**User Story 3: Leave Integration with Scheduling and Payroll**
Title: Integrate Leave with Scheduling and Payroll
User Story: As a system I want approved leaves to update schedules and payroll hours So that absences are accurately reflected
Acceptance Criteria:
Scenario: Approved leave
Given a leave is approved
When the schedule is generated
Then the employee is marked as unavailable and payroll hours are adjusted
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Exports include approved leaves
