### E06: Leave & Absence Management

**User Story 1**
- **Title:** Request Leave
- **User Story:** As a worker, I want to request PTO, sick, or unpaid leave so that my absences are tracked.
- **Acceptance Criteria:**
    - Scenario: Submit leave request
      - Given I am logged in
      - When I submit a leave request
      - Then the request is recorded and pending approval
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Validate accrual balances.

**User Story 2**
- **Title:** Approve or Deny Leave Requests
- **User Story:** As a supervisor, I want to approve or deny leave requests so that staffing is managed.
- **Acceptance Criteria:**
    - Scenario: Approve leave
      - Given a pending leave request
      - When I approve it
      - Then the employee's leave balance is updated and shift flagged for coverage
    - Scenario: Deny leave
      - Given a pending leave request
      - When I deny it
      - Then the employee is notified and no balance is deducted
- **Additional Details:** Priority: Medium, Story Points: 3, Dependencies: User Story 1, Notes: Track approval history.

**User Story 3**
- **Title:** Update Leave Balances
- **User Story:** As an HR user, I want leave balances to update automatically so that accruals are accurate.
- **Acceptance Criteria:**
    - Scenario: Balance update
      - Given a leave is approved
      - When the leave period starts
      - Then the employee's leave balance is decremented accordingly
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: User Story 2, Notes: Support multiple leave types.

**User Story 4**
- **Title:** Exclude Approved Leave from Scheduling
- **User Story:** As a scheduler, I want approved leaves to auto-flag scheduled shifts for coverage so that there are no gaps.
- **Acceptance Criteria:**
    - Scenario: Shift auto-flag
      - Given an employee has approved leave
      - When a shift overlaps with leave
      - Then the shift is flagged for coverage
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E05, Notes: Notify supervisors.

**User Story 5**
- **Title:** Export Leave Records
- **User Story:** As an HR user, I want to export leave records so that I can reconcile with payroll.
- **Acceptance Criteria:**
    - Scenario: Export approved leaves
      - Given leave records exist
      - When I export data
      - Then only approved leaves are included in the export
- **Additional Details:** Priority: Medium, Story Points: 1, Dependencies: User Story 3, Notes: CSV format.
