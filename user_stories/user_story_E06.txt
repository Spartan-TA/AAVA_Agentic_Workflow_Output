### Epic E06 - Leave & Absence Management

**User Story 1**
- Title: Leave Request Submission
- User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my time off is properly recorded.
- Acceptance Criteria:
  - Given a leave request,
    When I submit it,
    Then it is recorded and pending approval.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Multiple leave types.

**User Story 2**
- Title: Leave Approval Workflow
- User Story: As a supervisor, I want to approve or deny leave requests so that staffing is maintained.
- Acceptance Criteria:
  - Given a pending leave request,
    When I approve or deny,
    Then the employee is notified and balances are updated.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Approval workflow.

**User Story 3**
- Title: Accrual Balance Management
- User Story: As an HR user, I want leave accrual balances and policies enforced so that compliance is maintained.
- Acceptance Criteria:
  - Given an employee's leave balance,
    When a leave is approved,
    Then the balance is decremented according to policy.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Policy enforcement.

**User Story 4**
- Title: Scheduling Integration for Approved Leave
- User Story: As a scheduler, I want approved leaves to auto-flag scheduled shifts for coverage so that staffing gaps are addressed.
- Acceptance Criteria:
  - Given an approved leave,
    When I view the schedule,
    Then affected shifts are flagged for coverage.
- Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E05, Notes: Integration with scheduling.

**User Story 5**
- Title: Leave Export for Payroll
- User Story: As a payroll specialist, I want to export approved leaves so that payroll calculations are accurate.
- Acceptance Criteria:
  - Given approved leave records,
    When I export data,
    Then only approved leaves are included.
- Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E05, Notes: Export for payroll.
