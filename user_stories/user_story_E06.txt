Epic E06: Leave & Absence Management

1. Title: Request Leave
   User Story: As a WORKER I want to request PTO, sick, or unpaid leave So that my time off is tracked.
   Acceptance Criteria:
     Scenario: Leave request
     Given available leave balance
     When I POST /leave/request
     Then a leave request is created and pending approval
   Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02,E03,E05, Notes: Validate balance.

2. Title: Approve/Deny Leave
   User Story: As a SUPERVISOR I want to approve or deny leave requests So that staffing is managed.
   Acceptance Criteria:
     Scenario: Leave approval
     Given a pending leave request
     When I approve or deny
     Then the request status is updated and employee notified
   Additional Details: Priority: Medium, Story Points: 2, Dependencies: E06, Notes: Audit decision.

3. Title: Update Leave Balances
   User Story: As an HR I want leave balances to update automatically So that records are accurate.
   Acceptance Criteria:
     Scenario: Balance update
     Given an approved leave
     When the leave period starts
     Then the employee's balance is reduced accordingly
   Additional Details: Priority: Medium, Story Points: 1, Dependencies: E06, Notes: Support accrual policies.

4. Title: Flag Scheduled Shifts for Coverage
   User Story: As a SUPERVISOR I want scheduled shifts to auto-flag for coverage when leave is approved So that gaps are filled.
   Acceptance Criteria:
     Scenario: Shift coverage flag
     Given an approved leave
     When the leave overlaps scheduled shifts
     Then those shifts are flagged for coverage
   Additional Details: Priority: Medium, Story Points: 2, Dependencies: E06, Notes: Notify team.

5. Title: Error Handling for Insufficient Balance
   User Story: As a WORKER I want to receive an error when requesting leave with insufficient balance So that I understand my limits.
   Acceptance Criteria:
     Scenario: Insufficient leave balance
     Given a zero balance
     When I request leave
     Then a 400 error is returned with reason
   Additional Details: Priority: Medium, Story Points: 1, Dependencies: E06, Notes: Error message must specify leave type.
