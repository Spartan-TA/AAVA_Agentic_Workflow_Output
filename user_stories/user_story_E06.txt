### E06 - Leave & Absence Management

**User Story 1**
Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave So that my time off is tracked.
Acceptance Criteria:
- Given leave request, When I submit, Then a pending leave record is created.
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: PTO, sick, unpaid.

**User Story 2**
Title: Approve/Deny Leave
User Story: As a supervisor, I want to approve or deny leave requests So that staffing is managed.
Acceptance Criteria:
- Given a pending leave, When I approve, Then the employee's balance updates and scheduled shifts are flagged for coverage.
- When I deny, Then the request is marked as denied.
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Approval workflow.

**User Story 3**
Title: Accrual Balances and Policies
User Story: As an HR user, I want to manage leave accrual balances and policies So that compliance is maintained.
Acceptance Criteria:
- Given accrual policy, When leave is approved, Then balances update according to policy.
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Policy-driven.

**User Story 4**
Title: Leave Export for Payroll
User Story: As a payroll user, I want to export approved leaves So that payroll hours are accurate.
Acceptance Criteria:
- Given approved leaves, When exporting, Then only approved leaves are included in the export file.
Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E05, Notes: Export format.
