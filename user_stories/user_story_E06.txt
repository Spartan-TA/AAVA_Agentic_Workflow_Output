### E06 - Leave & Absence Management

**User Story 1**
Title: Request and Approve Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my absences are tracked.
Acceptance Criteria:
Scenario: Leave Request
Given I am logged in
When I submit a leave request
Then my supervisor receives an approval task
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Leave types and balances must be validated.

**User Story 2**
Title: Update Leave Accrual Balances
User Story: As an HR user, I want leave balances to update automatically so that accrual policies are enforced.
Acceptance Criteria:
Scenario: Accrual Update
Given an approved leave
When the leave is taken
Then the employee's balance is decremented accordingly
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Accrual policies must be configurable.

**User Story 3**
Title: Exclude Approved Leave from Scheduling and Payroll
User Story: As a scheduler, I want approved leaves to automatically flag scheduled shifts for coverage so that staffing gaps are addressed.
Acceptance Criteria:
Scenario: Shift Auto-Flag
Given an employee has approved leave
When a shift overlaps with the leave
Then the shift is flagged for coverage and excluded from payroll hours
Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E05
- Notes: Integration hooks for scheduling and payroll.

**User Story 4**
Title: Export Approved Leaves
User Story: As an HR user, I want to export approved leaves so that I can report on absence trends.
Acceptance Criteria:
Scenario: Leave Export
Given approved leave records exist
When I export the data
Then the export includes all relevant fields and matches the UI
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Export format: CSV.
