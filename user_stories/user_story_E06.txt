### E06 - Leave & Absence Management

**User Story 1:**
- Title: Request Leave
- User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my absences are tracked.
- Acceptance Criteria:
  - Scenario: Submit leave request
    - Given I am logged in
    - When I submit a leave request
    - Then the request is created and pending approval
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: E02, E03, E05

**User Story 2:**
- Title: Approve/Deny Leave
- User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
- Acceptance Criteria:
  - Scenario: Approve leave
    - Given a pending leave request
    - When I approve it
    - Then the employee's leave balance updates and the schedule is flagged
  - Scenario: Deny leave
    - Given a pending leave request
    - When I deny it
    - Then the employee is notified
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: E02, E03, E05

**User Story 3:**
- Title: Update Leave Balances
- User Story: As an employee, I want my leave balances to update automatically so that I know my available time off.
- Acceptance Criteria:
  - Scenario: Balance updates
    - Given an approved leave
    - When the leave is taken
    - Then my balance decreases accordingly
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05

**User Story 4:**
- Title: Exclude Approved Leave from Scheduling
- User Story: As a scheduler, I want approved leaves to auto-flag scheduled shifts for coverage so that shifts are not left uncovered.
- Acceptance Criteria:
  - Scenario: Shift flagged
    - Given an approved leave overlaps a scheduled shift
    - When the leave is approved
    - Then the shift is flagged for coverage
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05

**User Story 5:**
- Title: Export Leave Records
- User Story: As an HR user, I want to export approved leave records so that I can report on absences.
- Acceptance Criteria:
  - Scenario: Export leaves
    - Given approved leave records
    - When I request an export
    - Then a file is generated with leave details
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05
