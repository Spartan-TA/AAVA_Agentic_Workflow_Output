Title: Secure Employee Data Endpoints

User Story: As an ADMIN I want employee data endpoints to be secured So that only authorized users can access sensitive information

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without HR or ADMIN role
  When they access /employees
  Then access is denied

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs, RBAC
- Notes: Use Spring Security
