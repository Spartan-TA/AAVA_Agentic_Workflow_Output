Title: View Employee Details

User Story: As an HR administrator I want to view detailed employee profiles So that I can quickly access relevant information for HR processes

Acceptance Criteria:
Scenario: View employee profile
Given I am on the employee list page
When I select an employee
Then I should see their full profile including contact, job, and status information

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee database
- Notes: Ensure sensitive data is protected based on user role.
