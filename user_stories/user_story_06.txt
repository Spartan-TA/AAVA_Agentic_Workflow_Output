Title: Implement Create Employee API Endpoint

User Story: As an HR manager I want to create new employee records via a REST API so that I can add employees to the system efficiently.

Acceptance Criteria:

Scenario: Successfully create employee with valid data
Given I have valid employee data including name, badgeId, role, department, shiftGroup, and hireDate
When I POST to /api/v1/employees with the employee data
Then I should receive a 201 Created response
And the response should contain the created employee with a generated ID
And the employee should be persisted in the database
And audit fields should be populated

Scenario: Reject duplicate badgeId
Given an employee with badgeId 'EMP001' already exists
When I POST to /api/v1/employees with badgeId 'EMP001'
Then I should receive a 409 Conflict response
And the error message should indicate duplicate badgeId

Scenario: Validate required fields
Given I have employee data missing required fields
When I POST to /api/v1/employees
Then I should receive a 400 Bad Request response
And the error message should list all missing required fields

Scenario: Validate field formats
Given I have employee data with invalid email format
When I POST to /api/v1/employees
Then I should receive a 400 Bad Request response
And the error message should indicate invalid email format

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee entity (E02), Project scaffolding (E01)
- Notes: Use DTOs for request/response. Implement proper validation using Bean Validation annotations. Return appropriate HTTP status codes.
