Title: Equipment & Asset Assignment
User Story 1: As an asset manager I want to create and manage asset registry for scanners, forklifts, and PPE So that assets are tracked
Acceptance Criteria:
Scenario: Asset registry CRUD
Given I am authenticated
When I create, update, or delete an asset
Then changes are reflected in registry
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee master data, RBAC, Certification tracking
- Notes: Track asset condition

User Story 2: As a supervisor I want to assign assets to employees and track checkout/return So that accountability is maintained
Acceptance Criteria:
Scenario: Asset assignment
Given assets exist
When I assign or return assets
Then history log is updated per asset and employee
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Asset registry
- Notes: Prevent overdue returns

User Story 3: As a system I want to block asset assignment when required certifications are invalid So that safety is ensured
Acceptance Criteria:
Scenario: Assignment block
Given employee lacks valid certification
When asset assignment is attempted
Then action is blocked and user notified
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Certification tracking
- Notes: Show reason for block

User Story 4: As an asset manager I want to view asset history logs So that usage is audited
Acceptance Criteria:
Scenario: Asset history view
Given assets are assigned
When I view asset history
Then logs show all check-in/out events
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment
- Notes: Filter by employee/asset

User Story 5: As a supervisor I want to generate reports of overdue asset returns So that follow-up is possible
Acceptance Criteria:
Scenario: Overdue asset report
Given assets are overdue
When I generate report
Then list of overdue returns is available
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment
- Notes: Exportable CSV
