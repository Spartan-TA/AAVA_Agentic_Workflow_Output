Title: API Key/OAuth2 Toggle

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication So that I can select the most appropriate security protocol for integrations

Acceptance Criteria:
Scenario: Authentication method selection
Given the system configuration panel
When I choose API key or OAuth2
Then all API endpoints should enforce the selected authentication method

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Base package structure
- Notes: Document the configuration steps for both methods.
