Title: Attendance Corrections Workflow

User Story: As a supervisor, I want to submit corrections for missed punches so that attendance records are accurate for payroll.

Acceptance Criteria:
Scenario: Correction submission and approval
Given a missed punch is detected
When a correction is submitted
Then an approval task is created
And the correction is applied upon approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Time & Attendance
- Notes: Corrections must be auditable.
