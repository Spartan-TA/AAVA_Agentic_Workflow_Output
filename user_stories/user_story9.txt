Title: Document Employee APIs in OpenAPI with Example Schemas

User Story: As an integration developer I want Employee CRUD APIs documented in OpenAPI with example schemas So that I can easily integrate and test against the warehouse employee management system.

Acceptance Criteria:
Scenario: OpenAPI documentation available
  Given the Employee APIs are implemented
  When I access the OpenAPI documentation endpoint
  Then all Employee endpoints are described with request/response schemas and examples

Scenario: Example payloads
  Given the OpenAPI documentation
  When I view the schemas for POST/PUT/PATCH
  Then example payloads for employee creation and update are provided

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Documentation should include all fields (name, badgeId, role, department, shiftGroup, hireDate, status) and error responses.
