Title: Implement Role-Based Endpoint Security

User Story: As a Security Administrator I want to enforce role-based access control on all API endpoints so that only authorized users can access sensitive data and operations

Acceptance Criteria:
Scenario: Unauthorized access attempt
  Given a user without valid credentials
  When they attempt to access a protected endpoint
  Then the system returns a 401 Unauthorized response

Scenario: Forbidden action by insufficient role
  Given a user with SUPERVISOR role
  When they attempt to perform an ADMIN-only operation
  Then the system returns a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E01, E02
- Notes: Cover all endpoints; ensure test coverage for both 401 and 403 cases.
