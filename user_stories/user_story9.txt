Title: Create Shift Schedule
User Story: As a scheduler I want to create shift schedules for employees so that work coverage is ensured
Acceptance Criteria:
Scenario: Create new shift schedule
  Given I am logged in as a scheduler
  When I select employees and assign shifts
  Then the shift schedule is saved and visible to assigned employees
Scenario: Overlapping shift warning
  Given I am assigning a shift
  When the selected time overlaps with an existing shift
  Then I receive a warning and must resolve the conflict
Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Employee Master Data CRUD
- Notes: Validate against existing schedules

Title: Edit Shift Schedule
User Story: As a scheduler I want to edit existing shift schedules so that changes in staffing can be accommodated
Acceptance Criteria:
Scenario: Edit shift details
  Given a shift schedule exists
  When I update the shift time or assigned employee
  Then the changes are saved and affected employees are notified
Scenario: Prevent editing past shifts
  Given a shift has already occurred
  When I attempt to edit the shift
  Then I receive an error message
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Notifications & Announcements
- Notes: Editing should trigger notifications

Title: Employee Shift View
User Story: As an employee I want to view my assigned shifts so that I know when I am scheduled to work
Acceptance Criteria:
Scenario: View upcoming shifts
  Given I am logged in as an employee
  When I access my shift calendar
  Then I see all upcoming assigned shifts
Scenario: Filter shifts by date
  Given I am on my shift calendar
  When I select a date range
  Then I see shifts for the selected period
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Shift & Schedule Management
- Notes: Calendar view should support filtering
