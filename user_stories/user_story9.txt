Title: Implement Role-Based Endpoint Security
User Story: As a system administrator I want to restrict API endpoints based on user roles So that only authorized users can perform sensitive operations
Acceptance Criteria:
Scenario: Role-based access enforcement
Given a user with a specific role
When the user attempts to access a protected endpoint
Then access is granted or denied according to their role permissions
Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project scaffolding (E01), Employee CRUD (E02)
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER; unauthorized requests return 401, forbidden actions return 403
