User Story: As an asset manager I want to assign and track equipment to employees so that asset accountability and safe operation are ensured.

Acceptance Criteria:
Scenario: Asset assignment and certification validation
Given assets are registered
When check-in/out occurs
Then blocks happen if certs are invalid, history log is visible, and overdue returns are reported
