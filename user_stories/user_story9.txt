Title: Clock In/Out with Geofence
User Story: As a warehouse worker I want to clock in and out using my device with geofence validation So that my attendance is accurately recorded for payroll and compliance
Acceptance Criteria:
Scenario: Successful clock-in with geofence
Given I am within the warehouse geofence
When I submit a clock-in event
Then my attendance record is created and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Device ID and location must be captured

Title: Calculate Hours Worked per Shift
User Story: As a supervisor I want the system to automatically calculate hours worked per shift So that I can review accurate attendance totals for my team
Acceptance Criteria:
Scenario: Shift hours calculation
Given clock-in and clock-out events exist for a shift
When the system processes attendance records
Then the total hours worked are computed and visible in reports
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance module
- Notes: Handle overnight and split shifts

Title: Missed Punches and Corrections Workflow
User Story: As a worker I want to request corrections for missed punches So that my attendance record is accurate and approved by my supervisor
Acceptance Criteria:
Scenario: Correction request
Given I missed a clock-in or clock-out
When I submit a correction request
Then a supervisor is notified and can approve or deny the correction
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance, Notifications
- Notes: Correction history must be auditable

Title: Attendance Report Export
User Story: As an HR manager I want to export attendance reports in CSV format So that I can reconcile payroll and compliance records
Acceptance Criteria:
Scenario: Export attendance report
Given attendance records exist for a date range
When I request a CSV export
Then the report is generated and downloadable
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Attendance, Reporting
- Notes: Export must include corrections and approval status
