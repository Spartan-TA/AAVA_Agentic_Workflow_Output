Title: API Key/OAuth2 Toggle for Authentication

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication So that I can adapt security to integration requirements

Acceptance Criteria:
Scenario: Toggle authentication method
Given I am in the system configuration panel
When I select API key or OAuth2
Then all endpoints require the chosen authentication method

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Configuration should be documented and covered by automated tests
