Title: Security Configuration Toggle

User Story: As a system admin I want to toggle between API key and OAuth2 authentication so that the system supports different security models.

Acceptance Criteria:
Scenario: Auth toggle
Given the config is set
When I restart the app
Then the selected auth method is enforced

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC Enforcement
- Notes: Configurable via properties.
