Title: Soft-Delete Employee Records
User Story: As an HR manager I want to soft-delete employee records So that I can retain historical data without exposing inactive employees
Acceptance Criteria:
Scenario: Employee Soft-Delete
  Given I have HR manager access
  When I DELETE /employees/{id}
  Then the employee record is marked as inactive and excluded from active queries
