Title: API Key/OAuth2 Security Toggle

User Story: As an admin, I want to configure API authentication via API key or OAuth2 so that integration partners can be managed securely.

Acceptance Criteria:

Scenario: API key authentication enabled
Given the config
When API key is enabled
Then endpoints require a valid key

Scenario: OAuth2 authentication enabled
Given the config
When OAuth2 is enabled
Then endpoints require a valid token

Scenario: Invalid credentials denied
Given an invalid key/token
When accessing the API
Then access is denied

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Configurable via properties
