Title: Implement Role-Based Access Control (RBAC)

User Story: As an admin I want to assign roles to users so that access to sensitive operations is restricted based on authorization level

Acceptance Criteria:
Scenario: Assigning roles to users
Given a user exists in the system
When an admin assigns a role (ADMIN, HR, SUPERVISOR, WORKER) to the user
Then the user should have access only to endpoints permitted for their role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding, Employee Master Data
- Notes: Must cover endpoint and method-level security; roles configurable via API or UI.
