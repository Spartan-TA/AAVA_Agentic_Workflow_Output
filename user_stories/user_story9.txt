### E09 â Equipment & Asset Assignment

**User Story 1: Asset Registry CRUD**
- **User Story:** As an asset manager, I want to manage the asset registry so that all equipment is tracked.
- **Acceptance Criteria:**
  - Given asset details,
  - When I create/update/delete,
  - Then the registry reflects the changes.
- **Additional Details:** Priority: Medium; Story Points: 2; Dependencies: E02, E03, E07; Notes: Include asset type, condition.

**User Story 2: Assign/Return Equipment**
- **User Story:** As a supervisor, I want to check out and return assets to employees so that usage is tracked.
- **Acceptance Criteria:**
  - Given an asset,
  - When I assign or return,
  - Then the transaction is logged with timestamps.
- **Additional Details:** Priority: Medium; Story Points: 2; Dependencies: E09-1; Notes: Prevent double assignment.

**User Story 3: Block Assignment Without Valid Cert**
- **User Story:** As a supervisor, I want to prevent asset assignment if required certs are missing so that safety is ensured.
- **Acceptance Criteria:**
  - Given a missing/expired cert,
  - When I assign restricted equipment,
  - Then the system blocks the action.
- **Additional Details:** Priority: Medium; Story Points: 2; Dependencies: E07, E09-1; Notes: Show error message.

**User Story 4: Asset Condition Tracking**
- **User Story:** As an asset manager, I want to track asset condition so that maintenance is scheduled.
- **Acceptance Criteria:**
  - Given an asset,
  - When condition is updated,
  - Then the history is logged and visible.
- **Additional Details:** Priority: Medium; Story Points: 2; Dependencies: E09-1; Notes: Support status: Good, Needs Repair, Out of Service.

**User Story 5: Overdue Asset Return Report**
- **User Story:** As a supervisor, I want to report overdue asset returns so that accountability is enforced.
- **Acceptance Criteria:**
  - Given checked-out assets,
  - When due date passes,
  - Then overdue items are listed in a report.
- **Additional Details:** Priority: Medium; Story Points: 1; Dependencies: E09-2; Notes: Notify responsible employees.
