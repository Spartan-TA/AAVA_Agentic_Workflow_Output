Title: Equipment & Asset Assignment

User Story: As an asset manager I want to assign and track equipment (scanners, forklifts, PPE) to employees so that accountability and safe operation are ensured.

Acceptance Criteria:
Scenario: Assign asset to employee
  Given an asset and a qualified employee
  When I check out the asset
  Then the assignment is logged and certification is validated

Scenario: Return asset
  Given an asset is checked out
  When the employee returns it
  Then the asset is marked as returned and condition is updated

Scenario: Block assignment if certification missing
  Given an employee lacks required certification
  When I attempt to assign an asset
  Then the system blocks the assignment

Scenario: Overdue asset report
  Given assets are overdue for return
  When I generate a report
  Then all overdue assets are listed

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data (E02), RBAC (E03), Training & Certification Tracking (E07)
- Notes: Asset registry CRUD, history log per asset and employee, overdue reports.
