Title: View User Permissions

User Story: As a system administrator I want to view user permissions So that I can audit and verify access levels

Acceptance Criteria:
Scenario: View permissions
Given I am on the user management page
When I select a user
Then I should see a list of all permissions assigned to that user

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: RBAC module
- Notes: Permissions should be displayed in a clear and readable format.
