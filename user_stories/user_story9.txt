Title: Implement Role-Based Access Control

User Story: As a System Administrator I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) to users So that access to sensitive operations is restricted based on user responsibilities

Acceptance Criteria:

Scenario: Unauthorized requests return 401
  Given a user without authentication
  When they attempt to access a protected endpoint
  Then the response is 401 Unauthorized

Scenario: Forbidden actions return 403
  Given a user with insufficient role
  When they attempt to perform a restricted operation
  Then the response is 403 Forbidden

Scenario: ADMIN can manage all records
  Given a user with ADMIN role
  When they access any management endpoint
  Then all operations are permitted

Scenario: SUPERVISOR limited to team
  Given a user with SUPERVISOR role
  When they access team management endpoints
  Then only their team's records are accessible

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E01, E02
- Notes: Use Spring Security; roles mapped to endpoints and methods; test coverage required for all security rules.
