### E09: Equipment & Asset Assignment

#### User Story 1
Title: Asset Registry CRUD

User Story: As an asset manager, I want to create, update, and delete asset records So that equipment inventory is maintained.

Acceptance Criteria:
Scenario: Asset CRUD
Given asset data
When I perform CRUD operations
Then asset records are updated accordingly

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Asset types: scanners, forklifts, PPE

#### User Story 2
Title: Asset Check-In/Out Endpoints

User Story: As a supervisor, I want to check assets in and out to employees So that usage is tracked.

Acceptance Criteria:
Scenario: Asset check-in/out
Given an asset and employee
When I check out or return an asset
Then the transaction is recorded

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: History log per asset

#### User Story 3
Title: Block Asset Use if Certification Missing

User Story: As a safety officer, I want to prevent asset use if required certification is missing So that safety is enforced.

Acceptance Criteria:
Scenario: Certification check
Given an asset requiring certification
When an employee without valid certification attempts checkout
Then the checkout is blocked

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Certification check integrated

#### User Story 4
Title: Overdue Asset Return Reports

User Story: As an asset manager, I want reports of overdue asset returns So that accountability is maintained.

Acceptance Criteria:
Scenario: Overdue report
Given asset checkout history
When assets are overdue
Then a report is generated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Report filterable by employee/asset
