Title: Implement Row-Level Security for Supervisors

User Story:
As a supervisor, I want to only see and manage records for employees on my team so that I do not access data outside my scope.

Acceptance Criteria:
- Scenario: Supervisor requests employee list
  Given a user is authenticated as SUPERVISOR
  When they request the employee list
  Then only employees assigned to their team are returned

- Scenario: Supervisor attempts to update non-team employee
  Given a user is authenticated as SUPERVISOR
  When they attempt to update an employee not on their team
  Then the response is 403 Forbidden

Additional Details:
- Team membership must be defined in the employee domain
- Row-level security must be enforced in both API and service layers
- Automated tests must validate supervisor data boundaries
