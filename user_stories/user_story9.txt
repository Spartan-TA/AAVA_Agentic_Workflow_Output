Title: Support API Key/OAuth2 Toggle

User Story: As a system admin I want to toggle between API key and OAuth2 authentication So that integration partners can use the appropriate method

Acceptance Criteria:

Scenario: API key authentication enabled via config
Given API key mode is enabled
When I send requests with a valid API key
Then access is granted

Scenario: OAuth2 authentication enabled via config
Given OAuth2 mode is enabled
When I send requests with a valid OAuth2 token
Then access is granted

Scenario: Invalid credentials are rejected
Given either auth mode is enabled
When I send invalid credentials
Then I receive a 401 Unauthorized response

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: RBAC implementation
- Notes: Use application properties to switch modes; document usage in README
