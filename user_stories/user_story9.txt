Title: Implement Role-Based Access Control (RBAC) with Spring Security

User Story: As a system administrator I want to configure role-based access control using Spring Security so that users have permissions appropriate to their roles (ADMIN, HR, SUPERVISOR, WORKER).

Acceptance Criteria:
Scenario: Role-based endpoint access
  Given a user is authenticated
  When they access an endpoint
  Then access should be granted or denied based on their assigned role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01), Employee domain (E02)
- Notes: Roles must be enforced at both method and endpoint levels.
