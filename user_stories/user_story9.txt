Title: Secure Endpoints with Spring Security
User Story: As a developer I want to secure all APIs and endpoints with Spring Security So that unauthorized access is prevented.
Acceptance Criteria:
Scenario: Unauthorized request blocked
Given an unauthenticated request
When I access a protected endpoint
Then I receive a 401 Unauthorized error
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC
- Notes: Security rules must be covered by tests
