Title: Asset Assignment and Checkout

User Story: As a supervisor I want to assign equipment and PPE to employees and track checkout/return So that asset usage is accountable.

Acceptance Criteria:
Scenario: Asset assignment and tracking
Given assets are registered
When I assign and check out assets to employees
Then the system logs the transaction and blocks use if certification is missing

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E02, E03, E07
- Notes: History log per asset and employee.

Title: Overdue Asset Return Reporting

User Story: As an asset manager I want to view reports of overdue asset returns So that lost or misused equipment is minimized.

Acceptance Criteria:
Scenario: Overdue asset report generation
Given assets are checked out
When the return date passes without check-in
Then the asset appears in the overdue report

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Asset registry CRUD supported.
