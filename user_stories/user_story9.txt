Title: Restrict Access by Role

User Story: As a system administrator I want to restrict access to sensitive endpoints based on user roles So that only authorized personnel can perform critical operations

Acceptance Criteria:

Scenario: Unauthorized request returns 401
Given a user is not authenticated
When they attempt to access a protected endpoint
Then the system should return a 401 Unauthorized response

Scenario: Forbidden action returns 403
Given a user is authenticated but lacks the required role
When they attempt to perform a restricted action
Then the system should return a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain (E02), Project scaffolding (E01)
- Notes: Role definitions must be configurable and test coverage required.
