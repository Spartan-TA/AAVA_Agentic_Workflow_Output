Title: Worker Restricted Access
User Story: As a WORKER I want to access only my own records So that my privacy is protected and I cannot view or modify other employees' data
Acceptance Criteria:
Scenario: Worker attempts unauthorized access
Given I am logged in as WORKER
When I try to access another employee's record
Then I should receive a 401 Unauthorized or 403 Forbidden error
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Ensure error codes are consistent and covered by automated security tests.
