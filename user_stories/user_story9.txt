Title: Time & Attendance - Missed Punches and Corrections

User Story: As a supervisor, I want to handle missed punches and approve corrections so that attendance records are accurate.

Acceptance Criteria:

Scenario: Missed punch correction request
Given a worker missed a clock-in or clock-out
When the worker submits a correction request
Then a task is created for supervisor approval

Scenario: Supervisor approves correction
Given a correction task is pending
When the supervisor approves it
Then the attendance record is updated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Clock in/out endpoints
- Notes: All corrections must be auditable.
