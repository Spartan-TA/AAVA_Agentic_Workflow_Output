Epic: E09 - Equipment & Asset Assignment

User Story 1: Asset Registry CRUD
Title: Manage Asset Registry
User Story: As an operations manager, I want to create, update, and delete asset records so that equipment is tracked.
Acceptance Criteria (Gherkin):
Given access to asset registry,
When I perform CRUD operations,
Then assets are managed and visible in the registry.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Supports accountability.

User Story 2: Asset Check-In/Out
Title: Assign and Return Assets
User Story: As a supervisor, I want to assign and return assets to employees so that usage is tracked.
Acceptance Criteria (Gherkin):
Given assets and employees exist,
When I check-in/out an asset,
Then the event is recorded and asset condition is updated.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Supports safe operation.

User Story 3: Certification Blocking
Title: Block Asset Assignment if Certification Invalid
User Story: As a supervisor, I want to block asset assignment if employee certification is invalid so that safety is ensured.
Acceptance Criteria (Gherkin):
Given an employee lacks valid certification,
When I assign an asset,
Then the assignment is blocked.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Supports compliance.

User Story 4: Asset History Log
Title: View Asset Assignment History
User Story: As an operations manager, I want to view asset assignment history per asset and employee so that accountability is maintained.
Acceptance Criteria (Gherkin):
Given asset assignments exist,
When I view asset history,
Then all check-in/out events are displayed.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E07
Notes: Supports audits.

User Story 5: Overdue Asset Report
Title: Report Overdue Asset Returns
User Story: As an operations manager, I want to report overdue asset returns so that assets are recovered promptly.
Acceptance Criteria (Gherkin):
Given asset assignments exist,
When an asset is overdue,
Then the report lists overdue assets and responsible employees.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E07
Notes: Supports asset recovery.
