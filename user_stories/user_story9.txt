Title: Assign and Track Equipment & Assets

User Story:
As an asset manager, I want to assign equipment and PPE to employees, track check-in/out, and block use if certifications are missing so that assets are used safely and responsibly.

Acceptance Criteria:
Scenario 1: Asset registry
  Given I have asset details
  When I create or update an asset
  Then the asset is listed in the registry

Scenario 2: Assign asset
  Given an asset and a qualified employee
  When I check out the asset
  Then the assignment is recorded

Scenario 3: Block unqualified use
  Given an employee lacks required certification
  When I attempt to assign restricted equipment
  Then the system blocks the assignment

Scenario 4: Track asset history
  Given assets are assigned and returned
  When I view asset or employee history
  Then I see all check-in/out events

Scenario 5: Overdue returns report
  Given assets are overdue for return
  When I generate a report
  Then overdue assets are listed

Additional Details:
Priority: Medium
Story Points: 8
Dependencies: E02, E03, E07
Notes: Asset condition state must be tracked.
