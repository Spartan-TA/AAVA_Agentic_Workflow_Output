Title: Add Spring Security with RBAC Roles

User Story:
As a security architect,
I want to implement Spring Security with role-based access control (RBAC) for roles such as ADMIN, HR, SUPERVISOR, and WORKER,
So that sensitive operations are restricted to authorized users and compliance requirements are met.

Acceptance Criteria:
- Roles are defined and assigned to users in the system.
- Security rules restrict access to endpoints and methods based on role.
- Unauthorized requests return 401; forbidden actions return 403.
- ADMIN can manage all records; SUPERVISOR limited to their team.
- Security rules are covered by automated tests.

Additional Details:
- Use annotations for method and endpoint security.
- Role assignments are persisted and auditable.
- Document security model and role permissions.
