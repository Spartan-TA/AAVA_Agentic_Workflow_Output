Title: Record Employee Clock-In Event

User Story: As an employee I want to clock in at the start of my shift so that my worked hours are accurately tracked

Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift and on site
When I submit a clock-in event
Then my attendance record should show the clock-in time and associate it with my shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Geofence and device capture optional

Title: Record Employee Clock-Out Event

User Story: As an employee I want to clock out at the end of my shift so that my worked hours are accurately tracked

Acceptance Criteria:
Scenario: Successful clock-out
Given I am clocked in for a shift
When I submit a clock-out event
Then my attendance record should show the clock-out time and calculate total hours worked

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Automatic shift association

Title: Handle Missed Punches and Corrections

User Story: As a supervisor I want to review and approve corrections for missed punches so that attendance records remain accurate

Acceptance Criteria:
Scenario: Correction workflow
Given an employee missed a punch
When a correction request is submitted
Then a supervisor should be able to approve or deny the correction and update the attendance record

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Attendance, RBAC
- Notes: Approval tasks generated

Title: Export Attendance Reports

User Story: As an HR manager I want to export attendance data to CSV so that payroll processing is streamlined

Acceptance Criteria:
Scenario: Exporting attendance
Given I have access to attendance records
When I request an export
Then a CSV file should be generated with daily totals and corrections

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance, Payroll Integration
- Notes: Exportable reports
