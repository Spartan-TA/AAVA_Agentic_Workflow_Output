Title: Implement Employee Soft-Delete API

User Story: As an HR admin I want to soft-delete employee records So that historical data is preserved and inactive employees are excluded from active lists

Acceptance Criteria:
Scenario: Soft-delete employee
Given an existing employee record
When I DELETE /employees/{id}
Then the employee status is set to inactive and record is not physically removed

Scenario: Exclude inactive employees
Given soft-deleted employees exist
When I list employees
Then inactive employees are excluded from active lists by default

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story6.txt, user_story7.txt
- Notes: Provide option to view all (including inactive) for audit purposes
