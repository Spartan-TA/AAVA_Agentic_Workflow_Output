### E09 - Equipment & Asset Assignment

**User Story 1**
Title: Manage Asset Registry
User Story: As an asset manager I want to create, update, and delete asset records (scanners, forklifts, PPE) So that all equipment is tracked.
Acceptance Criteria:
Scenario: Asset CRUD
Given I have asset manager access
When I manage assets
Then changes are persisted in the registry
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Track asset condition state

**User Story 2**
Title: Check Out and Return Assets
User Story: As an employee I want to check out and return assets So that usage is tracked and assets are available when needed.
Acceptance Criteria:
Scenario: Asset check-out/in
Given an asset is available
When I check it out
Then the assignment is recorded
When I return it
Then the asset is marked as available
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E09-1
- Notes: Prevent double check-out

**User Story 3**
Title: Block Asset Use if Certification Invalid
User Story: As a system I want to prevent asset check-out if required certifications are expired So that only qualified employees use equipment.
Acceptance Criteria:
Scenario: Certification check
Given my certification is expired
When I attempt to check out a restricted asset
Then the system blocks the action
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E09-2
- Notes: Applies to forklifts and other regulated assets

**User Story 4**
Title: Maintain Asset and Employee History Log
User Story: As an asset manager I want to view the history of asset assignments and returns So that accountability is ensured.
Acceptance Criteria:
Scenario: View asset history
Given an asset has been checked out and returned
When I view its history
Then all assignment events are listed with timestamps and users
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E09-2
- Notes: History visible per asset and employee

**User Story 5**
Title: Report Overdue Asset Returns
User Story: As a supervisor I want to generate reports of overdue asset returns So that I can follow up with employees.
Acceptance Criteria:
Scenario: Overdue report
Given assets are overdue for return
When I generate the report
Then all overdue items and responsible employees are listed
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E09-2
- Notes: Support export to CSV
