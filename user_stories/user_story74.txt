Title: Offboarding Workflow for Access and Asset Revocation

User Story:
As an HR administrator, I want offboarding to automatically revoke system access, collect assigned assets, and update schedules so that terminated employees are deprovisioned securely and efficiently.

Acceptance Criteria:
- Scenario: Offboarding revokes access and collects assets
  Given an employee is terminated
  When offboarding is triggered
  Then system access is revoked, assets are flagged for return, and schedules are updated

- Scenario: Offboarding actions are logged
  Given offboarding actions occur
  When the audit log is reviewed
  Then all actions are traceable by user and timestamp

Additional Details:
- Asset collection must include overdue asset reporting
- Schedule updates must remove or reassign shifts
- All offboarding actions must be auditable and exportable
