Title: Initiate Employee Offboarding Workflow

User Story:
As an HR administrator, I want to initiate an offboarding workflow for departing employees so that all exit tasks and documentation are completed efficiently and securely.

Acceptance Criteria:
Scenario 1: Start offboarding workflow
  Given an employee is marked for departure
  When I initiate offboarding
  Then offboarding tasks are assigned to relevant departments and the employee receives instructions

Scenario 2: Track offboarding progress
  Given offboarding is in progress
  When I view the employee's offboarding status
  Then I see a checklist of completed and pending tasks

Additional Details:
Priority: High
Story Points: 3
Dependencies: Employee profile, task management
Notes: Workflow should include asset return, exit interview, and access revocation.
