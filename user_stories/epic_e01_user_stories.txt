### Epic E01: Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to scaffold a Spring Boot project with Maven so that all modules have a consistent foundation for development and deployment.
Acceptance Criteria:
Scenario: Project Initialization
Given a clean repository
When I run the Maven initialization command
Then the project structure is created with base packages for employee, scheduling, attendance, and safety
And the project builds and runs on port 8080
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps

**User Story 2**
Title: Database Migration Setup
User Story: As a developer, I want to configure Flyway/Liquibase for database migrations so that schema changes are versioned and repeatable.
Acceptance Criteria:
Scenario: Baseline Migration
Given the migration tool is configured
When I run the migration
Then the baseline schema is applied successfully
And future migrations can be tracked
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project structure
- Notes: Use Flyway or Liquibase as per team standard

**User Story 3**
Title: Enable Actuator Health Endpoint
User Story: As an ops engineer, I want to enable the Actuator health endpoint so that I can monitor application health.
Acceptance Criteria:
Scenario: Health Endpoint Availability
Given the application is running
When I access /actuator/health
Then the endpoint returns status UP
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project structure
- Notes: Health endpoint must be documented
