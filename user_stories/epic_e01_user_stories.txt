EPIC E01 - PROJECT SCAFFOLDING & DOMAIN SETUP

===========================================

Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot project with Maven So that I have a standardized foundation for all modules

Acceptance Criteria:
Scenario: Project scaffolding and build
Given I have cloned the repository
When I run the build command
Then the project should build and run on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure README includes build and run steps
