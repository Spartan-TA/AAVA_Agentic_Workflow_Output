## Epic E01: Project Scaffolding & Domain Setup

### User Story 1: Initialize Spring Boot Project Structure
**User Story:**  
As a developer, I want to initialize a Spring Boot project with Maven and core modules so that the team can develop features on a standardized foundation.

**Acceptance Criteria (Gherkin):**
```
Given a new repository
When I run the build command
Then the project builds successfully on port 8080

Given the repository
When I open the project structure
Then I see base packages for employee, scheduling, attendance, and safety modules
```

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: None  
Notes: README must include build/run steps.

---

### User Story 2: Configure Database Migration Tool
**User Story:**  
As a developer, I want to set up Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable.

**Acceptance Criteria (Gherkin):**
```
Given the project is built
When I start the application
Then Flyway/Liquibase runs the baseline migration without errors

Given a new migration script
When I apply it
Then the schema updates and is tracked in the migration history
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Project structure  
Notes: Baseline migration must succeed on first run.

---

### User Story 3: Enable Actuator Health Endpoint
**User Story:**  
As an operations engineer, I want the Actuator health endpoint enabled so that I can monitor application health.

**Acceptance Criteria (Gherkin):**
```
Given the application is running
When I access /actuator/health
Then the endpoint returns status "UP"
```

**Additional Details:**  
Priority: High  
Story Points: 1  
Dependencies: Project structure  
Notes: Health endpoint must be accessible without authentication for initial setup.
