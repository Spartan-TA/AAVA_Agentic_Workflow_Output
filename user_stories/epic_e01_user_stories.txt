### EPIC E01 - Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot project with Maven So that the team has a standardized foundation for all modules.

Acceptance Criteria:
Scenario: Project initialization
Given I have cloned the repository
When I run the build command
Then the project builds successfully and runs on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure README contains build/run steps.
