### E01 - Project Scaffolding & Domain Setup

**Title:** Initialize Spring Boot Project
User Story: As a developer I want to initialize a Spring Boot project with Maven So that I have a standardized foundation for all modules
Acceptance Criteria:
Scenario: Project setup
Given I have cloned the repository
When I run `mvn clean install`
Then the project builds successfully and runs on port 8080
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: README must include build/run steps
