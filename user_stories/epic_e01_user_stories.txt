### Epic E01: Project Scaffolding & Domain Setup

#### User Story 1: Initialize Spring Boot Project Structure
- **Title:** Spring Boot Project Initialization
- **User Story:** As a developer, I want a Spring Boot project scaffolded with Maven so that all modules can be developed consistently.
- **Acceptance Criteria:**
  ```
  Scenario: Project scaffolding and build
    Given a fresh codebase
    When I run 'mvn clean install'
    Then the project builds successfully and runs on port 8080
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** None
- **Notes:** README must include build/run steps.

#### User Story 2: Configure Base Packages and Modules
- **Title:** Base Package Structure Setup
- **User Story:** As a developer, I want base packages and core modules (employee, scheduling, attendance, safety) configured so that future features are organized.
- **Acceptance Criteria:**
  ```
  Scenario: Base package structure exists
    Given the project is initialized
    When I inspect the codebase
    Then I see packages for employee, scheduling, attendance, and safety
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E01
- **Notes:** Follows company package naming conventions.

#### User Story 3: Database Migration Tool Integration
- **Title:** Flyway/Liquibase Migration Setup
- **User Story:** As a developer, I want Flyway or Liquibase integrated so that database schema changes are versioned and repeatable.
- **Acceptance Criteria:**
  ```
  Scenario: Baseline migration runs
    Given the project is started
    When I check the database
    Then baseline migration has executed and schema is initialized
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E01
- **Notes:** Baseline migration must run on startup.

#### User Story 4: Actuator Health Endpoint
- **Title:** Actuator Health Endpoint Enabled
- **User Story:** As an operator, I want the Actuator health endpoint enabled so that I can monitor service status.
- **Acceptance Criteria:**
  ```
  Scenario: Health endpoint returns UP
    Given the service is running
    When I GET /actuator/health
    Then the response status is 200 and body contains "UP"
  ```
- **Priority:** High
- **Story Points:** 1
- **Dependencies:** E01
- **Notes:** Health endpoint must be accessible.
