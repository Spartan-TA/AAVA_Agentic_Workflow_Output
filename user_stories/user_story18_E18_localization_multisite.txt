### Epic E18: Localization & Multi-Site

#### 1. Assign Employees to Sites
User Story: As an HR user I want to assign employees to specific warehouse sites So that multi-site operations are managed.
Acceptance Criteria:
Scenario: Site assignment
Given an employee
When I assign a site
Then their records reflect the site
Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01, E02, E03, E05
- Notes: Support site transfer.

#### 2. Support Multiple Time Zones for Shift Times
User Story: As a scheduler I want shift times to reflect local time zones So that scheduling is accurate.
Acceptance Criteria:
Scenario: Time zone support
Given multiple sites
When I view shift times
Then times are shown in local TZ
Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: Site assignment
- Notes: Handle daylight savings.

#### 3. Localize UI Strings
User Story: As a user I want UI strings localized So that I can use the app in my language.
Acceptance Criteria:
Scenario: UI localization
Given my language preference
When I use the app
Then all strings are localized
Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: Site assignment
- Notes: Support major languages.

#### 4. Configure Site-Specific Policies and Shift Templates
User Story: As an admin I want site-specific policies and shift templates So that regional compliance is met.
Acceptance Criteria:
Scenario: Site-specific configuration
Given multiple sites
When I configure policies/templates
Then each site has its own settings
Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: Site assignment
- Notes: Policy inheritance supported.

#### 5. Filter Reports by Site
User Story: As a manager I want to filter reports by site So that analysis is regional.
Acceptance Criteria:
Scenario: Site filter in reports
Given reports
When I apply site filter
Then only data for selected site is shown
Additional Details:
- Priority: Low
- Story Points: 1
- Dependencies: Site assignment
- Notes: Multi-site dashboard.
