Title: OpenAPI Documentation for Integration Endpoints

User Story: As a developer I want all HRIS, WMS, and SSO APIs documented in OpenAPI format so that I can easily integrate and test against the platform

Acceptance Criteria:
Scenario: API documentation is available and accurate
  Given I access the API documentation endpoint
  When I review the HRIS, WMS, and SSO API specs
  Then all endpoints, parameters, and responses are described in OpenAPI and kept up to date with implementation

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: Documentation must be accessible to authorized integrators.
