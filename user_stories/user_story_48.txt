Title: Announcements Visible on Dashboard

User Story: As a worker I want to see important announcements on my dashboard so that I am always informed about critical updates

Acceptance Criteria:
Scenario: Viewing announcements
Given there are active announcements
When I log in to my dashboard
Then I see the latest announcements prominently displayed

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Dashboard module, announcement service
- Notes: Announcements should be dismissible and support rich text
