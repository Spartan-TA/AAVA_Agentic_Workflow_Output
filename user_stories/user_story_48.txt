Title: Role-Based Dashboards

User Story: As a user I want my dashboard to show relevant information based on my role So that I can quickly access the tools and data I need

Acceptance Criteria:
Scenario: View role-based dashboard
Given I am logged in
When I access my dashboard
Then I should see widgets and data tailored to my role (employee, manager, admin)

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User roles, dashboard module
- Notes: Support customization and permissions.
