### E01 - Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project
User Story: As a developer, I want to initialize a Spring Boot (Maven) project with base packages So that all modules have a standardized foundation.
Acceptance Criteria:
- Given the repository is cloned, When I run `mvn spring-boot:run`, Then the application starts on port 8080 and the health endpoint returns UP.
- Given the project, When I open the README, Then I see build and run instructions.
Additional Details: Priority: High, Story Points: 3, Dependencies: None, Notes: Scaffold only.

**User Story 2**
Title: Set Up Core Domain Modules
User Story: As a developer, I want to create core modules for employee, scheduling, attendance, and safety So that each domain is separated for maintainability.
Acceptance Criteria:
- Given the codebase, When I inspect the package structure, Then I see separate packages for each core domain.
Additional Details: Priority: High, Story Points: 5, Dependencies: E01, Notes: Follows DDD principles.

**User Story 3**
Title: Configure Database Migration Tool
User Story: As a developer, I want to add Flyway/Liquibase for DB migrations So that schema changes are versioned and repeatable.
Acceptance Criteria:
- Given the project, When I start the app, Then Flyway/Liquibase runs the baseline migration and DB tables are created.
Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Baseline only.

**User Story 4**
Title: Enable Spring Boot Actuator
User Story: As an operator, I want Actuator endpoints enabled So that I can monitor application health and metrics.
Acceptance Criteria:
- Given the app is running, When I access `/actuator/health`, Then I see status UP.
Additional Details: Priority: High, Story Points: 1, Dependencies: E01, Notes: Health only.
