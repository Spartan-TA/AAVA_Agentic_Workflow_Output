### E01 - Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to initialize a Spring Boot project with Maven and configure base packages so that the codebase is standardized and easy to extend.
Acceptance Criteria:
Scenario: Project Initialization
Given a new repository
When I run the Maven build
Then the project builds successfully and runs on port 8080
Scenario: Package Structure
Given the base package structure
When I inspect the codebase
Then core modules (employee, scheduling, attendance, safety) are present
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps

**User Story 2**
Title: Database Migration Setup
User Story: As a developer, I want to add Flyway/Liquibase for database migrations so that schema changes are versioned and repeatable.
Acceptance Criteria:
Scenario: Migration Execution
Given the migration scripts
When I start the application
Then Flyway/Liquibase runs baseline migration successfully
Scenario: Migration Failure
Given an invalid migration
When I start the application
Then the build fails with a clear error
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Baseline migration must create initial schema

**User Story 3**
Title: Enable Actuator Health Endpoint
User Story: As a DevOps engineer, I want to enable the Actuator health endpoint so that I can monitor application health.
Acceptance Criteria:
Scenario: Health Endpoint
Given the application is running
When I access /actuator/health
Then the endpoint returns status UP
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: None
- Notes: Health endpoint must be documented in README
