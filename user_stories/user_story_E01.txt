[E01] Project Scaffolding & Domain Setup

User Story 1
Title: Initialize Spring Boot Project Structure

User Story: As a developer, I want to initialize a Spring Boot (Maven) project with standard base packages so that all modules follow a consistent structure.

Acceptance Criteria:
Scenario: Project initialization
Given a new repository
When I run the build command
Then the project compiles and runs on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps

User Story 2
Title: Set Up Core Domain Modules

User Story: As a developer, I want to scaffold core modules (employee, scheduling, attendance, safety) so that each business area has a dedicated package.

Acceptance Criteria:
Scenario: Core modules present
Given the project is initialized
When I inspect the source code
Then I see base packages for employee, scheduling, attendance, and safety

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01-1
- Notes: Follows domain-driven design

User Story 3
Title: Integrate Database Migration Tool

User Story: As a developer, I want Flyway or Liquibase configured for DB migrations so that schema changes are versioned and repeatable.

Acceptance Criteria:
Scenario: Migration runs on startup
Given a clean database
When the application starts
Then baseline migration is applied automatically

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01-1
- Notes: Migration scripts stored under db/migration

User Story 4
Title: Enable Spring Actuator for Health Checks

User Story: As an operator, I want Actuator endpoints enabled so that I can monitor application health.

Acceptance Criteria:
Scenario: Health endpoint available
Given the application is running
When I GET /actuator/health
Then I receive a 200 response with status UP

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01-1
- Notes: Secure actuator endpoints except health

User Story 5
Title: Document Project Setup in README

User Story: As a developer, I want a README with build and run instructions so that onboarding is fast and consistent.

Acceptance Criteria:
Scenario: README present
Given the repository is cloned
When I open README.md
Then I see clear steps to build and run the project

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01-1
- Notes: Include Java version, Maven commands, and port info
