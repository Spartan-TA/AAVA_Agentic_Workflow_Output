### E01 - Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project
User Story: As a Developer I want to initialize a Spring Boot project So that the EMS has a standardized foundation for all modules.
Acceptance Criteria:
Scenario: Project Initialization
Given a clean repository
When I run the build command
Then the project builds and runs on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure README includes build/run steps
