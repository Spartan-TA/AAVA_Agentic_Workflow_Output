### E01 - Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want the project to be scaffolded with Spring Boot and Maven so that all modules have a consistent foundation.
Acceptance Criteria:
Scenario: Project initialization
Given a new repository
When I build and run the project
Then the application starts on port 8080 and the base package structure is present
Priority: High
Story Points: 3
Dependencies: None
Notes: Ensure README includes build/run steps.

**User Story 2**
Title: Enable Database Migration Tool
User Story: As a developer, I want Flyway or Liquibase configured so that database schema changes are versioned and repeatable.
Acceptance Criteria:
Scenario: Baseline migration
Given the application is started
When Flyway/Liquibase runs
Then the baseline migration is applied without errors
Priority: High
Story Points: 2
Dependencies: None
Notes: Migration scripts should be in a dedicated folder.

**User Story 3**
Title: Expose Health Endpoint
User Story: As an operator, I want an Actuator health endpoint enabled so that I can monitor application status.
Acceptance Criteria:
Scenario: Health check
Given the application is running
When I GET /actuator/health
Then the response status is 200 and body contains "UP"
Priority: High
Story Points: 1
Dependencies: None
Notes: Endpoint should not expose sensitive info.
