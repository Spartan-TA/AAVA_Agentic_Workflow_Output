### E01 - Project Scaffolding & Domain Setup

**Title:** Initialize Spring Boot Project  
User Story: As a developer, I want to initialize a Spring Boot project with Maven So that I have a standardized foundation for all EMS modules.  
Acceptance Criteria:  
Scenario: Project Initialization  
Given a new repository  
When I run the Maven build  
Then the project builds successfully and runs on port 8080  
Additional Details:  
- Priority: High  
- Story Points: 3  
- Dependencies: None  
- Notes: README must include build/run instructions
