### E01 - Project Scaffolding & Domain Setup

**Title:** Initialize Spring Boot Project Structure
User Story: As a developer I want to initialize a Spring Boot project with Maven So that the team has a standardized foundation for all modules
Acceptance Criteria:
Scenario: Project builds and runs
Given the base project is set up
When I run `mvn spring-boot:run`
Then the application starts on port 8080
Scenario: Health endpoint available
Given the application is running
When I access `/actuator/health`
Then the response is `{"status":"UP"}`
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps

**Title:** Configure Core Domain Modules
User Story: As a developer I want to set up base packages for employee, scheduling, attendance, and safety So that each domain is organized and ready for feature development
Acceptance Criteria:
Scenario: Base package structure exists
Given the project is initialized
When I inspect the source tree
Then I see packages for employee, scheduling, attendance, safety
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Initialize Spring Boot Project Structure
- Notes: Follows company package naming conventions

**Title:** Enable Database Migrations
User Story: As a developer I want to add Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable
Acceptance Criteria:
Scenario: Baseline migration runs
Given the migration tool is configured
When I start the application
Then baseline migration is applied to the database
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Initialize Spring Boot Project Structure
- Notes: Migration scripts stored under `/db/migration`
