EPIC E01: Project Scaffolding & Domain Setup

===========================================

Title: Project Scaffolding - Initialize Spring Boot Project
User Story: As a developer, I want to initialize a Spring Boot project with Maven so that I have a standardized foundation for the EMS.
Acceptance Criteria:
Scenario: Project initialization
Given I have cloned the repository
When I run 'mvn clean install'
Then the project builds successfully and runs on port 8080
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Should include .gitignore, README, and basic directory structure.
