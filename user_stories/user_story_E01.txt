Title: Project Scaffolding & Domain Setup - Initialize Spring Boot Project
User Story: As a developer I want to initialize a Spring Boot (Maven) project with base packages and core modules So that the team has a standardized foundation for development.
Acceptance Criteria:
Scenario: Project initialization
Given I have cloned the repository
When I run the build and start the application
Then the app runs on port 8080 and the Actuator health endpoint returns UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps.
