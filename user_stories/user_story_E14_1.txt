Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all create, update, and delete actions on sensitive data (employee PII, schedules, approvals, payroll) to be logged centrally So that I can ensure regulatory requirements and enable forensic analysis

Acceptance Criteria:
Scenario: Audit log entry creation
Given a user performs a create, update, or delete action on sensitive data
When the action is completed
Then an audit log entry is created capturing actor, timestamp, before/after values, and entity type

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03 (RBAC)
- Notes: Audit log must be tamper-evident and immutable.
