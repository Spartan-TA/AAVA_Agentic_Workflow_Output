Title: Audit Logging of Sensitive Changes

User Story: As a compliance officer I want every create, update, and delete of sensitive data to be logged with actor, timestamp, and before/after values So that we meet audit and forensic analysis requirements

Acceptance Criteria:
Scenario: Audit log entry for sensitive change
Given a user makes a change to employee PII, schedules, approvals, or payroll
When the change is saved
Then an immutable audit log entry is created with all required details

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: E03
- Notes: Log table must be tamper-evident and exportable by date/user/entity.
