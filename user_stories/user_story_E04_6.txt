Title: Attendance Exception Alerts

User Story: As a supervisor I want to receive alerts for attendance exceptions So that I can address issues promptly

Acceptance Criteria:
Scenario: Attendance exception alert
Given an exception occurs (e.g., missed clock-in)
When the system detects it
Then I should receive a notification with details

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Notification module
- Notes: Support email and in-app alerts
