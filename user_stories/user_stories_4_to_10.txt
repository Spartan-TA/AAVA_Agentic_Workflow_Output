USER STORY 4
Title: Employee CRUD API - Create Employee
User Story: As an HR MANAGER I want to create new employee records with name, badgeId, role, department, shiftGroup, hireDate, and status So that I can maintain accurate employee master data.
Acceptance Criteria:
Scenario: Create Employee
  Given valid employee details
  When I POST to /employees
  Then a new employee record is created
  And the badgeId is unique
  And the response matches the OpenAPI schema
Additional Details:
Priority: High
Story Points: 3
Dependencies: Project Scaffolding
Notes: Enforce badgeId uniqueness at DB and API level.
