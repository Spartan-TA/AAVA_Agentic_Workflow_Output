Title: Expose WMS Connector

User Story: As a developer I want a connector for WMS integration So that warehouse management systems can synchronize inventory and assignments

Acceptance Criteria:
Scenario: Use WMS connector
Given I have valid credentials
When I connect to the WMS API
Then the system should exchange inventory and assignment data securely

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: WMS API, authentication
- Notes: Support scheduled sync and error handling.
