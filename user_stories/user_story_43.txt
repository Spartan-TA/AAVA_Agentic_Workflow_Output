Title: Return Equipment

User Story: As an employee I want to return equipment when no longer needed So that inventory records remain accurate and equipment can be reassigned

Acceptance Criteria:
Scenario: Equipment return
Given equipment is assigned to me
When I initiate a return request
Then the equipment manager should be notified and the equipment marked as returned

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Equipment assignment
- Notes: Support for condition reporting on return
