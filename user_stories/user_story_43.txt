Title: Map Payroll Fields to Provider Format

User Story: As a payroll administrator I want to map payroll data fields to provider-specific formats So that exports are compatible with different payroll systems

Acceptance Criteria:
Scenario: Configure field mapping
Given I am logged in as a payroll administrator
When I access the payroll export settings
Then I should be able to map internal fields to provider-required fields

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Integration Layer
- Notes: Support for multiple provider templates.
