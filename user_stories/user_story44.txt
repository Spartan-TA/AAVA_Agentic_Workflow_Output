Title: Send System Notifications to Users

User Story: As a system administrator I want to send notifications to users So that they are informed about important events and updates

Acceptance Criteria:
Scenario: Sending notifications
Given I have an announcement or event to communicate
When I create and send a notification
Then targeted users should receive the notification via their preferred channel (email, in-app, SMS)

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Notification service, user preferences
- Notes: Support scheduling and targeting by role or department.
