Title: Export Payroll Data to CSV

User Story:
As a payroll administrator, I want to export payroll data to a CSV file so that I can import it into external payroll systems and ensure accurate payments.

Acceptance Criteria:
Scenario 1: Export payroll data
  Given payroll data for the current period is finalized
  When I select 'Export to CSV'
  Then a CSV file containing all relevant payroll fields is generated and downloaded

Scenario 2: Validate export format
  Given I export payroll data
  When the file is generated
  Then the format matches the required template for external payroll systems

Additional Details:
Priority: High
Story Points: 2
Dependencies: Payroll data finalization
Notes: Export should include employee ID, hours, earnings, deductions, and taxes.
