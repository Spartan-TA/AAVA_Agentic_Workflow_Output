Title: OSHA Reporting Export

User Story: As a compliance officer I want to export OSHA-compliant safety incident reports So that regulatory reporting requirements are met

Acceptance Criteria:
Scenario: Export OSHA report
  Given I am authenticated and have access to safety incidents
  When I request an OSHA export
  Then a downloadable file (CSV, PDF) with required OSHA fields should be generated
Scenario: Export with filters
  Given I have applied filters (e.g., date range, location)
  When I export the report
  Then only filtered incidents should be included

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Safety module, reporting engine
- Notes: Format must meet OSHA specifications
