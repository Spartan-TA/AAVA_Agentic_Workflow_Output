Title: Asset Checkout/Return Workflow

User Story: As an employee I want to check out and return assets through the system So that asset usage is tracked and availability is updated in real time

Acceptance Criteria:
Scenario: Asset checkout
Given an available asset
When I check it out
Then the system should record the transaction and update asset status

Scenario: Asset return
Given a checked-out asset
When I return it
Then the system should record the transaction and update asset status

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Equipment Asset Registry CRUD
- Notes: Support overdue notifications and asset condition reporting.
