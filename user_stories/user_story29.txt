Title: Employee Requests Equipment Return
User Story: As an employee I want to request the return of assigned equipment So that asset records remain accurate and resources are available for others
Acceptance Criteria:
Scenario: Request equipment return
Given I am logged into the system and have assigned equipment
When I submit a return request for equipment
Then the supervisor is notified and the asset status is updated upon approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset management module, notifications
- Notes: Return history should be tracked for compliance.
