Title: Request Paid Time Off (PTO)

User Story:
As an Employee, I want to request paid time off (PTO) through the system so that my supervisor can review and approve my leave efficiently.

Acceptance Criteria:
Scenario 1: Submit a PTO request
  Given I am logged into the system
  When I navigate to the leave request page and submit a PTO request
  Then my supervisor receives a notification for approval

Scenario 2: View PTO balance before requesting
  Given I have accrued PTO
  When I view the leave request page
  Then my available PTO balance is displayed

Scenario 3: Prevent requests exceeding balance
  Given my PTO balance is less than the requested days
  When I attempt to submit the request
  Then the system displays an error and prevents submission

Priority: Medium
Story Points: 5
Dependencies: E02, E03, E05
Notes: PTO requests must integrate with scheduling and payroll modules.
