Title: Certification CRUD and Expiry Alerts

User Story: As an HR manager I want to manage employee certifications and receive expiry alerts So that compliance is maintained and renewals are timely

Acceptance Criteria:
Scenario: Add certification
  Given I am authenticated
  When I add a certification to an employee record
  Then the certification should be saved
Scenario: Edit certification
  Given a certification exists
  When I update its details
  Then the changes should be saved
Scenario: Delete certification
  Given a certification exists
  When I delete it
  Then it should be removed from the employee record
Scenario: Expiry alert
  Given a certification is nearing expiry
  When the expiry date approaches
  Then an alert should be sent to the employee and manager

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Certification module, notification system
- Notes: Support for multiple certification types
