Title: Localization & Multi-Warehouse

User Story: As a warehouse manager I want to manage multiple warehouse sites with localized settings So that operations can be tailored to each location and language

Acceptance Criteria:
Scenario: Configure warehouse settings
Given I have admin access
When I add a new warehouse site
Then I can set local calendar, blackout dates, and language preferences

Scenario: Multi-language support
Given users access the system from different warehouses
When they log in
Then UI and notifications are presented in their preferred language

Additional Details:
- Priority: Medium
- Story Points: 6
- Dependencies: Shift & Schedule Management
- Notes: Multi-warehouse support; localization for UI and notifications
