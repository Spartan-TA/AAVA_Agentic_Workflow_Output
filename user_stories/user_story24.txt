Title: Accrual Balance Management and Scheduling Integration

User Story:
As an HR manager, I want leave accrual balances to update automatically and integrate with scheduling so that employees cannot be scheduled during approved leave and balances remain accurate.

Acceptance Criteria:
- Scenario: Leave approval updates accrual balance
  Given an employee has an accrual balance
  When a leave request is approved
  Then the balance is reduced by the approved amount

- Scenario: Approved leave blocks shift assignment
  Given an employee has approved leave
  When a manager tries to assign them to a shift during that period
  Then the system prevents the assignment

Additional Details:
- Accrual policies must be configurable by leave type
- Integration hooks must update scheduling and payroll modules
- All changes must be logged and exportable
