Title: Create Shift Templates

User Story: As a supervisor I want to create reusable shift templates so that I can efficiently schedule recurring shifts for my team.

Acceptance Criteria:

Scenario: Create basic shift template
Given I am a supervisor
When I POST to /api/v1/shifts/templates with shift details (name, start time, end time, break duration)
Then a shift template should be created
And the template should be reusable for scheduling

Scenario: Define shift rotation
Given I have multiple shift templates
When I create a rotation pattern (e.g., 2 days on, 1 day off)
Then the rotation should be saved
And I should be able to apply it to employees

Scenario: Set overtime rules
Given I am creating a shift template
When I define overtime thresholds (e.g., >8 hours/day, >40 hours/week)
Then the rules should be associated with the template
And overtime should be automatically calculated based on these rules

Scenario: Configure blackout dates
Given certain dates are warehouse holidays
When I mark them as blackout dates
Then no shifts should be scheduled on those dates
And the system should prevent scheduling conflicts

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee entity (E02), RBAC (E03), Attendance (E04)
- Notes: Support multiple shift types (day, night, swing). Allow template cloning. Validate shift times don't overlap.
