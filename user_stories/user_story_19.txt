Title: Employee Requests Shift Swap

User Story: As an employee I want to request a shift swap with a colleague So that I can manage personal conflicts without disrupting coverage

Acceptance Criteria:
Scenario: Submitting a shift swap request
Given I am assigned to a shift
When I submit a swap request to a colleague
Then the colleague should be notified and a manager must approve the swap before it is finalized

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Shift assignment, notifications
- Notes: All swap actions should be logged for audit purposes.
