Title: Manage Overtime Rules and Blackout Dates

User Story: As a scheduler I want to configure overtime rules and blackout dates So that scheduling complies with labor policies and warehouse operation calendars

Acceptance Criteria:
Scenario: Set overtime rule
Given a shift template
When I configure overtime parameters
Then overtime is calculated according to the rule

Scenario: Add blackout date
Given a warehouse calendar
When I add a blackout date
Then no shifts can be scheduled on that date

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC, Attendance, Shift Templates
- Notes: Blackout dates must prevent scheduling conflicts
