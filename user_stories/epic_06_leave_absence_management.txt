Title: Leave & Absence Management - Request Leave
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my time off is tracked and approved

Acceptance Criteria:
Scenario: Submit leave request
Given I have available leave balance
When I submit a leave request
Then the request is created and pending approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD, RBAC, Shift management
- Notes: Accrual balances enforced

Title: Leave & Absence Management - Approve/Deny Leave
User Story: As a supervisor I want to approve or deny leave requests So that staffing plans remain accurate

Acceptance Criteria:
Scenario: Approve leave
Given a pending leave request
When I approve it
Then the employee's leave balance is updated
And scheduled shifts are flagged for coverage

Scenario: Deny leave
Given a pending leave request
When I deny it
Then the request is marked as denied

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave request
- Notes: Approved leaves exported

Title: Leave & Absence Management - Update Leave Balances
User Story: As an HR manager I want leave balances to update automatically So that records reflect actual accruals and usage

Acceptance Criteria:
Scenario: Leave balance update
Given an approved leave
When the leave period starts
Then the employee's leave balance is reduced accordingly

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Leave approval
- Notes: Integration with payroll
