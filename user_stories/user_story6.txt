Title: Retrieve Employee Records API
User Story: As an HR manager I want to retrieve employee records with filtering and pagination So that I can efficiently manage and review employee data
Acceptance Criteria:
Scenario: Employee record retrieval
  Given multiple employee records exist
  When I GET /employees with filter and pagination parameters
  Then I receive a paginated, filtered list of employee DTOs
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation API
- Notes: Filtering by department, role, status; OpenAPI schemas must include examples
