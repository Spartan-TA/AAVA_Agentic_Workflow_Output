Title: API Key/OAuth2 Toggle
User Story: As a system administrator I want to toggle between API key and OAuth2 authentication So that I can adapt to different security requirements
Acceptance Criteria:
Scenario: Authentication mode switch
Given the config is set to API key mode
When a request is made with a valid API key
Then access is granted according to role permissions
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Must be switchable via config
