### E06 - Leave & Absence Management

**Title:** Request Leave
**User Story:** As an employee, I want to request PTO or sick leave so that my time off is tracked.
**Acceptance Criteria:**
Scenario: Leave request
Given I have leave balance
When I submit a request
Then the request is pending approval
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Validate against accrual policies.

**Title:** Approve/Deny Leave
**User Story:** As a supervisor, I want to approve or deny leave requests so that staffing is maintained.
**Acceptance Criteria:**
Scenario: Leave approval
Given a pending request
When I approve or deny
Then the employee is notified and balances are updated
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Auto-flag scheduled shifts for coverage.

**Title:** Export Approved Leaves
**User Story:** As an HR user, I want to export approved leave records so that payroll can be processed accurately.
**Acceptance Criteria:**
Scenario: Export leaves
Given approved leaves exist
When I export
Then a CSV file is generated with all relevant data
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Integrate with payroll export.
