Title: Update Employee Record
User Story: As an HR manager I want to update employee records So that I can keep employee information accurate and current
Acceptance Criteria:
Scenario: Employee update
Given an existing employee record
When I submit an update via the API
Then the employee record is updated and changes are reflected in the system
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee record creation (E02)
- Notes: PATCH/PUT endpoints must validate updates and preserve badgeId uniqueness
