---
EPIC E06: Leave & Absence Management

User Story 1:
Title: Request Leave (PTO, Sick, Unpaid)
User Story: As an employee, I want to request different types of leave so that my time off is tracked.
Acceptance Criteria in Gherkin:
Scenario: Leave request submission
  Given my employee account
  When I submit a leave request
  Then the request is recorded and pending approval
Additional Details:
  Priority: Medium
  Story Points: 2
  Dependencies: E02, E03, E05
  Notes: Support PTO, sick, unpaid leave

User Story 2:
Title: Approve or Deny Leave Requests
User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria in Gherkin:
Scenario: Leave approval workflow
  Given a pending leave request
  When I approve or deny the request
  Then the employee is notified and balances are updated
Additional Details:
  Priority: Medium
  Story Points: 2
  Dependencies: E02, E03, E05
  Notes: Approval status tracked

User Story 3:
Title: Update Accrual Balances and Policies
User Story: As an HR user, I want leave accruals to update automatically so that balances are accurate.
Acceptance Criteria in Gherkin:
Scenario: Accrual balance update
  Given an approved leave
  When the leave period starts
  Then the employee's accrual balance is reduced accordingly
Additional Details:
  Priority: Medium
  Story Points: 2
  Dependencies: E02, E03, E05
  Notes: Policy-driven accruals

User Story 4:
Title: Auto-Flag Scheduled Shifts for Coverage
User Story: As a system, I want scheduled shifts to be flagged when an employee is on leave so that coverage is arranged.
Acceptance Criteria in Gherkin:
Scenario: Shift coverage flagging
  Given an approved leave overlapping a scheduled shift
  When I view the shift schedule
  Then the shift is flagged for coverage
Additional Details:
  Priority: Medium
  Story Points: 2
  Dependencies: E02, E03, E05
  Notes: Integrate with shift management

User Story 5:
Title: Export Approved Leaves for Payroll
User Story: As a payroll admin, I want to export approved leaves so that payroll calculations are accurate.
Acceptance Criteria in Gherkin:
Scenario: Leave export
  Given approved leave records
  When I request a payroll export
  Then the file includes all approved leaves and types
Additional Details:
  Priority: Medium
  Story Points: 1
  Dependencies: E02, E03, E05
  Notes: Format compatible with payroll provider
