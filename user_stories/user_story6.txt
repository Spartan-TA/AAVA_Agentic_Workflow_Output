Title: Enforce Unique badgeId for Employee Records

User Story: As a system administrator I want to enforce unique badgeId for each employee So that duplicate badge assignments are prevented and data integrity is maintained.

Acceptance Criteria:
Scenario: Create employee with unique badgeId
  Given no existing employee with the same badgeId
  When I create a new employee
  Then the employee is created successfully

Scenario: Create employee with duplicate badgeId
  Given an existing employee with badgeId X
  When I attempt to create another employee with badgeId X
  Then the request is rejected with a validation error

Scenario: Update employee badgeId to duplicate
  Given two employees with different badgeIds
  When I update one employee's badgeId to match the other's
  Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Validation should occur at both API and database levels.
