Title: Leave Management - Request and Approve Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my absences are properly tracked.
Acceptance Criteria:
Scenario: Request leave
  Given I have available leave balance
  When I submit a leave request
  Then my supervisor is notified for approval

Scenario: Approve/deny leave
  Given a leave request is pending
  When my supervisor reviews it
  Then they can approve or deny

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E05
Notes: Supports compliance

Title: Leave Management - Accrual Balances and Policy Enforcement
User Story: As an HR manager, I want leave accrual balances and policies enforced so that leave is managed fairly.
Acceptance Criteria:
Scenario: Accrual balance update
  Given leave is approved
  When the balance is recalculated
  Then the employee's accrual is updated

Scenario: Policy enforcement
  Given a leave request exceeds balance
  When I submit the request
  Then the system rejects it

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Prevents overuse

Title: Leave Management - Integration with Scheduling and Payroll
User Story: As a scheduler, I want approved leaves to auto-flag scheduled shifts and update payroll exports so that staffing and pay are accurate.
Acceptance Criteria:
Scenario: Shift auto-flag
  Given an approved leave overlaps a shift
  When the schedule is generated
  Then the shift is flagged for coverage

Scenario: Payroll export update
  Given approved leave exists
  When payroll is exported
  Then leave hours are excluded

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Reduces manual intervention
