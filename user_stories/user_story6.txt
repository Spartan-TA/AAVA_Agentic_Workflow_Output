Title: Role-Based Access Control (RBAC) Implementation

User Story: As a system administrator, I want to configure RBAC with roles (ADMIN, HR, SUPERVISOR, WORKER) so that only authorized users can access sensitive endpoints.

Acceptance Criteria:
Scenario: Unauthorized access
Given a user with insufficient privileges
When they access a protected endpoint
Then they receive a 401 or 403 error as appropriate

Scenario: Admin access
Given an ADMIN user
When they access any employee record
Then access is granted

Scenario: Supervisor limited access
Given a SUPERVISOR
When they access records outside their team
Then access is denied

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API
- Notes: Cover security rules with automated tests.
