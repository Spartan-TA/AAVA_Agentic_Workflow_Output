Title: Implement Employee CRUD APIs

User Story:
As an API consumer,
I want to be able to create, read, update, and delete employee records via RESTful endpoints,
So that employee data can be managed programmatically and integrated with other systems.

Acceptance Criteria:
- POST /employees creates a new employee and returns the created record.
- GET /employees returns a paginated list of employees.
- GET /employees/{id} returns details for a specific employee.
- PUT/PATCH /employees/{id} updates employee fields.
- DELETE /employees/{id} performs a soft-delete.
- badgeId uniqueness enforced; errors returned for duplicates.
- API returns appropriate HTTP status codes and error messages.

Additional Details:
- Use DTOs for request/response payloads.
- Include OpenAPI documentation for all endpoints.
- Unit and integration tests cover all CRUD operations.
