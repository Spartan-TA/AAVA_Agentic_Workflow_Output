Title: Implement Soft Delete for Employees

User Story: As an HR manager I want to soft-delete employees So that historical data is preserved for audit and reporting

Acceptance Criteria:

Scenario: Soft-deleted employees are excluded from active lists
Given an employee is soft-deleted
When I GET /employees?status=active
Then the deleted employee is not included

Scenario: Soft-deleted employees can be restored
Given an employee is soft-deleted
When I PATCH /employees/{id} with status=active
Then the employee is restored to active status

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee CRUD APIs
- Notes: Add status field (active, deleted); update queries to filter by status
