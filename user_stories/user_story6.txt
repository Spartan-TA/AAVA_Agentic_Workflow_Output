---
Epic: E06 - Leave & Absence Management

User Story 1: Leave Request
Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my time off is tracked.
Acceptance Criteria (Gherkin):
Given I am logged in,
When I submit a leave request,
Then the request is recorded and my accrual balance is checked.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Supports compliance.

User Story 2: Leave Approval Workflow
Title: Approve/Deny Leave Requests
User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria (Gherkin):
Given a leave request exists,
When I approve or deny,
Then the employee is notified and balances are updated.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Supports staffing plans.

User Story 3: Leave Balance Tracking
Title: Track Leave Accruals
User Story: As an HR manager, I want to track leave accruals and policies so that balances are accurate.
Acceptance Criteria (Gherkin):
Given leave policies are defined,
When leave is requested or approved,
Then balances are updated accordingly.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05
Notes: Supports payroll.

User Story 4: Shift Coverage Flagging
Title: Auto-Flag Shifts for Coverage
User Story: As a scheduler, I want scheduled shifts to be auto-flagged for coverage when leave is approved so that staffing gaps are filled.
Acceptance Criteria (Gherkin):
Given a leave is approved,
When a shift overlaps,
Then the shift is flagged for coverage.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E05
Notes: Prevents understaffing.

User Story 5: Leave Export
Title: Export Approved Leaves
User Story: As an HR manager, I want to export approved leaves so that payroll and compliance reporting is accurate.
Acceptance Criteria (Gherkin):
Given approved leave data exists,
When I request an export,
Then the report includes all approved leaves.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E05
Notes: Supports payroll integration.
