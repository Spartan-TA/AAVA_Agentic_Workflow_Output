Title: Leave Management - Request Leave

User Story: As an employee I want to request PTO, sick, or unpaid leave so that my time off is tracked.

Acceptance Criteria:
Scenario: Submit leave request
Given I am an employee
When I submit a leave request with dates and type
Then my request is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Accrual balances checked.

Title: Leave Management - Approve/Deny Leave

User Story: As a supervisor I want to approve or deny leave requests so that staffing is managed.

Acceptance Criteria:
Scenario: Approve leave request
Given a leave request is pending
When I approve it
Then the employee's leave balance is updated and scheduled shifts are flagged for coverage

Scenario: Deny leave request
Given a leave request is pending
When I deny it
Then the employee is notified and no balance is deducted

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Integration with scheduling and payroll.

Title: Leave Management - Export Approved Leaves

User Story: As a payroll admin I want to export approved leaves so that payroll calculations are accurate.

Acceptance Criteria:
Scenario: Export approved leaves
Given approved leave records exist
When I request an export
Then I receive a file with all approved leaves for the period

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Format matches payroll requirements.
