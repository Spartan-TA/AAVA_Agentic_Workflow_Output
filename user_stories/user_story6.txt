Title: Leave & Absence Management

User Story: As an employee I want to request and track leave (PTO, sick, unpaid) so that my time off is properly managed and reflected in scheduling and payroll.

Acceptance Criteria:
Scenario: Request leave
  Given I am an employee
  When I submit a leave request with dates and type
  Then the request is logged and pending approval

Scenario: Approve/deny leave
  Given a supervisor
  When they review a leave request
  Then they can approve or deny the request and balances update accordingly

Scenario: Integration with scheduling
  Given approved leave
  When the schedule is generated
  Then my scheduled shifts are flagged for coverage

Scenario: Export leave records
  Given leave data exists
  When I request an export
  Then I receive a file showing approved leaves

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data (E02), RBAC (E03), Shift & Schedule Management (E05)
- Notes: Accrual balances and policies must be enforced; integration hooks for scheduling and payroll.
