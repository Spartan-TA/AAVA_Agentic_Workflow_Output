Title: Create Employee Domain and CRUD APIs

User Story: As a Backend Developer I want to implement CRUD APIs for employee records So that HR and supervisors can manage employee data efficiently

Acceptance Criteria:
Scenario: Employee CRUD operations
Given I have valid API credentials
When I POST, GET, PUT, PATCH, or DELETE to /employees
Then the employee record is created, retrieved, updated, or soft-deleted as requested

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: API must support pagination, filtering, and enforce unique badgeId for each employee.
