Title: Employee Domain CRUD - Delete (Soft-Delete) Employee
User Story: As an HR user I want to soft-delete employee records So that former employees are not shown in active lists but their history is retained.
Acceptance Criteria:
Scenario: Soft-delete employee
Given an existing employee
When I DELETE /employees/{id}
Then the employee is marked as inactive and excluded from active queries
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create Employee
- Notes: Implement soft-delete, not hard delete
