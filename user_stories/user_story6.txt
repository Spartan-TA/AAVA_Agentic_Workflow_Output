Title: Enforce Unique Badge ID for Employees

User Story: As a system administrator I want the system to enforce unique badge IDs for each employee so that duplicate badge assignments are prevented.

Acceptance Criteria:
Scenario: Unique badge ID validation
  Given I attempt to create or update an employee
  When I provide a badgeId that already exists
  Then the system should reject the operation with an appropriate error message

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints
- Notes: Validation should occur on both create and update operations.
