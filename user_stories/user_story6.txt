### E06 - Leave & Absence Management

**User Story 1:**
Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my absences are tracked and approved.
Acceptance Criteria:
Scenario: Submit leave request
  Given a logged-in employee
  When I submit a leave request
  Then the request is created and pending approval
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Leave workflow

**User Story 2:**
Title: Approve or Deny Leave
User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria:
Scenario: Process leave request
  Given a pending leave request
  When I approve or deny
  Then the employee is notified and the status is updated
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Supervisor action

**User Story 3:**
Title: Update Leave Balances
User Story: As an HR admin, I want leave balances to update automatically so that accruals and usage are accurate.
Acceptance Criteria:
Scenario: Automatic balance update
  Given an approved leave
  When the leave is taken
  Then the employee's balance is reduced accordingly
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Accrual logic

**User Story 4:**
Title: Exclude Approved Leave from Scheduling
User Story: As a scheduler, I want approved leave to automatically flag scheduled shifts for coverage so that shifts are not left unstaffed.
Acceptance Criteria:
Scenario: Flag shift for coverage
  Given an approved leave
  When the employee is scheduled for a shift during that period
  Then the shift is flagged for coverage
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Staffing continuity

**User Story 5:**
Title: Export Leave Data
User Story: As an HR admin, I want to export approved leave data so that it can be shared with payroll and compliance teams.
Acceptance Criteria:
Scenario: Generate leave export
  Given approved leave records
  When I request an export
  Then a file is generated with all relevant leave details
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Reporting
