Title: Retrieve Employee Records

User Story: As an HR manager I want to retrieve employee records with filtering and pagination So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Employee data retrieval
Given there are multiple employee records in the system
When I send a GET request to /employees with filter and pagination parameters
Then I receive a paginated list of employees matching the filter criteria

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain and CRUD APIs
- Notes: Filtering by department, role, and status must be supported.
