Title: Enforce Unique badgeId for Employee Records

User Story: As an HR administrator I want the system to enforce unique badgeId values for each employee so that duplicate records are prevented and identity is maintained

Acceptance Criteria:
Scenario: Create employee with unique badgeId
  Given no other employee has the same badgeId
  When I create a new employee
  Then the employee is created successfully

Scenario: Create employee with duplicate badgeId
  Given an employee already exists with badgeId X
  When I attempt to create another employee with badgeId X
  Then the system rejects the request with a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Validation should apply to both create and update operations.
