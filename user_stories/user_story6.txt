Title: Update Employee Record via API

User Story: As an HR manager I want to update employee details using an API So that employee information remains current and accurate

Acceptance Criteria:
Scenario: Employee update
Given an existing employee record
When I submit a PUT or PATCH request to /employees/{id} with updated details
Then the employee record should reflect the changes

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API (E02)
- Notes: API must validate updates; badgeId cannot be changed; OpenAPI schema must include examples
