### E06 - Leave & Absence Management

#### User Story 1
Title: Request Leave
User Story: As a WORKER I want to request PTO, sick, or unpaid leave So that my time off is tracked.
Acceptance Criteria:
Scenario: Leave Request
Given WORKER is authenticated
When WORKER submits leave request
Then request is created and balances checked
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Accrual policies enforced.

#### User Story 2
Title: Approve/Deny Leave
User Story: As a SUPERVISOR I want to approve or deny leave requests So that staffing is maintained.
Acceptance Criteria:
Scenario: Leave Approval
Given SUPERVISOR is authenticated
When SUPERVISOR reviews request
Then status is updated and employee notified
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Scheduled shifts auto-flagged.

#### User Story 3
Title: Leave Balance Update
User Story: As an HR I want leave balances to update automatically So that records are accurate.
Acceptance Criteria:
Scenario: Balance Update
Given leave is approved
When leave is taken
Then balances reflect new totals
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Integration hooks for payroll.

#### User Story 4
Title: Export Approved Leaves
User Story: As an HR I want to export approved leaves So that compliance and payroll are supported.
Acceptance Criteria:
Scenario: Leave Export
Given approved leave data exists
When HR requests export
Then file includes all approved leaves
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Export format configurable.
