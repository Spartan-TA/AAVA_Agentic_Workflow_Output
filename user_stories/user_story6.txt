Title: Soft-Delete Employee Record via API

User Story: As an HR manager I want to soft-delete employee records via API So that terminated employees are excluded from active lists but historical data is retained

Acceptance Criteria:
Scenario: Successful soft-delete
  Given an existing employee record
  When I DELETE /employees/{id}
  Then the employee status is updated to 'inactive' and record is excluded from active queries

Scenario: Restore deleted employee
  Given a previously soft-deleted employee
  When I PATCH /employees/{id} to restore
  Then the employee status is set to 'active' and record is included in active queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story4.txt, user_story5.txt
- Notes: Soft-deleted records must be filterable in API responses.
