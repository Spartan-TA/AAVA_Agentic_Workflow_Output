Title: Employee Pagination and Filtering

User Story: As an HR manager I want to paginate and filter employee records So that I can efficiently browse and locate specific employees in large datasets

Acceptance Criteria:
Scenario: Paginate employee records
  Given I am viewing the employee list
  When I select a page number or page size
  Then I should see only the corresponding subset of employee records
Scenario: Filter employee records
  Given I am on the employee list page
  When I apply filters (e.g., department, status)
  Then only matching employee records should be displayed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee list API
- Notes: Support for multiple filter criteria and sorting
