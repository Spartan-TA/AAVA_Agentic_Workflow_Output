Title: Role Based Access Control - Endpoint Security

User Story: As an admin, I want to restrict access to sensitive endpoints based on user roles so that only authorized users can perform critical actions.

Acceptance Criteria:
Scenario: Unauthorized Access
Given a user without proper role
When they access a protected endpoint
Then the response is 401 Unauthorized

Scenario: Forbidden Action
Given a user with insufficient permissions
When they attempt a restricted action
Then the response is 403 Forbidden

Scenario: Admin Access
Given an ADMIN user
When they access any endpoint
Then access is granted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Security rules covered by tests
