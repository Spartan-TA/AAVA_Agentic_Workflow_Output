### E06: Leave & Absence Management

#### 1. Request Leave
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my absences are tracked.
Acceptance Criteria:
Scenario: Submit leave request
Given I am logged in
When I submit a leave request
Then it is recorded and pending approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Validate against accrual balances.

#### 2. Approve or Deny Leave Requests
User Story: As a supervisor I want to approve or deny leave requests So that staffing is managed.
Acceptance Criteria:
Scenario: Approve leave
Given a pending leave request
When I approve or deny it
Then the employee is notified and balances are updated
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave requests, RBAC
- Notes: Track approval history.

#### 3. Update Accrual Balances
User Story: As a system I want to update leave accrual balances automatically So that balances are accurate.
Acceptance Criteria:
Scenario: Accrual update
Given a leave is approved
When the leave period starts
Then the employee's balance is reduced accordingly
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave approval
- Notes: Support different accrual policies.

#### 4. Flag Scheduled Shifts for Coverage
User Story: As a scheduler I want scheduled shifts auto-flagged for coverage when leave is approved So that coverage gaps are visible.
Acceptance Criteria:
Scenario: Shift flagged for coverage
Given an approved leave overlaps a scheduled shift
When the leave is approved
Then the shift is flagged for coverage
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Shift management, Leave approval
- Notes: Notify supervisors.

#### 5. Export Approved Leaves
User Story: As a payroll admin I want to export approved leave data So that payroll is accurate.
Acceptance Criteria:
Scenario: Export leave data
Given approved leave records exist
When I export leave data
Then the file includes all relevant leave details
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Leave data
- Notes: Support CSV export.
