Title: Enforce Unique badgeId for Employees

User Story: As a system administrator I want to ensure each employee has a unique badgeId so that duplicate records are prevented and data integrity is maintained.

Acceptance Criteria:
Scenario: Unique badgeId enforcement
  Given an employee record exists with a badgeId
  When I attempt to create or update another employee with the same badgeId
  Then the system rejects the request with a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Validation should occur at both API and database levels.
