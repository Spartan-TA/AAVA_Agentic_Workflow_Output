Epic E14: Audit Trail & Compliance

---

User Story 1: Centralized Audit Logging
As compliance, I want centralized audit logging for sensitive changes so that all actions are traceable.

Acceptance Criteria:
Scenario: Audit entry creation
  Given a sensitive change
  When it occurs
  Then an audit entry is created with actor, timestamp, before/after

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03
- Notes: Log table is immutable

---

User Story 2: Tamper-Evident Storage

Acceptance Criteria:
Scenario: Tamper detection

  Then tampering is detectable

Additional Details:
- Priority: High
- Story Points: 3
