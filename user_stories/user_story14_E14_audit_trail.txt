[E14] Audit Trail & Compliance

Title: Log Sensitive Changes with Actor and Timestamp
User Story: As a compliance officer I want all sensitive changes logged with actor and timestamp so that actions are traceable.
Acceptance Criteria:
Scenario: Sensitive Change Logging
Given a create/update/delete action
When the action is performed
Then an audit log entry is created with actor and timestamp

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03
- Notes: Cover employee PII, schedules, approvals, payroll

---

Title: Store Audit Logs in Immutable Table
User Story: As a compliance officer I want audit logs stored in an immutable table so that records cannot be tampered with.
Acceptance Criteria:
Scenario: Immutable Audit Log Storage
Given audit log entries
When I attempt to modify or delete logs
Then the system prevents changes

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Log Sensitive Changes
- Notes: Use append-only storage

User Story: As a compliance officer I want to export audit logs by date, user, or entity so that investigations are efficient.

- Priority: High
