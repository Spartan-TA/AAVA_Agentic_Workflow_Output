# Epic E14: Audit Trail & Compliance

## User Story 1: Centralized Audit Logging
**Title:** Centralized Audit Logging for Sensitive Changes  
**Narrative:** As a compliance officer, I want all sensitive changes logged so that forensic analysis is possible.  
**Acceptance Criteria (Gherkin):**
```
Given a sensitive create/update/delete
When the action occurs
Then an audit log entry is created with actor, timestamp, before/after
```
**Priority:** High  
**Story Points:** 3  
**Dependencies:** E03  
**Notes:** Cover employee PII, schedules, approvals, payroll.

---

## User Story 2: Tamper-Evident Storage for Audit Logs
**Title:** Tamper-Evident Storage for Audit Logs  
**Narrative:** As a compliance officer, I want audit logs stored in a tamper-evident manner so that integrity is maintained.  
**Acceptance Criteria (Gherkin):**
```
Given audit log entries
When I inspect the storage
Then logs are immutable and tamper-evident
```
**Priority:** High  
**Story Points:** 2  
**Dependencies:** E14  
**Notes:** Use append-only tables.

---

## User Story 3: Export Audit Logs by Date/User/Entity
**Title:** Export Audit Logs  
**Narrative:** As an auditor, I want to export audit logs by date, user, or entity so that investigations are efficient.  
**Acceptance Criteria (Gherkin):**
```
Given audit log data
When I request an export
Then logs are filtered and exported as requested
```
**Priority:** High  
**Story Points:** 2  
**Dependencies:** E14  
**Notes:** Support CSV/PDF formats.

## User Story 4: Automated Tests for Audit Coverage
**Title:** Automated Tests for Audit Coverage
