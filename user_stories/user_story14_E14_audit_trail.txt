**E14: Audit Trail & Compliance**

1. Title: Log Sensitive Changes
User Story: As a compliance officer, I want all sensitive changes to be logged with actor, timestamp, and before/after values so that audits are possible.
Acceptance Criteria:
Scenario: Change Logging
Given a create/update/delete
When the action occurs
Then an immutable log entry is created
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Tamper-evident storage.

2. Title: Export Audit Logs
User Story: As an auditor, I want to export audit logs by date, user, or entity so that investigations are efficient.
Acceptance Criteria:
Scenario: Log Export
Given audit log data
When I request an export
Then a file is generated with selected filters
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Support CSV/PDF.

3. Title: Validate Audit Coverage
User Story: As a QA engineer, I want tests to validate audit coverage so that all sensitive actions are logged.
Acceptance Criteria:
Scenario: Coverage Test
Given test cases
When I perform sensitive actions
Then audit logs are created for each
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Automate in CI.
