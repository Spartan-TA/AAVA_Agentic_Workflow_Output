Title: Configure Database Migration Tool

User Story: As a developer I want to add Flyway or Liquibase for database migrations so that schema changes are versioned, repeatable, and auditable.

Acceptance Criteria:

Scenario: Baseline migration executes successfully
Given the migration tool is configured in the project
When I start the application for the first time
Then the baseline migration script should execute
And the schema_version table should be created
And the baseline version should be recorded

Scenario: New migration applies correctly
Given a new migration script is added to the migrations folder
When I restart the application
Then the new migration should be detected
And it should apply without errors
And the schema_version table should reflect the new version

Scenario: Migration validation on build
Given migration scripts exist
When I run the Maven build
Then all migrations should be validated for syntax
And any conflicts should be reported

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding (E01)
- Notes: Choose either Flyway or Liquibase as the standard. Flyway is recommended for simplicity. Ensure migrations are idempotent.
