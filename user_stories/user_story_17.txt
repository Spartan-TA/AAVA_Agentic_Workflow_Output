Title: Request Leave

User Story: As an employee I want to request leave so that my time off is tracked and approved

Acceptance Criteria:
Scenario: Submit leave request
Given I have available leave balance
When I fill out and submit a leave request
Then my manager should be notified for approval

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Leave management module, Notification module
- Notes: Display leave balance and request status.
