Title: Audit Role Changes

User Story: As an admin I want to audit role changes So that I can track permission updates and ensure compliance

Acceptance Criteria:
Scenario: Role change auditing
Given a role is modified
When changes are saved
Then an audit log entry should be created with details of the change and the user who made it

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Role assignment and editing
- Notes: Display audit logs in the admin dashboard
