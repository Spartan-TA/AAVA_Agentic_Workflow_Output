Title: Implement Attendance Corrections Workflow

User Story: As a supervisor I want to review and approve attendance corrections so that missed punches and errors can be corrected accurately.

Acceptance Criteria:

Scenario: Employee requests correction
Given an employee missed a clock-in or clock-out
When they submit a correction request with reason and proposed time
Then a correction task should be created
And the task should be assigned to their supervisor
And the employee should receive confirmation

Scenario: Supervisor reviews correction
Given a correction request is pending
When the supervisor views the request
Then they should see the original attendance record
And they should see the proposed correction
And they should see the employee's reason

Scenario: Supervisor approves correction
Given a correction request is under review
When the supervisor approves it
Then the attendance record should be updated
And the correction should be logged in audit trail
And the employee should be notified

Scenario: Supervisor rejects correction
Given a correction request is under review
When the supervisor rejects it with a reason
Then the original record should remain unchanged
And the employee should be notified with rejection reason

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Clock-in/out endpoints (E04), RBAC (E03)
- Notes: Implement approval workflow. Maintain audit trail of all corrections. Support bulk corrections for system issues.
