Title: Supervisor Approval for Attendance Corrections

User Story: As a supervisor I want to review and approve or deny attendance correction requests So that only valid corrections are applied to employee records

Acceptance Criteria:
Scenario: Approving a correction request
Given a correction request is pending
When I review and approve the request
Then the attendance record is updated and the employee is notified

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: All approvals/denials must be logged for audit purposes.
