Title: Request Leave

User Story: As an employee I want to request leave So that I can manage my time off and ensure proper approval

Acceptance Criteria:
Scenario: Submit leave request
Given I am logged into the EMS
When I submit a leave request with dates and reason
Then the request should be routed to my supervisor for approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave management module
- Notes: Support for multiple leave types.
