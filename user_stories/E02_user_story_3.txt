Title: Support Soft-Delete for Employees

User Story: As an HR user, I want to soft-delete employee records So that historical data is preserved.

Acceptance Criteria:
Scenario: Soft-delete employee
Given an employee record
When I delete the employee
Then the record is marked as inactive, not removed from the database

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Soft-delete status visible in API
