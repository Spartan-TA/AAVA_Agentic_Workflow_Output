Title: Responsive Mobile Views for Core Flows

User Story: As a worker I want to clock-in/out, view schedules, request leave, and see announcements on my mobile device so that I can manage my work from anywhere

Acceptance Criteria:
Scenario: Using core flows on mobile
Given I access the application on my phone
When I navigate to clock-in, schedule, leave, or announcements
Then the views are responsive and fully functional

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Mobile UI, PWA framework
- Notes: Must support major browsers and Android/iOS
