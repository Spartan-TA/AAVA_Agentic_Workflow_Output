Title: Support Multiple Warehouses and Policies

User Story: As an administrator I want to manage multiple warehouses with distinct calendars, policies, and shift templates so that each location operates according to its local requirements

Acceptance Criteria:
Scenario: Configure warehouse-specific policies
  Given I am managing multiple warehouses
  When I set up calendars, policies, and shift templates for each
  Then the system enforces the correct rules per warehouse

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01 (Core), E02 (User Management), E05 (Attendance)
- Notes: Policies must be scoped by warehouse entity
