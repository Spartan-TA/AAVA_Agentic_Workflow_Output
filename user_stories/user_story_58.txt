Title: Implement Structured Logging and Distributed Tracing

User Story: As a DevOps engineer I want all system logs to be structured (JSON) and support distributed tracing so that I can efficiently monitor and troubleshoot issues across services.

Acceptance Criteria:
Scenario: Logging and tracing a request
Given a user action triggers multiple services
When the action is processed
Then all logs should include trace IDs and be stored in a structured format for analysis

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Use OpenTelemetry for tracing and ensure logs are queryable.
