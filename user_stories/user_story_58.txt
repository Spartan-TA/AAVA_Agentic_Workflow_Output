Title: Structured Logging and Distributed Tracing

User Story: As a DevOps engineer I want all logs to be structured (JSON) and include trace IDs for distributed tracing so that I can efficiently monitor and troubleshoot the system

Acceptance Criteria:
Scenario: Structured logs with trace IDs
  Given a request is processed by the system
  When logs are generated
  Then each log entry is in JSON format and includes a traceId for end-to-end tracing

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Integrate with OpenTelemetry for tracing; logs must be queryable and exportable.
