Title: Operational Reports with Filtering

User Story: As a supervisor I want to generate attendance, overtime, and leave reports filtered by date, department, and shift so that I can monitor workforce metrics

Acceptance Criteria:
Scenario: Generating filtered reports
Given I select a report type and filters
When I run the report
Then I see the relevant data displayed and summarized

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Reporting module, data warehouse
- Notes: Filters must support multi-select and date ranges
