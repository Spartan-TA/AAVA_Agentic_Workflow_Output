Title: PWA Installability and Lighthouse Score

User Story: As a mobile user I want the EMS PWA to be installable and meet Lighthouse PWA standards so that I have a reliable, app-like experience

Acceptance Criteria:
Scenario: Install PWA and measure Lighthouse score
  Given the PWA manifest is configured
  When I install the app and run Lighthouse
  Then the app is installable and achieves a high Lighthouse PWA score

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04 (Attendance), E05 (Scheduling), E06 (Leave), E12 (Notifications)
- Notes: Must support offline mode and push notifications
