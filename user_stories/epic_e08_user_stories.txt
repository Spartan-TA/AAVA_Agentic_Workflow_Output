EPIC E08: Safety Incidents & OSHA Reporting

===========================================

Title: Safety Incidents & OSHA Reporting

User Story: As a safety officer I want to record safety incidents and near-misses So that regulatory reporting is accurate

Acceptance Criteria:
Scenario: Incident recording
Given an incident occurs
When I submit details
Then the record is stored and workflow initiated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC
- Notes: Severity, location, involved employees

---

Title: OSHA Summary Export

User Story: As a compliance manager I want to export OSHA 300/300A summaries So that I can submit regulatory reports

Acceptance Criteria:
Scenario: OSHA export
Given incident data exists
When I request export
Then the summary file is generated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Safety incidents
- Notes: Metrics dashboard available
