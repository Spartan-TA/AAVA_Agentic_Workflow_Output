EPIC E08 - Safety Incidents & OSHA Reporting

===========================================

User Story 1
------------
Title: Record Safety Incident

User Story: As a supervisor, I want to record safety incidents with severity, location, and involved employees so that risks are tracked.

Acceptance Criteria:
Scenario: Record incident with validation
  Given incident data
  When I POST to /safety/incidents
  Then the incident is validated and recorded

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Supports OSHA compliance.

===========================================

User Story 2
------------
Title: Incident Investigation Workflow

User Story: As a safety officer, I want a workflow for investigating and resolving incidents so that corrective actions are documented.

Acceptance Criteria:
Scenario: Investigation status changes
  Given an open incident
  When investigation starts
  Then status changes to Investigating

Scenario: Incident resolved
  Given investigation is complete
  When corrective actions are taken
  Then status changes to Resolved

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Tracks lifecycle.

===========================================

User Story 3
------------
Title: OSHA Summary Export

User Story: As a compliance officer, I want to export OSHA 300/300A summary fields so that regulatory reporting is simplified.

Acceptance Criteria:
Scenario: Export OSHA summary
  Given incident data
  When I request an export
  Then a file is generated with required OSHA fields

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Regulatory requirement.
