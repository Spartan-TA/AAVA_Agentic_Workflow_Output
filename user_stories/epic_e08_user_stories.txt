EPIC E08 - SAFETY INCIDENTS & OSHA REPORTING

===========================================

Title: Record Safety Incident or Near-Miss

User Story: As a supervisor I want to record details of a safety incident or near-miss so that the event is documented for investigation and compliance

Acceptance Criteria:
Scenario: Incident recording
Given I witnessed or was informed of an incident
When I submit an incident report with required fields
Then the incident is logged and assigned a status of "Open"

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Required fields: severity, location, description, involved employees

---

Title: Manage Incident Investigation Workflow

User Story: As a safety officer I want to update the status and add investigation notes to incidents so that corrective actions are tracked

Acceptance Criteria:
Scenario: Incident investigation
Given an incident is under investigation
When I update the status and add notes
Then the incident status changes and all updates are logged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Statuses: Open, Investigating, Resolved

---

Title: Generate OSHA Summary Reports

User Story: As an admin I want to generate OSHA 300/300A summary reports so that regulatory reporting requirements are met

Acceptance Criteria:
Scenario: OSHA report generation
Given incidents are recorded in the system
When I request an OSHA summary
Then the report is generated with required fields and available for export

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Export formats: CSV, PDF

---

Title: Dashboard for Safety KPIs

User Story: As a manager I want to view a dashboard of safety KPIs so that I can monitor trends and take proactive action

Acceptance Criteria:
Scenario: Safety KPI dashboard
Given I have access to safety data
When I open the dashboard
Then I see metrics such as incident frequency, severity, and resolution times

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Role-based access to dashboard
