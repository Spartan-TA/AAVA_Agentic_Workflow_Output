Title: Leave Request Workflow

User Story: As a WORKER I want to request PTO, sick, or unpaid leave So that my time off is tracked and approved

Acceptance Criteria:
Scenario: Submit leave request
Given I am eligible for leave
When I submit a request
Then my supervisor receives an approval task

Scenario: Leave approval
Given a pending leave request
When the supervisor approves
Then my leave balance is updated

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee CRUD, RBAC, Shift management
- Notes: Scheduled shifts auto-flagged for coverage

Title: Leave Balance Management

User Story: As an HR I want to manage and update leave accrual balances So that policies are enforced

Acceptance Criteria:
Scenario: Balance update
Given a leave is approved
When I update the employee's balance
Then the new balance reflects the approved leave

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave request workflow
- Notes: Exportable for payroll
