Title: Document Build and Run Steps in README

User Story: As a Developer I want clear build and run instructions in the README So that new team members can quickly set up and contribute to the project

Acceptance Criteria:
Scenario: README includes setup steps
Given the project repository is initialized
When I open the README file
Then I see step-by-step instructions for building and running the application

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: README should include environment variables, migration steps, and troubleshooting tips.
