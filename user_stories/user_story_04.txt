Title: Provide Comprehensive README Documentation

User Story: As a new developer I want a comprehensive README with build and run instructions so that I can quickly set up the project locally without assistance.

Acceptance Criteria:

Scenario: README contains build instructions
Given I open the README file in the repository
When I read the build section
Then I should see step-by-step Maven build commands
And I should see prerequisites (Java version, Maven version)
And I should see how to run tests

Scenario: README contains run instructions
Given I have built the project
When I follow the run instructions in README
Then I should be able to start the application
And I should see the expected startup logs
And I should be able to access the application on port 8080

Scenario: Troubleshooting section exists
Given I encounter a common build or runtime error
When I consult the troubleshooting section
Then I should find the error listed
And I should find a solution or workaround

Scenario: Environment setup documented
Given I need to configure the application
When I read the environment setup section
Then I should see all required environment variables
And I should see database configuration instructions
And I should see how to configure different profiles (dev, test, prod)

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding (E01)
- Notes: Keep README up to date with every release. Include links to additional documentation. Add badges for build status and code coverage.
