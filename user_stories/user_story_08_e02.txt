Title: List and Filter Employees

User Story: As an HR manager I want to list and filter employees So that I can quickly find and manage employee records based on criteria

Acceptance Criteria:
Scenario: Filter employees by department
Given a list of employees
When I select a department filter
Then only employees from that department are shown in the list

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee domain module, UI filter controls
- Notes: Support filtering by department, status, and role.
