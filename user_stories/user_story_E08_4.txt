Title: Safety Metrics Dashboard

User Story: As a Safety Officer I want to view a dashboard of safety metrics including incident rates, severity, and corrective action status so that I can monitor trends and improve workplace safety

Acceptance Criteria:
Scenario: View dashboard metrics
Given incidents and investigations are recorded
When I access the safety dashboard
Then I see charts for incident rates, severity breakdown, and open corrective actions

Scenario: Filter dashboard by date and location
Given multiple incidents across locations
When I filter the dashboard by date range or location
Then metrics update to reflect the selected criteria

Scenario: Export dashboard data
Given I am viewing the safety dashboard
When I export the data
Then I receive a CSV or PDF file of the current metrics

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data (E02), RBAC (E03)
- Notes: Dashboard should support role-based access
