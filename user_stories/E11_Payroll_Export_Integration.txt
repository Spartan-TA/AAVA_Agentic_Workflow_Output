EPIC E11: Payroll Export Integration

---

Title: Payroll Export - Generate Payroll File
User Story: As a Payroll Admin I want to generate payroll-ready files from attendance and leave So that payroll processing is automated.
Acceptance Criteria:
Scenario: Generate payroll file
Given approved attendance and leave data
When I generate payroll export
Then the file matches provider schema and totals reconcile
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: Export format configurable

---

Title: Payroll Export - Secure Delivery
User Story: As a System I want to deliver payroll files securely via SFTP or API So that sensitive data is protected.
Acceptance Criteria:
Scenario: Secure payroll delivery
Given a payroll file is generated
When I deliver the file
Then it is sent via SFTP or API with confirmation
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Delivery failures retried with backoff

---

Title: Payroll Export - Export Audit Log
User Story: As an ADMIN I want to audit all payroll exports So that compliance is ensured.
Acceptance Criteria:
Scenario: Audit payroll exports
Given payroll exports occur
When I view the audit log
Then I see all export events with status and user
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Log exportable by date/user
