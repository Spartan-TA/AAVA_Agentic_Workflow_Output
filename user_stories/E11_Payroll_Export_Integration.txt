### E11: Payroll Export Integration

#### 1. Title: Generate Payroll Export Files
User Story: As a payroll admin I want to generate payroll-ready files from attendance and leave So that payroll processing is automated
Acceptance Criteria:
Scenario: Generate export
Given approved attendance and leave
When I export payroll
Then a file is generated matching provider schema

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Support multiple formats

---

#### 2. Title: Secure Delivery of Payroll Files
User Story: As a payroll admin I want payroll files delivered securely via SFTP or API So that sensitive data is protected
Acceptance Criteria:
Scenario: SFTP delivery
Given an export file
When I send via SFTP
Then the file is delivered securely and receipt is logged

Scenario: API delivery
Given an export file
When I send via API
Then the file is delivered securely

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Log all deliveries

---

#### 3. Title: Reconcile Payroll Totals with Reports
User Story: As a payroll admin I want to reconcile payroll exports with attendance and leave reports So that errors are detected
Acceptance Criteria:
Scenario: Totals match
Given exported data
When I compare with reports
Then totals for hours and pay match exactly

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Highlight discrepancies

---

#### 4. Title: Retry Failed Payroll Deliveries
User Story: As a system I want to retry failed payroll file deliveries with backoff So that files are not lost
Acceptance Criteria:
Scenario: Delivery fails
Given a delivery attempt fails
When the system retries
Then it uses exponential backoff and logs attempts

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Notify admin on repeated failures

---

#### 5. Title: Audit Log for Payroll Exports
User Story: As a compliance officer I want an audit log for every payroll export So that all actions are traceable
Acceptance Criteria:
Scenario: Log export
Given a payroll export occurs
When the file is generated or delivered
Then an audit entry is created with actor, timestamp, and status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Immutable log
