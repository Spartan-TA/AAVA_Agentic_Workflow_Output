# Epic E06: Leave & Absence Management

## User Story 1: Request Leave
- **Title:** Employee Leave Request
- **User Story:** As a worker, I want to request PTO, sick, or unpaid leave so that my time off is tracked.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a worker is authenticated
  When they submit a leave request
  Then the request is created and pending approval
  ```
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Validate accrual balances.

## User Story 2: Approve/Deny Leave
- **Title:** Supervisor Leave Approval
- **User Story:** As a supervisor, I want to approve or deny leave requests so that staffing plans are maintained.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a pending leave request
  When supervisor approves or denies
  Then the request status is updated
  And balances are adjusted
  ```
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Notify employee.

## User Story 3: Accrual Balance Management
- **Title:** Leave Accrual Balance Updates
- **User Story:** As an HR user, I want leave balances to update automatically so that policies are enforced.
- **Acceptance Criteria (Gherkin):**
  ```
  Given an approved leave
  When leave is taken
  Then accrual balances are reduced accordingly
  ```
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Policy-driven.

## User Story 4: Exclude Leave from Scheduling
- **Title:** Scheduling Integration for Leave
- **User Story:** As a system, I want approved leaves to flag scheduled shifts for coverage so that no-shows are avoided.
- **Acceptance Criteria (Gherkin):**
  ```
  Given an approved leave overlaps a scheduled shift
  When the schedule is generated
  Then the shift is flagged for coverage
  ```
- **Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Export approved leaves.
