Epic E06: Leave & Absence Management

---

User Story 6.1: Request Leave (PTO, Sick, Unpaid)

Title: Request Leave (PTO, Sick, Unpaid)

User Story: As an employee, I want to request different types of leave so that my absences are tracked.

Acceptance Criteria:

Scenario: Leave request recorded
Given the leave request form
When I submit a request
Then it is recorded with type and dates

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Core leave.

---

User Story 6.2: Approve or Deny Leave Requests

Title: Approve or Deny Leave Requests

User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.

Acceptance Criteria:

Scenario: Leave approval/denial processed
Given a pending request
When I approve/deny
Then the employee is notified and balances update

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E06.1
- Notes: Approval workflow.

User Story 6.3: Update Leave Balances and Policies

Title: Update Leave Balances and Policies

User Story: As an HR user, I want leave balances and accrual policies to update automatically so that records are accurate.

Acceptance Criteria:

Scenario: Leave balance updated after approval
Given an approved leave
When it is processed
Then the employee's leave balance is updated

Scenario: Accrual follows policy
Given a new policy
When it is applied
Then accruals follow the policy

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E06.2
- Notes: Accurate balances.

User Story 6.4: Exclude Approved Leave from Scheduling and Payroll

Title: Exclude Approved Leave from Scheduling and Payroll

User Story: As a scheduler, I want approved leaves to auto-flag scheduled shifts for coverage so that staffing gaps are filled.

Acceptance Criteria:

Scenario: Shift flagged for coverage
Given an approved leave
When a shift overlaps
Then the shift is flagged for coverage

Scenario: Hours excluded from payroll
Given payroll export
When leave is present
Then hours are excluded as per policy

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E06.2
- Notes: Integration.
