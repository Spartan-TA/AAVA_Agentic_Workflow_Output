EPIC E06: Leave & Absence Management

Title: Request Leave
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my time off is tracked
Acceptance Criteria:
Scenario: Leave request
Given I have leave balance
When I submit a request
Then my supervisor is notified for approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Accrual policies enforced

---

Title: Approve/Deny Leave
User Story: As a supervisor I want to approve or deny leave requests So that staffing plans remain accurate
Acceptance Criteria:
Scenario: Leave approval
Given a leave request is pending
When I approve or deny
Then the employee's balance updates and schedule is flagged
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Auto-flag scheduled shifts

---

Title: Export Approved Leaves
User Story: As a payroll admin I want to export approved leaves So that payroll hours are calculated correctly
Acceptance Criteria:
Scenario: Leave export
Given approved leaves exist
When I export data
Then the file includes all approved leaves
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E05
- Notes: Format for payroll integration
