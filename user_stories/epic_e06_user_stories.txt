### EPIC E06 - Leave & Absence Management

#### User Story 1
Title: Request Leave (PTO, Sick, Unpaid)

User Story: As an employee I want to request different types of leave So that my absences are tracked

Acceptance Criteria:
Scenario: Leave request submission
Given I am logged in
When I submit a leave request
Then the request is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Validate leave type and dates

---

#### User Story 2
Title: Approve or Deny Leave Requests

User Story: As a supervisor I want to approve or deny leave requests So that team coverage is maintained

Acceptance Criteria:
Scenario: Leave approval workflow
Given a pending leave request
When I approve or deny the request
Then the employee is notified and balances are updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1
- Notes: Approval required for all leave types

---

#### User Story 3
Title: Update Leave Accrual Balances

User Story: As an HR user I want leave balances to update automatically So that accrual policies are enforced

Acceptance Criteria:
Scenario: Leave balance update
Given an approved leave
When the leave period starts
Then the employee's leave balance is reduced accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: User Story 2
- Notes: Support monthly and annual accrual

---

#### User Story 4
Title: Exclude Approved Leave from Scheduling and Payroll

User Story: As a payroll admin I want approved leaves to be excluded from scheduling and payroll hours So that pay is accurate

Acceptance Criteria:
Scenario: Leave exclusion integration
Given an approved leave
When payroll and scheduling are processed
Then the leave period is excluded from shift assignments and payroll calculations

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: User Story 2, E11
- Notes: Integration hooks for external systems

---

#### User Story 5
Title: Export Approved Leaves for Reporting

User Story: As an HR user I want to export approved leave records So that I can analyze absence trends

Acceptance Criteria:
Scenario: Leave export
Given approved leave data
When I request an export
Then a file is generated with all relevant leave details

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 2
- Notes: Support CSV and PDF formats
