### Epic E06: Leave & Absence Management

**User Story 1**
Title: Request Leave
User Story: As an employee I want to request PTO, sick, or unpaid leave So that my time off is tracked
Acceptance Criteria:
Scenario: Leave request
Given I am authenticated
When I submit a leave request
Then the request is recorded and pending approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Leave types and accrual policies enforced

**User Story 2**
Title: Approve or Deny Leave Requests
User Story: As a supervisor I want to approve or deny leave requests So that staffing is managed
Acceptance Criteria:
Scenario: Leave approval
Given a pending leave request
When I approve or deny it
Then the employee is notified and balances are updated
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Approval workflow must be auditable

**User Story 3**
Title: Exclude Approved Leaves from Scheduling
User Story: As a scheduler I want approved leaves to automatically flag scheduled shifts for coverage So that shifts are not left uncovered
Acceptance Criteria:
Scenario: Shift coverage flag
Given an approved leave overlaps a scheduled shift
When I view the schedule
Then the shift is flagged for coverage
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Integration hooks for scheduling and payroll

**User Story 4**
Title: Export Leave Balances and History
User Story: As an HR user I want to export leave balances and history So that I can report on time off
Acceptance Criteria:
Scenario: Leave export
Given leave data exists
When I export the report
Then approved leaves and balances are included
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Export format matches payroll requirements
