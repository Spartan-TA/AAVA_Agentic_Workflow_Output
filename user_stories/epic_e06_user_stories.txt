### Epic E06: Leave & Absence Management

**User Story 1: Request Leave (PTO, Sick, Unpaid)**
User Story: As an employee I want to request PTO, sick, or unpaid leave so that my absences are tracked.
Acceptance Criteria:
Scenario: Leave request submission
Given available leave balance
When I submit a leave request
Then the request is created and pending approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Validate accruals

**User Story 2: Supervisor Approves or Denies Leave**
User Story: As a supervisor I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria:
Scenario: Leave approval workflow
Given a pending leave request
When I approve or deny
Then the request status updates and employee is notified
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E06
- Notes: Notification integration

**User Story 3: Update Leave Balances and Policies**
User Story: As an HR user I want leave balances to update according to policies so that records are accurate.
Acceptance Criteria:
Scenario: Balance update
Given an approved leave
When the leave period starts
Then the employee's balance is reduced accordingly
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E06
- Notes: Support multiple leave types

**User Story 4: Exclude Approved Leaves from Scheduling and Payroll**
User Story: As a payroll admin I want approved leaves to be excluded from scheduling and payroll calculations so that payroll is accurate.
Acceptance Criteria:
Scenario: Leave exclusion
Given an approved leave
When payroll is calculated
Then leave hours are excluded from regular hours
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E06, E11
- Notes: Integration hooks required

**User Story 5: Export Approved Leaves**
User Story: As an HR user I want to export approved leaves so that I can share records with management.
Acceptance Criteria:
Scenario: Leave export
Given approved leave records
When I request an export
Then a CSV file is generated with all relevant details
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E06
- Notes: Support date range filtering
