Title: Configure Base Packages

User Story: As a developer I want to configure base packages for Spring Boot So that application components are auto-discovered and loaded efficiently

Acceptance Criteria:
Scenario: Base package configuration
Given a new Spring Boot project
When I specify the base packages in the application configuration
Then all annotated components within those packages should be auto-discovered and loaded at startup

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot framework
- Notes: Ensure configuration supports modular package structure.
