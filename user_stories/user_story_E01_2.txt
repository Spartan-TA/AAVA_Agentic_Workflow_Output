Title: Configure Database Migrations with Flyway/Liquibase

User Story: As a developer I want to set up Flyway or Liquibase for database migrations so that the database schema can be versioned and consistently applied across environments.

Acceptance Criteria:
Scenario: Baseline migration setup
  Given the project is built and running
  When I start the application
  Then Flyway or Liquibase should execute baseline migration scripts and initialize the database schema

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story_E01_1
- Notes: Migration scripts must be idempotent and support rollback; document migration process in README.
