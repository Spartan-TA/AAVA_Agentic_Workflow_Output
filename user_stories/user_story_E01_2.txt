Title: Set Up Database Migration Tool

User Story: As a System Administrator I want to configure Flyway or Liquibase for database migrations so that schema changes are versioned and reliably applied across environments.

Acceptance Criteria:
Scenario: Baseline migration runs
Given the migration tool is configured
When I start the application
Then the baseline migration should execute and the database schema should be initialized

Scenario: Migration history tracking
Given multiple migrations are applied
When I query the migration history
Then I should see all applied migrations with timestamps and status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Choose either Flyway or Liquibase based on team preference and document setup in README.
