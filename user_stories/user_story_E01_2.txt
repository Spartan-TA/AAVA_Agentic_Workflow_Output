Title: Set Up Database Migration with Flyway/Liquibase

User Story: As a developer I want to configure Flyway or Liquibase for database migrations so that the database schema is versioned and consistent across environments

Acceptance Criteria:
Scenario: Baseline migration runs automatically
  Given a new or empty database
  When I start the application
  Then the baseline migration should execute and the schema should be initialized

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Migration scripts must be idempotent and support rollback
