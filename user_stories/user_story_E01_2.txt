Title: Set Up Database Migration with Flyway/Liquibase

User Story: As a developer I want to configure Flyway or Liquibase for database migrations so that schema changes are versioned and applied consistently across environments.

Acceptance Criteria:
Scenario: Baseline migration runs successfully
  Given the application starts with a fresh database
  When Flyway/Liquibase runs
  Then the baseline migration should be applied and the database schema should match the initial requirements

Scenario: Migration history tracking
  Given multiple migrations have been applied
  When I query the migration history
  Then I should see all applied migrations with timestamps and status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Migration scripts must be included; baseline migration must run on first startup; documentation for adding new migrations required.
