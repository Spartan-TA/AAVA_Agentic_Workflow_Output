Title: PDF Export and Role-Based Visibility of Reviews
User Story: As an HR manager I want to export performance reviews as PDF and control visibility by role so that documentation is secure and accessible to authorized users
Acceptance Criteria:
Scenario: Export review as PDF
Given a review is finalized
When I request export
Then a PDF is generated with all review details
Scenario: Control review visibility
Given reviews exist
When users access the review dashboard
Then they only see reviews for employees they supervise or manage
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: PDF export must match company branding
