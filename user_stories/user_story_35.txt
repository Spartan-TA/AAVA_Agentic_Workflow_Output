Title: OSHA 300/300A Report Generation

User Story: As a compliance manager I want to generate OSHA 300 and 300A reports from incident data So that regulatory requirements are met efficiently

Acceptance Criteria:
Scenario: Generating OSHA 300 report
Given incidents are recorded in the system
When I select the reporting period and generate the report
Then the OSHA 300 report should be produced in the required format

Scenario: Generating OSHA 300A summary
Given incidents are recorded in the system
When I select the reporting period and generate the summary
Then the OSHA 300A report should be produced and available for download

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Incident log, reporting module
- Notes: Reports must match OSHA formatting and support export to PDF/CSV.
