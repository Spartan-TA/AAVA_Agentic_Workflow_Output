Title: Block Asset Assignment for Invalid Certifications

User Story: As a scheduler I want the system to prevent asset assignment to employees lacking required certifications so that only qualified personnel operate equipment

Acceptance Criteria:
Scenario: Block assignment for invalid cert
  Given an employee does not have a valid certification for an asset
  When I attempt to assign the asset
  Then the system blocks the assignment and displays a warning

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E07 (Certifications), E02 (User Management)
- Notes: Applies to forklifts and other regulated assets
