### E04: Time & Attendance (Clock In/Out)

**User Story 1: Clock In/Out Endpoint**
User Story: As a worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift
When I POST to /attendance/clock-in
Then my clock-in event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate shift association.

**User Story 2: Geofence and Device Capture**
User Story: As a supervisor I want clock events to capture device and location So that I can verify attendance authenticity
Acceptance Criteria:
Scenario: Clock-in with geofence
Given I am within the warehouse geofence
When I clock in
Then my device ID and location are stored with the event
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Optional geofence.

**User Story 3: Handle Missed Punches and Corrections**
User Story: As a worker I want to request corrections for missed punches So that my hours are accurate
Acceptance Criteria:
Scenario: Correction request
Given I missed a clock-out
When I submit a correction
Then a supervisor approval task is created
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Approval workflow.

**User Story 4: Export Attendance Reports**
User Story: As a payroll admin I want to export attendance data So that I can process payroll
Acceptance Criteria:
Scenario: Export CSV
Given attendance data exists
When I request an export
Then a CSV file is generated with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Include corrections.
