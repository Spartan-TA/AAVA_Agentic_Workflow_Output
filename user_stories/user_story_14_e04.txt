Title: Missed Punch Correction

User Story: As an employee I want to request a correction for missed clock-ins or clock-outs So that my attendance record is accurate

Acceptance Criteria:
Scenario: Submit missed punch correction
Given I missed a clock-in or clock-out
When I submit a correction request with the correct time
Then my manager is notified and can approve or deny the correction

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance module, notification system
- Notes: Track all corrections for audit purposes.
