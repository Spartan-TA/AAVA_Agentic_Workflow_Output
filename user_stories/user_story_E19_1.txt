Title: Prometheus Metrics Integration

User Story: As a DevOps engineer I want the system to expose key operational metrics via Prometheus endpoints So that I can monitor warehouse application health and performance

Acceptance Criteria:
Scenario: Metrics endpoint
Given the application is running
When Prometheus scrapes the /metrics endpoint
Then all configured metrics are available and up-to-date

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Actuator, core modules
- Notes: Include metrics for API latency, error rates, job durations
