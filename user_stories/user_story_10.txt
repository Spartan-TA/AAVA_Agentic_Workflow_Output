Title: Support Employee Soft-Delete

User Story: As an HR manager I want employee records to be soft-deleted instead of permanently removed so that audit trails and historical data are preserved

Acceptance Criteria:
Scenario: Soft-delete operation
  Given an active employee record exists
  When I send a DELETE request to /employees/{id}
  Then the record should be marked as deleted but retained in the database

Scenario: Exclusion from active queries
  Given a record is soft-deleted
  When I list active employees
  Then the soft-deleted record should not appear

Scenario: Audit trail
  Given a record is soft-deleted
  When I review audit logs
  Then the deletion event should be logged with actor and timestamp

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Soft-deleted records should be recoverable by admin
