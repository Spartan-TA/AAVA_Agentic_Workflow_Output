Title: API Key/OAuth2 Security Toggle

User Story: As a system administrator I want to configure the authentication method between API Key and OAuth2 So that the system can adapt to different security requirements

Acceptance Criteria:
Scenario: Toggle authentication method
  Given I am authenticated as an ADMIN
  When I update the configuration to use API Key or OAuth2
  Then all endpoints enforce the selected authentication method

Scenario: Unauthorized access with wrong method
  Given the system is set to OAuth2
  When a request is made with only an API Key
  Then the request is rejected with a 401 Unauthorized response

Scenario: Configuration persistence
  Given the authentication method is changed
  When the system restarts
  Then the selected method remains active

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Configuration must be documented and testable.
