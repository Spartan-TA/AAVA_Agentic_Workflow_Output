Title: Missed Punches and Corrections Workflow
User Story: As a supervisor I want to handle missed punches and approve corrections So that attendance records remain accurate and auditable.
Acceptance Criteria:
Scenario: Missed punch detected
  Given a missing clock-in or clock-out
  When attendance is reviewed
  Then a correction task is created

Scenario: Correction approval
  Given a pending correction
  When a supervisor approves it
  Then the attendance record is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Correction workflow must be auditable.
