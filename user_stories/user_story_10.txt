Title: Define Roles and Permissions

User Story: As an ADMIN I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) to users so that access to system features is controlled by role

Acceptance Criteria:
Scenario: Assigning roles to users
Given I am an ADMIN
When I assign a role to a user
Then the user should have access only to features permitted by that role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Roles must be configurable and enforced across endpoints.
