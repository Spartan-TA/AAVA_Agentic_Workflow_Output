Title: Assign and Manage User Roles

User Story: As an admin I want to assign and update user roles (ADMIN, HR, SUPERVISOR, WORKER) So that access permissions are properly enforced across the system

Acceptance Criteria:
Scenario: Assign role to user
Given a user account
When I assign a role
Then the user receives the correct permissions for their role

Scenario: Update user role
Given an existing user
When I change their role
Then their access rights are updated immediately

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee CRUD
- Notes: Role changes must be auditable
