Title: Audit Role Changes

User Story: As a compliance officer I want to audit all role changes So that I can ensure proper access control and traceability

Acceptance Criteria:
Scenario: Audit log for role changes
Given a role is assigned or modified for any employee
When the change is saved
Then an audit log entry should be created with timestamp, user, and details

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Audit logging module
- Notes: Audit logs should be immutable and exportable.
