Title: Implement Role-Based Access Control (RBAC)

User Story: As an administrator I want to assign roles and permissions to users so that sensitive operations are restricted to authorized personnel

Acceptance Criteria:
Scenario: Assigning roles to users
Given a user exists in the system
When the administrator assigns a role (ADMIN, HR, SUPERVISOR, WORKER)
Then the user should have access only to the endpoints permitted by their role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee Master Data
- Notes: Must support method/endpoint security and row-level constraints.
