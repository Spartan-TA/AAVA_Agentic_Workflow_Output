Title: Provide REST APIs for HRIS/WMS Integration
User Story: As a system integrator I want REST APIs for HRIS and WMS So that data can be synchronized between systems
Acceptance Criteria:
Scenario: HRIS API
  Given employee data changes
  When the HRIS API is called
  Then the data is updated in both systems
Scenario: Webhook support
  Given an event occurs
  When a webhook is configured
  Then the external system is notified
Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project scaffolding, Employee CRUD, RBAC
- Notes: Support SSO integration
