### E11: Payroll Export Integration

**User Story 1**
Title: Generate Payroll Files
User Story: As a PAYROLL ADMIN I want to generate payroll-ready files from attendance and leave So that payroll runs are automated
Acceptance Criteria:
Scenario: Payroll export
Given approved attendance and leave
When I export payroll
Then the file matches provider schema
Additional Details:
Priority: High
Story Points: 2
Dependencies: E04, E06
Notes: Mapping configurable

**User Story 2**
Title: Secure Payroll Delivery
User Story: As a SYSTEM I want to deliver payroll files via SFTP or API So that data is securely transmitted
Acceptance Criteria:
Scenario: Secure delivery
Given a payroll file
When delivery is initiated
Then the file is sent securely and delivery status is logged
Additional Details:
Priority: High
Story Points: 2
Dependencies: E04, E06
Notes: Retries with backoff on failure

**User Story 3**
Title: Audit Payroll Exports
User Story: As an AUDITOR I want an audit log for every payroll export So that compliance is ensured
Acceptance Criteria:
Scenario: Audit log
Given a payroll export
When the export completes
Then an audit entry is created with timestamp and actor
Additional Details:
Priority: High
Story Points: 1
Dependencies: E04, E06
Notes: Log exportable
