Title: UI Localization for English and Spanish

User Story: As a warehouse employee I want to use the application in my preferred language (English or Spanish) so that I can understand and use all features effectively.

Acceptance Criteria:
Scenario: Changing UI language
Given I am on the language settings page
When I select English or Spanish
Then the system should display all UI elements in the selected language

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01, E02, E05
- Notes: All user-facing text must be translatable.
