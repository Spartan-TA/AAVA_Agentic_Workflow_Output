Title: Configure External Integrations

User Story: As a system administrator I want to configure external integrations So that our platform can connect with third-party systems (e.g., payroll, HRIS)

Acceptance Criteria:
Scenario: External integration configuration
Given I am logged in as a system administrator
When I set up or modify an integration
Then the system should connect and exchange data securely

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: API endpoints, authentication
- Notes: Support for OAuth and API keys
