Title: Automated Offboarding and Access/Asset Revocation

User Story: As an HR admin I want terminated employees to be offboarded automatically with access revoked, assets collected, and schedules updated so that security and compliance are maintained

Acceptance Criteria:
Scenario: Automated offboarding workflow
  Given an employee is terminated in the HRIS
  When the offboarding workflow is triggered
  Then all system access is revoked, asset return tasks are generated, and schedules are updated to remove the user

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Offboarding steps must be tracked and auditable; notifications sent to relevant departments.
