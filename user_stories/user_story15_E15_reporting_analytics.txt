Epic E15: Reporting & Analytics

---

User Story 1: Attendance and Overtime Reports
As management, I want reports for attendance and overtime so that staffing decisions are data-driven.

Acceptance Criteria:
Scenario: Attendance report
  Given attendance data
  When I request report
  Then data is filtered by date, department, shift

Scenario: Overtime report
  Given overtime data
  When I request report
  Then overtime hours are displayed

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Export CSV/PDF within 10s for 50k rows
