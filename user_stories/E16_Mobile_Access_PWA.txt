EPIC E16: Mobile Access (PWA)

---

Title: Mobile Access - Clock In/Out on Mobile
User Story: As a WORKER I want to clock in/out using my mobile device So that I can record attendance from anywhere in the warehouse.
Acceptance Criteria:
Scenario: Mobile clock in/out
Given I am on a mobile device
When I clock in/out
Then the event is recorded and queued if offline
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Offline queue with conflict resolution
