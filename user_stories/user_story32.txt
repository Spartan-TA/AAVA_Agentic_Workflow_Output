Title: Safety Metrics Dashboard Endpoints

User Story: As an operations manager I want access to safety metrics dashboard endpoints so that I can monitor incident trends and compliance in real time.

Acceptance Criteria:
Scenario: Metrics dashboard endpoint availability
Given safety incidents are recorded
When I access the dashboard endpoints
Then I see aggregated metrics and KPIs for safety performance

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: E02, E03
- Notes: Endpoints must support filtering by date, location, and severity.
