Title: Block Assignments for Expired Certifications

User Story:
As a Supervisor, I want the system to automatically block assignments for employees with expired certifications so that compliance and safety standards are maintained.

Acceptance Criteria:
Scenario 1: Prevent assignment to restricted tasks
  Given an employee's certification is expired
  When I attempt to assign them to a restricted task
  Then the system blocks the assignment and displays a warning

Scenario 2: Notify supervisor of blocked assignment
  Given an assignment is blocked due to expired certification
  When I review the assignment status
  Then I receive a notification explaining the reason

Scenario 3: Allow assignment after renewal
  Given an employee renews their certification
  When the renewal is approved
  Then the system allows assignment to restricted tasks

Priority: High
Story Points: 5
Dependencies: E02, E03
Notes: Must integrate with notifications and training tracking.
