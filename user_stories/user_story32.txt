Title: Configure Payroll Export Format

User Story: As a payroll administrator I want to configure the export format for payroll data so that it matches the requirements of our payroll provider

Acceptance Criteria:
Scenario: Setting export format
Given I am logged in as a payroll administrator
When I select a payroll provider and configure the export format
Then the system saves the configuration and uses it for future exports

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Payroll provider integration
- Notes: Support for multiple providers and custom field mapping.
