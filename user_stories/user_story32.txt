Title: Overdue Asset Return Reporting

User Story: As a supervisor I want to report overdue asset returns So that missing or late assets can be tracked and recovered

Acceptance Criteria:
Scenario: Identify overdue assets
  Given assets are assigned with expected return dates
  When the return date passes without check-in
  Then the asset should be flagged as overdue
Scenario: Generate overdue report
  Given overdue assets exist
  When I request a report
  Then a list of overdue assets and responsible employees should be generated
Scenario: Notify responsible employees
  Given assets are overdue
  When the report is generated
  Then notifications should be sent to responsible employees

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset management module, notification system
- Notes: Support for configurable grace periods
