Title: Audit Logging for Payroll Export Actions

User Story: As a compliance officer I want all payroll export actions to be logged So that I can review export history for auditing and compliance purposes

Acceptance Criteria:
Scenario: Logging export actions
Given a payroll export is performed
When the export completes or fails
Then an audit log entry should be created with timestamp, user, and status

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Payroll export, audit trail module
- Notes: Log both successful and failed export attempts.
