# Epic E12: Notifications & Announcements

## User Story 1: In-App and Email/SMS Notifications
**Title:** Send In-App and Email/SMS Notifications  
**Narrative:** As a supervisor, I want to notify users of shift changes, expiring certs, approvals, and announcements so that everyone is informed.  
**Acceptance Criteria (Gherkin):**
```
Given a notification event
When I send notifications
Then users receive messages via their chosen channels
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E03, E05, E06, E07  
**Notes:** Support opt-in/out per channel.

---

## User Story 2: Localized Notification Templates
**Title:** Localize Notification Templates  
**Narrative:** As a worker, I want notifications in my preferred language so that communication is clear.  
**Acceptance Criteria (Gherkin):**
```
Given notification templates
When I set my language preference
Then notifications are sent in the selected language
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E12, E18  
**Notes:** Support at least English and Spanish.

---

## User Story 3: Track Delivery Status and Rate Limits
**Title:** Track Notification Delivery and Apply Rate Limits  
**Narrative:** As an admin, I want to track delivery status and apply rate limits so that users are not spammed.  
**Acceptance Criteria (Gherkin):**
```
Given notification events
When delivery occurs
Then status is tracked (sent, delivered, failed)
And rate limits are enforced per user/channel
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E12  
**Notes:** Dashboard for delivery metrics.

---

## User Story 4: Announcements on Dashboard
**Title:** Display Announcements on Dashboard  
**Narrative:** As a worker, I want to see important announcements on my dashboard so that I am up-to-date.  
**Acceptance Criteria (Gherkin):**
```
Given active announcements
When I log in
Then announcements are visible on my dashboard
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E12  
**Notes:** Support expiration dates for announcements.
