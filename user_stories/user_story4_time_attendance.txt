EPIC: E04 - Time & Attendance (Clock In/Out)

===========================================
User Story 1
===========================================
Title: Implement Clock In/Out Endpoints

User Story: As a worker, I want to clock in and out via an endpoint so that my attendance is recorded.

Acceptance Criteria:
Scenario: Clock in/out event
Given I am authenticated
When I POST to /attendance/clock-in or /clock-out
Then my attendance event is recorded with a timestamp

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Device and geofence capture optional.

===========================================
User Story 2
===========================================
Title: Associate Clock Events with Shifts

User Story: As a system, I want to associate clock events with shifts so that hours worked are calculated.

Acceptance Criteria:
Scenario: Shift association
Given a clock-in and clock-out event
When both are recorded for a worker
Then the system calculates total hours for the shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Handle overnight shifts.

===========================================
User Story 3
===========================================
Title: Implement Missed Punch Correction Workflow

User Story: As a supervisor, I want to correct missed punches so that attendance records are accurate.

Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for supervisor review

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Corrections must be auditable.

===========================================
User Story 4
===========================================
Title: Export Attendance Reports in CSV

User Story: As a payroll admin, I want to export attendance reports in CSV so that payroll processing is streamlined.

Acceptance Criteria:
Scenario: Export attendance report
Given attendance data exists
When I request an export
Then a CSV file is generated with daily totals

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Include filters for date range, department.

===========================================
User Story 5
===========================================
Title: Validate Clock Event Sequences

User Story: As a system, I want to validate clock-in/out events to prevent duplicates or invalid sequences.

Acceptance Criteria:
Scenario: Event validation
Given a worker is already clocked in
When they attempt to clock in again
Then the request is rejected with an error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Prevent overlapping events.
