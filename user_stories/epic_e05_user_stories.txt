### Epic E05: Shift & Schedule Management

#### User Story 1: Create Recurring Shift Templates
- **Title:** Shift Template Creation
- **User Story:** As an HR user, I want to create recurring shift templates so that scheduling is efficient.
- **Acceptance Criteria:**
  ```
  Scenario: Create shift template
    Given valid shift details
    When I POST to /shifts/templates
    Then a new recurring shift template is created
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E02, E03, E04
- **Notes:** Templates support rotations.

#### User Story 2: Assign Shifts to Employees
- **Title:** Bulk Shift Assignment
- **User Story:** As a supervisor, I want to bulk-assign shifts to employees so that staffing is managed effectively.
- **Acceptance Criteria:**
  ```
  Scenario: Bulk assign shifts
    Given a list of employees and a shift template
    When I POST to /shifts/assign
    Then all selected employees are assigned to the shift
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E02, E03, E04
- **Notes:** Audit entries generated.

#### User Story 3: Detect and Prevent Scheduling Conflicts
- **Title:** Scheduling Conflict Detection
- **User Story:** As a scheduler, I want conflicts detected and prevented so that employees are not double-booked.
- **Acceptance Criteria:**
  ```
  Scenario: Prevent scheduling conflicts
    Given an employee has an existing shift
    When I try to assign an overlapping shift
    Then the system blocks the assignment and shows a conflict message
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E02, E03, E04
- **Notes:** Handles blackout dates.

#### User Story 4: Employee Shift Visibility
- **Title:** View Upcoming Shifts
- **User Story:** As a worker, I want to view my upcoming shifts so that I can plan my schedule.
- **Acceptance Criteria:**
  ```
  Scenario: View personal shifts
    Given I am logged in as a worker
    When I GET /shifts/mine
    Then I see a list of my upcoming shifts
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E02, E03, E04
- **Notes:** Personal shift calendar.
