Title: Create and Manage Shift Templates

User Story: As a Supervisor I want to create recurring shift templates and rotations So that scheduling is efficient and consistent

Acceptance Criteria:
Scenario: Shift Template Creation
Given access to scheduling module
When I create or edit a shift template
Then the template is saved and available for assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Support for overtime rules

===========================================

Title: Assign Shifts to Employees

User Story: As a Supervisor I want to assign shifts to employees individually or in bulk So that staffing is adequate

Acceptance Criteria:
Scenario: Shift Assignment
Given a shift template exists
When I assign shifts to employees
Then assignments are recorded and visible to workers

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Create and Manage Shift Templates
- Notes: Bulk assignment supported

===========================================

Title: Detect and Prevent Scheduling Conflicts

User Story: As a Scheduler I want the system to detect and prevent scheduling conflicts So that employees are not double-booked

Acceptance Criteria:
Scenario: Conflict Detection
Given existing shift assignments
When I attempt to assign overlapping shifts
Then the system blocks the assignment and notifies me

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Assign Shifts to Employees
- Notes: Blackout dates and operation calendars supported

===========================================

Title: Display Upcoming Shifts to Workers

User Story: As a Warehouse Worker I want to view my upcoming shifts So that I can plan my schedule

Acceptance Criteria:
Scenario: Upcoming Shifts Display
Given I am logged in
When I access my schedule
Then my personal upcoming shifts are displayed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Assign Shifts to Employees
- Notes: Audit entries generated for changes
