# Epic E05: Shift & Schedule Management

## User Story 1: Create Shift Templates
- **Title:** Shift Template CRUD
- **User Story:** As an HR user, I want to create and manage shift templates so that recurring schedules are standardized.
- **Acceptance Criteria (Gherkin):**
  ```
  Given HR is authenticated
  When they create/update/delete shift templates
  Then templates are stored and available for assignment
  ```
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, E04, Notes: Support rotations.

## User Story 2: Assign Shifts to Employees
- **Title:** Bulk Shift Assignment
- **User Story:** As a supervisor, I want to assign shifts to multiple employees so that staffing is efficient.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a list of employees
  When supervisor bulk-assigns shifts
  Then assignments are created
  And conflicts are detected and prevented
  ```
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, E04, Notes: Audit entries generated.

## User Story 3: View Upcoming Shifts
- **Title:** Worker Shift Schedule View
- **User Story:** As a worker, I want to view my upcoming shifts so that I can plan accordingly.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a worker is authenticated
  When they access their schedule
  Then upcoming shifts are displayed
  ```
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, E04, Notes: Personal calendar view.

## User Story 4: Blackout Dates & Operation Calendar
- **Title:** Manage Blackout Dates
- **User Story:** As an HR user, I want to set blackout dates and operation calendars so that scheduling conflicts are minimized.
- **Acceptance Criteria (Gherkin):**
  ```
  Given HR sets blackout dates
  When shifts are assigned
  Then assignments on blackout dates are blocked
  ```
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, E04, Notes: Calendar integration.
