## Epic E05: Shift & Schedule Management

### User Story 1: Create and Manage Shift Templates
**User Story:**  
As an HR user, I want to create recurring shift templates so that scheduling is efficient.

**Acceptance Criteria (Gherkin):**
```
Given shift template data
When I POST to /shifts/templates
Then a new shift template is created

Given existing templates
When I GET /shifts/templates
Then all templates are listed
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Employee CRUD, RBAC  
Notes: Templates include start/end times, recurrence.

---

### User Story 2: Assign Shifts to Employees
**User Story:**  
As a supervisor, I want to assign shifts to employees so that the warehouse is adequately staffed.

**Acceptance Criteria (Gherkin):**
```
Given a shift template and employee list
When I assign shifts
Then employees receive their shift assignments

Given overlapping assignments
When I attempt to assign a conflicting shift
Then the system prevents the conflict
```

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: Shift templates  
Notes: Bulk assignment supported.

---

### User Story 3: Handle Blackout Dates and Operation Calendars
**User Story:**  
As a scheduler, I want to define blackout dates so that shifts are not assigned during warehouse closures.

**Acceptance Criteria (Gherkin):**
```
Given a blackout date is set
When I assign shifts
Then no shifts are assigned on blackout dates

Given an operation calendar
When I view the schedule
Then blackout dates are clearly indicated
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Shift templates  
Notes: Blackout dates configurable.

---

### User Story 4: View Personal Upcoming Shifts
**User Story:**  
As a worker, I want to view my upcoming shifts so that I can plan my schedule.

**Acceptance Criteria (Gherkin):**
```
Given I am logged in
When I view my schedule
Then I see all upcoming shifts assigned to me
```

**Additional Details:**  
Priority: High  
Story Points: 1  
Dependencies: Shift assignment  
Notes: Personal dashboard.

---

### User Story 5: Audit Entries for Schedule Changes
**User Story:**  
As an auditor, I want all schedule changes to be logged so that compliance is maintained.

**Acceptance Criteria (Gherkin):**
```
Given a shift assignment is created, updated, or deleted
When I view the audit log
Then the change is recorded with actor, timestamp, and before/after values
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Audit trail  
Notes: Immutable log.
