Title: Incident Investigation and Corrective Action Workflow

User Story:
As a safety manager, I want to manage the workflow for investigating incidents and documenting corrective actions so that incidents are resolved and compliance is maintained.

Acceptance Criteria:
- Scenario: Incident status transitions
  Given an incident is recorded
  When the investigation begins
  Then the status changes to Investigating

- Scenario: Corrective action is documented
  Given an incident is being resolved
  When corrective actions are entered
  Then the status changes to Resolved and all actions are logged

Additional Details:
- Workflow must support Open, Investigating, and Resolved statuses
- All status changes and actions must be timestamped and auditable
- Corrective actions must be visible in incident reports
