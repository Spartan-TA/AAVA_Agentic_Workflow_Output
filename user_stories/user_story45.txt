Title: Certification Status Report

User Story: As a compliance officer I want to generate certification status reports So that I can monitor workforce compliance and take corrective action

Acceptance Criteria:
Scenario: Generating certification report
Given I have access to certification data
When I generate a status report
Then the report should list all employees with current, expired, and expiring certifications

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Certification module, reporting module
- Notes: Support for export and filtering by department.
