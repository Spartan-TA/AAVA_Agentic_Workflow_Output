Title: Schedule Automated Payroll Export

User Story:
As a payroll administrator, I want to schedule automated payroll data exports so that files are generated and sent to external systems on a recurring basis without manual intervention.

Acceptance Criteria:
Scenario 1: Set export schedule
  Given I have access to payroll export settings
  When I configure an export schedule (e.g., weekly, monthly)
  Then payroll data is automatically exported at the specified intervals

Scenario 2: Receive export confirmation
  Given an automated export occurs
  When the export is completed
  Then I receive a confirmation notification with a link to the exported file

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: Payroll data finalization, notification system
Notes: Should support integration with SFTP, email, or direct API endpoints.
