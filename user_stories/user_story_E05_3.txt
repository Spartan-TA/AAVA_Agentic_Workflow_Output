Title: Supervisors Bulk-Assign Shifts and Generate Audit Entries

User Story: As a supervisor I want to bulk-assign shifts to multiple employees and have audit entries generated So that I can efficiently manage team schedules and maintain a record of all changes

Acceptance Criteria:
Scenario: Bulk-assign shifts
Given I am authenticated as a SUPERVISOR
When I select multiple employees and assign them to a shift
Then the system creates the assignments and generates audit entries for each action

Scenario: Audit log review
Given shifts have been assigned or changed
When I review the audit log
Then I see detailed entries with actor, timestamp, and before/after state

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03, E04
- Notes: Bulk assignment must prevent conflicts and respect blackout dates; audit log must be immutable.
