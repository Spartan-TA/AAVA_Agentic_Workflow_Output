Title: Create Employee Record

User Story: As an HR administrator I want to create a new employee record with all required fields So that employee information is accurately captured in the system

Acceptance Criteria:
Scenario: Successful employee creation
Given I am on the employee creation form
When I enter valid details for name, badgeId, role, department, shiftGroup, hireDate, and status
Then the employee record should be saved and visible in the employee list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding & Domain Setup (E01)
- Notes: Validate mandatory fields and enforce unique badgeId.
