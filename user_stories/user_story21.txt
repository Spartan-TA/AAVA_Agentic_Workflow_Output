Title: Implement Audit Trail & Compliance Logging

User Story: As a compliance auditor I want centralized audit logs of all system actions So that regulatory requirements are met and suspicious activity can be investigated

Acceptance Criteria:
Scenario: View audit log for user actions
Given an auditor accesses the audit module
When they search for a user's activity
Then all relevant actions are displayed with timestamps and details

Additional Details:
- Priority: High
- Story Points: 6
- Dependencies: E03 (RBAC)
- Notes: Logs must be immutable and exportable for compliance reviews.
