Title: Responsive Mobile Views for Core Flows
User Story: As a warehouse worker I want responsive mobile views for clock-in/out, schedules, leave requests, and announcements So that I can use the system easily on my device
Acceptance Criteria:
Scenario: Responsive mobile view
Given I access the app on a mobile device
When I use core flows
Then the UI adapts and is fully usable
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance, Scheduling, Leave, Announcements
- Notes: Mobile-first design

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance, PWA
- Notes: Conflict resolution required
