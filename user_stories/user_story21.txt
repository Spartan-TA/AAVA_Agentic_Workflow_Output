Title: Leave Request Workflow

User Story: As an employee I want to submit leave requests and track their approval So that I can manage my time off transparently

Acceptance Criteria:
Scenario: Submit leave request
  Given I am authenticated
  When I submit a leave request
  Then the request should be logged and routed to my manager for approval
Scenario: Manager reviews leave request
  Given a leave request is pending
  When my manager approves or rejects it
  Then the request status should be updated accordingly
Scenario: View leave request status
  Given I have submitted leave requests
  When I view my leave dashboard
  Then I should see the status of all my requests

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave management module, workflow engine
- Notes: Support for multiple leave types
