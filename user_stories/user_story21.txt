Title: Define Overtime Rules

User Story:
As a Payroll Administrator, I want to define overtime rules (e.g., daily/weekly thresholds, double time) so that overtime pay is calculated accurately for all employees.

Acceptance Criteria:
Scenario 1: Set daily and weekly overtime thresholds
  Given I am on the overtime rules configuration page
  When I specify daily and weekly hour limits
  Then the system applies these rules to all shift calculations

Scenario 2: Apply double time for specific days
  Given overtime rules are defined
  When I set double time for holidays
  Then employees working on those days are compensated accordingly

Scenario 3: Override overtime rules for specific departments
  Given department-specific rules are allowed
  When I configure a department override
  Then only that department follows the custom overtime rules

Priority: High
Story Points: 5
Dependencies: E02, E03, E04
Notes: Must integrate with payroll export and support regulatory compliance.
