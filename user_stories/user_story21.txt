Title: Log Sensitive Changes
User Story: As a compliance officer I want all sensitive changes to be logged So that audit and forensic analysis is possible
Acceptance Criteria:
Scenario: Log change Given a create/update/delete occurs on sensitive data When the action is performed Then actor, timestamp, and before/after values are recorded
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC
- Notes: Immutable log table

Title: Export Audit Log
User Story: As an auditor I want to export audit logs by date, user, or entity So that compliance reviews are efficient
Acceptance Criteria:
Scenario: Export logs Given audit logs exist When I request an export Then logs are filtered and exported in CSV format
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: RBAC
- Notes: Export includes all relevant fields

Title: Validate Audit Coverage

- Priority: High
- Story Points: 1
