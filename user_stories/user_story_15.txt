Title: Role-Based API Access

User Story: As a developer I want API endpoints to enforce role-based access So that integrations respect system security policies

Acceptance Criteria:
Scenario: API call with insufficient role
  Given an API token with limited permissions
  When I call a restricted endpoint
  Then the API should return a 403 Forbidden error
Scenario: API call with sufficient role
  Given an API token with required permissions
  When I call an allowed endpoint
  Then the API should return the requested data

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: API gateway, role management
- Notes: Ensure role checks are performed at every endpoint and are auditable.
