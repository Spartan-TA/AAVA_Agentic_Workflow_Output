Title: Attendance Reports Export (CSV)

User Story: As an HR administrator I want to export attendance reports in CSV format So that I can analyze and share attendance data for payroll and compliance

Acceptance Criteria:
Scenario: Export attendance report
  Given attendance data exists for multiple employees
  When I request an export in CSV format
  Then the report is generated and available for download

Scenario: Report includes corrections
  Given corrections have been approved
  When I export the report
  Then all corrections are reflected in the exported data

Scenario: Export performance
  Given a large dataset (up to 50,000 rows)
  When I request an export
  Then the report is generated within 10 seconds

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export must include all relevant fields and be compatible with payroll systems.
