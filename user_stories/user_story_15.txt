Title: Handle Missed Punches and Correction Workflow

User Story: As a warehouse worker I want to request corrections for missed clock-in or clock-out events So that my attendance records remain accurate

Acceptance Criteria:
Scenario: Correction request submitted
Given I missed a punch
When I submit a correction request
Then a supervisor receives an approval task and my record is updated upon approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Correction requests must be auditable and tracked.
