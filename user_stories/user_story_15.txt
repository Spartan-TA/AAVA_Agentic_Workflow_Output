Title: Safety Incident Reporting
User Story: As a warehouse worker I want to report safety incidents or near-misses So that hazards are documented and addressed.
Acceptance Criteria:
Scenario: Submit incident report
  Given a safety incident occurs
  When I POST to /safety/incidents
  Then the incident is recorded with required fields

Scenario: Incident workflow
  Given a new incident
  When a safety manager reviews it
  Then status moves from Open to Investigating to Resolved

Scenario: OSHA summary export
  Given recorded incidents
  When I export OSHA 300/300A
  Then the file contains all required fields

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Metrics dashboard endpoints available.
