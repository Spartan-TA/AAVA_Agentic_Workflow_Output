====================================================================
Epic E05: Shift & Schedule Management
====================================================================

User Story 1:
- Title: Create and Manage Shift Templates
- User Story: As a scheduler, I want to define recurring shift templates so that I can standardize scheduling.
- Acceptance Criteria:
  - Given the UI/API, When I create a shift template, Then it is saved and available for assignment.
  - Given a template, When I edit or delete it, Then changes are reflected in future schedules.
- Additional Details: Priority: High, Story Points: 5, Dependencies: E02, E03, E04, Notes: Foundation for scheduling.

User Story 2:
- Title: Assign Shifts to Employees and Detect Conflicts
- User Story: As a supervisor, I want to assign shifts to employees and prevent scheduling conflicts so that coverage is ensured.
- Acceptance Criteria:
  - Given an assignment, When a conflict exists, Then the system prevents the assignment and notifies the user.
  - Given a valid assignment, When saved, Then the employee sees their upcoming shifts.
- Additional Details: Priority: High, Story Points: 5, Dependencies: User Story 1, Notes: Includes blackout dates.

User Story 3:
- Title: Bulk Assign Shifts and Generate Audit Entries
- User Story: As a supervisor, I want to bulk-assign shifts and have audit entries generated so that changes are tracked.
- Acceptance Criteria:
  - Given a bulk assignment, When completed, Then all affected employees are updated and audit logs are created.
- Additional Details: Priority: High, Story Points: 3, Dependencies: User Story 2, Notes: For large teams.

User Story 4:
- Title: Display Personal Shift Schedules to Workers
- User Story: As a worker, I want to view my upcoming shifts so that I can plan my attendance.
- Acceptance Criteria:
  - Given a worker login, When I view my schedule, Then all assigned shifts are visible.
- Additional Details: Priority: High, Story Points: 2, Dependencies: User Story 2, Notes: Improves transparency.
