Title: Delete Employee Master Data

User Story: As an HR manager I want to delete employee master data So that obsolete or incorrect employee records can be removed

Acceptance Criteria:
Scenario: Employee data deletion
Given I have access to the HR module
When I select an employee and choose delete
Then the employee record should be removed from the system

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee master data
- Notes: Confirm deletion with a warning prompt.
