Title: List, Filter, and Paginate Employee Records

User Story: As an HR manager I want to list, filter, and paginate employee records so that I can efficiently find and manage employees in large warehouses

Acceptance Criteria:
Scenario: Employee list with filters and pagination
  Given multiple employee records exist
  When I send a GET request to /employees with filter and pagination parameters
  Then the response contains only matching employees with correct pagination and OpenAPI schema examples

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD (E02)
- Notes: Support filtering by department, role, status, and shiftGroup; document all endpoints in OpenAPI
