Title: E02-4 Soft-Delete Employee Record

User Story:
As an HR administrator,
I want to soft-delete employee records via the API,
So that terminated employees are deactivated but their history is retained for compliance and reporting.

Acceptance Criteria:
Given a valid employee ID,
When the API endpoint is called to delete an employee,
Then the employee record is marked as inactive and is excluded from active lists, but not physically removed from the database.

Given an invalid employee ID,
When the API is called,
Then a not found error is returned and no changes are made.

Given a soft-deleted employee,
When retrieving employee records,
Then the record is only returned if explicitly requested with a filter for inactive records.

Additional Details:
- Soft-deleted records must retain all historical data.
- Audit log entry must be created for each soft-delete action.
- API must be documented in OpenAPI spec.
- Only authorized users can perform soft-delete.
