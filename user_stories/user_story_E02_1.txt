Title: Create Employee API (POST)

User Story: As an HR user, I want to create new employee records with name, badgeId, role, department, shiftGroup, hireDate, and status so that onboarding is streamlined.

Acceptance Criteria:

Scenario: Valid employee creation
Given valid employee data
When I POST to `/employees`
Then the employee is created and badgeId is unique

Scenario: Duplicate badgeId
Given an existing badgeId
When I POST another employee with the same badgeId
Then the request fails with a validation error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: OpenAPI schema must be provided.
