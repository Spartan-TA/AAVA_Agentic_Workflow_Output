Title: Create Employee Record via API

User Story: As an HR manager I want to create new employee records with name, badgeId, role, department, shiftGroup, hireDate, and status so that employee data is accurately captured in the system

Acceptance Criteria:
Scenario: Successful employee creation
  Given valid employee details
  When I submit a POST request to /employees
  Then a new employee record is created and badgeId is unique

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: Validate required fields and enforce badgeId uniqueness
