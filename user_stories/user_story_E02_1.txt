Title: Create Employee Master Data

User Story: As an HR manager I want to create employee master data So that all employee records are centrally stored and managed

Acceptance Criteria:
Scenario: Employee creation
Given I have access to the HR module
When I enter new employee details and submit
Then the employee record should be saved and visible in the employee list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Database, HR module
- Notes: Validate mandatory fields and unique employee ID.
