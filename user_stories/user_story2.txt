Title: Set Up Database Migration Tooling

User Story: As a developer I want to configure Flyway/Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:
Scenario: Migration tool configuration
  Given the project is initialized
  When I run the migration tool
  Then baseline migration is applied and database schema is created

Scenario: Migration repeatability
  Given a new migration is added
  When I run the migration tool again
  Then only unapplied migrations are executed and schema remains consistent

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: user_story1.txt
- Notes: Migration scripts must be documented in README.
