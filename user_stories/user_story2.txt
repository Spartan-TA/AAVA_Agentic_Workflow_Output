Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Spring Boot Actuator health endpoint So that I can monitor the application's health and readiness in production

Acceptance Criteria:

Scenario: Health endpoint returns UP
Given the application is running
When I access /actuator/health
Then the response should indicate status UP

Scenario: Health endpoint is secured
Given the application is running
When an unauthenticated user accesses /actuator/health
Then access should be denied

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project foundation
- Notes: Health endpoint must be included in monitoring dashboards.
