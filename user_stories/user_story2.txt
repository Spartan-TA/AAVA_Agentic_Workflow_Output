Title: Set Up Database Migration Tool
User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments
Acceptance Criteria:
Scenario: Baseline migration setup
  Given a new project with Flyway/Liquibase configured
  When I run the migration tool
  Then the baseline migration is applied and the database schema is initialized
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project scaffolding
- Notes: Baseline migration must run successfully on first build
