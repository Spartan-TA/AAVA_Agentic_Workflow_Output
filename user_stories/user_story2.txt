Title: Project Scaffolding - Add Actuator and Monitoring

User Story: As a developer, I want to enable Spring Boot Actuator endpoints so that we can monitor application health and metrics.

Acceptance Criteria:

Scenario: Actuator endpoints enabled
Given the application is running
When I access /actuator/health
Then I receive a status "UP"

Scenario: Metrics endpoint is available
Given the application is running
When I access /actuator/metrics
Then I receive application metrics data

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project initialization story
- Notes: Ensure security for actuator endpoints in production.
