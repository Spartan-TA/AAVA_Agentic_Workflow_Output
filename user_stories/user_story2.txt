Title: Integrate Flyway/Liquibase for Database Migrations

User Story: As a developer I want to integrate Flyway or Liquibase for managing database migrations So that schema changes are versioned and applied consistently across environments

Acceptance Criteria:
Scenario: Baseline migration applied
Given the project is initialized
When I run the application
Then Flyway/Liquibase applies the baseline migration and the database schema is up to date

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Baseline migration must run automatically on startup; migration scripts versioned in repo
