Title: Add Actuator Health Endpoint

User Story: As a DevOps engineer I want the application to expose a health endpoint via Spring Boot Actuator So that I can monitor the application's health status automatically

Acceptance Criteria:

Scenario: Health endpoint returns UP
Given the application is running
When I access '/actuator/health'
Then the response should be HTTP 200 with status 'UP'

Scenario: Health endpoint is documented
Given the API documentation is generated
When I review the OpenAPI/Swagger docs
Then the '/actuator/health' endpoint is included with example response

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Spring Boot Actuator
- Notes: Ensure actuator endpoints are secured as appropriate.
