Title: Employee Master Data CRUD Operations

User Story: As an HR manager I want to create, read, update, and delete employee records So that I can maintain a single source of truth for warehouse employee data.

Acceptance Criteria:
Scenario: Employee record management
Given I have HR manager access
When I POST, GET, PUT, PATCH, or DELETE /employees
Then the system enforces unique badgeId, supports soft-delete, and provides pagination and filtering

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup
- Notes: OpenAPI schemas with examples; ensure robust validation and error handling.
