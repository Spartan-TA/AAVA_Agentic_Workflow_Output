**User Story 2: User Profile Management - Edit Profile**

**Title:** Edit User Profile Information

**User Story:**
As a logged-in user, I want to update my profile information (name, email, phone number) so that my account details remain current and accurate.

**Acceptance Criteria:**
**Scenario 1:** Successful Profile Update
Given the user is logged in and on the profile page
When the user updates their name, email, or phone number and saves changes
Then the updated information is displayed on the profile page
And a confirmation message "Profile updated successfully" is shown

**Scenario 2:** Invalid Email Format
Given the user is on the profile edit form
When the user enters an invalid email format
Then an error message "Please enter a valid email address" is displayed
And the changes are not saved

**Scenario 3:** Unauthorized Access
Given the user is not logged in
When the user tries to access the profile edit page
Then the user is redirected to the login page

**Additional Details:**
- Priority: Medium
- Story Points: 5
- Dependencies: User profile API, authentication module
- Notes: Email changes should trigger a verification process; phone number should be validated for format.
