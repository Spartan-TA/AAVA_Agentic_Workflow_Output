Title: Database Migration Setup
User Story: As a developer I want to have Flyway/Liquibase configured for database migrations So that schema changes are versioned and repeatable
Acceptance Criteria:
Scenario: Baseline migration runs on startup
Given the application starts with a clean database
When Flyway/Liquibase executes
Then the baseline migration is applied and no errors occur

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding
- Notes: Migration scripts must be idempotent.
