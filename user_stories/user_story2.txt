Title: Configure Database Migration Tool

User Story: As a developer I want to set up Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:

Scenario: Baseline migration is applied on startup
Given a fresh database
When the application starts
Then the baseline migration is applied without errors

Scenario: Migration history is tracked
Given migrations have run
When I query the migration history table
Then all applied migrations are listed with timestamps

Scenario: Migration fails on error
Given a migration with a syntax error
When the application starts
Then the migration fails and no partial changes are applied

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding
- Notes: Choose Flyway or Liquibase based on team preference; document migration process in README
