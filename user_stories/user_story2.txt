EPIC E02 - Employee Master Data (CRUD)

===========================================

User Story 1: Create Employee API
---------------------------------------------
Title: Implement Employee CRUD API

User Story: As an HR user, I want to create, read, update, and delete employee records so that I can manage employee master data.

Acceptance Criteria:
Scenario: CRUD operations on employee records
  Given the API
  When I POST/GET/PUT/PATCH/DELETE /employees
  Then the operations succeed as per OpenAPI schema

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Support pagination and filtering.
