#### User Story 2: Configure Database Migration Tool
**As a** developer  
**I want** to set up Flyway/Liquibase for database migrations  
**so that** schema changes are versioned and repeatable across environments.

**Acceptance Criteria:**
- **Given** the migration tool is configured,  
  **When** I start the application,  
  **Then** baseline migration runs successfully and database schema is created.

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E01  
Notes: Use Flyway or Liquibase as per team preference.
