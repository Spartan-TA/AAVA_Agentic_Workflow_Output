Title: Database Migration Setup
User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable
Acceptance Criteria:
Scenario: Baseline migration runs on startup
Given the application is started with a clean database
When the migration tool executes
Then the baseline schema is created and versioned

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Initialization
- Notes: Migration scripts must be idempotent
