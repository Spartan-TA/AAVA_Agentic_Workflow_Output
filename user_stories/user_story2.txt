Title: Set Up Database Migration Tooling

User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and safely applied across environments

Acceptance Criteria:
Scenario: Baseline migration
Given the project is initialized
When I run the migration tool
Then the baseline schema is created and versioned in the database

Scenario: Migration health check
Given the application is running
When I access the Actuator health endpoint
Then the migration status is reported as UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: Migration scripts must be idempotent and documented
