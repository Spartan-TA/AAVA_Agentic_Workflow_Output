Title: Employee Master Data CRUD Operations

User Story: As an HR manager I want to create, read, update, and delete employee records So that I can maintain a single source of truth for all warehouse employees

Acceptance Criteria:
Scenario: Employee record management
Given I am authenticated as HR
When I use the employee CRUD endpoints
Then I should be able to add, view, update, and soft-delete employees with unique badgeId, and see pagination/filtering in the results

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: OpenAPI schemas must be documented with examples; soft-delete supported.
