Title: Database Migration Setup
User Story: As a developer, I want automated database migrations using Flyway/Liquibase so that schema changes are versioned and repeatable.
Acceptance Criteria:
  Given a new environment,
  When I start the application,
  Then Flyway/Liquibase runs the baseline migration and the DB schema is created.

  Given a migration script is added,
  When I run the migration,
  Then the schema updates without errors.

Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: Project Structure
  Notes: Ensures DB consistency.
