Title: Set Up Database Migration Tool

User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:
Scenario: Baseline migration
  Given the migration tool is configured
  When I run the migration command
  Then the baseline schema should be created in the database
Scenario: Migration failure handling
  Given an invalid migration script
  When I run the migration
  Then the process should fail with a clear error message

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Ensure migration scripts are included in version control
