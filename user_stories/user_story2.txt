Title: Set Up Database Migration with Flyway/Liquibase

User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:
Scenario: Database migration baseline
Given the project is initialized When I run the application Then Flyway or Liquibase applies the baseline migration and the database schema is created

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Migration scripts must be idempotent and documented
