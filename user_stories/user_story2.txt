Title: Integrate Database Migration Tool

User Story: As a developer, I want to set up Flyway or Liquibase for database migrations so that schema changes are version-controlled and repeatable.

Acceptance Criteria:

Scenario: Database migration tool is configured
Given the project is built
When the application starts
Then Flyway/Liquibase runs baseline migration successfully

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project structure
- Notes: Baseline migration must create initial schema
