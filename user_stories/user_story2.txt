Title: Database Migration Setup

User Story: As a developer, I want to add Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable across environments.

Acceptance Criteria:
Scenario: Database migration execution
Given the project is built
When the application starts
Then Flyway/Liquibase runs the baseline migration successfully
And the database schema is initialized as per the migration scripts

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding
- Notes: Migration scripts must be idempotent and support rollback.
