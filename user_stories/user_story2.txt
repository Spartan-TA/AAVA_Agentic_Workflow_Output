Title: Set Up Database Migration Tool

User Story: As a developer I want to configure Flyway or Liquibase for automated database migrations so that schema changes are versioned and repeatable across environments.

Acceptance Criteria:
Scenario: Database migration baseline
Given the migration tool is configured in the project
When I run the application for the first time
Then the baseline migration is applied and the database schema is created as per initial requirements

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Migration scripts must be idempotent and documented in the README.
