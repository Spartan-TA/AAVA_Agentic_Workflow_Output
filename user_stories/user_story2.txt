Title: Set Up Database Migration Tool

User Story: As a developer I want to configure Flyway or Liquibase for database migrations so that schema changes are versioned and applied consistently across environments

Acceptance Criteria:
Scenario: Baseline migration
  Given the migration tool is configured
  When I start the application
  Then the baseline migration should run and create the initial schema

Scenario: Migration tracking
  Given new migration scripts are added
  When the application is deployed
  Then migrations should apply in order without errors

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Document migration process in README; support both local and CI/CD environments.
