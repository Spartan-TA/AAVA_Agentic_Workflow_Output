Title: Database Migration Setup with Flyway/Liquibase

User Story: As a developer, I want automated database migrations using Flyway or Liquibase so that schema changes are versioned and repeatable.

Acceptance Criteria:

Scenario: Baseline migration is applied automatically
Given a fresh database
When I start the app
Then baseline migration is applied automatically

Scenario: Migration script executes successfully
Given a migration script
When I run the migration
Then the schema updates without errors

Scenario: Migration history is logged
Given the migration history
When I query the DB
Then all applied migrations are logged

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Ensures DB consistency
