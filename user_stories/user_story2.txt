Title: Set Up Database Migration Tooling
User Story: As a developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments.
Acceptance Criteria:
Scenario: Database migration baseline
Given the project is built and started
When the application starts for the first time
Then Flyway/Liquibase runs the baseline migration and the database schema is created as per initial requirements
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Migration scripts must be idempotent
