Title: Enable Database Migration Management

User Story:
As a developer, I want to integrate Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable across environments.

Acceptance Criteria (Gherkin):
Given the project is set up,
When I add a new migration script,
Then it should be applied automatically on application startup.

Given the project is deployed to a new environment,
When the application starts,
Then the database schema should match the latest migration version.

Additional Details:
Priority: High
Story Points: 3
Dependencies: None
Notes: Ensures DB consistency and supports future schema evolution.
