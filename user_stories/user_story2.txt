Title: Scaffold Core Modules and Health Endpoint

User Story: As a developer I want to scaffold core modules (employee, scheduling, attendance, safety) and enable the Actuator health endpoint so that the system is ready for feature development and operational monitoring.

Acceptance Criteria:
Scenario: Core module scaffolding
  Given the project is initialized
  When I create base packages for employee, scheduling, attendance, and safety
  Then each module has its own directory and starter classes

Scenario: Health endpoint setup
  Given the application is running
  When I access the Actuator health endpoint
  Then I receive a status of UP

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project initialization
- Notes: Ensure Actuator is enabled and accessible on port 8080; modules must be ready for further API development.
