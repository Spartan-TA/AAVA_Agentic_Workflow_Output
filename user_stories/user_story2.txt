Title: Create Employee Record
User Story: As an HR user, I want to create a new employee with badgeId, role, department, and other details so that I can onboard staff efficiently and maintain accurate records.
Acceptance Criteria:
  - Given valid employee details, when I POST to /employees, then a new employee record is created with a unique badgeId.
  - Given a duplicate badgeId, when I attempt to create an employee, then the API returns a validation error.
Additional Details:
  - Priority: High
  - Story Points: 3
  - Dependencies: E01
  - Notes: Must conform to OpenAPI schema; badgeId uniqueness enforced.
