Title: Set Up Base Package Structure

User Story: As a System Administrator I want to set up the base package structure for the EMS project So that all modules follow a consistent organization and are easier to maintain

Acceptance Criteria:

Scenario: Base packages created
Given the project is initialized
When I create the base packages for employee, scheduling, attendance, and safety modules
Then the package structure should reflect the domain organization and be documented in the README

Scenario: Core modules are accessible
Given the base packages are created
When a developer adds new features to a module
Then the package structure should support clear separation of concerns

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Follow standard naming conventions and document structure in README.
