EPIC E12 - Notifications & Announcements

User Story 1: Send In-App and Email/SMS Notifications
As a user I want to receive notifications for shift changes, expiring certs, approvals, and announcements So that I am informed in real time
Acceptance Criteria:
Scenario: Notification sent
Given a triggering event
When notification is generated
Then it is delivered via selected channels
Priority: Medium
Story Points: 2
Dependencies: E03, E05, E06, E07
Notes: Support in-app, email, SMS

User Story 2: Allow Users to Opt-In/Out Per Channel
As a user I want to opt-in or out of notification channels So that I control how I am notified
Acceptance Criteria:
Scenario: Channel preferences updated
Given notification settings
When I change preferences
Then notifications follow my selections
Priority: Medium
Story Points: 1
Dependencies: User Story 1
Notes: Store preferences per user

User Story 3: Localize Notification Templates
As an admin I want notification templates to be localized So that users receive messages in their language
Acceptance Criteria:
Scenario: Template localized
Given a template
When I select a language
Then notifications are sent in that language
Priority: Medium
Story Points: 1
Dependencies: User Story 1
Notes: Support multiple languages

User Story 4: Track Delivery Status and Apply Rate Limits
As a system I want to track notification delivery status and apply rate limits So that users are not spammed
Acceptance Criteria:
Scenario: Delivery tracked
Given a notification
When it is sent
Then status is updated and rate limits enforced
Priority: Medium
Story Points: 1
Dependencies: User Story 1
Notes: Log failures

User Story 5: Display Announcements on Dashboard
As a user I want to see announcements on my dashboard So that I am aware of important updates
Acceptance Criteria:
Scenario: Announcement visible
Given a new announcement
When I log in
Then it is displayed on the dashboard
Priority: Medium
Story Points: 1
Dependencies: User Story 1
Notes: Mark as read/unread
