# E08: Safety Incidents & OSHA Reporting

## User Story 1: Record Safety Incidents and Near-Misses
**User Story:**  
As a supervisor, I want to record safety incidents and near-misses so that risks are tracked.

**Acceptance Criteria (Gherkin):**
```
Given I POST to /safety/incidents with valid data
Then the incident is recorded with status "Open"

Given required fields are missing
Then the request is rejected with an error
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Capture severity, location, involved employees.

---

## User Story 2: Incident Investigation Workflow
**User Story:**  
As a safety manager, I want a workflow for investigating and resolving incidents so that corrective actions are tracked.

**Acceptance Criteria (Gherkin):**
```
Given an incident is recorded
When investigation starts
Then status changes to "Investigating"

Given investigation is complete
When corrective actions are recorded
Then status changes to "Resolved"
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Track timestamps and responsible users.

---

## User Story 3: Export OSHA 300/300A Reports
**User Story:**  
As a compliance officer, I want to export OSHA 300/300A summary reports so that regulatory requirements are met.

**Acceptance Criteria (Gherkin):**
```
Given incident data exists
When I export OSHA reports
Then a file is generated with all required fields
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Format per OSHA guidelines.

---

## User Story 4: Metrics Dashboard for Safety KPIs
**User Story:**  
As a safety manager, I want to view a dashboard of safety KPIs so that trends can be monitored.

**Acceptance Criteria (Gherkin):**
```
Given incidents are recorded
When I view the dashboard
Then I see metrics like incident rate, days since last incident, etc.
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Provide endpoints for BI integration.
