Title: Generate Payroll-Ready Export Files

User Story: As a payroll administrator I want to generate payroll-ready export files from approved attendance and leave data so that payroll processing is accurate and efficient

Acceptance Criteria:
Scenario: Generate payroll export
  Given attendance and leave records are approved
  When I generate a payroll export
  Then the file matches the provider schema and totals reconcile with internal reports

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04 (Attendance), E06 (Leave)
- Notes: Export must be compatible with multiple payroll providers
