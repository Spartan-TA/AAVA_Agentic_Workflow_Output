### E04: Time & Attendance (Clock In/Out)

#### Title: Clock-In/Clock-Out Endpoints
User Story: As a worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Clock-in
Given I am authenticated
When I POST to `/attendance/clock-in` with location/device info
Then my clock-in event is recorded

Scenario: Clock-out
Given I am authenticated
When I POST to `/attendance/clock-out`
Then my clock-out event is recorded

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Geofence validation optional

#### Title: Calculate Hours Worked
User Story: As a supervisor I want the system to calculate hours worked per shift So that payroll and compliance are accurate
Acceptance Criteria:
Scenario: Daily totals computed
Given clock-in/out events exist
When I request daily totals
Then hours worked are calculated per employee

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock-In/Clock-Out Endpoints
- Notes: Automatic shift association

#### Title: Missed Punches & Corrections Workflow
User Story: As a worker I want to submit corrections for missed punches So that my attendance is accurate
Acceptance Criteria:
Scenario: Correction submitted
Given I missed a punch
When I submit a correction request
Then an approval task is created for supervisor

Scenario: Correction approved
Given a correction task exists
When supervisor approves
Then attendance is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock-In/Clock-Out Endpoints
- Notes: Reports exportable (CSV)
