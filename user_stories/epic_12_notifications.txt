### E12: Notifications & Announcements

**User Story 1**
- Title: In-App and Email/SMS Notifications
- User Story: As a worker, I want to receive notifications for shift changes, expiring certs, and approvals so that I stay informed.
- Acceptance Criteria in Gherkin format:
  Scenario: Receive notification for shift change
  Given a shift is changed
  When the change is approved
  Then a notification is sent via selected channels
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E03, E05, E06, E07
  * Notes: Users opt-in/out per channel.

**User Story 2**
- Title: Localized Notification Templates
- User Story: As a supervisor, I want notification templates localized so that messages are clear to all users.
- Acceptance Criteria in Gherkin format:
  Scenario: Localized notification delivery
  Given a notification is triggered
  When the user's locale is set
  Then the message is sent in the correct language
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E03, E05, E06, E07
  * Notes: Templates managed centrally.

**User Story 3**
- Title: Announcements Dashboard
- User Story: As a worker, I want to see company announcements on my dashboard so that I don't miss important updates.
- Acceptance Criteria in Gherkin format:
  Scenario: Announcements visible on dashboard
  Given announcements exist
  When I log in
  Then I see all current announcements on my dashboard
- Additional Details:
  * Priority: Medium
  * Story Points: 1
  * Dependencies: E03, E05, E06, E07
  * Notes: Delivery status tracked.
