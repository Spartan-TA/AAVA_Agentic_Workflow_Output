EPIC E04: TIME & ATTENDANCE (CLOCK IN/OUT)

===========================================

Title: Clock In Endpoint

User Story: As a warehouse worker I want to clock in via an endpoint So that my attendance is recorded

Acceptance Criteria:
Scenario: Clock in event
Given my shift is scheduled
When I POST to /attendance/clock-in with valid credentials
Then my clock-in is recorded and associated with my shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Capture device and location if available

===========================================

Title: Clock Out Endpoint

User Story: As a warehouse worker I want to clock out via an endpoint So that my shift end is recorded

Acceptance Criteria:
Scenario: Clock out event
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out is recorded and hours worked are calculated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock In Endpoint
- Notes: Validate missed punches

===========================================

Title: Missed Punch Correction Workflow

User Story: As a supervisor I want a workflow for correcting missed punches So that attendance records are accurate

Acceptance Criteria:
Scenario: Correction request
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for supervisor review

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Clock In/Out Endpoints
- Notes: Track correction history

===========================================

Title: Attendance Reports Export

User Story: As an HR manager I want to export attendance reports in CSV So that I can reconcile payroll

Acceptance Criteria:
Scenario: Export attendance
Given attendance data exists
When I request an export
Then a CSV file is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Include shift association

===========================================

Title: Geofence Validation for Clock Events

User Story: As a warehouse manager I want optional geofence validation for clock-in/out So that only on-site events are accepted

Acceptance Criteria:
Scenario: Geofence validation
Given geofence is enabled
When a clock event is submitted
Then location is checked and only valid events are accepted

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Clock In/Out Endpoints
- Notes: Configurable per site
