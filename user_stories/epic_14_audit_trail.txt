### E14: Audit Trail & Compliance

**User Story 1**
- Title: Centralized Audit Logging
- User Story: As a compliance officer, I want all sensitive changes logged centrally so that I can audit activity.
- Acceptance Criteria in Gherkin format:
  Scenario: Log create/update/delete actions
  Given a sensitive change occurs
  When the action is performed
  Then the actor, timestamp, and before/after state are logged
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E03
  * Notes: Immutable log table.

**User Story 2**
- Title: Export Audit Logs
- User Story: As a compliance officer, I want to export audit logs by date, user, or entity so that I can support investigations.
- Acceptance Criteria in Gherkin format:
  Scenario: Export audit logs
  Given audit logs exist
  When I filter by date, user, or entity
  Then the matching logs are exported
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E03
  * Notes: Tests validate coverage.
