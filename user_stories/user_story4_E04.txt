### E04: Time & Attendance (Clock In/Out)

#### 1. Implement Clock-In Endpoint with Validation
User Story: As a worker I want to clock in at the start of my shift So that my attendance is recorded
Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift
When I POST to /attendance/clock-in
Then my clock-in event is recorded with timestamp and device info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate against shift schedule

#### 2. Implement Clock-Out Endpoint and Shift Association
User Story: As a worker I want to clock out at the end of my shift So that my hours worked are tracked
Acceptance Criteria:
Scenario: Successful clock-out
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Handle missed punches

#### 3. Handle Missed Punches and Corrections Workflow
User Story: As a supervisor I want to approve corrections for missed punches So that attendance data is accurate
Acceptance Criteria:
Scenario: Correction approval
Given a worker missed a punch
When a correction is submitted
Then an approval task is created for the supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Track correction history

#### 4. Export Attendance Reports
User Story: As a payroll admin I want to export attendance data So that I can process payroll
Acceptance Criteria:
Scenario: Export attendance as CSV
Given attendance records exist
When I request an export
Then a CSV file is generated with daily totals
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Include filters by date/employee

#### 5. Optional: Geofence Validation for Clock-In
User Story: As a supervisor I want to restrict clock-in to warehouse location So that only on-site attendance is recorded
Acceptance Criteria:
Scenario: Geofence enforced
Given I am outside the warehouse
When I attempt to clock in
Then the request is rejected
Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E02, E03
- Notes: Use device GPS if available
