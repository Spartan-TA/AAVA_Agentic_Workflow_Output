### E04 - Time & Attendance (Clock In/Out)

#### User Story 1: Clock-In Endpoint with Validation
- **Title:** Implement Clock-In Endpoint with Validation
- **User Story:** As a WORKER, I want to clock in at the start of my shift so that my attendance is recorded.
- **Acceptance Criteria:**
    - Given a valid clock-in request,
      When I POST to /attendance/clock-in,
      Then my attendance is recorded with timestamp and device info.
    - Given a clock-in outside allowed geofence,
      When I POST,
      Then the request is rejected.
- **Priority:** High
- **Story Points:** 5
- **Dependencies:** E02, E03
- **Notes:** Geofence is optional.

#### User Story 2: Clock-Out Endpoint with Validation
- **Title:** Implement Clock-Out Endpoint with Validation
- **User Story:** As a WORKER, I want to clock out at the end of my shift so that my worked hours are calculated.
- **Acceptance Criteria:**
    - Given a valid clock-out request,
      When I POST to /attendance/clock-out,
      Then my attendance is updated with clock-out time.
    - Given a missing clock-in,
      When I try to clock out,
      Then the system prompts for correction.
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E04-1
- **Notes:** Handles missed punches.

#### User Story 3: Calculate Hours Worked Per Shift
- **Title:** Calculate Hours Worked Per Shift
- **User Story:** As a SUPERVISOR, I want the system to calculate hours worked per shift so that payroll and compliance are accurate.
- **Acceptance Criteria:**
    - Given clock-in and clock-out records,
      When I view attendance,
      Then total hours worked are displayed.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E04-1, E04-2
- **Notes:** Used for payroll.

#### User Story 4: Missed Punches and Corrections Workflow
- **Title:** Handle Missed Punches and Corrections Workflow
- **User Story:** As a WORKER, I want to request corrections for missed punches so that my attendance is accurate.
- **Acceptance Criteria:**
    - Given a missed punch,
      When I submit a correction request,
      Then a task is created for supervisor approval.
    - Given supervisor approval,
      When the correction is approved,
      Then attendance is updated.
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E04-1, E04-2
- **Notes:** Approval workflow.

#### User Story 5: Export Attendance Reports
- **Title:** Export Attendance Reports
- **User Story:** As an ADMIN or HR, I want to export attendance data as CSV so that I can analyze and share records.
- **Acceptance Criteria:**
    - Given attendance data,
      When I request an export,
      Then a CSV file is generated with daily totals.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E04-3
- **Notes:** For compliance and payroll.
