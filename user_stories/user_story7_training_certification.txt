EPIC: E07 - Training & Certification Tracking

===========================================
User Story 1
===========================================
Title: Create and Manage Employee Certifications

User Story: As an HR admin, I want to create and manage certifications for employees so that compliance is tracked.

Acceptance Criteria:
Scenario: CRUD certifications
Given I have HR admin access
When I create, update, or delete a certification
Then the certification is persisted and linked to the employee

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Certification types configurable.

===========================================
User Story 2
===========================================
Title: Implement Certification Expiry Alerts

User Story: As a system, I want to alert employees and supervisors 30 and 7 days before a certification expires so that renewals are not missed.

Acceptance Criteria:
Scenario: Expiry alert notification
Given a certification is expiring in 30 or 7 days
When the alert job runs
Then the employee and supervisor receive a notification

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Notification channels configurable.

===========================================
User Story 3
===========================================
Title: Block Task Assignment for Expired Certifications

User Story: As a scheduler, I want to block assignment of tasks to employees with expired certifications so that only qualified staff are assigned.

Acceptance Criteria:
Scenario: Block unqualified assignment
Given an employee's certification is expired
When I attempt to assign them to a restricted task
Then the system prevents the assignment and notifies me

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Certification status must be checked in real-time.

===========================================
User Story 4
===========================================
Title: Enable Certification Proof Document Upload

User Story: As an employee, I want to upload proof documents for certifications so that compliance records are complete.

Acceptance Criteria:
Scenario: Upload certification proof
Given I have a new certification
When I upload a document
Then it is stored and linked to my profile

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Support PDF, JPG, PNG formats.

===========================================
User Story 5
===========================================
Title: Display Certification Status on Employee Profiles

User Story: As a supervisor, I want to view certification status on employee profiles so that I can verify qualifications.

Acceptance Criteria:
Scenario: View certification status
Given I am viewing an employee profile
When I access the certifications section
Then I see all current and expired certifications with status

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Status color-coded.
