### Epic E09: Equipment & Asset Assignment

#### 1. CRUD for Asset Registry
User Story: As an asset manager I want to create, read, update, and delete assets (scanners, forklifts, PPE) So that inventory is tracked.
Acceptance Criteria:
Scenario: Asset CRUD
Given the asset module
When I perform CRUD operations
Then assets are managed in the registry
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Include asset type and condition.

#### 2. Assign and Track Asset Check-In/Out
User Story: As a supervisor I want to assign assets to employees and track check-in/out So that accountability is maintained.
Acceptance Criteria:
Scenario: Asset assignment
Given an asset and employee
When I check out the asset
Then it is linked to the employee until returned
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Asset registry
- Notes: Overdue returns flagged.

#### 3. Block Asset Use if Certification Missing
User Story: As a supervisor I want to block asset use if required certifications are missing So that safety is enforced.
Acceptance Criteria:
Scenario: Certification check
Given an asset requiring certification
When an employee without valid cert tries to check out
Then the system blocks the action
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset registry, E07
- Notes: Error message shown.

#### 4. Maintain Asset Condition State
User Story: As an asset manager I want to record and update asset condition So that maintenance is tracked.
Acceptance Criteria:
Scenario: Condition update
Given an asset
When I update its condition
Then the new state is saved and visible
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset registry
- Notes: Condition history logged.

#### 5. Display Asset History per Asset and Employee
User Story: As a supervisor I want to view asset history per asset and employee So that usage is auditable.
Acceptance Criteria:
Scenario: Asset history display
Given an asset or employee
When I view history
Then all check-in/out events are listed
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment
- Notes: Exportable history.

#### 6. Report Overdue Asset Returns
User Story: As an asset manager I want to report overdue asset returns So that follow-up is possible.
Acceptance Criteria:
Scenario: Overdue report
Given assets checked out past due date
When I run the report
Then overdue assets are listed
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment
- Notes: Notification sent to responsible employee.
