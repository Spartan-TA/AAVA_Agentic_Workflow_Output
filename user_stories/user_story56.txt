Title: Mobile Clock-In/Out via PWA

User Story: As a warehouse worker I want to clock in and out using a mobile-friendly PWA So that I can record my attendance conveniently from any device

Acceptance Criteria:
Scenario: Mobile clock-in/out
Given I have installed the PWA on my mobile device
When I access the clock-in/out feature
Then I can record my attendance and the event is queued offline if connectivity is lost

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: E04, E05, E06, E12
- Notes: Offline queue must resolve conflicts; PWA manifest required
