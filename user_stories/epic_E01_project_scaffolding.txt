EPIC E01: PROJECT SCAFFOLDING & DOMAIN SETUP

===========================================

Title: Project Scaffolding - Spring Boot Project Initialization
User Story: As a developer, I want to initialize a Spring Boot (Maven) project with the correct base packages so that all modules have a consistent foundation.
Acceptance Criteria:
Scenario: Project builds and runs
  Given the project is cloned from the repository
  When I run the build and start the application
  Then the application starts on port 8080 and the health endpoint returns UP

Additional Details: 
Priority: High
Story Points: 3
Dependencies: None
Notes: Ensure README contains build/run steps.
