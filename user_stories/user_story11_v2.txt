Title: Role Assignment and Endpoint Security

User Story: As a system administrator I want to assign roles and secure endpoints So that only authorized users can access sensitive operations

Acceptance Criteria:
Scenario: Role-based access Given users with different roles exist When they access secured endpoints Then only users with appropriate roles are granted access; others receive 401 or 403 errors

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding (E01), Employee Master Data (E02)
- Notes: Cover ADMIN, HR, SUPERVISOR, WORKER roles; test coverage required
