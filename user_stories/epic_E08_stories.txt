EPIC E08 - Safety Incidents & OSHA Reporting

User Story 1: Record Safety Incidents and Near Misses
As a safety officer I want to record incidents and near-misses with severity, location, and involved employees So that safety events are tracked
Acceptance Criteria:
Scenario: Incident recorded
Given an incident form
When I submit details
Then the incident is saved with all required fields
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Validate required fields

User Story 2: Manage Incident Investigation Workflow
As a safety manager I want a workflow for investigating incidents and corrective actions So that follow-up is tracked
Acceptance Criteria:
Scenario: Investigation workflow
Given an open incident
When investigation starts
Then status updates to Investigating and actions are logged
Priority: High
Story Points: 2
Dependencies: User Story 1
Notes: Track corrective actions

User Story 3: Export OSHA Summary Reports
As a compliance officer I want to generate OSHA 300/300A summary reports So that regulatory requirements are met
Acceptance Criteria:
Scenario: OSHA export
Given incident records
When I request a summary
Then a file is generated with required fields
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Format per OSHA guidelines

User Story 4: Provide Safety Metrics Dashboard
As a manager I want a dashboard with safety KPIs So that trends and hotspots are visible
Acceptance Criteria:
Scenario: Metrics dashboard
Given incident data
When I view the dashboard
Then key metrics are displayed
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Filter by date/location
