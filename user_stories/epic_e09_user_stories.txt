EPIC E09: Equipment & Asset Assignment

Title: Assign Asset to Employee
User Story: As a supervisor I want to assign equipment and PPE to employees So that accountability is ensured
Acceptance Criteria:
Scenario: Asset assignment
Given assets are available
When I assign to an employee
Then the assignment is logged
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Track asset condition

Title: Track Asset Checkout/Return
User Story: As an employee I want to check out and return assets So that usage is tracked
Acceptance Criteria:
Scenario: Asset checkout/return
Given I am assigned an asset
When I check out or return
Then the event is recorded
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Overdue returns flagged

Title: Block Use if Certification Missing
User Story: As a system I want to block asset use if required certification is missing So that safety is maintained
Acceptance Criteria:
Scenario: Certification check
Given an asset requires certification
When an employee attempts to check out
Then the system blocks if certification is expired
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E07
- Notes: Alert supervisor
