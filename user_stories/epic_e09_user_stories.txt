### EPIC E09 - Equipment & Asset Assignment

#### User Story 1
Title: Assign Equipment to Employees

User Story: As an asset manager I want to assign equipment to employees So that asset responsibility is tracked

Acceptance Criteria:
Scenario: Assigning equipment
Given an available equipment item
When I assign it to an employee
Then the assignment should be recorded and visible in the employee's profile

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Equipment inventory, employee profiles
- Notes: Prevent double assignment of the same asset

---

#### User Story 2
Title: Track Asset Location

User Story: As a warehouse manager I want to track the location of assets So that I can quickly locate equipment when needed

Acceptance Criteria:
Scenario: Updating asset location
Given an asset is moved
When I update its location in the system
Then the new location should be reflected in the asset record

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset database
- Notes: Support barcode scanning for updates

---

#### User Story 3
Title: Equipment Return Workflow

User Story: As an employee I want to return assigned equipment So that asset records remain accurate

Acceptance Criteria:
Scenario: Returning equipment
Given I have an assigned asset
When I mark it as returned
Then the asset should become available for reassignment

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset assignment module
- Notes: Require condition check on return
