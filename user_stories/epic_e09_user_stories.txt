### Epic E09: Equipment & Asset Assignment

**User Story 1**
Title: Asset Registry CRUD
User Story: As an asset manager, I want to manage equipment records so that assets are tracked.
Acceptance Criteria:
Scenario: Asset CRUD
Given valid asset data
When I create, update, or delete an asset
Then the registry reflects the change
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee API, RBAC, Certification tracking
- Notes: Scanners, forklifts, PPE

**User Story 2**
Title: Asset Check-In/Check-Out
User Story: As a supervisor, I want employees to check in/out assets so that usage is tracked.
Acceptance Criteria:
Scenario: Asset Assignment
Given an available asset
When an employee checks out
Then the asset is assigned
When checked in
Then the asset is marked as returned
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset registry
- Notes: History log required

**User Story 3**
Title: Block Asset Use for Invalid Certification
User Story: As a supervisor, I want to prevent asset use if required certifications are missing so that safety is ensured.
Acceptance Criteria:
Scenario: Certification Check
Given an employee lacks valid certification
When they attempt to check out restricted asset
Then the system blocks the transaction
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Certification tracking
- Notes: PPE, forklifts, etc.

**User Story 4**
Title: Overdue Asset Return Report
User Story: As an asset manager, I want reports of overdue asset returns so that accountability is enforced.
Acceptance Criteria:
Scenario: Overdue Report
Given assets are checked out
When return is overdue
Then the report lists overdue assets and assigned employees
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Asset assignment
- Notes: Report exportable
