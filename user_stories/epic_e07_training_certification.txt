EPIC E07: Training & Certification Tracking

---

Title: Track Certifications and Expirations

User Story: As a supervisor I want to track employee certifications and expirations So that only qualified staff are assigned to equipment-sensitive roles

Acceptance Criteria:
Scenario: Certification tracking
Given certifications are entered
When expiry dates approach
Then alerts are generated 30/7 days before expiry

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: Forklift, PPE, etc.

---

Title: Block Assignment to Tasks with Expired Certs

User Story: As a scheduler I want to block assignment to tasks requiring expired certifications So that compliance is maintained

Acceptance Criteria:
Scenario: Assignment blocking
Given an employee's cert is expired
When I try to assign them to a sensitive task
Then the system prevents the assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Track Certifications and Expirations
- Notes: Scheduling checks

---

Title: Upload Proof Documents

User Story: As an employee I want to upload proof of certification So that my records are complete

Acceptance Criteria:
Scenario: Document upload
Given I have a valid cert
When I upload the document
Then it is attached to my profile

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Track Certifications and Expirations
- Notes: PDF/JPG supported

---

Title: Certification Status Visible on Profile

User Story: As a supervisor I want to view certification status on employee profiles So that I can quickly check qualifications

Acceptance Criteria:
Scenario: Profile view
Given I access an employee profile
When I view certifications
Then status and expiry are displayed

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Track Certifications and Expirations
- Notes: Highlight expired certs

---

Title: CRUD for Certifications

User Story: As an HR user I want to manage certifications via CRUD So that records are up-to-date

Acceptance Criteria:
Scenario: Certification CRUD
Given I have access
When I create, update, or delete certifications
Then changes are reflected immediately

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Track Certifications and Expirations
- Notes: Audit changes
