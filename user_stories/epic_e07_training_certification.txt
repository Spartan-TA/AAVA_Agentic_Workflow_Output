Title: Certification CRUD

User Story: As an HR I want to add, edit, and remove employee certifications So that compliance is tracked

Acceptance Criteria:
Scenario: Add certification
Given valid certification details
When I POST to /certifications
Then the certification is added to the employee profile

Scenario: Edit certification
Given an existing certification
When I PUT updated details
Then the certification is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC
- Notes: Certification status visible on profile

Title: Certification Expiry Alerts

User Story: As a SUPERVISOR I want to receive alerts for certifications expiring in 30/7 days So that renewals are managed proactively

Acceptance Criteria:
Scenario: Expiry alert
Given a certification is expiring soon
When the system checks expiry dates
Then an alert is sent to the supervisor and employee

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification CRUD
- Notes: Alerts sent via notification system

Title: Block Unqualified Assignment

User Story: As a System Administrator I want to block assignment to equipment-sensitive tasks if certification is expired So that safety is ensured

Acceptance Criteria:
Scenario: Assignment block
Given an expired certification
When I try to assign the employee to a sensitive task
Then the system rejects the assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification CRUD, Shift management
- Notes: Scheduling checks enforced
