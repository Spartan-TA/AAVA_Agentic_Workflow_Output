Title: Audit Trail for Transactions

User Story: As a compliance officer I want all system transactions to be logged in an audit trail So that data integrity and accountability are maintained

Acceptance Criteria:
Scenario: Transaction logging
Given a system transaction occurs
When the action is completed
Then the system should record the details in the audit trail

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Role Management
- Notes: Support export and filtering of audit logs.
