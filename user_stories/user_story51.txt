Title: Emergency Alert Broadcast

User Story:
As an HR administrator, I want to broadcast emergency alerts to all employees instantly so that everyone is informed and can respond appropriately in urgent situations.

Acceptance Criteria:
Scenario 1: Send emergency alert
  Given I have access to the emergency alert module
  When I send an alert
  Then all employees receive the message immediately via all available channels

Scenario 2: Confirm alert delivery
  Given an emergency alert is sent
  When I view the delivery report
  Then I see confirmation that the alert was delivered to all employees

Additional Details:
Priority: High
Story Points: 2
Dependencies: Notification system, employee contact information
Notes: Emergency alerts should override user notification preferences.
