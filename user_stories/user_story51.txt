Title: Export and Report on Audit Logs

User Story: As a compliance officer I want to export audit logs and generate compliance reports So that I can provide evidence for regulatory audits

Acceptance Criteria:
Scenario: Exporting audit logs
Given audit logs are available for a selected period
When I request an export or report
Then the system should generate a file or report with all relevant entries

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Audit trail module, reporting engine
- Notes: Support export formats (CSV, PDF) and filtering by user, action, date.
