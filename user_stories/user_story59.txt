Title: Docker Image Build and Push

User Story: As a DevOps engineer I want application code to be built into Docker images and pushed to a registry So that deployments are consistent and scalable

Acceptance Criteria:
Scenario: Building and pushing Docker images
Given new code is merged
When the pipeline runs
Then a Docker image should be built and pushed to the configured registry

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: CI/CD platform, Docker registry
- Notes: Support for version tagging and rollback.
