### E06: Leave & Absence Management

**User Story 1**
- Title: Request Leave
- User Story: As an employee, I want to request PTO or sick leave so that my absences are tracked.
- Acceptance Criteria in Gherkin format:
  Scenario: Submit leave request
  Given I am logged in
  When I submit a leave request
  Then the request is created and pending approval
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Validate accrual balances.

**User Story 2**
- Title: Approve or Deny Leave
- User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.
- Acceptance Criteria in Gherkin format:
  Scenario: Approve leave request
  Given a leave request is pending
  When I approve or deny it
  Then the employee is notified and balances are updated
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Auto-flag scheduled shifts for coverage.

**User Story 3**
- Title: Update Accrual Balances
- User Story: As an HR user, I want leave accruals to update automatically so that balances are accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Accrual balance updates
  Given an approved leave is processed
  When the leave is recorded
  Then the employee's accrual balance is reduced accordingly
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: E02, E03, E05
  * Notes: Integration with scheduling and payroll.

**User Story 4**
- Title: Export Approved Leaves
- User Story: As a payroll admin, I want to export approved leaves so that payroll calculations are accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Export leave data
  Given approved leave records exist
  When I request an export
  Then a file is generated with all approved leaves
- Additional Details:
  * Priority: Medium
  * Story Points: 1
  * Dependencies: E02, E03, E05
  * Notes: Format compatible with payroll system.
