Title: Role Based Access Control (RBAC)

User Story: As a system admin I want to assign roles and permissions so that only authorized users can access sensitive features.

Acceptance Criteria:
Scenario: Enforcing RBAC
Given a user with a specific role
When they access a protected endpoint
Then unauthorized requests return 401, forbidden actions return 403, and permissions are enforced as per role

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data
- Notes: Support ADMIN, HR, SUPERVISOR, WORKER roles; API key/OAuth2 toggle via config
