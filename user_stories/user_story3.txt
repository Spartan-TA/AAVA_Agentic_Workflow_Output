Title: Role-Based Access Control (RBAC)

User Story: As a system administrator I want to enforce role-based access control with endpoint and row-level security so that sensitive employee data and operations are only accessible to authorized users.

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user is not authenticated
  When they attempt to access a protected endpoint
  Then a 401 Unauthorized response is returned

Scenario: Forbidden action
  Given a user is authenticated but lacks the required role
  When they attempt to perform a restricted action
  Then a 403 Forbidden response is returned

Scenario: Role permissions
  Given users with ADMIN, HR, SUPERVISOR, and WORKER roles
  When they access endpoints
  Then ADMIN can manage all records, SUPERVISOR is limited to their team, and WORKER has restricted access

Scenario: Security configuration
  Given the system is deployed
  When API key/OAuth2 toggle is set in config
  Then authentication method is enforced accordingly

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Security rules must be covered by automated tests.
