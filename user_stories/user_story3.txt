Title: Enable Actuator Health Endpoint

User Story: As a DevOps Engineer I want to enable the Spring Boot Actuator health endpoint So that I can monitor the application's health status and automate deployment checks

Acceptance Criteria:
Scenario: Health endpoint availability
Given the application is running
When I access the /actuator/health endpoint
Then I receive a response indicating the application status is UP

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Health endpoint must be accessible and secured; required for CI/CD and monitoring integration.
