Title: Database Migration Integration

User Story: As a developer I want to integrate Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable

Acceptance Criteria:
Scenario: Baseline migration runs
Given a clean database
When I start the application
Then the baseline migration is applied and schema is created

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Initialization and Build Verification
- Notes: Migration scripts must be idempotent; failures must be logged
