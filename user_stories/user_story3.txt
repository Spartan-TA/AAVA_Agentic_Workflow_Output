Title: Role-Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations are restricted to authorized users and PII is protected

Acceptance Criteria:
Scenario: Role-based access enforcement
Given a user with a specific role
When the user attempts to access a protected endpoint or perform an action
Then unauthorized requests return 401, forbidden actions return 403, and ADMIN can manage all records while SUPERVISOR is limited to their team

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD)
- Notes: Security rules covered by tests; API key/OAuth2 toggle via config; method/endpoint security and row-level constraints.
