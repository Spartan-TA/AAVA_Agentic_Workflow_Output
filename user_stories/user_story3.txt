Title: Update Employee Information
User Story: As an HR user, I want to update employee details (role, department, status) so that records remain current and reflect organizational changes.
Acceptance Criteria:
  - Given an existing employee, when I PATCH /employees/{id} with valid updates, then the employee record is updated.
  - Given invalid data (e.g., missing required fields), when I PATCH, then a validation error is returned.
Additional Details:
  - Priority: High
  - Story Points: 2
  - Dependencies: E01, E02
  - Notes: Audit trail required for changes.
