Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to restrict API endpoints based on user roles so that only authorized users can access sensitive operations.

Acceptance Criteria:
Scenario: Endpoint access control
  Given a user with a specific role (ADMIN, HR, SUPERVISOR, WORKER)
  When they attempt to access a protected endpoint
  Then access is granted or denied according to their role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data
- Notes: Cover all endpoints with role-based security.

Title: Unauthorized and Forbidden Response Handling

User Story: As a user I want to receive clear 401 or 403 responses when access is denied so that I understand my permissions.

Acceptance Criteria:
Scenario: Access denied responses
  Given a user without sufficient permissions
  When they attempt a restricted action
  Then the system returns 401 (unauthorized) or 403 (forbidden) as appropriate

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Endpoint security
- Notes: Cover with automated security tests.
