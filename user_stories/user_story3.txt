Title: Implement Role-Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access control with roles (ADMIN, HR, SUPERVISOR, WORKER) so that sensitive operations and data are protected and only accessible to authorized users.

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without valid credentials
  When they attempt to access a protected endpoint
  Then the system returns a 401 Unauthorized response

Scenario: Forbidden action
  Given a user with insufficient privileges
  When they attempt to perform a restricted action
  Then the system returns a 403 Forbidden response

Scenario: Admin permissions
  Given a user with the ADMIN role
  When they access any employee record or endpoint
  Then they are granted full access

Scenario: Supervisor permissions
  Given a user with the SUPERVISOR role
  When they access records for their team
  Then they are granted access, but are restricted from other teams

Scenario: Security configuration
  Given the system is running
  When API key or OAuth2 is toggled via configuration
  Then the selected authentication method is enforced

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data
- Notes: Security rules must be covered by automated tests.
