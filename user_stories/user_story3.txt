Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations and data are restricted to authorized users

Acceptance Criteria:
Scenario: Unauthorized access
Given a user without proper credentials
When they attempt to access a protected endpoint
Then the system returns a 401 Unauthorized response

Scenario: Forbidden action
Given a user with insufficient privileges
When they attempt to perform a restricted operation
Then the system returns a 403 Forbidden response

Scenario: Role management
Given an ADMIN user
When they manage roles and permissions
Then they can assign and revoke roles for other users

Scenario: Security rule coverage
Given defined security rules
When automated tests are run
Then all rules are validated for correct enforcement

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: API key/OAuth2 toggle via config; row-level constraints where applicable; security rules covered by tests.
