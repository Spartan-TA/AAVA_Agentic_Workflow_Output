Title: Role Based Access Control (RBAC)

User Story: As an administrator I want to enforce role-based access control So that sensitive operations and PII are protected and only authorized users can perform restricted actions

Acceptance Criteria:

Scenario: Unauthorized access
Given a user without proper credentials
When they attempt to access a restricted endpoint
Then the system returns a 401 Unauthorized response

Scenario: Forbidden actions
Given a user with insufficient privileges
When they attempt to perform an action outside their role
Then the system returns a 403 Forbidden response

Scenario: Role permissions
Given users with different roles (ADMIN, HR, SUPERVISOR, WORKER)
When they access endpoints
Then permissions are enforced as per role definitions

Scenario: Security tests
Given the security rules are implemented
When tests are run
Then all rules are covered and validated

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (CRUD) (E02)
- Notes: API key/OAuth2 toggle via config, method/endpoint security, row-level constraints where applicable.
