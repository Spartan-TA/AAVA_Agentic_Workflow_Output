Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations are restricted to authorized users and PII is protected.

Acceptance Criteria:
Scenario: Enforcing access control
Given a user with a specific role
When they attempt to access a protected endpoint or method
Then unauthorized requests return 401, forbidden actions return 403, and role-based constraints are enforced

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data
- Notes: API key/OAuth2 toggle via config; security rules covered by tests.
