Title: Enable Actuator Health Monitoring

User Story: As a DevOps engineer I want to enable the Actuator health endpoint So that I can monitor application health and readiness for deployment

Acceptance Criteria:
Scenario: Health endpoint availability
  Given the application is running
  When I access /actuator/health
  Then the endpoint should return status UP
Scenario: Health endpoint failure
  Given a misconfigured application
  When I access /actuator/health
  Then the endpoint should return status DOWN with error details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure endpoint is secured and documented
