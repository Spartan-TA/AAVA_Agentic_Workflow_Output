Title: Enable Actuator Endpoints

User Story: As an operations engineer I want Actuator endpoints enabled So that I can monitor application health and metrics

Acceptance Criteria:

Scenario: Health endpoint is accessible
Given the application is running
When I access /actuator/health
Then I receive a 200 response with status UP

Scenario: Metrics endpoint is available
Given the application is running
When I access /actuator/metrics
Then I see standard JVM and application metrics

Scenario: Sensitive endpoints are secured
Given the application is running in staging or production
When I access sensitive actuator endpoints
Then access is restricted to authorized users

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding
- Notes: Document enabled endpoints; restrict sensitive endpoints in non-dev environments
