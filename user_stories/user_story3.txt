Title: Enable Actuator Health Endpoint
User Story: As a developer I want to enable the Actuator health endpoint So that I can monitor the application's health status
Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access the /actuator/health endpoint
Then I receive a response indicating status UP
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project scaffolding
- Notes: Endpoint must be accessible and secured
