Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access controls so that sensitive operations and data are protected and only authorized users can perform restricted actions.

Acceptance Criteria:
Scenario: Enforcing role-based security
Given a user with a specific role (ADMIN, HR, SUPERVISOR, WORKER)
When the user attempts to access an endpoint or perform an action
Then unauthorized requests return 401, forbidden actions return 403, and security rules are covered by automated tests
And ADMIN can manage all records, SUPERVISOR is limited to their team

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Support API key/OAuth2 toggle via config; method/endpoint and row-level security enforced.
