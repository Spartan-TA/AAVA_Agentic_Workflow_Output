Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Actuator health endpoint So that system health can be monitored automatically

Acceptance Criteria:
Scenario: Health endpoint availability
  Given the application is running
  When I access /actuator/health
  Then the endpoint returns status UP

Scenario: Health endpoint documentation
  Given the endpoint is enabled
  When I review the README
  Then instructions for accessing and interpreting health status are present
