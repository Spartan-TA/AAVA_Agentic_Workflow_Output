Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions (ADMIN, HR, SUPERVISOR, WORKER) so that sensitive operations are restricted and PII is protected.

Acceptance Criteria:
Scenario: Role-based access enforcement
Given a user attempts to access a protected endpoint
