Title: Database Migration Tool Integration
User Story: As a developer I want Flyway or Liquibase integrated into the project So that database schema changes are versioned and automated
Acceptance Criteria:
Scenario: Baseline migration runs on startup
Given a new environment with an empty database
When I start the application
Then Flyway/Liquibase applies the baseline migration and the schema is created
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Migration scripts must be tracked in version control
