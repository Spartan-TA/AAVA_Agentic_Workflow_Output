Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access control so that sensitive operations and data are restricted to authorized users.

Acceptance Criteria:
Scenario: Unauthorized access
Given a user without proper credentials
When they attempt to access a protected endpoint
Then the system returns a 401 Unauthorized response

Scenario: Forbidden action
Given a user with insufficient role
When they attempt to perform a restricted operation
Then the system returns a 403 Forbidden response

Scenario: Role permissions
Given an ADMIN user
When they access any record
Then all records are visible and manageable

Scenario: Supervisor constraints
Given a SUPERVISOR user
When they access team records
Then only their team's records are visible and manageable

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD)
- Notes: Security rules must be covered by automated tests. API key/OAuth2 toggle via config.
