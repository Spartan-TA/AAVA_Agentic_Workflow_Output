Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations are restricted to authorized users and PII is protected.

Acceptance Criteria:
Scenario: Unauthorized Access
Given a user without required role
When the user attempts a restricted action
Then a 401 or 403 error is returned

Scenario: Role Management
Given an ADMIN user
When managing records
Then all records are accessible

Scenario: Supervisor Constraints
Given a SUPERVISOR user
When accessing team records
Then only team records are accessible

Scenario: Security Testing
Given security rules are implemented
When tests are run
Then all rules are covered and pass

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: API key/OAuth2 toggle via config, method/endpoint security, row-level constraints.
