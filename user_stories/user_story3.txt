Title: Implement Role-Based Access Control

User Story: As a system administrator I want to configure role-based access for different user types So that sensitive operations and PII are protected and only authorized users can perform restricted actions

Acceptance Criteria:
Scenario: Role-based access enforcement
Given users have assigned roles (ADMIN, HR, SUPERVISOR, WORKER)
When they access endpoints or perform actions
Then unauthorized requests return 401, forbidden actions return 403, ADMIN can manage all records, SUPERVISOR is limited to their team, and security rules are covered by tests

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Employee Master Data
- Notes: API key/OAuth2 toggle via config; method/endpoint security and row-level constraints applied.
