Title: Role-Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations and PII are protected and only authorized users can access them

Acceptance Criteria:
Scenario: Unauthorized Access
Given a user without proper role
When they attempt to access a restricted endpoint
Then the system returns a 401 or 403 error

Scenario: Role Assignment
Given an ADMIN user
When they assign roles to users
Then the roles are updated and reflected in access controls

Scenario: Security Testing
Given security rules are implemented
When automated tests run
Then all rules are covered and pass

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Support API key/OAuth2 toggle via config and row-level constraints.
