Title: Database Migration Setup

User Story: As a DevOps Engineer I want to integrate Flyway/Liquibase for database migrations So that the database schema can be versioned and updated consistently across environments

Acceptance Criteria:

Scenario: Baseline migration runs on application startup
  Given a fresh database
  When the application starts
  Then the baseline migration is applied without errors

Scenario: Migration scripts are tracked and versioned
  Given new migration scripts are added
  When the application is built
  Then the scripts are applied in order and tracked in the migration history table

Scenario: Rollback is possible on migration failure
  Given a migration fails
  When the failure is detected
  Then the database is rolled back to the previous stable state

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Use Flyway or Liquibase as per team preference; ensure scripts are idempotent.
