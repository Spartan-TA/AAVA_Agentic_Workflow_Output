Title: Role Based Access Control Implementation

User Story: As an administrator I want to assign roles and permissions to users So that sensitive operations are restricted to authorized personnel

Acceptance Criteria:
Scenario: Role enforcement
Given a user with a specific role
When the user attempts to access a protected endpoint
Then unauthorized requests return 401, forbidden actions return 403, and ADMIN can manage all records, SUPERVISOR limited to team

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01), Employee Master Data (E02)
- Notes: Security rules must be covered by tests; API key/OAuth2 toggle via config.
