Title: Employee Domain CRUD API
User Story: As an HR user I want to create, read, update, and delete employee records via API So that employee data is accurate and up to date
Acceptance Criteria:
Scenario: Employee CRUD operations
Given valid employee data
When I POST, GET, PUT, PATCH, or DELETE /employees
Then the employee is created, retrieved, updated, or soft-deleted accordingly, with unique badgeId enforced
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Pagination, filtering, and OpenAPI docs required
