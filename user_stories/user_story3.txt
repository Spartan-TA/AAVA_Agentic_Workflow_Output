Title: Enable Actuator Health Endpoint

User Story: As a system administrator I want an Actuator health endpoint enabled So that I can monitor the application's health status in real time

Acceptance Criteria:
Scenario: Health endpoint availability
Given the application is running
When I access /actuator/health
Then I receive a response with status UP when the system is healthy

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Spring Boot project scaffolding
- Notes: Endpoint must be secured and documented in README.
