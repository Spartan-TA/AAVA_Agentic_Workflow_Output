Title: Enable Actuator Health Endpoint

User Story: As a developer I want to enable the Actuator health endpoint So that system health can be monitored and verified automatically

Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access the /actuator/health endpoint
Then the response status is UP and includes basic system health information

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project scaffolding
- Notes: Ensure endpoint is documented and accessible for monitoring tools
