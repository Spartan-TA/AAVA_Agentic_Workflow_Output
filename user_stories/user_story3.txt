### Epic E03: Role-Based Access Control (RBAC)

**User Story 1: Implement Role-Based Endpoint Security**
- Title: Secure Endpoints by Role
- User Story: As a System Admin, I want to restrict API endpoints by user role so that only authorized users can access sensitive data.
- Acceptance Criteria:
  ```
  Given an unauthenticated request,
  When accessing any protected endpoint,
  Then the response is 401 Unauthorized.

  Given a user with insufficient role,
  When accessing a forbidden endpoint,
  Then the response is 403 Forbidden.

  Given an ADMIN user,
  When accessing any employee record,
  Then access is granted.

  Given a SUPERVISOR user,
  When accessing employee records outside their team,
  Then access is denied.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E01, E02, Notes: Covers all major roles.

**User Story 2: Row-Level Security for Sensitive Data**
- Title: Enforce Row-Level Security
- User Story: As a Supervisor, I want to access only my team's employee records so that privacy is maintained.
- Acceptance Criteria:
  ```
  Given a SUPERVISOR user,
  When accessing employee records,
  Then only records for their team are returned.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, Notes: Team mapping required.

**User Story 3: API Key/OAuth2 Toggle**
- Title: Support API Key and OAuth2 Authentication
- User Story: As a System Admin, I want to toggle between API key and OAuth2 authentication so that security can be adapted to integration needs.
- Acceptance Criteria:
  ```
  Given the configuration is set to API key,
  When a request is made with a valid API key,
  Then access is granted.

  Given the configuration is set to OAuth2,
  When a request is made with a valid token,
  Then access is granted.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Configurable via properties.

**User Story 4: Automated Security Tests**
- Title: Automated Security Test Coverage
- User Story: As a Developer, I want automated tests for security rules so that unauthorized access is reliably blocked.
- Acceptance Criteria:
  ```
  Given the test suite,
  When tests are run,
  Then unauthorized and forbidden actions are covered and pass.
  ```
- Additional Details: Priority: High, Story Points: 1, Dependencies: E01, E02, Notes: Regression coverage.
