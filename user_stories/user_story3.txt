Title: Configure Database Migration Tool

User Story: As a backend developer I want to configure Flyway or Liquibase for database migrations So that schema changes are versioned and safely applied across environments

Acceptance Criteria:

Scenario: Baseline migration runs on startup
Given the application is started for the first time
When Flyway or Liquibase is enabled
Then the baseline migration scripts should execute and create the initial schema

Scenario: Migration history is tracked
Given migrations have been applied
When I query the migration history table
Then I should see all applied scripts with timestamps

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project foundation
- Notes: Migration scripts must be idempotent and documented in README.
