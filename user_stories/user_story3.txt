Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure roles and permissions so that sensitive operations and data are restricted to authorized users.

Acceptance Criteria:
Scenario: Role Enforcement
Given user roles are defined (ADMIN, HR, SUPERVISOR, WORKER)
When a user attempts to access a protected endpoint or perform an operation
Then unauthorized requests return 401, forbidden actions return 403, ADMIN can manage all records, SUPERVISOR is limited to their team, and security rules are covered by tests.

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data
- Notes: Support API key/OAuth2 toggle via config; ensure row-level constraints where applicable.
