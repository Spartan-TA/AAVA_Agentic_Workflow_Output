Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Spring Boot Actuator health endpoint so that system health can be monitored automatically.

Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access the /actuator/health endpoint
Then the response status is UP and includes basic system metrics

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: Endpoint must be secured and documented in the README.
