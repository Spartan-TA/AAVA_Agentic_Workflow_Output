Title: Role-Based Access Control (RBAC)

User Story: As a system administrator I want to enforce role-based access control so that sensitive operations are restricted to authorized users and PII is protected.

Acceptance Criteria:

Scenario: Unauthorized access
Given an unauthenticated request
When I attempt to access a protected endpoint
Then I receive a 401 Unauthorized response

Scenario: Forbidden action
Given a user with insufficient privileges
When I attempt to perform a restricted operation
Then I receive a 403 Forbidden response

Scenario: Role permissions
Given users with ADMIN, HR, SUPERVISOR, and WORKER roles
When they access endpoints
Then ADMIN can manage all records, SUPERVISOR is limited to their team, and other roles are restricted accordingly

Scenario: Security test coverage
Given the security configuration
When tests are executed
Then all security rules are validated by automated tests

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Support API key/OAuth2 toggle via config and row-level constraints where applicable.
