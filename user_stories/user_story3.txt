Title: Role Based Access Control Implementation

User Story: As a system administrator I want to configure role-based access control with endpoint and row-level security So that sensitive operations and PII are protected and only authorized roles can perform restricted actions

Acceptance Criteria:
Scenario: Access Control Enforcement
Given a user with a specific role
When the user attempts to access protected endpoints or perform restricted actions
Then unauthorized requests return 401, forbidden actions return 403, ADMIN can manage all records, SUPERVISOR is limited to their team, and security rules are covered by tests

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data
- Notes: API key/OAuth2 toggle via config; method/endpoint security; row-level constraints applied.
