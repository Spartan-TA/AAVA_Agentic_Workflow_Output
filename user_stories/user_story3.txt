Title: Implement Role-Based Access Control (RBAC)

User Story: As an administrator I want to assign roles and permissions to users So that sensitive operations are restricted to authorized personnel

Acceptance Criteria:
Scenario: Unauthorized access attempt
Given a user without the required role
When the user attempts to access a restricted endpoint
Then the system returns a 403 Forbidden error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding, Employee Master Data
- Notes: Must support ADMIN, HR, SUPERVISOR, WORKER roles; API key/OAuth2 toggle via config
