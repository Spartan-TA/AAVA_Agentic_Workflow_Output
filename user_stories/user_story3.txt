#### User Story 3: Enable Actuator Health Endpoint
**As a** DevOps engineer  
**I want** to enable the Spring Boot Actuator health endpoint  
**so that** system health can be monitored automatically.

**Acceptance Criteria:**
- **Given** the application is running,  
  **When** I access `/actuator/health`,  
  **Then** the endpoint returns status UP.

**Additional Details:**  
Priority: High  
Story Points: 1  
Dependencies: E01  
Notes: Ensure endpoint is secured for non-public access.
