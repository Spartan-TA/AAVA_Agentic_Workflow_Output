Title: Provide Comprehensive README Documentation

User Story: As a new developer I want a README file with clear build and run instructions So that I can set up the project quickly and avoid onboarding delays

Acceptance Criteria:

Scenario: README includes build and run steps
Given I open the README file
When I follow the instructions for building and running the project
Then the application starts successfully and all prerequisites are documented

Scenario: Troubleshooting section is present
Given I encounter a common setup error
When I consult the README troubleshooting section
Then I find guidance to resolve the issue

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: README must be kept up to date with any project structure or dependency changes.
