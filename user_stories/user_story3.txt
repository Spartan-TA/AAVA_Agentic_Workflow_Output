Title: Role-Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access control so that sensitive operations are restricted to authorized users and PII is protected.

Acceptance Criteria:
Scenario: Enforcing access control
Given a user with a specific role
When the user attempts to access a protected endpoint
Then unauthorized requests return 401 and forbidden actions return 403
And ADMIN can manage all records
And SUPERVISOR is limited to their team
And security rules are covered by automated tests

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD)
- Notes: Support API key/OAuth2 toggle via configuration; method and row-level security enforced.
