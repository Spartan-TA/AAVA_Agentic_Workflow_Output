Title: Health Monitoring Enablement
User Story: As an ops engineer, I want to enable Actuator endpoints so that I can monitor application health and metrics.
Acceptance Criteria:
Scenario: Health endpoint available
Given the application is running
When I access /actuator/health
Then the endpoint returns UP

Scenario: Metrics endpoint available
Given the application is running
When I access /actuator/metrics
Then I see relevant metrics

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project Initialization
- Notes: Required for observability
