Title: Enable Spring Boot Actuator Health Endpoint

User Story: As an operator, I want to access the Actuator health endpoint so that I can monitor application status.

Acceptance Criteria:

Scenario: Health endpoint returns UP status
Given the running app
When I GET /actuator/health
Then I receive a 200 response with status UP

Scenario: Health endpoint reflects failures
Given the app
When a health check fails
Then the health endpoint reflects the failure

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Required for monitoring
