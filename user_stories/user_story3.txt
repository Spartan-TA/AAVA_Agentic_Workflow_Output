Title: Employee CRUD - Create Employee

User Story: As an HR user, I want to create a new employee record with name, badgeId, role, department, shiftGroup, hireDate, and status so that employee data is accurately captured.

Acceptance Criteria:

Scenario: Create employee with valid data
Given I am authenticated as HR
When I POST to /employees with valid employee data
Then a new employee record is created and returned

Scenario: Duplicate badgeId is rejected
Given an employee with badgeId "12345" exists
When I POST a new employee with badgeId "12345"
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: badgeId must be unique; OpenAPI schema required.
