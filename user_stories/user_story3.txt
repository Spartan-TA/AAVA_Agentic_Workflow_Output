Title: Set Up Database Migration Tool

User Story: As a System Administrator I want to set up Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable across environments

Acceptance Criteria:

Scenario: Baseline migration runs
Given Flyway or Liquibase is configured in the project
When I start the application for the first time
Then the baseline migration should execute and create the initial schema

Scenario: Migration history tracked
Given multiple migrations are applied
When I query the migration history table
Then I should see all applied migrations with timestamps

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Document migration process in README.
