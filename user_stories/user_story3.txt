Title: Database Migration Setup with Flyway/Liquibase
User Story: As a backend developer I want automated database migration scripts configured So that database schema changes are versioned and applied consistently across environments
Acceptance Criteria:
Scenario: Baseline migration runs on application startup
Given a clean database
When I start the application
Then Flyway or Liquibase should apply the baseline migration and the schema should match the initial model

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Migration scripts must be idempotent and documented in the README.
