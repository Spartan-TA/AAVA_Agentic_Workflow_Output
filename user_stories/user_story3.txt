Title: Employee Creation and Retrieval API

User Story: As an HR manager I want to create and retrieve employee records via API so that I can maintain an accurate and accessible employee master data set.

Acceptance Criteria:
Scenario: Create employee
  Given I have valid employee details (name, badgeId, role, department, shiftGroup, hireDate, status)
  When I POST to /employees
  Then a new employee record is created and returned with a unique badgeId

Scenario: Retrieve employee
  Given employee records exist
  When I GET /employees/{id}
  Then the correct employee details are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: badgeId must be unique; API must validate required fields; OpenAPI schema must be provided with examples.
