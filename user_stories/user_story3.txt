Title: Role-Based Access Control (RBAC) - Role Setup
User Story: As an admin, I want to define roles (ADMIN, HR, SUPERVISOR, WORKER) so that access can be restricted appropriately.
Acceptance Criteria:
Scenario: Roles exist
  Given the system is running
  When I check the roles
  Then ADMIN, HR, SUPERVISOR, and WORKER roles are available
Additional Details:
Priority: High
Story Points: 2
Dependencies: E01, E02
Notes: Use Spring Security.

Title: Role-Based Access Control (RBAC) - Endpoint Security
User Story: As a system, I want to restrict endpoints and methods by role so that only authorized users can perform sensitive actions.
Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without required role
  When they access a protected endpoint
  Then the system returns 401 or 403 as appropriate
Additional Details:
Priority: High
Story Points: 3
Dependencies: E01, E02
Notes: Cover all sensitive endpoints.
