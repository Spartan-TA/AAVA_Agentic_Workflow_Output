Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Actuator health endpoint so that I can monitor the application's health status in production

Acceptance Criteria:
Scenario: Health endpoint available
  Given the application is running
  When I access /actuator/health
  Then the endpoint returns status UP if all checks pass

Scenario: Health endpoint failure
  Given a required dependency is down
  When I access /actuator/health
  Then the endpoint returns status DOWN with details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure endpoint is secured and documented in README.
