Title: Enable Actuator Health Endpoint

User Story: As a developer I want to enable the Actuator health endpoint So that I can monitor the application's health status and ensure it is running correctly

Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access the /actuator/health endpoint
Then the response status is UP and includes basic health information

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Endpoint must be accessible on port 8080; health status should reflect DB connectivity
