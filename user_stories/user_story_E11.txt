### E11 - Payroll Export Integration

#### User Story 1
Title: Generate Payroll-Ready Export
User Story: As an HR, I want to generate payroll-ready files from attendance and leave so that payroll runs are accurate.
Acceptance Criteria:
Scenario: Payroll Export
Given approved attendance and leave
When HR requests export
Then file matches provider schema
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Mapping required

#### User Story 2
Title: Secure Delivery of Payroll Files
User Story: As a DevOps Engineer, I want to deliver payroll files securely via SFTP/API so that sensitive data is protected.
Acceptance Criteria:
Scenario: Secure Delivery
Given a payroll file
When delivery is initiated
Then file is sent securely
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Audit log for every export

#### User Story 3
Title: Retry Failed Payroll Deliveries
User Story: As an ADMIN, I want failed payroll deliveries retried with backoff so that no data is lost.
Acceptance Criteria:
Scenario: Delivery Retry
Given a failed delivery
When retry logic triggers
Then delivery is retried with backoff
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E04, E06
- Notes: Retries logged

#### User Story 4
Title: Reconcile Payroll Totals
User Story: As an HR, I want payroll totals to reconcile with attendance and leave reports so that errors are minimized.
Acceptance Criteria:
Scenario: Reconciliation

When HR compares with reports
Then totals match
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E04, E06
- Notes: Reconciliation report
