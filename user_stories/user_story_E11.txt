### E11: Payroll Export Integration

**User Story 1: Generate Payroll Export Files**
- User Story: As a payroll admin, I want to generate payroll-ready files from attendance and leave data So that payroll processing is automated.
- Acceptance Criteria:
  - Scenario: Generate export
    - Given approved attendance and leave
    - When I generate the export
    - Then the file matches the provider schema and totals reconcile with reports
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: SFTP/API delivery.

**User Story 2: Export Delivery and Audit Logging**
- User Story: As a payroll admin, I want exports delivered securely and failures retried with audit logs So that payroll data is reliably transmitted.
- Acceptance Criteria:
  - Scenario: Successful delivery
    - Given a generated export
    - When I send it to the provider
    - Then delivery status is tracked and logged
  - Scenario: Failed delivery
    - Given a failed attempt
    - When the system retries
    - Then backoff is applied and all attempts are logged
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Audit log for every export.
