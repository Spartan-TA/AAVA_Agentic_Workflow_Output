### E11 - Payroll Export Integration

**User Story 1**
- Title: Generate Payroll-Ready Export Files
- User Story: As a payroll manager, I want to generate payroll-ready files from attendance and leave so that payroll runs are accurate.
- Acceptance Criteria:
  - Given attendance and leave data exists,
    When I generate an export,
    Then the file matches provider schema.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E04, E06, Notes: Payroll integration.

**User Story 2**
- Title: Map Data to External Provider Formats
- User Story: As a payroll manager, I want data mapped to external provider formats so that integration is seamless.
- Acceptance Criteria:
  - Given provider schema is defined,
    When I export data,
    Then mapping rules are applied.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E04, E06, Notes: Format compliance.

**User Story 3**
- Title: Secure Delivery via SFTP/API
- User Story: As a payroll manager, I want secure delivery of payroll files via SFTP/API so that sensitive data is protected.
- Acceptance Criteria:
  - Given an export file is generated,
    When I deliver via SFTP/API,
    Then the transfer is encrypted and logged.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E04, E06, Notes: Security.

**User Story 4**
- Title: Retry Failed Deliveries with Backoff
- User Story: As a payroll manager, I want failed deliveries retried with backoff so that exports are reliably delivered.
- Acceptance Criteria:
  - Given a delivery fails,
    When retry logic is triggered,
    Then retries occur with increasing delay until success or max attempts.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E04, E06, Notes: Reliability.

**User Story 5**
- Title: Audit Log for Every Export
- User Story: As a compliance officer, I want an audit log for every payroll export so that delivery history is traceable.
- Acceptance Criteria:
  - Given exports occur,
    When I view the audit log,
    Then every export event is recorded with timestamp and status.
- Additional Details: Priority: High, Story Points: 1, Dependencies: E04, E06, Notes: Compliance.
