### E11 - Payroll Export Integration

**User Story 1: Generate Payroll Files from Attendance and Leave**
- Title: Generate Payroll Export Files
- Narrative: As a payroll admin, I want to generate payroll files from attendance and leave so that payroll runs are automated.
- Acceptance Criteria:
  ```
  Given attendance and leave data,
  When I generate payroll files,
  Then files match provider schema and totals reconcile.
  ```
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Payroll automation.

**User Story 2: Map to External Provider Formats**
- Title: Map Payroll Data to Provider Formats
- Narrative: As a payroll admin, I want payroll data mapped to provider formats so that integration is seamless.
- Acceptance Criteria:
  ```
  Given provider requirements,
  When mapping payroll data,
  Then files conform to required formats.
  ```
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Integration.

**User Story 3: Secure Delivery via SFTP/API**
- Title: Secure Payroll File Delivery
- Narrative: As a payroll admin, I want payroll files delivered securely via SFTP or API so that data is protected.
- Acceptance Criteria:
  ```
  Given a payroll file,
  When delivered,
  Then transfer is secure and logged.
  ```
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Security.

**User Story 4: Retry Logic for Failed Deliveries**
- Title: Retry Failed Payroll Deliveries
- Narrative: As a payroll admin, I want failed deliveries retried with backoff so that files are not lost.
- Acceptance Criteria:
  ```
  Given a failed delivery,
  When retried,
  Then backoff logic is applied and success/failure is logged.
  ```
- Priority: High
- Story Points: 1
- Dependencies: Story 3
- Notes: Reliability.

**User Story 5: Audit Log for Payroll Exports**
- Title: Audit Payroll Export Events
- Narrative: As an auditor, I want an audit log for every payroll export so that compliance is maintained.
- Acceptance Criteria:
  ```
  Given a payroll export,
  When completed,
  Then an audit entry is created with details.
  ```
- Priority: High
- Story Points: 1
- Dependencies: Story 1
- Notes: Compliance.
