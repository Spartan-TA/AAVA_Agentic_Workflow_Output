### E11 - Payroll Export Integration

**User Story 1**
Title: Generate Payroll-Ready Files
User Story: As a Payroll Specialist I want to generate payroll-ready files from attendance and leave So that payroll runs are accurate.
Acceptance Criteria:
Scenario: Payroll File Generation
Given approved attendance and leave
When I export payroll files
Then files match provider schema

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Schema mapping required

**User Story 2**
Title: Secure Delivery via SFTP/API
User Story: As a DevOps Engineer I want to deliver payroll files securely via SFTP/API So that sensitive data is protected.
Acceptance Criteria:
Scenario: Secure Delivery
Given payroll files
When I send via SFTP/API
Then delivery is secure and logged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Audit log required

**User Story 3**
Title: Delivery Retry with Backoff
User Story: As a Payroll Specialist I want failed deliveries retried with backoff So that payroll files are not lost.
Acceptance Criteria:
Scenario: Delivery Retry
Given a failed delivery
When retry logic triggers
Then delivery is retried with backoff

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 2
- Notes: Configurable retry intervals

**User Story 4**
Title: Audit Log for Payroll Exports
User Story: As an ADMIN I want an audit log for every payroll export So that all actions are traceable.
Acceptance Criteria:
Scenario: Audit Logging
Given payroll exports
When exports occur
Then audit log records actor, timestamp, and status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Export history visible
