===========================================

Title: Implement CI pipeline for build and test
User Story: As a developer, I want an automated pipeline to build and test code so that changes are validated before deployment.
Acceptance Criteria:
Scenario: Automated build and test
  Given code is pushed to the repository
  When the pipeline runs
  Then the project is built and all tests are executed automatically

Additional Details:
Priority: High
Story Points: 3
Dependencies: E01
Notes: Fails on test or build errors.

---

Title: Integrate security scanning into CI pipeline
User Story: As a security engineer, I want security scans to run automatically so that vulnerabilities are detected early.
Acceptance Criteria:
Scenario: Security scanning
  Given code is built in CI
  When the pipeline runs
  Then security scans are executed and results reported

Additional Details:
Priority: High
Story Points: 2
Dependencies: E01
Notes: OWASP, Snyk, or similar.

---

Title: Build and push Docker images automatically
User Story: As a DevOps engineer, I want Docker images built and pushed to the registry so that deployments are consistent.
Acceptance Criteria:
Scenario: Docker image build
  Given a successful build
  When the pipeline completes
  Then a Docker image is built and pushed to the configured registry

Additional Details:
Priority: High
Story Points: 2
Dependencies: E01
Notes: Tags include commit SHA.

---

Title: Automated deployment to staging and production environments
User Story: As a release manager, I want deployments to staging and production to be automated so that releases are reliable and repeatable.
Acceptance Criteria:
Scenario: Automated deployment
  Given a new image is available
  When the deployment pipeline runs
  Then the application is deployed to staging or production with status reported

Additional Details:
Priority: High
Story Points: 3
Dependencies: E01
Notes: Supports rollback on failure.

END OF ALL USER STORIES (E01-E20)
