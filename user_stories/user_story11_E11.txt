### E11 - Payroll Export Integration

#### User Story 1: Generate Payroll-Ready Export Files
- **Title:** Generate Payroll-Ready Export Files
- **User Story:** As a PAYROLL ADMIN, I want to generate payroll files from attendance and leave data so that payroll processing is automated.
- **Acceptance Criteria:**
    - Given approved attendance and leave,
      When I generate an export,
      Then the file matches the provider schema.
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E04, E06
- **Notes:** Schema mapping.

#### User Story 2: Secure Delivery of Payroll Files
- **Title:** Secure Delivery of Payroll Files
- **User Story:** As a SYSTEM, I want to securely deliver payroll files via SFTP or API so that sensitive data is protected.
- **Acceptance Criteria:**
    - Given a payroll file,
      When I deliver it,
      Then it is sent via secure channel and delivery status is logged.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E11-1
- **Notes:** Security compliance.

#### User Story 3: Retry Failed Deliveries with Backoff
- **Title:** Retry Failed Payroll File Deliveries
- **User Story:** As a SYSTEM, I want to retry failed payroll file deliveries with exponential backoff so that files are eventually delivered.
- **Acceptance Criteria:**
    - Given a failed delivery,
      When a retry is triggered,
      Then the system retries with increasing intervals until success or max attempts.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E11-2
- **Notes:** Reliability.

#### User Story 4: Audit Log for Payroll Exports
- **Title:** Audit Log for Payroll Exports
- **User Story:** As an ADMIN, I want an audit log for every payroll export so that I can trace all actions.
- **Acceptance Criteria:**
    - Given a payroll export,
      When it is generated and delivered,
      Then an audit entry is created with timestamp, user, and status.
- **Priority:** High
- **Story Points:** 1
- **Dependencies:** E11-1
- **Notes:** Compliance.

#### User Story 5: Reconcile Payroll Totals with Reports
- **Title:** Reconcile Payroll Totals with Attendance Reports
- **User Story:** As a PAYROLL ADMIN, I want to reconcile payroll export totals with attendance and leave reports so that errors are detected.
- **Acceptance Criteria:**
    - Given a payroll export,
      When I compare totals,
      Then discrepancies are flagged for review.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E11-1, E04, E06
- **Notes:** Data integrity.
