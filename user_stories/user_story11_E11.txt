### E11 - Payroll Export Integration

**Title:** Payroll File Generation
User Story: As a payroll manager I want to generate payroll-ready files from attendance and leave So that payroll runs are accurate
Acceptance Criteria:
Scenario: Generate payroll file
Given approved attendance and leave
When I request export
Then the file matches provider schema
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: Secure delivery required

---

**Title:** Provider Format Mapping
User Story: As a developer I want to map EMS data to external payroll formats So that integration is seamless
Acceptance Criteria:
Scenario: Map fields
Given EMS data
When I export
Then fields match provider requirements
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Mapping documented

---

**Title:** Secure Delivery via SFTP/API
User Story: As a payroll manager I want payroll files delivered securely So that sensitive data is protected
Acceptance Criteria:
Scenario: SFTP delivery
Given a payroll file
When I send via SFTP
Then delivery is logged and retried on failure
Scenario: API delivery
Given a payroll file
When I send via API
Then delivery status is tracked
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Audit log for every export

---

**Title:** Export Audit Logging
User Story: As a compliance officer I want audit logs for payroll exports So that every export is traceable
Acceptance Criteria:
Scenario: Log export
Given a payroll export
When it is delivered
Then actor, timestamp, and status are logged
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Required for audit/compliance
