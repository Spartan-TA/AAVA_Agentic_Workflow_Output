Title: Shift Management - Create Shift Template

User Story: As an HR user I want to create recurring shift templates So that scheduling is efficient

Acceptance Criteria:
Scenario: Create shift template
Given valid shift details
When I POST to /shifts/templates
Then a new template is created and available for assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Supports rotations and blackout dates

Title: Shift Management - Audit Scheduling Changes

User Story: As an auditor I want all shift assignments and changes to be logged So that I can review scheduling history

Acceptance Criteria:
Scenario: Audit log for scheduling
Given any shift assignment or change
When the action occurs
Then an audit entry is generated with actor, timestamp, and before/after state

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Immutable audit log
