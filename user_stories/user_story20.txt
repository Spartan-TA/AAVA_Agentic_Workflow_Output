Title: Certification Assignment Blocking
User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that only qualified staff are assigned
Acceptance Criteria:
Scenario: Assignment blocking for expired certs
Given an employee's certification is expired
When I attempt to assign them to a restricted task
Then the system blocks the assignment and displays an error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification CRUD
- Notes: Status visible on employee profile
