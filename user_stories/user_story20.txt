Title: Workers View Personal Upcoming Shifts

User Story:
As a warehouse worker, I want to view my upcoming assigned shifts so that I can plan my attendance and availability.

Acceptance Criteria:
- Scenario: Worker views upcoming shifts
  Given a worker is authenticated
  When they access their schedule
  Then only their assigned future shifts are displayed

- Scenario: Shift changes are reflected in real time
  Given a shift is updated or reassigned
  When the worker refreshes their schedule
  Then the latest assignments are shown

Additional Details:
- Workers must not see other employees' shifts
- Shifts must include date, time, location, and role
- UI must be mobile-friendly
