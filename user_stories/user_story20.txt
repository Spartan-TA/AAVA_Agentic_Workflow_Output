Title: Audit Trail & Compliance

User Story: As a compliance officer I want to view immutable audit logs of sensitive changes So that regulatory and forensic requirements are met

Acceptance Criteria:
Scenario: Audit log entry
Given a create, update, or delete action occurs on sensitive data
When the action is performed
Then an audit log entry is created with actor, timestamp, before/after values

Scenario: Export audit logs
Given I need to review changes for a specific date or user
When I export audit logs
Then the system provides a tamper-evident file

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: RBAC
- Notes: Immutable log table; export by date/user/entity; tests validate coverage
