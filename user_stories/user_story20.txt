Title: Certification Expiry Alerts and Scheduling Checks

User Story: As a supervisor, I want to receive alerts for expiring certifications and prevent assignment to unqualified employees so that safety is ensured.

Acceptance Criteria:

Scenario: Expiry alerts sent
Given a certification expiring in 30 or 7 days
When detected
Then an alert is sent to the employee and supervisor

Scenario: Block unqualified assignment
Given a task requiring certification
When the employee's cert is expired
Then assignment is blocked

Scenario: View certification status
Given the employee profile
When viewed
Then certification status is visible

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E07
- Notes: Scheduling integration
