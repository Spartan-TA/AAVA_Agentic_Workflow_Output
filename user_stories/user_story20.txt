Title: CSV Export of Attendance Records

User Story: As a payroll administrator I want to export attendance records as CSV files So that I can process payroll and perform compliance audits efficiently

Acceptance Criteria:
Scenario: Successful export
  Given I have access to the attendance module
  When I request a CSV export for a date range
  Then the system generates a CSV file with all relevant attendance data
Scenario: Filtered export
  Given I specify filters (employee, department, shift)
  When I request a CSV export
  Then only matching records are included in the file
Scenario: Export error
  Given the export process fails
  When I request a CSV export
  Then I receive an error message with troubleshooting steps

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export should include all clock-in/out events, corrections, and calculated hours.
