### E20 - CI/CD & Deployment Automation

**User Story 1**
Title: Implement CI/CD Pipeline for Build and Test
User Story: As a developer I want a CI/CD pipeline to build and test the project on every PR So that code quality is maintained.
Acceptance Criteria:
Scenario: Pipeline runs on PR
Given a PR is opened
When the pipeline runs
Then all builds and tests pass before merge
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Use GitHub Actions or Jenkins

**User Story 2**
Title: Build and Push Docker Images with Commit SHA
User Story: As a DevOps engineer I want Docker images built and tagged with commit SHA So that deployments are traceable.
Acceptance Criteria:
Scenario: Docker image build
Given a commit is pushed
When the pipeline runs
Then a Docker image is built and tagged with the commit SHA
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E20-1
- Notes: Push to container registry

**User Story 3**
Title: Deploy to Staging Automatically
User Story: As a DevOps engineer I want deployments to staging to happen automatically after successful builds So that testing environments are always up to date.
Acceptance Criteria:
Scenario: Staging deployment
Given a build passes
When the pipeline completes
Then the app is deployed to staging
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E20-2
- Notes: Use environment variables for config

**User Story 4**

- Priority: High

- Priority: High
