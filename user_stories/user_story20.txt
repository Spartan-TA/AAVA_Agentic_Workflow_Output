Title: Personal Shift Visibility

User Story: As an employee I want to view my assigned shifts So that I can plan my work and personal schedule accordingly

Acceptance Criteria:
Scenario: View assigned shifts
  Given I am authenticated
  When I access my schedule page
  Then I should see all my upcoming and past shift assignments
Scenario: Filter shifts by date
  Given I am on my schedule page
  When I apply a date filter
  Then only shifts within the selected range should be displayed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Scheduling module
- Notes: Support for mobile and web clients
