### E20 - Continuous Deployment & Monitoring

**Title:** Automated Build & Deploy Pipeline
**User Story:** As a DevOps engineer, I want automated CI/CD pipelines so that deployments are consistent and reliable.
**Acceptance Criteria:**
Scenario: CI/CD pipeline
Given code is pushed
When the pipeline runs
Then the application is built, tested, and deployed automatically
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E01, Notes: Pipeline status visible in dashboard.

**Title:** Application Monitoring & Alerts
**User Story:** As a DevOps engineer, I want application monitoring and alerts so that issues are detected early.
**Acceptance Criteria:**
Scenario: Monitoring setup
Given the application is running
When an error occurs
Then an alert is sent to the team
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E01, Notes: Integrate with monitoring tools.
