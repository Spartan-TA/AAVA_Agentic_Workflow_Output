Title: Centralized Audit Logging
User Story: As a compliance officer I want all sensitive changes to be logged centrally so that audit requirements are met
Acceptance Criteria:
Scenario: Audit log creation
Given a sensitive change occurs
When the change is made
Then an audit log entry is created with actor, timestamp, and before/after values
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Covers employee PII, schedules, approvals, payroll
