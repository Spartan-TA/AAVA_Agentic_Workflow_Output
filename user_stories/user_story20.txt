Title: Support Localization for UI and Notifications

User Story: As a warehouse worker I want the UI and notifications to be available in my preferred language so that I can understand all system messages

Acceptance Criteria:
Scenario: Changing language preference
Given I am logged in
When I select a different language
Then all UI elements and notifications are displayed in that language

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Notification module
- Notes: Templates must be localized

Title: Enable Multi-Tenant Support for Multiple Warehouses

User Story: As a system administrator I want to enable multi-tenant support so that multiple warehouses can operate independently within the same system

Acceptance Criteria:
Scenario: Creating a new tenant
Given I am logged in as administrator
When I create a new tenant for a warehouse
Then data and configuration are isolated for that tenant

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Tenants must not share data

Scenario: Accessing tenant data

Then I see only records for my warehouse

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Multi-tenant support, RBAC
