Title: Block Asset Use if Certification Missing and Maintain Asset Condition State

User Story: As a warehouse supervisor I want the system to block asset check-out if the required certification is missing and track asset condition So that only qualified employees use equipment and asset health is monitored

Acceptance Criteria:
Scenario: Certification check on asset check-out
Given an employee attempts to check out an asset requiring certification
When their certification is expired or missing
Then the system blocks the check-out and notifies the employee and supervisor

Scenario: Update asset condition
Given an asset is returned
When I record its condition (e.g., good, damaged, needs repair)
Then the system updates the asset's status and logs the event

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E07
- Notes: Certification checks must be enforced for all regulated equipment; condition history must be auditable.
