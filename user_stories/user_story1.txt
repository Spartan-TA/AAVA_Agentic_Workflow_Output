Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize the Spring Boot project with standardized base modules So that all teams can build features on a consistent foundation

Acceptance Criteria:
Scenario: Project scaffolding and health check
  Given a clean repository
  When I run the build and start the application
  Then the application should run on port 8080 and the Actuator health endpoint should return UP
Scenario: Database migration setup
  Given the project is initialized
  When I run Flyway or Liquibase migrations
  Then the baseline migration should execute successfully and create the initial schema
Scenario: Documentation
  Given the project repository
  When I open the README file
  Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Base package structure must be created; ensure Actuator and migration tools are enabled
