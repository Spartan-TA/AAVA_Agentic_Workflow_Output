EPIC E01: Project Scaffolding & Domain Setup

User Story 1:
Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to initialize the Spring Boot project with standardized base modules so that future development is consistent and maintainable.
Acceptance Criteria in Gherkin:
Scenario: Project initialization
  Given a new repository
  When I run the build and start the application
  Then the application runs on port 8080 and the base package structure is present
Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: None
  Notes: Ensure README includes build/run steps

User Story 2:
Title: Database Migration Setup with Flyway/Liquibase
User Story: As a developer, I want to configure Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable.
Acceptance Criteria in Gherkin:
Scenario: Database migration baseline
  Given a configured migration tool
  When I start the application
  Then the baseline migration runs successfully and the database schema is created
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: None
  Notes: Choose Flyway or Liquibase per team preference
