Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules and database migration tools so that we have a standardized foundation to accelerate delivery and enforce consistency across modules

Acceptance Criteria:

Scenario: Successful project scaffolding
Given I have cloned the repository
When I build and run the project
Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
Given the project is running
When I check the database
Then Flyway/Liquibase should have run the baseline migration

Scenario: Documentation
Given I am a new developer
When I open the README
Then I should see clear build and run steps

Scenario: Package structure
Given the project is initialized
When I browse the source code
Then I should see base package structure for employee, scheduling, attendance, and safety modules

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure Actuator is enabled and accessible; README must be up-to-date with all steps; Migration tool must be configurable.
