Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot project with standardized base modules So that all future development is consistent and maintainable

Acceptance Criteria:
Scenario: Successful project initialization
Given I have access to the project repository
When I run the build and start the application
Then the application should run on port 8080 and the base package structure should be present

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps; Actuator health endpoint should return UP; Flyway/Liquibase baseline migration should execute
