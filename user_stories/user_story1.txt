Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a standardized Spring Boot (Maven) project with core modules and database migration tools so that all teams can accelerate delivery and maintain consistency across modules.

Acceptance Criteria:
Scenario: Project setup and verification
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration
  Given the project is started
  When Flyway or Liquibase is enabled
  Then the baseline migration should run successfully and the database schema should be initialized

Scenario: Documentation
  Given the repository is initialized
  When I open the README file
  Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
