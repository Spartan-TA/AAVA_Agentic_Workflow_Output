Title: Initialize Spring Boot Project and Base Package Structure

User Story: As a developer I want to initialize a Spring Boot (Maven) project and configure the base package structure so that the team has a standardized foundation for all modules.

Acceptance Criteria:
Scenario: Project scaffolding and structure
  Given I have access to the project repository
  When I run the build and start the application
  Then the application should run on port 8080 and the base package structure should be present

Additional Details:

- Dependencies: None
