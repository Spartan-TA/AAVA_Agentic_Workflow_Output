Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot (Maven) project with base packages and core modules so that the team has a standardized foundation for further development.

Acceptance Criteria:
Scenario: Project scaffolding and setup
  Given I have cloned the repository
  When I build and run the project on port 8080
  Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration setup
  Given the project is initialized
  When I run Flyway/Liquibase migrations
  Then the baseline migration completes without errors

Scenario: Documentation
  Given the project is set up
  When I open the README file
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Base package structure must be created; Actuator must be enabled for health checks; Flyway/Liquibase must be configured for DB migrations.
