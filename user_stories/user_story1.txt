Title: Initialize Warehouse Employee Management Project Foundation

User Story:
As a developer, I want to initialize a Spring Boot Maven project with standardized base packages and core modules (employee, scheduling, attendance, safety), including database migration tools and health monitoring, so that the team can rapidly and consistently build new features on a robust foundation.

Acceptance Criteria (Gherkin):
Given a new project repository,
When I run the build and start the application,
Then the application should start on port 8080,
And the Actuator health endpoint at /actuator/health should return status "UP".

Given the project repository,
When I inspect the directory structure,
Then I should see base packages for employee, scheduling, attendance, and safety modules.

Given the project is started,
When I check the database,
Then Flyway or Liquibase should have applied the baseline migration successfully.

Given the project repository,
When I open the README file,
Then I should see clear build and run instructions.

Additional Details:
Priority: High
Story Points: 5
Dependencies: None
Notes: Foundation for all subsequent stories; must be CI-ready.
