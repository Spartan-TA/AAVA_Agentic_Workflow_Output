Epic: E01 - Project Scaffolding & Domain Setup

User Story 1: Project Initialization
Title: Initialize Spring Boot Project
User Story: As a developer, I want to initialize a Spring Boot project with Maven so that the codebase is standardized and easy to maintain.
Acceptance Criteria (Gherkin):
Given the repository is cloned,
When I run 'mvn clean install',
Then the project builds successfully and runs on port 8080.
And the README contains build and run instructions.
Additional Details:
Priority: High
Story Points: 3
Dependencies: None
Notes: Foundation for all modules.

User Story 2: Core Module Setup
Title: Configure Base Packages and Core Modules
User Story: As a developer, I want to set up base packages and core modules (employee, scheduling, attendance, safety) so that future features are organized and scalable.
Acceptance Criteria (Gherkin):
Given the project structure,
When I inspect the codebase,
Then base packages for employee, scheduling, attendance, and safety exist.
And each module has a placeholder class.
Additional Details:
Priority: High
Story Points: 2
Dependencies: Project Initialization
Notes: Ensures modularity.

User Story 3: Database Migration Tool Integration
Title: Integrate Flyway/Liquibase for DB Migrations
User Story: As a developer, I want to integrate Flyway/Liquibase so that database migrations are automated and version-controlled.
Acceptance Criteria (Gherkin):
Given the project is running,
When I trigger a migration,
Then Flyway/Liquibase applies the baseline migration successfully.
And migration history is tracked.
Additional Details:
Priority: High
Story Points: 2
Dependencies: Project Initialization
Notes: Enables DB schema evolution.

User Story 4: Actuator Health Endpoint
Title: Enable Spring Boot Actuator
User Story: As a DevOps engineer, I want to enable Actuator so that I can monitor application health.
Acceptance Criteria (Gherkin):
Given the application is running,
When I access '/actuator/health',
Then the endpoint returns status 'UP'.
Additional Details:
Priority: High
Story Points: 1
Dependencies: Project Initialization
Notes: Required for production monitoring.
