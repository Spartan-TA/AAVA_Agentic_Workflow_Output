Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot project with core modules and database migration tools so that we have a standardized foundation for all future development.

Acceptance Criteria:
Scenario: Successful project scaffolding
Given I have cloned the repository
When I build and run the project
Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration setup
Given the base package structure is created
When I run Flyway/Liquibase
Then baseline migration is applied successfully

Scenario: Documentation
Given the project is initialized
When I check the README
Then build and run steps are clearly documented

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are scaffolded; Actuator enabled for health checks.
