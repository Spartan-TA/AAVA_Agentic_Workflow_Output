===========================================

User Story 1: Initialize Spring Boot Project
---------------------------------------------
Title: Initialize Spring Boot (Maven) Project

User Story: As a developer, I want to initialize a Spring Boot project using Maven so that the EMS application has a standardized foundation.

Acceptance Criteria:
Scenario: Successful project initialization
  Given a new repository
  When I run the Maven build
  Then the project builds successfully and runs on port 8080

Scenario: Health endpoint verification
  Given the project setup
  When I access the Actuator health endpoint
  Then it returns UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure README includes build/run steps.
