Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project and configure base packages So that we have a standardized foundation to accelerate delivery and enforce consistency across modules

Acceptance Criteria:
Scenario: Project Initialization
Given I have access to the repository
When I build and run the project on port 8080
Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database Migration Setup
Given the project is initialized
When I run Flyway/Liquibase migrations
Then the baseline migration completes without errors

Scenario: Documentation
Given the project is set up
When I view the README
Then I see clear build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
