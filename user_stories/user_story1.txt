Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot (Maven) project and configure base packages So that we have a standardized foundation for all modules and can accelerate delivery.

Acceptance Criteria:
Scenario: Project initialization
Given I have access to the repository
When I build and run the project
Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
Given the project is initialized
When I run Flyway/Liquibase migrations
Then the baseline migration should be applied successfully

Scenario: Documentation
Given the project is set up
When I view the README
Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
