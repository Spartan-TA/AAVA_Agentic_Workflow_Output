Title: Initialize Spring Boot Project

User Story: As a System Administrator I want to initialize a Spring Boot project with Maven So that I can provide a standardized foundation for all EMS modules

Acceptance Criteria:

Scenario: Project builds and runs
Given the project is initialized with Spring Boot and Maven
When I execute the build and run commands
Then the application should start successfully on port 8080

Scenario: Health endpoint returns UP
Given the application is running
When I access the Actuator health endpoint
Then I should receive a response indicating status UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build and run steps.
