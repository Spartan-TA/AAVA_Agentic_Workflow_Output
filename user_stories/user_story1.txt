Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot project with Maven and base package structure so that all modules have a consistent foundation for development

Acceptance Criteria:
Scenario: Project scaffolding
  Given I have cloned the repository
  When I run the build command
  Then the project should build successfully and run on port 8080

Scenario: Base package structure
  Given the project is initialized
  When I inspect the source code
  Then I should see core modules for employee, scheduling, attendance, and safety

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Follow standard Java package conventions; include README with build/run steps.
