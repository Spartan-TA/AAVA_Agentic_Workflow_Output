Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot project with core modules and database migration tools so that the foundation is standardized and ready for rapid feature delivery.

Acceptance Criteria:
Scenario: Successful project setup
Given I have cloned the repository
When I build and run the project
Then the application starts on port 8080 and the Actuator health endpoint returns UP
And the base package structure is present
And Flyway/Liquibase runs the baseline migration
And the README contains build/run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are present; Actuator and DB migration must be enabled.
