Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot project with standardized base packages and core modules So that future development is consistent and efficient across all warehouse management features

Acceptance Criteria:
Scenario: Successful project scaffolding
Given I have access to the repository
When I build and run the project on port 8080
Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration setup
Given the project is initialized
When Flyway or Liquibase runs
Then baseline migration is applied without errors

Scenario: Documentation
Given the project is set up
When I open the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
