Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot project with core modules and standardized configurations so that future development is consistent and efficient.

Acceptance Criteria:
Scenario: Successful project scaffolding
Given I have cloned the repository
When I build and run the project on port 8080
Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration setup
Given the project is running
When I execute Flyway/Liquibase migrations
Then the baseline migration completes without errors

Scenario: Documentation
Given the repository contains a README
When I view the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and core modules (employee, scheduling, attendance, safety) are present.
