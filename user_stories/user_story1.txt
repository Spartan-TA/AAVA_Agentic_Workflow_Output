Title: User Registration

User Story: As a new user I want to register for an account using my email and password So that I can access the platform securely

Acceptance Criteria:
Scenario: Successful registration
  Given I am on the registration page
  When I enter a valid email and password and submit the form
  Then a verification email should be sent to my email address
  And my account should be created but not activated until verification

Scenario: Email verification
  Given I have received a verification email
  When I click the verification link
  Then my account should be activated and I may be auto-logged in

Scenario: Invalid email format
  Given I am on the registration page
  When I enter an invalid email format
  Then I should see an error message indicating the email format is invalid

Scenario: Password requirements
  Given I am on the registration page
  When I enter a password less than 8 characters
  Then I should see an error message indicating password requirements

Scenario: Duplicate email
  Given I am on the registration page
  When I enter an email already registered
  Then I should see an error message indicating the email is already in use

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Authentication module, Email service (SendGrid), Frontend registration form
- Notes: Backend is Java Spring Boot, Frontend is React 19, Database is MySQL, Authentication is JWT, Passwords must be stored using bcrypt, Email must be sent within 3 seconds, Uptime for auth system must be 99.9%.
