Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project with core modules and database migration tools so that all teams can build features consistently and efficiently.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project on port 8080
  Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration setup
  Given the project is built
  When I run the application
  Then Flyway/Liquibase baseline migration is executed and the database schema is initialized

Scenario: Documentation
  Given I access the repository
  When I open the README
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
