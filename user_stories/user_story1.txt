Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to initialize a standardized Spring Boot project structure so that all modules follow a consistent architecture and onboarding is faster.
Acceptance Criteria:
  - Given a new repository, when I run the build, then the project compiles and runs on port 8080.
  - Given the repository, when I open the README, then I see clear build and run instructions.
Additional Details:
  - Priority: High
  - Story Points: 3
  - Dependencies: None
  - Notes: Base for all other modules.
