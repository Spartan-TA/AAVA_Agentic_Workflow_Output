Title: Project Initialization and Health Check

User Story: As a developer I want to initialize the Spring Boot project with standardized base packages and modules So that all teams can build on a consistent foundation.

Acceptance Criteria:
Scenario: Project scaffolding and health endpoint
Given the project is initialized with Maven and core modules
When I build and run the application
Then the server starts on port 8080 and the Actuator health endpoint returns UP

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps; base package structure must be present.

- Priority: High
