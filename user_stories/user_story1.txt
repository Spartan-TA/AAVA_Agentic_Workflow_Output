Title: Initialize Spring Boot Project Scaffolding

User Story: As a backend developer I want to initialize a Spring Boot (Maven) project with base packages and core modules So that the team has a standardized foundation for rapid and consistent delivery.

Acceptance Criteria:
Scenario: Project scaffolding setup
  Given a new repository
  When I run the build and start the application
  Then the project should build and run on port 8080
  And the base package structure should be created
  And the README should contain build/run steps

Scenario: Actuator health endpoint
  Given the application is running
  When I access the /actuator/health endpoint
  Then the response should be 'UP'

Scenario: Database migration baseline
  Given Flyway or Liquibase is configured
  When I start the application
  Then the baseline migration should run successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are included in initial scaffolding.
