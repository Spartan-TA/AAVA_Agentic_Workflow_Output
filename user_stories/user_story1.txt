Title: Initialize Spring Boot Project Structure

User Story: As a developer, I want to initialize a Spring Boot project with standardized base modules so that all teams can build features consistently and efficiently.

Acceptance Criteria:

Scenario: Project builds and runs on port 8080
  Given the project is cloned from the repository
  When I run the build and start the application
  Then the application starts successfully on port 8080

Scenario: Actuator health endpoint returns UP
  Given the application is running
  When I access /actuator/health
  Then the response status is UP

Scenario: Base package structure created
  Given the project is initialized
  When I inspect the source code
  Then the base packages for employee, scheduling, attendance, and safety modules exist

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps
