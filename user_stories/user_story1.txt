Title: Initialize Spring Boot Project Scaffolding

User Story: As a software engineer I want to initialize a Spring Boot project with base modules So that the Warehouse EMS has a robust and scalable foundation

Acceptance Criteria:

Scenario: Project initialization
Given I have access to the project repository
When I run the project initialization script
Then the Spring Boot project is created with base modules, Flyway/Liquibase migrations, and Actuator enabled

Scenario: Module verification
Given the project is initialized
When I inspect the modules
Then I should see Flyway/Liquibase and Actuator configured

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all base modules are included and properly configured
