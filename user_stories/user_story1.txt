Title: Initialize Project Scaffolding

User Story: As a developer I want to initialize the Spring Boot project with standardized base packages and core modules so that the team has a consistent and maintainable foundation for further development

Acceptance Criteria:
Scenario: Project scaffolding setup
  Given I have cloned the repository
  When I run the build and start the application
  Then the project should build successfully and run on port 8080
  And the base package structure should be present
  And the Actuator health endpoint should return UP
  And Flyway/Liquibase should run the baseline migration
  And the README should contain build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: This story covers only the initial scaffolding, not feature implementation.
