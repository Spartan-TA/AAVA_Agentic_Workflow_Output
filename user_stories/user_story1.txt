Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules and database migration tools so that the team has a standardized foundation for rapid and consistent delivery.

Acceptance Criteria:
Scenario: Successful project scaffolding
Given I have access to the project repository
When I build and run the project on port 8080
Then the application starts successfully and the Actuator health endpoint returns UP
And the base package structure is created
And Flyway/Liquibase runs baseline migration
And the README contains build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are present; verify DB migration tool is configured.
