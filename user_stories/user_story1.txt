Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules So that the EMS foundation is standardized and ready for feature development

Acceptance Criteria:
Scenario: Project scaffolding
  Given I have access to the repository
  When I run the build command
  Then the project should build successfully and run on port 8080
Scenario: Health endpoint
  Given the application is running
  When I access the /actuator/health endpoint
  Then I should receive a response with status UP
Scenario: Baseline migration
  Given the database is empty
  When I start the application
  Then Flyway/Liquibase should apply the baseline migration
Scenario: Documentation
  Given I open the README file
  When I review the build and run steps
  Then the instructions should be clear and complete

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Base package structure must be created; Actuator enabled; README must include build/run steps.
