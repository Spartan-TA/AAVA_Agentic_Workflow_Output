Title: Initialize Spring Boot Project

User Story: As a developer I want to initialize a Spring Boot project with standardized base packages and core modules So that all teams can build features on a consistent foundation

Acceptance Criteria:
Scenario: Project scaffolding
  Given I have cloned the repository
  When I run the build and start the application
  Then the application should start on port 8080 and the README should document build/run steps
Scenario: Health endpoint
  Given the application is running
  When I access the /actuator/health endpoint
  Then I should receive a response with status UP
Scenario: Base package structure
  Given the project is initialized
  When I inspect the codebase
  Then I should see base packages for employee, scheduling, attendance, and safety modules
Scenario: Database migration
  Given the application is running
  When I start the application for the first time
  Then Flyway or Liquibase should run the baseline migration successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure README is clear and all modules are present in initial commit
