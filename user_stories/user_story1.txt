Title: Initialize Project Scaffolding

User Story: As a developer, I want to initialize the Spring Boot project with Maven, configure base packages, and set up core modules so that the team has a standardized foundation for rapid and consistent delivery.

Acceptance Criteria:
Scenario: Project initialization and build
Given I clone the repository
When I run 'mvn clean install' and 'mvn spring-boot:run'
Then the application builds and runs on port 8080
And the base package structure for employee, scheduling, attendance, and safety modules exists
And the README contains build and run steps

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure Flyway/Liquibase is included for DB migrations and Actuator is enabled.
