Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project structure so that all modules follow consistent conventions and accelerate delivery.

Acceptance Criteria:

Scenario: Project initialization and health check
Given a new repository
When I build and run the project
Then the application starts on port 8080, the base package structure is present, and the Actuator health endpoint returns UP

Scenario: Database migration baseline
Given the project is running
When I start the application
Then Flyway/Liquibase baseline migration is executed successfully

Scenario: Documentation
Given the repository is cloned
When I open the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are scaffolded.
