Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot (Maven) project and configure base packages so that all modules have a standardized foundation and consistent structure.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
  Given the project is running
  When I start the application
  Then Flyway or Liquibase should apply the baseline migration without errors

Scenario: Documentation
  Given the repository is set up
  When I open the README
  Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
