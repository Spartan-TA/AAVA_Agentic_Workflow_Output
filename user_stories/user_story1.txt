Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules and base packages so that all teams have a standardized foundation for rapid and consistent delivery.

Acceptance Criteria:
Scenario: Successful project scaffolding
Given I have access to the repository
When I build and run the project
Then the application starts on port 8080, the README contains build/run steps, the Actuator health endpoint returns UP, the base package structure is present, and Flyway/Liquibase runs the baseline migration.

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure all core modules (employee, scheduling, attendance, safety) are included and DB migration tool is configured.
