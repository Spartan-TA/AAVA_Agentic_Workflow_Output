Title: Initialize Spring Boot Project

User Story: As a System Administrator I want to initialize a Spring Boot project with standardized base packages and modules so that the warehouse employee management system has a consistent and maintainable foundation.

Acceptance Criteria:
Scenario: Project setup and health check
  Given the project repository is cloned
  When I build and run the application on port 8080
  Then the application starts successfully and the Actuator health endpoint returns UP
Scenario: Database migration baseline
  Given the database is empty
  When I run Flyway/Liquibase migrations
  Then the baseline schema is created without errors
Scenario: Documentation availability
  Given the project repository
  When I open the README file
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health monitoring.
