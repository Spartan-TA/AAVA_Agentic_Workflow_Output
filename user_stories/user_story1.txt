Title: Project Scaffolding - Spring Boot Project Initialization

User Story: As a developer, I want to initialize a Spring Boot project with standard base modules so that all teams have a consistent and maintainable foundation.

Acceptance Criteria:

Scenario: Project builds and runs successfully
Given the project repository is cloned
When I run the build and start commands as documented
Then the application starts on port 8080 without errors

Scenario: Health endpoint is available
Given the application is running
When I access the /actuator/health endpoint
Then I receive a response with status "UP"

Scenario: Database migration runs on startup
Given the application starts for the first time
When Flyway or Liquibase is enabled
Then the baseline migration is applied to the database

Scenario: Base package structure exists
Given the project is initialized
When I browse the source code
Then I see base packages for employee, scheduling, attendance, and safety modules

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build and run steps; use Maven.
