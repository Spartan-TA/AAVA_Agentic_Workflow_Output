Title: Project Initialization and Scaffolding
User Story: As a developer, I want to initialize the Spring Boot project with standardized base packages and modules so that future development is consistent and maintainable.
Acceptance Criteria:
Scenario: Project builds and runs
Given the project is initialized
When I run the build and start the application
Then the application runs on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration baseline
Given Flyway/Liquibase is configured
When I run the migration
Then the baseline migration is applied successfully

Scenario: Documentation available
Given the project is initialized
When I open the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Foundation for all other modules
