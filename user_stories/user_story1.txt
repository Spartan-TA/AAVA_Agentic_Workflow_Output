Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project structure so that all modules follow consistent patterns and accelerate delivery.

Acceptance Criteria:
Scenario: Project initialization and health check
  Given I have cloned the repository
  When I build and run the project on port 8080
  Then the application starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration baseline
  Given the project is started
  When Flyway or Liquibase is enabled
  Then the baseline migration runs and the database schema is initialized

Scenario: Documentation and structure
  Given the repository is set up
  When I open the README
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created for employee, scheduling, attendance, and safety modules.
