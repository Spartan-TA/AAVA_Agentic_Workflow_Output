Title: Initialize Spring Boot Project

User Story: As a DevOps Engineer, I want to initialize a Spring Boot project with Maven so that the development team has a standardized foundation for all modules.

Acceptance Criteria:

Scenario: Successful project initialization
Given the project repository
When I run 'mvn clean install'
Then the project builds successfully and runs on port 8080

Scenario: Health endpoint verification
Given the project
When I access the actuator health endpoint
Then it returns UP

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Foundation for all subsequent modules.
