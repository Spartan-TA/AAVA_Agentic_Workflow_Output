Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project with core modules and DB migration tools so that we have a standardized foundation for rapid and consistent delivery.

Acceptance Criteria:
Scenario: Project Initialization
Given I have access to the repository
When I build and run the project
Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Base Package Structure
Given the project is initialized
When I inspect the codebase
Then the base package structure for employee, scheduling, attendance, and safety modules is present

Scenario: Database Migration
Given the project is running
When I execute Flyway/Liquibase migrations
Then baseline migration completes successfully

Scenario: Documentation
Given the project is initialized
When I view the README
Then build and run steps are clearly documented

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure Actuator and DB migration tools are enabled and working.
