Title: Initialize Spring Boot Project

User Story: As a developer, I want to initialize a Spring Boot project with Maven so that I have a standardized foundation for all modules.

Acceptance Criteria:

Scenario: Project builds and runs
Given the repository is cloned
When I run `mvn spring-boot:run`
Then the application starts on port 8080

Scenario: Health endpoint available
Given the application is running
When I access `/actuator/health`
Then the response status is 200 and body contains `"status": "UP"`

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Base for all other modules
- Epic: E01 - Project Scaffolding & Domain Setup
