Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project with core modules and database migration support so that all teams can build features consistently and reliably.

Acceptance Criteria:
Scenario: Project setup and verification
  Given a new repository
  When I build and run the project
  Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Database migration baseline
  Given the project is initialized
  When I run the migration tool
  Then Flyway/Liquibase applies the baseline migration successfully

Scenario: Documentation
  Given the project is set up
  When I open the README
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
