Title: Initialize Spring Boot Project Structure

User Story: As a developer I want to initialize a Spring Boot project with Maven and a standardized package structure So that all modules have a consistent foundation and onboarding is faster

Acceptance Criteria:

Scenario: Project builds and runs on default port
Given the project is cloned from the repository
When I run 'mvn spring-boot:run'
Then the application should start successfully on port 8080

Scenario: Base package structure is present
Given the project is opened in an IDE
When I browse the source folders
Then I should see base packages for employee, scheduling, attendance, and safety modules

Scenario: Database migration runs on startup
Given a clean database
When I start the application
Then Flyway or Liquibase should run the baseline migration and complete without errors

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure README includes build and run instructions.
