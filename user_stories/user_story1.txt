Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project with core modules and database migration tools so that all teams can accelerate delivery and maintain consistency across the warehouse employee management system.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
  Given the project is running
  When I inspect the database
  Then Flyway or Liquibase should have run the baseline migration

Scenario: Documentation
  Given I am a new developer
  When I open the README
  Then I should see clear build and run instructions

Scenario: Package structure
  Given the project is initialized
  When I browse the source code
  Then I should see base packages for employee, scheduling, attendance, and safety modules

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure Actuator is enabled and accessible; baseline migration must not fail on empty DB.
