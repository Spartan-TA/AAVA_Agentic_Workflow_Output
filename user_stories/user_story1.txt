Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project with core modules and database migration tools so that all teams can accelerate delivery and maintain consistency across modules

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
  Given the project is built
  When I run the application
  Then Flyway/Liquibase should execute the baseline migration without errors

Scenario: Documentation
  Given the repository contains a README
  When I view the README
  Then it should include clear build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
