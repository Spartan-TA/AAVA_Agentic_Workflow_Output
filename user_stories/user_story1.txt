Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize the Spring Boot (Maven) project and configure base packages So that I have a standardized foundation to accelerate delivery and enforce consistency across modules

Acceptance Criteria:

Scenario: Project initialization and setup
Given I have access to the repository
When I build and run the project on port 8080
Then the project starts successfully and the Actuator health endpoint returns UP

Scenario: Database migration setup
Given Flyway/Liquibase is configured
When I run the baseline migration
Then the database schema is created as expected

Scenario: Documentation
Given the project is initialized
When I check the README
Then it contains clear build and run steps

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled for health checks.
