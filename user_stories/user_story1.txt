Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a Spring Boot (Maven) project and configure base packages So that all modules have a standardized foundation for rapid delivery and consistency.

Acceptance Criteria:
Scenario: Project Initialization
Given a clean development environment
When I run the build and start the application
Then the project runs on port 8080 and the Actuator health endpoint returns UP

Scenario: Database Migration Setup
Given the project is initialized
When I run Flyway/Liquibase migration
Then baseline migration is applied successfully

Scenario: Documentation
Given the project is initialized
When I open the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
