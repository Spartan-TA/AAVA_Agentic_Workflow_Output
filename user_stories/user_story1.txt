#### User Story 1: Initialize Spring Boot Project Structure
**As a** developer  
**I want** to initialize a Spring Boot (Maven) project with base packages and modules  
**so that** the team has a standardized foundation for rapid development and consistency.

**Acceptance Criteria:**
- **Given** a new repository,  
  **When** I run the build command,  
  **Then** the project compiles and runs on port 8080.
- **Given** the project is initialized,  
  **When** I inspect the package structure,  
  **Then** core modules (employee, scheduling, attendance, safety) are present.

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: None  
Notes: Ensure README includes build/run steps.
