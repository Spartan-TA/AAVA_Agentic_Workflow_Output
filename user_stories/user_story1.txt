Title: Initialize Project Scaffolding

User Story: As a developer I want to initialize the Spring Boot project with Maven and configure base packages so that we have a standardized foundation for all modules.

Acceptance Criteria:
Scenario: Project builds and runs on port 8080
Given the project is cloned from the repository
When I run the build and start the application
Then the application should start successfully on port 8080

Scenario: README contains build/run steps
Given the repository is cloned
When I open the README file
Then I see clear instructions for building and running the project

Scenario: Actuator health endpoint returns UP
Given the application is running
When I access /actuator/health
Then the response status is UP

Scenario: Base package structure is created
Given the project is initialized
When I browse the source code
Then I see packages for employee, scheduling, attendance, and safety modules

Scenario: Flyway/Liquibase runs baseline migration
Given the application starts for the first time
When the database is empty
Then Flyway/Liquibase applies the baseline migration successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: This story sets up the foundation for all subsequent modules.

Title: Configure Database Migration Tool

User Story: As a developer I want to configure Flyway or Liquibase for database migrations so that schema changes are versioned and repeatable.

Acceptance Criteria:
Scenario: Baseline migration runs on startup
Given the application starts with an empty database
When Flyway/Liquibase runs
Then the baseline schema is applied without errors

Scenario: Migration scripts are versioned
Given new migration scripts are added
When the application starts
Then migrations are applied in order

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Enables safe and consistent DB evolution.
