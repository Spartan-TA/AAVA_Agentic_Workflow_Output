Title: Project Scaffolding & Domain Setup

User Story: As a developer I want to initialize a standardized Spring Boot project structure so that all modules follow consistent conventions and accelerate delivery.

Acceptance Criteria:
Scenario: Successful project scaffolding
  Given I have cloned the repository
  When I build and run the project
  Then the application should start on port 8080 and the Actuator health endpoint should return UP

Scenario: Database migration setup
  Given the project is built
  When I start the application
  Then Flyway/Liquibase should run baseline migration successfully

Scenario: Documentation
  Given the repository is set up
  When I view the README
  Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created and Actuator is enabled.
