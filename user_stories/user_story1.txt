**User Story 1: User Authentication - Login Functionality**

**Title:** User Login with Email and Password

**User Story:**
As a registered user, I want to log in using my email and password so that I can securely access my account and personalized features.

**Acceptance Criteria:**
**Scenario 1:** Successful Login
Given the user is on the login page
When the user enters a valid email and password
Then the user is redirected to the dashboard
And a session is created for the user

**Scenario 2:** Invalid Credentials
Given the user is on the login page
When the user enters an invalid email or password
Then an error message "Invalid credentials" is displayed
And the user remains on the login page

**Scenario 3:** Account Locked After Multiple Failed Attempts
Given the user has failed to log in 5 times consecutively
When the user attempts to log in again
Then the account is locked
And a message "Your account is locked due to multiple failed attempts" is displayed

**Additional Details:**
- Priority: High
- Story Points: 8
- Dependencies: User database, authentication service, session management module
- Notes: Ensure password is encrypted during transmission; consider implementing CAPTCHA after multiple failed attempts.
