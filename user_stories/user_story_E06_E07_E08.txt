Epic E06: Leave & Absence Management
------------------------------------------------------------

User Story 1: Request Leave

Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my absences are tracked and approved.
Acceptance Criteria:
  Scenario: Leave request submission
    Given employee is logged in
    When they submit a leave request
    Then request is recorded and pending approval

Additional Details:
  Priority: Medium
  Story Points: 2
  Dependencies: E02, E03, E05
  Notes: Supports multiple leave types

---

Title: Approve/Deny Leave Requests

    Given a leave request is pending

  Scenario: Supervisor denies leave
    Given a leave request is pending

  Priority: Medium
