Title: Create Employee Record

User Story: As an HR user I want to create a new employee record with all required fields So that employee information is accurately captured in the system

Acceptance Criteria:
Scenario: Creating a new employee
Given I am on the employee creation page
When I enter valid details (name, badgeId, role, department, shiftGroup, hireDate, status) and submit
Then the employee is created and appears in the employee list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: badgeId must be unique; validation errors shown for missing/invalid fields
