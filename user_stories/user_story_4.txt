Title: Document Build and Run Steps in README

User Story: As a Developer I want a comprehensive README with build and run instructions So that new team members can onboard quickly and run the project without confusion

Acceptance Criteria:
Scenario: README onboarding
Given a new developer joins the team
When they follow the README instructions
Then they can build and run the project successfully on their local machine

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: README must include environment setup, build/run commands, and troubleshooting tips
