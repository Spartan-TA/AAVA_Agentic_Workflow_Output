Title: Document Build and Run Steps

User Story: As a new developer I want clear build and run instructions in the README so that I can set up the project without confusion.

Acceptance Criteria:
Scenario: README Contains Build Steps
  Given the repository is cloned
  When I open the README
  Then I see step-by-step instructions for building and running the project

Scenario: README Verification
  Given the README is updated
  When I follow the instructions
  Then the project builds and runs successfully

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: Include troubleshooting tips for common setup issues.
