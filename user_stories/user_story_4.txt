Title: Delete Employee (Soft Delete)

User Story: As an HR manager I want to soft-delete employee records so that historical data is preserved for compliance.

Acceptance Criteria:
Scenario: Soft-delete employee
Given an active employee record
When I send a DELETE request
Then the employee status is updated to 'inactive' and the record is excluded from active queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain model
- Notes: Record remains in database for audit purposes.
