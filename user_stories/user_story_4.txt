Title: Document Build and Run Steps

Acceptance Criteria:
Scenario: Project documentation
Given the project repository
When I open the README file
Then I should see step-by-step instructions for building and running the application

- Story Points: 2
- Dependencies: Project scaffolding
- Notes: README must include instructions for DB migration and health endpoint verification
