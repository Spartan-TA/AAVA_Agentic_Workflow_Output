Title: Actuator Endpoint Enablement
User Story: As an operations engineer I want Actuator endpoints enabled So that I can monitor application health and metrics.
Acceptance Criteria:
Scenario: Health endpoint is enabled
  Given the application is running
  When I access /actuator/health
  Then I receive a 200 response with status UP

Scenario: Metrics endpoint is enabled
  Given the application is running
  When I access /actuator/metrics
  Then I receive application metrics data

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Sensitive endpoints secured by default.
