Title: Document Build and Run Steps in README

User Story: As a developer I want clear build and run instructions in the README So that new contributors can set up the project quickly and consistently

Acceptance Criteria:
Scenario: README includes build/run steps
Given the project repository
When I open the README
Then I see step-by-step instructions for building and running the application

Scenario: README update validation
Given a change in build/run process
When I update the README
Then the instructions reflect the latest process

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: README must be reviewed for accuracy before release
