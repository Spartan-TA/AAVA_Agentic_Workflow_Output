Title: Update and Soft-Delete Employee Records

User Story: As an HR manager I want to update employee details and perform soft-deletes So that employee data remains current and historical records are preserved

Acceptance Criteria:
Scenario: Employee update and soft-delete
Given an existing employee record
When I send a PUT/PATCH request to update details or a DELETE request
Then the record is updated or marked as deleted (soft-delete), not removed from the database

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Soft-deleted employees should not appear in active lists but remain queryable for audit.
