Title: Document Build and Run Steps in README

User Story: As a developer I want clear build and run instructions in the README So that new team members can quickly set up and run the EMS project

Acceptance Criteria:
Scenario: README completeness
Given the project is initialized
When I open the README file
Then it contains step-by-step instructions for building and running the application

Scenario: Troubleshooting section
Given the README is available
When I encounter common build/run issues
Then the README provides troubleshooting tips and contact info

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: Include environment setup, dependencies, and health check instructions.
