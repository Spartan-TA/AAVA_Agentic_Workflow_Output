Title: Asset Check-In/Check-Out Endpoints

User Story:
As a warehouse worker, I want to check out and return assets using secure endpoints so that asset usage and responsibility are clearly tracked.

Acceptance Criteria:
- Scenario: Worker checks out an asset
  Given a worker is authenticated and eligible
  When they check out an asset
  Then the asset status is updated and the assignment is logged

- Scenario: Worker returns an asset
  Given a worker has a checked-out asset
  When they check it in
  Then the asset status is updated and the return is logged

Additional Details:
- Check-out must validate required certifications
- All check-in/out actions must be timestamped and auditable
- Overdue returns must trigger alerts
