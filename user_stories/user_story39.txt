Title: PDF Export of Completed Reviews

User Story: As an HR manager I want to export completed performance reviews as PDF files so that records can be archived and shared securely.

Acceptance Criteria:
Scenario: PDF export of review
Given a performance review is completed and acknowledged
When I request a PDF export
Then the system generates a PDF file with all review details and signatures

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Export includes goals, ratings, comments, and acknowledgements.
