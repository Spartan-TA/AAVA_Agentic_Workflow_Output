Title: Announcement Dashboard Visibility

User Story: As an employee I want to view company announcements on my dashboard So that I am aware of important updates and events

Acceptance Criteria:
Scenario: Viewing announcements
Given there are active company announcements
When I log in to my dashboard
Then I should see a list of current announcements with details

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Announcement module, dashboard UI
- Notes: Support for announcement expiration and read/unread status.
