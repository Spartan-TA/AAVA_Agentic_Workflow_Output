Title: UI Localization and Language Toggle for Spanish/English

User Story: As an employee I want the UI to be localized and allow toggling between Spanish and English So that I can use the system in my preferred language

Acceptance Criteria:
Scenario: Language toggle
Given I am on any EMS page
When I select my preferred language
Then the UI updates to Spanish or English and date/time formats are localized

Additional Details:
- Priority: Low
- Story Points: 4
- Dependencies: E01, E02, E05
- Notes: All UI elements and notifications must be translated.
