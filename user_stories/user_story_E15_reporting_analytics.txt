Title: Generate Operational Reports

User Story: As a Supervisor I want to generate operational reports for attendance, overtime, leave balances, and certification status So that I can make data-driven staffing decisions

Acceptance Criteria:
Scenario: Report generation
Given operational data
When I request a report
Then the report should be generated with filters by date, department, and shift

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Attendance (E04), Shift Management (E05), Leave Management (E06), Certification Tracking (E07), Safety Incidents (E08), Audit Trail (E14)
- Notes: Export to CSV/PDF

Title: Safety KPI Dashboard

User Story: As a Safety Officer I want to view safety KPIs on a dashboard So that I can monitor incident trends and compliance

Acceptance Criteria:
Scenario: Dashboard view
Given safety incident data
When I access the dashboard
Then I should see key metrics like incident rate, severity distribution, and open investigations

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Safety Incidents (E08)
- Notes: Role-based access control
