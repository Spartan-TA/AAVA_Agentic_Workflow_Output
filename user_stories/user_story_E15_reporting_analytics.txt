Title: Operational Reports for Attendance and Leave
User Story: As a manager I want to view reports on attendance, overtime, and leave So that I can monitor workforce trends
Acceptance Criteria:
Scenario: Attendance report
  Given attendance data exists
  When I generate a report
  Then I see summary and detail views
Scenario: Leave report
  Given leave data exists
  When I generate a report
  Then I see balances and trends
Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Attendance, Leave, Audit trail
- Notes: Export to CSV/PDF
