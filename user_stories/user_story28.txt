Title: Asset Assignment and Certification Check

User Story: As an asset manager I want to assign assets to employees and verify required certifications So that only qualified personnel use specialized equipment

Acceptance Criteria:
Scenario: Asset assignment
Given an asset and employee
When I assign the asset
Then the system should check for required certifications and confirm assignment

Scenario: Certification check failure
Given an employee without required certification
When I attempt to assign the asset
Then the system should block the assignment and display a warning

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Equipment Asset Registry CRUD, Certification CRUD and Expiry Alerts
- Notes: Support override by authorized personnel with justification.
