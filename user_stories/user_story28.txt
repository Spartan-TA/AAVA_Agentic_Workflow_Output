Title: CRUD Operations for Employee Certifications

User Story:
As an HR or safety manager, I want to create, update, view, and delete employee certifications so that compliance and training records are accurately maintained.

Acceptance Criteria:
- Scenario: Add a new certification
  Given the manager is authenticated
  When they submit a valid certification record
  Then the certification is saved and visible on the employee profile

- Scenario: Update or delete a certification
  Given an existing certification
  When the manager updates or deletes it
  Then the changes are reflected in the system

Additional Details:
- Certifications must include type, issue/expiry dates, and proof document
- Deletion must check for active assignments requiring the cert
- All changes must be auditable
