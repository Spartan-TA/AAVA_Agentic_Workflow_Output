Title: Integrate Leave with Scheduling and Payroll

User Story:
As an HR Administrator, I want leave requests and approvals to automatically update employee schedules and payroll calculations so that there are no manual errors or omissions.

Acceptance Criteria:
Scenario 1: Approved leave blocks schedule
  Given a leave request is approved
  When the leave period starts
  Then the employee is marked as unavailable in the schedule

Scenario 2: Payroll reflects leave type
  Given a leave request is approved
  When payroll is processed
  Then the correct pay type (PTO, sick, unpaid) is applied

Scenario 3: Notifications for leave status
  Given a leave request is approved or denied
  When the status changes
  Then the employee and supervisor receive notifications

Priority: Medium
Story Points: 8
Dependencies: E02, E03, E05
Notes: Integration must be real-time and support external payroll exports.
