Title: Employee API Search by Shift Group
User Story: As an HR user I want to search for employees by shift group via API So that I can manage shift assignments
Acceptance Criteria:
Scenario: Search by Shift Group
Given employee records exist
When I GET /employees?shiftGroup=Night
Then only employees in the Night shift group are returned
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee CRUD API
- Notes: Support multiple shift group filters
