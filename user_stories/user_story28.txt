Title: Employee Search, Pagination, and Filtering API

User Story: As an HR user I want to search, paginate, and filter employee records via API So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Employee search and filter
Given a large set of employee records
When I GET /employees with query parameters (e.g., department, status, page, size)
Then the API returns paginated and filtered results matching the criteria

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD APIs (E02)
- Notes: Support filtering by department, role, status, and implement pagination
