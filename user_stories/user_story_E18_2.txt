Title: Multi-Tenant Data Isolation

User Story: As a system administrator I want each warehouse tenant to have isolated data and configuration So that sensitive information is not accessible across tenants

Acceptance Criteria:
Scenario: Tenant isolation
Given multiple tenants are configured
When a user from one tenant accesses the system
Then they only see data and settings for their own tenant

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Authentication, RBAC
- Notes: Enforce at DB and API layers
