Title: UI Language Toggle and Spanish Translations

User Story: As a bilingual employee I want to switch the EMS UI between English and Spanish So that I can use the system in my preferred language

Acceptance Criteria:
Scenario: Language toggle and translation
Given I am on any EMS screen
When I select Spanish from the language toggle
Then all UI text is displayed in Spanish and date/time is formatted for my site

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01, E02, E05
- Notes: All user-facing text must be translated; toggle available on all screens.
