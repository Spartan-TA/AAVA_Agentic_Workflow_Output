Title: Manager Views Analytics Dashboard
User Story: As a manager I want to view an analytics dashboard with key workforce metrics So that I can make informed decisions
Acceptance Criteria:
Scenario: View analytics dashboard
Given workforce data is available
When I access the analytics dashboard
Then I see visualizations of attendance, leave, and performance metrics
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Analytics engine, data modules
- Notes: Dashboard should support filtering by date and team.
