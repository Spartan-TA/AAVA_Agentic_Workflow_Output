### E11: Payroll Export Integration

**User Story 1**
- Title: Generate Payroll Export Files
- User Story: As a payroll admin, I want to generate payroll-ready files from attendance and leave data so that payroll runs are accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Export payroll file
  Given approved attendance and leave data exists
  When I generate a payroll export
  Then the file matches the provider schema and totals reconcile with reports
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E04, E06
  * Notes: Secure delivery via SFTP/API.

**User Story 2**
- Title: Retry Failed Payroll Deliveries
- User Story: As a payroll admin, I want failed exports to be retried automatically so that no data is lost.
- Acceptance Criteria in Gherkin format:
  Scenario: Retry failed delivery
  Given a payroll export delivery fails
  When the system retries with backoff
  Then delivery is retried until successful or max attempts reached
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E04, E06
  * Notes: Audit log for every export.
