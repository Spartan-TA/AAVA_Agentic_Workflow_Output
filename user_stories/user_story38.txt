Title: Asset Registry CRUD Operations

User Story:
As an asset manager, I want to create, update, view, and delete asset records (scanners, forklifts, PPE) so that all equipment is tracked and managed efficiently.

Acceptance Criteria:
- Scenario: Add a new asset
  Given the manager is authenticated
  When they submit a valid asset record
  Then the asset is saved and visible in the registry

- Scenario: Update or delete an asset
  Given an existing asset
  When the manager updates or deletes it
  Then the changes are reflected in the system

Additional Details:
- Assets must include type, serial number, condition, and assignment status
- Deletion must check for active checkouts
- All changes must be auditable
