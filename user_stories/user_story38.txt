Title: Configure HRIS/WMS API Endpoints

User Story: As a system integrator I want to configure API endpoints for HRIS and WMS systems so that data can be exchanged seamlessly

Acceptance Criteria:
Scenario: Configuring API endpoints
Given I am logged in as a system integrator
When I enter API endpoint details and credentials
Then the system saves the configuration and tests the connection

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: HRIS/WMS provider, security module
- Notes: Support for multiple endpoints and secure credential storage.
