Title: Employee Self-Assessment Submission

User Story: As an employee I want to submit my self-assessment during the review cycle So that my manager can evaluate my performance based on my own input

Acceptance Criteria:
Scenario: Submitting self-assessment
Given the review cycle is active and I am notified
When I access my review form and submit my self-assessment
Then my submission should be saved and visible to my manager

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Review cycle initiation, notification system
- Notes: Allow employees to edit until the deadline.
