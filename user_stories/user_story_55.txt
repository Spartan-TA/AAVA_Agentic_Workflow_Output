Title: Configure Notification Rules

User Story: As an admin I want to configure notification rules for system events So that users receive relevant notifications based on their roles and actions

Acceptance Criteria:
Scenario: Notification rule configuration
Given I am logged in as an admin
When I create or modify notification rules
Then the system should apply these rules to all future notifications

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Notifications module
- Notes: Support for role-based and event-based rules
