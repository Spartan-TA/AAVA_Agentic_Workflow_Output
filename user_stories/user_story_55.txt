Title: Metrics Endpoints and Dashboard Access Control

User Story: As a BI analyst I want metrics endpoints for operational data and dashboards with role-based access so that analytics are available for authorized users and external BI tools

Acceptance Criteria:
Scenario: Access metrics and dashboards
  Given I have the appropriate role
  When I access metrics endpoints or dashboards
  Then I see only the data I am authorized to view and can export metrics within 10 seconds for up to 50,000 rows

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04 (Attendance), E05 (Scheduling), E06 (Leave), E07 (Certifications), E08 (Safety), E14 (Audit)
- Notes: Metrics endpoints must be documented
