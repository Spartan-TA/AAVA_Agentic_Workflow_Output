Title: Localization Support

User Story: As a global user I want the system to support multiple languages and regional formats So that I can use the platform in my preferred locale

Acceptance Criteria:
Scenario: Change language preference
Given I am logged in
When I select a different language or region
Then the system should update UI text, dates, and currency formats accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Localization module
- Notes: Support RTL languages and custom date formats.
