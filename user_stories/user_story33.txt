Title: Asset Check-In/Out Workflow

User Story: As an employee I want to check out and return equipment and PPE So that asset usage is tracked and overdue returns are flagged

Acceptance Criteria:
Scenario: Asset check-in/out
Given I am assigned an asset
When I check out or return the asset
Then the system updates the assignment status and logs the transaction

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Asset Registry, Employee Master Data
- Notes: Overdue returns should trigger notifications and appear in reports.
