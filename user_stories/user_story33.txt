Title: Automated Security Tests for Access Control

User Story: As a QA engineer I want automated tests covering security rules So that unauthorized and forbidden actions are reliably detected

Acceptance Criteria:
Scenario: Security rule test coverage
Given the security configuration is in place
When I run the automated test suite
Then all access control rules are validated and unauthorized actions return 401/403

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role-based access control (E03)
- Notes: Cover all roles and endpoints in test cases
