Title: Employee API Export to Excel
User Story: As an HR user I want to export employee lists to Excel via API So that I can analyze and manipulate data in spreadsheets
Acceptance Criteria:
Scenario: Export to Excel
Given employee records exist
When I GET /employees/export?format=xlsx
Then I receive an Excel file with employee data
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee API Bulk Export
- Notes: Support custom column selection
