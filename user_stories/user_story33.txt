Title: Generate OSHA Compliance Reports

User Story: As a compliance officer I want to generate OSHA compliance reports from incident data So that regulatory requirements are met and audits are streamlined

Acceptance Criteria:
Scenario: Generating a compliance report
Given there are logged safety incidents
When I select a reporting period and generate a report
Then the report should include all required OSHA fields and be exportable

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Incident log, reporting module
- Notes: Support PDF and Excel export formats.
