Title: Export Payroll Data for Processing

User Story: As a payroll administrator I want to export payroll data for a given period so that I can process payroll accurately and on time

Acceptance Criteria:
Scenario: Exporting payroll data
Given I am logged in as a payroll administrator
When I select a pay period and export payroll data
Then I receive a file in the configured format ready for upload to the payroll provider

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Payroll export configuration, attendance data
- Notes: Export should include all required fields for the provider.
