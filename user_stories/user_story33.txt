Title: Role-Based Review Visibility

User Story: As an HR manager I want review visibility to be restricted based on user roles So that only authorized personnel can view or edit performance reviews

Acceptance Criteria:
Scenario: Review visibility enforcement
Given a set of user roles
When a user accesses a review
Then the system should enforce visibility rules and restrict access as appropriate

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Performance Review Cycle Creation, Role-Based Access Control Setup
- Notes: Support audit logging of review access.
