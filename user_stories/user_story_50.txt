Title: OpenAPI Documentation for All APIs

User Story: As a developer I want all EMS APIs to be documented in OpenAPI format so that integration and maintenance are streamlined and consistent

Acceptance Criteria:
Scenario: Publish OpenAPI documentation
  Given new or updated API endpoints are released
  When I view the API documentation
  Then all endpoints, parameters, and responses are described per OpenAPI standards

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01 (Core), E02 (User Management), E03 (Scheduling)
- Notes: Documentation must be versioned and accessible to integrators
