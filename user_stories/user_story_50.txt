Title: Audit Log Export and Test Coverage

User Story: As an auditor I want to export audit logs by date, user, or entity and ensure test coverage so that compliance reviews are efficient and reliable

Acceptance Criteria:
Scenario: Export and test audit logs
  Given I have appropriate permissions
  When I filter audit logs by date range, user, or entity and export them
  Then I receive a tamper-evident file and automated tests validate log coverage for all sensitive actions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Export format must be CSV or PDF; test suite must cover all create/update/delete actions.
