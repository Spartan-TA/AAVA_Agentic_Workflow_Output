Title: Automated Pipeline on Every PR

User Story: As a developer I want a CI/CD pipeline to run on every pull request so that code is built, tested, and validated before merging

Acceptance Criteria:
Scenario: Running pipeline on PR
Given a pull request is opened
When the pipeline runs
Then all build, test, and security scan steps complete successfully

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: GitHub Actions/Jenkins, test suite
- Notes: Pipeline failures must block merge
