Epic E18: Localization & Multi-Tenant

---

User Story 1: Locale-Specific Date/Time, Currency, Language
As a worker, I want date/time, currency, and language to match my locale so that the system is usable globally.

Acceptance Criteria:
Scenario: Locale configuration
  Given my locale
  When I use the app
  Then formats match my region

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02
- Notes: Locale settings per user

---

User Story 2: Tenant Isolation for Data and Config
As IT, I want tenant isolation so that data and config are separated per warehouse/region.

Acceptance Criteria:
Scenario: Tenant isolation
  Given multiple tenants
  When I access data
  Then only my tenant's data is visible

Additional Details:
- Priority: Low
- Story Points: 5
- Dependencies: E01, E02
- Notes: Multi-tenant architecture
