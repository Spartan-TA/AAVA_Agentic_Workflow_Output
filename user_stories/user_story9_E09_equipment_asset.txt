### Epic E09: Equipment & Asset Assignment

**User Story 1**
Title: Register Equipment Asset
User Story: As an ADMIN, I want to register equipment assets so that inventory is tracked.
Acceptance Criteria:
Scenario: Asset registration
Given asset details
When I POST to /assets
Then the asset is added to the registry
Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E07
Notes: PPE, scanners, forklifts.

**User Story 2**
Title: Assign Asset to Employee
User Story: As a SUPERVISOR, I want to assign assets to employees so that accountability is enforced.
Acceptance Criteria:
Scenario: Asset assignment
Given an asset and employee
When I assign
Then the asset is checked out to the employee
Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E07
Notes: Certification check required.

**User Story 3**
Title: Block Asset Use if Certification Missing
User Story: As a SUPERVISOR, I want asset assignment blocked if required certification is missing so that safety is ensured.
Acceptance Criteria:
Scenario: Assignment block
Given missing certification
When I assign asset
Then the system prevents assignment
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: Error message shown.

**User Story 4**
Title: Asset Check-In/Out
User Story: As a WORKER, I want to check in/out assets so that usage is tracked.
Acceptance Criteria:
Scenario: Asset check-in/out
Given an assigned asset
When I check in/out
Then the event is logged
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E07
Notes: History log per asset.

**User Story 5**
Title: Overdue Asset Return Report
User Story: As an ADMIN, I want reports of overdue asset returns so that follow-up is possible.
Acceptance Criteria:
Scenario: Overdue report

Additional Details:
Priority: Medium
Story Points: 2
