# Epic E09: Equipment & Asset Assignment

## User Story 1: Asset Registry CRUD
**Title:** Manage Asset Registry  
**Narrative:** As an asset manager, I want to create, update, and delete asset records so that equipment is tracked.  
**Acceptance Criteria (Gherkin):**
```
Given the asset module
When I add or update an asset
Then it is saved and visible in the registry
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E02, E03, E07  
**Notes:** Include asset condition state.

---

## User Story 2: Check-In/Out Endpoints
**Title:** Asset Check-In/Out Endpoints  
**Narrative:** As a worker, I want to check out and return equipment so that usage is tracked.  
**Acceptance Criteria (Gherkin):**
```
Given an asset record
When I check out or return equipment
Then the event is logged with timestamp and employee
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E09  
**Notes:** Prevent checkout if certification missing.

---

## User Story 3: Block Checkout for Invalid Certification
**Title:** Block Checkout for Invalid Certification  
**Narrative:** As a supervisor, I want asset checkout blocked if required certifications are invalid so that safety is maintained.  
**Acceptance Criteria (Gherkin):**
```
Given an asset requiring certification
When an employee's certification is expired or missing
Then checkout is blocked and a warning is shown
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E07, E09  
**Notes:** Integrate with certification module.

---

## User Story 4: Asset History Log
**Title:** Asset and Employee History Log  
**Narrative:** As an asset manager, I want to view the history of asset assignments and returns so that accountability is ensured.  
**Acceptance Criteria (Gherkin):**
```
Given an asset or employee profile
When I view the history log
Then all check-in/out events are listed with timestamps
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E09  
**Notes:** Support export to CSV.

---

## User Story 5: Overdue Asset Return Reports
**Title:** Report Overdue Asset Returns  
**Narrative:** As a supervisor, I want reports of overdue asset returns so that assets are recovered promptly.  
**Acceptance Criteria (Gherkin):**
```
Given asset assignment data
When an asset is overdue for return
Then it appears in the overdue report
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E09  
**Notes:** Notify responsible employees.
