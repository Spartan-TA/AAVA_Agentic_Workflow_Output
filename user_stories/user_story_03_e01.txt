Title: Enable Actuator Health Endpoint

User Story: As a system administrator I want to access a health endpoint So that I can monitor the application's status and uptime

Acceptance Criteria:
Scenario: Health endpoint returns status
Given the application is running
When I access the /actuator/health endpoint
Then I receive a JSON response indicating the application's health status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot Actuator module
- Notes: Secure the endpoint to allow only authorized access.
