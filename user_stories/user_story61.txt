Title: Deployment Automation and Rollback

User Story: As a release manager I want automated deployment and rollback capabilities So that releases can be performed reliably and reverted quickly if issues arise

Acceptance Criteria:
Scenario: Automated deployment
  Given a release is approved
  When the deployment is triggered
  Then the application should be deployed to the production environment without manual intervention

Scenario: Rollback
  Given a deployment fails or critical issue is detected
  When rollback is initiated
  Then the system should revert to the previous stable version automatically

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: CI/CD pipeline, deployment scripts
- Notes: Ensure rollback is tested and does not affect persistent data.
