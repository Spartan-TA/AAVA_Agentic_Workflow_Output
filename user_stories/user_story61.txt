Title: Automated Offboarding and Asset Collection

User Story: As an HR manager I want access and assets to be revoked and collected automatically upon termination So that offboarding is efficient and secure

Acceptance Criteria:
Scenario: Employee offboarding
Given an employee is terminated
When the offboarding workflow runs
Then system access is revoked, assets are collected, and schedules are updated

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Offboarding actions must be logged and auditable
