Title: Localize UI for Spanish and English

User Story: As a bilingual user I want to switch the UI language between Spanish and English So that I can use the system in my preferred language

Acceptance Criteria:
Scenario: Changing UI language
Given I am on the settings page
When I select Spanish as my preferred language
Then the UI updates to display all text in Spanish

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Localization framework
- Notes: Language selection should persist across sessions.
