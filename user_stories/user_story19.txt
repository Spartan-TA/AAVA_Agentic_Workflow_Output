Title: Shift Conflict Detection

User Story: As a scheduler I want the system to detect shift conflicts automatically So that I can avoid double-booking employees and ensure compliance with labor rules

Acceptance Criteria:
Scenario: Detect overlapping shifts
  Given an employee has existing shift assignments
  When I attempt to assign a new shift that overlaps
  Then the system should notify me of the conflict and prevent assignment
Scenario: Detect rule violations
  Given labor rules are configured
  When I assign shifts
  Then the system should alert me if any assignments violate rules (e.g., overtime, rest periods)

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Scheduling module, rule engine
- Notes: Support for configurable rules
