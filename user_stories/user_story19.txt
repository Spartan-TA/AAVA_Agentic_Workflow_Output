Title: Payroll Export Integration

User Story: As a payroll administrator, I want to generate payroll-ready files from approved attendance and leave, mapped to provider formats, and deliver securely so that payroll runs are accurate and efficient.

Acceptance Criteria:
Scenario: Payroll export generation
Given approved attendance and leave data
When I trigger a payroll export
Then the file matches provider schema
And failed deliveries are retried with backoff
And an audit log is created for every export

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Time & Attendance, Leave Management
- Notes: Secure delivery via SFTP/API.
