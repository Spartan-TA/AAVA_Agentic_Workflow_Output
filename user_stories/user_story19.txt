Title: Payroll Export Generation
User Story: As a payroll admin, I want to generate payroll-ready files from attendance and leave data so that payroll processing is accurate and efficient.
Acceptance Criteria:
  Given approved attendance and leave,
  When I export payroll,
  Then the file matches provider schema and totals reconcile.

  Given a failed delivery,
  When retried,
  Then the system uses exponential backoff.

Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: Attendance, Leave
  Notes: Audit log for exports.
