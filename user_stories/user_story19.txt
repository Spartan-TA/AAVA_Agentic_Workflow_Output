Title: Leave Approval and Balances Update

User Story: As a supervisor I want to approve or reject leave requests and update employee leave balances So that leave management is accurate and transparent

Acceptance Criteria:
Scenario: Leave approval
Given a pending leave request
When I approve the request
Then the employee's leave balance should be reduced accordingly

Scenario: Leave rejection
Given a pending leave request
When I reject the request
Then the employee should be notified and the balance should remain unchanged

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Leave Request Submission
- Notes: Support notifications for approval/rejection.
