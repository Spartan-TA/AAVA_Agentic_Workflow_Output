Title: Observability - Expose Metrics Endpoint

User Story: As an SRE I want a metrics endpoint for Prometheus/Grafana so that I can monitor API latency, queue depth, and error rates.

Acceptance Criteria:
Scenario: Metrics endpoint is scraped
Given the application is running
When Prometheus scrapes /actuator/prometheus
Then custom metrics are available

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E01
- Notes: Structured logging in JSON.

Title: Observability - Dashboards and Alerts

User Story: As an SRE I want dashboards and alerting rules for key flows so that issues are detected proactively.

Acceptance Criteria:
Scenario: Dashboards for key flows
Given metrics are available
When I access Grafana
Then I see dashboards for API latency, queue depth, error rates

Scenario: Alerts for 5xx errors
Given error rates exceed threshold
When an alert is triggered
Then runbooks are linked in the alert

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E01
- Notes: Proactive monitoring.
