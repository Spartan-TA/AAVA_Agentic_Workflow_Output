Title: Audit Trail & Compliance
User Story: As a compliance officer I want all sensitive changes to be logged with actor and timestamp So that audits and investigations are possible
Acceptance Criteria:
Scenario: Log create/update/delete
Given a sensitive operation occurs
When the action is performed
Then an immutable log entry is created with before/after values

Scenario: Export audit log
Given a date range and entity
When I request an export
Then the log is exported as CSV

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: RBAC
- Notes: Tamper-evident storage; test coverage required.
