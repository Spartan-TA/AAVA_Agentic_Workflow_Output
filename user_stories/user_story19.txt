Title: Detect and Prevent Scheduling Conflicts

User Story:
As a scheduling manager, I want the system to detect and prevent scheduling conflicts so that employees are not double-booked or assigned during blackout dates.

Acceptance Criteria:
- Scenario: Attempt to assign overlapping shifts
  Given an employee is already assigned to a shift
  When a manager tries to assign them to an overlapping shift
  Then the system blocks the assignment and displays an error

- Scenario: Assignment during blackout date
  Given a blackout date is configured
  When a manager tries to assign a shift on that date
  Then the system prevents the assignment

Additional Details:
- Conflicts must be detected in real time during assignment
- Blackout dates and warehouse operation calendars must be configurable
- All conflict checks must be covered by automated tests
