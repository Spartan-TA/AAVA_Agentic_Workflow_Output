Title: Track Certification Expiry and Block Assignments

User Story: As a compliance officer I want to track employee certifications and block assignments to tasks requiring valid certs So that only qualified staff are assigned

Acceptance Criteria:

Scenario: Certification CRUD operations
Given I have proper permissions
When I create, update, or delete a certification
Then the changes are reflected in the employee profile

Scenario: Alert before certification expiry
Given a certification is expiring in 30 or 7 days
When the date approaches
Then an alert is sent to the employee and supervisor

Scenario: Block assignment if certification expired
Given an employee's certification is expired
When I attempt to assign them to a restricted task
Then the system prevents the assignment

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee CRUD APIs, RBAC
- Notes: Upload proof documents; show cert status on profile
