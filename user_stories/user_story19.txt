Title: Integration Layer (HRIS/WMS APIs)

User Story: As a system administrator I want to synchronize employee and warehouse data with external HRIS and WMS systems So that master data is consistent and duplicate entry is minimized

Acceptance Criteria:
Scenario: HRIS sync job
Given new hires or terminations in HRIS
When the sync job runs
Then employees are created, updated, or terminated in EMS

Scenario: JWT/OAuth2-secured APIs
Given an external system requests data
When it authenticates via JWT/OAuth2
Then access is granted and APIs respond with correct data

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding, Employee Master Data, RBAC
- Notes: Webhooks for events; OpenAPI documentation; idempotent API operations
