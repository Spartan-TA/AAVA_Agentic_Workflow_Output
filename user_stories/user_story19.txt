Title: Certification CRUD and Document Upload

User Story: As an HR user, I want to manage employee certifications and upload proof documents so that compliance is tracked.

Acceptance Criteria:

Scenario: Add or update certification
Given the certification module
When I add or update a certification
Then it is saved and visible on the employee profile

Scenario: Upload proof document
Given a certification
When I upload a document
Then it is stored and linked to the record

Scenario: Soft-delete certification
Given a certification
When deleted
Then it is soft-deleted

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Proof required for compliance
