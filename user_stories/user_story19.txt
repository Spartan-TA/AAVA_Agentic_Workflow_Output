Title: Shift Template CRUD

User Story: As an HR manager I want to create, update, and delete shift templates so that recurring schedules can be efficiently managed

Acceptance Criteria:
Scenario: Create shift template
Given I am logged in as HR or ADMIN
When I submit a new shift template
Then the template is saved and available for assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Support for recurring patterns and blackout dates.
