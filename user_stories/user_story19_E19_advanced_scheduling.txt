# Epic E19: Advanced Scheduling (AI/Optimization)

## User Story 1: Advanced Shift Rotations and Overtime Rules
**Title:** Advanced Shift Rotations and Overtime Rules  
**Narrative:** As a scheduler, I want to configure advanced shift rotations and overtime rules so that staffing is optimized.  
**Acceptance Criteria (Gherkin):**
```
Given the scheduling module
When I configure rotations and overtime
Then rules are enforced in shift assignments
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E05  
**Notes:** Support exceptions and overrides.

## User Story 2: Handle Blackout Dates and Operation Calendars
**Title:** Handle Blackout Dates and Operation Calendars
