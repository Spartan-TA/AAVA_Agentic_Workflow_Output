EPIC E06: Leave & Absence Management

---

Title: Request Leave
User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my time off is tracked.

Acceptance Criteria:
Scenario: Submit leave request
  Given I am logged in
  When I submit a leave request
  Then the request is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Supports multiple leave types

---

Title: Approve/Deny Leave
User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.

Acceptance Criteria:
Scenario: Process leave request
  Given a pending leave request
  When I approve or deny it
  Then the employee is notified and balances update

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Approval workflow

---

Title: Update Leave Balances
User Story: As an HR manager, I want leave balances to update automatically so that accruals are accurate.

Acceptance Criteria:
Scenario: Auto-update balances
  Given a leave is approved
  When the leave period starts
  Then the employee's leave balance is reduced accordingly

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Accrual policies configurable

---

Title: Flag Scheduled Shifts for Coverage
User Story: As a supervisor, I want scheduled shifts to auto-flag for coverage when an employee is on leave.

Acceptance Criteria:
Scenario: Flag shift for coverage
  Given an approved leave overlaps a scheduled shift
  When I view the schedule
  Then the shift is flagged for coverage

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E05
- Notes: Integration with shift management

---

Title: Export Approved Leaves
User Story: As a payroll admin, I want to export approved leaves so that payroll calculations are accurate.

Acceptance Criteria:
Scenario: Export leave data
  Given approved leave records
  When I export leave data
  Then the file matches payroll provider schema

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E11
- Notes: CSV export
