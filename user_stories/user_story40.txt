Title: Employee Goal Setting and Tracking

User Story: As an employee I want to set and track my professional goals So that I can monitor my progress and align with organizational objectives

Acceptance Criteria:
Scenario: Setting and updating goals
Given I am on my performance dashboard
When I create or update my goals
Then my goals should be saved and visible to my manager for review

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee profile, manager dashboard
- Notes: Allow goal status updates and comments.
