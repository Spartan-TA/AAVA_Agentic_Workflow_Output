Title: Block Asset Use When Required Certifications Are Invalid

User Story:
As a supervisor, I want the system to block asset check-out or use if the employee's required certifications are expired or missing so that safety and compliance are maintained.

Acceptance Criteria:
- Scenario: Check-out blocked due to invalid certification
  Given an employee's required certification is expired or missing
  When they attempt to check out an asset
  Then the system prevents the check-out and displays an error

- Scenario: Check-out allowed with valid certification
  Given an employee's certification is valid
  When they check out an asset
  Then the check-out is successful

Additional Details:
- Certification requirements must be configurable per asset type
- All blocked attempts must be logged for audit
- UI must clearly indicate reason for blocked check-out
