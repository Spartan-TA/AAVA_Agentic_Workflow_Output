Title: Advanced Search for Shipments

User Story: As a warehouse manager I want to perform advanced searches for shipments using multiple criteria So that I can quickly locate and track incoming and outgoing goods

Acceptance Criteria:
Scenario: Advanced search execution
Given a set of shipment records
When I enter search criteria
Then the system should return matching shipments with relevant details

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Equipment Asset Registry CRUD
- Notes: Support filtering by date, supplier, and status.
