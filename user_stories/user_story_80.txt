Title: Automated Deployment to Staging and Approval for Production

User Story: As a release manager I want the pipeline to auto-deploy to staging and require approval for production so that releases are controlled and tested before going live

Acceptance Criteria:
Scenario: Deploying to staging and production
Given a successful build
When the pipeline completes
Then the application is deployed to staging automatically and production deployment requires manual approval

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: CI/CD pipeline, deployment scripts
- Notes: Approval workflow must be auditable
