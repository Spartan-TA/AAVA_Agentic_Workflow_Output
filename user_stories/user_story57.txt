Title: HRIS Sync Job for New Hires and Terminations

User Story:
As an HRIS administrator, I want a scheduled sync job to create or update employee records from the HRIS so that employee data is always current in the warehouse system.

Acceptance Criteria:
- Scenario: New hire is created from HRIS
  Given a new employee is added in the HRIS
  When the sync job runs
  Then the employee is created in the warehouse system

- Scenario: Termination is reflected in warehouse system
  Given an employee is terminated in the HRIS
  When the sync job runs
  Then the employee status is updated or deactivated in the warehouse system

Additional Details:
- Sync must be idempotent and handle updates, not just inserts
- All sync actions must be logged and auditable
- Errors must trigger alerts to admins
