Title: Mobile Push Notifications

User Story: As an employee I want to receive push notifications on my mobile device So that I am alerted to important updates and actions in real time

Acceptance Criteria:
Scenario: Receiving push notifications
Given I have installed the PWA and enabled notifications
When a relevant event occurs (e.g., new announcement, approval required)
Then I should receive a push notification on my device

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notification service, PWA framework
- Notes: Support notification preferences and opt-out.
