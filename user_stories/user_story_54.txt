Title: Automate Deprovisioning of Access and Assets

User Story: As an HR manager I want employee access and assigned assets to be deprovisioned automatically upon termination so that security and asset recovery are ensured.

Acceptance Criteria:
Scenario: Offboarding an employee
Given an employee is marked as terminated
When the offboarding workflow is triggered
Then the system should revoke all system access, unassign assets, and notify relevant departments

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Deprovisioning should be auditable and reversible if needed.
