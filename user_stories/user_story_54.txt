Title: Generate Operational Reports

User Story: As an operations manager I want to generate reports on attendance, overtime, leave balances, certification status, and safety KPIs so that I can monitor workforce performance and compliance

Acceptance Criteria:
Scenario: Generate operational report
  Given operational data is available
  When I select report type and filters
  Then the report is generated and available for export in CSV or PDF

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04 (Attendance), E05 (Scheduling), E06 (Leave), E07 (Certifications), E08 (Safety), E14 (Audit)
- Notes: Reports must support date, department, and shift filters
