Title: Support Pagination and Filtering for Employee Records

User Story: As an HR manager I want to paginate and filter employee records via the API so that I can efficiently manage large employee datasets.

Acceptance Criteria:
Scenario: Paginated and filtered employee list
  Given I am viewing the employee list
  When I provide pagination and filter parameters (e.g., department, status)
  Then the API should return the correct subset of employees

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints
- Notes: Filtering should support department, role, status, and shiftGroup.
