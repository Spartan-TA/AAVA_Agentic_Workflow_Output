Title: Support Soft-Delete for Employee Records

User Story: As an HR manager I want to soft-delete employee records So that terminated employees are excluded from active lists but historical data is retained for compliance.

Acceptance Criteria:
Scenario: Soft-delete employee
  Given an active employee
  When I DELETE /employees/{id}
  Then the employee status is set to 'inactive' and record is excluded from active queries

Scenario: Retrieve soft-deleted employees
  Given soft-deleted employees exist
  When I query with a filter for inactive status
  Then soft-deleted employees are returned

Scenario: Prevent hard delete
  Given an employee record
  When I attempt a hard delete
  Then the request is rejected or not supported

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Soft-deleted records should be auditable and restorable if needed.
