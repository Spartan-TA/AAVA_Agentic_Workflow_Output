Title: Implement Employee List Pagination and Filtering

User Story: As an HR manager I want to paginate and filter employee records so that I can efficiently find and manage employees in large warehouses.

Acceptance Criteria:
Scenario: Paginated and filtered employee list
  Given there are more than 50 employees
  When I request the employee list with pagination and filter parameters
  Then the API returns the correct subset of employees matching the criteria

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Support filtering by department, role, status, and shiftGroup.
