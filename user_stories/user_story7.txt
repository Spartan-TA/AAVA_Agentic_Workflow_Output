Title: Employee Master Data (CRUD) - Employee Deletion

User Story: As an HR manager I want to soft-delete employee records so that historical data is preserved but inactive employees are excluded from active lists.

Acceptance Criteria:
Scenario: Soft-delete employee
Given an existing employee
When I DELETE /employees/{id}
Then the employee status changes to inactive and record is excluded from active queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Creation
- Notes: Implement soft-delete, not hard delete.
