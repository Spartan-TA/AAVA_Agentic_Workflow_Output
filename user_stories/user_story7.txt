Title: Soft-Delete Employee Record

User Story: As an HR user I want to soft-delete employee records So that terminated employees are not lost but excluded from active processes

Acceptance Criteria:

Scenario: Successful soft-delete
Given I am authenticated as HR
When I submit a DELETE request to /employees/{id}
Then the employee record should be marked as inactive and excluded from active lists

Scenario: Deleted employee not shown in active queries
Given an employee is soft-deleted
When I query active employees
Then the deleted employee should not appear in the results

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Soft-deleted records must be retrievable for audit purposes.
