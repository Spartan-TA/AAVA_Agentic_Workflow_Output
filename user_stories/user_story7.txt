Title: API Key/OAuth2 Toggle
User Story: As a system admin I want to toggle between API key and OAuth2 authentication via configuration So that integration with different environments is flexible
Acceptance Criteria:
Scenario: Authentication mode switch
Given the application is configured for API key mode
When I make a request with a valid API key
Then access is granted

Given the application is configured for OAuth2 mode
When I authenticate via OAuth2
Then access is granted

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: RBAC Setup
- Notes: Configuration-driven; document in README.
