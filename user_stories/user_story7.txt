Title: Training & Certification - Track Certifications

User Story: As an HR user I want to record and track employee certifications so that compliance is maintained.

Acceptance Criteria:
Scenario: Add certification to employee
Given an employee exists
When I add a certification
Then it is visible on the employee profile

Scenario: Certification expiry alerts
Given a certification is expiring in 30 or 7 days
When the system checks expirations
Then an alert is generated for the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Proof documents can be uploaded.

Title: Training & Certification - Block Unqualified Assignments

User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications so that safety is ensured.

Acceptance Criteria:
Scenario: Block assignment to unqualified employee
Given a task requires a valid certification
When I try to assign it to an employee with an expired cert
Then the system blocks the assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Certification status checked during scheduling.
