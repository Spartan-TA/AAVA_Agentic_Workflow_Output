Title: Implement Role-Based Access Control (RBAC)

User Story: As a system administrator I want to enforce role-based access control for all EMS endpoints So that only authorized users can perform sensitive operations

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user is not authenticated
  When they access a protected endpoint
  Then the system should return a 401 Unauthorized error
Scenario: Forbidden actions
  Given a user is authenticated but lacks permissions
  When they attempt a restricted operation
  Then the system should return a 403 Forbidden error
Scenario: Role permissions
  Given users have roles (ADMIN, HR, SUPERVISOR, WORKER)
  When they access endpoints
  Then permissions should be enforced according to their role

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Method/endpoint security must be covered by automated tests.
