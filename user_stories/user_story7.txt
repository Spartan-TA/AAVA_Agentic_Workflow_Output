Title: Role-Based Endpoint Security
User Story: As a system administrator I want to restrict API endpoints based on user roles So that only authorized users can access sensitive operations
Acceptance Criteria:
Scenario: Unauthorized access attempt
Given I am not authenticated
When I access a protected endpoint
Then I receive a 401 Unauthorized response

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER
