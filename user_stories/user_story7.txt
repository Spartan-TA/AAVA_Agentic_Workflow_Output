Title: Update Employee Record API
User Story: As an HR manager I want to update employee details via an API So that employee information remains accurate and up-to-date
Acceptance Criteria:
Scenario: Employee record update
  Given an existing employee record
  When I PUT or PATCH to /employees/{id} with updated details
  Then the employee record is updated and changes are reflected in subsequent queries
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation API
- Notes: API must validate updates and support partial updates
