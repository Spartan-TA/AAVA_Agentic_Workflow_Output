Title: Implement Pagination and Filtering for Employee List

User Story: As an HR manager I want to paginate and filter the employee list via API so that I can efficiently search and manage large numbers of employee records.

Acceptance Criteria:
Scenario: Paginated and filtered employee list
  Given there are more than 20 employees in the system
  When I call GET /employees with pagination and filter parameters
  Then the API returns the correct subset of employees based on the criteria
  And the response includes pagination metadata

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints (E02)
- Notes: Support filtering by department, role, status, and shiftGroup.
