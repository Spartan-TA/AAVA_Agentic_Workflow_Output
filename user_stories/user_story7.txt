Title: Role-Based Access Control Enforcement

User Story: As a system admin I want to restrict endpoints by user role so that only authorized users can perform sensitive actions.

Acceptance Criteria:
Scenario: Access control
Given a user with a specific role
When they access a protected endpoint
Then unauthorized requests return 401, forbidden actions return 403

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01,E02
- Notes: Roles: ADMIN, HR, SUPERVISOR, WORKER.
