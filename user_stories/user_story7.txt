Title: Role-Based Access Control Setup
User Story: As a security admin, I want to configure roles (ADMIN, HR, SUPERVISOR, WORKER) so that access to sensitive operations is restricted.
Acceptance Criteria:
Scenario: Unauthorized request
Given a user is not authenticated
When they access a protected endpoint
Then a 401 Unauthorized is returned

Scenario: Forbidden action
Given a user is authenticated but lacks permission
When they attempt a restricted action
Then a 403 Forbidden is returned

Scenario: ADMIN access
Given a user has ADMIN role
When they access any employee record
Then access is granted

Scenario: SUPERVISOR access
Given a user has SUPERVISOR role
When they access team employee records
Then access is granted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API, Project Scaffolding
- Notes: Must be covered by automated tests
