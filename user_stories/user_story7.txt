Title: Implement Employee CRUD Endpoints

User Story: As an HR user I want to create, read, update, and delete employee records via API endpoints So that employee data can be managed efficiently and accurately

Acceptance Criteria:
Scenario: CRUD API operations
Given the Employee domain model is defined
When I send POST, GET, PUT, PATCH, or DELETE requests to /employees
Then the corresponding employee record is created, retrieved, updated, or deleted as expected

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain model (E02), Project scaffolding (E01)
- Notes: Endpoints must follow REST conventions; error handling for invalid input
