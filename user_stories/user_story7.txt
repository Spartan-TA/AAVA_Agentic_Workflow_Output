### E07 - Training & Certification Tracking

#### User Story 1
Title: Add Certification to Employee
User Story: As an HR I want to add certifications to employee profiles So that qualification is tracked.
Acceptance Criteria:
Scenario: Certification Addition
Given HR is authenticated
When HR adds certification
Then certification appears on profile
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Proof documents uploadable.

#### User Story 2
Title: Certification Expiry Alerts
User Story: As a SUPERVISOR I want alerts for expiring certifications So that renewals are timely.
Acceptance Criteria:
Scenario: Expiry Notification
Given certification is expiring in 30/7 days
When alert is triggered
Then supervisor and employee are notified
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Alerts configurable.

#### User Story 3
Title: Block Assignment for Expired Certs
User Story: As a System Administrator I want to prevent assignment to tasks requiring expired certifications So that compliance is enforced.
Acceptance Criteria:
Scenario: Assignment Block
Given employee's certification is expired
When assignment is attempted
Then system blocks and notifies user
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Scheduling checks required.

#### User Story 4
Title: Certification Status Visibility
User Story: As a WORKER I want to see my certification status So that I know my eligibility for tasks.
Acceptance Criteria:
Scenario: Status Viewing
Given WORKER is authenticated
When WORKER views profile
Then certification status is displayed
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Mobile-friendly.
