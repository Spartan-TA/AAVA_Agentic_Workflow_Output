### E07 - Training & Certification Tracking

**User Story 1:**
Title: Manage Employee Certifications
User Story: As an HR admin, I want to add, update, and remove employee certifications so that compliance is tracked.
Acceptance Criteria:
Scenario: Create certification
  Given valid certification data
  When I POST /certifications
  Then the certification is created
Scenario: Update certification
  Given an existing certification
  When I PUT /certifications/{id}
  Then the certification is updated
Scenario: Delete certification
  Given an existing certification
  When I DELETE /certifications/{id}
  Then the certification is deleted
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Certification CRUD

**User Story 2:**
Title: Certification Expiry Alerts
User Story: As an employee, I want to be alerted before my certification expires so that I can renew on time.
Acceptance Criteria:
Scenario: Send expiry alerts
  Given a certification expiring in 30 or 7 days
  When the system checks expirations
  Then an alert is sent to the employee and supervisor
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Proactive compliance

**User Story 3:**
Title: Block Assignment to Tasks Requiring Valid Certification
User Story: As a scheduler, I want to prevent assignment of employees to tasks requiring certifications if their cert is expired.
Acceptance Criteria:
Scenario: Block expired certification assignment
  Given an expired certification
  When I try to assign the employee to a restricted task
  Then the system blocks the assignment
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Safety enforcement

**User Story 4:**
Title: Upload Proof of Certification

Acceptance Criteria:

Additional Details:
- Priority: High
- Story Points: 2

**User Story 5:**
Title: Display Certification Status on Profile
