Title: API Security Toggle

User Story: As a DevOps engineer, I want to toggle between API key and OAuth2 authentication via configuration so that the system can adapt to different security requirements.

Acceptance Criteria:
Scenario: API key authentication
Given the application is configured for API key
When a request is made with a valid API key
Then access is granted

Scenario: OAuth2 authentication
Given the application is configured for OAuth2
When a request is made with a valid OAuth2 token
Then access is granted

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: RBAC Implementation
- Notes: Document configuration steps.
