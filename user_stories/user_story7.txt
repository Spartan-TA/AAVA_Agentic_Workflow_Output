# E07: Training & Certification Tracking

## User Story 1
- Title: Manage Employee Certifications
- User Story: As an HR user, I want to CRUD certifications for employees so that compliance is tracked.
- Acceptance Criteria in Gherkin format:
  Scenario: Certification CRUD
  Given an employee profile
  When I add, update, or remove a certification
  Then the changes are saved and visible
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E02, E03
  * Notes: Support proof document upload

## User Story 2
- Title: Alert for Expiring Certifications
- User Story: As a supervisor, I want alerts for certifications expiring in 30/7 days so that renewals are timely.
- Acceptance Criteria in Gherkin format:
  Scenario: Expiry alert
  Given a certification nearing expiry
  When the threshold is reached
  Then an alert is sent to the employee and supervisor
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Certification records
  * Notes: Email/SMS/in-app notification

## User Story 3
- Title: Block Assignment for Expired Certifications
- User Story: As a scheduler, I want to block assignment to tasks requiring expired certifications so that only qualified staff are assigned.
- Acceptance Criteria in Gherkin format:
  Scenario: Assignment block
  Given an employee with expired certification
  When I try to assign them to a restricted task
  Then the system prevents the assignment and shows an error
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Certification status, scheduling
  * Notes: Integrate with shift assignment

## User Story 4
- Title: Display Certification Status on Profile
- User Story: As an employee, I want to see my certification status on my profile so that I am aware of renewals.
- Acceptance Criteria in Gherkin format:
  Scenario: Profile certification view
  Given an employee profile
  When viewed
  Then all certifications and their status are displayed
- Additional Details:
  * Priority: High
  * Story Points: 1
  * Dependencies: Certification records
  * Notes: Include expiry dates and proof documents
