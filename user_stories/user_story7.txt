Title: Implement Role-Based Access Control for Endpoints

User Story: As a system administrator I want to restrict access to sensitive endpoints based on user roles So that only authorized users can perform sensitive operations

Acceptance Criteria:
Scenario: Unauthorized access
Given a user without proper role
When they attempt to access a restricted endpoint
Then the API returns 401 Unauthorized

Scenario: Forbidden action
Given a user with insufficient privileges
When they attempt to perform a forbidden action
Then the API returns 403 Forbidden

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01), Employee CRUD APIs (E02)
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER
