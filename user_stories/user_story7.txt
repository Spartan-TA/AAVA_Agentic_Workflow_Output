Title: Support Pagination and Filtering for Employee Queries

User Story: As an HR administrator I want to paginate and filter employee records via the API so that I can efficiently manage large datasets and quickly find relevant employees

Acceptance Criteria:
Scenario: Paginated employee list
  Given there are more than 50 employees
  When I GET /employees?page=2&size=20
  Then I receive the correct page of results with metadata for total pages and count

Scenario: Filter by department
  Given employees belong to different departments
  When I GET /employees?department=Shipping
  Then only employees in the Shipping department are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD APIs
- Notes: Filtering should support department, role, status, and hireDate.
