Epic: E07 - Training & Certification Tracking

User Story 1: Certification CRUD
Title: Manage Employee Certifications
User Story: As an HR manager, I want to create, update, and delete certifications for employees so that compliance is tracked.
Acceptance Criteria (Gherkin):
Given access to certifications,
When I perform CRUD operations,
Then certifications are managed and visible on employee profiles.
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Supports safety.

User Story 2: Expiry Alerts
Title: Certification Expiry Notifications
User Story: As a supervisor, I want alerts for certifications expiring in 30/7 days so that renewals are timely.
Acceptance Criteria (Gherkin):
Given a certification is expiring,
When the expiry is within 30/7 days,
Then an alert is sent to the employee and supervisor.
Additional Details:
Priority: High
Story Points: 1
Dependencies: E02, E03
Notes: Prevents lapses.

User Story 3: Assignment Blocking
Title: Block Assignment to Expired Certifications
User Story: As a scheduler, I want to block assignment of tasks to employees with expired certifications so that safety is ensured.
Acceptance Criteria (Gherkin):
Given a certification is expired,
When I assign a task requiring certification,
Then the assignment is blocked.
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Supports compliance.

User Story 4: Proof Document Upload
Title: Upload Certification Proof
User Story: As an employee, I want to upload proof documents for certifications so that records are complete.
Acceptance Criteria (Gherkin):
Given a certification is created,
When I upload a document,
Then the proof is attached to the certification record.
Additional Details:
Priority: High
Story Points: 1
Dependencies: E02, E03
Notes: Supports audits.
