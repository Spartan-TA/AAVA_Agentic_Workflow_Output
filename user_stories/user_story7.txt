Title: List and Filter Employee Records via API

User Story: As an HR manager I want to list and filter employee records using the API So that I can quickly find employees by department, role, or status

Acceptance Criteria:
Scenario: Employee listing and filtering
Given multiple employee records exist When I GET /employees with filter parameters Then only matching employees are returned and results are paginated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation (E02)
- Notes: Support filtering by department, role, shiftGroup, status, and pagination
