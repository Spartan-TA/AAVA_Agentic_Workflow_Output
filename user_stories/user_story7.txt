Title: Training & Certification Tracking
User Story 1: As an HR user I want to create and manage certifications for employees So that compliance is tracked
Acceptance Criteria:
Scenario: Certification CRUD
Given I am authenticated as HR
When I create, update, or delete a certification
Then changes are reflected in employee profiles
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee master data, RBAC
- Notes: Support document upload

User Story 2: As a system I want to alert employees and supervisors 30/7 days before certification expiry So that renewals are timely
Acceptance Criteria:
Scenario: Expiry alert
Given a certification is nearing expiry
When alert conditions are met
Then notifications are sent to relevant users
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notification module
- Notes: Localized templates

User Story 3: As a supervisor I want to block assignment to tasks requiring expired certifications So that safety is ensured
Acceptance Criteria:
Scenario: Assignment block
Given a certification is expired
When assignment is attempted
Then the action is blocked and user notified
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Shift management, Certification tracking
- Notes: Show status on assignment screen

User Story 4: As a worker I want to view my certification status on my profile So that I know my qualifications
Acceptance Criteria:
Scenario: Certification status view
Given certifications exist
When I access my profile
Then I see current and expired certifications
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Certification CRUD
- Notes: Mobile-friendly

User Story 5: As an HR user I want to upload proof documents for certifications So that records are complete
Acceptance Criteria:
Scenario: Proof document upload
Given a certification is created
When I upload a document
Then it is stored and linked to the certification
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification CRUD
- Notes: Support PDF/JPG formats
