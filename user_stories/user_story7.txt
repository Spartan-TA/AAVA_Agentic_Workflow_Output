### Epic E06: Leave & Absence Management

**User Story 1: Request Leave**
- Title: Employee Leave Request
- User Story: As a Worker, I want to request PTO, sick, or unpaid leave so that my time off is tracked.
- Acceptance Criteria:
  ```
  Given a WORKER is authenticated,
  When they submit a leave request,
  Then the request is recorded and pending approval.
  ```
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: PTO, sick, unpaid options.

**User Story 2: Approve/Deny Leave**
- Title: Supervisor Leave Approval
- User Story: As a Supervisor, I want to approve or deny leave requests so that staffing is managed.
- Acceptance Criteria:
  ```
  Given a leave request is pending,
  When a SUPERVISOR reviews,
  Then they can approve or deny the request.

  Given a leave is approved,
  When the schedule is updated,
  Then the employee's shifts are flagged for coverage.
  ```
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Approval workflow.

**User Story 3: Update Leave Balances**
- Title: Update Leave Accrual Balances
- User Story: As an HR user, I want leave balances to update automatically so that accruals are accurate.
- Acceptance Criteria:
  ```
  Given a leave is approved,
  When the system processes the request,
  Then the employee's leave balance is updated.
  ```
- Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E05, Notes: Policy-driven.

**User Story 4: Exclude Leave from Payroll and Scheduling**
- Title: Integrate Leave with Payroll and Scheduling
- User Story: As a System Admin, I want approved leaves to be excluded from payroll hours and scheduling so that records are accurate.
- Acceptance Criteria:
  ```
  Given a leave is approved,
  When payroll and scheduling are processed,
  Then the employee's hours are adjusted accordingly.
  ```
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, Notes: Integration hooks.

**User Story 5: Export Approved Leaves**
- Title: Export Approved Leave Data
- User Story: As an HR user, I want to export approved leave data so that compliance reports are complete.
- Acceptance Criteria:
  ```
  Given approved leave records exist,
  When HR exports leave data,
  Then a report is generated showing all approved leaves.
  ```
- Additional Details: Priority: Medium, Story Points: 1, Dependencies: E02, E03, E05, Notes: Exportable format.
