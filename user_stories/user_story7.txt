Title: Training & Certification Tracking

User Story: As a safety manager I want to track employee certifications and expirations so that only qualified staff are assigned to equipment-sensitive roles and compliance is maintained.

Acceptance Criteria:
Scenario: Add certification
Given an employee profile exists
When I add a new certification with expiry date
Then the certification is saved and visible on the profile

Scenario: Expiry alerts
Given a certification is nearing expiry
When the expiry is within 30 or 7 days
Then an alert is generated for the employee and supervisor

Scenario: Block unqualified assignment
Given a certification is expired
When I attempt to assign the employee to a restricted task
Then the system blocks the assignment

Scenario: Upload proof document
Given a certification is added
When I upload a proof document
Then the document is attached to the certification record

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee Master Data (CRUD), Role Based Access Control (RBAC)
- Notes: Certification status must be visible on employee profiles; scheduling checks required.
