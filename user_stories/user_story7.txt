Title: Employee Soft-Delete Support
User Story: As an HR manager I want to soft-delete employee records So that I can retain historical data without permanent removal
Acceptance Criteria:
Scenario: Soft-Delete Employee
Given an employee record exists
When I perform a delete operation
Then the record should be flagged as deleted but remain in the database
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Ensure soft-deleted records are excluded from active queries
