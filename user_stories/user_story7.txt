Title: Provide OpenAPI Schemas with Examples

User Story: As a developer I want OpenAPI schemas with example requests and responses So that API consumers can easily integrate

Acceptance Criteria:

Scenario: OpenAPI docs include all employee endpoints
Given the application is running
When I access /swagger-ui or /v3/api-docs
Then all employee endpoints are documented

Scenario: Example payloads are present
Given the OpenAPI docs are generated
When I view the schema for POST /employees
Then I see example request and response bodies

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD APIs
- Notes: Use springdoc-openapi; keep docs up to date with code changes
