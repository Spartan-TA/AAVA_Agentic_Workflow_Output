EPIC E07 - Training & Certification Tracking

===========================================

User Story 1: Certification CRUD
---------------------------------------------
Title: Manage Employee Certifications (CRUD)

User Story: As a safety manager, I want to add, update, and delete certifications for employees so that compliance is tracked.

Acceptance Criteria:
Scenario: Certification management
  Given the certification endpoint
  When CRUD operations are performed
  Then certifications are updated accordingly

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support proof document upload.

===========================================

User Story 2: Expiry Alerts
---------------------------------------------
Title: Alert for Certification Expiry (30/7 Days)

User Story: As a supervisor, I want alerts for certifications expiring in 30/7 days so that renewals are timely.

Acceptance Criteria:
Scenario: Expiry notification
  Given a certification nearing expiry
  When within alert window
  Then an alert is sent to employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Email/SMS integration.

===========================================

User Story 3: Scheduling Checks for Certification
---------------------------------------------
Title: Block Assignment to Tasks Requiring Valid Certification

User Story: As a scheduler, I want to block assignment to tasks if certification is expired so that only qualified staff are assigned.

Acceptance Criteria:
Scenario: Certification validation
  Given a task requiring certification
  When employee's cert is expired
  Then assignment is blocked

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Integrate with scheduling.
