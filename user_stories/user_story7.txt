Title: Update Employee Record

User Story: As an HR manager I want to update employee records via API So that employee information remains accurate and up to date

Acceptance Criteria:
Scenario: Employee update
Given an existing employee record
When I send a PUT or PATCH request to /employees/{id} with updated details
Then the employee record is updated and changes are reflected in subsequent queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain and CRUD APIs
- Notes: API must validate updates and maintain audit history.
