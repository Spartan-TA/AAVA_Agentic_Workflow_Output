EPIC 11: PAYROLL EXPORT INTEGRATION

===========================================

Title: Payroll Export Generation

User Story: As a payroll administrator I want to generate payroll-ready files from attendance and leave So that payroll runs are accurate and automated

Acceptance Criteria:
Scenario: Generate payroll export
Given approved attendance and leave records exist
When I export payroll data
Then the file matches provider schema

Scenario: Failed delivery retry
Given a payroll export fails
When the system retries delivery
Then exponential backoff is applied

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Attendance, Leave Management
- Notes: Secure delivery via SFTP/API; audit log for every export
