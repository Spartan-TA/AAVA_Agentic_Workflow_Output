Title: Automate Build and Deployment Pipeline

Acceptance Criteria:
Scenario: Pipeline automation
Given code changes are committed
When the pipeline runs
Then builds, tests, and deployments are executed automatically
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: CI/CD tools
- Notes: Supports rollback on failure
