Title: Certification Proof Document Upload
User Story: As an employee I want to upload proof documents for my certifications so that HR can verify my qualifications
Acceptance Criteria:
Scenario: Upload certification document
Given I have a certification to add
When I upload a document as proof
Then the document is stored and linked to my certification record
Scenario: View uploaded document
Given a certification has a document attached
When HR views the certification
Then the document is accessible for review
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Support PDF, image formats; enforce file size limits
