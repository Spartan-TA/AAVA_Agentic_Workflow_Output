Title: Employee Uploads Certification Proof

User Story: As an employee I want to upload proof of completed certifications So that my qualifications are up to date in the system

Acceptance Criteria:
Scenario: Uploading certification proof
Given I have completed a required certification
When I upload the certificate document
Then the document should be stored and visible to my manager for verification

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee profile, document storage
- Notes: Support common file formats (PDF, JPG, PNG).
