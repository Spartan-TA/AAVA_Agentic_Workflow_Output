Title: Safety Metrics Dashboard Endpoints

User Story: As a safety manager I want access to dashboard endpoints showing safety KPIs and incident trends so that I can monitor workplace safety and take proactive measures

Acceptance Criteria:
Scenario: View safety metrics dashboard
  Given safety incidents are recorded in the system
  When I access the safety dashboard
  Then I see up-to-date KPIs, trends, and filterable metrics

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02 (User Management), E03 (Scheduling)
- Notes: Metrics must be exportable for BI tools
