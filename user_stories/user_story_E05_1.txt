Title: E05-1 Create and Manage Shift Templates

User Story:
As a scheduler,
I want to create and manage reusable shift templates,
So that I can quickly assign standard shift patterns to employees and teams.

Acceptance Criteria:
Given a set of shift parameters (start time, end time, break, role, location),
When a shift template is created or updated,
Then it is saved and available for assignment to employees.

Given a request to view shift templates,
When the API or UI is accessed,
Then all active templates are listed with their details.

Given a template is no longer needed,
When it is deleted,
Then it is removed from the list and cannot be assigned to future shifts.

Additional Details:
- Templates must support recurring and one-time shifts.
- Audit log entry must be created for all template changes.
- API and UI must support full CRUD operations for templates.
- Templates must be versioned for auditability.
