**E08: Safety Incidents & OSHA Reporting**

1. Title: Record Safety Incident
User Story: As a supervisor, I want to record safety incidents with severity, location, description, and involved employees so that all events are tracked for compliance.
Acceptance Criteria:
Scenario: Incident Recording
Given incident details
When I POST to /safety/incidents
Then the incident is logged and validated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support near-misses.

2. Title: Incident Investigation Workflow
User Story: As a safety manager, I want to manage incident status from Open to Investigating to Resolved so that corrective actions are tracked.
Acceptance Criteria:
Scenario: Status Workflow
Given an open incident
When I update status
Then the workflow progresses and actions are logged
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Story 1
- Notes: Audit status changes.

3. Title: OSHA Summary Export
User Story: As a compliance officer, I want to export OSHA 300/300A summaries so that regulatory reporting is simplified.
Acceptance Criteria:
Scenario: OSHA Export
Given recorded incidents
When I request an export
Then a file is generated with required fields
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Validate field mapping.

4. Title: Safety Metrics Dashboard
User Story: As a safety manager, I want a dashboard of safety KPIs so that I can monitor trends and take action.
Acceptance Criteria:
Scenario: Metrics Dashboard
Given incident data
When I view the dashboard
Then KPIs are displayed with filters
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Support export.
