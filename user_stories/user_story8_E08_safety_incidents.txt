Epic E08: Safety Incidents & OSHA Reporting

---

User Story 1: Record Safety Incidents
As a supervisor, I want to record safety incidents and near-misses so that safety data is tracked.

Acceptance Criteria:
Scenario: Incident creation
  Given valid incident data
  When I POST to /safety/incidents
  Then the incident is saved

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Severity and location required

---

User Story 2: Incident Workflow
As a safety officer, I want incidents to progress through investigation and resolution so that corrective actions are tracked.

Acceptance Criteria:
Scenario: Status workflow
  Given an open incident
  When investigation starts
  Then status changes to Investigating

Scenario: Resolution
  Given an investigating incident
  When corrective actions are completed
  Then status changes to Resolved

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Workflow auditable

---

User Story 3: OSHA Summary Export
As compliance, I want to export OSHA 300/300A summaries so that regulatory reports are generated.

Acceptance Criteria:
Scenario: OSHA export
  Given incident data
  When I request OSHA summary
  Then a file is generated with required fields

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export format matches OSHA requirements

---

User Story 4: Safety Metrics Dashboard
As management, I want dashboard endpoints for safety KPIs so that I can monitor trends.

Acceptance Criteria:
Scenario: Metrics endpoint
  Given incident data
  When I access the dashboard
  Then KPIs are displayed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Metrics include incident rates
