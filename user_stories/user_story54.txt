Title: Announcements Dashboard and Audit Logging

User Story:
As a supervisor or admin, I want to post announcements visible on the dashboard and have all actions logged so that important information is communicated and compliance is demonstrated.

Acceptance Criteria:
- Scenario: Post announcement to dashboard
  Given a supervisor or admin is authenticated
  When they post an announcement
  Then it is visible to all targeted users on their dashboard

- Scenario: Announcement actions are logged
  Given announcements are posted, edited, or deleted
  When the audit log is reviewed
  Then all actions are traceable by user and timestamp

Additional Details:
- Announcements must support targeting by role, department, or location
- All announcement actions must be exportable for audit
- Announcements must be dismissible by users
