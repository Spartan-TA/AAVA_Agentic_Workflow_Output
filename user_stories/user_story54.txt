Title: Locale-Specific Configuration

User Story: As a system administrator I want to configure locale-specific settings for each tenant So that users see dates, times, and formats relevant to their region

Acceptance Criteria:
Scenario: Setting locale configuration
Given multiple tenants exist
When I configure locale settings for a tenant
Then users of that tenant should see region-appropriate formats throughout the system

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Tenant management, localization module
- Notes: Support for language, currency, and time zone.
