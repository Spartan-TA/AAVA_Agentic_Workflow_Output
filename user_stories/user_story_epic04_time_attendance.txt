EPIC 04: TIME & ATTENDANCE (CLOCK IN/OUT)

---

Title: Clock In Endpoint

User Story: As a WORKER I want to clock in at the start of my shift So that my attendance is accurately recorded

Acceptance Criteria:

Scenario: Successful Clock In
Given my shift is scheduled
When I POST to /attendance/clock-in with valid location and device info
Then my clock-in event should be recorded and associated with my shift

Scenario: Geofence Validation
Given geofence is enabled
When I clock in outside the allowed area
Then the system should reject the clock-in

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC
- Notes: Capture device and location data

---

Title: Clock Out Endpoint

User Story: As a WORKER I want to clock out at the end of my shift So that my worked hours are calculated

Acceptance Criteria:

Scenario: Successful Clock Out
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out event should be recorded and hours computed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD, RBAC
- Notes: Validate shift association

---

Title: Handle Missed Punches

User Story: As a WORKER I want to request corrections for missed clock-in/out events So that my attendance records are accurate

Acceptance Criteria:

Scenario: Correction Request
Given I missed a clock-in/out
When I submit a correction request
Then an approval task should be created for my supervisor

Scenario: Approval Workflow
Given a correction request is pending
When my supervisor approves it
Then the attendance record should be updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Attendance, RBAC
- Notes: Track correction history

---

Title: Attendance Reports Export

User Story: As an HR user I want to export attendance reports in CSV format So that I can analyze and share attendance data

Acceptance Criteria:

Scenario: CSV Export
Given attendance data exists
When I request a report export
Then a CSV file should be generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance
- Notes: Include shift and employee details
