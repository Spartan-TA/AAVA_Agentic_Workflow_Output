Title: Shift Swap Request

User Story: As a warehouse employee, I want to request a shift swap with a colleague So that I can manage my work-life balance.

Acceptance Criteria:
Scenario: Shift swap request
Given I am assigned to a shift
When I submit a swap request to a colleague
Then the manager is notified and can approve or reject the request

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Shift Scheduling
- Notes: Swap history tracked for compliance
