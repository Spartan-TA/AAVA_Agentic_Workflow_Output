Title: UI Localization and Language Toggle

User Story: As a worker I want to toggle the UI language between English and Spanish so that I can use the application in my preferred language

Acceptance Criteria:
Scenario: Changing UI language
Given I am on any page
When I select a different language from the language toggle
Then the UI updates to display all text in the selected language

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: Localization module, UI framework
- Notes: All user-facing text must be translatable
