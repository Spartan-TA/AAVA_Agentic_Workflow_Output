Title: Update Employee Record

User Story:
As an HR manager, I want to update employee details such as department, role, or status so that records remain accurate and reflect current assignments.

Acceptance Criteria:
Given an existing employee record,
When I PUT or PATCH to /employees/{id} with updated details,
Then the employee record is updated and changes are reflected in all related modules.

Additional Details:
Priority: High
Story Points: 2
Dependencies: Employee record must exist
Notes: Changes should be tracked for audit purposes.
