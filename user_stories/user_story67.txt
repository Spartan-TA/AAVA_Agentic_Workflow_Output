Title: Receive Push Notifications on Mobile

User Story:
As an employee, I want to receive push notifications from the EMS on my mobile device so that I am promptly informed of important updates and tasks.

Acceptance Criteria:
Scenario 1: Enable push notifications
  Given the PWA is installed
  When I enable push notifications in settings
  Then I receive alerts for new tasks, announcements, and messages

Scenario 2: Manage notification preferences
  Given push notifications are enabled
  When I update my preferences
  Then only selected types of notifications are sent to my device

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: PWA framework, notification system
Notes: Push notifications should be configurable and respect user preferences.
