Title: RBAC Role Setup and Endpoint Security

User Story: As a system administrator I want to configure roles (ADMIN, HR, SUPERVISOR, WORKER) and secure endpoints so that only authorized users can access sensitive operations.

Acceptance Criteria:
Scenario: Role configuration
  Given the application is running
  When I assign roles to users
  Then users have access only to endpoints permitted by their role

Scenario: Endpoint security
  Given a user is authenticated
  When they access a restricted endpoint
  Then unauthorized requests return 401 and forbidden actions return 403

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee master data (E02), Project scaffolding (E01)
- Notes: Security rules must be covered by automated tests; roles must be configurable via Spring Security.
