Title: Update Employee Record via API

User Story: As an HR manager I want to update employee details using the API So that employee information remains current and accurate

Acceptance Criteria:
Scenario: Employee update
Given an existing employee record When I PUT or PATCH updated details to /employees/{id} Then the employee record is updated and changes are reflected in queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation (E02)
- Notes: Validate input and support partial updates
