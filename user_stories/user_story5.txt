Title: Employee Domain CRUD - Update Employee
User Story: As an HR user I want to update employee details So that records remain accurate as employees change roles or departments.
Acceptance Criteria:
Scenario: Update employee information
Given an existing employee record
When I PUT or PATCH to /employees/{id} with updated data
Then the employee record is updated and changes are reflected in GET requests
