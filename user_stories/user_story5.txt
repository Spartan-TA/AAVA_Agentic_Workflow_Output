Title: Create Employee Record

User Story: As an HR user I want to create a new employee record with all required fields So that employee information is accurately stored and available for downstream processes

Acceptance Criteria:

Scenario: Successful employee creation
Given I am authenticated as HR
When I submit a POST request to /employees with valid data (name, badgeId, role, department, shiftGroup, hireDate, status)
Then a new employee record should be created and returned

Scenario: Badge ID uniqueness enforced
Given an employee with badgeId X exists
When I attempt to create another employee with badgeId X
Then I should receive a validation error indicating badgeId must be unique

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: All required fields must be validated before creation.
