Title: Provide Explanations for Assertion and Reason Answers

User Story: As a student I want to view explanations for assertion and reason MCQ answers So that I can understand the reasoning behind correct and incorrect options

Acceptance Criteria:
Scenario: Viewing Answer Explanations
  Given I have completed an assertion and reason MCQ assessment
  When I review my results
  Then I should see explanations for each question's correct answer

Additional Details:
Priority: Low
Story Points: 2
Dependencies: Content authoring for explanations
Notes: Explanations can be authored by teachers during question creation
