Title: Application Runs on Standard Port
User Story: As a developer I want the application to run on port 8080 by default So that local development and deployment are consistent across environments
Acceptance Criteria:
Scenario: Application starts on port 8080
Given the application is started with default configuration
When I access http://localhost:8080
Then the application should be reachable and serve the default endpoint

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: Port should be configurable via environment variable for CI/CD compatibility.
