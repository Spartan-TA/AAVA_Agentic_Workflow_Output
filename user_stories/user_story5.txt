Title: Enforce Unique Badge ID

User Story: As an HR user, I want to ensure each employee has a unique badgeId so that duplicate records are prevented.

Acceptance Criteria:

Scenario: Unique badgeId enforcement
Given an existing employee with badgeId X
When I try to create another employee with badgeId X
Then the system rejects the request with a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD
- Notes: Error message must be clear
