Title: Employee Data Pagination & Filtering

User Story: As an HR manager I want to paginate and filter employee data via the API So that I can efficiently browse and locate specific employee records

Acceptance Criteria:
Scenario: Paginated employee list
Given a large set of employee records
When I request a specific page and filter criteria
Then the API should return only the relevant subset of employee data

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Support filtering by department, role, and employment status.
