Title: Implement Employee CRUD APIs

User Story: As an HR manager I want to create, read, update, and delete employee records via API So that employee data is accurately maintained in the system

Acceptance Criteria:
Scenario: Employee CRUD operations
Given valid employee data When I use POST/GET/PUT/PATCH/DELETE on /employees Then the corresponding employee record is created, retrieved, updated, or deleted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: API must support pagination and filtering
