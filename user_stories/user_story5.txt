Title: Employee Data Validation and Pagination

User Story: As a system, I want to enforce unique badgeId and support pagination/filtering on employee queries so that data integrity and performance are maintained.

Acceptance Criteria:
Scenario: BadgeId uniqueness validation
Given multiple employees exist
When I attempt to create an employee with an existing badgeId
Then the request is rejected with a validation error

Scenario: Pagination and filtering
Given many employees exist
When I query /employees with pagination/filter parameters
Then the response contains the correct subset of employees

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Include OpenAPI schemas with examples.
