Title: Employee List Filtering & Pagination
User Story: As an HR user, I want to filter and paginate employee records by department, role, and status so that I can efficiently manage large staff lists.
Acceptance Criteria:
  - Given filter parameters, when I GET /employees?department=X&role=Y, then only matching employees are returned.
  - Given a large dataset, when I request a page, then results are paginated per API spec.
Additional Details:
  - Priority: High
  - Story Points: 2
  - Dependencies: E01, E02
  - Notes: Must return OpenAPI examples.
