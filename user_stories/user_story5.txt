Title: Create Employee Record via API

User Story: As an HR user I want to create a new employee record with all required fields So that employee data is accurately captured in the system

Acceptance Criteria:

Scenario: Successful employee creation
Given I have valid employee details (name, badgeId, role, department, shiftGroup, hireDate, status)
When I POST to /employees with the details
Then the employee is created and returned with a unique ID

Scenario: Duplicate badgeId is rejected
Given an employee exists with badgeId '12345'
When I attempt to create another employee with badgeId '12345'
Then the API responds with a validation error and the record is not created

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: badgeId must be unique and required.
