Title: Employee Data Validation & Filtering
User Story: As an HR user, I want employee APIs to support pagination and filtering so that I can efficiently manage large employee lists.
Acceptance Criteria:
  Given a large employee dataset,
  When I request /employees with pagination parameters,
  Then I receive a paginated list.

  Given filter parameters (e.g., department, status),
  When I request /employees,
  Then only matching employees are returned.

Additional Details:
  Priority: Medium
  Story Points: 3
  Dependencies: Employee CRUD API
  Notes: OpenAPI schemas with examples.
