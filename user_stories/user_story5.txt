Title: Implement Employee CRUD APIs and Web DTOs

User Story: As an HR manager I want to create, read, update, and delete employee records via APIs and web DTOs So that I can manage warehouse employee master data efficiently.

Acceptance Criteria:
Scenario: Create employee
  Given valid employee details
  When I POST to /employees
  Then a new employee record is created and returned

Scenario: Read employee
  Given an existing employee
  When I GET /employees/{id}
  Then the employee details are returned

Scenario: Update employee
  Given an existing employee
  When I PUT or PATCH /employees/{id} with updated details
  Then the employee record is updated

Scenario: Delete employee
  Given an existing employee
  When I DELETE /employees/{id}
  Then the employee record is soft-deleted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: DTOs must include name, badgeId, role, department, shiftGroup, hireDate, status.
