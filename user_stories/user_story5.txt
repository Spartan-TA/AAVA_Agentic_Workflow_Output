Title: Update Employee Record via API

User Story: As an HR Manager I want to update employee details via a secure API So that employee information remains accurate and current

Acceptance Criteria:
Scenario: Employee Update
Given I have HR role access
When I PUT/PATCH updated data to /employees/{id}
Then the employee record is updated and changes are reflected in the system

Scenario: Validation on Update
Given an employee exists
When I update badgeId to a value already in use
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: user_story4.txt
- Notes: API must support partial updates; OpenAPI schema must be documented.
