Title: Create Employee Record
User Story: As an HR manager I want to create a new employee record So that I can onboard staff and maintain accurate employee data
Acceptance Criteria:
Scenario: Successful employee creation Given I have valid employee details When I submit the create employee form Then a new employee record is created and visible in the employee list
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding & Domain Setup (E01)
- Notes: badgeId must be unique; OpenAPI schema required

Title: Delete (Soft) Employee Record
User Story: As an HR manager I want to soft-delete employee records So that I can retain historical data while removing inactive employees from active lists

Scenario: Soft-delete employee Given an active employee record When I choose to delete Then the record is marked inactive and excluded from active queries
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data CRUD (E02)
- Notes: Soft-delete only; must support restore
