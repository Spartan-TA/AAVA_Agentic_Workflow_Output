Title: Implement Employee CRUD APIs

User Story: As an HR user I want to create, read, update, and delete employee records via API So that employee data is managed efficiently

Acceptance Criteria:
Scenario: Create employee
  Given valid employee data
  When I call the create employee API
  Then a new employee record is created

Scenario: Update employee
  Given an existing employee
  When I call the update employee API with new data
  Then the employee record is updated

Scenario: Delete employee
  Given an existing employee
  When I call the delete employee API
  Then the employee record is removed

Scenario: Get employee
  Given an existing employee
  When I call the get employee API
  Then the employee data is returned

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee entity and repository
- Notes: Validate all input fields
