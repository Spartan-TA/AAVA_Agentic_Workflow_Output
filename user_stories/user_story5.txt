Title: Shift Template Management

User Story: As a scheduler I want to create and manage recurring shift templates So that scheduling is efficient and consistent.

Acceptance Criteria:
Scenario: Shift template CRUD operations
Given I access the shift management module
When I create, update, or delete a shift template
Then the template is available for assignment and conflicts are detected

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03, E04
- Notes: Audit entries generated for changes.

Title: Bulk Shift Assignment

User Story: As a supervisor I want to assign shifts to multiple employees in bulk So that staffing can be managed quickly.

Acceptance Criteria:
Scenario: Bulk assignment workflow
Given a list of employees and a shift template
When I perform a bulk assignment
Then all selected employees are assigned shifts without conflicts

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Workers see personal upcoming shifts.
