Title: Retrieve Employee Records via API

User Story: As an HR manager I want to retrieve employee records using a GET API So that I can view and manage employee information efficiently

Acceptance Criteria:
Scenario: Employee retrieval
Given employees exist in the system
When I send a GET request to /employees
Then I receive a paginated and filterable list of employees with all relevant details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation
- Notes: Support pagination, filtering, and OpenAPI schema documentation.
