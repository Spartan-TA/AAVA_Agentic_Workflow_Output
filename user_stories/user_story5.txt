Title: Create Employee Record via API

User Story: As an HR manager I want to create a new employee record using an API so that employee onboarding is streamlined and consistent.

Acceptance Criteria:
Scenario: Successful employee creation
Given I have valid employee data
When I submit a POST request to /employees
Then a new employee record is created with a unique badgeId and all required fields

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: API must validate required fields and enforce unique badgeId.
