Title: Employee CRUD - Create Employee

User Story: As an HR user I want to create a new employee record with name, badgeId, role, department, shiftGroup, hireDate, and status So that employee data is centrally managed

Acceptance Criteria:
Scenario: Create employee
Given valid employee details
When I POST to /employees
Then the employee is created with a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: badgeId must be unique; OpenAPI schema must be updated
