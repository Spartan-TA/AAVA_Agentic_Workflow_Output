Title: Edit Employee Details

User Story: As an HR manager I want to edit employee details So that I can keep employee records up to date

Acceptance Criteria:
Scenario: Edit employee details
Given I am on the employee profile page
When I update the employee's information and save
Then the changes should be reflected in the employee record

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD module
- Notes: Validate all required fields before saving.
