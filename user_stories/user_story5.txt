Title: Create Employee Record

User Story: As an HR manager I want to create a new employee record So that I can onboard new staff into the warehouse system

Acceptance Criteria:
Scenario: Successful employee creation
Given I am on the employee creation form
When I enter valid employee details and submit
Then the employee record should be created with a unique badgeId and visible in the employee list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding (E01)
- Notes: Enforce badgeId uniqueness and validate required fields.
