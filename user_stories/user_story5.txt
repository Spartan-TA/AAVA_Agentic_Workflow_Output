Title: Employee Master Data - Soft Delete & Filtering

User Story: As an HR user, I want to soft-delete employees and filter by status so that records are retained for compliance and reporting.

Acceptance Criteria:
Scenario: Soft Delete Employee
Given an employee record
When I DELETE /employees/{id}
Then the employee status is updated to "inactive" and record is not removed

Scenario: Filter by Status
Given multiple employees
When I GET /employees?status=inactive
Then only inactive employees are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Soft-deleted records excluded from active lists
