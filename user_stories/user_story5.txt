Title: Employee Data Filtering and Pagination
User Story: As an HR manager, I want to filter and paginate employee lists so that I can efficiently manage large datasets.
Acceptance Criteria:
Scenario: Filter by department
Given employees exist in multiple departments
When I GET /employees?department=Shipping
Then only employees in Shipping are returned

Scenario: Paginate results
Given more than 50 employees exist
When I GET /employees?page=2&size=25
Then I receive the correct page of results

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Improves usability for large warehouses
