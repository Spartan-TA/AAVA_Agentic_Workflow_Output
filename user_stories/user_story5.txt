**User Story 5: Notifications - Receive Real-Time Alerts**

**Title:** Real-Time Notification Delivery

**User Story:**
As a user, I want to receive real-time notifications about important events so that I am promptly informed and can take necessary actions.

**Acceptance Criteria:**
**Scenario 1:** Receive Notification
Given an important event occurs (e.g., new message, system alert)
When the user is logged in
Then a notification is displayed in the notification center
And an alert icon is updated

**Scenario 2:** Notification Read Status
Given the user has unread notifications
When the user views a notification
Then the notification status changes to "read"
And the unread count decreases

**Scenario 3:** Notification Preferences
Given the user is on the notification settings page
When the user updates their notification preferences
Then only selected types of notifications are delivered

**Additional Details:**
- Priority: High
- Story Points: 8
- Dependencies: Notification service, event trigger module, user preferences API
- Notes: Support both in-app and email notifications; ensure notifications are not duplicated.
