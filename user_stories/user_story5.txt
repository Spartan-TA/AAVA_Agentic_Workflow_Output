Title: Create Employee Record
User Story: As an HR manager I want to create employee records with name, badgeId, role, department, shiftGroup, hireDate, and status So that I can maintain a single source of truth for warehouse employees
Acceptance Criteria:
Scenario: Employee creation
Given I have HR role access
When I submit a new employee record via the API
Then the employee is created with a unique badgeId and all required fields
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: API must validate required fields and enforce badgeId uniqueness
