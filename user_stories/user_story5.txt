Title: Update Employee Record via API

User Story: As an HR manager I want to update employee records via API So that changes to employee details are accurately reflected in the system

Acceptance Criteria:
Scenario: Successful employee update
  Given an existing employee record
  When I PUT or PATCH to /employees/{id} with valid changes
  Then the employee record is updated and audit log is generated

Scenario: Invalid update
  Given an invalid update request
  When I PUT or PATCH to /employees/{id}
  Then I receive a validation error and no changes are made

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story4.txt
- Notes: Audit log must capture before/after state for compliance.
