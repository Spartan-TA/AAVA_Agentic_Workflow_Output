Title: Create Employee Record via API

User Story: As an HR manager I want to create a new employee record using an API So that employee onboarding is streamlined and accurate

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record should be created with a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: API must validate required fields; badgeId must be unique; OpenAPI schema must include examples
