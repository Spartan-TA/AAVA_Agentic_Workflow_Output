Title: Create Employee Record

User Story: As an HR manager I want to create new employee records via API So that employee data is centralized and accessible across systems

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record is created with a unique badgeId and all required fields

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding (E01)
- Notes: API must validate required fields and enforce unique badgeId.
