Title: Update Employee Record

User Story: As an HR manager I want to update an employee's details So that changes in role, department, or status are accurately reflected

Acceptance Criteria:

Scenario: Successful employee update
Given an existing employee record
When I submit a PUT or PATCH request with updated details
Then the employee record should be updated and returned with the new information

Scenario: Invalid update
Given an employee record
When I submit an update with an invalid badgeId or missing required fields
Then the system should reject the request with a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee record creation (E02)
- Notes: All changes should be tracked for audit purposes.
