### E05 - Shift & Schedule Management

**User Story 1:**
Title: CRUD for Shift Templates
User Story: As a scheduler, I want to create, update, and delete shift templates so that recurring schedules are easy to manage.
Acceptance Criteria:
Scenario: Create shift template
  Given valid shift data
  When I POST /shifts/templates
  Then the template is created
Scenario: Update shift template
  Given an existing template
  When I PUT /shifts/templates/{id}
  Then the template is updated
Scenario: Delete shift template
  Given an existing template
  When I DELETE /shifts/templates/{id}
  Then the template is deleted
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Template management

**User Story 2:**
Title: Assign Shifts to Employees
User Story: As a supervisor, I want to assign shifts to employees so that staffing is planned in advance.
Acceptance Criteria:
Scenario: Successful shift assignment

  Then the assignments are visible in their schedules
Additional Details:
- Priority: High
- Story Points: 3

**User Story 3:**
