# E04: Time & Attendance (Clock In/Out)

## User Story 1: Clock In/Out with Device and Geofence Capture
**User Story:**  
As a warehouse worker, I want to clock in and out using my device and location so that attendance is accurately recorded.

**Acceptance Criteria (Gherkin):**
```
Given a valid device and location
When I POST to /attendance/clock-in
Then my clock-in event is recorded with timestamp and location

Given I clock out
When I POST to /attendance/clock-out
Then my clock-out event is recorded
```

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: E02, E03  
Notes: Geofence is optional.

---

## User Story 2: Calculate Hours Worked per Shift
**User Story:**  
As a payroll manager, I want the system to calculate hours worked per shift so that payroll is accurate.

**Acceptance Criteria (Gherkin):**
```
Given clock-in and clock-out events for a shift
When I view the attendance record
Then total hours worked are displayed
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Handle overnight shifts.

---

## User Story 3: Handle Missed Punches and Corrections Workflow
**User Story:**  
As a supervisor, I want to approve corrections for missed punches so that attendance data is accurate.

**Acceptance Criteria (Gherkin):**
```
Given a missed punch is detected
When an employee submits a correction
Then a task is created for supervisor approval

Given a supervisor approves a correction
Then the attendance record is updated
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Track correction history.

---

## User Story 4: Export Attendance Reports (CSV)
**User Story:**  
As an HR user, I want to export attendance data as CSV so that I can analyze and share reports.

**Acceptance Criteria (Gherkin):**
```
Given attendance data exists
When I request a CSV export
Then a file is generated with all relevant fields
```

**Additional Details:**  
Priority: High  
Story Points: 1  
Dependencies: E02, E03  
Notes: Include filters for date range, department.
