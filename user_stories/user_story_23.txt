Title: Block Assignment for Expired Certifications
User Story: As a scheduler I want the system to prevent assignment of employees to tasks requiring certifications if their certification is expired so that we maintain compliance and safety
Acceptance Criteria:
Scenario: Block assignment for expired certification
Given an employee has an expired certification required for a task
When I attempt to assign them to the task
Then the system blocks the assignment and displays an error
Scenario: Allow assignment for valid certification
Given an employee has a valid certification
When I assign them to the task
Then the assignment is successful
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Applies to all certification-dependent tasks
