Title: Submit PTO Request

User Story: As an employee I want to submit a Paid Time Off (PTO) request So that my manager can review and approve my leave

Acceptance Criteria:
Scenario: Successful PTO request submission
Given I am logged into the system
When I fill out the PTO request form and submit
Then my request should be visible in the pending requests list and a notification sent to my manager

Scenario: Validation error on incomplete form
Given I am on the PTO request form
When I leave required fields blank and attempt to submit
Then I should see validation errors and the request should not be submitted

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User authentication, notification module
- Notes: PTO types and available balance must be displayed on the form.
