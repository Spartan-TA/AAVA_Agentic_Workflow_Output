Title: Auto-Flag Scheduled Shifts for Coverage

User Story: As a scheduler I want the system to automatically flag scheduled shifts that overlap with approved leave so that I can proactively arrange coverage and avoid understaffing

Acceptance Criteria:
Scenario: Leave approval triggers shift flag
  Given an employee's leave request is approved
  When the leave overlaps with scheduled shifts
  Then those shifts are flagged for coverage and appear in the coverage report

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E03 (Scheduling), E05 (Attendance)
- Notes: Flags must be visible to both schedulers and supervisors
