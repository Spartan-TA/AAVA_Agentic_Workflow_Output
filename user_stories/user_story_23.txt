Title: Block Assignment for Expired Certifications

User Story: As a scheduler I want the system to block shift assignment for employees with expired certifications so that compliance is enforced

Acceptance Criteria:
Scenario: Prevent assignment with expired certification
Given an employee's certification is expired
When I attempt to assign a shift requiring that certification
Then the system should prevent the assignment and display an error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Certification tracking, Scheduling module
- Notes: Display reason for block to scheduler.
