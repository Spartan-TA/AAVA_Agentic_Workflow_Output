====================================================================
Epic E09: Equipment & Asset Assignment
====================================================================

User Story 1:
- Title: Manage Asset Registry (CRUD)
- User Story: As an asset manager, I want to add, update, and remove assets so that inventory is accurate.
- Acceptance Criteria:
  - Given the asset form, When I manage assets, Then changes are reflected in the registry.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: E02, E03, E07, Notes: Includes asset types.

User Story 2:
- Title: Assign and Track Equipment to Employees
- User Story: As a supervisor, I want to check out and return equipment to employees so that usage is tracked.
- Acceptance Criteria:
  - Given a check-out, When processed, Then the asset is assigned to the employee.
  - Given a return, When processed, Then the asset is marked as available.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: User Story 1, Notes: Tracks history.

User Story 3:
- Title: Block Asset Assignment if Certification is Invalid
- User Story: As a supervisor, I want to prevent asset assignment if the employee's certification is invalid so that safety is enforced.
- Acceptance Criteria:
  - Given an assignment, When the required certification is missing or expired, Then the system blocks the assignment.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: User Story 2, Notes: Integrates with E07.

User Story 4:
- Title: Maintain Asset Condition State and Overdue Reports
- User Story: As an asset manager, I want to track asset condition and generate overdue return reports so that assets are maintained.
- Acceptance Criteria:
  - Given an asset, When condition is updated, Then history is logged.
  - Given overdue assets, When I request a report, Then all overdue returns are listed.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: User Story 2, Notes: For accountability.
