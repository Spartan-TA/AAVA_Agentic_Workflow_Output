## E09 - Equipment & Asset Assignment

### Story 1: Asset Registry CRUD
- **User Story:** As an Admin, I want to manage the asset registry so that all equipment is tracked.
- **Acceptance Criteria:**
    ```
    Given valid asset details
    When I create, update, or delete an asset
    Then the registry reflects the changes
    ```
- **Additional Details:**  
    Priority: Medium  
    Story Points: 3  
    Dependencies: E02, E03, E07  
    Notes: Asset types include scanners, forklifts, PPE.

### Story 2: Check-In/Out Equipment
- **User Story:** As a Worker, I want to check out and return equipment so that usage is tracked.
- **Acceptance Criteria:**
    ```
    Given available equipment and valid certification
    When I check out an asset
    Then the assignment is recorded

    Given missing or expired certification
    When I attempt to check out restricted equipment
    Then the system blocks the action
    ```
- **Additional Details:**  
    Priority: Medium  
    Story Points: 4  
    Dependencies: E02, E03, E07  
    Notes: Real-time validation.

### Story 3: Asset Condition Tracking
- **User Story:** As a Supervisor, I want to record asset condition at check-in/out so that maintenance needs are identified.
- **Acceptance Criteria:**
    ```
    Given an asset is returned
    When I record its condition
    Then the state is updated in the registry
    ```
- **Additional Details:**  
    Priority: Low  
    Story Points: 2  
    Dependencies: E02, E03, E07  
    Notes: Condition options: Good, Needs Maintenance, Damaged.

### Story 4: Overdue Asset Return Report
- **User Story:** As an Admin, I want to generate reports of overdue asset returns so that accountability is enforced.
- **Acceptance Criteria:**
    ```
    Given overdue assets
    When I generate the report
    Then I see all assets not returned by due date
    ```
- **Additional Details:**  
    Priority: Low  
    Story Points: 2  
    Dependencies: E02, E03, E07  
    Notes: Include employee and asset details.
