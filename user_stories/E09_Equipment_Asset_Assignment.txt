EPIC E09: Equipment & Asset Assignment

---

Title: Asset Assignment - Register Asset
User Story: As an ADMIN I want to register assets (scanners, forklifts, PPE) So that asset inventory is tracked.
Acceptance Criteria:
Scenario: Register asset
Given asset details
When I POST to /assets
Then the asset is added to the registry
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Asset type, serial, condition required

---

Title: Asset Assignment - Assign Asset
User Story: As a SUPERVISOR I want to assign assets to employees So that accountability is maintained.
Acceptance Criteria:
Scenario: Assign asset
Given an asset and a qualified employee
When I assign the asset
Then the assignment is updated and history logged
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Certification check enforced

---

Title: Asset Assignment - Block Unqualified Use
User Story: As a System I want to prevent asset assignment if required certification is missing So that only qualified staff use equipment.
Acceptance Criteria:
Scenario: Block unqualified assignment
Given an employee lacks certification
When I assign a restricted asset
Then the system blocks the assignment and shows an error
Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E07
- Notes: Enforced at assignment and check-out

---

Title: Asset Assignment - Asset History & Overdue Report
User Story: As an ADMIN I want to view asset assignment history and overdue returns So that asset usage is auditable.
Acceptance Criteria:
Scenario: View asset history
Given assets are assigned and returned
When I view asset history
Then I see all check-in/out events and overdue reports
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Overdue logic based on asset type
