### E09: Equipment & Asset Assignment

#### User Story 1
**Title:** Asset Registry CRUD
**User Story:** As an ADMIN I want to manage the registry of equipment and PPE So that assets are tracked
**Acceptance Criteria (Gherkin):**
```
Given asset data
When I POST/PUT/DELETE /assets
Then assets are created, updated, or deleted

Given duplicate asset ID
When I create
Then I receive a validation error
```
**Additional Details:** Priority: Medium, Story Points: 3, Dependencies: E02, E03, E07, Notes: Condition state tracked

#### User Story 2
**Title:** Asset Checkout/Return
**User Story:** As a WORKER I want to check out and return equipment So that asset usage is logged
**Acceptance Criteria (Gherkin):**
```
Given valid certification
When I check out an asset
Then the asset is assigned and history logged

Given expired certification
When I check out
Then the system blocks the checkout
```
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: Certification checks

#### User Story 3
**Title:** Overdue Asset Report
**User Story:** As an ADMIN I want reports of overdue asset returns So that accountability is enforced
**Acceptance Criteria (Gherkin):**
```
Given overdue assets
When I generate a report
Then I see all assets not returned by due date

Given no overdue assets
When I generate a report
Then the report is empty or shows no records
```
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E07, Notes: History log per asset/employee
