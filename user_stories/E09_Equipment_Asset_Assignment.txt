[E09] Equipment & Asset Assignment

Title: CRUD for Asset Registry
User Story: As an asset manager I want to create, read, update, and delete assets So that equipment records are maintained.
Acceptance Criteria:
Scenario: Asset registry CRUD
Given the asset module is available
When I manage assets
Then changes are persisted and visible

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E07
Notes: Include asset type and condition.

---

Title: Assign Assets to Employees
User Story: As a supervisor I want to assign assets to employees and track check-in/out So that accountability is ensured.
Acceptance Criteria:
Scenario: Asset assignment
Given assets and employees exist
When I assign or check-in/out assets
Then the assignment is logged and history is updated

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: CRUD for Asset Registry
Notes: Support overdue return alerts.

---

Title: Block Asset Use if Certification Missing
User Story: As a supervisor I want to block asset use if required certification is missing So that safety is maintained.
Acceptance Criteria:
Scenario: Certification check for asset use
Given an employee lacks valid certification
When attempting to check out asset
Then the system blocks the action

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: CRUD for Asset Registry, Certification Tracking
Notes: Show clear error messages.
