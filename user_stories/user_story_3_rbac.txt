Title: Role-Based Access Control (RBAC) - Role Setup

User Story: As a security admin, I want to define roles (ADMIN, HR, SUPERVISOR, WORKER) so that access is controlled.

Acceptance Criteria:
Scenario: Role definitions
Given the security config
When I inspect roles
Then ADMIN, HR, SUPERVISOR, WORKER are defined

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding, Employee CRUD
- Notes: Use Spring Security
