Title: Document All APIs in OpenAPI Format

User Story: As a developer I want all HRIS, WMS, and IDP APIs to be documented in OpenAPI format So that integration is straightforward and standards-compliant

Acceptance Criteria:
Scenario: API documentation
Given new or updated API endpoints
When documentation is generated
Then OpenAPI specs are published and accessible to integrators

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Documentation must be versioned and updated with every release.
