Title: Deployment Audit and Rollback

User Story: As a DevOps engineer I want to audit deployments and perform rollbacks So that I can ensure release integrity and recover from failed deployments

Acceptance Criteria:
Scenario: Auditing and rolling back deployments
Given a deployment has occurred
When I review the deployment audit log
Then I should see details of each deployment and have the option to trigger a rollback if needed

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: CI/CD tool, audit log module
- Notes: Log deployment status, user, and rollback actions.
