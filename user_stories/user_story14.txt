Title: Audit Trail & Compliance

User Story: As a compliance officer I want all sensitive changes to be logged in a tamper-evident audit trail so that regulatory and forensic requirements are met.

Acceptance Criteria:

Scenario: Log sensitive changes
Given a create, update, or delete action on sensitive data
When the action occurs
Then the actor, timestamp, and before/after values are recorded in an immutable log

Scenario: Export audit log
Given audit log data exists
When I filter by date, user, or entity
Then only matching entries are exported

Scenario: Test coverage
Given audit logging is implemented
When automated tests run
Then all sensitive actions are covered

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Role-Based Access Control (E03)
- Notes: Centralized audit logging for PII, schedules, approvals, payroll; export and test validation required.
