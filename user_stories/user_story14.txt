Title: Assign Equipment to Employees

User Story: As a supervisor I want to assign equipment and PPE to employees so that accountability and safety are maintained

Acceptance Criteria:
Scenario: Assigning equipment
Given an employee is qualified
When I assign equipment
Then the assignment should be logged and asset status updated

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee Master Data, Certification Tracking
- Notes: Asset registry CRUD

Title: Track Equipment Checkout and Return

User Story: As an employee I want to check out and return equipment so that asset usage is tracked

Acceptance Criteria:
Scenario: Equipment checkout
Given equipment is available
When I check out the equipment
Then the system should log the checkout and prevent use if certification is missing

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Asset Registry, Certification Tracking
- Notes: Blocks when certs invalid
