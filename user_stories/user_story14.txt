Title: Audit Trail & Compliance

User Story: As a compliance officer I want centralized audit logging for sensitive changes (employee PII, schedules, approvals, payroll) with tamper-evident storage So that we can ensure regulatory compliance and detect unauthorized changes.

Acceptance Criteria:
Scenario: Audit log creation and integrity
Given a sensitive change occurs in the system
When the change is processed
Then an audit log entry is created with immutable, tamper-evident storage and is accessible for review.

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E03
- Notes: Audit logs must be exportable and support retention policies.
