Title: Audit Trail & Compliance

User Story: As a compliance officer I want centralized audit logging for sensitive changes so that audit and forensic analysis needs are met and tamper-evident storage is ensured.

Acceptance Criteria:
Scenario: Audit logging of changes
Given a sensitive create, update, or delete action occurs
When the action is performed
Then the audit log records actor, timestamp, before/after states
And the log table is immutable
And logs can be exported by date, user, or entity
And tests validate audit coverage

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Role-Based Access Control (RBAC)
- Notes: Centralized logging for employee PII, schedules, approvals, payroll; tamper-evident storage.
