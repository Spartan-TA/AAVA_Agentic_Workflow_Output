Title: Audit Trail & Compliance - Audit Logging
User Story: As a compliance officer, I want all sensitive changes logged with actor, timestamp, and before/after so that audits are possible.
Acceptance Criteria:
Scenario: Log sensitive change
  Given a create/update/delete
  When the action occurs
  Then an audit log entry is created
Additional Details:
Priority: High
Story Points: 2
Dependencies: E03
Notes: Cover PII, schedules, approvals, payroll.
