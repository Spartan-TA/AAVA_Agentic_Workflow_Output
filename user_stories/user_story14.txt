User Story 14: As a warehouse worker, I want to clock in using the mobile app, so that my attendance is recorded with device and optional geofence validation.

Acceptance Criteria:
- POST /attendance/clock-in endpoint accepts employee ID, timestamp, device info, and optional geofence data.
- If geofence is enabled, location must be within allowed area; otherwise, clock-in is rejected with error.
- Device info is captured for audit.
- Successful clock-in automatically associates with the correct shift based on schedule.
- Error returned if clock-in is outside scheduled shift window or duplicate for the same shift.
- Event is logged in audit trail with actor, timestamp, and device/location details.
- API request/response documented in OpenAPI spec.
