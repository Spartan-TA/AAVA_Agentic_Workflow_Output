Title: Create Shift Templates and Schedules

User Story: As a scheduler I want to create recurring shift templates and assign them to employees So that staffing is planned efficiently

Acceptance Criteria:

Scenario: Create shift template
Given valid shift parameters
When I POST to /shifts/templates
Then a new shift template is created

Scenario: Assign shift to employee
Given a shift template exists
When I assign it to an employee
Then the employee's schedule is updated

Scenario: Detect and prevent scheduling conflicts
Given an employee has overlapping shifts
When I attempt to assign a conflicting shift
Then the system prevents the assignment and returns an error

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee CRUD APIs, RBAC, Time & Attendance
- Notes: Support for rotations, overtime rules, blackout dates
