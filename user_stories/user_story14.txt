Title: Enforce Row-Level Security

User Story: As a supervisor I want row-level security on employee data So that I can only access records for my team

Acceptance Criteria:
Scenario: Supervisor access
Given a supervisor is logged in
When they access employee records
Then only records for their team are returned

Scenario: Admin access
Given an admin is logged in
When they access employee records
Then all records are accessible

- Priority: High
- Story Points: 3
