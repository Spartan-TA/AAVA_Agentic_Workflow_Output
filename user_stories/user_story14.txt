Title: Shift Template Management

User Story: As a scheduler I want to create and manage shift templates So that recurring work schedules can be quickly assigned to employees

Acceptance Criteria:
Scenario: Shift template creation
Given the scheduling interface
When I define a new shift template
Then it should be saved and available for future assignments

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: Employee CRUD API
- Notes: Support editing and deletion of templates.
