Title: Track Employee Certifications
User Story: As an HR manager I want to track employee certifications and expirations So that compliance and safety requirements are met
Acceptance Criteria:
Scenario: Certification tracking Given an employee profile exists When I add or update certifications Then expiration dates and alerts are set
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: Alerts 30/7 days before expiry

Title: Block Assignment for Expired Certifications
User Story: As a supervisor I want to prevent assignment of tasks to employees with expired certifications So that only qualified staff operate equipment
Acceptance Criteria:
Scenario: Assignment block Given an employee's certification is expired When I attempt to assign equipment Then the system blocks the assignment and notifies me
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC, Asset Assignment
- Notes: Certification status visible on profile

Title: Upload Proof of Certification
User Story: As an employee I want to upload proof documents for certifications So that my qualifications are verified
Acceptance Criteria:
Scenario: Upload proof Given I have a new certification When I upload the document Then it is stored and linked to my profile
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee Master Data, RBAC
- Notes: Document storage and retrieval
