Title: Define User Roles

User Story: As an admin I want to create and manage user roles So that I can control access to system features based on responsibilities

Acceptance Criteria:
Scenario: Creating a new role
Given I am on the roles management page
When I enter a role name and permissions and submit
Then the new role should be saved and visible in the roles list

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User management module
- Notes: Roles should be editable and deletable.
