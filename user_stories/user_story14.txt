Title: Time & Attendance Clock-In/Out Endpoints

User Story: As an employee I want to clock in and out via API endpoints So that my attendance is accurately recorded in the system

Acceptance Criteria:
Scenario: Successful clock-in
  Given I am authenticated
  When I submit a clock-in request
  Then my clock-in time should be recorded
Scenario: Successful clock-out
  Given I am authenticated and clocked in
  When I submit a clock-out request
  Then my clock-out time should be recorded
Scenario: Invalid clock-in/out
  Given I am not authenticated
  When I attempt to clock in or out
  Then the request should be rejected

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Attendance API
- Notes: Support for mobile and web clients
