### E14 - Audit Trail & Compliance

**Title:** Log Sensitive Changes
**User Story:** As a compliance officer, I want all sensitive changes to be logged so that audit requirements are met.
**Acceptance Criteria:**
Scenario: Audit log entry
Given a create/update/delete action
When it occurs
Then actor, timestamp, before/after values are recorded
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E03, Notes: Immutable log table.

**Title:** Export Audit Logs
**User Story:** As an auditor, I want to export audit logs by date, user, or entity so that investigations are supported.
**Acceptance Criteria:**
Scenario: Audit log export
Given logs exist
When I export by filter
Then only matching entries are included
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E03, Notes: Validate coverage with tests.
