Title: Employee Clock-In Event

User Story: As a Warehouse Worker I want to clock in at the start of my shift So that my attendance and hours worked are accurately recorded for payroll and compliance

Acceptance Criteria:

Scenario: Successful clock-in
  Given my shift is scheduled for today
  When I submit a clock-in event via /attendance/clock-in
  Then my attendance is recorded and associated with my shift

Scenario: Geofence validation (optional)
  Given geofence is enabled
  When I clock in outside the allowed location
  Then the request is rejected with a location error

Scenario: Device capture
  Given I use a registered device
  When I clock in
  Then the device ID is captured with the event

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Support geofence as a configurable option; capture device metadata for audit.
