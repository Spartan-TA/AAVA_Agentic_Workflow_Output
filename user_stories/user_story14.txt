Title: Submit Leave Request
User Story: As an employee I want to submit a leave request So that my absence is recorded and approved by my manager
Acceptance Criteria:
Scenario: Leave request submission
Given I am logged in as an employee
When I fill out the leave request form and submit it
Then my manager should receive a notification to review and approve/reject the request
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, Notifications
- Notes: Ensure leave balance is checked before submission.
