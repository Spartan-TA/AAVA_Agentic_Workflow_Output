Title: UI Localization and Language Toggle

User Story: As a bilingual user I want to toggle the UI language between Spanish and English so that I can use the system in my preferred language

Acceptance Criteria:
Scenario: Switch UI language
  Given the system supports multiple languages
  When I select Spanish or English from the language toggle
  Then all UI elements update to the selected language and date/time formats respect locale

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01 (Core), E02 (User Management), E05 (Attendance)
- Notes: Tests must cover both languages
