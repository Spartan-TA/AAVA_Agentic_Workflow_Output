EPIC 06: LEAVE & ABSENCE MANAGEMENT

---

Title: Request Leave

User Story: As a WORKER I want to request PTO, sick, or unpaid leave So that my absence is recorded and approved

Acceptance Criteria:

Scenario: Leave Request Submission
Given I am logged in as WORKER
When I submit a leave request
Then the request should be routed to my supervisor for approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD, RBAC, Shift Assignment
- Notes: Support multiple leave types

---

Title: Approve/Deny Leave Requests

User Story: As a SUPERVISOR I want to approve or deny leave requests So that staffing plans are updated

Acceptance Criteria:

Scenario: Leave Approval
Given a leave request is pending
When I approve it
Then the employee's leave balance should be updated and scheduled shifts flagged for coverage

Scenario: Leave Denial
Given a leave request is pending
When I deny it
Then the employee should be notified

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave Requests, Shift Assignment
- Notes: Track approval history

---

Title: Leave Accrual Balance Management

User Story: As an HR user I want to manage leave accrual balances and policies So that leave entitlements are accurate

Acceptance Criteria:

Scenario: Accrual Policy Setup
Given I have HR role
When I configure accrual policies
Then employee balances should update automatically

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave Management
- Notes: Support annual and monthly accruals

---

Title: Exclude Approved Leaves from Scheduling

User Story: As a System Administrator I want approved leaves to automatically exclude employees from scheduled shifts and payroll hours So that compliance and coverage are maintained

Acceptance Criteria:

Scenario: Leave Exclusion
Given an employee has approved leave
When schedules and payroll are generated
Then the employee should be excluded from both

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave Management, Shift Assignment, Payroll
- Notes: Integration hooks for scheduling and payroll modules

---

Title: Export Approved Leaves

User Story: As an HR user I want to export approved leave data So that I can report and analyze absence trends

Acceptance Criteria:

Scenario: Leave Export
Given approved leave records exist
When I request an export
Then a CSV file should be generated with leave details

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Leave Management
- Notes: Include employee, type, dates, status

---
