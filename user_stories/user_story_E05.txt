### E05 - Shift & Schedule Management

**User Story 1**
Title: Create and Manage Shift Templates
User Story: As an ADMIN I want to define recurring shift templates and rotations So that scheduling is efficient
Acceptance Criteria:
Scenario: Create shift template
Given I am an admin
When I POST to /shifts/templates
Then The template is saved and available for assignment
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Support weekly/daily patterns

**User Story 2**
Title: Assign Shifts to Employees
User Story: As a SUPERVISOR I want to assign shifts to employees in bulk So that staffing is streamlined
Acceptance Criteria:
Scenario: Bulk assignment
Given Shift templates exist
When I assign multiple employees
Then All assignments are saved and audit entries generated
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E05-1
- Notes: Audit log required

**User Story 3**
Title: Detect and Prevent Scheduling Conflicts
User Story: As a SUPERVISOR I want the system to detect conflicts when assigning shifts So that double-booking is avoided
Acceptance Criteria:
Scenario: Conflict detection
Given An employee has a shift assigned
When I try to assign an overlapping shift
Then The system blocks the assignment and shows an error
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E05-2
- Notes: Include blackout dates

**User Story 4**
Title: Worker Views Upcoming Shifts
User Story: As a WORKER I want to view my upcoming shifts So that I can plan my schedule
Acceptance Criteria:
Scenario: View shifts
Given I am logged in
When I access my schedule
Then I see all upcoming assigned shifts
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E05-2
- Notes: Mobile-friendly
