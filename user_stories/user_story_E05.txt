### E05: Shift & Schedule Management

**User Story 1: Shift Template CRUD**
Title: Manage Shift Templates
User Story: As an HR user I want to create, update, and delete shift templates So that recurring schedules are easy to manage
Acceptance Criteria:
Scenario: Create shift template
Given required fields are provided
When I POST to /shifts/templates
Then a new template is created
Scenario: Delete shift template
Given a template exists
When I DELETE /shifts/templates/{id}
Then the template is removed
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Templates include start/end times, rotation, overtime rules

**User Story 2: Conflict Detection**
Title: Detect and Prevent Scheduling Conflicts
User Story: As a scheduler I want the system to detect and prevent shift conflicts So that employees are not double-booked
Acceptance Criteria:
Scenario: Overlapping shifts
Given an employee is assigned to a shift
When I try to assign them to an overlapping shift
Then the system rejects the assignment with a conflict error
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03, E04
- Notes: Handles blackout dates and operation calendars

**User Story 3: Bulk Assignment and Audit Logging**
Title: Bulk Assign Shifts and Log Actions
User Story: As a supervisor I want to bulk-assign shifts and have all actions audited So that scheduling is efficient and traceable
Acceptance Criteria:
Scenario: Bulk assignment
Given a list of employees
When I assign them to a shift
Then all assignments are created and audit entries are logged
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03, E04
- Notes: Audit log includes actor, timestamp, before/after

**User Story 4: Worker Shift Visibility**
Title: View Personal Upcoming Shifts
User Story: As a worker I want to view my upcoming shifts So that I know when I am scheduled
Acceptance Criteria:
Scenario: View shifts
Given I am logged in
When I GET /shifts/mine
Then I see a list of my upcoming shifts
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03, E04
- Notes: Mobile-friendly view
