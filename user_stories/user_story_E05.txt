### E05 - Shift & Schedule Management

**User Story 1**
Title: Manage Shift Templates
User Story: As an HR user, I want to create, update, and delete shift templates so that recurring schedules are easy to set up.
Acceptance Criteria:
Scenario: Shift template CRUD
Given access to scheduling
When I create a new template
Then it is available for assignment
Priority: High
Story Points: 3
Dependencies: E02, E03, E04
Notes: Support different shift patterns.

**User Story 2**
Title: Assign Shifts to Employees
User Story: As a supervisor, I want to assign shifts to employees in bulk so that scheduling is efficient.
Acceptance Criteria:
Scenario: Bulk assignment
Given a list of employees
When I assign a shift template
Then all selected employees receive the shift
Priority: High
Story Points: 3
Dependencies: E02, E03, E04
Notes: Prevent overlapping assignments.

**User Story 3**
Title: Detect and Prevent Scheduling Conflicts
User Story: As a scheduler, I want the system to detect conflicts so that employees are not double-booked.
Acceptance Criteria:
Scenario: Conflict detection
Given an employee with an existing shift
When I assign a new overlapping shift
Then the system blocks the assignment and shows an error
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Include blackout dates and warehouse calendar.

**User Story 4**
Title: View Personal Upcoming Shifts
User Story: As a worker, I want to view my upcoming shifts so that I can plan my schedule.
Acceptance Criteria:
Scenario: View shifts
Given I am logged in
When I access my schedule
Then I see all upcoming assigned shifts
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Show shift details and location.

**User Story 5**
Title: Audit Shift Assignments
User Story: As an admin, I want all shift changes to be audited so that I can track scheduling history.
Acceptance Criteria:
Scenario: Audit entry
Given a shift assignment
When it is created, updated, or deleted
Then an audit entry is generated with actor and timestamp
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Store audit logs in immutable table.
