### E05: Shift & Schedule Management

**User Story 1**
Title: Create and Manage Shift Templates
User Story: As an ADMIN I want to define recurring shift templates So that scheduling is efficient.
Acceptance Criteria:
Scenario: Create template
  Given I provide shift details
  When I save
  Then a new template is created
Scenario: Edit template
  Given a template exists
  When I update details
  Then changes are saved
Scenario: Delete template
  Given a template exists
  When I delete
  Then it is removed
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03, E04
Notes: Templates for common shifts.

**User Story 2**
Title: Assign Shifts and Detect Conflicts
User Story: As a SUPERVISOR I want to assign shifts and prevent conflicts So that staffing is correct.
Acceptance Criteria:
Scenario: Assign shift
  Given an employee is available
  When I assign a shift
  Then the assignment is saved
Scenario: Conflict detected
  Given overlapping shifts
  When I assign
  Then I receive a conflict error
Scenario: Bulk assignment
  Given a group of employees
  When I bulk assign
  Then all assignments are processed
Additional Details:
Priority: High
Story Points: 5
Dependencies: E02, E03, E04
Notes: Conflict prevention.

**User Story 3**
Title: Worker Views Upcoming Shifts
User Story: As a WORKER I want to view my upcoming shifts So that I can plan accordingly.
Acceptance Criteria:
Scenario: View personal schedule
  Given I am logged in
  When I access my schedule
  Then I see my upcoming shifts
Scenario: Blackout dates shown
  Given a blackout date
  When I view my schedule
  Then I see the blackout indicated
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Personal dashboard.
