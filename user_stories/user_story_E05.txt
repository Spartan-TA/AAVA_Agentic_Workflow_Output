### Epic E05: Shift & Schedule Management

**User Story 1: Create Shift Template**
- Title: Shift Template CRUD
- User Story: As an HR, I want to create and manage shift templates so that recurring schedules are standardized.
- Acceptance Criteria:
  ```
  Given valid shift details,
  When I create a shift template,
  Then it is saved and available for assignment.

  When I update or delete a template,
  Then changes are reflected immediately.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, E04, Notes: Supports rotations.

**User Story 2: Assign Shifts to Employees**
- Title: Bulk Shift Assignment
- User Story: As a SUPERVISOR, I want to assign shifts to multiple employees so that scheduling is efficient.
- Acceptance Criteria:
  ```
  Given a list of employees,
  When I bulk-assign shifts,
  Then each employee receives their schedule and conflicts are detected.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, E04, Notes: Conflict prevention.

**User Story 3: Detect Scheduling Conflicts**
- Title: Schedule Conflict Detection
- User Story: As a SYSTEM, I want to detect and prevent scheduling conflicts so that employees are not double-booked.
- Acceptance Criteria:
  ```
  Given overlapping shifts,
  When assigning schedules,
  Then the system blocks conflicting assignments and notifies the user.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, E04, Notes: Real-time validation.

**User Story 4: Personal Upcoming Shifts View**
- Title: Worker Shift Dashboard
- User Story: As a WORKER, I want to view my upcoming shifts so that I can plan my attendance.
- Acceptance Criteria:
  ```
  Given assigned shifts,
  When I access my dashboard,
  Then I see a list of my upcoming shifts.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, E04, Notes: Mobile-friendly.

**User Story 5: Audit Entries for Scheduling**
- Title: Schedule Audit Logging
- User Story: As an ADMIN, I want audit entries for all schedule changes so that compliance is maintained.
- Acceptance Criteria:
  ```
  Given a schedule change,
  When the change is made,
  Then an audit entry is created with actor, timestamp, and before/after state.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, E04, Notes: Links to E14.
