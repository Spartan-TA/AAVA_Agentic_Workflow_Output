Title: Prevent Use of Assets if Certification Missing

User Story: As an Asset Manager I want the system to block asset checkout to employees lacking required certifications so that only qualified staff use sensitive equipment

Acceptance Criteria:
Scenario: Block checkout for missing certification
Given an employee lacks the required certification for a forklift
When I attempt to assign the forklift
Then the system blocks the checkout and displays an error message

Scenario: Allow checkout for valid certification
Given an employee has the required certification
When I assign the asset
Then the checkout is successful

Scenario: Certification renewed
Given an employee renews their certification
When I update their profile
Then they become eligible for asset checkout

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee Master Data (E02), RBAC (E03), Certification Tracking (E07)
- Notes: Block logic must be enforced in both UI and API
