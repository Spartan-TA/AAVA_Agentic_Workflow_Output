Title: Maintain Asset Condition State and Prevent Use Without Certification

User Story: As a warehouse manager I want to track the condition of assets and prevent use by employees lacking required certifications So that safety and compliance are ensured

Acceptance Criteria:
Scenario: Prevent use of asset without certification
Given an asset is assigned to an employee
When the employee lacks the required certification or the asset is marked as out-of-service
Then the system should block usage and notify the manager

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02 (Employee Profiles), E03 (Scheduling), E07 (Training & Certification Tracking)
- Notes: Asset condition should be updated after each return and visible in the assignment dashboard.
