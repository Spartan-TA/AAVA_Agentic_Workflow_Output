Title: E04-4 Attendance Reporting and Export

User Story:
As an HR or payroll user,
I want to generate and export attendance reports for employees,
So that I can review attendance patterns and provide data for payroll and compliance.

Acceptance Criteria:
Given a set of employees and a date range,
When the attendance report is generated,
Then it includes all clock-in/out events, corrections, and calculated hours for each employee.

Given a request for export,
When the export function is used,
Then the report is available in CSV and PDF formats.

Given a report is generated,
When it is reviewed,
Then all data is accurate, complete, and matches the underlying attendance records.

Additional Details:
- Reports must support filtering by department, location, and status.
- Exported files must be secured and access-controlled.
- Report generation must be auditable.
- API and UI must support report generation and export.
