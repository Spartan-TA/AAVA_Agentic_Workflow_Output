Title: Approve Attendance Corrections

User Story: As a supervisor I want to approve attendance corrections So that legitimate changes are reflected in payroll

Acceptance Criteria:
Scenario: Attendance correction approval
Given an employee submits a correction request
When I review and approve it
Then the attendance record should be updated accordingly
