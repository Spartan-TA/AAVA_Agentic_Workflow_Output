Title: Attendance Reporting and Export

User Story: As a payroll administrator I want to export attendance reports in CSV format so that payroll processing and compliance audits are streamlined

Acceptance Criteria:
Scenario: Exporting attendance report
Given attendance data is available for a pay period
When I request an export via the reporting interface
Then a CSV file should be generated with daily totals and corrections included

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export must include all approved corrections; format must match payroll provider requirements.
