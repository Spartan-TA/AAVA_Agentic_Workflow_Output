### E18 - Localization & Multi-Site

#### User Story 1: Support Multiple Warehouses and Sites
- **Title:** Support Multiple Warehouses and Sites
- **User Story:** As an ADMIN, I want to manage multiple warehouse sites so that each has its own policies and data.
- **Acceptance Criteria:**
    - Given multiple sites,
      When I configure them,
      Then each site has separate settings and data.
- **Priority:** Low
- **Story Points:** 3
- **Dependencies:** E01, E02, E05
- **Notes:** Multi-site support.

#### User Story 2: Time Zone and Locale Configuration
- **Title:** Time Zone and Locale Configuration per Site
- **User Story:** As an ADMIN, I want to set time zones and locales per site so that schedules and reports are accurate.
- **Acceptance Criteria:**
    - Given a site,
      When I set time zone and locale,
      Then all times and formats reflect the setting.
- **Priority:** Low
- **Story Points:** 2
- **Dependencies:** E18-1
- **Notes:** Internationalization.

#### User Story 3: Language Support for UI and Notifications
- **Title:** Language Support for UI and Notifications
- **User Story:** As a USER, I want the UI and notifications in my preferred language so that I can understand all information.
- **Acceptance Criteria:**
    - Given a language preference,
      When I use the app,
      Then all text and notifications are localized.
- **Priority:** Low
- **Story Points:** 2
- **Dependencies:** E18-1, E12
- **Notes:** Localization.

#### User Story 4: Site-Specific Policies
- **Title:** Site-Specific Policies and Rules
- **User Story:** As an ADMIN, I want to define site-specific policies (e.g., holidays, overtime) so that each warehouse operates according to local rules.
- **Acceptance Criteria:**
    - Given a site,
      When I configure policies,
      Then they apply only to that site.
- **Priority:** Low
- **Story Points:** 2
- **Dependencies:** E18-1
- **Notes:** Flexibility.
