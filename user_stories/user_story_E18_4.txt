Title: Language Localization

User Story: As a warehouse worker I want the application interface to be available in my preferred language So that I can use the system comfortably

Acceptance Criteria:
Scenario: Language selection
Given multiple languages are supported
When I select my preferred language
Then all UI elements and notifications are shown in that language

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Notification module
- Notes: Start with English, Spanish, Mandarin
