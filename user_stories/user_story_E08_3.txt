Title: OSHA Summary Export and Metrics Dashboard Endpoints

User Story: As a compliance manager I want to export OSHA 300/300A summary fields and access safety metrics dashboards So that regulatory reporting and safety analysis are streamlined

Acceptance Criteria:
Scenario: Export OSHA summary
Given I am authenticated as HR or ADMIN
When I request an OSHA summary export for a specified period
Then the system generates a CSV file with all required OSHA 300/300A fields

Scenario: Access safety metrics dashboard
Given incidents have been reported
When I access the dashboard endpoint
Then I see aggregated safety KPIs and trends

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Export format must match OSHA requirements; dashboard must be accessible via API and UI.
