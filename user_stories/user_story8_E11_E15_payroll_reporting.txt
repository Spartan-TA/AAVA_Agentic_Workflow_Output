## E11: Payroll Export Integration

### Story 1: Generate Payroll Export Files
- **User Story:** As a payroll admin, I want to generate payroll-ready files from attendance and leave data so that payroll processing is automated.
- **Acceptance Criteria (Gherkin):**
  ```
  Given approved attendance and leave records
  When I generate a payroll export
  Then the file matches the provider's schema and totals reconcile with reports
  ```
- **Priority:** High
- **Story Points:** 5
- **Dependencies:** E04, E06
- **Notes:** Support multiple formats.

### Story 2: Secure Delivery of Payroll Files (SFTP/API)
- **User Story:** As a payroll admin, I want payroll files delivered securely via SFTP or API so that sensitive data is protected.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a payroll export is generated
  When delivery is configured for SFTP or API
  Then the file is sent securely and delivery status is tracked
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E11-1
- **Notes:** Retry with backoff on failure.

### Story 3: Audit Log for Payroll Exports
- **User Story:** As an auditor, I want all payroll exports logged so that I can trace data delivery.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a payroll export is generated or delivered
  When I view the audit log
  Then I see actor, timestamp, export details, and delivery status
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E14
- **Notes:** Immutable log.
