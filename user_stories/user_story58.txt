Title: Structured Logging and Distributed Tracing

User Story: As a DevOps engineer I want structured logging and distributed tracing implemented So that I can efficiently monitor and debug system behavior across services

Acceptance Criteria:
Scenario: Structured logging
  Given the application is running in production
  When an event occurs
  Then logs should be captured in a structured format (e.g., JSON) with relevant metadata

Scenario: Distributed tracing
  Given a request traverses multiple services
  When I review the trace
  Then I should see a complete path of the request with timing and error details

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Logging framework, tracing libraries (e.g., OpenTelemetry)
- Notes: Ensure logs do not contain sensitive data; integrate with centralized log management.
