Title: WMS Link for Department and Location Data

User Story:
As a warehouse manager, I want the system to link with the WMS to synchronize department and location data so that employee assignments and reporting are accurate.

Acceptance Criteria:
- Scenario: Department/location data is synced from WMS
  Given new or updated departments/locations in WMS
  When the sync job runs
  Then the warehouse system reflects the latest data

- Scenario: Assignments use latest department/location
  Given departments/locations are updated
  When employees are assigned to shifts or tasks
  Then the latest data is used for assignment and reporting

Additional Details:
- Sync must be idempotent and handle updates
- All sync actions must be logged and auditable
- Errors must trigger alerts to admins
