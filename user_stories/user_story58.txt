Title: Offline Access and Data Sync

User Story: As an employee I want to access key features and sync data when offline So that I can continue working without interruption and update the system when reconnected

Acceptance Criteria:
Scenario: Using offline mode
Given I am using the PWA without internet access
When I perform supported actions (e.g., fill forms, view records)
Then my changes should be saved locally and synced when connectivity is restored

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: PWA framework, local storage
- Notes: Indicate sync status and handle conflicts.
