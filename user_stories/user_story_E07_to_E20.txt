- User Story: As a DevOps engineer, I want deployments to staging automated so that testing is fast.
- Acceptance Criteria:
  - Given a successful build, When pipeline completes, Then deploy to staging occurs automatically.
  - Given failed deploy, When detected, Then rollback is triggered.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Fast feedback.

**User Story 4: Production Deploy with Approval**
- Title: Require Approval for Production Deploy
- User Story: As a DevOps engineer, I want production deploys to require approval so that risk is managed.
- Acceptance Criteria:
  - Given a production deploy, When approval is granted, Then deploy proceeds.
  - Given no approval, When attempted, Then deploy is blocked.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Risk management.

**User Story 5: Rollback Capability**
- Title: Test Rollback Capability
- User Story: As a DevOps engineer, I want rollback tested in the pipeline so that failed deploys can be reverted.
- Acceptance Criteria:
  - Given a failed deploy, When rollback is triggered, Then previous version is restored.
  - Given rollback tests, When run, Then rollback succeeds.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Reliability.
