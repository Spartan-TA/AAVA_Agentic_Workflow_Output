Title: Key Metrics Exposure for Monitoring

User Story: As a DevOps engineer I want key application metrics to be exposed via Micrometer/Prometheus endpoints so that I can monitor system health and performance

Acceptance Criteria:
Scenario: Accessing metrics endpoints
Given the application is running
When I query the metrics endpoint
Then I receive current values for latency, error rates, and resource usage

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Metrics library, monitoring stack
- Notes: Metrics must be available for Grafana dashboards
