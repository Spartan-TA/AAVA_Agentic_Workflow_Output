### E14: Audit Trail & Compliance

**User Story 1: Centralized Audit Logging**
- User Story: As a compliance officer, I want all sensitive changes to be logged with actor, timestamp, and before/after values So that changes are traceable.
- Acceptance Criteria:
  - Scenario: Log create/update/delete
    - Given a sensitive operation
    - When the action is performed
    - Then an immutable log entry is created
- Priority: High
- Story Points: 5
- Dependencies: E03
- Notes: Export by date/user/entity.

**User Story 2: Tamper-Evident Storage**
- User Story: As a compliance officer, I want audit logs stored in a tamper-evident manner So that forensic analysis is possible.
- Acceptance Criteria:
  - Scenario: Log integrity
    - Given audit logs
    - When I attempt to modify them
    - Then the system detects and prevents tampering
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Tests validate coverage.
