Title: Task Completion Tracking

User Story: As a warehouse employee, I want to mark tasks as completed So that my manager knows which tasks are finished.

Acceptance Criteria:
Scenario: Task completion
Given I am assigned a task
When I mark the task as completed
Then the task status updates and the manager is notified

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Task Assignment
- Notes: Completion timestamps recorded
