Title: Installable PWA Manifest

User Story: As a warehouse worker I want to install the EMS web app as a Progressive Web App (PWA) on my device So that I can access it quickly and offline

Acceptance Criteria:
Scenario: PWA installation
Given I am using a supported browser
When I visit the EMS web app
Then I am prompted to install the app and it appears on my device home screen

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Manifest must include icons, name, and offline support.
