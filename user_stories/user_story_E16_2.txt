Title: PWA Installability and Offline Support

User Story: As a warehouse worker I want to install the EMS app as a PWA and use core features offline So that I can access essential functions even without network connectivity

Acceptance Criteria:
Scenario: PWA install and offline queue
Given I install the EMS PWA on my device
When I use clock-in/out or request leave offline
Then the actions are queued and synced with conflict resolution when connectivity is restored

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E04, E05, E06, E12
- Notes: Must achieve high Lighthouse PWA score and support offline queue for clock events.
