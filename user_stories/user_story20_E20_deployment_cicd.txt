[E20] Deployment & CI/CD

Title: Automate Build and Deployment Pipeline
User Story: As a DevOps engineer I want automated build and deployment pipelines so that releases are fast and reliable.
Acceptance Criteria:
Scenario: CI/CD Pipeline Automation
Given source code changes
When I push to main branch
Then build and deployment run automatically

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Use GitHub Actions or Jenkins

---

Title: Run Automated Tests in CI
User Story: As a QA engineer I want automated tests run in CI so that code quality is maintained.
Acceptance Criteria:
Scenario: CI Test Execution
Given a code change
When CI pipeline runs
Then all tests execute and results are reported

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Automate Build and Deployment Pipeline
- Notes: Fail build on test failure

---

Title: Deploy to Multiple Environments
User Story: As a DevOps engineer I want deployments to dev, staging, and prod environments so that releases are controlled.
Acceptance Criteria:
Scenario: Multi-Environment Deployment
Given a successful build
When deployment runs
Then artifacts are deployed to all configured environments

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Automate Build and Deployment Pipeline
- Notes: Support environment variables

---

Title: Rollback on Failed Deployment
User Story: As a DevOps engineer I want automatic rollback on failed deployment so that downtime is minimized.
Acceptance Criteria:
Scenario: Deployment Rollback
Given a failed deployment
When rollback is triggered
Then previous version is restored

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Deploy to Multiple Environments
- Notes: Notify stakeholders

Title: Track Deployment History
User Story: As a DevOps engineer I want deployment history tracked so that changes are auditable.
Acceptance Criteria:
Scenario: Deployment History Tracking
Given deployments
When I view history
Then all deployments with status and actor are listed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Automate Build and Deployment Pipeline
