### E14: Audit Trail & Compliance

#### User Story 1
**Title:** Audit Logging for Sensitive Changes
**User Story:** As an ADMIN I want all sensitive changes logged with actor and timestamp So that compliance is maintained
**Acceptance Criteria (Gherkin):**
```
Given a create/update/delete action
When I view the audit log
Then I see actor, timestamp, before/after values

Given no sensitive changes
When I view the log
Then no entries are present
```
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E03, Notes: Immutable log table

#### User Story 2
**Title:** Audit Log Export
**User Story:** As an HR I want to export audit logs by date, user, or entity So that forensic analysis is possible
**Acceptance Criteria (Gherkin):**
```
Given audit log entries
When I export by date/user/entity
Then I receive a file with matching entries

Given no matching entries
When I export
Then the file is empty
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E03, Notes: Export endpoints
