Title: List and Filter Employee Records via API

User Story: As an HR manager I want to list and filter employee records using a REST API so that I can quickly find employees based on department, role, or status

Acceptance Criteria:
Scenario: Employee listing
  Given multiple employee records exist
  When I send a GET request to /employees
  Then I should receive a paginated list of employee records

Scenario: Employee filtering
  Given employee records with various departments and roles exist
  When I send a GET request with filter parameters (e.g., department, role, status)
  Then only matching employee records should be returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: API should support pagination and filtering by multiple fields
