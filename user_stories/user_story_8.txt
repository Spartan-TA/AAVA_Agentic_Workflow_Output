Title: Retrieve Employee List with Pagination and Filtering

User Story: As an HR manager I want to retrieve a paginated and filtered list of employees So that I can efficiently manage large employee datasets and find relevant records quickly

Acceptance Criteria:
Scenario: Paginated employee list
Given a large number of employee records
When I GET /employees with pagination parameters
Then the response contains the correct page of results

Scenario: Filter employee list
Given employee records with various departments and statuses
When I GET /employees with filter parameters
Then only matching records are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: API must support OpenAPI schema with examples
