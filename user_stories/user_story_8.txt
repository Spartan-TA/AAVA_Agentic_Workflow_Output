Title: Implement Role Based Access Control (RBAC) with Endpoint Security

User Story: As a System Administrator I want to configure RBAC with roles (ADMIN, HR, SUPERVISOR, WORKER) and secure endpoints so that sensitive operations are restricted to authorized users in the Warehouse EMS.

Acceptance Criteria:
Scenario: Unauthorized Access
  Given a user without proper role
  When they attempt to access a restricted endpoint
  Then the system returns a 401 Unauthorized response

Scenario: Forbidden Actions
  Given a user with insufficient privileges
  When they attempt to perform a forbidden action
  Then the system returns a 403 Forbidden response

Scenario: Role Assignment
  Given a user account exists
  When I assign a role
  Then the user gains access to permitted endpoints and actions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01), Employee Master Data (E02)
- Notes: Security rules must be covered by automated tests; roles should be configurable via admin interface.
