Title: API Key/OAuth2 Toggle
User Story: As a DevOps engineer I want to toggle between API key and OAuth2 authentication via configuration So that integration with different environments is flexible.
Acceptance Criteria:
Scenario: Toggle authentication method
  Given a config change
  When I restart the application
  Then the selected authentication method is enforced

Scenario: Both methods are tested
  Given test cases for both methods
  When I run security tests
  Then all pass for both API key and OAuth2

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Document toggle usage in README.
