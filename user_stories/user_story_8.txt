Title: List and Filter Employee Records via API

User Story: As an HR Manager I want to list and filter employee records with pagination So that I can efficiently manage large employee datasets and find relevant records quickly.

Acceptance Criteria:
Scenario: Successful listing with pagination
Given multiple employee records exist
When I GET /employees with pagination parameters
Then I receive a paginated list of employee records

Scenario: Filtering by department and status
Given employee records with various departments and statuses
When I GET /employees?department=Shipping&status=active
Then only active employees in the Shipping department are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain, Project scaffolding
- Notes: Ensure OpenAPI schema documents pagination and filtering options.
