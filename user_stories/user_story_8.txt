Title: Soft-Delete Employee Record

User Story: As an HR manager I want to soft-delete employee records so that terminated employees are excluded from active lists but historical data is retained.

Acceptance Criteria:
Scenario: Soft-Delete Action
  Given an active employee record
  When I send a DELETE request to /employees/{id}
  Then the employee status is updated to 'inactive' and the record is excluded from active queries

Scenario: Historical Data Retention
  Given an employee has been soft-deleted
  When I query for historical records
  Then the employee's data remains accessible for audit purposes

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: No physical deletion from the database; audit log entry required for every delete action.
