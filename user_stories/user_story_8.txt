Title: Enforce Unique BadgeId and Support Soft-Delete

User Story: As an HR Manager I want the system to enforce unique badgeId and allow soft-deletion of employee records So that data integrity is maintained and deleted records can be recovered if needed

Acceptance Criteria:
Scenario: Unique badgeId enforcement and soft-delete
Given an attempt to create or update an employee
When the badgeId already exists
Then the system rejects the operation with a clear error message
And when an employee is deleted
Then the record is marked as inactive but remains in the database

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Soft-deleted records should be excluded from active queries but retrievable for audit
