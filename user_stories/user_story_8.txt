Title: Retrieve and Filter Employee Records

User Story: As an HR user I want to retrieve and filter employee records by department, status, or shiftGroup So that I can quickly find relevant employees

Acceptance Criteria:
Scenario: Employee search and filtering
Given multiple employee records exist
When I request a list with filters applied
Then only matching employees are returned with pagination

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: user_story_5
- Notes: Support GET /employees with query parameters for filtering and pagination
