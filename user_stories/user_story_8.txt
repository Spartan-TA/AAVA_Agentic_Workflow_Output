Title: Implement Role-Based Endpoint Security

User Story: As an admin I want to restrict access to sensitive endpoints based on user roles So that only authorized users can perform critical operations

Acceptance Criteria:
Scenario: Unauthorized access attempt
Given a user without the required role
When the user tries to access a protected endpoint
Then the system returns a 403 Forbidden error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee Master Data
- Notes: Cover all endpoints handling PII and payroll data.
