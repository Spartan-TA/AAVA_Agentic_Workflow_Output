Title: Mobile Access (PWA)
User Story: As a warehouse worker, I want to use my mobile device to clock in/out, view schedules, request leave, and see announcements so that I can work efficiently on the go.
Acceptance Criteria:
  Scenario: Responsive Views
    Given mobile device
    When accessing core flows
    Then UI is usable and responsive
  Scenario: PWA Install
    Given browser support
    When I install the app
    Then PWA manifest is present and app is installable
  Scenario: Offline Queue
    Given no connectivity
    When I clock in/out
    Then events are queued and synced when online
  Scenario: Lighthouse Score
    Given PWA implementation
    When tested
    Then Lighthouse PWA score meets threshold
