Title: Support Rollback Capability in CI/CD Pipeline

User Story: As a DevOps engineer I want the CI/CD pipeline to support automated rollback to the previous stable version so that failed deployments can be quickly reverted.

Acceptance Criteria:
Scenario: Rolling back after failed deployment
Given a deployment to production fails
When the pipeline detects the failure
Then the system should automatically rollback to the last successful deployment and notify the team

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Rollback actions should be logged and auditable.
