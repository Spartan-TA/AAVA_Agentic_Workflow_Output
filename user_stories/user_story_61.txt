Title: Record System Activity in Audit Trail

User Story: As a system I want to record all significant activity in an audit trail So that actions are traceable for compliance and troubleshooting

Acceptance Criteria:
Scenario: Audit trail recording
Given system activity occurs (e.g., login, data change)
When the activity is performed
Then the audit trail should record the user, timestamp, and action details

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: All modules
- Notes: Audit trail must be tamper-proof
