Title: Implement Employee CRUD APIs

User Story: As an HR I want to create, read, update, and delete employee records via APIs So that employee data is managed efficiently

Acceptance Criteria:
Scenario: Create employee
  Given valid employee data
  When I POST to /employees
  Then a new employee is created

Scenario: Update employee
  Given an existing employee
  When I PUT updated data to /employees/{id}
  Then the employee record is updated

Scenario: Delete employee
  Given an employee ID
  When I DELETE /employees/{id}
  Then the employee is removed

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee Domain Model
- Notes: Validate input data
