Title: Enable Application Monitoring

User Story: As a System Administrator I want to enable Spring Actuator endpoints So that I can monitor application health and metrics

Acceptance Criteria:
Scenario: Actuator endpoints enabled
  Given the application is running
  When I access /actuator/health
  Then I see the application health status

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Initialize Spring Boot Project
- Notes: Secure actuator endpoints
