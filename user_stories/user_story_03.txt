Title: Enable Actuator for Health Monitoring

User Story: As an operations engineer I want to enable Spring Boot Actuator so that I can monitor the application's health, metrics, and operational status.

Acceptance Criteria:

Scenario: Health endpoint returns status
Given the application is running
When I send a GET request to /actuator/health
Then I should receive a 200 OK response
And the response should contain status UP
And database connectivity status should be included

Scenario: Metrics endpoint provides data
Given the application is running
When I send a GET request to /actuator/metrics
Then I should receive a list of available metrics
And metrics should include JVM memory, CPU, and HTTP request statistics

Scenario: Actuator endpoints are secured
Given actuator endpoints are configured
When an unauthenticated user tries to access /actuator/metrics
Then access should be denied with 401 Unauthorized
And only ADMIN role should have access to sensitive endpoints

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding (E01)
- Notes: Ensure actuator endpoints are secured appropriately. Expose only health endpoint publicly, secure others with authentication.
