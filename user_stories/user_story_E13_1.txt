Title: Expose REST APIs for HRIS New Hires/Terms

User Story: As a system integrator I want REST APIs that allow HRIS systems to create and terminate employee records so that master data is synchronized automatically across platforms.

Acceptance Criteria:
Scenario: HRIS API integration
Given a valid JWT/OAuth2 token
When the HRIS system sends a new hire or termination request
Then the employee record should be created or deactivated in the EMS

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Scaffolding (E01), Employee Master Data (E02), RBAC (E03)
- Notes: API must be documented in OpenAPI and support idempotency.
