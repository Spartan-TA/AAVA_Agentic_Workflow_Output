Title: Safety Incident Reporting
User Story: As a supervisor I want to record safety incidents and track investigation status So that regulatory reporting is accurate
Acceptance Criteria:
Scenario: Record incident
Given an incident occurs
When I POST to /safety/incidents with required fields
Then the incident is logged with status Open

Scenario: Status workflow
Given an incident is Open
When I update status to Investigating or Resolved
Then the status is updated and audit log is generated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API, RBAC
- Notes: Export OSHA 300/300A; dashboard metrics.
