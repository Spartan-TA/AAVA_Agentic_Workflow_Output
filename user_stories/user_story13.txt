Title: Shift Template Management

User Story: As an HR manager I want to create and manage shift templates So that recurring schedules are easily assigned

Acceptance Criteria:
Scenario: Create Shift Template
  Given valid shift details
  When I POST to /shifts/templates
  Then a new shift template is created

Scenario: Assign Template
  Given a shift template
  When I assign it to employees
  Then their schedules are updated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: user_story5, user_story11
- Notes: Detect and prevent scheduling conflicts.
