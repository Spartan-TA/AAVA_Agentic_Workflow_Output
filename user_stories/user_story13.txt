Title: Unauthorized and Forbidden Request Handling

User Story: As a developer I want the API to handle unauthorized and forbidden requests gracefully So that clients receive clear error messages and security is maintained

Acceptance Criteria:
Scenario: Unauthorized request
  Given a request is made without valid authentication
  When the API receives the request
  Then a 401 Unauthorized error should be returned
Scenario: Forbidden request
  Given a request is made by an authenticated user lacking permission
  When the API receives the request
  Then a 403 Forbidden error should be returned

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: API error handling
- Notes: Error responses must follow standard format
