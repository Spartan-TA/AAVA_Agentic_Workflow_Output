Title: Missed Punch Correction Workflow

User Story: As a warehouse worker I want to submit a correction request for missed clock-in/out events So that my attendance record is accurate and payroll is correct

Acceptance Criteria:
Scenario: Submit missed punch correction
Given I missed a clock-in or clock-out event
When I submit a correction request
Then a supervisor approval task is created and my record is updated upon approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Correction workflow must be auditable and exportable
