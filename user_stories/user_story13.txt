Title: Record Safety Incidents and Near-Misses
User Story: As a supervisor I want to record safety incidents and near-misses with details So that all events are tracked for investigation and compliance
Acceptance Criteria:
Scenario: Incident record
Given an incident occurs
When I submit the incident form with required details
Then the record is saved and visible in the safety dashboard
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: Severity, location, and involved employees required

Title: Investigation Workflow for Incidents
User Story: As a safety manager I want to manage investigation workflows for incidents So that corrective actions and status are tracked
Acceptance Criteria:
Scenario: Investigation workflow
Given an incident is recorded
When I update the status to Investigating or Resolved
Then the workflow history is logged and visible
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Incident Records
- Notes: Status transitions: Open, Investigating, Resolved

Title: OSHA Summary Export
User Story: As an HR manager I want to export OSHA 300/300A summaries So that regulatory reporting requirements are met
Acceptance Criteria:
Scenario: OSHA export
Given incidents are recorded for a period
When I request an OSHA export
Then the summary file is generated and downloadable
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Incident Records, Reporting
- Notes: Export fields must match OSHA schema

Title: Safety Metrics Dashboard
User Story: As an admin I want to view safety KPIs and metrics on a dashboard So that I can monitor trends and take proactive actions
Acceptance Criteria:
Scenario: Safety dashboard
Given incident data exists
When I access the safety dashboard
Then KPIs and metrics are displayed with filtering options
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Reporting, Incident Records
- Notes: Metrics include incident rate, severity, and resolution time
