Title: API Key/OAuth2 Toggle via Configuration

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication via configuration So that I can adapt security to different environments and integration needs

Acceptance Criteria:

Scenario: Toggle authentication method
Given the application is running
When I change the authentication configuration
Then the system should switch between API key and OAuth2 authentication

Scenario: Authentication method enforced
Given a selected authentication method
When a request is made
Then only requests using the configured method should be accepted

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC setup (E03), Project scaffolding (E01)
- Notes: Configuration changes must be documented and tested.
