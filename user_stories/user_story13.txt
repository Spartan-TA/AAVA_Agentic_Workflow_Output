### E13 - Integration Layer (HRIS/WMS APIs)

**User Story 1**
Title: Expose JWT/OAuth2-Secured REST APIs
User Story: As an integration developer I want REST APIs secured with JWT/OAuth2 So that external systems can access data securely.
Acceptance Criteria:
Scenario: Secure API access
Given I have a valid token
When I call the API
Then access is granted per permissions
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: Document token acquisition

**User Story 2**
Title: Sync Employees from HRIS
User Story: As an HR admin I want a sync job to create or update employees from HRIS So that master data is consistent.
Acceptance Criteria:
Scenario: HRIS sync
Given new hires or terms in HRIS
When the sync job runs
Then employee records are created or updated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E13-1
- Notes: Idempotent processing

**User Story 3**
Title: Link Departments and Locations from WMS
User Story: As a system I want to link employee departments and locations from WMS So that assignments are accurate.
Acceptance Criteria:
Scenario: WMS integration
Given WMS provides department/location data
When I sync
Then employee records are updated accordingly
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E13-1
- Notes: Handle mapping errors gracefully

**User Story 4**
Title: Provide Webhooks for Events
User Story: As an external system I want to receive webhooks for key events So that I can react in real time.
Acceptance Criteria:
Scenario: Webhook delivery
Given an event occurs (e.g., new hire)
When the webhook is triggered
Then the external system receives the payload
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E13-1
- Notes: Webhooks are idempotent

**User Story 5**
Title: Document APIs in OpenAPI
User Story: As a developer I want all integration APIs documented in OpenAPI So that integration is straightforward.
Acceptance Criteria:
Scenario: OpenAPI docs
Given the application is running
When I access the docs
Then all endpoints are described with examples
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E13-1
- Notes: Keep docs up to date
