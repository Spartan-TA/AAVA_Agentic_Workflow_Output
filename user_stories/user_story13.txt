Title: Integration Layer (HRIS/WMS APIs)

User Story: As a system integrator I want to expose REST APIs and connectors for HRIS, WMS, and IDP so that master data is synchronized and duplicate entry is reduced.

Acceptance Criteria:
Scenario: Secure API access
  Given APIs are exposed
  When I authenticate via JWT/OAuth2
  Then access is granted to authorized clients only

Scenario: HRIS sync job
  Given new hires or terminations in HRIS
  When the sync job runs
  Then employee records are created or updated in the system

Scenario: WMS department/location link
  Given department/location data in WMS
  When the integration runs
  Then employee records are updated with correct department/location

Scenario: Webhook event delivery
  Given an event occurs
  When a webhook is triggered
  Then the event is delivered idempotently to the configured endpoint

Scenario: API documentation
  Given APIs are available
  When I view the OpenAPI documentation
  Then all endpoints and schemas are documented

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding (E01), Employee Master Data (E02), RBAC (E03)
- Notes: SSO integration via IDP; idempotent webhooks; OpenAPI docs required.
