Title: Employee API Audit Logging
User Story: As a Compliance Officer I want all changes to employee records logged with timestamps and user IDs So that audit trails are available for compliance
Acceptance Criteria:
Scenario: Audit Log Entry
Given an employee record is created, updated, or deleted
When the action occurs
Then an audit log entry is generated with timestamp and user ID
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Store logs securely and make them queryable
