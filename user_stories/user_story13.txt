Title: Integration Layer - Expose HRIS API

User Story: As a systems integrator I want to expose REST APIs for HRIS so that new hires and terminations are synchronized.

Acceptance Criteria:
Scenario: HRIS sync job creates/updates employees
Given new hire/term data in HRIS
When the sync job runs
Then employee records are created or updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: JWT/OAuth2-secured APIs.
