Title: Expose Integration APIs

User Story:
As a system integrator, I want to expose REST APIs and connectors for HRIS, WMS, and IDP so that master data is synchronized and SSO is supported.

Acceptance Criteria:
Scenario 1: Secure APIs
  Given APIs are exposed
  When accessed with JWT/OAuth2
  Then access is authorized

Scenario 2: HRIS sync
  Given new hires or terms in HRIS
  When the sync job runs
  Then employees are created or updated

Scenario 3: WMS integration
  Given department/location data in WMS
  When linked via API
  Then employee records are updated

Scenario 4: Webhook events
  Given relevant events occur
  When webhooks are configured
  Then idempotent webhooks are triggered

Scenario 5: API documentation
  Given APIs are available
  When I access OpenAPI docs
  Then all endpoints are documented

Additional Details:
Priority: High
Story Points: 13
Dependencies: E01, E02, E03
Notes: SSO via IDP must be supported.
