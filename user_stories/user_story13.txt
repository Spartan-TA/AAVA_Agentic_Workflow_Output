Title: Audit Role Changes

User Story: As a COMPLIANCE OFFICER I want to audit all role changes So that I can ensure regulatory compliance and traceability

Acceptance Criteria:

Scenario: Role change is logged
Given a role is assigned or changed for a user
When the change occurs
Then an audit log entry should be created with timestamp, user, and action details

Scenario: Compliance officer reviews audit logs
Given I am logged in as COMPLIANCE OFFICER
When I access the audit log
Then I should see all role assignment and change events

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03-1, E03-2
- Notes: Audit logs must be immutable and exportable for compliance checks.
