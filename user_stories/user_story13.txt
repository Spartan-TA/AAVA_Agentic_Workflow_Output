Title: Calculate Daily Totals and Export Reports

User Story: As a payroll admin I want daily attendance totals and exportable reports So that payroll processing is accurate

Acceptance Criteria:

Scenario: Daily totals are computed
Given attendance events for a day
When I request daily totals
Then the system returns total hours worked per employee

Scenario: Export attendance report as CSV
Given attendance data exists
When I request an export
Then I receive a CSV file with attendance records

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Time & Attendance Clock In/Out
- Notes: Support date range filters; ensure CSV format matches payroll requirements
