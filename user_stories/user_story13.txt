Title: Integration Layer (HRIS/WMS APIs)

User Story: As a system integrator I want to expose REST APIs and connectors for HRIS, WMS, and IDP so that master data is synchronized and duplicate entry is reduced.

Acceptance Criteria:
Scenario: API integration and synchronization
Given secured API endpoints are available
When HRIS sync jobs run or WMS/IDP connectors are invoked
Then employees are created/updated from HRIS
And department/location data is linked from WMS
And webhooks are idempotent
And APIs are documented in OpenAPI

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD), Role-Based Access Control (RBAC)
- Notes: JWT/OAuth2-secured APIs; SSO via IDP; webhooks for events.
