### EPIC E05 - Shift & Schedule Management

**User Story 1**
Title: Create and Manage Shift Templates

User Story: As a Supervisor I want to create recurring shift templates So that scheduling is efficient and consistent

Acceptance Criteria:
Scenario: Template creation
Given valid shift details
When I POST to /shifts/templates
Then a new template is created

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Support rotations and overtime rules

**User Story 2**
Title: Assign Shifts to Employees

User Story: As a Supervisor I want to assign shifts to employees in bulk So that staffing is managed effectively

Acceptance Criteria:
Scenario: Bulk assignment
Given a list of employees and a shift template
When I POST to /shifts/assign
Then shifts are assigned and audit entries generated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Prevent scheduling conflicts

**User Story 3**
Title: Detect and Prevent Scheduling Conflicts

User Story: As a Scheduler I want the system to detect and prevent shift conflicts So that employees are not double-booked

Acceptance Criteria:
Scenario: Conflict detection
Given overlapping shifts
When I assign a new shift
Then the system blocks the assignment and returns an error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Handle blackout dates and operation calendars

**User Story 4**
Title: View Upcoming Shifts

User Story: As a Warehouse Worker I want to view my upcoming shifts So that I can plan my schedule

Acceptance Criteria:
Scenario: Personal shift view
Given I am logged in
When I GET /shifts/upcoming
Then my personal shift schedule is displayed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Support mobile-friendly views

### EPIC E06 - Leave & Absence Management

**User Story 1**
Title: Request Leave (PTO, Sick, Unpaid)

User Story: As a Warehouse Worker I want to request leave via the system So that my time off is tracked and approved

Acceptance Criteria:
Scenario: Leave request
Given I have available leave balance
When I submit a leave request
Then the request is created and pending approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Support multiple leave types

**User Story 2**
Title: Approve or Deny Leave Requests

User Story: As a Supervisor I want to approve or deny leave requests So that staffing levels are maintained

Acceptance Criteria:
Scenario: Approval workflow
Given a pending leave request
When I approve or deny
Then the employee is notified and balances are updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1
- Notes: Track approval history

**User Story 3**
Title: Update Leave Balances and Policies

User Story: As an HR Manager I want leave balances to update automatically So that accruals and policies are enforced

Acceptance Criteria:
Scenario: Balance update
Given an approved leave
When the leave period starts
Then the employee's balance is reduced accordingly

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Integrate with scheduling and payroll modules

**User Story 4**
Title: Export Approved Leaves

User Story: As an HR Manager I want to export approved leave records So that compliance and payroll processes are supported

Acceptance Criteria:
Scenario: Leave export
Given approved leave data
When I request an export
Then the records are downloadable in CSV format

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: User Story 1, User Story 2
- Notes: Include scheduled shift coverage flags
