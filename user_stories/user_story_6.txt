Title: Create Employee Record
User Story: As an HR manager I want to create a new employee record with all required fields So that employee data is accurately captured from the start
Acceptance Criteria:
Scenario: Employee creation
Given I have HR role access
When I submit a POST request to /employees with valid data
Then a new employee record is created and badgeId is unique
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Required fields include name, badgeId, role, department, shiftGroup, hireDate, status.
