Title: Role-Based Endpoint Security and Access Control

User Story: As an administrator I want to restrict API access based on user roles So that sensitive operations are only performed by authorized personnel

Acceptance Criteria:
Scenario: Role-based access enforcement
Given a user with a specific role (ADMIN, HR, SUPERVISOR, WORKER)
When the user attempts to access secured endpoints
Then unauthorized requests return 401, forbidden actions return 403, and access is granted only per role permissions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API, Project scaffolding
- Notes: Security rules must be covered by automated tests; row-level constraints applied where needed.
