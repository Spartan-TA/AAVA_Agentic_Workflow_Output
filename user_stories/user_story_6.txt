Title: Implement Employee CRUD Endpoints

User Story: As an HR Manager I want to create, read, update, and delete employee records via API So that employee master data is accurate and up to date

Acceptance Criteria:

Scenario: Create employee
Given I have valid employee data
When I POST to /employees
Then a new employee record is created and returned

Scenario: Update employee
Given an employee exists
When I PUT or PATCH to /employees/{id} with updated data
Then the employee record is updated accordingly

Scenario: Delete employee (soft delete)
Given an employee exists
When I DELETE /employees/{id}
Then the employee is marked as deleted but not removed from the database

Scenario: Retrieve employee
Given employees exist
When I GET /employees
Then I receive a paginated list of employees

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Ensure OpenAPI schemas are provided for all endpoints.
