Title: Create Employee Web DTOs and OpenAPI Schemas

User Story: As a Developer I want to define Employee DTOs and OpenAPI schemas with examples So that front-end and integration teams can consume APIs with predictable data structures

Acceptance Criteria:
Scenario: DTO and schema availability
Given the Employee API is implemented
When I view the OpenAPI documentation
Then Employee DTOs and example payloads are present and accurate

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Schemas must include all fields: name, badgeId, role, department, shiftGroup, hireDate, status
