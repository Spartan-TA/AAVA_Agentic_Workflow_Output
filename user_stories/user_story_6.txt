Title: Update Employee Record via API

User Story: As an HR manager I want to update employee details via API So that I can keep employee information current and accurate

Acceptance Criteria:
Scenario: Update employee
Given an existing employee record
When I PUT or PATCH updated details to /employees/{id}
Then the employee record is updated and changes are reflected in the system

Scenario: Invalid update
Given an invalid field value
When I attempt to update the employee record
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: API must validate input and return OpenAPI schema
