Title: Implement Pagination and Filtering for Employee Records

User Story: As an HR Manager I want to paginate and filter employee records by department, role, and status so that I can efficiently manage large datasets and quickly find relevant employees.

Acceptance Criteria:
Scenario: Paginated Employee List
  Given there are more than 50 employee records
  When I request the employee list with pagination parameters
  Then the response contains the correct page size and navigation links

Scenario: Filter Employee Records
  Given employee records exist
  When I apply filters for department, role, or status
  Then only matching employee records are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD APIs (E02)
- Notes: Ensure performance for large datasets; filters should be combinable.
