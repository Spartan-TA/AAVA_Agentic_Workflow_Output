Title: Retrieve Employee Records via API

User Story: As an HR manager I want to retrieve employee records using GET /employees So that I can view and manage employee information efficiently

Acceptance Criteria:
Scenario: Retrieve all employees
Given employee records exist
When I send a GET request to /employees
Then the API returns a paginated list of employees

Scenario: Filtering employees
Given employee records exist
When I send a GET request with filter parameters (e.g., department, status)
Then the API returns only matching employees

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain
- Notes: Support pagination and filtering; ensure OpenAPI schema includes examples.
