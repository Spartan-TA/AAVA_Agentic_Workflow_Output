Title: User Profile - Change Password
User Story: As a registered user I want to change my password So that I can maintain my account security
Acceptance Criteria: 
Scenario: Password change
Given I am on the change password page
When I enter my current and new password and submit
Then my password is updated and I receive a confirmation
Additional Details: 
Priority: High
Story Points: 2
Dependencies: Authentication module
Notes: New password must meet security requirements
