Title: Employee DTOs and Validation
User Story: As a developer I want employee DTOs with validation for name, badgeId, role, department, shiftGroup, hireDate, and status So that only valid data is accepted.
Acceptance Criteria:
Scenario: Invalid badgeId rejected
  Given a duplicate badgeId
  When I POST or PUT an employee
  Then I receive a 400 error

Scenario: Required fields enforced
  Given missing required fields
  When I POST or PUT an employee
  Then I receive validation errors

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Validation errors returned as per API standards.
