Title: Update Employee Record via API

User Story: As an HR Manager I want to update employee details using the API So that employee information remains accurate and up-to-date.

Acceptance Criteria:
Scenario: Successful employee update
Given an existing employee record
When I PUT/PATCH updated data to /employees/{id}
Then the employee record is updated and changes are reflected in the system

Scenario: Invalid update data
Given an employee record exists
When I send invalid data (e.g., missing required fields)
Then the API returns a validation error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain, Project scaffolding
- Notes: Ensure OpenAPI schema documents update operations and error responses.
