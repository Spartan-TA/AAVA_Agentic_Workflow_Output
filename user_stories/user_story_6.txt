Title: Retrieve Employee Records

User Story: As an HR manager I want to retrieve employee records with filtering and pagination so that I can efficiently manage large employee datasets.

Acceptance Criteria:
Scenario: Retrieve All Employees
  Given multiple employee records exist
  When I send a GET request to /employees
  Then I should receive a paginated list of employees

Scenario: Filter by Department
  Given employees are assigned to departments
  When I filter by department in the GET request
  Then only employees from the specified department are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Filtering should support department, role, status; OpenAPI schema must document query parameters.
