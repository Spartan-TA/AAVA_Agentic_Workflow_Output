Title: Create Employee Record

User Story: As an HR user I want to create a new employee record with name, badgeId, role, department, shiftGroup, hireDate, and status So that employee information is accurately captured in the system

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record is created and badgeId uniqueness is enforced

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Validate required fields and enforce unique badgeId.
