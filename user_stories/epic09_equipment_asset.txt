### EPIC 9 (E09): Equipment & Asset Assignment

**User Story 9.1: Manage Asset Registry**
- Title: Manage Asset Registry (CRUD)
- User Story: As an asset manager, I want to create, update, and delete assets so that all equipment is tracked.
- Acceptance Criteria:
    - Given the asset registry,
      When I perform CRUD operations,
      Then assets are managed with type, condition, and assignment status.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: E02, E03, E07, Notes: Core asset management.

**User Story 9.2: Assign and Track Asset Check-In/Out**
- Title: Assign and Track Asset Check-In/Out
- User Story: As a supervisor, I want to assign assets to employees and track check-in/out so that accountability is maintained.
- Acceptance Criteria:
    - Given an asset,
      When it is checked out or returned,
      Then the transaction is logged with employee, time, and condition.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: 9.1, Notes: Ensures traceability.

**User Story 9.3: Block Asset Use Without Valid Certification**
- Title: Block Asset Use Without Valid Certification
- User Story: As a system, I want to block asset check-out if the employee's required certification is invalid so that safety is enforced.
- Acceptance Criteria:
    - Given an asset requiring certification,
      When an employee without valid cert attempts check-out,
      Then the system blocks the action and notifies the user.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: 9.1, Notes: Safety enforcement.

**User Story 9.4: Maintain Asset Condition State**
- Title: Maintain and Update Asset Condition State
- User Story: As an asset manager, I want to update asset condition on check-in/out so that maintenance needs are tracked.
- Acceptance Criteria:
    - Given an asset check-in/out,
      When condition is updated,
      Then the new state is recorded in the asset history.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: 9.2, Notes: Supports maintenance.

**User Story 9.5: Report Overdue Asset Returns**
- Title: Report Overdue Asset Returns
- User Story: As a supervisor, I want to view reports of overdue asset returns so that follow-up actions can be taken.
- Acceptance Criteria:
    - Given the asset module,
      When I request overdue returns,
      Then a report of all overdue assets by employee is generated.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: 9.2, Notes: Accountability.
