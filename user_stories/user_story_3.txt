Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want the Actuator health endpoint enabled so that I can monitor the EMS application's health status in production.

Acceptance Criteria:
Scenario: Health Endpoint Availability
  Given the EMS application is running
  When I send a GET request to /actuator/health
  Then the response should indicate status UP

Scenario: Health Check Failure
  Given a critical dependency is unavailable
  When I query /actuator/health
  Then the response should indicate status DOWN and list the failing component

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Health endpoint must be secured; should integrate with monitoring tools.
