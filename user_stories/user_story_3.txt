Title: Enable Actuator Health Endpoint

User Story: As a System Administrator I want to enable the Spring Boot Actuator health endpoint So that I can monitor the application's health status programmatically

Acceptance Criteria:
Scenario: Health endpoint availability
Given the application is running
When I access the /actuator/health endpoint
Then the endpoint should return a status of UP when the application is healthy

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure endpoint is secured and documented in the README.
