Title: Set Up Flyway/Liquibase for Database Migrations

User Story: As a developer I want to add Flyway/Liquibase for database migrations So that schema changes are versioned and applied consistently across environments.

Acceptance Criteria:
Scenario: Baseline migration
  Given a new database
  When I start the application
  Then Flyway/Liquibase applies the baseline migration
Scenario: Migration history
  Given multiple migration scripts
  When I run the migration
  Then all scripts are applied in order and tracked in the migration table

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: user_story_1.txt, user_story_2.txt
- Notes: Migration scripts must be idempotent and documented.
