Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Actuator health endpoint so that I can monitor the application's health status in real time.

Acceptance Criteria:
Scenario: Health Endpoint Availability
Given the application is running
When I access /actuator/health
Then I should receive a response with status UP if the application is healthy

Scenario: Health Check Failure
Given a dependent service is down
When I access /actuator/health
Then the endpoint should report the relevant status and details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure health endpoint is documented in README and secured for authorized access only.
