Title: Enable Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Spring Boot Actuator health endpoint So that I can monitor application health and automate deployment checks

Acceptance Criteria:
Scenario: Health endpoint returns UP
Given the application is running
When I access /actuator/health
Then the endpoint returns status UP

Scenario: Health endpoint failure
Given a misconfigured database
When I access /actuator/health
Then the endpoint returns status DOWN with details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Endpoint must be documented in README
