Title: Configure Flyway/Liquibase for Baseline Migration

User Story: As a database administrator I want to configure Flyway/Liquibase for baseline database migration So that all core modules have a consistent and versioned schema from the start.

Acceptance Criteria:
Scenario: Baseline migration execution
  Given Flyway/Liquibase is configured in the project
  When I run the migration tool
  Then the baseline schema for employee, scheduling, attendance, and safety modules should be created
Scenario: Migration validation
  Given the baseline migration has run
  When I inspect the database
  Then all required tables and relationships should exist
Scenario: Migration documentation
  Given the migration scripts are present
  When I open the README
  Then I should see instructions for running migrations

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Ensure migration scripts are idempotent and documented.
