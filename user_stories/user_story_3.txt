Title: Implement Role-Based Access Control (RBAC)

User Story: As a System Administrator I want to configure RBAC with roles and endpoint/method security so that sensitive operations are restricted to authorized users.

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without proper role
  When they attempt to access a protected endpoint
  Then they receive a 401 Unauthorized response
Scenario: Forbidden actions
  Given a user with insufficient permissions
  When they attempt a restricted action
  Then they receive a 403 Forbidden response
Scenario: Admin role access
  Given an ADMIN user
  When they access any employee record
  Then they can perform all CRUD operations
Scenario: Supervisor role constraints
  Given a SUPERVISOR user
  When they access employee records
  Then they are limited to their team
Scenario: Security test coverage
  Given the security rules are implemented
  When tests are run
  Then all rules are covered and pass

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project scaffolding (E01), Employee CRUD (E02)
- Notes: Support API key/OAuth2 toggle via config.
