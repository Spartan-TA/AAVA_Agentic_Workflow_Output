Title: Employee Creation and Retrieval via CRUD APIs

User Story: As an HR manager I want to create and retrieve employee records with all relevant fields So that I can maintain an accurate employee master data set

Acceptance Criteria:
Scenario: Employee creation and retrieval
Given the employee API is available
When I POST a new employee with name, badgeId, role, department, shiftGroup, hireDate, and status
Then the employee is created and can be retrieved via GET /employees

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: badgeId must be unique; OpenAPI schemas must include examples.
