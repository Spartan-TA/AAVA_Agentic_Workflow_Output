Title: Document Project Setup and Build Instructions

User Story: As a Developer I want clear documentation for project setup, build, and run steps so that new team members can onboard quickly and avoid configuration errors.

Acceptance Criteria:
Scenario: README Documentation
  Given the project repository is initialized
  When I open the README file
  Then it contains step-by-step instructions for building and running the project

Scenario: Troubleshooting Section
  Given the README is available
  When I encounter common setup issues
  Then the README provides troubleshooting tips and contact information

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Documentation should be updated with every major change to setup or dependencies.
