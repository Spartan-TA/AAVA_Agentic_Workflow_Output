Title: Offline Access to Key Features

User Story:
As an employee, I want to access key EMS features (profile, announcements, tasks) offline via the mobile PWA so that I can stay productive even without internet connectivity.

Acceptance Criteria:
Scenario 1: Access offline features
  Given the PWA is installed
  When I lose internet connectivity
  Then I can still view my profile, announcements, and tasks

Scenario 2: Sync data when online
  Given I have used offline features
  When my device reconnects to the internet
  Then any updates or new data are automatically synced

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: PWA framework, EMS modules
Notes: Offline mode should display a clear indicator and sync status.
