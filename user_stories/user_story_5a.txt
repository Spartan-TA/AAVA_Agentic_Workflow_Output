Title: Create Employee Record via API

User Story: As an HR manager I want to create a new employee record using a REST API so that employee data is consistently captured and stored

Acceptance Criteria:
Scenario: Employee creation
  Given I have valid employee details
  When I send a POST request to /employees
  Then a new employee record should be created and returned with a unique badgeId

Scenario: BadgeId uniqueness
  Given an employee with a badgeId exists
  When I attempt to create another employee with the same badgeId
  Then the request should fail with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: API should follow OpenAPI schema with example payloads
