Title: Employee Master Data (CRUD) - Create Employee

User Story: As an HR user, I want to create employee records with name, badgeId, role, department, shiftGroup, hireDate, and status so that employee data is centrally managed.

Acceptance Criteria:
Scenario: Employee creation
Given valid employee data
When I POST to /employees
Then a new employee is created with a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding
- Notes: Validate badgeId uniqueness

Title: Employee Master Data (CRUD) - Update Employee

User Story: As an HR user, I want to update employee details so that records remain accurate.

Acceptance Criteria:
Scenario: Employee update
Given an existing employee
When I PUT/PATCH to /employees/{id}
Then the employee data is updated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create Employee
- Notes: Partial updates supported

Title: Employee Master Data (CRUD) - Delete Employee (Soft Delete)

User Story: As an HR user, I want to soft-delete employee records so that historical data is preserved.

Acceptance Criteria:
Scenario: Employee soft-delete
Given an employee record
When I DELETE /employees/{id}
Then the employee is marked as inactive, not removed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create Employee
- Notes: Soft-delete flag
