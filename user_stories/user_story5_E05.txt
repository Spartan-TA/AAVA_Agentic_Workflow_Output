### Epic E05: Shift & Schedule Management

**User Story 1: Create Shift Templates**
Title: Implement Shift Template CRUD
User Story: As a scheduler, I want to create and manage shift templates so that recurring schedules are easy to set up.
Acceptance Criteria:
Scenario: Shift template created
Given valid shift details
When I POST to `/shifts/templates`
Then a new shift template is created
Priority: High
Story Points: 3
Dependencies: E02, E03, E04
Notes: Support rotations and overtime rules

**User Story 2: Assign Shifts to Employees**
Title: Assign Shifts to Employees
User Story: As a supervisor, I want to assign shifts to employees in bulk so that staffing is efficient.
Acceptance Criteria:
Scenario: Shifts assigned in bulk
Given a list of employees
When I POST to `/shifts/assign`
Then shifts are assigned and conflicts are checked
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Prevent scheduling conflicts

**User Story 3: Blackout Dates and Calendar Integration**
Title: Manage Blackout Dates and Warehouse Calendars
User Story: As a scheduler, I want to set blackout dates and integrate warehouse operation calendars so that scheduling respects operational constraints.
Acceptance Criteria:
Scenario: Blackout date prevents assignment
Given a blackout date is set
When I assign a shift on that date
Then the system blocks the assignment
Priority: High
Story Points: 2
Dependencies: E02, E03, E04
Notes: Audit entries for changes

**User Story 4: Personal Upcoming Shifts View**
Title: Workers View Upcoming Shifts
User Story: As a worker, I want to view my upcoming shifts so that I can plan my schedule.
Acceptance Criteria:
Scenario: Upcoming shifts displayed
Given I am logged in
When I view my schedule
Then my upcoming shifts are listed
Priority: High
Story Points: 1
Dependencies: E02, E03, E04
Notes: Filter by date

**User Story 5: Audit Trail for Scheduling**
Title: Generate Audit Entries for Scheduling Actions
User Story: As a compliance officer, I want audit entries for scheduling changes so that all actions are traceable.
Acceptance Criteria:
Scenario: Audit entry created
Given a shift assignment is changed
When the change is saved
Then an audit entry is logged with actor and timestamp
Priority: High
Story Points: 1
Dependencies: E02, E03, E04
Notes: Link to E14
