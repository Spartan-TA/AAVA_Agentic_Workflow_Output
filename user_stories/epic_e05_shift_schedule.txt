Title: Shift Template Management

User Story: As an ADMIN I want to create and manage recurring shift templates So that scheduling is efficient and consistent

Acceptance Criteria:
Scenario: Create shift template
Given valid shift details
When I POST to /shifts/templates
Then a new template is created

Scenario: Edit shift template
Given an existing template
When I PUT updated details
Then the template is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC, Attendance
- Notes: Supports blackout dates

Title: Shift Assignment

User Story: As a SUPERVISOR I want to bulk-assign shifts to employees So that staffing is managed efficiently

Acceptance Criteria:
Scenario: Bulk assignment
Given a list of employees and a shift template
When I POST to /shifts/assign
Then all selected employees are assigned to the shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Shift templates
- Notes: Conflicts detected and prevented

Title: Personal Shift View

User Story: As a WORKER I want to view my upcoming shifts So that I can plan my schedule

Acceptance Criteria:
Scenario: View shifts
Given I am logged in
When I access /shifts/my
Then my personal shift schedule is displayed

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Shift assignment
- Notes: Mobile-friendly view
