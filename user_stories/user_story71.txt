Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all sensitive changes (employee PII, schedules, approvals, payroll) to be logged centrally So that audit and compliance requirements are met

Acceptance Criteria:
Scenario: Audit log entry
Given a sensitive change occurs
When the change is processed
Then an audit log entry is created with actor, timestamp, before/after values

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03
- Notes: Audit logs must be immutable and tamper-evident.
