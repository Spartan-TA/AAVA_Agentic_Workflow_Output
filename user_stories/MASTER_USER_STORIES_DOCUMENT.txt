Epic E01: Project Scaffolding & Domain Setup
--------------------------------------------------------------------

User Story E01-1: Initialize Spring Boot Project
------------------------------------------------
User Story:
As a developer, I want to initialize a Spring Boot (Maven) project with core dependencies so that I have a standardized foundation for all modules.

Acceptance Criteria:
Given I am in the project root,
When I run 'mvn clean install',
Then the project builds successfully and runs on port 8080.

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Should include README with build/run steps.
