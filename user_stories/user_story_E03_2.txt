Title: Assign Permissions to Roles

User Story: As an admin I want to assign permissions to roles So that I can control access to system features

Acceptance Criteria:
Scenario: Assign permissions
Given I am on the role management page
When I select a role and assign permissions
Then the role should have updated access rights

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role management UI
- Notes: Support bulk assignment
