Title: E03-2 Row-Level Security for Supervisors

User Story:
As a supervisor,
I want to access only the employee records for my direct reports,
So that I can manage my team without viewing data for other employees.

Acceptance Criteria:
Given a supervisor is authenticated,
When they retrieve employee records,
Then only records for their direct reports are returned.

Given a supervisor attempts to access records outside their scope,
When the API is called,
Then access is denied with a 403 Forbidden error and no data is leaked.

Given a change in reporting structure,
When the supervisor's team changes,
Then their access is updated immediately to reflect the new reporting lines.

Additional Details:
- Direct reports are defined in the org structure.
- Security must be enforced at the data access layer.
- All access attempts must be logged for audit purposes.
- API documentation must describe row-level security behavior.
