Title: Enforce Method and Endpoint Security

User Story: As a system administrator I want to restrict access to sensitive methods and endpoints based on user roles So that only authorized users can perform critical actions

Acceptance Criteria:
Scenario: Endpoint access restriction
Given a user is authenticated
When the user attempts to access a restricted endpoint
Then access should be granted only if the user's role permits it; otherwise, an error message is shown

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Ensure all endpoints are covered and tested for role-based access.
