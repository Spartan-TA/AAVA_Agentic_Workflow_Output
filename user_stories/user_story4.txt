# E04: Time & Attendance (Clock In/Out)

## User Story 1
- Title: Implement Clock-In/Clock-Out Endpoints
- User Story: As a warehouse worker, I want to clock in and out via an endpoint so that my attendance is recorded.
- Acceptance Criteria in Gherkin format:
  Scenario: Clock-in/out event
  Given a valid employee
  When they POST to /attendance/clock-in or /clock-out
  Then the event is validated and recorded
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E02, E03
  * Notes: Capture device and location if available

## User Story 2
- Title: Geofence Validation for Attendance
- User Story: As a supervisor, I want clock-in/out to validate geofence so that only on-premise attendance is accepted.
- Acceptance Criteria in Gherkin format:
  Scenario: Geofence validation
  Given a clock-in/out request
  When the location is outside the geofence
  Then the request is rejected with an error
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Clock-in/out endpoint
  * Notes: Optional feature

## User Story 3
- Title: Automatic Shift Association
- User Story: As a worker, I want my clock-in/out events automatically associated with my scheduled shift so that hours are calculated correctly.
- Acceptance Criteria in Gherkin format:
  Scenario: Shift association
  Given a clock-in event
  When the employee is scheduled for a shift
  Then the event is linked to the shift
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Shift schedule
  * Notes: Handle overlapping shifts

## User Story 4
- Title: Handle Missed Punches and Corrections
- User Story: As a supervisor, I want a workflow for missed punches and corrections so that attendance records are accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Missed punch correction
  Given a missed punch event
  When a correction is submitted
  Then an approval task is created for supervisor review
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: Attendance records
  * Notes: Approval workflow

## User Story 5
- Title: Export Attendance Reports
- User Story: As an HR user, I want to export attendance reports in CSV format so that payroll processing is streamlined.
- Acceptance Criteria in Gherkin format:
  Scenario: Attendance report export
  Given attendance data
  When I request an export
  Then a CSV file is generated with daily totals
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: Attendance records
  * Notes: Include corrections and approvals
