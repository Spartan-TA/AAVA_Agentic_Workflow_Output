Title: Document Build and Run Steps in README

User Story: As a Developer I want the README file to include clear build and run instructions So that new team members can quickly set up and run the project without confusion

Acceptance Criteria:
Scenario: README documentation
Given the project repository is initialized
When I open the README file
Then I see step-by-step instructions for building and running the application locally

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Instructions must include prerequisites, build commands, and how to access the running app on port 8080.
