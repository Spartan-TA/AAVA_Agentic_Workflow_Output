Title: Employee CRUD API Implementation

User Story: As an HR user, I want to create, read, update, and delete employee records so that employee data is managed centrally.

Acceptance Criteria:

Scenario: Create new employee with unique badgeId
Given the API
When I POST valid employee data
Then a new employee is created with a unique badgeId

Scenario: Retrieve paginated employee list
Given existing employees
When I GET /employees
Then I receive a paginated list with filtering options

Scenario: Update employee data
Given an employee
When I PATCH or PUT
Then the employee data updates

Scenario: Soft-delete employee
Given an employee
When I DELETE
Then the employee is soft-deleted (status updated, not removed)

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E01
- Notes: OpenAPI schemas required
