### E04 - Time & Attendance (Clock In/Out)

#### User Story 1
Title: Clock In Event
User Story: As a WORKER I want to clock in with device and optional geofence So that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Clock In
Given WORKER is authenticated
When WORKER submits POST /attendance/clock-in
Then event is validated and recorded with device info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence optional.

#### User Story 2
Title: Clock Out Event
User Story: As a WORKER I want to clock out So that my shift hours are tracked.
Acceptance Criteria:
Scenario: Clock Out
Given WORKER is authenticated
When WORKER submits POST /attendance/clock-out
Then event is validated and recorded
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Shift association automatic.

#### User Story 3
Title: Missed Punch Correction Workflow
User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction Approval
Given a missed punch is flagged
When SUPERVISOR reviews and approves
Then correction is applied and audit entry generated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Approval tasks created.

#### User Story 4
Title: Attendance Reports Export
User Story: As an HR I want to export attendance reports in CSV So that payroll processing is streamlined.
Acceptance Criteria:
Scenario: Report Export
Given attendance data exists
When HR requests export
Then CSV file is generated with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export includes corrections.
