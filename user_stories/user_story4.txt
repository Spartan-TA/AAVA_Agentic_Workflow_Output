Title: Clock-In/Out Event Capture

User Story: As a warehouse worker I want to clock in and out using my device So that my attendance is accurately recorded.

Acceptance Criteria:
Scenario: Clock-in/out with device capture
Given I am scheduled for a shift
When I submit a clock-in or clock-out event
Then the system records the event with device and geofence data

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Automatic shift association; validation on endpoints.

Title: Attendance Correction Workflow

User Story: As a supervisor I want to approve corrections for missed punches So that attendance records remain accurate.

Acceptance Criteria:
Scenario: Correction approval process
Given an employee submits a correction request
When I review and approve or deny the correction
Then the attendance record is updated accordingly

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Approval tasks generated; reports exportable as CSV.
