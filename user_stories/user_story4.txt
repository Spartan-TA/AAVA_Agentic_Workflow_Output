Title: Employee CRUD - Read, Update, Delete Employee

User Story: As an HR user, I want to view, update, and soft-delete employee records so that employee data remains current and accurate.

Acceptance Criteria:

Scenario: View employee list with pagination and filtering
Given employees exist in the system
When I GET /employees with pagination and filter parameters
Then I receive a paginated, filtered list of employees

Scenario: Update employee details
Given an employee exists
When I PUT or PATCH /employees/{id} with updated data
Then the employee record is updated

Scenario: Soft-delete employee
Given an employee exists
When I DELETE /employees/{id}
Then the employee is marked as deleted but not removed from the database

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee create story
- Notes: Support filtering by department, role, status.
