Title: Implement Time & Attendance Clock In/Out Workflow

User Story: As a warehouse worker I want to clock in and out using secure endpoints with optional geofence and device capture so that my worked hours are accurately tracked for payroll and compliance.

Acceptance Criteria:
Scenario: Clock in event
  Given I am scheduled for a shift
  When I submit a clock-in request with valid credentials
  Then my attendance is recorded and associated with the correct shift

Scenario: Clock out event
  Given I am clocked in
  When I submit a clock-out request
  Then my attendance is updated and hours worked are calculated

Scenario: Missed punch correction
  Given I missed a clock-in or clock-out
  When I submit a correction request
  Then an approval task is generated for supervisor review

Scenario: Attendance reporting
  Given attendance records exist
  When I request a daily report
  Then totals are computed and exportable as CSV

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee Master Data, Role-Based Access Control
- Notes: Device and geofence capture are optional; corrections require supervisor approval.
