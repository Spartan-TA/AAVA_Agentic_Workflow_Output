Title: Create Employee Record via API

User Story: As an HR manager I want to create new employee records using a REST API So that I can onboard staff efficiently and maintain accurate master data

Acceptance Criteria:
Scenario: Successful employee creation
  Given I have valid employee details
  When I POST to /employees
  Then a new employee record should be created with a unique badgeId
Scenario: BadgeId uniqueness
  Given an employee with a badgeId exists
  When I try to create another employee with the same badgeId
  Then the request should fail with a validation error
Scenario: API schema documentation
  Given the API is available
  When I view the OpenAPI documentation
  Then I should see the employee creation schema with example values

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Employee domain must include name, badgeId, role, department, shiftGroup, hireDate, status.
