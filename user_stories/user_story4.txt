EPIC E04: Time & Attendance (Clock In/Out)

User Story 1:
Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria in Gherkin:
Scenario: Clock-in event
  Given a valid employee
  When I POST to /attendance/clock-in
  Then my clock-in event is recorded with timestamp and location
Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: E02, E03
  Notes: Capture device info if available

User Story 2:
Title: Calculate Hours Worked Per Shift
User Story: As a supervisor, I want hours worked to be calculated automatically so that payroll is accurate.
Acceptance Criteria in Gherkin:
Scenario: Shift hours calculation
  Given clock-in and clock-out events
  When I view attendance records
  Then total hours worked per shift are displayed
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: E02, E03
  Notes: Handle overnight shifts

User Story 3:
Title: Handle Missed Punches and Corrections Workflow
User Story: As a worker, I want to request corrections for missed punches so that my attendance is accurate.
Acceptance Criteria in Gherkin:
Scenario: Missed punch correction
  Given a missed clock-in or clock-out
  When I submit a correction request
  Then an approval task is created for my supervisor
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: E02, E03
  Notes: Track correction status

User Story 4:
Title: Associate Attendance with Shifts Automatically
User Story: As a system, I want clock events to be linked to scheduled shifts so that reporting is consistent.
Acceptance Criteria in Gherkin:
Scenario: Automatic shift association
  Given a clock-in event
  When I process attendance
  Then the event is linked to the correct shift based on time and employee
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: E02, E03
  Notes: Use shift schedule logic

User Story 5:
Title: Export Attendance Reports as CSV
User Story: As an HR user, I want to export attendance data as CSV so that it can be used for payroll.
Acceptance Criteria in Gherkin:
Scenario: Attendance report export
  Given attendance records
  When I request a CSV export
  Then I receive a file with daily totals and corrections
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: E02, E03
  Notes: Include approval status in export
