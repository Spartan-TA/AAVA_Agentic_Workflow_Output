Title: Create Employee Record via API

User Story: As an HR manager I want to create new employee records via API So that onboarding is efficient and accurate

Acceptance Criteria:
Scenario: Successful employee creation
  Given I have valid employee data
  When I POST to /employees
  Then a new employee record is created and badgeId is unique

Scenario: Invalid data
  Given I submit incomplete or invalid data
  When I POST to /employees
  Then I receive a validation error message

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: user_story1.txt, user_story2.txt
- Notes: API must follow OpenAPI schema and support example payloads.
