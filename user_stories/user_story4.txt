Title: Create Employee API Endpoints

User Story: As an HR user, I want to create, read, update, and delete employee records so that employee data is managed centrally.

Acceptance Criteria:

Scenario: CRUD operations for employees
Given valid employee data
When I POST/GET/PUT/PATCH/DELETE to /employees
Then the employee record is created, retrieved, updated, or soft-deleted accordingly

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01
- Notes: Soft-delete should not remove records from DB
