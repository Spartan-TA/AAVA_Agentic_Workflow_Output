Title: Document Project Setup and Build/Run Steps

User Story: As a new developer I want clear documentation of project setup and build/run steps in the README So that I can onboard quickly and avoid configuration errors.

Acceptance Criteria:
Scenario: README documentation
  Given a new repository
  When I open the README file
  Then I should see step-by-step instructions for building and running the application
  And details for configuring environment variables and dependencies

Scenario: Update on major changes
  Given a significant change to project setup
  When the change is merged
  Then the README should be updated to reflect the new steps

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Include troubleshooting tips and links to migration/health documentation.
