EPIC E04 - Time & Attendance (Clock In/Out)

===========================================

User Story 1: Clock-In Endpoint with Validation
---------------------------------------------
Title: Implement Clock-In Endpoint with Validation

User Story: As a worker, I want to clock in with device and location validation so that attendance is accurately captured.

Acceptance Criteria:
Scenario: Valid clock-in
  Given a clock-in request
  When device and location are valid
  Then attendance is recorded

Scenario: Invalid clock-in attempt
  Given invalid device/location
  When clock-in is attempted
  Then an error is returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Optional geofence.

===========================================

User Story 2: Clock-Out Endpoint
---------------------------------------------
Title: Implement Clock-Out Endpoint

User Story: As a worker, I want to clock out so that my shift hours are tracked.

Acceptance Criteria:
Scenario: Successful clock-out
  Given a clock-out request
  When submitted
  Then attendance is updated and daily totals computed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Link to shift.

User Story 3: Missed Punches and Corrections Workflow
---------------------------------------------
Title: Handle Missed Punches and Corrections

Scenario: Correction approval
  Given supervisor approval
  When correction is processed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Track correction history.
