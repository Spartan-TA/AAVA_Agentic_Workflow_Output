Title: Document Build and Run Steps in README

User Story: As a developer I want clear build and run instructions documented in the README so that new team members can set up and run the project without confusion.

Acceptance Criteria:
Scenario: README documentation
  Given the project repository is initialized
  When I open the README file
  Then I should see step-by-step instructions for building and running the application

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Spring Boot project scaffolding
- Notes: README must include prerequisites, build commands, run commands, and troubleshooting tips.
