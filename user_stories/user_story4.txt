Title: Document Build and Run Steps in README

User Story: As a developer I want clear build and run instructions documented in the README So that new team members can quickly set up and run the project

Acceptance Criteria:
Scenario: README documentation
Given the project repository is initialized
When I open the README file
Then I see step-by-step instructions for building and running the application on port 8080

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: README must be updated with every major change to build/run process
