Title: Create Employee Record via API

User Story: As an HR manager I want to create new employee records using a POST API So that new hires are accurately added to the Warehouse EMS

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then the employee is created with a unique badgeId and appears in the employee list

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure badgeId uniqueness and required fields validation.
