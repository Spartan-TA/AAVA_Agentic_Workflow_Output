Title: Provide Developer Onboarding Documentation

User Story: As a new developer I want a README with build and run instructions So that I can quickly set up the project and contribute effectively

Acceptance Criteria:
Scenario: Onboarding documentation
Given I have cloned the repository
When I open the README file
Then I see clear steps for building, running, and testing the application

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Spring Boot project scaffolding
- Notes: README must be kept up to date with every major change.
