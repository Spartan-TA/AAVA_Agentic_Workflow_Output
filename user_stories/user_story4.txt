### Epic E04: Time & Attendance (Clock In/Out)

**User Story 1: Clock-In Endpoint**
- Title: Employee Clock-In Endpoint
- User Story: As a Worker, I want to clock in at the start of my shift so that my attendance is recorded.
- Acceptance Criteria:
  ```
  Given a WORKER is authenticated,
  When they POST to /attendance/clock-in with valid data,
  Then a clock-in event is recorded and associated with their shift.

  Given a WORKER is outside the geofence,
  When they attempt to clock in,
  Then the request is rejected.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Geofence optional.

**User Story 2: Clock-Out Endpoint**
- Title: Employee Clock-Out Endpoint
- User Story: As a Worker, I want to clock out at the end of my shift so that my hours are tracked.
- Acceptance Criteria:
  ```
  Given a WORKER is authenticated,
  When they POST to /attendance/clock-out,
  Then a clock-out event is recorded and hours worked are calculated.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Shift association required.

**User Story 3: Handle Missed Punches**
- Title: Missed Punch Correction Workflow
- User Story: As a Worker, I want to request corrections for missed punches so that my attendance is accurate.
- Acceptance Criteria:
  ```
  Given a WORKER missed a punch,
  When they submit a correction request,
  Then a supervisor approval task is created.

  Given a SUPERVISOR reviews a correction,
  When they approve or deny,
  Then the attendance record is updated accordingly.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Approval workflow.

**User Story 4: Attendance Reporting**
- Title: Export Attendance Reports
- User Story: As an HR user, I want to export attendance reports in CSV format so that payroll processing is streamlined.
- Acceptance Criteria:
  ```
  Given attendance data exists,
  When HR requests a report export,
  Then a CSV file is generated with daily totals per employee.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Exportable by date range.
