Title: Set Up Flyway/Liquibase for Baseline DB Migrations

User Story: As a Database Administrator I want to set up Flyway or Liquibase for baseline database migrations so that schema changes are versioned and applied consistently across environments.

Acceptance Criteria:
Scenario: Baseline migration runs successfully
  Given the migration tool is configured
  When I run the migration command
  Then the baseline schema is created without errors

Scenario: Migration failure handling
  Given an invalid migration script
  When I run the migration command
  Then the process fails and logs the error details

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Migration scripts should be stored in version control and documented in README.
