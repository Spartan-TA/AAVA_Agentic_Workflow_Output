Title: Enable Actuator Health Endpoint and Document Build Steps

User Story: As a System Administrator I want to enable the Actuator health endpoint and document build/run steps in the README So that system health can be monitored and onboarding is simplified

Acceptance Criteria:

Scenario: Actuator health endpoint enabled
Given the application is running
When I access /actuator/health
Then I should receive a status UP response

Scenario: README contains build/run instructions
Given the project repository is initialized
When I open the README file
Then I should see clear instructions for building and running the application

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: README should be updated with every major setup change.
