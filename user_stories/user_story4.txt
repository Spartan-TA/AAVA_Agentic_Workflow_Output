Title: Employee Clock In
User Story: As an employee I want to clock in at the start of my shift so that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Successful clock in
Given I am logged into the system
When I select 'Clock In'
Then my start time should be recorded and confirmation displayed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance module
- Notes: Prevent multiple clock-ins per shift

Title: Employee Clock Out

Acceptance Criteria:

When I select 'Clock Out'
Then my end time should be recorded and confirmation displayed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance module
- Notes: Prevent clock out before clock in
