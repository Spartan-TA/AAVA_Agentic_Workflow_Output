Title: Employee CRUD API Implementation
User Story: As an HR manager, I want to create, read, update, and delete employee records via API so that employee data is managed centrally.
Acceptance Criteria:
Scenario: Create employee
Given valid employee data
When I POST to /employees
Then a new employee is created with a unique badgeId

Scenario: Read employee
Given employees exist
When I GET /employees/{id}
Then the correct employee data is returned

Scenario: Update employee
Given an employee exists
When I PUT/PATCH /employees/{id}
Then the employee data is updated

Scenario: Delete employee (soft-delete)
Given an employee exists
When I DELETE /employees/{id}
Then the employee is soft-deleted and excluded from active queries

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Scaffolding
- Notes: Must support OpenAPI schemas with examples
