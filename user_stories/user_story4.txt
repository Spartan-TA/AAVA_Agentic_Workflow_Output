Title: Configure and Validate Database Migration Tool

User Story: As a backend developer I want Flyway or Liquibase configured for automated database migrations So that schema changes are versioned and applied consistently across environments

Acceptance Criteria:

Scenario: Baseline migration runs on first startup
Given a new environment with an empty database
When the application starts
Then the baseline migration is applied and all core tables are created

Scenario: Migration errors are surfaced
Given a migration fails due to a syntax error
When the application starts
Then the error is logged and the application fails to start

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Database, Flyway or Liquibase
- Notes: Migration scripts must be idempotent and versioned.
