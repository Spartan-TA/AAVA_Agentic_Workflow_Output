Title: Create Employee Record via API

User Story: As an HR Manager I want to create new employee records via a secure API So that all warehouse staff are registered with accurate master data

Acceptance Criteria:
Scenario: Employee Creation
Given I have HR role access
When I POST valid employee data to /employees
Then a new employee record is created with a unique badgeId

Scenario: BadgeId Uniqueness
Given an employee exists with badgeId X
When I attempt to create another employee with badgeId X
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: user_story1.txt, user_story2.txt
- Notes: API must validate required fields; OpenAPI schema must be documented.
