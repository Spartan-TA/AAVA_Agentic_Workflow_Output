Title: Employee CRUD API Implementation
User Story: As an HR manager I want to create, read, update, and delete employee records via APIs So that employee data is managed centrally
Acceptance Criteria:
Scenario: Employee CRUD operations
Given I have valid HR credentials
When I perform POST, GET, PUT, PATCH, or DELETE on /employees
Then the employee record is created, retrieved, updated, or soft-deleted as requested

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project Initialization
- Notes: Soft-delete must be supported
