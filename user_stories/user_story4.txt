Title: Create Employee Record

User Story: As an HR manager I want to create a new employee record with all required fields So that employee information is accurately captured in the system

Acceptance Criteria:

Scenario: Successful employee creation
Given I have valid employee details (name, badgeId, role, department, shiftGroup, hireDate, status)
When I submit a POST request to /employees
Then the employee record should be created and returned with a unique badgeId

Scenario: Duplicate badgeId
Given an employee with badgeId 123 already exists
When I attempt to create another employee with badgeId 123
Then the system should reject the request with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01)
- Notes: badgeId must be unique and validated at API and DB level.
