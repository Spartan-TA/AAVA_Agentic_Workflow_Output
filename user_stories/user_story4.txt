Title: Implement Employee CRUD APIs

User Story: As an HR manager I want to create, read, update, and delete employee records via APIs So that employee data is accurate and up to date

Acceptance Criteria:
Scenario: Create employee
Given I have valid employee data
When I POST to /employees
Then a new employee record is created and returned

Scenario: Update employee
Given an existing employee record
When I PUT or PATCH to /employees/{id}
Then the employee record is updated accordingly

Scenario: Delete employee
Given an existing employee record
When I DELETE /employees/{id}
Then the employee is soft-deleted and excluded from active queries

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: API must enforce unique badgeId and support pagination/filtering
