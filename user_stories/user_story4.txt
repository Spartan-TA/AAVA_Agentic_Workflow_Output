Title: Time & Attendance (Clock In/Out)

User Story: As a warehouse worker I want to clock in and out using a secure endpoint so that my working hours are accurately recorded for payroll and compliance.

Acceptance Criteria:
Scenario: Clock-in event
  Given I am scheduled for a shift
  When I submit a clock-in request with valid credentials and location
  Then my attendance is recorded and associated with the correct shift

Scenario: Clock-out event
  Given I am clocked in
  When I submit a clock-out request
  Then my attendance record is updated and daily totals are computed

Scenario: Missed punch correction
  Given I missed a clock-in or clock-out
  When I submit a correction request
  Then an approval task is generated for my supervisor

Scenario: Attendance report export
  Given attendance data exists
  When I request an export
  Then I receive a CSV file of attendance records

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee Master Data (E02), RBAC (E03)
- Notes: Geofence and device capture are optional; corrections workflow required.
