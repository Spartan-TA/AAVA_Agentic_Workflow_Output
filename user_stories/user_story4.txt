Title: Provide Comprehensive Project README
User Story: As a new developer I want a comprehensive README with build, run, and test instructions So that I can quickly set up and contribute to the project
Acceptance Criteria:
Scenario: README contains setup and usage instructions
Given I have access to the repository
When I open the README file
Then I should find clear steps for building, running, and testing the application

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Include environment variable descriptions, troubleshooting tips, and contact info for support.
