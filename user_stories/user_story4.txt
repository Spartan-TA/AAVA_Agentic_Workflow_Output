### E04 - Time & Attendance (Clock In/Out)

**User Story 1:**
Title: Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Successful clock-in
  Given a valid employee
  When I POST to /attendance/clock-in
  Then my clock-in is recorded with timestamp, device, and location
Scenario: Successful clock-out
  Given a valid employee
  When I POST to /attendance/clock-out
  Then my clock-out is recorded
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Core attendance

**User Story 2:**
Title: Geofence and Device Validation
User Story: As a supervisor, I want clock events to capture device and location so that only on-site attendance is accepted.
Acceptance Criteria:
Scenario: Reject off-site clock-in
  Given a clock-in from outside geofence
  When I POST to /attendance/clock-in
  Then the request is rejected
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Prevents fraud

**User Story 3:**
Title: Automatic Shift Association
User Story: As a worker, I want my clock events linked to my scheduled shift so that hours are calculated correctly.
Acceptance Criteria:
Scenario: Link clock-in to scheduled shift
  Given a clock-in during a scheduled shift
  When I POST to /attendance/clock-in
  Then the event is associated with the correct shift
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Accurate payroll

**User Story 4:**
Title: Missed Punches and Corrections Workflow
User Story: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
Scenario: Submit correction request
  Given a missed punch
  When I submit a correction
  Then an approval task is created for my supervisor
Scenario: Approve correction
  Given a supervisor
  When I approve/deny a correction
  Then the attendance record is updated accordingly
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Error handling

**User Story 5:**
Title: Attendance Reports Export
User Story: As an HR admin, I want to export attendance reports as CSV so that I can process payroll.
Acceptance Criteria:
Scenario: Generate CSV export
  Given attendance data
  When I request a report export
  Then a CSV file is generated with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Payroll integration
