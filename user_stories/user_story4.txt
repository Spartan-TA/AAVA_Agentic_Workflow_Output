Title: Document Build and Run Steps in README

User Story: As a developer I want a comprehensive README with build and run instructions so that new team members can set up the project quickly and consistently

Acceptance Criteria:
Scenario: README includes setup instructions
  Given I open the README file
  When I follow the documented steps
  Then I can build and run the project successfully on my local machine

Scenario: Troubleshooting section
  Given I encounter a common setup issue
  When I check the README
  Then I find troubleshooting tips or links to further resources

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Project scaffolding
- Notes: Include sections for prerequisites, build commands, run commands, and contact for support.
