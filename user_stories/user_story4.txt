Title: Enable Actuator for Health Checks

User Story:
As a DevOps engineer,
I want the application to expose Spring Boot Actuator health endpoints,
So that I can monitor the application's health and readiness for deployment and operations.

Acceptance Criteria:
- Actuator endpoints (e.g., /actuator/health, /actuator/info) are enabled and accessible.
- Health endpoint returns status 'UP' when the application is running.
- Sensitive actuator endpoints are secured and not exposed publicly.
- Documentation exists for available actuator endpoints and their usage.

Additional Details:
- Actuator should be enabled in all environments, with production-appropriate security.
- Health checks should include database connectivity and any critical downstream dependencies.
- README updated with instructions for accessing health endpoints.
