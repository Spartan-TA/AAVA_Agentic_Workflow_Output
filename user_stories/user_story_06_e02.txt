Title: Edit Employee Details

User Story: As an HR manager I want to edit employee details So that I can keep employee information accurate and up-to-date

Acceptance Criteria:
Scenario: Employee details updated
Given an existing employee record
When I update the employee's information and save changes
Then the updated details are reflected in the system and audit logged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain module, audit logging
- Notes: Track changes for compliance and allow only authorized users to edit.
