### E15: Reporting & Analytics

#### User Story 1
**Title:** Attendance & Overtime Reports
**User Story:** As an HR I want operational reports for attendance and overtime So that staffing decisions are data-driven
**Acceptance Criteria (Gherkin):**
```
Given attendance/overtime data
When I filter by date, department, shift
Then I see matching records

Given large data set (50k rows)
When I export
Then the file is generated within 10 seconds
```
**Additional Details:** Priority: Medium, Story Points: 3, Dependencies: E04, E05, E06, E07, E08, E14, Notes: CSV/PDF export

#### User Story 2
**Title:** Certification & Safety KPI Dashboards
**User Story:** As a SUPERVISOR I want dashboards for certification status and safety KPIs So that compliance is visible
**Acceptance Criteria (Gherkin):**
```
Given certification and safety data
When I view dashboard
Then I see metrics and status for my team

Given no data
When I view dashboard
Then metrics show zero or N/A
```
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E04, E05, E06, E07, E08, E14, Notes: Role-based access
