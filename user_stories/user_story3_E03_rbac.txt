### Epic E03: Role-Based Access Control (RBAC)

**User Story 1**
Title: Implement Role-Based Security
User Story: As an ADMIN, I want to manage all employee records so that sensitive operations are restricted to authorized users.
Acceptance Criteria:
Scenario: Admin access
Given ADMIN role
When I access any employee endpoint
Then access is granted
Additional Details:
Priority: High
Story Points: 5
Dependencies: E01, E02
Notes: Security rules must be covered by tests.

**User Story 2**
Title: Supervisor Row-Level Constraints
User Story: As a SUPERVISOR, I want access limited to my team's records so that I cannot view other teams' data.
Acceptance Criteria:
Scenario: Supervisor access
Given SUPERVISOR role
When I GET /employees
Then only my team's records are returned
Additional Details:
Priority: High
Story Points: 3
Dependencies: E01, E02
Notes: Team mapping required.

**User Story 3**
Title: Unauthorized Request Handling
User Story: As a USER, I want unauthorized requests to return 401 so that security is enforced.
Acceptance Criteria:
Scenario: Unauthorized access
Given no authentication
When I access a protected endpoint
Then response is 401 Unauthorized
Additional Details:
Priority: High
Story Points: 2
Dependencies: E01, E02
Notes: Applies to all endpoints.

**User Story 4**
Title: Forbidden Action Handling
User Story: As a USER, I want forbidden actions to return 403 so that permissions are clear.
Acceptance Criteria:
Scenario: Forbidden access
Given insufficient role
When I attempt a restricted action
Then response is 403 Forbidden
Additional Details:
Priority: High
Story Points: 2
Dependencies: E01, E02
Notes: Must be logged for audit.

**User Story 5**
Title: API Key/OAuth2 Toggle
User Story: As a DEVOPS ENGINEER, I want to toggle between API key and OAuth2 authentication via config so that integration is flexible.
Acceptance Criteria:
Scenario: Auth toggle
Given a config change
When I set auth mode to OAuth2
Then endpoints require OAuth2 tokens
Additional Details:
Priority: High
Story Points: 3
Dependencies: E01, E02
Notes: Document toggle steps.
