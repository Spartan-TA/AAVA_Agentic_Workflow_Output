[E03] Role-Based Access Control (RBAC)

Title: Implement Role Definitions
User Story: As a security admin I want roles (ADMIN, HR, SUPERVISOR, WORKER) defined so that access can be controlled.
Acceptance Criteria:
Scenario: Role Definition
Given the system configuration
When I assign roles to users
Then roles are persisted and recognized by security layer

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Use enum for roles

---

Title: Secure Endpoints by Role
User Story: As a security admin I want to restrict API endpoints by role so that only authorized users can perform sensitive actions.
Acceptance Criteria:
Scenario: Endpoint Security
Given a user with insufficient role
When they access a restricted endpoint
Then the system returns 401 or 403

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role Definitions
- Notes: Cover all sensitive endpoints

---

Title: Enable Row-Level Security
User Story: As a supervisor I want to see only my team's data so that privacy is maintained.
Acceptance Criteria:
Scenario: Row-Level Data Access
Given a supervisor user
When they access employee data
Then only records for their team are visible

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Secure Endpoints by Role
- Notes: Use department/team mapping

---

Title: Support API Key/OAuth2 Toggle
User Story: As a security admin I want to toggle between API key and OAuth2 authentication via config so that integration flexibility is provided.
Acceptance Criteria:
Scenario: Auth Toggle
Given the config setting
When I switch between API key and OAuth2
Then authentication method changes accordingly

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Role Definitions
- Notes: Document config options

Title: Cover Security Rules with Automated Tests
User Story: As a QA engineer I want automated tests for security rules so that regressions are caught early.
Acceptance Criteria:
Scenario: Security Test Coverage
Given the test suite
When I run security tests
Then unauthorized and forbidden actions are correctly handled

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Secure Endpoints by Role
- Notes: Include negative test cases
