### Epic E03: Role-Based Access Control (RBAC)

#### 1. Add Spring Security with Roles
User Story: As an admin I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) to users So that access is controlled.
Acceptance Criteria:
Scenario: Role assignment
Given a user account
When I assign a role
Then the user has permissions per role
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Roles stored in DB.

#### 2. Secure Endpoints by Role
User Story: As a developer I want to restrict API endpoints by user role So that sensitive operations are protected.
Acceptance Criteria:
Scenario: Unauthorized access blocked
Given a user with insufficient role
When they access a restricted endpoint
Then the API returns 401 or 403
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Roles implemented
- Notes: Use method/endpoint security annotations.

#### 3. Implement Row-Level Security
User Story: As a supervisor I want to access only my team's records So that data privacy is maintained.
Acceptance Criteria:
Scenario: Row-level access
Given a supervisor is logged in
When they request employee data
Then only their team's records are returned
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Secure endpoints
- Notes: Enforce via queries or filters.

#### 4. Support API Key/OAuth2 Toggle via Config
User Story: As a developer I want to toggle between API key and OAuth2 authentication So that integration flexibility is provided.
Acceptance Criteria:
Scenario: Auth method toggled
Given the config is set to API key
When I authenticate with API key
Then access is granted
And when set to OAuth2
Then OAuth2 flow is enforced
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Security setup
- Notes: Document both flows.

#### 5. Cover Security Rules with Automated Tests
User Story: As a QA engineer I want automated tests for security rules So that regressions are prevented.
Acceptance Criteria:
Scenario: Security tests run
Given the test suite
When I run security tests
Then unauthorized and forbidden actions are covered
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Security setup
- Notes: Include edge cases.
