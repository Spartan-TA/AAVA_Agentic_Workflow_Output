Title: Tenant Isolation and Locale Configuration

User Story: As a system admin I want each warehouse or region to have isolated data and locale-specific settings so that operations are secure and tailored to local requirements

Acceptance Criteria:
Scenario: Tenant isolation and locale settings
  Given I manage multiple tenants
  When I configure locale (date/time, currency, language) for a tenant
  Then all data and configuration are isolated and UI strings are translated accordingly

Additional Details:
- Priority: Low
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: Tenant ID required in all entities; tests must validate isolation and locale application.
