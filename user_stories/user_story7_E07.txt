### E07 - Training & Certification Tracking

#### User Story 1: CRUD for Certifications
- **Title:** CRUD for Certifications
- **User Story:** As an HR, I want to create, read, update, and delete certifications for employees so that qualifications are tracked.
- **Acceptance Criteria:**
    - Given a certification,
      When I create or update it,
      Then it is saved to the employee profile.
    - Given a delete request,
      When I delete a certification,
      Then it is removed.
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E02, E03
- **Notes:** Includes proof upload.

#### User Story 2: Alert on Expiring Certifications
- **Title:** Alert on Expiring Certifications
- **User Story:** As a SUPERVISOR or HR, I want to receive alerts before certifications expire so that renewals are not missed.
- **Acceptance Criteria:**
    - Given a certification expiring in 30 or 7 days,
      When the system checks,
      Then an alert is sent to the employee and supervisor.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E07-1
- **Notes:** Automated notifications.

#### User Story 3: Block Assignment to Unqualified Tasks
- **Title:** Block Assignment to Unqualified Tasks
- **User Story:** As a SYSTEM, I want to block assignment of tasks or equipment to employees with expired certifications so that safety is ensured.
- **Acceptance Criteria:**
    - Given an expired certification,
      When I try to assign a restricted task,
      Then the system blocks the assignment.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E07-1, E05, E09
- **Notes:** Compliance.

#### User Story 4: Certification Status on Employee Profile
- **Title:** Show Certification Status on Employee Profile
- **User Story:** As an HR or SUPERVISOR, I want to see certification status on the employee profile so that I can verify qualifications.
- **Acceptance Criteria:**
    - Given an employee profile,
      When I view it,
      Then all certifications and their status are displayed.
- **Priority:** High
- **Story Points:** 1
- **Dependencies:** E07-1
- **Notes:** Quick reference.

#### User Story 5: Upload Proof of Certification
- **Title:** Upload Proof of Certification
- **User Story:** As an EMPLOYEE, I want to upload proof documents for certifications so that compliance is documented.
- **Acceptance Criteria:**
    - Given a certification,
      When I upload a document,
      Then it is stored and linked to the certification.
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E07-1
- **Notes:** Document management.
