### E07 - Training & Certification Tracking

**Title:** Certification CRUD
User Story: As an HR user I want to add, edit, and remove certifications for employees So that compliance is tracked
Acceptance Criteria:
Scenario: Add certification
Given valid cert data
When I POST to `/certifications`
Then the cert is added to the employee profile
Scenario: Remove certification
Given an expired cert
When I DELETE
Then the cert is removed
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Proof documents uploadable

---

**Title:** Certification Expiry Alerts
User Story: As a supervisor I want alerts for expiring certifications So that renewals are not missed
Acceptance Criteria:
Scenario: Alert 30 days before expiry
Given a cert expiring in 30 days
When the system checks
Then an alert is sent to the employee and supervisor
Scenario: Alert 7 days before expiry
Given a cert expiring in 7 days
When the system checks
Then a reminder is sent
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Alerts visible in dashboard

---

**Title:** Block Unqualified Assignments
User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that safety is maintained
Acceptance Criteria:
Scenario: Assignment blocked
Given an employee with expired cert
When I try to assign them to a forklift shift
Then the system prevents the assignment
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Certification status checked on assignment

---

**Title:** Certification Status on Profile
User Story: As an employee I want to view my certification status So that I know when renewals are due
Acceptance Criteria:
Scenario: View cert status
Given I am logged in
When I view my profile
Then all certifications and expiry dates are listed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Status visible to supervisors
