Title: Bulk Schedule/Certification Import and Async Status Tracking

User Story: As a supervisor I want to import schedules and certifications in bulk and track processing status So that large updates are efficient and errors are visible

Acceptance Criteria:
Scenario: Bulk import and status endpoint
Given a CSV/Excel file for schedules or certifications
When I upload the file
Then the system processes the import asynchronously and provides a status endpoint for progress/errors

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E05, E07
- Notes: Rollback on failure; status endpoint must show progress and errors.
