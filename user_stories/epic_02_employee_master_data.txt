Title: Employee Master Data (CRUD) - Create Employee Record
User Story: As an HR manager I want to create a new employee record So that I can maintain accurate employee master data

Acceptance Criteria:
Scenario: Create employee
Given valid employee details (name, badgeId, role, department, shiftGroup, hireDate, status)
When I POST to /employees
Then a new employee record is created
And badgeId is unique

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: OpenAPI schema must include examples

---

Title: Employee Master Data (CRUD) - Update Employee Record
User Story: As an HR manager I want to update employee details So that employee information remains current

Acceptance Criteria:
Scenario: Update employee
Given an existing employee
When I PUT or PATCH to /employees/{id} with updated details
Then the employee record is updated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create employee record
- Notes: Soft-delete supported

---

Title: Employee Master Data (CRUD) - Delete Employee Record
User Story: As an HR manager I want to soft-delete an employee record So that records are not permanently lost and can be audited

Acceptance Criteria:
Scenario: Soft-delete employee
Given an existing employee
When I DELETE /employees/{id}
Then the employee status is set to inactive
And the record remains in the database

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create employee record
- Notes: Deletion must be soft, not hard

---

Title: Employee Master Data (CRUD) - List & Filter Employees
User Story: As an HR manager I want to list and filter employee records So that I can quickly find relevant employees

Acceptance Criteria:
Scenario: List and filter employees
Given multiple employee records exist
When I GET /employees with pagination and filters
Then I receive a paginated, filtered list of employees

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Create employee record
- Notes: Filtering by department, role, status
