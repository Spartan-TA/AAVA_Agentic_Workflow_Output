# E06: Leave & Absence Management

## User Story 1: Request Leave (PTO, Sick, Unpaid)
**User Story:**  
As an employee, I want to request different types of leave so that my absences are tracked.

**Acceptance Criteria (Gherkin):**
```
Given I am logged in
When I submit a leave request
Then the request is created with pending status

Given I request leave overlapping with a scheduled shift
Then the shift is flagged for coverage
```

**Additional Details:**  
Priority: Medium  
Story Points: 2  
Dependencies: E02, E03, E05  
Notes: Support multiple leave types.

---

## User Story 2: Supervisor Approves or Denies Leave
**User Story:**  
As a supervisor, I want to approve or deny leave requests so that staffing is managed.

**Acceptance Criteria (Gherkin):**
```
Given a pending leave request
When I approve or deny it
Then the employee is notified and balances are updated
```

**Additional Details:**  
Priority: Medium  
Story Points: 2  
Dependencies: E02, E03, E05  
Notes: Approval workflow required.

---

## User Story 3: Update Accrual Balances and Policies
**User Story:**  
As an HR user, I want leave balances to update automatically based on accrual policies so that records are accurate.

**Acceptance Criteria (Gherkin):**
```
Given an approved leave
When the leave is taken
Then the employee's balance is reduced accordingly

Given a new accrual policy is set
When the accrual job runs
Then balances are updated for all eligible employees
```

**Additional Details:**  
Priority: Medium  
Story Points: 3  
Dependencies: E02, E03, E05  
Notes: Support annual carryover rules.

---

## User Story 4: Exclude Approved Leave from Scheduling and Payroll
**User Story:**  
As a payroll manager, I want approved leaves to be excluded from scheduling and payroll calculations so that pay is correct.

**Acceptance Criteria (Gherkin):**
```
Given an employee has approved leave
When payroll is calculated
Then leave days are excluded from payable hours

Given a shift overlaps with approved leave
Then the shift is flagged for coverage
```

**Additional Details:**  
Priority: Medium  
Story Points: 2  
Dependencies: E02, E03, E05  
Notes: Integrate with scheduling and payroll modules.

---

## User Story 5: Export Approved Leaves
**User Story:**  
As an HR user, I want to export a list of approved leaves so that I can share with other departments.

**Acceptance Criteria (Gherkin):**
```
Given approved leave records exist
When I export the data
Then a CSV file is generated with all relevant fields
```

**Additional Details:**  
Priority: Medium  
Story Points: 1  
Dependencies: E02, E03, E05  
Notes: Include filters for date range, department.
