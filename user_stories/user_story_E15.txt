### E15 - Reporting & Analytics

**User Story 1**
Title: Filterable Operational Reports
User Story: As an HR I want operational reports filterable by date, department, and shift So that data-driven decisions are possible.
Acceptance Criteria:
Scenario: Report Filtering
Given report data
When I apply filters
Then results are updated accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Supports multiple report types

**User Story 2**
Title: Export Reports as CSV/PDF
User Story: As an HR I want to export reports as CSV/PDF So that data can be shared externally.
Acceptance Criteria:
Scenario: Report Export
Given report data
When I export
Then files are generated within 10s for up to 50k rows

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Story 1
- Notes: Export performance tested
