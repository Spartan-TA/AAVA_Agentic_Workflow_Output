### E15 - Reporting & Analytics

**User Story 1**
Title: Generate Operational Reports
User Story: As a manager, I want reports on attendance, overtime, leave, certifications, and safety so that I can monitor operations.
Acceptance Criteria:
Scenario: Report generation
Given operational data
When I generate a report
Then the report includes all relevant metrics
Priority: Medium
Story Points: 3
Dependencies: E04, E05, E06, E07, E08, E14
Notes: Support CSV and PDF export.

**User Story 2**
Title: Filter Reports by Date, Department, and Shift
User Story: As a manager, I want to filter reports so that I can analyze specific data segments.
Acceptance Criteria:
Scenario: Report filtering
Given report data
When I apply filters
Then only matching records are shown
Priority: Medium
Story Points: 2
Dependencies: E04, E05, E06, E07, E08, E14
Notes: Support multi-select filters.

**User Story 3**
Title: Export Large Reports Efficiently
User Story: As a user, I want to export up to 50k rows within 10 seconds so that large datasets are accessible.
Acceptance Criteria:
Scenario: Large export
Given a large report
When I export
Then the file is generated within 10 seconds
Priority: Medium
Story Points: 3
Dependencies: E04, E05, E06, E07, E08, E14
Notes: Optimize queries and export logic.

**User Story 4**
Title: Role-Based Dashboard Access
User Story: As a user, I want dashboard access controlled by role so that sensitive data is protected.
Acceptance Criteria:
Scenario: Dashboard access

When I access the dashboard
Then only authorized data is visible
Priority: Medium
Story Points: 2
Dependencies: E04, E05, E06, E07, E08, E14
Notes: Enforce RBAC on all dashboard endpoints.

**User Story 5**

Acceptance Criteria:
