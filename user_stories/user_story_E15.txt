### E15: Reporting & Analytics

#### User Story 1
Title: Attendance and Overtime Reporting
User Story: As an operations manager, I want to generate reports on attendance and overtime so that I can monitor workforce utilization.
Acceptance Criteria:
Scenario: Generate report
  Given attendance data exists
  When I filter by date, department, or shift
  Then I see totals and can export CSV/PDF
Additional Details:
Priority: Medium
Story Points: 5
Dependencies: E04, E05
Notes: Exports must complete within 10s for 50k rows.

#### User Story 2
Title: Leave and Certification Reporting
User Story: As an HR user, I want to report on leave balances and certification status so that I can ensure compliance.
Acceptance Criteria:
Scenario: Generate report
  Given leave and certification data exists
  When I generate a report
  Then I see balances, expirations, and can export results
Additional Details:
Priority: Medium
Story Points: 5
Dependencies: E06, E07
Notes: Reports must be role-based.

#### User Story 3
Title: Safety Metrics Dashboard
User Story: As a safety manager, I want to view KPIs on incidents and corrective actions so that I can improve safety.
Acceptance Criteria:
Scenario: View dashboard
  Given incident data exists
  When I view the dashboard
  Then I see charts for incident rates, types, and resolution times
Additional Details:
Priority: Medium
Story Points: 5
Dependencies: E08
Notes: Metrics endpoints must be available for BI.

#### User Story 4
Title: Role-Based Report Access
User Story: As an admin, I want to control who can access which reports so that sensitive data is protected.
Acceptance Criteria:
Scenario: Access control
  Given I am assigned a role
  When I access reports
  Then I only see those permitted for my role
Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E03
Notes: Access rules must be documented.
