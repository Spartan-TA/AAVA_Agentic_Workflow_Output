### E15 - Reporting & Analytics

#### User Story 1
Title: Filter Reports by Date, Department, Shift
User Story: As an HR, I want to filter operational reports by date, department, and shift so that insights are actionable.
Acceptance Criteria:
Scenario: Report Filtering
Given report data
When HR applies filters
Then only matching records are shown
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Filters must be fast

#### User Story 2
Title: Export Reports in CSV/PDF
User Story: As an ADMIN, I want to export reports in CSV/PDF so that data can be shared.
Acceptance Criteria:
Scenario: Report Export
Given filtered report
When ADMIN requests export

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E07, E08, E14
