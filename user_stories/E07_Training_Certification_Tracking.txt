### E07: Training & Certification Tracking

#### 1. Title: Manage Employee Certifications (CRUD)
User Story: As an HR user I want to add, update, and remove employee certifications So that compliance is tracked
Acceptance Criteria:
Scenario: Add certification
Given an employee
When I POST a certification
Then it is added to their profile

Scenario: Remove certification
Given an expired certification
When I DELETE it
Then it is removed from the profile

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Track expiration dates

---

#### 2. Title: Certification Expiry Alerts
User Story: As a supervisor I want to receive alerts before certifications expire So that renewals are not missed
Acceptance Criteria:
Scenario: 30/7 day alerts
Given a certification expires in 30 or 7 days
When the date approaches
Then an alert is sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Configurable alert periods

---

#### 3. Title: Block Assignment for Expired Certifications
User Story: As a scheduler I want to prevent assignment to tasks requiring valid certifications So that only qualified staff are assigned
Acceptance Criteria:
Scenario: Assignment blocked
Given an employee's certification is expired
When I assign them to a restricted task
Then the system prevents the assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Enforce at scheduling time

---

#### 4. Title: Upload Certification Proof Documents
User Story: As an HR user I want to upload proof documents for certifications So that records are complete
Acceptance Criteria:
Scenario: Upload document
Given a certification
When I upload a file
Then it is stored and linked to the certification

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Support PDF/JPG/PNG

---

#### 5. Title: Display Certification Status on Employee Profile
User Story: As a supervisor I want to view certification status on employee profiles So that I can verify qualifications
Acceptance Criteria:
Scenario: View profile
Given an employee
When I view their profile
Then all certifications and statuses are displayed

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Show expiry dates
