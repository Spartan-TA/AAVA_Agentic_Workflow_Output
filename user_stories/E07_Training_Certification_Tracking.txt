### E07: Training & Certification Tracking

#### User Story 1
**Title:** Certification CRUD
**User Story:** As an HR I want to add and update employee certifications So that compliance is tracked
**Acceptance Criteria (Gherkin):**
```
Given certification data
When I POST/PUT /certifications
Then certifications are created or updated for employees

Given expired certification
When I update
Then the system flags for renewal
```
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Proof document upload

#### User Story 2
**Title:** Certification Expiry Alerts
**User Story:** As a SUPERVISOR I want alerts for expiring certifications So that renewals are not missed
**Acceptance Criteria (Gherkin):**
```
Given a certification expiring in 30/7 days
When I view alerts
Then I see notifications for renewal

Given no expiring certifications
When I view alerts
Then no notifications are shown
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Dashboard and email/SMS

#### User Story 3
**Title:** Assignment Block for Expired Certs
**User Story:** As a SUPERVISOR I want to prevent assignment of tasks to employees with expired certifications So that safety is ensured
**Acceptance Criteria (Gherkin):**
```
Given an employee with expired cert
When I assign equipment-sensitive tasks
Then the system blocks the assignment

Given valid certification
When I assign
Then assignment proceeds
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Scheduling checks
