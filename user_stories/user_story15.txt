Title: Leave & Absence Management - Request Leave

User Story: As a worker, I want to request PTO, sick, or unpaid leave so that my absences are properly recorded.

Acceptance Criteria:

Scenario: Submit leave request
Given I am authenticated as a worker
When I POST a leave request with type and dates
Then the request is created and pending approval

Scenario: Leave request validation
Given I have insufficient accrual balance
When I submit a PTO request
Then the request is rejected

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee CRUD, RBAC, Scheduling
- Notes: Accrual balances must be enforced.
