Title: Reporting - Attendance & Overtime Reports

User Story: As a supervisor I want to generate attendance and overtime reports so that I can monitor staffing and compliance.

Acceptance Criteria:
Scenario: Generate attendance report
Given attendance data exists
When I request a report for a date range
Then I receive a report filtered by date, department, and shift

Scenario: Export report as CSV/PDF
Given a report is generated
When I request an export
Then I receive the file within 10 seconds for up to 50k rows

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Access controlled.

Title: Reporting - Certification & Safety KPIs

User Story: As a safety manager I want to view certification status and safety KPIs so that I can identify risks.

Acceptance Criteria:
Scenario: View certification status dashboard
Given certification data exists
When I access the dashboard
Then I see current certification status for all employees

Scenario: View safety KPIs
Given incident data exists
When I access the dashboard
Then I see safety metrics and trends

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Metrics endpoints available for BI.
