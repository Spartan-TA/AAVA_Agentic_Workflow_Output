Title: Leave Request Workflow

User Story: As an employee I want to request paid or unpaid leave So that my time off is tracked and approved

Acceptance Criteria:
Scenario: Submit Leave Request
  Given I have leave balance
  When I submit a leave request
  Then the request is pending supervisor approval

Scenario: Leave Approval
  Given a pending leave request
  When the supervisor approves
  Then my leave balance is updated
