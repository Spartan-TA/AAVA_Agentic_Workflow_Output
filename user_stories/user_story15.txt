Title: Record Safety Incidents and Near-Misses

User Story: As a safety officer I want to record incidents and near-misses with details so that safety trends can be tracked and addressed

Acceptance Criteria:
Scenario: Recording a safety incident
Given an incident occurs in the warehouse
When I submit an incident report with severity, location, and involved employees
Then the incident is logged and available for investigation

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Validation required for all fields

Title: Manage Incident Investigation Workflow

User Story: As a supervisor I want to manage the investigation workflow for safety incidents so that corrective actions are tracked and completed

Acceptance Criteria:
Scenario: Investigating an incident
Given an incident is logged
When I update the status to 'Investigating' and add corrective actions
Then the workflow progresses and actions are tracked until resolution

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Incident logging
- Notes: Statuses: Open, Investigating, Resolved

Title: Export OSHA Summary Reports

Acceptance Criteria:
Scenario: Exporting OSHA report

When I export the OSHA summary
Then I receive a file with all required fields for the selected period

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Incident data
- Notes: Export formats CSV and PDF
