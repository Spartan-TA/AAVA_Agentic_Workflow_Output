Title: Shift Audit Entry Generation
User Story: As a compliance officer, I want audit entries generated for shift changes so that all modifications are traceable.
Acceptance Criteria:
Scenario: Audit entry created
Given a shift is created, updated, or deleted
When the action occurs
Then an audit entry is logged with actor, timestamp, and before/after state

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Shift Assignment
- Notes: Supports compliance requirements
