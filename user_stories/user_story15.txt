Title: Approve/Reject Leave Request
User Story: As a manager I want to approve or reject leave requests So that I can manage team availability
Acceptance Criteria:
Scenario: Leave request approval
Given I am logged in as a manager
When I review a pending leave request and select approve or reject
Then the employee should be notified of the decision and the leave calendar updated accordingly
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notifications, Calendar module
- Notes: Approval workflow must be auditable.
