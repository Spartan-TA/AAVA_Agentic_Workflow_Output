Title: Daily Attendance Totals and Exportable Reports

User Story:
As a payroll administrator, I want to generate daily attendance totals and export reports in CSV format so that payroll processing is accurate and efficient.

Acceptance Criteria:
- Scenario: Daily totals are computed
  Given attendance events are recorded for a day
  When the system calculates totals
  Then each worker's total hours worked is available

- Scenario: Export attendance report
  Given attendance data exists for a period
  When the administrator exports the report
  Then a CSV file is generated with all relevant fields

Additional Details:
- Reports must include shift association, corrections, and approval status
- Export must be available via API and UI
- Exported data must match internal calculations
