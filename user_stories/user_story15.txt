Title: Expose REST APIs for HRIS Integration

User Story: As a system integrator I want REST APIs for HRIS to create and update employee records so that master data is synchronized automatically

Acceptance Criteria:
Scenario: HRIS API integration
Given HRIS sends a new hire event
When the API receives the event
Then a new employee record is created or updated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding, Employee master data, RBAC
- Notes: JWT/OAuth2-secured APIs
