Title: Request Leave or PTO

User Story: As an employee I want to submit leave or PTO requests through the system So that my time off is tracked and approved efficiently

Acceptance Criteria:
Scenario: Leave request submitted
  Given I am logged in
  When I submit a leave or PTO request
  Then my manager should be notified for approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee entity, notification system
- Notes: Support different leave types (vacation, sick, unpaid, etc.).
