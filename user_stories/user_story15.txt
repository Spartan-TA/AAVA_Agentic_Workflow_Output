Title: Attendance Correction Workflow

User Story: As an employee I want to request corrections to my attendance records So that mistakes in clock-in/out times can be rectified

Acceptance Criteria:
Scenario: Submit correction request
  Given I am authenticated
  When I submit a correction request for a specific attendance record
  Then the request should be logged and routed to my manager
Scenario: Manager reviews correction
  Given a correction request is pending
  When my manager reviews and approves or rejects it
  Then the attendance record should be updated or the request marked as rejected

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Attendance API, workflow engine
- Notes: Correction history must be auditable
