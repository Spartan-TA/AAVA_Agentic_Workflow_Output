Title: Generate Operational Reports

User Story:
As an operations manager, I want to generate reports on attendance, overtime, leave balances, certifications, and safety KPIs so that I can make data-driven decisions.

Acceptance Criteria:
Scenario 1: Filter reports
  Given report data exists
  When I filter by date, department, or shift
  Then the report updates accordingly

Scenario 2: Export reports
  Given a report is generated
  When I export to CSV or PDF
  Then the export completes within 10 seconds for up to 50k rows

Scenario 3: Access control
  Given reports exist
  When users access them
  Then access is restricted by role

Scenario 4: Metrics endpoints
  Given metrics are available
  When accessed via API
  Then BI tools can consume them

Additional Details:
Priority: Medium
Story Points: 8
Dependencies: E04, E05, E06, E07, E08, E14
Notes: Dashboards must be role-based.
