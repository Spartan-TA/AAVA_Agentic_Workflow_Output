Epic E03: Role-Based Access Control (RBAC)

1. Title: Restrict Sensitive Operations
   User Story: As an ADMIN I want to restrict sensitive endpoints to authorized roles So that PII is protected.
   Acceptance Criteria:
     Scenario: Unauthorized access
     Given a user without ADMIN role
     When they access /employees/delete
     Then a 403 Forbidden error is returned
   Additional Details: Priority: High, Story Points: 2, Dependencies: E01,E02, Notes: Test coverage required.

2. Title: Supervisor Row-Level Constraints
   User Story: As a SUPERVISOR I want to access only my team's records So that I cannot view other teams' data.
   Acceptance Criteria:
     Scenario: Supervisor access
     Given a supervisor of Team A
     When they GET /employees
     Then only Team A employees are returned
   Additional Details: Priority: High, Story Points: 2, Dependencies: E02, Notes: Row-level security.

3. Title: API Key/OAuth2 Toggle
   User Story: As a DEVOPS ENGINEER I want to toggle between API key and OAuth2 authentication So that integration flexibility is maintained.
   Acceptance Criteria:
     Scenario: Config toggle
     Given the config is set to API key
     When I authenticate
     Then API key is required and OAuth2 is disabled
   Additional Details: Priority: Medium, Story Points: 2, Dependencies: E01,E02, Notes: Document config options.

4. Title: Worker Restricted Access
   User Story: As a WORKER I want to access only my own profile So that my privacy is ensured.
   Acceptance Criteria:
     Scenario: Worker profile access
     Given a logged-in worker
     When they GET /employees/{id}
     Then only their own record is accessible
   Additional Details: Priority: High, Story Points: 1, Dependencies: E02, Notes: 401 for unauthenticated.

5. Title: Error Handling for Unauthorized Requests
   User Story: As a USER I want clear error messages for unauthorized actions So that I understand access issues.
   Acceptance Criteria:
     Scenario: Unauthorized request
     Given no valid token
     When I access a protected endpoint
     Then a 401 Unauthorized error is returned
   Additional Details: Priority: High, Story Points: 1, Dependencies: E03, Notes: Error message must be clear.
