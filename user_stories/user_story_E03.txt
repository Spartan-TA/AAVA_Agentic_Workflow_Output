[E03] Role-Based Access Control (RBAC)

User Story 1
Title: Implement Role-Based Authentication

User Story: As a system, I want to authenticate users and assign roles (ADMIN, HR, SUPERVISOR, WORKER) so that access is controlled.

Acceptance Criteria:
Scenario: User login with role
Given a valid user credential
When I log in
Then I receive a token with the correct role

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01,E02
- Notes: Use Spring Security

User Story 2
Title: Secure Endpoints by Role

User Story: As a system, I want to restrict API endpoints by user role so that only authorized users can perform sensitive actions.

Acceptance Criteria:
Scenario: Access control enforced
Given a user with insufficient role
When I access a restricted endpoint
Then I receive 403 Forbidden

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03-1
- Notes: Method and endpoint security

User Story 3
Title: Enforce Row-Level Security for Supervisors

User Story: As a supervisor, I want to access only my team's data so that privacy is maintained.

Acceptance Criteria:
Scenario: Supervisor data access
Given a supervisor user
When I list employees
Then I see only employees assigned to my team

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03-2
- Notes: Row-level constraints

User Story 4
Title: Support API Key/OAuth2 Toggle

User Story: As an admin, I want to toggle between API key and OAuth2 authentication via config so that integration is flexible.

Acceptance Criteria:
Scenario: Auth mode switchable
Given the config is set to API key
When I authenticate
Then API key is required

Given the config is set to OAuth2
When I authenticate
Then OAuth2 is required

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03-1
- Notes: Configurable at startup

User Story 5
Title: Add Security Tests for All Rules

User Story: As a QA, I want automated tests for all security rules so that unauthorized access is prevented.

Acceptance Criteria:
Scenario: Security tests pass
Given the test suite
When I run security tests
Then all unauthorized/forbidden cases are covered

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E03-2
- Notes: Test 401 and 403 cases
