### E03: Role Based Access Control (RBAC)

**User Story 1: Implement Role-Based Endpoint Security**
- User Story: As an admin, I want to restrict API endpoints by user role So that only authorized users can access sensitive data.
- Acceptance Criteria:
  - Scenario: Unauthorized access
    - Given a user without credentials
    - When accessing a protected endpoint
    - Then a 401 Unauthorized is returned
  - Scenario: Forbidden action
    - Given a user with insufficient role
    - When accessing a restricted endpoint
    - Then a 403 Forbidden is returned
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Roles: ADMIN, HR, SUPERVISOR, WORKER.

**User Story 2: Row-Level Security for Supervisors**
- User Story: As a supervisor, I want to access only my team's records So that I cannot view or modify other teams' data.
- Acceptance Criteria:
  - Scenario: Supervisor access
    - Given a supervisor user
    - When accessing employee data
    - Then only employees in their team are visible/editable
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Security rules must be covered by tests.
