EPIC E18 - Localization & Multi-Warehouse

===========================================

User Story 1: Warehouse Entity with Config
---------------------------------------------
Title: Support Multiple Warehouses with Config

User Story: As an admin, I want to configure multiple warehouses so that site-specific policies are applied.

Acceptance Criteria:
Scenario: Warehouse configuration
  Given warehouse entity
  When created
  Then config options are available

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02, E05
- Notes: Support calendars, shift templates.
