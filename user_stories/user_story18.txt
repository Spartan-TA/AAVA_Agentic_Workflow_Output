Title: Employee API Localization and Internationalization
User Story: As a Global HR user I want Employee API error messages and responses localized So that users in different regions can understand them
Acceptance Criteria:
Scenario: Localized Error Message
Given a user with locale preference
When an error occurs
Then the error message is returned in the user's language
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD API
- Notes: Support at least English and Spanish
