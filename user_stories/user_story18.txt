### E18 - Localization & Multi-Warehouse

**Title:** Support Multiple Warehouses
**User Story:** As an admin, I want to manage multiple warehouses so that operations are scalable.
**Acceptance Criteria:**
Scenario: Multi-warehouse support
Given multiple warehouses
When I assign employees
Then each is linked to a specific warehouse
**Additional Details:** Priority: Medium, Story Points: 3, Dependencies: E02, E03, Notes: Filter data by warehouse.

**Title:** Localization of UI
**User Story:** As a user, I want the UI to be available in multiple languages so that it is accessible to all staff.
**Acceptance Criteria:**
Scenario: Language selection
Given I select a language
When I use the app
Then all UI elements are localized
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, Notes: Support at least English and Spanish.
