Title: Support Multiple Warehouse Locations
User Story: As an administrator I want to manage multiple warehouse locations in the system so that operations can be tracked separately.
Acceptance Criteria:
Scenario: Adding warehouse location
Given I am on the warehouse management page
When I add a new location
Then the location should be available for assignment and reporting
Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02, E05
- Notes: Locations selectable in all relevant modules
