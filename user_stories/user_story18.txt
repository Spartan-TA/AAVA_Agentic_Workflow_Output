Title: Calculate Hours Worked Per Shift

User Story: As a payroll administrator I want the system to automatically calculate hours worked per shift based on clock-in and clock-out events So that payroll processing is accurate and efficient

Acceptance Criteria:
Scenario: Standard shift calculation
  Given an employee has valid clock-in and clock-out events for a shift
  When the shift ends
  Then the total hours worked are calculated and stored
Scenario: Multiple clock events
  Given an employee has multiple clock-in/out events in a day
  When the day ends
  Then the system aggregates all valid intervals to compute total hours
Scenario: Missing clock-out
  Given an employee has clocked in but not clocked out
  When the shift ends
  Then the system flags the record for correction

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support for overnight shifts and split shifts required.
