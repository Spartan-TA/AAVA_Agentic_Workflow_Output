Title: Create Shift Templates

User Story: As a SCHEDULER I want to create reusable shift templates So that I can quickly assign standard shifts to employees

Acceptance Criteria:

Scenario: Scheduler creates a shift template
Given I am logged in as SCHEDULER
When I define shift start/end times and roles
Then the template is saved for future use

Scenario: Scheduler edits a shift template
Given a template exists
When I update the template
Then changes are reflected for future assignments

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Templates should support multiple locations and roles.
