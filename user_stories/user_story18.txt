Title: Performance Review Cycle
User Story: As an HR user, I want to create and assign performance review cycles so that structured feedback is collected.
Acceptance Criteria:
  Given a review template,
  When I assign it to employees,
  Then they can submit and acknowledge reviews.

  Given a completed review,
  When it is signed off,
  Then the history is immutable.

Additional Details:
  Priority: Medium
  Story Points: 5
  Dependencies: Employee CRUD, RBAC
  Notes: PDF export supported.
