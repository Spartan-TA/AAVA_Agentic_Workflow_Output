User Story 1: Localize UI
Title: Localize User Interface
User Story: As a worker, I want the UI localized in my language so that I can use the system comfortably.
Acceptance Criteria (Gherkin):
Given localization files exist,
When I select a language,
Then UI is displayed in chosen language.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E12
Notes: Supports inclusivity.
