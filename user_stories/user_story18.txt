Title: HRIS Sync for New Hires and Terminations
User Story: As an HR manager I want the system to sync new hires and terminations from HRIS So that employee data is always up to date
Acceptance Criteria:
Scenario: HRIS sync job
Given new hires or terminations exist in HRIS
When the sync job runs
Then employee records are created or updated accordingly
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, HRIS API
- Notes: Idempotent sync required
