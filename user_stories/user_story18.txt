Title: Localization - Support Multiple Tenants

User Story: As an admin I want to support multiple warehouses/regions with tenant isolation so that data and config are separated.

Acceptance Criteria:
Scenario: Tenant ID in all entities
Given multiple tenants exist
When I create or query data
Then all records are associated with a tenant ID

Scenario: Data isolation enforced
Given I am logged in as a tenant user
When I access data
Then I only see data for my tenant

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: E01, E02
- Notes: Tests validate isolation.

Title: Localization - Locale-Specific Config

User Story: As a user I want locale-specific date/time, currency, and language so that the system matches my region.

Acceptance Criteria:
Scenario: Locale config per tenant
Given a tenant is configured for a locale
When I view dates, times, and currency
Then they are formatted per locale

Scenario: Translations for UI strings
Given translations exist
When I change language
Then UI strings update accordingly

Additional Details:
- Priority: Low
- Story Points: 2
- Dependencies: E01, E02
- Notes: Timezone-aware timestamps.
