Title: Localization & Multi-Tenant
User Story 1: As a system I want to support multiple warehouses and regions So that operations are scalable
Acceptance Criteria:
Scenario: Multi-tenant support
Given multiple warehouses/regions exist
When users access system
Then data is isolated per tenant
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee master data, Shift management
- Notes: Tenant-aware APIs

User Story 2: As a user I want to select language and locale So that I use the system in my preferred language
Acceptance Criteria:
Scenario: Locale selection
Given multiple locales are supported
When I select language
Then UI and notifications are localized
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Notification module
- Notes: Support at least English/Spanish

User Story 3: As a system I want to isolate data and configuration per warehouse So that privacy is maintained

Additional Details:
- Priority: Medium
- Story Points: 2

Additional Details:
- Priority: Medium
- Story Points: 2
