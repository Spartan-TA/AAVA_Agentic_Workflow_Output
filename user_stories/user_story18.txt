Title: Localization & Multi-Warehouse - Multi-Language and Warehouse Support
User Story: As a global admin, I want the system to support multiple languages and warehouses so that it can be used across regions.
Acceptance Criteria:
Scenario: Language selection
  Given multiple locales are configured
  When I select a language
  Then the UI updates accordingly

Scenario: Warehouse selection
  Given multiple warehouses exist
  When I select a warehouse
  Then data is scoped to that location

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E01, E02, E03
Notes: Supports global operations
