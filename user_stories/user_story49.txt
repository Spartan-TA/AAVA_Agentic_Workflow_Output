Title: Secure Delivery and Retry of Payroll Exports

User Story:
As a payroll administrator, I want payroll exports to be delivered securely via SFTP or API and automatically retried with backoff if delivery fails so that payroll data reaches the provider reliably.

Acceptance Criteria:
- Scenario: Export delivered via SFTP/API
  Given an export file is generated
  When secure delivery is configured
  Then the file is sent to the provider endpoint

- Scenario: Failed delivery is retried
  Given a delivery attempt fails
  When the retry logic runs
  Then the export is retried with exponential backoff until successful or max attempts reached

Additional Details:
- Delivery status must be tracked and visible in the UI
- All delivery attempts and failures must be logged
- Secure protocols and credentials must be configurable
