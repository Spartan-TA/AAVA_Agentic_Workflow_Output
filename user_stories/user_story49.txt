Title: Mobile Leave Request

User Story: As an employee I want to request leave using my mobile device So that I can manage my time off conveniently

Acceptance Criteria:
Scenario: Requesting leave on mobile
Given I am logged into the mobile app
When I submit a leave request
Then my manager should be notified and the request tracked in the system

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Mobile app, leave management module
- Notes: Support for leave balance display and approval workflow.
