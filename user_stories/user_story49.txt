Title: Offline Mobile Access for Critical Features

User Story: As a user I want to access critical features of the platform on my mobile device even when offline so that I can continue working without interruption

Acceptance Criteria:
Scenario: Using PWA offline
Given I have installed the PWA and previously logged in
When I lose internet connectivity
Then I can still clock in/out, view my schedule, and submit requests, with data syncing when reconnected

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: PWA, offline storage
- Notes: Show clear indicators for offline mode and pending syncs.
