Title: Enable Actuator Health Endpoint

User Story: As a system administrator I want to access the Actuator health endpoint so that I can monitor the application's health status in real time

Acceptance Criteria:
Scenario: Health endpoint availability
  Given the application is running
  When I send a GET request to /actuator/health
  Then the response should indicate status UP

Scenario: Health endpoint documentation
  Given the health endpoint is enabled
  When I review the API documentation
  Then the endpoint should be described with example responses

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Ensure endpoint is secured and accessible only to authorized users
