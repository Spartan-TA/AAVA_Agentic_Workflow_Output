#### User Story 10: API Key/OAuth2 Toggle via Config
**As a** DevOps engineer  
**I want** to toggle between API key and OAuth2 authentication via configuration  
**so that** the system supports different security models.

**Acceptance Criteria:**
- **Given** a config change,  
  **When** I restart the application,  
  **Then** authentication mode switches as specified.

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: E03  
Notes: Document configuration options.
