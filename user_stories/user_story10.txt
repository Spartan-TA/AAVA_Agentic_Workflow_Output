Title: Unauthorized and Forbidden Request Handling

User Story: As a user I want to receive clear error responses when I attempt unauthorized or forbidden actions So that I understand my access limitations

Acceptance Criteria:
Scenario: Unauthorized request
Given I am not authenticated
When I request a protected endpoint
Then I should receive a 401 Unauthorized error

Scenario: Forbidden request
Given I am authenticated but lack required role
When I request a restricted endpoint
Then I should receive a 403 Forbidden error

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Error messages should be clear and consistent across endpoints
