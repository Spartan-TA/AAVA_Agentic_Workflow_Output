Title: Track Employee Certifications
User Story: As an HR manager I want to record and track employee certifications So that compliance and qualification status are always visible
Acceptance Criteria:
Scenario: Add certification Given an employee profile When I add a certification with expiry date Then the certification is visible and alerts are scheduled
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data CRUD (E02), RBAC (E03)
- Notes: Certification CRUD; expiry alerts

Title: Alert for Expiring Certifications
User Story: As a supervisor I want to receive alerts for certifications expiring soon So that I can ensure staff remain qualified
Acceptance Criteria:
Scenario: Certification expiry alert Given a certification is expiring in 30/7 days When the system checks expiry dates Then an alert is sent to the supervisor and employee
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Training & Certification Tracking (E07)
- Notes: Alert timing configurable

Title: Block Assignment to Unqualified Roles
User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that safety and compliance are maintained

Scenario: Block assignment Given an employee's certification is expired When I try to assign them to a restricted task Then the system blocks the assignment and displays a warning
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Training & Certification Tracking (E07)
- Notes: Scheduling checks required
