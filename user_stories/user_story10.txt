Title: Submit Leave Request
User Story: As an employee I want to submit a leave request so that my absence is officially recorded and approved
Acceptance Criteria:
Scenario: Successful leave request submission
  Given I am logged in as an employee
  When I fill out and submit the leave request form
  Then my request is saved and routed to my supervisor for approval
Scenario: Request exceeds available leave balance
  Given I have limited leave balance
  When I request more days than available
  Then I receive an error and cannot submit the request
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data CRUD
- Notes: Validate leave balance before submission

Title: Approve/Reject Leave Request
User Story: As a supervisor I want to approve or reject leave requests so that team coverage is maintained
Acceptance Criteria:
Scenario: Approve leave request
  Given a pending leave request exists
  When I click 'Approve'
  Then the request status is updated and the employee is notified
Scenario: Reject leave request
  Given a pending leave request exists
  When I click 'Reject' and provide a reason
  Then the request status is updated and the employee is notified
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notifications & Announcements
- Notes: Approval/rejection should trigger notifications

Title: View Leave Balance

  Then I see my available leave days
Additional Details:
- Priority: Medium
