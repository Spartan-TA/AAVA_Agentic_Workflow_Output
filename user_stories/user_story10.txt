Title: Clock In/Out Event Capture
User Story: As a warehouse worker I want to clock in and out using my device so that my working hours are accurately recorded
Acceptance Criteria:
Scenario: Successful clock in/out
Given I am logged in and at the warehouse
When I clock in or out using the app
Then my attendance event is recorded with timestamp and device info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence validation optional

Title: Missed Punch Correction Workflow
User Story: As a supervisor I want to approve corrections for missed punches so that attendance records remain accurate
Acceptance Criteria:
Scenario: Correction approval
Given a worker submits a missed punch correction
When I review and approve the correction
Then the attendance record is updated and flagged as corrected
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Approval task generated

Title: Automatic Shift Association
User Story: As a system I want to associate clock events with scheduled shifts so that daily totals are computed automatically
Acceptance Criteria:
Scenario: Shift association
Given a clock event is recorded
When the system processes attendance
Then the event is linked to the correct shift and daily hours are calculated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Handles overnight shifts
