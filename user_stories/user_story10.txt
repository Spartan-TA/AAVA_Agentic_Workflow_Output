Title: Secure Endpoints and Methods

User Story: As a developer I want to secure endpoints and methods based on role So that only authorized users can perform sensitive operations

Acceptance Criteria:

Scenario: Method-level security enforced
Given a user with a specific role
When I call a method with @PreAuthorize
Then access is allowed or denied based on role

Scenario: Row-level constraints applied
Given a SUPERVISOR user
When I access employee data
Then I only see employees in my team

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: RBAC implementation
- Notes: Use @PreAuthorize, @PostAuthorize; implement row-level filters
