Title: Conduct Performance Reviews

User Story:
As a supervisor, I want to create and manage performance reviews with goals, competencies, and ratings so that employee development is structured and documented.

Acceptance Criteria:
Scenario 1: Create review cycle
  Given I am a supervisor
  When I create a new review cycle
  Then it is assigned to selected employees

Scenario 2: Submit and acknowledge review
  Given a review is assigned
  When supervisor and employee complete their sections
  Then both can acknowledge and sign off

Scenario 3: Export review
  Given a review is completed
  When I export the review
  Then a PDF is generated

Scenario 4: Role-based visibility
  Given reviews exist
  When users access them
  Then access is limited by role

Scenario 5: Immutable history
  Given a review is signed off
  When I attempt to edit it
  Then the review is locked

Additional Details:
Priority: Medium
Story Points: 8
Dependencies: E02, E03
Notes: Templates for quarterly/annual cycles.
