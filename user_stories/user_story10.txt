Title: Attendance Corrections Workflow
User Story: As a supervisor, I want to approve corrections for missed punches so that attendance records remain accurate.
Acceptance Criteria:
Scenario: Missed punch correction requested
Given a worker missed clock-in
When they submit a correction
Then an approval task is created for the supervisor

Scenario: Correction approved
Given a correction task is pending
When the supervisor approves
Then the attendance record is updated

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Time & Attendance
- Notes: Approval workflow required
