Title: Schedule Conflict Detection
User Story: As a scheduler I want the system to detect and prevent shift conflicts So that employees are not double-booked
Acceptance Criteria:
Scenario: Assign overlapping shifts
Given an employee already assigned to a shift
When I try to assign another overlapping shift
Then the system blocks the assignment and shows a conflict error
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03, E04
- Notes: Bulk assignment supported
