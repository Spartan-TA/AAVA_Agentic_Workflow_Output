Title: Attendance Totals & Corrections Workflow
User Story: As a supervisor, I want daily attendance totals and a workflow for missed punch corrections so that payroll is accurate.
Acceptance Criteria:
  Given attendance events,
  When I view daily totals,
  Then hours worked are computed per shift.

  Given a correction request,
  When I approve/deny,
  Then the attendance record updates accordingly.

Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: Attendance Clock In/Out
  Notes: Approval tasks generated.
