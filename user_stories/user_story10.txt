Title: Performance Reviews - Create Review Cycle

User Story: As an HR user I want to create quarterly or annual performance review cycles so that structured feedback is collected.

Acceptance Criteria:
Scenario: Create review cycle
Given I am authenticated as HR
When I POST to /reviews/cycles with details
Then a new review cycle is created

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Templates for goals, competencies, ratings.

---

Title: Performance Reviews - Assign Reviews

User Story: As a supervisor I want to assign performance reviews to employees so that feedback is gathered.

Acceptance Criteria:
Scenario: Assign review to employee
Given a review cycle exists
When I assign it to an employee
Then the employee is notified and can submit input

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Supervisor/employee acknowledgement required.

---

Title: Performance Reviews - Submit and Acknowledge

User Story: As an employee I want to submit my self-review and acknowledge supervisor feedback so that the review process is complete.

Acceptance Criteria:
Scenario: Submit self-review
Given a review is assigned
When I submit my input
Then it is recorded

Scenario: Acknowledge supervisor review
Given supervisor feedback is submitted
When I acknowledge it
Then the review is marked complete

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Immutable after sign-off.

---

Title: Performance Reviews - Export Review PDF

User Story: As an HR user I want to export completed reviews as PDF so that records are archived.

Acceptance Criteria:
Scenario: Export review as PDF
Given a review is completed
When I request a PDF export
Then I receive a PDF file with all review details

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03
- Notes: Role-based visibility enforced.
