Title: BadgeId Uniqueness Enforcement
User Story: As a system administrator I want badgeId to be unique across all employee records So that duplicate badge assignments are prevented
Acceptance Criteria:
Scenario: BadgeId uniqueness validation
Given an existing employee with badgeId X
When I attempt to create or update another employee with badgeId X
Then the operation fails with a validation error
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01
- Notes: Validation must be enforced at API and database levels
