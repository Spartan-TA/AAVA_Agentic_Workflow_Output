Title: Unauthorized and Forbidden Request Handling

User Story: As a developer I want the API to return clear error messages for unauthorized and forbidden requests So that clients can handle access issues appropriately

Acceptance Criteria:
Scenario: Unauthorized request
Given a request without valid authentication
When the API receives the request
Then it should return a 401 Unauthorized error with a descriptive message

Scenario: Forbidden request
Given a request with valid authentication but insufficient permissions
When the API receives the request
Then it should return a 403 Forbidden error with a descriptive message

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: API Key/OAuth2 Toggle, Role-Based Access Control
- Notes: Ensure error messages are consistent and documented.
