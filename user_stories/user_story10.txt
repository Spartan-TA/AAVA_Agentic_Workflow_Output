Title: Support API Key and OAuth2 Security Toggle

User Story:
As a DevOps engineer, I want to configure the authentication mechanism (API key or OAuth2) via application settings so that the system can adapt to different security requirements.

Acceptance Criteria:
- Scenario: System is configured for API key authentication
  Given the application is set to API key mode
  When a request is made with a valid API key
  Then the request is authenticated and processed

- Scenario: System is configured for OAuth2 authentication
  Given the application is set to OAuth2 mode
  When a request is made with a valid OAuth2 token
  Then the request is authenticated and processed

- Scenario: Invalid credentials
  Given the application is in either mode
  When a request is made with invalid credentials
  Then the response is 401 Unauthorized

Additional Details:
- Configuration must be switchable without code changes (e.g., via application.yml)
- Automated tests must cover both authentication modes
