Title: Support API Key/OAuth2 Toggle
User Story: As a system admin I want to toggle between API key and OAuth2 authentication via configuration So that the system supports different security models.
Acceptance Criteria:
Scenario: Switch authentication mode
Given the config is set to API key
When I authenticate with a valid key
Then access is granted; when set to OAuth2, only valid tokens are accepted
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC, Security
- Notes: Must be documented
