Title: Implement Method and Endpoint Security

User Story:
As a backend developer,
I want to enforce security at both the method and endpoint levels,
So that only authorized users can access sensitive operations and data.

Acceptance Criteria:
- Security annotations are applied to controller methods and service layer.
- Endpoints are protected according to role permissions.
- Unauthorized access attempts are logged and return appropriate HTTP status codes.
- Automated tests verify security enforcement for all endpoints.

Additional Details:
- Use @PreAuthorize, @Secured, or similar annotations.
- Security configuration is documented and versioned.
- Security rules are reviewed for completeness and coverage.
