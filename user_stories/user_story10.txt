Title: Performance Reviews & Goals

User Story: As an HR manager I want to create and manage performance review cycles and goals so that employee feedback and development are structured and tracked.

Acceptance Criteria:

Scenario: Create review cycle
Given I am an HR manager
When I create a new review cycle
Then it is assigned to selected employees

Scenario: Submit and acknowledge review
Given a review is assigned
When a supervisor submits ratings and comments
Then the employee can acknowledge the review

Scenario: PDF export
Given a completed review
When I export the review
Then a PDF is generated with all details

Scenario: Immutable history
Given a signed-off review
When I attempt to edit it
Then the review remains immutable

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data (E02), Role-Based Access Control (E03)
- Notes: Track goals, competencies, ratings, and acknowledgements; role-based visibility required.
