Title: Define Roles and Permissions

User Story: As a SYSTEM ADMIN I want to define roles and permissions So that I can control access to sensitive features and data

Acceptance Criteria:

Scenario: Admin creates a new role
Given I am logged in as SYSTEM ADMIN
When I navigate to the roles management page and create a new role
Then the role should be saved with specified permissions

Scenario: Admin assigns permissions to a role
Given a role exists
When I select permissions for the role
Then only users assigned to that role can access those features

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Roles must be configurable and support granular permissions.
