EPIC E10 - Performance Reviews & Goals

===========================================

User Story 1: Create Review Cycles
---------------------------------------------
Title: Create Quarterly/Annual Review Cycles

User Story: As an HR user, I want to create review cycles so that performance reviews are scheduled.

Acceptance Criteria:
Scenario: Review cycle creation
  Given review cycle endpoint
  When cycle is created
  Then employees are assigned to the cycle

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Support recurring cycles.

===========================================

User Story 2: Assign Reviews to Employees
---------------------------------------------
Title: Assign Performance Reviews to Employees

User Story: As a supervisor, I want to assign reviews to my team so that feedback is structured.

Acceptance Criteria:
Scenario: Review assignment
  Given a review cycle

  Then review forms are generated

Additional Details:
- Priority: Medium
- Story Points: 2
