Title: Implement Role Based Access Control (RBAC)

User Story: As a system administrator I want to assign roles and permissions to users So that I can control access to sensitive features and endpoints

Acceptance Criteria:
Scenario: Restrict access based on role
Given a user with the 'Manager' role
When the user attempts to access an admin-only endpoint
Then the system denies access and returns an authorization error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01 (Project Scaffolding & Domain Setup), E02 (Employee Master Data CRUD)
- Notes: Must support method-level and endpoint-level security using Spring Security.
