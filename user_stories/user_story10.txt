Title: Implement Employee Listing with Pagination and Filtering

User Story: As an HR admin I want to list employee records with pagination and filtering So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Paginated listing
Given multiple employee records exist
When I GET /employees with pagination parameters
Then the response contains the correct page of employee records

Scenario: Filtering
Given employees with different departments and statuses exist
When I filter by department or status
Then only matching employees are returned
