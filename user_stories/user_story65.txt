Title: Generate and Export Operational Reports

User Story:
As an operations manager, I want to generate and export operational reports (attendance, overtime, leave balances, certification status, safety KPIs) so that I can make data-driven decisions and ensure compliance.

Acceptance Criteria:
- Scenario: Generate report with filters
  Given operational data exists
  When the manager selects filters (date, department, shift)
  Then the report is generated with matching data

- Scenario: Export report in CSV/PDF
  Given a report is generated
  When the manager exports it
  Then a CSV or PDF file is created within 10 seconds for up to 50,000 rows

Additional Details:
- Reports must include all relevant fields and be exportable from UI and API
- Exported data must match displayed data
- All exports must be logged for audit
