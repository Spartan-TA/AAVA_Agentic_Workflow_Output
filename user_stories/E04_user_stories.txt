E04: Time & Attendance (Clock In/Out)

User Story 1
Title: Implement Clock-In Endpoint with Geofence

User Story: As a Worker I want to clock in via an endpoint with optional geofence validation So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock-in with geofence
Given my device is within the allowed geofence
When I POST to /attendance/clock-in
Then my clock-in event is recorded with location data

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Geofence validation is configurable

---

User Story 2
Title: Implement Clock-Out Endpoint

User Story: As a Worker I want to clock out via an endpoint So that my shift end time is captured

Acceptance Criteria:
Scenario: Clock-out event
Given I am currently clocked in
When I POST to /attendance/clock-out
Then my clock-out event is recorded and shift hours are calculated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock-in endpoint
- Notes: Device capture is required

---

User Story 3

Additional Details:
- Priority: High
- Story Points: 3
