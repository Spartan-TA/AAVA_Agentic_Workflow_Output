Title: Implement CI/CD Pipeline with Build, Test, and Deployment Automation

User Story: As a DevOps engineer I want to automate build, test, security scan, and deployment processes using GitHub Actions or Jenkins so that releases are reliable and efficient.

Acceptance Criteria:
Scenario: Automated pipeline execution
Given code is pushed to the repository
When the CI/CD pipeline runs
Then the system should build, test, scan for vulnerabilities, and deploy to staging or production automatically

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Pipeline should support rollback on failure.
