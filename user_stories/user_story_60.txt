Title: Automated Pipeline for Build, Test, and Deploy

User Story: As a DevOps engineer I want a CI/CD pipeline that builds, tests, scans, creates Docker images, and deploys to staging/prod so that releases are reliable and repeatable

Acceptance Criteria:
Scenario: CI/CD pipeline execution
  Given a pull request is opened or merged
  When the pipeline runs
  Then code is built, tests and security scans pass, a Docker image is tagged, and deployment to staging is automatic while production requires approval

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E01
- Notes: Use GitHub Actions or Jenkins; pipeline status visible to team.
