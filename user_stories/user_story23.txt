Title: Document Build and Run Steps in README

User Story: As a developer I want clear build and run instructions in the README So that new team members can quickly set up the project

Acceptance Criteria:
Scenario: Onboarding a new developer
Given a new developer joins the team
When they follow the README instructions
Then they can build and run the project without external help

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: README must include prerequisites, build commands, run commands, and troubleshooting tips
