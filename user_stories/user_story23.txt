Title: Certification Document Upload

User Story: As an employee I want to upload certification documents to my profile So that HR can verify my credentials and maintain compliance records

Acceptance Criteria:
Scenario: Document upload
Given a valid certification document
When I upload it to my profile
Then the document should be stored securely and linked to my certification record

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Certification CRUD and Expiry Alerts
- Notes: Support PDF and image formats, enforce file size limits.
