Title: Delete Employee Record

User Story: As an HR administrator I want to delete an employee record So that terminated employees are removed from the active roster

Acceptance Criteria:
Scenario: Successful employee deletion
Given I am viewing an employee's profile
When I choose to delete the record
Then the employee should be removed from the active list and archived for compliance

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding & Domain Setup (E01)
- Notes: Prevent deletion if dependencies exist (e.g., payroll, attendance).
