Title: Leave Request and Approval Workflow

User Story:
As an employee, I want to request PTO, sick, or unpaid leave and have my supervisor approve or deny it so that my time off is properly tracked and covered.

Acceptance Criteria:
- Scenario: Employee submits leave request
  Given an employee is authenticated
  When they submit a leave request with type and dates
  Then a pending approval task is created for their supervisor

- Scenario: Supervisor approves or denies leave
  Given a supervisor has a pending leave request
  When they approve or deny it
  Then the employee is notified and the leave balance is updated

Additional Details:
- Leave types must include PTO, sick, and unpaid
- Requests must check for sufficient accrual balance
- All actions must be logged and exportable
