Title: Support Multiple Warehouses with Distinct Calendars
User Story: As an admin I want to manage multiple warehouses each with their own operation calendars So that scheduling and policies are accurate per location
Acceptance Criteria:
Scenario: Multi-warehouse calendar
Given multiple warehouses exist
When I configure operation calendars
Then each warehouse uses its own calendar for scheduling
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Scheduling, Warehouse Master Data
- Notes: Blackout dates per warehouse

Title: Warehouse-Specific Policies and Rules
User Story: As an HR manager I want to define policies and rules per warehouse So that compliance and staffing are tailored to each location
Acceptance Criteria:
Scenario: Warehouse policy configuration
Given multiple warehouses exist
When I set policies for each
Then the rules apply only to the selected warehouse
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Policy Engine, Warehouse Master Data
- Notes: Policies include leave, overtime, attendance
