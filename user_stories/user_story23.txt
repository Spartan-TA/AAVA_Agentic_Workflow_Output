Title: Leave Coverage Flagging

User Story: As a manager I want to flag leave requests that require coverage So that I can ensure adequate staffing during employee absences

Acceptance Criteria:
Scenario: Flag leave for coverage
  Given a leave request is submitted
  When I review the request
  Then I can mark it as requiring coverage
Scenario: Assign coverage
  Given a leave request is flagged
  When I assign another employee to cover
  Then the coverage assignment should be recorded
Scenario: Notify coverage assignee
  Given coverage is assigned
  When the assignment is saved
  Then the coverage assignee should be notified

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Leave management module, notification system
- Notes: Support for multiple coverage assignees
