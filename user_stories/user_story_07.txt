Title: Implement Get Employee API Endpoints

User Story: As an HR user I want to retrieve employee records via REST API so that I can view employee information.

Acceptance Criteria:

Scenario: Get employee by ID
Given an employee with ID 123 exists
When I GET /api/v1/employees/123
Then I should receive a 200 OK response
And the response should contain the employee details

Scenario: Get non-existent employee
Given no employee with ID 999 exists
When I GET /api/v1/employees/999
Then I should receive a 404 Not Found response
And the error message should indicate employee not found

Scenario: Get all employees with pagination
Given there are 50 employees in the system
When I GET /api/v1/employees?page=0&size=20
Then I should receive a 200 OK response
And the response should contain 20 employees
And pagination metadata should include total pages, total elements, current page

Scenario: Get employee by badgeId
Given an employee with badgeId 'EMP001' exists
When I GET /api/v1/employees/badge/EMP001
Then I should receive a 200 OK response
And the response should contain the employee with badgeId 'EMP001'

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee entity (E02), Create employee API (E02)
- Notes: Support multiple query methods. Implement proper error handling. Use DTOs for responses.
