Title: Manager Approves Leave Request

User Story: As a manager I want to review and approve or reject leave requests So that I can ensure adequate team coverage

Acceptance Criteria:
Scenario: Approving a leave request
Given I am logged in as a manager
When I review a pending leave request
Then I can approve or reject it and the employee is notified of the decision

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave request submission, notifications
- Notes: Approval/rejection actions should be logged for audit.
