Title: Request Leave

User Story: As an employee I want to request leave through the system So that my manager can review and approve my time off

Acceptance Criteria:
Scenario: Submit leave request
Given I am logged in and have available leave balance
When I submit a leave request
Then my manager should be notified and the request should appear in their approval queue

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave management module
- Notes: Should support multiple leave types (sick, vacation, etc.).
