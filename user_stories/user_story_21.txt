Title: Track Employee Certifications

User Story: As an HR administrator I want to track employee certifications so that compliance requirements are met

Acceptance Criteria:
Scenario: Add certification record
Given I am on an employee profile
When I add certification details and expiration date
Then the certification should be tracked and visible in the system

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee profile module
- Notes: Support multiple certifications per employee.
