Title: Approve or Reject Leave Request
User Story: As a supervisor I want to approve or reject employee leave requests So that I can manage team availability and workload
Acceptance Criteria:
Scenario: Leave approval workflow
Given a leave request is submitted
When I review the request
Then I can approve or reject it and the employee is notified of the decision
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notification module, leave request module
- Notes: Record decision and comments for audit.
