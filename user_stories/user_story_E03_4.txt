Title: API Key/OAuth2 Toggle and Security Test Coverage

User Story: As a system architect I want to enable a toggle between API key and OAuth2 authentication So that the system can support both internal and external integration security requirements

Acceptance Criteria:
Scenario: Switch authentication mode
Given the system is configured for API key or OAuth2
When a request is made to a protected endpoint
Then the system enforces the selected authentication method and denies requests that do not comply

Scenario: Security rules covered by tests
Given all endpoints are protected by RBAC
When automated tests are executed
Then all security rules are validated and coverage is reported

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Configuration must allow runtime selection of auth mode; CI pipeline must include security test coverage report.
