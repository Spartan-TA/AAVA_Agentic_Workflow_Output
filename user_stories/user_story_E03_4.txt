Title: API Key/OAuth2 Toggle via Config

User Story: As a system administrator I want to toggle between API key and OAuth2 authentication via configuration so that I can adapt security protocols to different environments

Acceptance Criteria:
Scenario: Switching authentication methods
Given I have access to system configuration
When I change the authentication mode from API key to OAuth2
Then all endpoints should require the selected authentication method

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Configuration must be documented; changes should be reflected immediately without downtime.
