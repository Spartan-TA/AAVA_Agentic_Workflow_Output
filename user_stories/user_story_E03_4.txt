Title: E03-4 Security Test Coverage

User Story:
As a QA engineer,
I want automated tests to verify all security controls on API endpoints,
So that unauthorized access and privilege escalation are prevented and detected early.

Acceptance Criteria:
Given a set of API endpoints with role-based restrictions,
When automated security tests are run,
Then all endpoints are tested for unauthorized access, privilege escalation, and data leakage.

Given a new or updated endpoint,
When the test suite is executed,
Then security tests are included for the new/changed functionality.

Given a failed security test,
When the test run completes,
Then a detailed report is generated and the build fails.

Additional Details:
- Tests must cover all roles and negative scenarios.
- Security test results must be visible in CI/CD pipelines.
- Test coverage must be tracked and reported.
- Security tests must be reviewed and updated regularly.
