Title: Tenant Data Isolation

User Story: As a system administrator I want each warehouse (tenant) to have isolated data so that information is secure and not accessible across tenants

Acceptance Criteria:
Scenario: Enforcing data isolation
Given multiple tenants are configured
When a user queries data
Then only data for their tenant is returned and tenant ID is enforced in all queries

Additional Details:
- Priority: Low
- Story Points: 3
- Dependencies: Database schema, access control
- Notes: Data isolation must be validated by automated tests
