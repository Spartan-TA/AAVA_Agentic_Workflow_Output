Title: Safety KPI Reporting and BI Metrics Endpoints

User Story: As a safety manager I want to generate safety KPI reports and access metrics endpoints So that I can monitor safety compliance and integrate data with BI tools

Acceptance Criteria:
Scenario: Safety KPI report and metrics endpoint
Given safety data is available
When I request a report or access the metrics endpoint
Then the report is generated and metrics are available for BI integration

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Metrics endpoint must be documented and access controlled
