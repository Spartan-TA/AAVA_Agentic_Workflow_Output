Title: PDF Export and Role-Based Visibility

User Story: As an HR manager I want to export completed performance reviews to PDF and control visibility by role So that records are securely shared and accessed only by authorized users

Acceptance Criteria:
Scenario: Export and visibility
Given a review is completed and signed-off
When I select 'Export to PDF' and set visibility permissions
Then the PDF is generated and only accessible to permitted roles

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E02, E03
- Notes: Exported PDFs must include immutable history and signatures.
