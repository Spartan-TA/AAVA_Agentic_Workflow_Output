Title: Scheduled Report Delivery

User Story: As a manager I want to schedule automatic delivery of key reports So that I receive timely insights without manual intervention

Acceptance Criteria:
Scenario: Scheduling report delivery
Given I have created a report
When I set up a delivery schedule
Then the report should be generated and sent to my email or dashboard at the specified intervals

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Reporting engine, notification service
- Notes: Support daily, weekly, and monthly schedules.
