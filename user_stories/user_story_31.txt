Title: CI/CD Pipeline Implementation

User Story: As a DevOps engineer I want to implement a CI/CD pipeline for automated build, test, security scan, and deployment So that releases are reliable and repeatable with minimal downtime

Acceptance Criteria:
Scenario: Pipeline execution on PR
Given a pull request is created
When the pipeline runs
Then build, test, and security scans are executed

Scenario: Test gate before merge
Given pipeline is running
When tests fail
Then the merge is blocked

Scenario: Docker image creation
Given tests pass
When the pipeline completes
Then a Docker image is created and tagged with commit SHA

Scenario: Deployment to staging/production
Given a Docker image is ready
When deployment is triggered
Then blue-green or canary deployment is executed

Scenario: Rollback capability
Given a deployment issue
When rollback is initiated
Then the previous version is restored

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding
- Notes: Pipeline must support GitHub Actions or Jenkins; rollback must be tested
