EPIC E10 - PERFORMANCE REVIEWS & GOALS

===========================================

Title: Create Performance Review Template

User Story: As an HR admin I want to create and manage review templates so that performance reviews are standardized

Acceptance Criteria:
Scenario: Template creation
Given I have HR admin access
When I create or edit a review template
Then it is saved and available for assignment

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Templates include competencies, goals, rating scales

---

Title: Assign Performance Review to Employee

User Story: As a supervisor I want to assign a performance review to an employee so that the review process can begin

Acceptance Criteria:
Scenario: Review assignment
Given a review cycle is active
When I assign a review
Then the employee receives a notification and can begin the self-assessment

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Assignment triggers workflow for supervisor and employee

---

Title: Submit and Acknowledge Performance Review

User Story: As an employee I want to submit my self-assessment and acknowledge the final review so that the process is complete

Acceptance Criteria:
Scenario: Review submission and acknowledgement
Given a review is assigned
When I submit my self-assessment and acknowledge the supervisor's review
Then the review is locked and archived

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Immutable after acknowledgement

---

Title: Export Performance Review as PDF

User Story: As a supervisor I want to export completed performance reviews as PDF so that I can share or archive them

Acceptance Criteria:
Scenario: PDF export
Given a review is completed
When I request export
Then a PDF is generated with all review details

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03
- Notes: PDF includes signatures and timestamps
