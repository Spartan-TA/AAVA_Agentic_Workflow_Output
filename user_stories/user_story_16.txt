Title: Audit Shift Assignments

User Story: As an auditor I want to review shift assignment history so that compliance and fairness can be ensured

Acceptance Criteria:
Scenario: Audit shift assignments
Given I have access to the audit log
When I filter by employee or date range
Then I should see all shift assignment changes with timestamps and user actions

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Audit log module, Scheduling module
- Notes: Exportable audit trail required.
