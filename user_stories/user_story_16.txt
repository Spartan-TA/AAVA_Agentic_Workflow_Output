Title: Export Attendance Reports

User Story: As a payroll specialist I want to export daily attendance reports in CSV format So that payroll processing is accurate and efficient

Acceptance Criteria:
Scenario: Export attendance report
Given attendance data exists for a date range
When I request a CSV export
Then the system generates a file with all relevant clock-in/out events and totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: Export should support filtering by department and shift group.
