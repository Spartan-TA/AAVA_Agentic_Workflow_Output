Title: Implement Role-Based Permissions

User Story: As a system administrator I want to configure role-based permissions So that users only access features relevant to their role

Acceptance Criteria:
Scenario: Role-based access enforced
Given a user with a specific role
When the user attempts to access a restricted feature
Then access is granted or denied based on their assigned permissions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User management, security module
- Notes: Support at least Admin, Manager, and Employee roles.
