Title: Request Leave

User Story: As an employee I want to request leave for vacation, sick days, or personal reasons So that my absence is recorded and approved in advance

Acceptance Criteria:
Scenario: Submitting a leave request
Given I am logged into the system
When I fill out and submit a leave request form
Then my supervisor should be notified for approval

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notification system, supervisor role
- Notes: Leave types should be configurable.
