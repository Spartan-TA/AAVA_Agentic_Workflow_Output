Title: Employee API Search by Badge ID
User Story: As an HR user I want to search for employees by badge ID via API So that I can quickly locate specific records
Acceptance Criteria:
Scenario: Search by Badge ID
Given employee records exist
When I GET /employees?badgeId=12345
Then only the matching employee is returned
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee CRUD API
- Notes: Support partial and exact matches
