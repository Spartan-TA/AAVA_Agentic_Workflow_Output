Title: Create Employee API Endpoint

User Story: As an HR user I want to create new employee records via an API So that employee onboarding is streamlined and consistent

Acceptance Criteria:
Scenario: Employee creation
Given valid employee data (name, badgeId, role, department, shiftGroup, hireDate, status)
When I POST to /employees
Then a new employee is created with a unique badgeId and the record is persisted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding (E01)
- Notes: Enforce unique badgeId and validate required fields
