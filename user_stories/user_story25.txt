Title: Certification Assignment Blocking

User Story: As an HR manager I want to block assignment of roles or tasks to employees lacking required certifications So that compliance and safety are ensured

Acceptance Criteria:
Scenario: Block assignment without certification
  Given an employee lacks a required certification
  When I attempt to assign a role or task
  Then the system should prevent the assignment and display an error
Scenario: Allow assignment with certification
  Given an employee has the required certification
  When I assign a role or task
  Then the assignment should proceed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification module, assignment engine
- Notes: Support for multiple certification requirements
