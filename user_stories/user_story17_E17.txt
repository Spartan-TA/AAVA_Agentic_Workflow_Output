### E17 - Onboarding & Offboarding Workflow

**Title:** Automated Onboarding from HRIS
User Story: As an HR user I want new hires provisioned automatically from HRIS So that onboarding is fast and accurate
Acceptance Criteria:
Scenario: New hire appears
Given new hire in HRIS
When EMS syncs
Then account, initial schedule, and training tasks are created
Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Reduces manual effort

---

**Title:** Training and Asset Assignment Tasks
User Story: As a supervisor I want onboarding tasks for training and asset assignment So that new hires are ready for work
Acceptance Criteria:
Scenario: Assign training
Given new hire
When onboarding starts
Then required training tasks are generated
Scenario: Assign assets
Given new hire
When onboarding starts
Then asset assignment tasks are generated
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Tasks visible to supervisors

---

**Title:** Automated Offboarding Workflow
User Story: As an HR user I want offboarding to revoke access and collect assets So that terminated employees are properly deprovisioned
Acceptance Criteria:
Scenario: Revoke access
Given terminated employee
When offboarding starts
Then system disables account
Scenario: Collect assets
Given terminated employee
When offboarding starts
Then asset return tasks are generated
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Updates schedules and training status

---

**Title:** Schedule Update on Offboarding
User Story: As a scheduler I want offboarding to update schedules So that shifts are reassigned
Acceptance Criteria:
Scenario: Remove from schedule
Given terminated employee
When offboarding completes
Then scheduled shifts are flagged for coverage
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Ensures no gaps in staffing
