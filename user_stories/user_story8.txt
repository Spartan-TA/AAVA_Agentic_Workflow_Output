Title: List and Filter Employees

User Story: As an HR Administrator I want to list and filter employees by department, role, and status So that I can quickly find relevant employee records for management and reporting

Acceptance Criteria:

Scenario: List employees with pagination
  Given multiple employee records exist
  When I request the employee list with pagination parameters
  Then I receive a paginated list of employees

Scenario: Filter employees by department and role
  Given employees in different departments and roles
  When I filter by department and/or role
  Then only matching employees are returned

Scenario: Filter by status (active/inactive)
  Given employees with different statuses
  When I filter by status
  Then only employees with the selected status are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Support query parameters for filtering; ensure performance for large datasets.
