Title: List and Filter Employee Records

User Story: As an HR user I want to list, filter, and paginate employee records So that I can efficiently search and manage large employee datasets

Acceptance Criteria:

Scenario: Paginated employee list
Given there are more than 20 employee records
When I request the employee list with pagination parameters
Then I should receive a paginated response with metadata (total, page, size)

Scenario: Filter by department and status
Given employee records exist with various departments and statuses
When I apply filters for department and status
Then only matching employee records should be returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Filtering and pagination must be supported in API and documented in OpenAPI schemas.
