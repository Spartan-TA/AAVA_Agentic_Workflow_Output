Title: Enforce Role-Based Endpoint Security

User Story:
As a system administrator, I want all API endpoints to enforce role-based access so that only authorized users can access sensitive data and operations.

Acceptance Criteria:
- Scenario: Unauthorized user attempts to access a protected endpoint
  Given a user is not authenticated
  When they call a protected API endpoint
  Then the response is 401 Unauthorized

- Scenario: User with insufficient role attempts forbidden action
  Given a user is authenticated as WORKER
  When they attempt to access an ADMIN-only endpoint
  Then the response is 403 Forbidden

- Scenario: ADMIN accesses all endpoints
  Given a user is authenticated as ADMIN
  When they access any endpoint
  Then the response is 200 OK

Additional Details:
- Endpoint security must be declarative (e.g., method-level annotations)
- Roles: ADMIN, HR, SUPERVISOR, WORKER
- Security rules must be covered by automated tests
