Title: Generate OpenAPI Schemas with Examples for Employee APIs

User Story: As a developer I want the employee APIs to be documented with OpenAPI schemas and examples so that integration and testing are simplified for all consumers.

Acceptance Criteria:
Scenario: OpenAPI documentation with examples
  Given the employee API endpoints are implemented
  When I view the OpenAPI documentation
  Then each endpoint should have a schema and example payloads for requests and responses

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints
- Notes: Ensure all fields (name, badgeId, role, department, shiftGroup, hireDate, status) are covered in the documentation.
