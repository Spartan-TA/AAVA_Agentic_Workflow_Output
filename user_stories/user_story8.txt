Title: Generate OpenAPI Schemas for Employee Endpoints

User Story: As a developer I want OpenAPI schemas with examples for all employee endpoints So that API consumers can easily understand and integrate with the employee APIs

Acceptance Criteria:

Scenario: OpenAPI documentation available
Given the application is running
When I access the OpenAPI documentation endpoint
Then I should see schemas for all employee CRUD endpoints with example requests and responses

Scenario: Schema matches implementation
Given the API implementation
When I compare the OpenAPI schema to actual requests and responses
Then all fields and types should match

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints (E02)
- Notes: Schemas must be kept up to date with code changes.
