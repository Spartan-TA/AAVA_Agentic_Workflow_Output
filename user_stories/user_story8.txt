Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to restrict API endpoints based on user roles So that sensitive operations are only accessible to authorized personnel

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without the required role
  When they attempt to access a restricted endpoint
  Then the system returns a 401 or 403 error

Scenario: Role-based permissions
  Given a user with the ADMIN role
  When they access management endpoints
  Then all operations are permitted

Scenario: Supervisor access
  Given a user with the SUPERVISOR role
  When they access team management endpoints
  Then only team-specific operations are permitted

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: user_story1.txt, user_story4.txt
- Notes: Security rules must be covered by automated tests.
