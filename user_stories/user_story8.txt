Title: Role-Based Access Control (RBAC) Setup

User Story: As a system administrator I want to configure roles and permissions So that sensitive operations are restricted to authorized users

Acceptance Criteria:
Scenario: Unauthorized Access
  Given a user without proper role
  When they access a restricted endpoint
  Then the API returns 401 Unauthorized

Scenario: Forbidden Action
  Given a user with insufficient permissions
  When they attempt a forbidden action
  Then the API returns 403 Forbidden

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: user_story1, user_story5
- Notes: Cover ADMIN, HR, SUPERVISOR, WORKER roles.
