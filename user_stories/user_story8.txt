Title: Employee List Pagination & Filtering

User Story: As an HR manager I want to view and filter employee records with pagination So that I can efficiently manage large numbers of employees

Acceptance Criteria:
Scenario: Filter and paginate employee list
Given a large set of employee records
When I apply filters and navigate pages
Then only matching records should be displayed and pagination controls should work as expected

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data (E02)
- Notes: Support filtering by department, status, and role.
