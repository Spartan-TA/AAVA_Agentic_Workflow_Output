Title: API Key/OAuth2 Security Toggle
User Story: As a system admin, I want to toggle between API key and OAuth2 authentication so that the system can adapt to different security requirements.
Acceptance Criteria:
  Given the config is set to API key,
  When requests are made with a valid key,
  Then access is granted.

  Given the config is set to OAuth2,
  When requests are made with a valid token,
  Then access is granted.

Additional Details:
  Priority: Medium
  Story Points: 3
  Dependencies: Role-Based Endpoint Security
  Notes: Configuration-driven.
