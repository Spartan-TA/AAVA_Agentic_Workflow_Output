Title: Employee Unique Badge ID Enforcement

User Story: As an HR administrator I want to enforce unique badge IDs for employees So that there are no duplicate badge assignments and access control remains secure

Acceptance Criteria:
Scenario: Add employee with badge ID
  Given I am adding a new employee
  When I enter a badge ID
  Then the system should validate that the badge ID is not already assigned
Scenario: Duplicate badge ID entry
  Given a badge ID is already assigned
  When I attempt to assign it to another employee
  Then the system should display an error and prevent saving

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation/edit API
- Notes: Badge ID uniqueness must be enforced at the database level
