Title: Row-Level Security for Supervisors

User Story: As a supervisor I want to access only my team's records so that I cannot view or modify other teams' data.

Acceptance Criteria:
Scenario: Supervisor access
Given a supervisor is logged in
When they access employee data
Then only their team's records are visible

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: RBAC Enforcement
- Notes: Row-level constraints.
