Title: Record Safety Incident
User Story: As a warehouse worker I want to record safety incidents or near-misses so that hazards are documented and addressed.
Acceptance Criteria:
Scenario: Incident Recording
Given I witness or experience a safety incident
When I submit an incident report with required details
Then the incident is recorded and validated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, Role-Based Access Control
- Notes: Capture severity, location, description, and involved employees.

Title: Manage Incident Investigation Workflow
User Story: As a safety officer I want to manage the investigation workflow for reported incidents so that corrective actions are tracked and completed.
Acceptance Criteria:
Scenario: Investigation Workflow
Given an incident is reported
When I change the status from Open to Investigating to Resolved
Then the workflow is tracked and corrective actions are logged
Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Record Safety Incident
- Notes: Status changes must be auditable.

Title: Export OSHA Summary Reports
User Story: As a compliance manager I want to export OSHA 300/300A summary reports so that regulatory requirements are met.
Acceptance Criteria:
Scenario: OSHA Report Export
Given incident data is available
When I request an OSHA summary export
Then the report is generated with required fields
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Manage Incident Investigation Workflow
- Notes: Include all relevant metrics and fields.

Title: Safety Metrics Dashboard
User Story: As a supervisor I want to view safety metrics on a dashboard so that I can monitor trends and improve safety culture.
Acceptance Criteria:
Scenario: Metrics Dashboard
Given safety incident data exists
When I access the dashboard endpoint
Then safety KPIs and incident statistics are displayed
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Record Safety Incident
- Notes: Dashboard should be role-based and filterable.
