Title: Implement Role-Based Access Control (RBAC)
User Story: As a system admin I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) to users So that access to sensitive operations is restricted appropriately.
Acceptance Criteria:
Scenario: Role assignment and enforcement
Given a user with SUPERVISOR role
When they access an ADMIN endpoint
Then they receive a 403 Forbidden error
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, Project scaffolding
- Notes: Roles must be configurable
