Title: Delete and Soft-Delete Employee Record API
User Story: As an HR manager I want to delete or soft-delete employee records via an API So that terminated employees are removed from active lists but historical data is preserved
Acceptance Criteria:
Scenario: Employee record deletion
  Given an existing employee record
  When I DELETE /employees/{id}
  Then the employee record is soft-deleted and excluded from active queries
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation API
- Notes: Soft-deleted records must be retrievable for audit purposes
