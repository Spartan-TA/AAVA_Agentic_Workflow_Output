Title: API Key/OAuth2 Security Toggle
User Story: As a system admin, I want to toggle between API key and OAuth2 authentication via config so that integration flexibility is maintained.
Acceptance Criteria:
Scenario: API key enabled
Given API key mode is configured
When a request includes a valid API key
Then access is granted

Scenario: OAuth2 enabled
Given OAuth2 mode is configured
When a request includes a valid OAuth2 token
Then access is granted

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: RBAC Setup
- Notes: Supports external integrations
