### E08 - Safety Incidents & OSHA Reporting

**Title:** Record Safety Incident
**User Story:** As a supervisor, I want to record safety incidents so that all events are tracked for compliance.
**Acceptance Criteria:**
Scenario: Incident recording
Given an incident occurs
When I POST to `/safety/incidents`
Then the incident is saved with all required fields
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Validate severity, location, involved employees.

**Title:** Incident Investigation Workflow
**User Story:** As a safety officer, I want to manage investigation workflows so that corrective actions are tracked.
**Acceptance Criteria:**
Scenario: Investigation status
Given an open incident
When I update status
Then the workflow moves from Open to Investigating to Resolved
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Audit all status changes.

**Title:** OSHA Summary Export
**User Story:** As a compliance manager, I want to export OSHA summary reports so that regulatory requirements are met.
**Acceptance Criteria:**
Scenario: OSHA export
Given incidents are recorded
When I export
Then OSHA 300/300A fields are included in the file
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Dashboard metrics available.
