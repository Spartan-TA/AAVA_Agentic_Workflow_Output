Title: Safety Incident Recording

User Story: As a safety officer I want to record incidents and near-misses with severity and location So that safety data is tracked and reported.

Acceptance Criteria:
Scenario: Incident recording workflow
Given an incident occurs
When I submit a report via POST /safety/incidents
Then the incident is logged with all required fields

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Status workflow (Open, Investigating, Resolved).

Acceptance Criteria:
Scenario: OSHA report generation

When I request an OSHA summary

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Metrics dashboard endpoints available.
