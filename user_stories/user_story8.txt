Title: Generate OpenAPI Schemas for Employee APIs

User Story:
As an API integrator,
I want the Employee APIs to have accurate and complete OpenAPI (Swagger) schemas,
So that I can easily understand, test, and integrate with the endpoints.

Acceptance Criteria:
- All Employee CRUD endpoints are documented in OpenAPI format.
- Request and response schemas include all fields, types, and validation rules.
- Example payloads are provided for each endpoint.
- OpenAPI docs are accessible via /swagger-ui or similar endpoint.
- Documentation is updated automatically with code changes.

Additional Details:
- Use annotations to generate OpenAPI docs.
- Include error response schemas and descriptions.
- Ensure docs are versioned and available in all environments.
