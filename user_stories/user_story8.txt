Title: Soft Delete Employee

User Story: As an HR administrator I want to soft-delete employee records So that I can retain historical data while removing inactive employees from active lists

Acceptance Criteria:
Scenario: Successful soft-delete Given an existing employee record When I send a DELETE request to /employees/{id} Then the employee status is updated to 'inactive' and the record is excluded from active queries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding (E01)
- Notes: Ensure soft-deleted employees are not returned in active lists but remain in the database
