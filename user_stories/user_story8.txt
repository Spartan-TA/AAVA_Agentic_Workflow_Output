Title: Employee Master Data (CRUD) - Employee Listing & Filtering

User Story: As an HR manager I want to list and filter employees by department, role, and status so that I can quickly find relevant records.

Acceptance Criteria:
Scenario: Filter employees
Given multiple employees exist
When I GET /employees with filter parameters
Then only matching employees are returned with pagination

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Creation
- Notes: Support pagination and OpenAPI schema.
