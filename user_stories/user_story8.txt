Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to restrict API endpoints based on user roles So that sensitive operations are only accessible to authorized users

Acceptance Criteria:
Scenario: Endpoint access control
Given a user with a specific role When they access a protected endpoint Then only permitted actions are allowed and unauthorized requests return 401/403

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding (E01), Employee domain (E02)
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER; security rules must be covered by tests
