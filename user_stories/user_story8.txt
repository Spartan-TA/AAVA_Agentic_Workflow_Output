Title: Define User Roles and Permissions

User Story: As an admin I want to define user roles and assign permissions so that access to system features is controlled and secure

Acceptance Criteria:
Scenario: Role creation and permission assignment
Given I am logged in as an admin
When I navigate to the RBAC settings and create a new role with selected permissions
Then the role should be saved and available for assignment to users

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: User management module
- Notes: Roles should support granular permissions for all major modules.
