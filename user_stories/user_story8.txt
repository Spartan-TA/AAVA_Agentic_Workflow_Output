### Epic E07: Training & Certification Tracking

**User Story 1: Track Employee Certifications**
- Title: Track Employee Certifications
- User Story: As an HR user, I want to record employee certifications and expirations so that compliance is maintained.
- Acceptance Criteria:
  ```
  Given HR is authenticated,
  When they add a certification,
  Then the certification and expiry date are recorded for the employee.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Forklift, PPE, etc.

**User Story 2: Alert on Expiring Certifications**
- Title: Certification Expiry Alerts
- User Story: As a Supervisor, I want to receive alerts for certifications expiring in 30/7 days so that renewals are managed.
- Acceptance Criteria:
  ```
  Given a certification is expiring soon,
  When the system checks expiry dates,
  Then an alert is sent to the supervisor and employee.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Automated notifications.

**User Story 3: Block Assignment for Expired Certifications**
- Title: Block Assignment to Unqualified Employees
- User Story: As a Scheduler, I want to prevent assignment of tasks to employees with expired certifications so that safety is ensured.
- Acceptance Criteria:
  ```
  Given an employee's certification is expired,
  When a task requiring certification is assigned,
  Then the assignment is blocked and a warning is shown.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Scheduling checks.

**User Story 4: Upload Certification Documents**
- Title: Upload Proof of Certification
- User Story: As an HR user, I want to upload proof documents for certifications so that records are verifiable.
- Acceptance Criteria:
  ```
  Given HR is authenticated,
  When they upload a document,
  Then the document is stored and linked to the certification record.
  ```
- Additional Details: Priority: High, Story Points: 1, Dependencies: E02, E03, Notes: Document storage.

**User Story 5: Certification Status on Employee Profile**
- Title: Display Certification Status on Profile
- User Story: As a Supervisor, I want to view certification status on employee profiles so that I can quickly check qualifications.
- Acceptance Criteria:
  ```
  Given a supervisor views an employee profile,
  When the profile loads,
  Then certification status and expiry dates are displayed.
  ```
- Additional Details: Priority: High, Story Points: 1, Dependencies: E02, E03, Notes: Profile UI.

### Epic E08: Safety Incidents & OSHA Reporting

**User Story 1: Record Safety Incident**
- Title: Record Safety Incident
- User Story: As a Supervisor, I want to record safety incidents with severity, location, and involved employees so that regulatory requirements are met.
- Acceptance Criteria:
  ```
  Given a SUPERVISOR is authenticated,
  When they POST to /safety/incidents with valid data,
  Then the incident is recorded and validated.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: OSHA fields required.

**User Story 2: Incident Investigation Workflow**
- Title: Investigate Safety Incident
- User Story: As a Safety Officer, I want to manage the investigation workflow for incidents so that corrective actions are tracked.
- Acceptance Criteria:
  ```
  Given an incident is recorded,
  When the status changes from Open to Investigating to Resolved,
  Then each transition is logged and corrective actions are documented.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Status workflow.

**User Story 3: OSHA Summary Export**
- Title: Export OSHA Summary Reports
- User Story: As a Compliance Officer, I want to export OSHA 300/300A summary reports so that regulatory filings are accurate.
- Acceptance Criteria:
  ```
  Given safety incident data exists,
  When OSHA summary is requested,
  Then a report is generated with required fields.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Export format.

**User Story 4: Safety Metrics Dashboard**
- Title: Safety Metrics Dashboard Endpoints
- User Story: As a Safety Officer, I want dashboard endpoints for safety KPIs so that I can monitor trends.
- Acceptance Criteria:
  ```
  Given safety data exists,
  When dashboard endpoints are accessed,
  Then metrics such as incident rate and severity are returned.
  ```
- Additional Details: Priority: High, Story Points: 1, Dependencies: E02, E03, Notes: API endpoints.
