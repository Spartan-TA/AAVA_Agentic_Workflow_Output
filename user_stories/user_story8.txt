Title: Retrieve Employee Records with Pagination and Filtering

User Story: As an HR manager I want to retrieve employee records with pagination and filtering So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Employee data retrieval
Given multiple employee records exist
When I send a GET request to /employees with pagination and filter parameters
Then the response should include only the matching records and support pagination

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API (E02)
- Notes: Filters must support department, role, status; pagination must be configurable; OpenAPI schema must include examples
