Title: Create Performance Review Templates

User Story: As an HR manager I want to create quarterly and annual performance review templates So that supervisors can conduct consistent and structured evaluations

Acceptance Criteria:
Scenario: Create review template
Given I am logged in as an HR manager
When I create or edit a performance review template
Then the template should be available for supervisors to use in employee reviews

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02 (Employee Profiles), E03 (Scheduling)
- Notes: Templates should support customizable competencies, goals, and rating scales.
