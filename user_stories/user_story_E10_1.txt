Title: Create Quarterly/Annual Review Templates

User Story: As an HR manager I want to create standardized quarterly and annual performance review templates so that supervisors can consistently evaluate employees across the organization.

Acceptance Criteria:
Scenario: Template creation
Given I am logged in as an HR manager
When I navigate to the performance review section and select 'Create Template'
Then I should be able to define review periods, competencies, rating scales, and save the template for future use

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Employee Master Data (E02), RBAC (E03)
- Notes: Templates must be immutable after sign-off and support PDF export.
