Title: Submit Leave Request

User Story: As an EMPLOYEE I want to submit a leave request So that I can formally notify my supervisor of planned absences

Acceptance Criteria:

Scenario: Employee submits leave request
Given I am logged in as EMPLOYEE
When I fill out the leave request form
Then my supervisor is notified for approval

Scenario: Leave request validation
Given I have submitted a request
When my leave balance is checked
Then I am notified if I do not have enough leave

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Leave types should be configurable (vacation, sick, etc.).
