Title: Overtime Rules and Shift Rotation Management

User Story:
As a scheduling manager, I want to configure overtime rules and manage shift rotations so that staffing is fair and compliant with labor policies.

Acceptance Criteria:
- Scenario: Overtime rule configuration
  Given the manager defines overtime thresholds
  When shifts are assigned exceeding those thresholds
  Then overtime is flagged and reported

- Scenario: Shift rotation assignment
  Given a rotation pattern is configured
  When shifts are generated
  Then employees are assigned according to the rotation

Additional Details:
- Overtime rules must be flexible per department/site
- Rotation patterns must support weekly/monthly cycles
- All overtime and rotation assignments must be auditable
