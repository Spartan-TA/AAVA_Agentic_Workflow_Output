Title: Audit Trail Logging
User Story: As a compliance officer, I want all sensitive changes logged with actor, timestamp, and before/after so that audits are possible.
Acceptance Criteria:
  Given a create/update/delete,
  When performed,
  Then an immutable log entry is created.

  Given an audit request,
  When I filter by date/user/entity,
  Then matching logs are exported.

Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: RBAC
  Notes: Tamper-evident storage.
