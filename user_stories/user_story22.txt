Title: Audit Trail for Sensitive Changes

User Story: As a compliance officer, I want centralized audit logging for sensitive changes so that all actions are traceable and tamper-evident.

Acceptance Criteria:
Scenario: Audit log creation
Given a create/update/delete action occurs
When the action is processed
Then the actor, timestamp, and before/after state are logged immutably
And logs can be exported by date, user, or entity

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: RBAC
- Notes: Automated tests must validate coverage.
