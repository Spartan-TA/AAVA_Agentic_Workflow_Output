Title: Generate Operational Reports (Attendance, Overtime, Leave)

User Story: As a manager I want to generate operational reports for attendance, overtime, and leave balances so that I can make data-driven staffing decisions

Acceptance Criteria:
Scenario: Generating a report
Given I have access to reporting tools
When I select the desired report and filters
Then I receive a report with the requested data in under 10 seconds for up to 50k rows

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Attendance, Leave, Overtime data
- Notes: Export formats CSV and PDF
