Title: Onboarding & Offboarding Workflow
User Story: As an HR user I want onboarding to provision accounts, schedule, and training tasks automatically So that new hires are productive quickly
Acceptance Criteria:
Scenario: New hire onboarding
Given a new employee appears from HRIS
When onboarding runs
Then account, schedule, and training tasks are created

Scenario: Offboarding
Given an employee is terminated
When offboarding runs
Then access is revoked, assets collected, and schedules updated

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: Employee CRUD API, RBAC, Schedule Management, Certification Tracking, Asset Assignment, Integration Layer
- Notes: Automated task generation; audit all actions.
