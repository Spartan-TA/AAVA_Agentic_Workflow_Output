Title: Performance Review Cycle Management

User Story: As an HR manager I want to create and manage performance review cycles So that employee feedback and goals are tracked

Acceptance Criteria:

Scenario: Create review cycle
Given valid review parameters
When I create a new cycle
Then it is available for assignment to employees

Scenario: Assign review to employee
Given a review cycle exists
When I assign it to an employee
Then the employee can submit self-review

Scenario: Supervisor/employee acknowledgement
Given a review is completed
When both parties acknowledge
Then the review is locked and history is immutable

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: Employee CRUD APIs, RBAC
- Notes: PDF export; role-based visibility
