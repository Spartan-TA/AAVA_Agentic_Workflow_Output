Title: Update Employee Record

User Story: As an HR administrator I want to update an employee's details So that changes in role, department, or status are reflected in the system

Acceptance Criteria:
Scenario: Successful employee update
Given I am viewing an employee's profile
When I edit and save changes to their information
Then the updated details should be stored and visible in the employee list

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding & Domain Setup (E01)
- Notes: Track changes for audit purposes.
