Title: Equipment & Asset Assignment - Asset Checkout/Return

User Story: As an employee, I want to check out and return equipment so that asset usage is tracked.

Acceptance Criteria:
Scenario: Asset Checkout
Given valid certification
When I POST /assets/checkout
Then asset is assigned to employee

Scenario: Asset Return
Given an assigned asset
When I POST /assets/return
Then asset is returned and history logged

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Blocks when certs invalid; overdue reports
