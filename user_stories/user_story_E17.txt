### E17 - Onboarding & Offboarding Workflow

**User Story 1**
Title: Automate New Hire Provisioning
User Story: As an HR user, I want new hires from HRIS to trigger account, schedule, and training setup so that onboarding is seamless.
Acceptance Criteria:
Scenario: New hire onboarding
Given a new hire in HRIS
When the sync job runs
Then an EMS account, initial schedule, and required training tasks are created
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Notify supervisor of pending tasks.

**User Story 2**
Title: Automate Offboarding Tasks
User Story: As an HR user, I want terminations to trigger access revocation, asset collection, and schedule updates so that offboarding is complete.
Acceptance Criteria:
Scenario: Offboarding workflow
Given a terminated employee
When offboarding is triggered
Then access is revoked, assets are collected, and schedules are updated
Priority: Medium
Story Points: 3
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Track completion of all offboarding steps.

**User Story 3**
Title: Track Onboarding/Offboarding Task Completion
User Story: As a supervisor, I want to track the status of onboarding and offboarding tasks so that nothing is missed.
Acceptance Criteria:
Scenario: Task tracking
Given onboarding/offboarding tasks
When I view the workflow
Then I see status for each required task
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Send reminders for overdue tasks.
