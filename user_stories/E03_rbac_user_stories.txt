### EPIC E03: Role-Based Access Control (RBAC)

**User Story 11**
Title: Add Spring Security with Roles  
User Story: As a developer I want to add Spring Security with roles (ADMIN, HR, SUPERVISOR, WORKER) So that access is controlled  
Acceptance Criteria:  
Scenario: Role Setup  
Given the project is running  
When I configure roles  
Then endpoints are protected based on user role  
Additional Details:  
- Priority: High  
- Story Points: 2  
- Dependencies: E01, E02  
- Notes: Document role permissions

**User Story 12**
Title: Implement Method and Endpoint Security  
User Story: As a developer I want to secure methods and endpoints So that sensitive operations are restricted  
Acceptance Criteria:  
Scenario: Endpoint Security  
Given roles are configured  
When I access a protected endpoint  
Then unauthorized requests return 401, forbidden actions return 403  
Additional Details:  
- Priority: High  
- Story Points: 2  
- Dependencies: User Story 11  
- Notes: Cover security rules with tests
