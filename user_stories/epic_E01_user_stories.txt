E01 - PROJECT SCAFFOLDING & DOMAIN SETUP USER STORIES

Title: Initialize Spring Boot Project Structure
User Story: As a developer, I want to initialize a Spring Boot project with Maven and configure base packages so that all modules have a standardized foundation for development.
Acceptance Criteria:
Scenario: Project Initialization
Given a new repository
When I run the build and start the application
Then the application runs on port 8080 and the README contains build/run steps
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure base package structure is created for employee, scheduling, attendance, safety modules.
