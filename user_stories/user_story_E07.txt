### E07 - Training & Certification Tracking

**User Story 1**
- Title: CRUD for Certifications
- User Story: As an HR user, I want to create, update, and delete certifications for employees so that training records are maintained.
- Acceptance Criteria:
  - Given the certification API is available,
    When I create/update/delete a certification,
    Then the record is persisted and visible on the employee profile.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Compliance tracking.

**User Story 2**
- Title: Alert for Expiring Certifications
- User Story: As a supervisor, I want alerts 30/7 days before certification expiry so that renewals are timely.
- Acceptance Criteria:
  - Given a certification is expiring,
    When the alert window is reached,
    Then notifications are sent to the employee and supervisor.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Safety compliance.

**User Story 3**
- Title: Block Assignment to Tasks Requiring Expired Certs
- User Story: As a scheduler, I want assignments blocked if certifications are expired so that only qualified staff are assigned.
- Acceptance Criteria:
  - Given a task requires certification,
    When the employee's cert is expired,
    Then assignment is blocked and an error is shown.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Safety enforcement.

**User Story 4**
- Title: Upload Proof Documents for Certifications
- User Story: As an employee, I want to upload proof documents for certifications so that records are verifiable.
- Acceptance Criteria:
  - Given a certification is added,
    When I upload a document,
    Then it is stored and linked to the certification.
- Additional Details: Priority: High, Story Points: 1, Dependencies: E02, E03, Notes: Document management.

**User Story 5**
- Title: Display Certification Status on Employee Profile
- User Story: As a supervisor, I want to see certification status on employee profiles so that I can verify qualifications.
- Acceptance Criteria:
  - Given I view an employee profile,
    When certifications exist,
    Then their status (valid/expiring/expired) is displayed.
- Additional Details: Priority: High, Story Points: 1, Dependencies: E02, E03, Notes: Visibility.
