### E07 - Training & Certification Tracking

#### User Story 1
Title: Track Employee Certifications
User Story: As an HR, I want to track required certifications and expirations so that compliance is maintained.
Acceptance Criteria:
Scenario: Certification Tracking
Given employee records
When HR adds certifications
Then expiration dates and alerts are set
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Alerts 30/7 days before expiry

#### User Story 2
Title: Block Assignment to Expired Certifications
User Story: As a SUPERVISOR, I want to prevent assignment to tasks requiring expired certifications so that only qualified staff are assigned.
Acceptance Criteria:
Scenario: Assignment Block
Given an expired certification
When SUPERVISOR assigns a task
Then assignment is blocked
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Scheduling checks required

#### User Story 3
Title: Upload Proof of Certification
User Story: As a WORKER, I want to upload proof documents for certifications so that records are complete.
Acceptance Criteria:
Scenario: Proof Upload
Given a certification
When WORKER uploads a document
Then it is attached to their profile
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Document storage required

#### User Story 4
Title: Certification Status Visibility
User Story: As a SUPERVISOR, I want to view certification status on employee profiles so that I can verify qualifications.
Acceptance Criteria:
Scenario: Status Viewing
Given employee profiles
When SUPERVISOR views
Then certification status is visible
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Status must be clear
