EPIC E07 - TRAINING & CERTIFICATION TRACKING

===========================================
User Story 1
===========================================

Title: Track Employee Certifications

User Story: As an HR user I want to record and track employee certifications So that compliance is maintained

Acceptance Criteria:
Scenario: Certification CRUD
Given an employee
When I add/edit/delete a certification
Then the certification status is updated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Certification types configurable

===========================================
User Story 2
===========================================

Title: Alert for Expiring Certifications

User Story: As a supervisor I want to receive alerts for certifications expiring soon So that renewals are not missed

Acceptance Criteria:
Scenario: Expiry alert
Given a certification expiring in 30 or 7 days
When the date approaches
Then an alert is sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E07
- Notes: Notification channel configurable

===========================================
User Story 3
===========================================

Title: Block Assignment to Tasks Requiring Valid Certification

User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that safety is ensured

Acceptance Criteria:
Scenario: Assignment block
Given an expired certification
When I try to assign a restricted task
Then the system blocks the assignment

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E07
- Notes: Applies to equipment-sensitive roles

===========================================
User Story 4
===========================================

Title: Upload Proof Documents for Certifications

User Story: As an employee I want to upload proof of certification So that my records are complete

Acceptance Criteria:
Scenario: Proof upload
Given a valid certification
When I upload a document
Then it is stored and linked to my profile

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E07
- Notes: File type restrictions enforced
