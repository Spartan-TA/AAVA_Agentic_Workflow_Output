### E07: Training & Certification Tracking

**User Story 1**
- Title: Manage Employee Certifications
- User Story: As an HR user, I want to CRUD certifications for employees so that qualifications are tracked.
- Acceptance Criteria:
    - Given the certification API,
      When I create, update, or delete a certification,
      Then the employee's profile reflects the change.
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: For compliance.

**User Story 2**
- Title: Alert on Certification Expiry
- User Story: As a supervisor, I want alerts for certifications expiring in 30/7 days so that renewals are timely.
- Acceptance Criteria:
    - Given an expiring certification,
      When 30 or 7 days remain,
      Then an alert is sent to the employee and supervisor.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: For safety.

**User Story 3**
- Title: Block Assignments for Expired Certifications
- User Story: As a scheduler, I want to block task assignments if required certifications are expired so that only qualified staff are assigned.
- Acceptance Criteria:
    - Given an expired certification,
      When I assign a task requiring it,
      Then the system prevents the assignment.
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: For compliance.

**User Story 4**
- Title: Upload Proof of Certification
- User Story: As an employee, I want to upload proof documents for certifications so that compliance is documented.
- Acceptance Criteria:
    - Given a certification,
      When I upload a document,
      Then it is stored and visible on my profile.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: For audit.

**User Story 5**
- Title: Display Certification Status on Profile
- User Story: As a supervisor, I want to view certification status on employee profiles so that I can verify qualifications.
- Acceptance Criteria:
    - Given an employee profile,
      When I view it,
      Then all certifications and their status are displayed.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: For visibility.
