### E07: Training & Certification Tracking

#### User Story 1
Title: Manage Employee Certifications
User Story: As an HR admin, I want to create, update, and delete employee certifications so that records are accurate and up-to-date.
Acceptance Criteria:
Scenario: Add certification
  Given I am an HR admin
  When I add a certification to an employee
  Then it is visible on their profile with type, issue date, and expiry
Scenario: Delete certification
  Given a certification is deleted
  When it is removed
  Then it no longer appears in scheduling or compliance checks
Additional Details:
Priority: High
Story Points: 5
Dependencies: E02, E03
Notes: Certification types should be configurable.

#### User Story 2
Title: Certification Expiry Notifications
User Story: As an employee or supervisor, I want to receive alerts before a certification expires so that renewals can be completed on time.
Acceptance Criteria:
Scenario: Expiry alert
  Given a certification is expiring in 30 or 7 days
  When the system runs the daily check
  Then an alert is sent to the employee and supervisor
Additional Details:
Priority: High
Story Points: 3
Dependencies: E12
Notes: Alerts should be configurable by type and channel.

#### User Story 3
Title: Block Assignment to Tasks Requiring Valid Certification
User Story: As a scheduler, I want to prevent assignment of employees with expired certifications to restricted tasks so that compliance is maintained.
Acceptance Criteria:
Scenario: Block expired certification
  Given an employee's certification is expired
  When I attempt to assign them to a restricted shift
  Then the system blocks the assignment and displays a warning
Additional Details:
Priority: High
Story Points: 5
Dependencies: E05
Notes: Block logic must be enforced in both UI and API.

#### User Story 4
Title: Certification Document Upload
User Story: As an employee or HR admin, I want to upload proof of certification so that records are verifiable.
Acceptance Criteria:
Scenario: Document upload
  Given I have a valid certification document
  When I upload it to the system
  Then it is stored securely and linked to the certification record
Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E02
Notes: Support PDF, JPG, PNG formats.
