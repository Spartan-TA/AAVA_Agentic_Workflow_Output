Title: Assign Roles to Users

User Story: As an admin I want to assign roles to users So that I can ensure appropriate access levels across the organization

Acceptance Criteria:
Scenario: Role assignment
Given I am logged in as an admin
When I select a user and assign a role
Then the user should inherit the permissions associated with that role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role definition
- Notes: Role changes should be auditable
