Title: Support API Key and OAuth2 Security Toggle

User Story: As a system administrator I want to configure the system to use either API key or OAuth2 authentication So that I can adapt security to organizational requirements

Acceptance Criteria:
Scenario: API key authentication
Given the system is configured for API key
When a request is made with a valid key
Then the request is authorized

Scenario: OAuth2 authentication
Given the system is configured for OAuth2
When a request is made with a valid token
Then the request is authorized

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding, Employee CRUD
- Notes: Configuration must be documented and tested
