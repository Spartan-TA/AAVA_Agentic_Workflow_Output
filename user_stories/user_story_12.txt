Title: Automated Security Tests for Role Enforcement

User Story: As a QA engineer I want automated tests that verify role-based access restrictions So that unauthorized actions are reliably blocked and compliance is maintained

Acceptance Criteria:
Scenario: Test unauthorized access
Given a test user with limited permissions
When the test attempts to perform admin-only actions
Then the system returns 403 and logs the attempt

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: All RBAC implementation stories
- Notes: Tests must cover all critical endpoints and roles.
