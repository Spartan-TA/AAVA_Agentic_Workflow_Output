Title: Assign Roles to Users

User Story: As an administrator I want to assign roles to users So that I can ensure each user has appropriate access rights

Acceptance Criteria:
Scenario: Assigning a role
  Given a user exists in the system
  When I select a user and assign a role
  Then the user should inherit the permissions associated with that role
Scenario: Changing a user's role
  Given a user already has a role
  When I change the user's role
  Then the user's permissions should be updated accordingly

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role management
- Notes: Changes to roles should be logged for audit purposes.
