Title: Attendance Report Export

User Story: As a manager I want to export attendance reports so that I can analyze and share attendance data externally

Acceptance Criteria:
Scenario: Export attendance report
Given I am on the attendance report page
When I select a date range and export format
Then the report should be generated and downloaded in the selected format

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Reporting module
- Notes: Support CSV and PDF export formats.
