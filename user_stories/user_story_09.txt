Title: Implement Delete Employee API Endpoint

User Story: As an HR manager I want to delete employee records via REST API so that I can remove employees who have left the organization.

Acceptance Criteria:

Scenario: Soft delete employee
Given an employee with ID 123 exists and is active
When I DELETE /api/v1/employees/123
Then I should receive a 204 No Content response
And the employee status should be updated to DELETED or INACTIVE
And the deletedAt timestamp should be set
And the deletedBy field should reflect the current user
And the employee should not appear in default queries

Scenario: Delete non-existent employee
Given no employee with ID 999 exists
When I DELETE /api/v1/employees/999
Then I should receive a 404 Not Found response

Scenario: Prevent deletion of employee with active assignments
Given an employee with ID 123 has active shift assignments
When I DELETE /api/v1/employees/123
Then I should receive a 409 Conflict response
And the error message should indicate active assignments exist

Scenario: Retrieve deleted employees
Given an employee was soft-deleted
When I GET /api/v1/employees?includeDeleted=true
Then the deleted employee should be included in results
And the status should show as DELETED

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee entity (E02), CRUD APIs (E02)
- Notes: Implement soft delete only. Never physically delete employee records for audit purposes. Check for dependencies before deletion.
