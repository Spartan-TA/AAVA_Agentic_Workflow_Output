Title: Role-Based Access to Reports and Dashboards

User Story: As a department manager I want access to reports and dashboards to be restricted based on user roles So that sensitive data is only visible to authorized personnel

Acceptance Criteria:
Scenario: Role-based report access
Given multiple user roles exist in the system
When a user accesses the reporting dashboard
Then they can only view reports and data permitted by their role

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Access rules must be covered by automated tests.
