EPIC E01: Project Scaffolding & Domain Setup

---

User Story 1

Title: Initialize Spring Boot Project Structure

User Story: As a developer, I want a standardized Spring Boot project structure so that all modules follow consistent conventions and are easy to maintain.

Acceptance Criteria:

Scenario: Successful project build and startup
Given the repository is cloned
When I run `mvn clean install`
Then the project builds successfully and runs on port 8080

Scenario: Health endpoint verification
Given the project is running
When I access `/actuator/health`
Then I receive a status of "UP"

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Base for all other modules.

---

User Story 2

Title: Configure Database Migrations with Flyway/Liquibase

User Story: As a developer, I want automated database migrations so that schema changes are versioned and repeatable.

Acceptance Criteria:

Scenario: Baseline migration on startup
Given the application starts
When Flyway/Liquibase is enabled
Then the baseline migration is applied automatically

Scenario: New migration application
Given a new migration is added
When I run the app
Then the migration is applied without manual intervention

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Supports future DB changes.
