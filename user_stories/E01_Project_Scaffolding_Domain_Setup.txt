### E01: Project Scaffolding & Domain Setup

**Epic Description:**
Initialize Spring Boot (Maven) project; configure base packages; set up core modules (employee, scheduling, attendance, safety); add Flyway/Liquibase for DB migrations; enable Actuator.

---

**User Story 1: Project Initialization and Build**

Title: Initialize Spring Boot Project with Maven

User Story: As a developer, I want to initialize a Spring Boot project with Maven so that I have a standardized foundation for all modules.

Acceptance Criteria:

Scenario: Project builds and runs on port 8080
  Given the project is cloned from the repository
  When I run 'mvn spring-boot:run'
  Then the application starts successfully on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build and run steps.

---

**User Story 2: Core Module Setup**

Title: Configure Base Packages and Core Modules

User Story: As a developer, I want to set up base packages and core modules (employee, scheduling, attendance, safety) so that the codebase is organized and modular.

Acceptance Criteria:

Scenario: Base package structure is created
  Given the project is initialized
  When I inspect the source code
  Then I see separate packages for employee, scheduling, attendance, and safety modules

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Initialization
- Notes: Follow standard naming conventions.

---

**User Story 3: Database Migration Tool Integration**

Title: Integrate Flyway/Liquibase for DB Migrations

User Story: As a developer, I want to add Flyway or Liquibase to manage database migrations so that schema changes are versioned and repeatable.

Acceptance Criteria:

Scenario: Baseline migration runs on startup
  Given the application starts for the first time
  When Flyway/Liquibase executes
  Then the baseline migration is applied to the database without errors

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Initialization
- Notes: Use a sample migration for initial setup.

**User Story 4: Health Monitoring**

Title: Enable Spring Boot Actuator Health Endpoint

  Then the response status is 200 and the body contains "status":"UP"
