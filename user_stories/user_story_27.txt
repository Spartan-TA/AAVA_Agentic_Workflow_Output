Title: Request Leave

User Story: As an employee I want to request leave So that I can take time off as needed and have my absence recorded

Acceptance Criteria:
Scenario: Leave request submission
Given I am logged in as an employee
When I submit a leave request
Then my manager should be notified and able to approve or reject the request

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave policy, notifications
- Notes: Support for multiple leave types
