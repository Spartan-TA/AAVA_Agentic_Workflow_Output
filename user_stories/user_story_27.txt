Title: Block Assignment for Expired Certifications

User Story: As a scheduler I want the system to prevent assignment of employees to tasks requiring certifications if their certification is expired so that safety and compliance are enforced

Acceptance Criteria:
Scenario: Assignment blocked for expired cert
  Given an employee's required certification is expired
  When I attempt to assign them to a restricted task
  Then the system blocks the assignment and displays a warning

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02 (User Management), E03 (Scheduling)
- Notes: Block must be enforced for all certification-dependent tasks
