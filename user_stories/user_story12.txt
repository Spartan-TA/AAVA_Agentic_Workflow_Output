Title: HR Role Permissions for Employee Data

User Story:
As an HR user, I want to manage employee records (excluding payroll and admin-only fields) so that I can perform HR functions without overreaching access.

Acceptance Criteria:
- Scenario: HR updates employee profile
  Given a user is authenticated as HR
  When they update non-admin employee fields
  Then the update is successful

- Scenario: HR attempts to access admin-only fields
  Given a user is authenticated as HR
  When they attempt to update or view admin-only fields
  Then the response is 403 Forbidden

Additional Details:
- HR role must be able to CRUD employee data except for admin-only fields (e.g., system settings)
- Field-level security must be enforced in both API and UI
- Automated tests must validate HR permissions
