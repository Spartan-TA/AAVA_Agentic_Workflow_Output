Title: Security Test Coverage

User Story: As a QA Engineer I want automated tests for all security rules and role-based access controls So that unauthorized access and privilege escalation are prevented

Acceptance Criteria:

Scenario: Unauthorized access test
  Given a user without authentication
  When they attempt to access a protected endpoint
  Then the test verifies a 401 Unauthorized response

Scenario: Role-based access test
  Given users with different roles
  When they attempt to perform restricted operations
  Then the test verifies correct 403 Forbidden or permitted responses

Scenario: Row-level security test
  Given a SUPERVISOR user
  When they access team data
  Then the test verifies only their team's records are returned

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Use unit and integration tests; cover all endpoints and roles; include negative test cases.
