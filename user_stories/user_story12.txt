Title: Missed Punch Correction Workflow

User Story: As a supervisor I want to approve corrections for missed punches so that attendance data is accurate.

Acceptance Criteria:
Scenario: Correction request
Given a missed punch is reported
When a correction is submitted
Then an approval task is created and processed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock-In/Out
- Notes: Approval workflow.
