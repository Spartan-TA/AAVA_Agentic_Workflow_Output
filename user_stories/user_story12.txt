Title: Attendance Correction Workflow

User Story: As a worker, I want to request corrections for missed punches so that my attendance record is accurate.

Acceptance Criteria:

Scenario: Submit correction request
Given a missed punch
When I submit a correction
Then an approval task is created for my supervisor

Scenario: Supervisor reviews correction
Given a supervisor
When reviewing corrections
Then they can approve or reject with comments

Scenario: Approved correction updates totals
Given an approved correction
When processed
Then attendance totals update

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04
- Notes: Approval workflow
