Title: WORKER Role Endpoint Security

User Story: As a WORKER I want to access only my own profile and attendance records So that my privacy is protected and I cannot view or modify other employees' data

Acceptance Criteria:

Scenario: WORKER can access own data
Given I am authenticated as a WORKER
When I access my profile or attendance endpoints
Then I should see only my own information

Scenario: WORKER cannot access other employees' data
Given I am authenticated as a WORKER
When I attempt to access another employee's profile or attendance
Then access should be denied with a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain (E02), RBAC setup (E03)
- Notes: Endpoint security must be enforced for all sensitive data.
