Title: Set Up Spring Security Roles

User Story: As a system administrator I want to configure roles (ADMIN, HR, SUPERVISOR, WORKER) in Spring Security So that access to sensitive operations is restricted

Acceptance Criteria:
Scenario: Role configuration
Given Spring Security is enabled
When I assign roles to users
Then each user has access only to permitted endpoints and actions

Scenario: Unauthorized access
Given a user without required role
When they access a restricted endpoint
Then they receive a 401 Unauthorized response

- Priority: High
- Story Points: 3
- Dependencies: user_story1.txt, user_story6.txt
- Notes: Document role matrix and permissions
