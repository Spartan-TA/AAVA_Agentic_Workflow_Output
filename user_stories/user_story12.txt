Title: Track Employee Certifications

User Story: As an HR manager I want to track employee certifications and expirations so that compliance is maintained

Acceptance Criteria:
Scenario: Adding a certification
Given I am managing an employee profile
When I add a certification with an expiry date
Then the certification should be tracked and alerts generated before expiry

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Alerts 30/7 days before expiry

Title: Block Assignment to Expired Certifications

User Story: As a supervisor I want to prevent assignment of tasks to employees with expired certifications so that safety is ensured

Acceptance Criteria:
Scenario: Assignment check
Given an employee's certification is expired
When I attempt to assign them to a restricted task
Then the system should block the assignment and notify me

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Certification Tracking, Scheduling
- Notes: Certification status visible on profile

Title: Upload Proof of Certification

User Story: As an employee I want to upload proof documents for certifications so that my qualifications are validated

Acceptance Criteria:
Scenario: Uploading proof
Given I have a valid certification
When I upload a document
Then the document should be stored and linked to my profile

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Certification Tracking
- Notes: Document management integration
