Title: Shift Template Management
User Story: As an HR manager, I want to create and manage recurring shift templates so that scheduling is efficient and consistent.
Acceptance Criteria:
Scenario: Create shift template
Given valid shift details
When I POST to /shifts/templates
Then a new template is created

Scenario: Edit shift template
Given a template exists
When I PUT/PATCH /shifts/templates/{id}
Then the template is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC, Attendance
- Notes: Supports rotations and overtime rules
