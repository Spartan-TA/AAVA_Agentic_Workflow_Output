Title: Supervisor Approve Attendance Exceptions

User Story: As a supervisor I want to review and approve or reject attendance exceptions so that time records are accurate and policy-compliant

Acceptance Criteria:
Scenario: Approving an attendance exception
Given an employee has submitted an exception request (missed clock in/out)
When I review the request and select approve or reject
Then the employee's attendance record is updated accordingly and the employee is notified

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notification module, attendance records
- Notes: All actions should be logged for audit purposes.
