Title: Attendance Correction Workflow

User Story: As an employee I want to request corrections to my attendance records So that errors in clock in/out times can be resolved

Acceptance Criteria:
Scenario: Correction request submission
Given an attendance record with an error
When I submit a correction request
Then the request should be routed to my supervisor for review

Scenario: Supervisor approval
Given a pending correction request
When my supervisor approves it
Then the attendance record should be updated accordingly

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: Clock In/Out Endpoint
- Notes: Track correction history for audit purposes.
