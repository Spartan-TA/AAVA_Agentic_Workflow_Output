Title: Role-Based Access Control (RBAC) - API Key/OAuth2 Toggle

User Story: As a system admin I want to toggle between API key and OAuth2 authentication so that integration security can be configured per environment.

Acceptance Criteria:
Scenario: Auth method toggle
Given the configuration is set
When the application starts
Then the selected auth method is enforced

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role Assignment
- Notes: Document configuration options.
