Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all sensitive changes to employee PII, schedules, approvals, and payroll to be logged centrally So that we maintain regulatory compliance and can trace all actions

Acceptance Criteria:
Scenario: Audit log entry for sensitive change
Given a create, update, or delete action on sensitive data
When the action is performed
Then an immutable log entry is created with actor, timestamp, before/after values

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E03
- Notes: Log table must be tamper-evident and support export by date/user/entity
