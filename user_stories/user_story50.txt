Title: Audit Log for Every Payroll Export

User Story:
As a compliance officer, I want every payroll export to be logged with actor, timestamp, and delivery status so that all payroll data transfers are auditable and traceable.

Acceptance Criteria:
- Scenario: Export is logged with details
  Given a payroll export is generated
  When the export is delivered or fails
  Then an audit log entry is created with actor, timestamp, and status

- Scenario: Audit log is exportable
  Given export logs exist
  When the officer exports the audit log
  Then all export events and details are included

Additional Details:
- Audit log must be filterable by date, user, and export status
- All log entries must be immutable
- Exported logs must match internal records
