Title: Record All User Actions in Audit Trail

User Story: As a compliance officer I want all user actions to be recorded in an audit trail So that I can monitor system usage and ensure regulatory compliance

Acceptance Criteria:
Scenario: Logging user actions
Given a user performs any action in the system
When the action is completed
Then an audit log entry should be created with timestamp, user, action, and affected data

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Audit trail module, user management
- Notes: Support export and filtering of audit logs.
