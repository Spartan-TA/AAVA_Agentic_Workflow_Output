Title: Supervisor Approval and Audit of Attendance Corrections

User Story:
As a supervisor, I want to review, approve, or reject attendance correction requests and have all actions logged for audit so that attendance data remains accurate and compliant.

Acceptance Criteria:
- Scenario: Supervisor receives notification for correction
  Given a worker submits a correction
  When the supervisor logs in
  Then the correction task is visible in their approval queue

- Scenario: Supervisor approves or rejects correction
  Given a pending correction task
  When the supervisor acts on it
  Then the attendance record is updated and the action is logged

- Scenario: Audit log of corrections
  Given corrections are processed
  When an auditor reviews the logs
  Then all actions (submit, approve, reject) are traceable by user and timestamp

Additional Details:
- All correction actions must trigger notifications to affected users
- Audit log must be exportable and filterable by date/user
- Supervisors must only see corrections for their team
