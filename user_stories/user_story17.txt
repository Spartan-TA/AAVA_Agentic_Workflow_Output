Title: Automate Onboarding & Offboarding

User Story:
As an HR administrator, I want to automate account provisioning, initial scheduling, required training, and deprovisioning on termination so that employee lifecycle changes are efficient and secure.

Acceptance Criteria:
Scenario 1: New hire onboarding
  Given a new hire appears from HRIS
  When onboarding is triggered
  Then accounts, schedules, and training tasks are created

Scenario 2: Asset assignment
  Given onboarding is in progress
  When assets are required
  Then asset assignment tasks are generated

Scenario 3: Offboarding
  Given an employee is terminated
  When offboarding is triggered
  Then access is revoked, assets are collected, and schedules updated

Scenario 4: Workflow tracking
  Given onboarding/offboarding tasks exist
  When I view the workflow
  Then I see status and completion for each task

Additional Details:
Priority: Medium
Story Points: 13
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Integration with HRIS and asset registry required.
