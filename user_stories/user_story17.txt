---
Epic: E17 - Onboarding & Offboarding Workflow

User Story 1: New Hire Provisioning
Title: Automate New Hire Provisioning
User Story: As an HR manager, I want new hires from HRIS to be provisioned with accounts, schedules, and training tasks so that onboarding is efficient.
Acceptance Criteria (Gherkin):
Given a new hire appears from HRIS,
When onboarding triggers,
Then account, schedule, and training tasks are created.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Reduces cycle time.

User Story 2: Asset Assignment for Onboarding
Title: Assign Assets to New Hires
User Story: As an operations manager, I want assets assigned to new hires during onboarding so that equipment is ready.
Acceptance Criteria (Gherkin):
Given onboarding tasks exist,
When assets are assigned,
Then assignments are recorded and tracked.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Supports readiness.

User Story 3: Offboarding Workflow
Title: Automate Offboarding
User Story: As an HR manager, I want access, asset collection, and schedule updates automated during offboarding so that risk is reduced.
Acceptance Criteria (Gherkin):
Given an employee is terminated,
When offboarding triggers,
Then access is revoked, assets collected, and schedules updated.
Additional Details:
Priority: Medium
Story Points: 2
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Supports compliance.

User Story 4: Task Generation for Onboarding/Offboarding
Title: Generate Onboarding/Offboarding Tasks
User Story: As a supervisor, I want onboarding/offboarding tasks generated so that nothing is missed.
Acceptance Criteria (Gherkin):
Given a lifecycle event occurs,
When tasks are generated,
Then all required tasks are listed and tracked.
Additional Details:
Priority: Medium
Story Points: 1
Dependencies: E02, E03, E05, E07, E09, E13
Notes: Supports process completeness.
