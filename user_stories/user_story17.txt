Title: Attendance Reports Export

User Story: As an HR manager I want to export attendance reports as CSV so that I can analyze shift totals and compliance for payroll processing

Acceptance Criteria:
Scenario: Export attendance report
Given attendance data is available for a date range
When I request a CSV export
Then the report is generated and downloadable within 10 seconds

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export must include daily totals and corrections; support filtering by employee, shift, and date.
