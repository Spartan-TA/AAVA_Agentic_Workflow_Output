Title: Attendance Exception Reporting

User Story: As an HR MANAGER I want to generate reports on attendance exceptions So that I can identify patterns and address issues proactively

Acceptance Criteria:

Scenario: Exception report generation
Given attendance data is available
When I run an exception report
Then I see all instances of missed clock-ins, late arrivals, and early departures

Scenario: Exception notification
Given an exception is detected
When the report is generated
Then relevant supervisors are notified automatically

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04-1, E04-2, E04-3
- Notes: Reports should be exportable and filterable by date, department, and location.
