Title: Shift Template Management

User Story: As a scheduler I want to create and manage shift templates So that I can quickly assign standard shift patterns to employees

Acceptance Criteria:
Scenario: Create shift template
  Given I am authenticated as a scheduler
  When I define a new shift template (start/end time, role, recurrence)
  Then the template should be saved and available for assignment
Scenario: Edit shift template
  Given a shift template exists
  When I update its details
  Then the changes should be saved
Scenario: Delete shift template
  Given a shift template exists
  When I delete it
  Then it should be removed from the system

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Scheduling module
- Notes: Support for recurring and ad-hoc templates
