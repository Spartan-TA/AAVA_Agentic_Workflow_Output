### E17 - Onboarding & Offboarding Workflow

**User Story 1**
Title: Automate New Hire Provisioning from HRIS
User Story: As an HR admin I want new hires from HRIS to be provisioned automatically So that onboarding is efficient.
Acceptance Criteria:
Scenario: New hire provisioning
Given a new hire appears in HRIS
When the sync job runs
Then the employee is created in the system
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Trigger onboarding tasks

**User Story 2**
Title: Generate Onboarding Tasks for Training and Asset Assignment
User Story: As a supervisor I want onboarding tasks generated for required training and asset assignment So that new hires are ready to work.
Acceptance Criteria:
Scenario: Onboarding tasks
Given a new hire is provisioned
When onboarding starts
Then tasks for training and asset assignment are created
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E17-1
- Notes: Tasks visible to responsible parties

**User Story 3**
Title: Automate Offboarding to Revoke Access and Collect Assets
User Story: As an HR admin I want offboarding to revoke system access and collect assigned assets So that terminations are handled securely.
Acceptance Criteria:
Scenario: Offboarding workflow
Given an employee is terminated
When offboarding is triggered
Then access is revoked and asset return tasks are created
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E17-1
- Notes: Update schedules to remove employee

**User Story 4**
Title: Update Schedules and Training Status on Offboarding
User Story: As a scheduler I want employee schedules and training status updated on offboarding So that records are accurate.
Acceptance Criteria:
Scenario: Schedule update
Given an employee is offboarded
When the process completes
Then all future shifts and training assignments are updated
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E17-3
- Notes: Remove from active rosters
