EPIC E17 - Onboarding & Offboarding Workflow

===========================================

User Story 1: Automate Account Provisioning
---------------------------------------------
Title: Automate Account Provisioning for New Hires

User Story: As an HR user, I want accounts provisioned automatically for new hires so that onboarding is efficient.

Acceptance Criteria:
Scenario: Account creation
  Given HRIS sync
  When new hire appears
  Then account is provisioned

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Link to training/tasks.
