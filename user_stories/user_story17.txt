Title: Onboarding & Offboarding Workflow
User Story 1: As an HR user I want new hires to appear from HRIS integration So that onboarding is automated
Acceptance Criteria:
Scenario: New hire onboarding
Given HRIS sync is enabled
When new hire is detected
Then onboarding tasks are generated
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Employee master data, RBAC, Shift management, Certification tracking, Asset assignment, Integration layer
- Notes: Assign initial schedule

User Story 2: As a system I want to generate tasks for required training and asset assignment So that onboarding is complete
Acceptance Criteria:
Scenario: Onboarding task generation
Given new hire is onboarded
When tasks are generated
Then training and asset assignment tasks are assigned
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Onboarding workflow
- Notes: Track task completion

User Story 3: As a system I want to automate deprovisioning of access and assets on termination So that offboarding is secure
Acceptance Criteria:
Scenario: Offboarding automation
Given employee is terminated
When offboarding is triggered
Then access is revoked, assets collected, schedules updated
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Asset assignment, Integration layer
- Notes: Log all actions

User Story 4: As a supervisor I want to review onboarding/offboarding status So that I monitor progress
Acceptance Criteria:
Scenario: Status review
Given workflow tasks exist
When I access status dashboard
Then progress is displayed per employee
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Onboarding/offboarding workflow
- Notes: Filter by department

User Story 5: As a system I want to update schedules and training status during onboarding/offboarding So that records are current
Acceptance Criteria:
Scenario: Schedule/training update
Given onboarding/offboarding occurs
When status changes
Then schedules and training records are updated
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Shift management, Certification tracking
- Notes: Audit changes
