Title: Employee Submit Leave Request

User Story: As an employee I want to submit a leave request so that my planned absences are tracked and approved

Acceptance Criteria:
Scenario: Submitting a leave request
Given I am logged in as an employee
When I fill out and submit a leave request form
Then my supervisor is notified and the request is pending approval

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notification module
- Notes: Leave types should include vacation, sick, and unpaid leave.
