Title: Onboarding - Automate New Hire Provisioning

User Story: As an HR user I want new hires from HRIS to be automatically provisioned with accounts, schedule, and required training so that onboarding is efficient.

Acceptance Criteria:
Scenario: New hire appears from HRIS
Given a new hire is added in HRIS
When the sync job runs
Then the employee is created, scheduled, and assigned training tasks

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Tasks generated for asset assignment.

Title: Offboarding - Automate Termination Workflow

User Story: As an HR user I want terminated employees to have access revoked, assets collected, and schedules updated so that offboarding is secure.

Acceptance Criteria:
Scenario: Offboard employee
Given an employee is terminated in HRIS
When the sync job runs
Then access is revoked, assets are collected, and schedules are updated

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Deprovisioning automated.
