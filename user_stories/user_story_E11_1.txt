Title: Payroll Export File Generation

User Story: As a payroll administrator I want to generate payroll-ready files from approved attendance and leave So that I can process payroll efficiently and accurately

Acceptance Criteria:
Scenario: Generate payroll export file
Given approved attendance and leave records are available
When I initiate a payroll export
Then the generated file matches the external provider schema and includes all required data

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: Must support multiple provider formats and validate schema before export.
