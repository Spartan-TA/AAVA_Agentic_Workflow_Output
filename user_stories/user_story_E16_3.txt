Title: Offline Queue and Conflict Resolution for Clock Events

User Story: As a warehouse worker I want my clock-in/out events to be queued offline and synced with conflict resolution So that my attendance is accurately recorded even with poor connectivity

Acceptance Criteria:
Scenario: Offline clock event sync
Given my device is offline
When I submit a clock-in or clock-out event
Then the event is queued locally and synced to the server when online, with conflicts resolved automatically

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04, E05, E06, E12
- Notes: Must handle duplicate or overlapping events gracefully.
