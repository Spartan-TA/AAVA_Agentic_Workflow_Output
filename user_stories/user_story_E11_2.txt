Title: Payroll Export Delivery and Retry

User Story: As a payroll administrator I want payroll exports to be securely delivered to external providers via SFTP or API So that payroll files reach the provider reliably and securely

Acceptance Criteria:
Scenario: Secure delivery and retry
Given a payroll export file is generated
When delivery to the provider fails
Then the system retries with exponential backoff and logs each attempt in the audit trail

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Audit log must capture every export and retry event.
