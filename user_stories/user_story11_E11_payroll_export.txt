[E11] Payroll Export Integration

Title: Generate Payroll-Ready Export Files
User Story: As a payroll manager I want to generate payroll-ready files from approved attendance and leave so that payroll runs are automated.
Acceptance Criteria:
Scenario: Payroll Export Generation
Given approved attendance and leave records
When I generate export
Then the file matches provider schema

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Support multiple provider formats

---

Title: Map Data to External Payroll Provider Formats
User Story: As a payroll manager I want data mapped to external payroll provider formats so that integration is seamless.
Acceptance Criteria:
Scenario: Data Mapping
Given provider requirements
When I export payroll data
Then fields are mapped correctly

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Generate Payroll-Ready Export Files
- Notes: Document mapping rules

Title: Secure Delivery via SFTP/API
User Story: As a payroll manager I want payroll files delivered securely via SFTP or API so that sensitive data is protected.
Acceptance Criteria:
Scenario: Secure File Delivery
Given an export file
When I deliver via SFTP/API
Then delivery is encrypted and logged

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Generate Payroll-Ready Export Files
- Notes: Retry failed deliveries

Acceptance Criteria:
Scenario: Payroll Export Audit Logging

Additional Details:
- Priority: High
- Story Points: 2

Title: Retry Failed Deliveries with Backoff
User Story: As a payroll manager I want failed deliveries retried with exponential backoff so that exports are reliable.
Acceptance Criteria:
Scenario: Delivery Retry
Given a failed delivery
When the system retries
Then retries follow backoff strategy and are logged

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Secure Delivery via SFTP/API
- Notes: Notify on repeated failures
