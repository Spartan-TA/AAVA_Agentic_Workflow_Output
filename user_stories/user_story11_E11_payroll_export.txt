Epic E11: Payroll Export Integration

---

User Story 1: Generate Payroll-Ready Files
As payroll, I want to generate payroll-ready files from attendance and leave so that payroll runs are automated.

Acceptance Criteria:
Scenario: File generation
  Given approved attendance and leave
  When I request payroll export
  Then files match provider schema

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04, E06
- Notes: Export format configurable

---

User Story 2: Secure Delivery via SFTP/API
As payroll, I want files delivered securely via SFTP or API so that data is protected.

Acceptance Criteria:
Scenario: SFTP delivery
  Given a payroll file
  When I send via SFTP
  Then delivery is confirmed

Scenario: API delivery
  Given a payroll file
  When I send via API
  Then delivery is confirmed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Delivery failures retried

---

User Story 3: Delivery Failure Handling
As payroll, I want failed deliveries retried with backoff so that exports are reliable.

Acceptance Criteria:
Scenario: Delivery failure
  Given a failed delivery
  When retry logic runs
  Then delivery is retried with backoff

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Audit log for every export

---

User Story 4: Audit Log for Exports
As compliance, I want an audit log for every payroll export so that changes are traceable.

Acceptance Criteria:
Scenario: Audit entry
  Given a payroll export
  When export occurs
  Then an audit entry is created

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Log includes actor, timestamp, status
