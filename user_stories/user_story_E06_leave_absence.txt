Title: Request Leave

User Story: As a Warehouse Worker I want to request PTO, sick, or unpaid leave So that my absence is recorded and approved

Acceptance Criteria:
Scenario: Request leave
Given leave balances
When I submit a leave request
Then my supervisor should be notified for approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee CRUD APIs (E02), RBAC (E03), Shift Management (E05)
- Notes: Show available balances
