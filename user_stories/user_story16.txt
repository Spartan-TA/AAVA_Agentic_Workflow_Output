Title: Request Shift Swap
User Story: As an employee I want to request a shift swap with a coworker So that I can manage personal commitments without affecting coverage
Acceptance Criteria:
Scenario: Request shift swap
Given I am logged into the system and have an assigned shift
When I submit a shift swap request to a coworker
Then the coworker receives a notification and can accept or decline the request
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Shift data, notifications
- Notes: Approval by supervisor required for final confirmation.
