Title: Attendance Correction Approval

User Story: As a Supervisor I want to review and approve or deny attendance correction requests So that missed punches are handled accurately and fairly

Acceptance Criteria:

Scenario: Correction request submitted
  Given a worker missed a clock-in or clock-out
  When they submit a correction request
  Then a supervisor is notified and the request appears in their approval queue

Scenario: Supervisor approves correction
  Given a pending correction request
  When the supervisor approves it
  Then the attendance record is updated and marked as corrected

Scenario: Supervisor denies correction
  Given a pending correction request
  When the supervisor denies it
  Then the attendance record remains unchanged and the worker is notified

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Track all corrections in audit trail; notify workers of approval/denial.
