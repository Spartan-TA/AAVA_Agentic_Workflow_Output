# E16: Mobile Access (PWA)

## User Story 1
- Title: Responsive Mobile Views for Core Flows
- User Story: As a worker, I want responsive mobile views for clock-in/out, schedules, leave requests, and announcements so that I can use the system on any device.
- Acceptance Criteria in Gherkin format:
  Scenario: Mobile view usability
  Given a mobile device
  When I access core flows
  Then the UI is responsive and usable
- Additional Details:
  * Priority: Medium
  * Story Points: 3
  * Dependencies: E04, E05, E06, E12
  * Notes: Test on multiple devices

## User Story 2
- Title: Installable PWA Manifest
- User Story: As a worker, I want to install the app as a PWA so that I have quick access from my home screen.
- Acceptance Criteria in Gherkin format:
  Scenario: PWA installation
  Given the app
  When I install it
  Then it appears on my device home screen
- Additional Details:
  * Priority: Medium
  * Story Points: 2
  * Dependencies: Mobile views
  * Notes: Manifest and service worker setup

## User Story 3
- Title: Offline Queue for Clock Events
- User Story: As a worker, I want clock-in/out events queued offline so that my attendance is recorded even without connectivity.
- Acceptance Criteria in Gherkin format:
  Scenario: Offline clock event
  Given no network connectivity
  When I clock in or out
  Then the event is queued and synced when online
- Additional Details:
  * Priority: Medium
  * Story Points: 3
  * Dependencies: Mobile views
  * Notes: Conflict resolution on sync
