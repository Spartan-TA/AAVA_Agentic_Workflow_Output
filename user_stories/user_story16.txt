Title: Payroll Export Integration
User Story: As a payroll admin I want to export approved attendance and leave data in provider format So that payroll processing is automated
Acceptance Criteria:
Scenario: Generate payroll export
Given approved attendance and leave records
When I trigger export
Then a file matching provider schema is generated and delivered securely

Scenario: Failed delivery retry
Given an export fails
When the system retries with backoff
Then delivery succeeds or error is logged

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Attendance, Leave Management
- Notes: SFTP/API delivery; audit log for exports.
