Title: Device and Geofence Validation for Attendance Events

User Story:
As a warehouse supervisor, I want clock-in/out events to validate device identity and (optionally) geofence location so that only authorized devices and locations are used for attendance.

Acceptance Criteria:
- Scenario: Clock-in from authorized device and location
  Given a worker uses a registered device within the geofence
  When they clock in
  Then the event is accepted

- Scenario: Clock-in from unauthorized device or outside geofence
  Given a worker uses an unregistered device or is outside the geofence
  When they clock in
  Then the response is 403 Forbidden

Additional Details:
- Device registration must be managed by supervisors/admins
- Geofence validation is configurable per site
- All device and location data must be logged for audit
