Title: Blackout Dates and Operation Calendar

User Story: As a scheduler I want to define blackout dates and maintain an operation calendar So that shifts are not assigned on holidays or non-working days

Acceptance Criteria:
Scenario: Blackout date creation
Given the calendar interface
When I add a blackout date
Then the system should prevent shift assignments on that date

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Shift Assignment and Conflict Detection
- Notes: Support recurring holidays and custom events.
