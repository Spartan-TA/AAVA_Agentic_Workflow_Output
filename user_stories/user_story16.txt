### E16 - Mobile Access (PWA)

**Title:** Mobile Clock-In/Out
**User Story:** As a worker, I want to clock in/out from my mobile device so that attendance is convenient.
**Acceptance Criteria:**
Scenario: Mobile clock-in
Given I am on mobile
When I clock in/out
Then the event is recorded and synced
**Additional Details:** Priority: Medium, Story Points: 3, Dependencies: E04, E05, E06, E12, Notes: Offline queue with conflict resolution.

**Title:** View Schedule on Mobile
**User Story:** As a worker, I want to view my schedule on mobile so that I can access it anywhere.
**Acceptance Criteria:**
Scenario: Mobile schedule view
Given I am logged in
When I access my schedule
Then it is responsive and installable as a PWA
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E04, E05, E06, E12, Notes: Lighthouse PWA score.
