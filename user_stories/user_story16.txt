Title: Leave Request and Approval Workflow

User Story: As an employee, I want to request PTO, sick, or unpaid leave so that my time off is tracked and approved.

Acceptance Criteria:

Scenario: Submit leave request
Given the leave form
When I submit a request
Then it is routed to my supervisor for approval

Scenario: Supervisor reviews request
Given a supervisor
When reviewing
Then they can approve or deny with comments

Scenario: Approved leave updates balance and schedule
Given an approved leave
When processed
Then my leave balance updates and scheduled shifts are flagged for coverage

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E05
- Notes: Integration with scheduling
