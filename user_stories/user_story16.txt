Title: Leave & Absence Management - Approve/Deny Leave

User Story: As a supervisor, I want to approve or deny leave requests so that staffing is managed.

Acceptance Criteria:

Scenario: Approve leave request
Given a leave request is pending
When I approve it
Then the employee's leave balance is updated and the schedule is flagged for coverage

Scenario: Deny leave request
Given a leave request is pending
When I deny it
Then the request is marked as denied and the employee is notified

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Leave request
- Notes: Approved leaves must be excluded from scheduling and payroll.
