Title: Automated Overtime Calculation

User Story: As a PAYROLL ADMIN I want the system to automatically calculate overtime So that payroll processing is accurate and efficient

Acceptance Criteria:

Scenario: Overtime calculation
Given employee attendance records are available
When total hours exceed standard work hours
Then overtime hours are calculated and flagged for payroll

Scenario: Overtime report generation
Given overtime records exist
When I generate a payroll report
Then overtime is included in the report

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04-1, E04-2
- Notes: Overtime rules must be configurable per location.
