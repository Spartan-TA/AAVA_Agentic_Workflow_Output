Title: Mobile Access (PWA)
User Story: As a warehouse worker I want to use a mobile-friendly interface to clock in/out, view schedules, request leave, and see announcements so that I can perform core tasks from any device.
Acceptance Criteria:
Scenario: Mobile usability and offline support
Given I am using a mobile device
When I access the PWA
Then I can perform clock-in/out, view schedules, request leave, and see announcements
And the app is installable as a PWA
And offline queue for clock events is supported with conflict resolution
And Lighthouse PWA score is at least 80
Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: Time & Attendance (Clock In/Out), Shift & Schedule Management, Leave & Absence Management, Notifications & Announcements
- Notes: Responsive views required; offline-first design preferred.
