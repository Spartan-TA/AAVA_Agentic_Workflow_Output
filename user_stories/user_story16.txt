Title: Mobile Access - Clock In/Out on Mobile

User Story: As a worker I want to clock in/out using my mobile device so that I can record attendance from anywhere.

Acceptance Criteria:
Scenario: Clock in/out via mobile
Given I have a mobile device
When I access the PWA and clock in/out
Then my attendance is recorded

Scenario: Offline clock events queued
Given I am offline
When I clock in/out
Then the event is queued and synced when online

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Conflict resolution for offline events.

Title: Mobile Access - View Schedule and Announcements
