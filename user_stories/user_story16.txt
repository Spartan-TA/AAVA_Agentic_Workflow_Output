Title: Implement Clock-Out API Endpoint

User Story: As a warehouse worker I want to clock out using a secure API endpoint So that my shift end time is accurately recorded for payroll and compliance

Acceptance Criteria:
Scenario: Successful clock-out
  Given I am authenticated and have clocked in for the current shift
  When I submit a clock-out request via the API
  Then my clock-out event is recorded with timestamp, device ID, and geolocation
Scenario: Invalid clock-out attempt
  Given I have not clocked in for the current shift
  When I attempt to clock out
  Then the request is rejected with an error message
Scenario: Duplicate clock-out
  Given I have already clocked out for the current shift
  When I attempt to clock out again
  Then the request is rejected and no duplicate event is created

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Ensure geofence validation and device capture are implemented.
