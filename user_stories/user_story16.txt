Title: Missed Punch Correction Workflow

User Story: As a WORKER I want to submit corrections for missed clock-in/out events so that my attendance record is accurate and payroll is correct

Acceptance Criteria:
Scenario: Correction request
Given I missed a clock-in/out event
When I submit a correction request
Then an approval task is created for my supervisor and my attendance record is updated upon approval

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Correction workflow must be auditable; notifications sent to supervisor.
