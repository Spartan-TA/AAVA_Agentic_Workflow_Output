Title: Mobile Access (PWA)

User Story: As a warehouse worker I want to access core workflows (clock-in/out, schedules, leave requests, announcements) on my mobile device so that I can perform essential tasks conveniently, even offline.

Acceptance Criteria:
Scenario: Responsive mobile views
  Given I am using a mobile device
  When I access the application
  Then all core flows are usable and responsive

Scenario: Installable PWA
  Given the application is a PWA
  When I install it on my device
  Then it appears as an app and supports offline access

Scenario: Offline clock events
  Given I am offline
  When I clock in or out
  Then the event is queued and resolved when connectivity is restored

Scenario: PWA performance
  Given the PWA is implemented
  When I run Lighthouse tests
  Then the PWA score meets required standards

Additional Details:
- Priority: Medium
- Story Points: 8
- Dependencies: Time & Attendance (E04), Shift & Schedule Management (E05), Leave & Absence Management (E06), Notifications & Announcements (E12)
- Notes: Offline queue for clock events; installable manifest; Lighthouse PWA score.
