### E16: Mobile Access (PWA)

#### User Story 1
Title: Responsive Clock-In/Out Views

User Story: As a worker, I want responsive views to clock in/out on mobile So that I can use my device easily.

Acceptance Criteria:
Scenario: Mobile clock-in/out
Given a mobile device
When I access the clock-in/out page
Then the view is responsive and usable

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E12
- Notes: Usability tested on common devices
