Title: Shift Template Creation
User Story: As an HR manager I want to create recurring shift templates So that I can efficiently schedule employees and handle rotations
Acceptance Criteria:
Scenario: Create shift template
Given I am on the shift management page
When I define a new shift template with recurrence and save it
Then the template is available for assignment and conflicts are detected
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03, E04
- Notes: Recurring shifts must support rotations and blackout dates.
