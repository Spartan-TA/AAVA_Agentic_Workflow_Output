Title: Assign Equipment & Track Asset Usage

User Story: As a warehouse manager I want to assign equipment to employees and track checkout/return So that asset usage is monitored and losses are minimized

Acceptance Criteria:
Scenario: Track equipment checkout and return
Given an employee requests equipment
When the manager assigns and logs the checkout
Then the system records the transaction and tracks return status

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02 (Employee Master Data CRUD), E03 (RBAC), E07 (Training & Certification Tracking)
- Notes: Include overdue notifications and asset condition tracking.
