### E16 - Mobile Access (PWA)

**User Story 1**
Title: Responsive Mobile Views for Core Flows
User Story: As a worker I want to clock in/out, view schedules, request leave, and see announcements on my mobile device So that I can use the system anywhere.
Acceptance Criteria:
Scenario: Mobile usability
Given I access the app on mobile
When I use core flows
Then all features are usable and responsive
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E12
- Notes: Test on multiple devices

**User Story 2**
Title: Installable PWA Manifest
User Story: As a user I want to install the app as a PWA So that I can access it like a native app.
Acceptance Criteria:
Scenario: PWA installation
Given I access the app
When I choose to install
Then the app is added to my home screen
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E16-1
- Notes: Manifest includes icons and metadata

**User Story 3**
Title: Offline Queue for Clock Events
User Story: As a worker I want to clock in/out offline and have events queued So that my attendance is captured even without connectivity.
Acceptance Criteria:
Scenario: Offline clock-in
Given I am offline
When I clock in
Then the event is queued and synced when online
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E16-1
- Notes: Conflict resolution for duplicate events
