Title: Mobile Access - Installable PWA and Offline Support
User Story: As a worker, I want to install the app as a PWA and use it offline so that I can clock in/out even without connectivity.
Acceptance Criteria:
Scenario: Install PWA
  Given I use a supported browser
  When I install the app
  Then it appears on my home screen

Scenario: Offline clock-in/out
  Given I am offline
  When I clock in/out
  Then the event is queued and synced when online

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: E04, E05, E06, E12
Notes: Supports unreliable connectivity
