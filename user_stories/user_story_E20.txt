### E20 - CI/CD & Deployment Automation

#### User Story 1
Title: Automated Pipeline for Build, Test, Security Scan
User Story: As a Developer, I want a CI/CD pipeline that runs build, test, and security scan on every PR so that code quality is enforced.
Acceptance Criteria:
Scenario: Pipeline Execution
Given a PR
When pipeline runs
Then build, tests, and security scan pass before merge
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: GitHub Actions or Jenkins

#### User Story 2
Title: Docker Image Build and Tagging
User Story: As a DevOps Engineer, I want Docker images built and tagged with commit SHA so that deployments are traceable.
Acceptance Criteria:
Scenario: Docker Build
Given a successful build
When image is created
Then it is tagged with commit SHA
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01
- Notes: Tagging required

#### User Story 3
Title: Automated Deployment to Staging and Production
User Story: As an ADMIN, I want automated deployment to staging and production so that releases are consistent.
Acceptance Criteria:
Scenario: Deployment Automation
Given a tagged image
When deployment triggers
Then app is deployed to staging/prod
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Blue-green or canary deploy

#### User Story 4
Title: Rollback Strategy for Failed Deployments
User Story: As a DevOps Engineer, I want a rollback strategy so that failed deployments are reverted in less than 5 minutes.
Acceptance Criteria:
Scenario: Rollback Execution
Given a failed deployment
When rollback triggers
Then previous version is restored within 5 minutes
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E01
- Notes: Rollback documented
