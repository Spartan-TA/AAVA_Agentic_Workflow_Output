### E20 - CI/CD & Deployment Automation

**User Story 1**
- Title: Build and Test Pipeline on Every PR
- User Story: As a developer, I want a CI pipeline that builds and tests on every PR so that code quality is maintained.
- Acceptance Criteria:
  - Given a PR is opened,
    When the pipeline runs,
    Then build and tests pass before merge.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Quality.

**User Story 2**
- Title: Security Scan in CI Pipeline
- User Story: As a DevOps engineer, I want security scans in the pipeline so that vulnerabilities are detected early.
- Acceptance Criteria:
  - Given the pipeline runs,
    When security scans execute,
    Then issues are reported before deployment.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Security.

**User Story 3**
- Title: Docker Image Push with Commit SHA Tag
- User Story: As a DevOps engineer, I want Docker images pushed with commit SHA tags so that deployments are traceable.
- Acceptance Criteria:
  - Given a build completes,
    When the image is pushed,
    Then it is tagged with the commit SHA.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Traceability.

**User Story 4**
- Title: Deploy to Staging/Prod with Blue-Green or Canary
- User Story: As a DevOps engineer, I want deployments to staging/prod with blue-green or canary strategies so that downtime is minimized.
- Acceptance Criteria:
  - Given a deployment is triggered,
    When blue-green/canary is used,
    Then traffic is switched with minimal disruption.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E01, Notes: Reliability.

**User Story 5**
- Title: Rollback Plan Tested in Pipeline
- User Story: As a DevOps engineer, I want rollback plans tested in the pipeline so that failed deployments can be reverted.
- Acceptance Criteria:
  - Given a deployment fails,
    When rollback is triggered,
    Then the previous version is restored.
- Additional Details: Priority: High, Story Points: 1, Dependencies: E01, Notes: Safety.
