Epic E03: Role-Based Access Control (RBAC)
------------------------------------------------------------

User Story 1: Implement Role-Based Endpoint Security

Title: Implement Role-Based Endpoint Security
User Story: As a system administrator, I want to restrict API endpoints based on user roles (ADMIN, HR, SUPERVISOR, WORKER) so that sensitive operations are protected.
Acceptance Criteria:
  Scenario: Unauthorized access returns 401
    Given a user without authentication
    When they access a protected endpoint
    Then the response is 401 Unauthorized

  Scenario: Forbidden actions return 403
    Given a user with insufficient role
    When they attempt restricted action
    Then the response is 403 Forbidden

Additional Details:
  Priority: High
  Story Points: 3
  Dependencies: E01, E02
  Notes: Security foundation
