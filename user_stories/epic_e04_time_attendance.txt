EPIC E04: Time & Attendance (Clock In/Out)

---

Title: Implement Clock-In/Out Endpoints

User Story: As a warehouse worker I want to clock in and out via endpoints So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock-in/out
Given I am authenticated
When I POST to /attendance/clock-in or /clock-out
Then my event is recorded with timestamp

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data, RBAC
- Notes: Geofence optional

---

Title: Capture Device and Location Data

User Story: As a supervisor I want device and location data captured on clock events So that compliance is ensured

Acceptance Criteria:
Scenario: Data capture
Given I clock in/out
When my device and location are available
Then they are stored with the event

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Implement Clock-In/Out Endpoints
- Notes: Device ID, GPS coordinates

---

Title: Calculate Hours Worked Per Shift

User Story: As a payroll admin I want hours worked per shift calculated automatically So that payroll is accurate

Acceptance Criteria:
Scenario: Hours calculation
Given clock-in/out events exist
When I view shift totals
Then hours are computed correctly

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Implement Clock-In/Out Endpoints
- Notes: Handle overnight shifts

---

Title: Handle Missed Punches and Corrections

User Story: As a worker I want to request corrections for missed punches So that my attendance is accurate

Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch
When I submit a correction request
Then an approval task is created for my supervisor

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Implement Clock-In/Out Endpoints
- Notes: Approval workflow required

---

Title: Export Attendance Reports

User Story: As a payroll admin I want to export attendance reports in CSV So that payroll processing is streamlined

Acceptance Criteria:
Scenario: Report export
Given attendance data exists
When I request a CSV export
Then the file is generated with correct totals

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Calculate Hours Worked Per Shift
- Notes: Include corrections
