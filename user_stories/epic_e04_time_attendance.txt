EPIC E04: TIME & ATTENDANCE (CLOCK IN/OUT)

===========================================

Title: Time & Attendance - Clock In/Out
User Story: As a worker, I want to clock in and out with device and optional geofence capture so that my work hours are accurately recorded.
Acceptance Criteria:
Scenario: Clock in/out
  Given a valid employee
  When I POST to /attendance/clock-in or /clock-out
  Then the event is recorded with device and location info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02,E03
- Notes: Geofence is optional.

---

Title: Time & Attendance - Calculate Hours Worked
User Story: As a supervisor, I want the system to calculate hours worked per shift so that payroll is accurate.
Acceptance Criteria:
Scenario: Calculate hours
  Given clock in/out events
  When the shift ends
  Then total hours are computed and visible
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02,E03
- Notes: Handle overnight shifts.

---

Title: Time & Attendance - Missed Punches & Corrections
User Story: As a worker, I want to request corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
Scenario: Missed punch correction
  Given a missed punch
  When I submit a correction
  Then an approval task is created for my supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02,E03
- Notes: Track correction history.

---

Title: Time & Attendance - Attendance Reports
User Story: As an HR user, I want to export attendance reports in CSV so that I can analyze and share data.
Acceptance Criteria:
Scenario: Export attendance
  Given attendance data
  When I request export
  Then a CSV file is generated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02,E03
- Notes: Include filters.
