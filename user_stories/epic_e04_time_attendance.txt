Title: Clock In/Out - Record Event

User Story: As a worker I want to clock in and out via an endpoint So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock in/out
Given a valid employee and location
When I POST to /attendance/clock-in or /clock-out
Then the event is recorded with timestamp and device info

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence validation optional
