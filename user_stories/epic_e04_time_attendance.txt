Title: Clock In/Out Endpoint

User Story: As a WORKER I want to clock in and out via API endpoints So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock in event
Given I am scheduled for a shift
When I POST to /attendance/clock-in
Then my clock-in time is recorded and associated with my shift

Scenario: Clock out event
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out time is recorded

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD, RBAC
- Notes: Geofence and device capture optional

Title: Attendance Correction Workflow

User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records are accurate

Acceptance Criteria:
Scenario: Correction request
Given a missed punch
When a correction is submitted
Then an approval task is created for the supervisor

Scenario: Correction approval
Given a pending correction
When the supervisor approves
Then the attendance record is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock In/Out Endpoint
- Notes: Correction workflow tracked in audit log

Title: Attendance Reporting

User Story: As an HR I want to export attendance reports in CSV format So that payroll and compliance needs are met

Acceptance Criteria:
Scenario: Report export
Given attendance data exists
When I request a CSV export
Then the report is generated with daily totals

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Export includes corrections
