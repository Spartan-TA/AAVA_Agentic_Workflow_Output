EPIC E04: TIME & ATTENDANCE (CLOCK IN/OUT)

===========================================

Title: Clock In/Out Attendance Endpoint

User Story: As a warehouse worker I want to clock in and out using a secure endpoint So that my attendance is accurately recorded

Acceptance Criteria:

Scenario: Clock-in event
Given I am scheduled for a shift
When I POST to /attendance/clock-in with valid data
Then my clock-in is recorded and associated with my shift

Scenario: Clock-out event
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out is recorded and hours are calculated

Scenario: Geofence validation
Given geofence is enabled
When I clock in/out outside the allowed area
Then the event is rejected

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Employee Master Data, Role-Based Access Control
- Notes: Capture device info for audit

---

Title: Attendance Corrections Workflow

User Story: As a supervisor I want to manage missed punches and attendance corrections So that attendance records remain accurate

Acceptance Criteria:

Scenario: Missed punch correction
Given a worker missed a punch
When a correction request is submitted
Then an approval task is created for the supervisor

Scenario: Correction approval
Given a correction task exists
When the supervisor approves it
Then the attendance record is updated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Clock In/Out Attendance Endpoint
- Notes: Corrections must be auditable

---

Title: Attendance Reporting

User Story: As an HR manager I want to export attendance reports So that I can reconcile payroll and compliance

Acceptance Criteria:

Scenario: Export report
Given attendance data exists
When I request a CSV export
Then the report is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock In/Out Attendance Endpoint
- Notes: Support date range and filtering
