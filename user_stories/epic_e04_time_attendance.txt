## User Story 1: Implement Clock-In/Clock-Out Endpoints
**User Story:**  
As a worker, I want to clock in and out via an endpoint so that my attendance is recorded.

**Acceptance Criteria (Gherkin):**  
Given a valid employee  
When they POST to /attendance/clock-in or /clock-out  
Then the event is recorded with timestamp

**Additional Details:**  
- Priority: High  
- Story Points: 3  
- Dependencies: E02, E03  
- Notes: Optionally capture device and geofence

---

## User Story 2: Calculate Hours Worked Per Shift
**User Story:**  
As a payroll admin, I want the system to calculate total hours worked per shift so that payroll is accurate.

**Acceptance Criteria (Gherkin):**  
Given valid clock-in/out events  
When I view shift data  
Then total hours are computed and displayed

**Additional Details:**  
- Priority: High  
- Story Points: 2  
- Dependencies: E04-1  
- Notes: Handle overnight shifts

---

## User Story 3: Handle Missed Punches and Corrections
**User Story:**  
As a supervisor, I want to approve corrections for missed punches so that attendance records are accurate.

**Acceptance Criteria (Gherkin):**  
Given a missed punch  
When a correction is submitted  
Then a task is created for supervisor approval  
And once approved, the record is updated

**Additional Details:**  
- Priority: Medium  
- Story Points: 2  
- Dependencies: E04-1  
- Notes: Corrections logged for audit

---

## User Story 4: Export Attendance Reports
**User Story:**  
As an HR user, I want to export attendance data as CSV so that I can analyze and share it.

**Acceptance Criteria (Gherkin):**  
Given attendance records  
When I request an export  
Then a CSV file is generated with daily totals

**Additional Details:**  
- Priority: Medium  
- Story Points: 1  
- Dependencies: E04-2  
- Notes: Include filters for date range, department
