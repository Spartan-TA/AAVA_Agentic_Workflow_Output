Title: Configure Review Templates

User Story: As an HR manager I want to configure performance review templates So that reviews are standardized and relevant to each role

Acceptance Criteria:
Scenario: Review template configuration
Given I am logged in as an HR manager
When I create or modify a review template
Then the template should be available for use in future reviews

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Role management, review module
- Notes: Support for multiple template versions
