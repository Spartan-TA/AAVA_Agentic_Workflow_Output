**User Story 3**
- **Title:** Integrate Database Migration Tool
- **User Story:** As a developer, I want Flyway or Liquibase configured so that database schema changes are versioned and repeatable.
- **Acceptance Criteria (Gherkin):**
  ```
  Given the project is running,
  When I start the application,
  Then baseline migrations should be applied automatically,
  And the migration history should be tracked.
  ```
- **Additional Details:**  
  Priority: High  
  Story Points: 2  
  Dependencies: E01-1  
  Notes: Choose Flyway or Liquibase.
