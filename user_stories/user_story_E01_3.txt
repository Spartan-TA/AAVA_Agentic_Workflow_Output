Title: Database Migration Tool Integration

User Story: As a developer I want to integrate Flyway or Liquibase for database migrations So that schema changes are versioned and repeatable

Acceptance Criteria:
Scenario: Migration tool configured
Given the project is built
When I check the configuration
Then Flyway or Liquibase is enabled and runs on startup

Scenario: Baseline migration present
Given a new database
When the application starts
Then the baseline schema is created without errors

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Initialization
- Notes: Baseline migration must cover all core tables
