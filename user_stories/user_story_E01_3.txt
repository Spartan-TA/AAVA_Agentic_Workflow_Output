Title: Document Build/Run Steps and Verify Package Structure

User Story: As a developer I want the README to include clear build and run instructions and the base package structure to be verified so that new team members can onboard quickly and modules remain organized.

Acceptance Criteria:
Scenario: README documentation
Given the repository is cloned
When I open the README file
Then I see step-by-step build and run instructions

Scenario: Package structure verification
Given the project is built
When I inspect the source code
Then the core modules (employee, scheduling, attendance, safety) are present in the base package structure

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure documentation is up-to-date with latest module additions.
