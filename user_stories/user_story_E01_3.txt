Title: Enable Actuator Health Endpoint

User Story: As a System Administrator I want to enable the Actuator health endpoint So that I can monitor the application's health status in real time

Acceptance Criteria:
Scenario: Health endpoint enabled
  Given the application is running
  When I access /actuator/health
  Then the endpoint returns status UP
Scenario: Health monitoring
  Given the application is deployed
  When the health endpoint is queried
  Then the response includes status and relevant subsystem checks

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project scaffolding
- Notes: Ensure endpoint is secured and documented
