Title: Enable Actuator Health Endpoint

User Story: As a system administrator I want to enable the actuator health endpoint So that I can monitor application health and status in real time

Acceptance Criteria:
Scenario: Health endpoint enabled
Given the application is running
When I access the /actuator/health endpoint
Then I should receive a detailed health status response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot Actuator
- Notes: Secure the endpoint for admin-only access.
