Title: Upload Certification Proof Documents

User Story: As an employee I want to upload proof of my certifications so that my compliance status is documented and visible to HR and supervisors

Acceptance Criteria:
Scenario: Upload certification document
  Given I have a valid certification document
  When I upload the file to my profile
  Then the document is stored securely and linked to my certification record

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02 (User Management), E03 (Scheduling)
- Notes: Supported file types: PDF, JPG, PNG
