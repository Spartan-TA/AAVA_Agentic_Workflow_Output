Title: Support Multiple Languages and Locales

User Story: As a global user I want the platform to support multiple languages and locales So that I can use the system in my preferred language and regional format

Acceptance Criteria:
Scenario: Changing language and locale
Given I have access to language settings
When I select a different language or locale
Then the platform UI and data formats should update accordingly

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Localization engine, translation files
- Notes: Support date, time, and currency formats.
