Title: Provide Webhooks for Event Notifications

User Story: As a system integrator I want to receive webhook notifications for key events (e.g., new hire, schedule change) so that external systems can react in real time.

Acceptance Criteria:
Scenario: Receiving a webhook on new hire
Given a new employee is added to the system
When the event occurs
Then the system should send a webhook with relevant data to the configured endpoint

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: Webhook delivery should be logged and support retries on failure.
