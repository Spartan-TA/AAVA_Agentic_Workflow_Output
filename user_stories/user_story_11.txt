Title: Generate OpenAPI Documentation for Employee APIs

User Story: As a developer I want comprehensive OpenAPI documentation for all employee APIs so that I can easily integrate with the system.

Acceptance Criteria:

Scenario: OpenAPI spec is accessible
Given the application is running
When I navigate to /v3/api-docs
Then I should receive the OpenAPI specification in JSON format
And all employee endpoints should be documented

Scenario: Swagger UI is available
Given the application is running
When I navigate to /swagger-ui.html
Then I should see the Swagger UI interface
And I should be able to browse all employee endpoints
And I should be able to try out the APIs

Scenario: Request schemas include examples
Given I view the POST /employees endpoint in Swagger UI
When I expand the request body schema
Then I should see example request payloads
And all required fields should be marked
And field descriptions should be present

Scenario: Response schemas include examples
Given I view any employee endpoint
When I expand the response schema
Then I should see example responses for success cases
And I should see example error responses
And HTTP status codes should be documented

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs (E02)
- Notes: Use SpringDoc OpenAPI. Keep documentation in sync with implementation. Include authentication requirements in documentation.
