Title: Define User Roles and Permissions

User Story: As a system administrator I want to define user roles and permissions So that I can control access to sensitive features and data

Acceptance Criteria:
Scenario: Role creation
  Given I am logged in as an administrator
  When I navigate to the roles management page and create a new role
  Then the role should be saved and available for assignment
Scenario: Permission assignment
  Given a role exists
  When I assign permissions to the role
  Then users with that role should inherit the assigned permissions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User management module
- Notes: Roles should be configurable and support granular permissions.
