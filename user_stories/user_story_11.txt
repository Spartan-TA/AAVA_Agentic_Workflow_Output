Title: Support API Key/OAuth2 Toggle via Configuration

User Story: As a System Administrator I want to toggle between API key and OAuth2 authentication methods So that I can adapt security to organizational requirements and integrations.

Acceptance Criteria:
Scenario: API key authentication enabled
Given the configuration is set to API key mode
When I access a protected endpoint with a valid API key
Then access is granted

Scenario: OAuth2 authentication enabled
Given the configuration is set to OAuth2 mode
When I access a protected endpoint with a valid OAuth2 token
Then access is granted

Scenario: Invalid authentication method
Given the configuration is set to OAuth2 mode
When I access a protected endpoint with an API key
Then access is denied with a 401 error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role-based endpoint security
- Notes: Configuration must be documented and testable in all environments.
