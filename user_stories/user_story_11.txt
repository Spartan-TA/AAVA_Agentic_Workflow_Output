Title: Track Employee Certifications
User Story: As an HR manager I want to track employee certifications and expirations so that compliance is maintained
Acceptance Criteria:
Scenario: Certification tracking
Given I have access to employee profiles
When I add or update certification records
Then the system stores expiration dates and alerts for renewals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC
- Notes: Alerts 30/7 days before expiry

Title: Block Assignment to Tasks Requiring Certification
User Story: As a supervisor I want the system to block assignment of tasks to employees with expired certifications so that only qualified staff operate equipment
Acceptance Criteria:
Scenario: Assignment block
Given a certification is expired
When I attempt to assign a task requiring certification
Then the system prevents the assignment and notifies me
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Scheduling, Certification module
- Notes: Certification status visible on profile

Title: Upload Proof of Certification
User Story: As an employee I want to upload proof documents for certifications so that my records are complete and verifiable
Acceptance Criteria:
Scenario: Document upload
Given I have a valid certification
When I upload a proof document
Then the document is stored and linked to my certification record
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Certification module
- Notes: Document storage must be secure

Title: Certification Status Dashboard
User Story: As a supervisor I want to view a dashboard of certification statuses so that I can proactively manage renewals
Acceptance Criteria:
Scenario: Dashboard view
Given I am logged in as a supervisor
When I access the certification dashboard
Then I see all employees with upcoming expirations and current status
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Certification module
- Notes: Dashboard supports filtering by department
