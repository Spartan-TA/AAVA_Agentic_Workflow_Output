Title: Enforce Method and Row-Level Security

User Story: As a system administrator I want to enforce method-level and row-level security So that only authorized users can access or modify data relevant to their role or team

Acceptance Criteria:
Scenario: Supervisor access
Given a SUPERVISOR role
When accessing employee data
Then only records for their team are visible/editable

Scenario: Admin access
Given an ADMIN role
When accessing employee data
Then all records are visible/editable

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Project scaffolding, Employee CRUD
- Notes: Security rules must be covered by automated tests
