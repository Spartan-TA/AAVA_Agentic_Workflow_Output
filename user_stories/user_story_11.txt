Title: Define User Roles and Permissions

User Story: As an admin I want to define user roles and permissions So that I can control access to sensitive system features

Acceptance Criteria:
Scenario: Role creation and permission assignment
Given I am logged in as an admin
When I create a new role and assign permissions
Then the role should be available for assignment and permissions enforced

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: User management module
- Notes: Ensure granular permission settings
