Title: Shift Template Management
User Story: As a scheduler I want to create and manage recurring shift templates So that scheduling is efficient and consistent.
Acceptance Criteria:
Scenario: Create shift template
  Given valid shift details
  When I POST to /shifts/templates
  Then a new template is created

Scenario: Edit/delete shift template
  Given an existing template
  When I PUT or DELETE the template
  Then the template is updated or removed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03, E04
- Notes: Templates support rotations and overtime rules.
