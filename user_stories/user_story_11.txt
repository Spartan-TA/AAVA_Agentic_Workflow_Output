Title: User Authentication - Password Reset Request
User Story: As a user who forgot my password I want to request a password reset So that I can regain access to my account
Acceptance Criteria: 
Scenario: Reset request
Given I am on the login page
When I click forgot password and enter my email
Then I receive a password reset link via email
Additional Details: 
Priority: High
Story Points: 2
Dependencies: Email service, Authentication module
Notes: Reset link should expire after 1 hour
