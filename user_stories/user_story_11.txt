Title: Enforce Endpoint and Method Security

User Story: As a developer I want to secure API endpoints and methods based on user roles so that unauthorized access is prevented

Acceptance Criteria:
Scenario: Accessing a restricted endpoint
Given a user with insufficient role
When they attempt to access a restricted endpoint
Then the system returns a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: Security rules must be covered by automated tests.
