Title: Define Roles and Permissions Matrix

User Story: As a system administrator I want to define roles and assign permissions So that I can control access to sensitive features and data

Acceptance Criteria:
Scenario: Creating a new role
Given I am on the RBAC configuration page
When I create a new role and assign permissions
Then the role should be available for assignment to users

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: User management module
- Notes: Roles should support granular permissions for CRUD operations.
