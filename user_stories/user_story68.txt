Title: Submit Requests via Mobile PWA

User Story:
As an employee, I want to submit requests (e.g., leave, equipment, support) via the mobile PWA so that I can manage my needs conveniently from anywhere.

Acceptance Criteria:
Scenario 1: Submit request on mobile
  Given the PWA is installed
  When I access the requests module
  Then I can fill out and submit a new request

Scenario 2: Track request status
  Given I have submitted a request
  When I view my requests
  Then I see the current status and any updates

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: EMS request modules, PWA framework
Notes: Request forms should be mobile-optimized and support attachments.
