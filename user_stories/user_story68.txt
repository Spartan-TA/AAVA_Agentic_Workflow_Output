Title: Metrics Endpoints for BI and Export

User Story:
As a data analyst, I want to access metrics endpoints and export operational data for BI tools so that I can perform advanced analysis and reporting.

Acceptance Criteria:
- Scenario: Metrics endpoint returns operational data
  Given metrics endpoints are implemented
  When a BI tool queries the endpoint
  Then operational data is returned in a standard format (JSON, CSV)

- Scenario: Export is available for BI
  Given operational data exists
  When the analyst exports it
  Then a file is generated within 10 seconds for up to 50,000 rows

Additional Details:
- Endpoints must be secured and access-controlled
- Exported data must match metrics endpoint data
- All exports must be logged for audit
