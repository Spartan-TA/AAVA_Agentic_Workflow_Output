Title: Equipment Assignment and Checkout

User Story: As a supervisor I want to assign and check out equipment to employees So that asset usage is tracked and accountability is maintained

Acceptance Criteria:
Scenario: Assign equipment
  Given I am authenticated as a supervisor
  When I assign equipment to an employee
  Then the assignment should be recorded
Scenario: Equipment checkout
  Given equipment is assigned
  When the employee checks out the equipment
  Then the checkout time should be logged
Scenario: Equipment return
  Given equipment is checked out
  When the employee returns it
  Then the return time should be logged and the asset marked as available

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Asset management module
- Notes: Support for multiple asset types
