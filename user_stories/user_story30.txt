Title: Report Safety Incident

User Story: As an EMPLOYEE I want to report a safety incident So that hazards are documented and addressed promptly

Acceptance Criteria:

Scenario: Employee submits incident report
Given I am logged in as EMPLOYEE
When I fill out the incident report form
Then the safety manager is notified and the incident is logged

Scenario: Incident report validation
Given a report is submitted
When required fields are missing
Then the system prompts for completion before submission

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Reports must be timestamped and support attachments.
