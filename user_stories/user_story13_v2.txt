Title: API Key/OAuth2 Toggle via Configuration

User Story: As a system administrator I want to toggle API key and OAuth2 authentication via configuration So that I can adapt security protocols to organizational requirements

Acceptance Criteria:
Scenario: Toggle authentication method Given the system is configured for authentication When I change the config to API key or OAuth2 Then the system enforces the selected authentication method for all endpoints

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project Scaffolding (E01), Employee Master Data (E02)
- Notes: Ensure toggle is documented and covered by automated tests
