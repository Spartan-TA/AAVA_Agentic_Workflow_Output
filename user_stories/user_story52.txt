Title: Localized Notification Templates and Delivery Status Tracking

User Story:
As an admin, I want notification templates to be localized and delivery status to be tracked so that users receive messages in their preferred language and delivery issues are visible.

Acceptance Criteria:
- Scenario: Notification sent in user's preferred language
  Given a user has set a language preference
  When a notification is sent
  Then the template is localized accordingly

- Scenario: Delivery status is tracked
  Given a notification is sent
  When the admin reviews delivery logs
  Then the status (delivered, failed, pending) is visible for each channel

Additional Details:
- Templates must support multiple languages
- Delivery logs must be filterable by user, channel, and status
- All delivery failures must trigger alerts to admins
