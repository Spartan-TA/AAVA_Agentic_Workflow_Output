Title: Track Onboarding/Offboarding Progress

User Story: As an HR manager I want to track the progress of onboarding and offboarding workflows so that I can ensure all tasks are completed on time

Acceptance Criteria:
Scenario: Monitoring workflow progress
Given onboarding or offboarding is in progress
When I view the workflow dashboard
Then I see the status of each task and receive alerts for overdue items

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Task management, notification module
- Notes: Dashboard should support filtering by location, role, and status.
