Title: Distributed Tracing with Jaeger/Zipkin

User Story: As a platform engineer I want distributed tracing enabled across all services So that I can diagnose performance bottlenecks and failures

Acceptance Criteria:
Scenario: Trace propagation
Given a request flows through multiple services
When tracing is enabled
Then the trace is visible end-to-end in Jaeger or Zipkin

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Service mesh, logging
- Notes: Instrument all major flows
