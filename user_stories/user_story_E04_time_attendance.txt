Title: Clock In/Out Event Capture

User Story: As a Warehouse Worker I want to clock in and out using my device So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock in
Given I am at the warehouse
When I clock in using the app
Then my clock-in time and location should be recorded

Scenario: Clock out
Given I am clocked in
When I clock out
Then my clock-out time and location should be recorded

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD APIs (E02), RBAC (E03)
- Notes: Capture device info

Title: Geofence Validation for Attendance

User Story: As a Supervisor I want to ensure clock-in/out events occur within the warehouse geofence So that only valid attendance is recorded

Acceptance Criteria:
Scenario: Geofence validation
Given a clock-in request
When the device location is outside the geofence
Then the clock-in should be rejected

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock In/Out Event Capture
