Title: Employee Clock In/Out via Web/Mobile
User Story: As a warehouse employee, I want to clock in and out using the web or mobile app so that my working hours are accurately recorded.
Acceptance Criteria:
Scenario: Clock in event is recorded
Given I am logged in and my shift is scheduled for today
When I access the clock-in page and tap "Clock In"
Then my clock-in event is recorded with timestamp, device info, and (if enabled) geolocation

Scenario: Clock out event is recorded
Given I am clocked in
When I tap "Clock Out"
Then my clock-out event is recorded and my shift hours are calculated
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Device and geofence capture optional per config.

---

Title: Geofence Validation for Clock Events
User Story: As a supervisor, I want clock-in/out events to be validated against a geofence so that only on-premise attendance is accepted.
Acceptance Criteria:
Scenario: Geofence validation blocks off-site clock events
Given geofencing is enabled
When an employee attempts to clock in/out outside the defined geofence
Then the system rejects the event and displays an error message
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: US04.1
- Notes: Geofence coordinates configurable per warehouse.

---

Title: Automatic Shift Association & Hours Calculation
User Story: As a payroll admin, I want clock events to be automatically associated with scheduled shifts and hours calculated for payroll.
Acceptance Criteria:
Scenario: Clock events are associated with shifts
Given an employee clocks in/out
When the event is recorded
Then the system associates it with the correct shift and calculates total hours worked for the day
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E05
- Notes: Handles overnight shifts and split shifts.

---

Title: Missed Punches & Correction Workflow
User Story: As an employee, I want to request corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
Scenario: Correction request is submitted
Given I missed a clock-in or clock-out
When I submit a correction request
Then a task is created for supervisor approval and my hours are updated upon approval
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: US04.1, E03
- Notes: Correction requests visible in supervisor dashboard.

---

Title: Attendance Export (CSV)
User Story: As an admin, I want to export attendance data as CSV for reporting and payroll.
Acceptance Criteria:
Scenario: Attendance data is exported
Given I have attendance data for a date range
When I request an export
Then the system generates a CSV file with all relevant fields
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: US04.3
- Notes: Export includes employee, timestamps, shift, corrections.
