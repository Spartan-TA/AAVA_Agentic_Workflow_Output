EPIC E04: Time & Attendance (Clock In/Out)

---

Title: Time & Attendance (Clock In/Out) - Clock In/Out Events
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.

Acceptance Criteria:
Scenario: Clock in with valid data
  Given I am scheduled to work
  When I POST to /attendance/clock-in with my badgeId
  Then my clock-in event is recorded

Scenario: Clock out with valid data
  Given I am clocked in
  When I POST to /attendance/clock-out
  Then my clock-out event is recorded

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Core attendance flow

---

Title: Time & Attendance (Clock In/Out) - Geofence & Device Capture
User Story: As a supervisor, I want to capture geolocation and device info on clock events so that I can verify attendance authenticity.

Acceptance Criteria:
Scenario: Clock in with geofence
  Given geofence is enabled
  When I clock in outside allowed area
  Then the request is rejected

Scenario: Device info is logged
  Given I clock in/out
  When the event is recorded
  Then device info is stored with the event

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Optional geofence

---

Title: Time & Attendance (Clock In/Out) - Handle Missed Punches & Corrections
User Story: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.

Acceptance Criteria:
Scenario: Submit correction request
  Given I missed a clock event
  When I submit a correction
  Then an approval task is created for my supervisor

Scenario: Supervisor approves correction
  Given a correction is pending
  When supervisor approves
  Then attendance is updated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Ensures payroll accuracy

---

Title: Time & Attendance (Clock In/Out) - Attendance Reporting
User Story: As a payroll user, I want to export attendance reports so that payroll processing is efficient.

Acceptance Criteria:
Scenario: Export attendance as CSV
  Given attendance data exists
  When I request a report
  Then a CSV file is generated with daily totals

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Supports payroll
