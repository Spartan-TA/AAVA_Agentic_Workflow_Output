Title: Initialize Spring Boot Project

User Story: As a SYSTEM, I want to initialize a Spring Boot project with Maven so that the application has a standardized and maintainable foundation.

Acceptance Criteria:

Scenario 1: Successful Build
Given the repository is cloned
When I run `mvn clean install`
Then the project builds successfully without errors

Scenario 2: Health Check Endpoint
Given the application is started
When I access `http://localhost:8080/actuator/health`
Then I receive a status of "UP"

Scenario 3: Documentation Available
Given the project root
When I open the README
Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Use Spring Initializr, include Actuator dependency, document steps in README.
