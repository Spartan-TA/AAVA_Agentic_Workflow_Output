Title: Initialize Spring Boot Project Structure

User Story: As a developer, I want the project to be scaffolded with Spring Boot and Maven so that all modules have a consistent foundation.

Acceptance Criteria:

Scenario: Project builds and runs
Given the repository is cloned
When I run `mvn spring-boot:run`
Then the application starts on port 8080

Scenario: Health endpoint returns UP
Given the application is running
When I GET `/actuator/health`
Then the response status is 200 and body contains `"status":"UP"`

Additional Details:
- Priority: High

- Dependencies: None
- Notes: README must include build/run steps.
