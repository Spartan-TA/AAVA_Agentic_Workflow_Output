Title: Project Scaffolding & Domain Setup - Initialize Project Repository

User Story: As a developer, I want to initialize a Spring Boot project repository with standardized structure so that all modules can be developed consistently and efficiently.

Acceptance Criteria:
Scenario: Project repository is initialized
  Given a new project repository
  When I clone and build the project
  Then it should build successfully on port 8080
  And the README should contain build and run instructions
  And the base package structure should be present
  And the Actuator health endpoint should return UP
  And Flyway/Liquibase should run the baseline migration

Additional Details:
Priority: High
Story Points: 5
Dependencies: None
Notes: Foundation for all subsequent modules; must be completed before feature development.
