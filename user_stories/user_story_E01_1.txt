Title: Initialize Spring Boot Project Structure

User Story: As a DEVELOPER, I want a standardized Spring Boot project scaffold So that all modules follow a consistent structure and onboarding is faster.

Acceptance Criteria:

Scenario: Successful build
Given the repository is cloned
When I run `mvn clean install`
Then the build should succeed without errors

Scenario: Health check endpoint
Given the application is started
When I access `http://localhost:8080/actuator/health`
Then the status should be "UP"

Scenario: README instructions
Given the project README
When I follow the build and run steps
Then the application starts successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Foundation for all other modules
