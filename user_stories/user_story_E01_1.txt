Title: Initialize Spring Boot Project

User Story: As a System Administrator I want to initialize a Spring Boot (Maven) project with standardized base packages So that all modules have a consistent foundation and build process

Acceptance Criteria:
Scenario: Project initialization
  Given I have access to the repository
  When I run the build command
  Then the project builds and runs on port 8080
Scenario: Base package structure
  Given the project is initialized
  When I inspect the source code
  Then the base package structure is present for employee, scheduling, attendance, and safety modules
Scenario: Documentation
  Given the project is initialized
  When I open the README file
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: Ensure Maven configuration and directory structure are standardized
