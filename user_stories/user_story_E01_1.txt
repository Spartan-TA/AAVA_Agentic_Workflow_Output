Title: Project Initialization and Build Verification

User Story: As a developer I want to initialize the Spring Boot project with Maven and verify it builds and runs on port 8080 So that the team has a reliable foundation for further development

Acceptance Criteria:
Scenario: Project builds and runs
Given the project repository is cloned
When I run the build and start the application
Then the application starts on port 8080 and the Actuator health endpoint returns UP

Scenario: Baseline migration runs
Given the database is empty
When the application starts
Then Flyway/Liquibase applies the baseline migration successfully

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: None
- Notes: README must include build/run steps
