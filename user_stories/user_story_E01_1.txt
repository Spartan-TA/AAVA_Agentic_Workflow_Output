Title: Initialize Spring Boot Project

User Story: As a System Administrator I want to initialize a Spring Boot (Maven) project with standardized base packages so that all modules can be developed consistently and efficiently.

Acceptance Criteria:
Scenario: Project initialization
Given I have access to the repository
When I run the build and start the application
Then the application should run on port 8080 and the base package structure should be present

Scenario: Documentation availability
Given the repository is cloned
When I open the README file
Then I should see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure Maven wrapper is included and README is up to date.
