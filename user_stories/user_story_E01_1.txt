Title: Initialize Spring Boot Project with Standard Structure

User Story: As a developer, I want a Spring Boot project scaffolded with Maven and a standardized package structure so that all modules follow consistent conventions.

Acceptance Criteria:

Scenario: Successful project build
Given a fresh clone
When I run `mvn clean install`
Then the project builds successfully and runs on port 8080

Scenario: Package structure validation
Given the project
When I inspect the source
Then I see base packages for employee, scheduling, attendance, and safety modules

Scenario: README instructions
Given the README
When I follow the build/run instructions
Then I can start the application without errors

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Foundation for all other modules
