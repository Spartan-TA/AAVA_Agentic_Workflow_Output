Title: Employee CRUD - Create Employee

User Story: As an HR user I want to create a new employee record with all required fields So that employee data is accurately captured

Acceptance Criteria:
Scenario: Create employee
Given valid employee details
When I POST to /employees
Then a new employee is created with a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: badgeId must be unique

---

Title: Employee CRUD - Update Employee

User Story: As an HR user I want to update employee details So that records remain current

Acceptance Criteria:
Scenario: Update employee
Given an existing employee
When I PATCH employee details
Then the changes are saved and reflected in GET responses

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: PATCH supports partial updates

---

Title: Employee CRUD - Delete (Soft Delete)

User Story: As an HR user I want to soft-delete an employee So that historical data is preserved

Acceptance Criteria:
Scenario: Soft-delete employee
Given an active employee
When I DELETE the employee
Then the status is set to inactive and record is not removed from DB

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01
- Notes: Soft-deleted employees are excluded from active lists

---

Title: Employee CRUD - List & Filter

User Story: As an HR user I want to list and filter employees by department, role, or status So that I can quickly find relevant records

Acceptance Criteria:
Scenario: Filter employees
Given multiple employees exist
When I GET /employees with filters
Then only matching employees are returned with pagination

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01
- Notes: Supports pagination and filtering
