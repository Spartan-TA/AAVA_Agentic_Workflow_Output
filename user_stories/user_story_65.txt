Title: Lighthouse PWA Score Validation

User Story: As a QA engineer I want the mobile application to achieve a Lighthouse PWA score of at least 80 so that we ensure a high-quality, performant, and reliable user experience

Acceptance Criteria:
Scenario: Running Lighthouse audit
Given the PWA is deployed to staging
When I run a Lighthouse audit
Then the PWA score is 80 or higher and all core flows pass

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: QA automation, PWA framework
- Notes: Failing the score threshold must block release
