Title: Webhooks for Event Notifications

User Story: As a system integrator I want the EMS to send webhooks for key events (new hire, termination, schedule change) so that downstream systems can react in real time.

Acceptance Criteria:
Scenario: Event webhook delivery
Given a key event occurs in the EMS
When the webhook endpoint is configured
Then a POST request should be sent with event details and delivery status tracked

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project Scaffolding (E01), Employee Master Data (E02), RBAC (E03)
- Notes: Webhooks must be idempotent and retry on failure.
