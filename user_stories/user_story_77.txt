Title: Distributed Tracing and Dashboard Setup

User Story: As a DevOps engineer I want distributed tracing and Grafana dashboards configured so that I can visualize request flows and system health across services

Acceptance Criteria:
Scenario: Visualizing distributed traces
Given distributed tracing is enabled
When I view the Grafana dashboard
Then I can see traces for requests, error rates, and latency across all services

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: OpenTelemetry, Grafana, logging/metrics stack
- Notes: Dashboards must be accessible to the operations team
