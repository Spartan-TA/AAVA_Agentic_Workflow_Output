Title: Webhooks for Event Notifications

User Story: As a developer I want to receive webhook notifications for key events so that external systems can react to changes in real time

Acceptance Criteria:
Scenario: Receiving webhook on employee update
Given a webhook endpoint is registered
When an employee record is updated
Then a POST request with event details is sent to the endpoint and duplicate events are not sent

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Webhook service, event bus
- Notes: Webhooks must be idempotent and retry on failure
