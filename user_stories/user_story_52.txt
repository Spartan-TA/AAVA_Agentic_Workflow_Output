Title: Mobile Leave Request and Announcement Viewing

User Story: As a warehouse worker I want to request leave and view company announcements from my mobile device so that I can stay informed and manage my time off easily.

Acceptance Criteria:
Scenario: Requesting leave on mobile
Given I am logged in on a mobile device
When I submit a leave request or view announcements
Then the system should process my request and display announcements in a mobile-optimized format

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E12
- Notes: Leave requests should be available offline and sync when online.
