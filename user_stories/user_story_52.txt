Title: Role-Based Dashboards and BI Metrics Endpoints

User Story: As an executive I want to view key workforce and safety KPIs on a dashboard and access metrics endpoints so that I can monitor performance and feed data into BI tools

Acceptance Criteria:
Scenario: Dashboard and metrics endpoint access
  Given I have the appropriate role
  When I access the dashboard or metrics API
  Then I see only the KPIs and data permitted for my role and can retrieve metrics for BI integration

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E07, E08, E14
- Notes: Metrics endpoints must be documented and secured; dashboards configurable per role.
