Title: Export and Filter Audit Logs

User Story: As an auditor I want to export audit logs by date, user, or entity so that I can efficiently review compliance and investigate incidents

Acceptance Criteria:
Scenario: Export filtered audit log
  Given audit logs are stored in the system
  When I filter by date, user, or entity and export
  Then I receive a file with all matching log entries

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03 (Scheduling)
- Notes: Export format must be CSV or PDF
