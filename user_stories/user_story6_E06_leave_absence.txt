# Epic E06: Leave & Absence Management

## User Story 1: Request Leave (PTO, Sick, Unpaid)
**Title:** Employees Request Leave  
**Narrative:** As an employee, I want to request PTO, sick, or unpaid leave so that my absences are tracked.  
**Acceptance Criteria (Gherkin):**
```
Given my employee profile
When I submit a leave request
Then the request is recorded and pending approval
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E02, E03, E05  
**Notes:** Validate accrual balances.

---

## User Story 2: Approve/Deny Leave Requests
**Title:** Supervisors Approve/Deny Leave  
**Narrative:** As a supervisor, I want to approve or deny leave requests so that staffing is managed.  
**Acceptance Criteria (Gherkin):**
```
Given a pending leave request
When I approve or deny
Then the employee is notified
And balances are updated if approved
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E06  
**Notes:** Track approval history.

---

## User Story 3: Update Accrual Balances
**Title:** Update Leave Accrual Balances  
**Narrative:** As an HR user, I want leave balances to update automatically so that records are accurate.  
**Acceptance Criteria (Gherkin):**
```
Given an approved leave
When the leave period starts
Then accrual balances are deducted accordingly
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E06  
**Notes:** Support multiple leave types.

---

## User Story 4: Exclude Approved Leaves from Scheduling
**Title:** Exclude Approved Leaves from Scheduling  
**Narrative:** As a scheduler, I want approved leaves to flag scheduled shifts for coverage so that staffing gaps are filled.  
**Acceptance Criteria (Gherkin):**
```
Given an approved leave
When I view the schedule
Then affected shifts are flagged for coverage
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E05, E06  
**Notes:** Integrate with shift assignment.

---

## User Story 5: Export Leave Reports
**Title:** Export Approved Leaves  
**Narrative:** As an HR user, I want to export approved leave records so that compliance and payroll are supported.  
**Acceptance Criteria (Gherkin):**
```
Given leave data
When I request an export
Then a report is generated with all approved leaves
```
**Priority:** Medium  
**Story Points:** 1  
**Dependencies:** E06  
**Notes:** Include filters for date, employee, type.
