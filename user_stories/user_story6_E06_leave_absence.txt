Epic E06: Leave & Absence Management

---

User Story 1: Request Leave
As a worker, I want to request PTO, sick, or unpaid leave so that my time off is tracked.

Acceptance Criteria:
Scenario: Leave request
  Given I am eligible
  When I submit a leave request
  Then it is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Accrual balances checked

---

User Story 2: Approve/Deny Leave
As a supervisor, I want to approve or deny leave requests so that staffing is managed.

Acceptance Criteria:
Scenario: Leave approval
  Given a pending request
  When I approve or deny
  Then the request status is updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Approval workflow logged

---

User Story 3: Update Accrual Balances
As HR, I want leave balances to update automatically so that records are accurate.

Acceptance Criteria:
Scenario: Accrual update
  Given approved leave
  When leave is taken
  Then accrual balance decreases

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Policies configurable

---

User Story 4: Exclude from Scheduling and Payroll
As payroll, I want approved leaves to exclude employees from scheduling and payroll hours so that calculations are correct.

Acceptance Criteria:
Scenario: Exclusion from schedule
  Given approved leave
  When schedules are generated
  Then employee is flagged for coverage

Scenario: Payroll exclusion
  Given approved unpaid leave
  When payroll is exported
  Then hours are excluded

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Integration hooks required

---

User Story 5: Leave Export
As HR, I want to export approved leaves so that records can be shared with payroll.

Acceptance Criteria:
Scenario: Export leaves
  Given approved leave data
  When I request an export
  Then a file is generated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Export format configurable
