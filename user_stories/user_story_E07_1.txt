Title: Certification Management CRUD

User Story: As a Training Coordinator I want to create, update, and delete employee certifications so that I can ensure accurate tracking of required qualifications for warehouse roles

Acceptance Criteria:
Scenario: Add certification
Given an employee profile exists
When I add a new certification with type, issue date, and expiry date
Then the certification appears in the employee's profile and is tracked for expiry

Scenario: Update certification
Given a certification exists for an employee
When I update the expiry date or upload a new proof document
Then the changes are saved and visible on the profile

Scenario: Delete certification
Given a certification exists for an employee
When I delete the certification
Then it is removed from the employee's profile and audit log records the deletion

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee Master Data (E02), RBAC (E03)
- Notes: Certification types should be configurable; deletion must be logged for compliance
