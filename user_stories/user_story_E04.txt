[E04] Time & Attendance (Clock In/Out)

User Story 1
Title: Implement Clock-In/Clock-Out Endpoints

User Story: As a worker, I want to clock in and out via API so that my attendance is recorded.

Acceptance Criteria:
Scenario: Clock-in/out event
Given a valid employee
When I POST to /attendance/clock-in or /clock-out
Then the event is recorded with timestamp

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02,E03
- Notes: Device and location info captured

User Story 2
Title: Associate Attendance with Shifts

User Story: As a system, I want to automatically associate clock events with scheduled shifts so that hours are calculated correctly.

Acceptance Criteria:
Scenario: Shift association
Given a clock-in event
When the shift matches the time
Then the event is linked to the correct shift

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04-1
- Notes: Handles overnight shifts

User Story 3
Title: Handle Missed Punches and Corrections

User Story: As a supervisor, I want to approve corrections for missed punches so that attendance data is accurate.

Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch
When an employee submits a correction
Then an approval task is created for the supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04-1
- Notes: Correction history tracked

User Story 4
Title: Calculate Daily Hours Worked

User Story: As a payroll system, I want to compute total hours worked per shift so that payroll is accurate.

Acceptance Criteria:
Scenario: Daily totals computed
Given clock-in/out events for a day
When I request the daily report
Then total hours are calculated per employee

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04-2
- Notes: Handles overtime and breaks

User Story 5
Title: Export Attendance Reports

User Story: As an admin, I want to export attendance data as CSV so that I can analyze and share reports.

Acceptance Criteria:

Then a CSV file is generated with all relevant fields

Additional Details:
- Priority: High
- Story Points: 1
