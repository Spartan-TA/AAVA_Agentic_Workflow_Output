### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint
User Story: As a worker, I want to clock in via an endpoint with optional geofence and device capture So that my attendance is accurately recorded.
Acceptance Criteria:
- Given valid credentials, When I POST to `/attendance/clock-in`, Then my clock-in event is recorded with location/device info.
- Given missing location/device, When geofence is required, Then validation fails.
Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Geofence optional.

**User Story 2**
Title: Clock-Out Endpoint
User Story: As a worker, I want to clock out via an endpoint So that my shift end is recorded.
Acceptance Criteria:
- Given a clock-in, When I POST to `/attendance/clock-out`, Then my clock-out event is recorded and shift duration calculated.
Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Duration calculation.

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a supervisor, I want to manage missed punches and corrections So that attendance records are accurate.
Acceptance Criteria:
- Given a missed punch, When a correction is submitted, Then an approval task is created for supervisor.
- Given approval, When correction is accepted, Then attendance record updates.
Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Approval workflow.

**User Story 4**
Title: Attendance Reporting
User Story: As an HR user, I want to export attendance reports in CSV So that payroll processing is supported.
Acceptance Criteria:
- Given attendance data, When I request a report, Then a CSV file is generated with daily totals.
Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Export format.
