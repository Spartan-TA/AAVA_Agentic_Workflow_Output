### E04: Time & Attendance (Clock In/Out)

#### 1. Implement Clock-In/Clock-Out Endpoints
User Story: As a warehouse worker I want to clock in and out via API So that my work hours are accurately recorded
Acceptance Criteria:
Scenario: Clock-in event
Given I am scheduled for a shift
When I POST to /attendance/clock-in
Then my clock-in time is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate shift assignment

#### 2. Capture Device and Location Data
User Story: As a supervisor I want clock events to capture device and (optionally) geofence location So that I can verify attendance authenticity
Acceptance Criteria:
Scenario: Device/location capture
Given I clock in from a device
When the event is recorded
Then device ID and location (if available) are stored with the event
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Geofence optional, configurable

#### 3. Handle Missed Punches and Corrections
User Story: As a worker I want to request corrections for missed punches So that my attendance is accurate for payroll
Acceptance Criteria:
Scenario: Missed punch correction
Given I missed a clock-out
When I submit a correction request
Then an approval task is created for my supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Attendance endpoints
- Notes: Correction workflow with audit trail

#### 4. Calculate Hours Worked per Shift
User Story: As a payroll admin I want hours worked to be calculated per shift So that payroll is accurate
Acceptance Criteria:
Scenario: Hours calculation
Given clock-in and clock-out events exist
When I view the attendance report
Then total hours per shift are computed and visible
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Handle overnight shifts

#### 5. Export Attendance Reports
User Story: As a supervisor I want to export attendance data as CSV So that I can analyze and share reports
Acceptance Criteria:
Scenario: CSV export
Given attendance data exists
When I request an export
Then a CSV file is generated with all relevant fields
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Include filters for date range, employee
