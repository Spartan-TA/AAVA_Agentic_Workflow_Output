### E04 - Time & Attendance (Clock In/Out)

#### User Story 1
Title: Clock-In Event Recording
User Story: As a WORKER, I want to clock in with device and optional geofence so that my attendance is accurately captured.
Acceptance Criteria:
Scenario: Valid Clock-In
Given a WORKER at the warehouse
When they submit a clock-in event
Then the event is recorded with device and location
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validation required

#### User Story 2
Title: Clock-Out Event Recording
User Story: As a WORKER, I want to clock out so that my shift hours are tracked.
Acceptance Criteria:
Scenario: Valid Clock-Out
Given a WORKER who has clocked in
When they submit a clock-out event
Then the event is recorded and hours are calculated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Automatic shift association

#### User Story 3
Title: Missed Punch Correction Workflow
User Story: As a SUPERVISOR, I want to handle missed punches and corrections so that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction Request
Given a missed punch
When a correction is submitted
Then an approval task is created
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Approval workflow required

#### User Story 4
Title: Attendance Reporting
User Story: As an HR, I want to export attendance reports in CSV so that payroll processing is streamlined.
Acceptance Criteria:
Scenario: Report Export
Given attendance data
When HR requests export
Then a CSV file is generated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Daily totals computed
