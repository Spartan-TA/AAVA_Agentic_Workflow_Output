### E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Clock-in/out events recorded
  Given a worker is authenticated
  When they POST to /attendance/clock-in or /clock-out
  Then the event is validated and stored
Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Core attendance.

**User Story 2**
Title: Associate Attendance with Shifts Automatically
User Story: As a worker, I want my clock-in/out events to be linked to my scheduled shift so that hours are calculated correctly.
Acceptance Criteria:
Scenario: Shift association
  Given a clock-in event
  When the event is processed
  Then it is linked to the correct shift
Additional Details: Priority: High, Story Points: 2, Dependencies: E04-1, E05, Notes: Accurate payroll.

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a supervisor, I want to manage missed punches and approve corrections so that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction workflow
  Given a missed punch is reported
  When a correction is submitted
  Then an approval task is created for the supervisor
Additional Details: Priority: High, Story Points: 3, Dependencies: E04-1, Notes: Compliance.

**User Story 4**
Title: Calculate Daily Totals for Hours Worked
User Story: As a payroll admin, I want daily totals of hours worked per employee so that payroll is accurate.
Acceptance Criteria:
Scenario: Daily totals computed
  Given attendance records
  When I request daily totals
  Then the system returns accurate hours per employee
Additional Details: Priority: High, Story Points: 2, Dependencies: E04-2, Notes: Payroll integration.

**User Story 5**
Title: Export Attendance Reports (CSV)
User Story: As a supervisor, I want to export attendance data as CSV so that I can analyze and share records.
Acceptance Criteria:
Scenario: CSV export
  Given attendance data exists
  When I request an export
  Then a CSV file is generated with the correct data
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E04-4, Notes: Reporting.
