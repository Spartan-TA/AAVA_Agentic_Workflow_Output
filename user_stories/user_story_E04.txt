### E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint with Geofence
User Story: As a WORKER I want to clock in with geolocation So that attendance is accurate and location-verified
Acceptance Criteria:
Scenario: Valid clock-in
Given I am within the geofence
When I POST to `/attendance/clock-in` with my location
Then my clock-in is recorded
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Returns 400 if outside geofence

**User Story 2**
Title: Clock-Out Endpoint with Device Capture
User Story: As a WORKER I want to clock out using my device So that my shift end is accurately recorded
Acceptance Criteria:
Scenario: Valid clock-out
Given I am clocked in
When I POST to `/attendance/clock-out`
Then my clock-out is recorded and hours are calculated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Device ID must be logged

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records are accurate
Acceptance Criteria:
Scenario: Missed punch correction
Given a worker missed a clock-in
When a correction is submitted
Then a supervisor receives an approval task
And upon approval, attendance is updated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Correction history is auditable

**User Story 4**
Title: Export Attendance Reports
User Story: As an ADMIN I want to export attendance data as CSV So that I can process payroll
Acceptance Criteria:
Scenario: Export report
Given attendance data exists
When I request an export
Then a CSV file is generated with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export includes all relevant fields
