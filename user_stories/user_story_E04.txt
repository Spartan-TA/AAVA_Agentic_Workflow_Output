### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In/Clock-Out Endpoints  
User Story: As a WORKER, I want to clock in and out via API so that my attendance is recorded accurately.  
Acceptance Criteria:  
Scenario: Clock-In/Out  
Given the attendance API  
When I POST to /attendance/clock-in or /clock-out  
Then my event is validated and recorded  
Additional Details:  
- Priority: High  
- Story Points: 5  
- Dependencies: E02, E03  
- Notes: Device and geofence optional

**User Story 2**
Title: Automatic Shift Association  
User Story: As a WORKER, I want my clock-in/out events to be automatically associated with my scheduled shift so that hours worked are calculated correctly.  
Acceptance Criteria:  
Scenario: Shift Association  
Given a scheduled shift  
When I clock in/out  
Then the event is linked to the shift  
Additional Details:  
- Priority: High  
- Story Points: 3  
- Dependencies: E02, E03  
- Notes: Handles overlapping shifts

**User Story 3**
Title: Missed Punches and Corrections Workflow  
User Story: As a SUPERVISOR, I want to handle missed punches and corrections so that attendance records are accurate.  
Acceptance Criteria:  
Scenario: Correction Workflow  
Given a missed punch  
When a correction is submitted  
Then an approval task is created  
Additional Details:  
- Priority: High  
- Story Points: 5  
- Dependencies: E02, E03  
- Notes: Approval workflow required

**User Story 4**
Title: Export Attendance Reports  
User Story: As an HR user, I want to export attendance reports in CSV format so that payroll processing is streamlined.  
Acceptance Criteria:  
Scenario: Report Export  
Given attendance data  
When I request a CSV export  
Then the report is generated and downloadable  
Additional Details:  
- Priority: High  
- Story Points: 3  
- Dependencies: E02, E03  
- Notes: Export includes daily totals
