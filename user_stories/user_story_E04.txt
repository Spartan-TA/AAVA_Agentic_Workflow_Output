### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint with Validation
User Story: As a WORKER I want to clock in via API with device and optional geofence So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Clock-in
Given I am a valid employee
When I POST to /attendance/clock-in with required data
Then My clock-in is recorded with timestamp and device info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence optional

**User Story 2**
Title: Clock-Out Endpoint and Shift Association
User Story: As a WORKER I want to clock out and have my shift automatically associated So that my work hours are tracked
Acceptance Criteria:
Scenario: Clock-out
Given I am clocked in
When I POST to /attendance/clock-out
Then My clock-out is recorded and shift hours are calculated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04-1
- Notes: Handle overnight shifts

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records are accurate
Acceptance Criteria:
Scenario: Missed punch correction
Given A worker missed a punch
When A correction is submitted
Then An approval task is created for supervisor review
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E04-1
- Notes: Correction workflow

**User Story 4**
Title: Export Attendance Reports
User Story: As an HR user I want to export attendance data as CSV So that I can process payroll
Acceptance Criteria:
Scenario: Export report
Given Attendance data exists
When I request an export
Then I receive a CSV file with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04-2
- Notes: Include filters
