### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint with Validation
User Story: As a WORKER I want to clock in via an endpoint with device and optional geofence capture So that attendance is accurately recorded.
Acceptance Criteria:
Scenario: Clock-In Event
Given a valid worker and device
When I POST /attendance/clock-in
Then the event is validated and recorded

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Device and geofence optional

**User Story 2**
Title: Clock-Out Endpoint with Validation
User Story: As a WORKER I want to clock out via an endpoint So that my shift hours are tracked.
Acceptance Criteria:
Scenario: Clock-Out Event
Given a valid worker and device
When I POST /attendance/clock-out
Then the event is validated and recorded

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Shift association automatic

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction Workflow
Given a missed punch
When a correction is submitted
Then an approval task is created for supervisor

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: User Story 1, User Story 2
- Notes: Approval workflow required

**User Story 4**
Title: Attendance Reports Exportable (CSV)
User Story: As an HR I want to export attendance reports in CSV format So that payroll processing is simplified.
Acceptance Criteria:
Scenario: Attendance Export
Given attendance data exists
When I request a CSV export
Then the file is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Export includes corrections
