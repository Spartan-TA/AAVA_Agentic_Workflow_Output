### EPIC E04 - Time & Attendance (Clock In/Out)

**User Story 1**

Title: Clock-In Endpoint with Validation

User Story: As a worker, I want to clock in using an endpoint with validation so that my attendance is accurately recorded.

Acceptance Criteria:
Scenario: Clock-In Event
Given a valid badgeId and location
When I POST to /attendance/clock-in
Then my clock-in event is recorded with timestamp and device info

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence validation optional

---

**User Story 2**

Title: Clock-Out Endpoint with Shift Association

User Story: As a worker, I want to clock out and have my shift automatically associated so that hours worked are calculated correctly.

Acceptance Criteria:
Scenario: Clock-Out Event
Given a valid clock-in event
When I POST to /attendance/clock-out
Then my shift is closed and hours worked are computed

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Device capture required

---

**User Story 3**

Title: Missed Punch Correction Workflow

User Story: As a supervisor, I want to handle missed punches and corrections through an approval workflow so that attendance records are accurate.

Acceptance Criteria:
Scenario: Correction Request
Given a missed punch event
When a correction is submitted
Then an approval task is created for supervisor review

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Corrections must be auditable

---

**User Story 4**

Title: Daily Attendance Totals Calculation

User Story: As a payroll administrator, I want daily totals to be computed for each employee so that payroll processing is streamlined.

Acceptance Criteria:
Scenario: Daily Totals
Given attendance events for a day
When totals are calculated
Then hours worked per shift are available for export

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Totals must exclude unapproved corrections

---

**User Story 5**

Title: Attendance Report Export (CSV)

User Story: As a payroll administrator, I want to export attendance reports in CSV format so that data can be integrated with payroll systems.

Acceptance Criteria:
Scenario: Report Export
Given attendance data
When I request a CSV export
Then the file is generated and available for download

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Export must include all relevant fields
