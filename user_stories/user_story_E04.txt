### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
- Title: Clock In Endpoint
- User Story: As a WORKER I want to clock in at the start of my shift So that my attendance is recorded
- Acceptance Criteria:
  - Given a valid request, When I POST to /attendance/clock-in, Then my clock-in is recorded with timestamp and device info
  - Given an invalid request, When I POST, Then I receive a validation error
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03

**User Story 2**
- Title: Clock Out Endpoint
- User Story: As a WORKER I want to clock out at the end of my shift So that my hours are tracked
- Acceptance Criteria:
  - Given a valid request, When I POST to /attendance/clock-out, Then my clock-out is recorded and shift hours are calculated
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03

**User Story 3**
- Title: Handle Missed Punches and Corrections
- User Story: As a SUPERVISOR I want to approve corrections for missed punches So that attendance data is accurate
- Acceptance Criteria:
  - Given a missed punch, When a correction is submitted, Then an approval task is created
  - Given a supervisor, When I approve/deny, Then the attendance record is updated accordingly
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03

**User Story 4**
- Title: Attendance Reporting and Export
- User Story: As an HR I want to export attendance reports in CSV So that payroll can process hours
- Acceptance Criteria:
  - Given attendance data, When I request export, Then a CSV file is generated with daily totals
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03
