## E04: Time & Attendance (Clock In/Out)

**User Story 1**  
Title: Clock-In Endpoint  
User Story: As a Worker, I want to clock in via an endpoint so that my attendance is recorded.  
Acceptance Criteria:  
Scenario: Clock-in  
Given my badgeId and location  
When I POST to /attendance/clock-in  
Then my clock-in is validated and recorded  
Additional Details:  
Priority: High  
Story Points: 3  
Dependencies: E02, E03  
Notes: Optional geofence validation.

**User Story 2**  
Title: Clock-Out Endpoint  
User Story: As a Worker, I want to clock out via an endpoint so that my shift is completed.  
Acceptance Criteria:  
Scenario: Clock-out  
Given my badgeId  
When I POST to /attendance/clock-out  
Then my clock-out is validated and recorded  
Additional Details:  
Priority: High  
Story Points: 3  
Dependencies: E02, E03  
Notes: Device capture required.

**User Story 3**  
Title: Missed Punch Correction Workflow  
User Story: As a Supervisor, I want to handle missed punches and corrections so that attendance records are accurate.  
Acceptance Criteria:  
Scenario: Correction request  
Given a missed punch  
When a correction is submitted  
Then an approval task is created  
Additional Details:  
Priority: High  
Story Points: 5  
Dependencies: E02, E03  
Notes: Approval workflow must be auditable.

**User Story 4**  
Title: Attendance Reporting  
User Story: As an HR user, I want to export attendance reports in CSV so that payroll processing is streamlined.  
Acceptance Criteria:  
Scenario: Report export  
Given attendance data  
When I request a CSV export  
Then the report is generated and downloadable  
Additional Details:  
Priority: High  
Story Points: 2  
Dependencies: E02, E03  
Notes: Daily totals computed automatically.
