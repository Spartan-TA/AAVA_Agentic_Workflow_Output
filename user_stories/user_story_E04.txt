### E04: Time & Attendance (Clock In/Out)

**User Story 1**
- **Title:** Clock In Endpoint
- **User Story:** As a worker, I want to clock in at the start of my shift so that my attendance is recorded.
- **Acceptance Criteria:**
    - Scenario: Valid clock-in
      - Given I am scheduled for a shift
      - When I POST to `/attendance/clock-in` with my badgeId
      - Then my clock-in event is recorded with timestamp and device info
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Optionally capture geofence.

**User Story 2**
- **Title:** Clock Out Endpoint
- **User Story:** As a worker, I want to clock out at the end of my shift so that my work hours are tracked.
- **Acceptance Criteria:**
    - Scenario: Valid clock-out
      - Given I am clocked in
      - When I POST to `/attendance/clock-out`
      - Then my clock-out event is recorded and hours worked are calculated
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: User Story 1, Notes: Validate clock-in exists.

**User Story 3**
- **Title:** Handle Missed Punches and Corrections
- **User Story:** As a supervisor, I want to correct missed punches so that attendance records are accurate.
- **Acceptance Criteria:**
    - Scenario: Correction workflow
      - Given a missed punch is detected
      - When a correction is submitted
      - Then an approval task is created for supervisor review
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: User Story 1, Notes: Track correction history.

**User Story 4**
- **Title:** Attendance Reports Export
- **User Story:** As an HR user, I want to export attendance data so that I can process payroll.
- **Acceptance Criteria:**
    - Scenario: Export CSV
      - Given attendance data exists
      - When I request an export
      - Then a CSV file is generated with daily totals
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: User Story 1, Notes: Include shift association.

**User Story 5**
- **Title:** Automatic Shift Association
- **User Story:** As a worker, I want my clock-in/out events linked to my scheduled shift so that hours are correctly attributed.
- **Acceptance Criteria:**
    - Scenario: Shift association
      - Given I clock in during my scheduled shift
      - When the event is recorded
      - Then it is linked to the correct shift
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: E05, Notes: Handle overlapping shifts.
