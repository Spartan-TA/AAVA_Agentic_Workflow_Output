### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Valid clock-in
Given a scheduled shift
When I POST to /attendance/clock-in with my badgeId
Then my clock-in event is recorded and associated with my shift
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Validate badgeId and shift association.

**User Story 2**
Title: Calculate Hours Worked Per Shift
User Story: As a supervisor, I want the system to calculate hours worked per shift so that payroll is accurate.
Acceptance Criteria:
Scenario: Shift total calculation
Given clock-in and clock-out events
When the shift ends
Then total hours worked are computed and stored
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Handle overnight shifts.

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a worker, I want to request corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
Scenario: Missed punch correction
Given a missed clock-in
When I submit a correction request
Then an approval task is created for my supervisor
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Track correction status.

**User Story 4**
Title: Export Attendance Reports
User Story: As an admin, I want to export attendance data as CSV so that I can analyze attendance trends.
Acceptance Criteria:
Scenario: CSV export
Given attendance records
When I request an export
Then a CSV file is generated with all relevant fields
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Include filters for date range and employee.
