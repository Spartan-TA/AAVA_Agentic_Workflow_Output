### E04 - Time & Attendance (Clock In/Out)

**User Story 1: Clock-In Event**
- Title: Record Clock-In Event
- User Story: As a warehouse worker, I want to clock in with device and optional geofence so that my attendance is accurately recorded.
- Acceptance Criteria:
  - Given the clock-in endpoint,
    When I submit with valid device and location,
    Then my clock-in is recorded and shift is associated.
  - Given invalid location,
    When I submit,
    Then the clock-in is rejected.
- Additional Details: Priority: High, Story Points: 5, Dependencies: E02, E03, Notes: Geofence optional.

**User Story 2: Clock-Out Event**
- Title: Record Clock-Out Event
- User Story: As a warehouse worker, I want to clock out so that my hours worked are calculated.
- Acceptance Criteria:
  - Given the clock-out endpoint,
    When I submit,
    Then my clock-out is recorded and daily totals are computed.
  - Given missing clock-in,
    When I clock out,
    Then a missed punch is flagged.
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Handles missed punches.

**User Story 3: Missed Punch Correction**
- Title: Submit Correction for Missed Punch
- User Story: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.
- Acceptance Criteria:
  - Given a missed punch,
    When I submit a correction,
    Then an approval task is created for supervisor.
  - Given supervisor approval,
    When correction is reviewed,
    Then attendance is updated.
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Approval workflow.

**User Story 4: Attendance Reporting**
- Title: Export Attendance Reports
- User Story: As a supervisor, I want to export attendance reports in CSV so that records can be reviewed and shared.
- Acceptance Criteria:
  - Given the report endpoint,
    When I request export,
    Then a CSV file is generated with daily totals.
  - Given filters,
    When I apply,
    Then only relevant records are exported.
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Supports compliance.
