Epic E04: Time & Attendance (Clock In/Out)

1. Title: Implement Clock-In/Clock-Out Endpoints
   User Story: As a warehouse worker I want to clock in and out So that my working hours are accurately recorded.
   Acceptance Criteria:
   Scenario: Clock in/out event
   Given I am an active employee
   When I POST to /attendance/clock-in or /clock-out
   Then my attendance event is recorded with timestamp
   Additional Details:
   - Priority: High
   - Story Points: 3
   - Dependencies: E02, E03
   - Notes: Validate employee status.

2. Title: Capture Geofence and Device Info (Optional)
   User Story: As a supervisor I want clock events to capture location and device So that I can verify attendance authenticity.
   Acceptance Criteria:
   Scenario: Geofence/device capture
   Given geofence is enabled
   When a clock event is submitted
   Then location and device info are stored with the event
   Additional Details:
   - Priority: Medium
   - Story Points: 2
   - Dependencies: E02, E03
   - Notes: Optional feature.

3. Title: Calculate Hours Worked per Shift
   User Story: As a payroll manager I want hours worked per shift calculated So that payroll processing is accurate.
   Acceptance Criteria:
   Scenario: Shift hours calculation
   Given clock-in and clock-out events exist
   When daily totals are computed
   Then hours worked per shift are available for export
   Additional Details:
   - Priority: High
   - Story Points: 2
   - Dependencies: E02, E03
   - Notes: Handle overnight shifts.

4. Title: Handle Missed Punches and Corrections Workflow
   User Story: As a worker I want to request corrections for missed punches So that my attendance record is accurate.
   Acceptance Criteria:
   Scenario: Correction request
   Given a missed punch is detected
   When I submit a correction request
   Then an approval task is created for my supervisor
   Additional Details:
   - Priority: High
   - Story Points: 3
   - Dependencies: E02, E03
   - Notes: Approval workflow required.

5. Title: Export Attendance Reports (CSV)
   User Story: As a payroll manager I want to export attendance reports So that I can process payroll and audits.
   Acceptance Criteria:
   Scenario: Attendance report export
   Given attendance data exists
   When I request a CSV export
   Then a file is generated with daily totals and corrections
   Additional Details:
   - Priority: High
   - Story Points: 2
   - Dependencies: E02, E03
   - Notes: Include filters by date/employee.
