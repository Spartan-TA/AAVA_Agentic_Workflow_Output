### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Clock-In
Given I am scheduled for a shift
When I POST to /attendance/clock-in with valid credentials
Then my clock-in event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Device and optional geofence capture.

**User Story 2**
Title: Calculate Hours Worked Per Shift
User Story: As a supervisor, I want the system to calculate hours worked per shift so that payroll and compliance are accurate.
Acceptance Criteria:
Scenario: Shift Hours Calculation
Given a worker clocks in and out
When the shift ends
Then the total hours worked are computed and stored
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Handle overnight shifts.

**User Story 3**
Title: Handle Missed Punches and Corrections Workflow
User Story: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
Scenario: Missed Punch Correction
Given I missed clocking out
When I submit a correction request
Then an approval task is created for my supervisor
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Correction requests must be auditable.

**User Story 4**
Title: Export Attendance Reports
User Story: As an HR user, I want to export attendance reports as CSV so that I can analyze attendance data.
Acceptance Criteria:
Scenario: Attendance Report Export
Given attendance data exists
When I request a CSV export
Then the file is generated and matches the displayed data
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Include filters for date range and employee.
