### E04 - Time & Attendance (Clock In/Out)

**User Story 1: Clock-In/Out Endpoints with Validation**
- Title: Employee Clock-In/Out API
- Narrative: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
- Acceptance Criteria:
  ```
  Given a valid employee,
  When I POST /attendance/clock-in or /clock-out,
  Then my attendance is recorded with validation (geofence, device).
  ```
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Core attendance.

**User Story 2: Shift Association and Hours Calculation**
- Title: Associate Attendance with Shifts
- Narrative: As a supervisor, I want clock events linked to shifts so that hours worked are calculated automatically.
- Acceptance Criteria:
  ```
  Given clock-in/out events,
  When processed,
  Then hours are calculated and associated with the correct shift.
  ```
- Priority: High
- Story Points: 3
- Dependencies: Story 1
- Notes: Payroll accuracy.

**User Story 3: Missed Punches and Corrections Workflow**
- Title: Attendance Corrections Workflow
- Narrative: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.
- Acceptance Criteria:
  ```
  Given a missed punch,
  When I submit a correction,
  Then an approval task is created for my supervisor.
  ```
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Error handling.

**User Story 4: Attendance CSV Export**
- Title: Export Attendance Records to CSV
- Narrative: As a payroll admin, I want to export attendance records to CSV so that payroll processing is streamlined.
- Acceptance Criteria:
  ```
  Given attendance data,
  When I request an export,
  Then a CSV file is generated with daily totals.
  ```
- Priority: High
- Story Points: 1
- Dependencies: Story 1
- Notes: Payroll integration.
