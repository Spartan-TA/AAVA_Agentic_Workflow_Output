### Epic E04: Time & Attendance (Clock In/Out)

**User Story 1: Clock-In Endpoint**
- Title: Employee Clock-In API
- User Story: As a WORKER, I want to clock in at the start of my shift so that my attendance is recorded.
- Acceptance Criteria:
  ```
  Given a valid employee and shift,
  When I POST to /attendance/clock-in,
  Then my clock-in event is recorded with timestamp and device info.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Geofence optional.

**User Story 2: Clock-Out Endpoint**
- Title: Employee Clock-Out API
- User Story: As a WORKER, I want to clock out at the end of my shift so that my worked hours are calculated.
- Acceptance Criteria:
  ```
  Given a valid clock-in event,
  When I POST to /attendance/clock-out,
  Then my clock-out event is recorded and hours worked are calculated.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Validates shift association.

**User Story 3: Missed Punch Correction Workflow**
- Title: Attendance Correction Request
- User Story: As a WORKER, I want to request corrections for missed punches so that my attendance is accurate.
- Acceptance Criteria:
  ```
  Given a missed punch,
  When I submit a correction request,
  Then an approval task is created for my supervisor.

  Given a supervisor,
  When reviewing correction requests,
  Then they can approve or deny the correction.
  ```
- Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Approval workflow.

**User Story 4: Attendance Reporting**
- Title: Attendance Report Export
- User Story: As an ADMIN, I want to export attendance reports so that payroll processing is streamlined.
- Acceptance Criteria:
  ```
  Given attendance data,
  When I request a report export,
  Then a CSV file is generated with daily totals per employee.
  ```
- Additional Details: Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Supports filtering.
