### E04 - Time & Attendance (Clock In/Out)

**Title:** Clock In/Out Event Recording  
User Story: As a worker, I want to clock in and out So that my attendance is accurately tracked.  
Acceptance Criteria:  
Scenario: Clock Event  
Given a valid badgeId  
When I POST to /attendance/clock-in or /clock-out  
Then the event is recorded with timestamp and device info  
Additional Details:  
- Priority: High  
- Story Points: 3  
- Dependencies: Employee Master Data, RBAC  
- Notes: Geofence optional

---

**Title:** Shift Hours Calculation  
User Story: As a payroll manager, I want to calculate hours worked per shift So that payroll is accurate.  
Acceptance Criteria:  
Scenario: Hours Calculation  
Given clock-in/out events  
When I generate daily totals  
Then hours worked are computed per employee  
Additional Details:  
- Priority: High  
- Story Points: 2  
- Dependencies: Clock In/Out Event Recording  
- Notes: Automatic shift association

---

**Title:** Missed Punch Correction Workflow  
User Story: As a supervisor, I want to handle missed punches and corrections So that attendance records are accurate.  
Acceptance Criteria:  
Scenario: Correction Request  
Given a missed punch  
When a correction is submitted  
Then an approval task is created for supervisor review  
Additional Details:  
- Priority: High  
- Story Points: 2  
- Dependencies: Clock In/Out Event Recording  
- Notes: Correction workflow tracked

---

**Title:** Attendance Report Export  
User Story: As an HR user, I want to export attendance reports in CSV format So that records can be analyzed externally.  
Acceptance Criteria:  
Scenario: Report Export  
Given attendance data  
When I request an export  
Then a CSV file is generated and downloadable  
Additional Details:  
- Priority: High  
- Story Points: 2  
- Dependencies: Clock In/Out Event Recording  
- Notes: Export includes daily totals
