[E04] Time & Attendance (Clock In/Out)

User Story 1
Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.
Acceptance Criteria:
  Scenario: Clock-in/out event
    Given I am a valid employee
    When I POST to /attendance/clock-in or /clock-out
    Then my event is recorded with timestamp and validation
Additional Details: Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Device and geofence optional

User Story 2
Title: Capture Device and Geofence Data (Optional)
User Story: As a supervisor, I want device and geofence data captured on clock events so that I can verify location compliance.
Acceptance Criteria:
  Scenario: Device/geofence capture
    Given I clock in/out
    When my device supports location
    Then the event includes device and geofence info
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E04-1, Notes: Optional for MVP

User Story 3
Title: Calculate Hours Worked per Shift
User Story: As a payroll manager, I want hours worked per shift calculated so that payroll is accurate.
Acceptance Criteria:
  Scenario: Shift hours calculation
    Given clock-in and clock-out events exist
    When I view the shift summary
    Then total hours worked are computed automatically
Additional Details: Priority: High, Story Points: 2, Dependencies: E04-1, Notes: Handles overnight shifts

User Story 4
Title: Handle Missed Punches and Corrections Workflow
User Story: As a worker, I want to submit corrections for missed punches so that my attendance is accurate.
Acceptance Criteria:
  Scenario: Correction submission
    Given I missed a punch
    When I submit a correction request
    Then an approval task is created for my supervisor
Additional Details: Priority: High, Story Points: 3, Dependencies: E04-1, Notes: Approval workflow

User Story 5
Title: Export Attendance Reports (CSV)
User Story: As a supervisor, I want to export attendance reports in CSV format so that I can analyze attendance data.
Acceptance Criteria:
  Scenario: Export attendance
    Given attendance data exists
    When I request a CSV export
    Then the file is generated with all relevant fields
Additional Details: Priority: Medium, Story Points: 2, Dependencies: E04-1, Notes: Download via API

User Story 6
Title: Associate Clock Events with Shifts Automatically
User Story: As a worker, I want my clock events automatically associated with my scheduled shift so that reporting is accurate.
Acceptance Criteria:
  Scenario: Automatic shift association
    Given I clock in/out
    When my shift is scheduled
    Then the event is linked to the correct shift
Additional Details: Priority: High, Story Points: 2, Dependencies: E05, Notes: Handles overlapping shifts
