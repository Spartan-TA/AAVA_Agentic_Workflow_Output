### E04 - Time & Attendance (Clock In/Out)

**Title:** Implement Clock-In/Out Endpoints
User Story: As a warehouse worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Valid clock-in
Given my badgeId and location
When I POST to `/attendance/clock-in`
Then my clock-in is recorded with timestamp and device info
Scenario: Geofence validation
Given geofence is enabled
When I clock in outside allowed area
Then the request is rejected
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Device capture required for audit

**Title:** Calculate Hours Worked Per Shift
User Story: As a payroll manager I want daily totals of hours worked per employee So that payroll calculations are accurate
Acceptance Criteria:
Scenario: Daily totals computed
Given clock-in/out events
When I request daily attendance
Then totals are calculated per shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Implement Clock-In/Out Endpoints
- Notes: Handles overnight shifts

**Title:** Handle Missed Punches and Corrections
User Story: As a supervisor I want to approve corrections for missed punches So that attendance records are accurate
Acceptance Criteria:
Scenario: Missed punch correction
Given a missed punch
When an employee submits a correction
Then a supervisor approval task is created
Scenario: Correction approved
Given a pending correction
When supervisor approves
Then attendance record is updated
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Implement Clock-In/Out Endpoints
- Notes: Corrections tracked in audit log

**Title:** Export Attendance Reports
User Story: As an HR user I want to export attendance reports in CSV format So that I can analyze and share data
Acceptance Criteria:
Scenario: Export attendance
Given attendance data
When I request export
Then a CSV file is generated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Calculate Hours Worked Per Shift
- Notes: Export includes all relevant fields
