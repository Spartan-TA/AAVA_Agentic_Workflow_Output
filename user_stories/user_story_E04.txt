### E04 - Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock In/Out Endpoints with Validation
User Story: As a worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Clock in/out
Given a valid employee
When I POST to /attendance/clock-in or /clock-out
Then the event is recorded with timestamp and device info
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence optional

**User Story 2**
Title: Calculate Hours Worked Per Shift
User Story: As a payroll admin I want hours worked per shift to be calculated automatically So that payroll is accurate
Acceptance Criteria:
Scenario: Shift hours calculation
Given clock-in and clock-out events
When the shift ends
Then total hours are computed and stored
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Handles overnight shifts

**User Story 3**
Title: Missed Punches and Corrections Workflow
User Story: As a worker I want to request corrections for missed punches So that my attendance record is accurate
Acceptance Criteria:
Scenario: Missed punch correction
Given a missed punch
When I submit a correction request
Then an approval task is created for my supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Correction audit trail required

**User Story 4**
Title: Attendance Reports Export
User Story: As an HR user I want to export attendance data as CSV So that I can analyze and share records
Acceptance Criteria:
Scenario: Export attendance
Given attendance data exists
When I request an export
Then a CSV file is generated with all relevant fields
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 2
- Notes: Export includes corrections
