Title: Create Employee Record

User Story: As an HR manager I want to create a new employee record with all required fields So that employee information is accurately stored in the system

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee details
When I submit a POST request to /employees
Then a new employee record should be created with a unique badgeId

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Validate required fields and enforce badgeId uniqueness.
