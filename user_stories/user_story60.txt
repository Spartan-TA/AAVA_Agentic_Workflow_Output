Title: OpenAPI Documentation for All Integration APIs

User Story:
As a developer, I want all integration APIs (HRIS, WMS, IDP, webhooks) to be documented in OpenAPI so that external systems can integrate reliably and securely.

Acceptance Criteria:
- Scenario: OpenAPI docs are available for all endpoints
  Given integration APIs are implemented
  When a developer accesses the documentation endpoint
  Then all endpoints, schemas, and security requirements are documented

- Scenario: Documentation is updated with API changes
  Given APIs are updated
  When the docs are regenerated
  Then the latest changes are reflected

Additional Details:
- OpenAPI docs must be accessible via a public or secured endpoint
- All request/response examples must be included
- Documentation must be versioned and exportable
