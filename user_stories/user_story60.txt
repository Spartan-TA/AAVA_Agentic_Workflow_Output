Title: Initiate Employee Offboarding Workflow

User Story: As an HR manager I want to initiate an offboarding workflow for departing employees So that all exit tasks and access revocation are handled systematically

Acceptance Criteria:
Scenario: Starting offboarding workflow
Given an employee is marked for departure
When I initiate offboarding
Then the workflow should assign exit tasks and revoke system access

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Workflow engine, access management
- Notes: Support customizable offboarding templates and notifications.
