Title: CI/CD Pipeline Setup

User Story: As a developer I want a CI/CD pipeline configured So that code changes are automatically built, tested, and deployed to staging environments

Acceptance Criteria:
Scenario: Automated build and test
  Given a new commit is pushed to the repository
  When the pipeline runs
  Then the code should be built and all tests executed automatically

Scenario: Deployment to staging
  Given tests pass successfully
  When the pipeline completes
  Then the application should be deployed to the staging environment

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Version control, build server (e.g., GitHub Actions, Jenkins)
- Notes: Pipeline should include linting, unit/integration tests, and rollback on failure.
