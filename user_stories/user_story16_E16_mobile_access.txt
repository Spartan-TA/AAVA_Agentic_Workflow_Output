Epic E16: Mobile Access (PWA)

---

User Story 1: Responsive Mobile Views
As a worker, I want responsive views for clock-in/out, schedules, leave requests, and announcements so that I can use the system on my device.

Acceptance Criteria:
Scenario: Mobile usability
  Given I access the app on mobile
  When I use core flows
  Then they are usable and responsive

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E04, E05, E06, E12
- Notes: Mobile-first design

User Story 3: Offline Queue for Clock Events
As a worker, I want clock events to queue offline so that I can record attendance without connectivity.

Acceptance Criteria:
Scenario: Offline clock-in
  Given no network
  When I clock in
  Then event is queued and synced when online

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Conflict resolution on sync
