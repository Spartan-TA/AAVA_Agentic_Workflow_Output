# Epic E16: Mobile Access (PWA)

## User Story 1: Responsive Mobile Views for Core Flows
**Title:** Responsive Mobile Views for Core Flows  
**Narrative:** As a worker, I want to clock-in/out, view schedules, request leave, and see announcements on my mobile device so that I can work efficiently.  
**Acceptance Criteria (Gherkin):**
```
Given my mobile device
When I access the application
Then all core flows are usable and responsive
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E04, E05, E06, E12  
**Notes:** Test on multiple devices.

## User Story 3: Offline Queue for Clock Events
**Title:** Offline Queue for Clock Events  
**Narrative:** As a worker, I want clock events queued offline and synced when online so that my attendance is always recorded.  
**Acceptance Criteria (Gherkin):**
```
Given offline mode
When I clock in/out
Then events are queued locally
When connectivity is restored
Then events are synced and conflicts resolved
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E16  
**Notes:** Handle duplicate events.
