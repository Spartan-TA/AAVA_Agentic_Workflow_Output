Title: Implement Role-Based Access Control
User Story: As an admin I want to restrict access to sensitive operations based on user roles So that only authorized users can perform certain actions
Acceptance Criteria:
Scenario: Role-Based Restrictions
Given a user with a specific role
When the user attempts a restricted operation
Then unauthorized requests return 401 and forbidden actions return 403
Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD
- Notes: Roles: ADMIN, HR, SUPERVISOR, WORKER
