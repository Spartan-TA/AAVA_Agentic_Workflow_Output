Title: Missed Punch Notifications and Correction Workflow

User Story: As a Warehouse Worker I want to be notified if I miss a clock-in or clock-out so that I can request a correction and ensure my attendance is accurate.

Acceptance Criteria:
Scenario: Notification of missed punch
Given I missed a clock-in or clock-out
When the system detects the anomaly
Then I receive an in-app and email notification with instructions to request a correction

Scenario: Supervisor reviews correction request
Given a worker submits a missed punch correction
When the Supervisor reviews the request
Then the Supervisor can approve or reject the correction and the attendance record is updated accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: Notification service, Attendance module
- Notes: All corrections must be logged for audit purposes.
