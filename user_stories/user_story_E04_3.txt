Title: Handle Missed Punches

User Story: As a worker I want to report and correct missed clock-in/out punches So that my attendance record is accurate and payroll is not affected

Acceptance Criteria:
Scenario: Missed punch correction
Given I missed a clock-in or clock-out event
When I submit a correction request
Then my supervisor should be notified and able to approve or reject the correction

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Track all corrections for audit; notify payroll if changes affect pay.
