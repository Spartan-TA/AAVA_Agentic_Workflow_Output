Title: Missed Punches and Corrections Workflow

User Story: As a warehouse worker I want to request corrections for missed clock-in or clock-out events so that my attendance record is accurate and payroll is not affected

Acceptance Criteria:
Scenario: Requesting a correction
Given I missed a clock-in or clock-out event
When I submit a correction request
Then an approval task should be created for my supervisor and my record updated upon approval

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Correction requests must be tracked; audit trail required for all changes.
