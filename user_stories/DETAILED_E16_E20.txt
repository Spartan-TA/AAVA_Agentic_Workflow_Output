DETAILED USER STORIES E16-E20

E16 STORY 1
Title: Responsive Views for Core Flows
User Story: As a worker I want to clock in out view schedules request leave and see announcements on mobile So that I can use the system anywhere
Acceptance Criteria:
Scenario: Mobile usability
Given a mobile device
When I access the app
Then all core flows are usable and responsive
Priority: Medium Story Points: 3 Dependencies: E04 E05 E06 E12

Then it installs as a PWA
Priority: Medium Story Points: 2 Dependencies: E16-1
