EPIC E14 - Audit Trail & Compliance

===========================================

User Story 1
------------
Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer, I want all create/update/delete actions on sensitive data to be logged so that forensic analysis is possible.

Acceptance Criteria:
Scenario: Log sensitive changes
  Given a sensitive change
  When the action occurs
  Then an audit log entry is created with actor, timestamp, before/after values

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03
- Notes: Covers PII, schedules, approvals, payroll.

===========================================

User Story 2
