EPIC E14: Audit Trail & Compliance

===========================================

Title: Audit Trail & Compliance

User Story: As a compliance officer I want centralized audit logging for sensitive changes So that forensic analysis is possible

Acceptance Criteria:
Scenario: Audit log creation
Given a sensitive change occurs
When I review logs
Then actor, timestamp, before/after are recorded

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC
- Notes: Immutable log table
