Title: Submit Requests via Mobile

User Story: As an employee I want to submit requests (e.g., leave, shift swap) via mobile So that I can manage work-related tasks from anywhere

Acceptance Criteria:
Scenario: Mobile request submission
Given I have a mobile device and access to the app
When I submit a request
Then the request should be processed and notifications sent as appropriate

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Mobile app, request modules
- Notes: Support for all major request types
