EPIC 01: PROJECT SCAFFOLDING & DOMAIN SETUP

===========================================

Title: Initialize Spring Boot Project
User Story: As a Developer I want to initialize a Spring Boot project with Maven So that I can ensure a standardized foundation for all modules
Acceptance Criteria:
Scenario: Project initialization
Given I have access to the repository
When I run the build command
Then the project builds and runs on port 8080

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: README must include build/run steps
