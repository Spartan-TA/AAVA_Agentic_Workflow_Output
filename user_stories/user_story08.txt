Title: Employee List Pagination and Filtering

User Story: As an HR manager I want to paginate and filter employee lists So that I can efficiently find and manage employee records

Acceptance Criteria:
Scenario: Paginated and filtered employee list
Given there are multiple employee records
When I request /employees with pagination and filter parameters
Then the response should return the correct subset of employees based on the criteria

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD endpoints
- Notes: Support filtering by department, status, and role.
