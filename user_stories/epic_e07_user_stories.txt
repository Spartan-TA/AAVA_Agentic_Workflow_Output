EPIC E07 - Training & Certification Tracking

===========================================

User Story 1
------------
Title: Certification CRUD Operations

User Story: As an HR user, I want to create, update, and delete certifications for employees so that compliance is tracked.

Acceptance Criteria:
Scenario: Manage certification records
  Given certification data
  When I POST/PUT/DELETE /certifications
  Then the certification records are managed accordingly

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Supports multiple cert types.

===========================================

User Story 2
------------
Title: Expiry Alert Notifications

User Story: As an employee, I want to receive alerts 30 and 7 days before my certification expires so that I can renew on time.

Acceptance Criteria:
Scenario: Alert sent before expiry
  Given a certification nearing expiry
  When the date is 30 or 7 days before
  Then an alert is sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Reduces lapses.

===========================================

User Story 3
------------
Title: Block Assignment for Expired Certifications

User Story: As a scheduler, I want to prevent assignment to tasks requiring expired certifications so that safety is maintained.

Acceptance Criteria:
Scenario: System blocks assignment with expired cert
  Given an expired certification
  When I attempt to assign a task
  Then the system blocks the assignment and notifies the user

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Safety compliance.

===========================================

User Story 4
------------
Title: Upload Proof of Certification

User Story: As an employee, I want to upload proof documents for certifications so that records are complete.

Acceptance Criteria:
Scenario: Upload and link certification document
  Given a certification
  When I upload a document
  Then the file is stored and linked to my profile

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Supports audits.

===========================================

User Story 5
------------
Title: Certification Status on Employee Profile

User Story: As a supervisor, I want to view certification status on employee profiles so that I can assign qualified staff.

Acceptance Criteria:
Scenario: View certification status
  Given an employee profile
  When I view certifications
  Then I see current status and expiry dates

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: E02, E03
- Notes: Improves visibility.
