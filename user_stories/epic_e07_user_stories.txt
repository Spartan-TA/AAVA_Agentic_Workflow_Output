### EPIC E07 - Training & Certification Tracking

#### User Story 1
Title: CRUD for Employee Certifications

User Story: As an HR user I want to create, read, update, and delete employee certifications So that compliance is tracked

Acceptance Criteria:
Scenario: Certification CRUD operations
Given the certification module
When I perform CRUD actions
Then certifications are managed correctly in the system

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support file upload for proof documents

---

#### User Story 2
Title: Alert for Expiring Certifications

User Story: As a supervisor I want to receive alerts for certifications expiring in 30 or 7 days So that renewals are not missed

Acceptance Criteria:
Scenario: Certification expiry alert
Given a certification expiring soon
When the alert job runs
Then notifications are sent to the employee and supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Alerts via email and in-app

---

#### User Story 3
Title: Block Assignment to Tasks Requiring Expired Certifications

User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that safety is maintained

Acceptance Criteria:
Scenario: Assignment block for expired certs
Given an expired certification
When I assign a task requiring that cert
Then the system blocks the assignment and shows an error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1, E05
- Notes: Error message specifies missing certification

---

#### User Story 4
Title: Display Certification Status on Employee Profile

User Story: As an HR user I want to view certification status on the employee profile So that compliance is visible

Acceptance Criteria:
Scenario: Certification status display
Given an employee profile
When I view the profile
Then all certifications and their statuses are listed

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1
- Notes: Color-code by expiry status
