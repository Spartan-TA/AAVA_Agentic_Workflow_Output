EPIC E07: Training & Certification Tracking

===========================================

Title: Training & Certification Tracking

User Story: As a safety manager I want to track employee certifications and expirations So that only qualified staff operate equipment

Acceptance Criteria:
Scenario: Certification tracking
Given an employee profile
When I add a certification
Then expiry alerts are generated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC
- Notes: Alerts 30/7 days before expiry

---

Title: Block Assignment for Expired Certifications

User Story: As a supervisor I want to block shift assignment for expired certifications So that compliance is enforced

Acceptance Criteria:
Scenario: Assignment block
Given a certification is expired
When I assign a task requiring it
Then the system prevents assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification tracking
- Notes: Status visible on profile
