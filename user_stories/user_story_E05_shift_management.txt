Title: Create Shift Templates

User Story: As an HR Manager I want to create recurring shift templates So that schedules can be assigned efficiently

Acceptance Criteria:
Scenario: Shift template creation
Given shift details
When I create a template
Then the template should be available for assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD APIs (E02), RBAC (E03), Clock In/Out (E04)
- Notes: Support weekly and monthly patterns
