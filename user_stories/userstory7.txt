Title: Retrieve Employee Records via API

User Story: As an HR manager I want to retrieve employee records by various filters (name, badgeId, department, status) So that I can view and manage employee data efficiently

Acceptance Criteria:
Scenario: Employee retrieval
Given employee records exist in the system
When I submit a get employee API request with filters
Then the matching employee records should be returned

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee creation
- Notes: Support pagination and sorting in API responses.
