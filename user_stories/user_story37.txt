Title: Certification Renewal Workflow

User Story: As an employee I want to submit renewal requests for expiring certifications so that I can maintain my eligibility for assigned tasks.

Acceptance Criteria:
Scenario: Submit renewal request
Given my certification is expiring soon
When I submit a renewal request with updated documentation
Then the request should be routed to HR for approval

Scenario: HR approves renewal
Given a renewal request is pending
When HR reviews and approves the renewal
Then the certification status should be updated and expiration date extended

Scenario: HR rejects renewal
Given a renewal request is pending
When HR rejects the renewal
Then the certification status should remain unchanged and the employee notified

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Certification CRUD (E07), Notifications (E12)
- Notes: Renewal requests and approvals should be logged for compliance.
