Title: In-App and Email Notification Delivery

User Story: As a user I want to receive notifications in-app and via email So that I am informed of important events and updates

Acceptance Criteria:
Scenario: Notification delivery
Given an event triggers a notification
When my notification preferences are set
Then I should receive the notification through my preferred channels

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Notification module, user preferences
- Notes: Support for opt-in/opt-out and notification history.
