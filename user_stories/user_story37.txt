Title: Company-Wide Announcements

User Story: As an HR manager I want to send company-wide announcements so that all employees are informed of important updates and events

Acceptance Criteria:
Scenario: Sending an announcement
Given I am logged in as an HR manager
When I create and send an announcement
Then all employees receive the message via their preferred notification channel

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Notification module, user preferences
- Notes: Announcements should be archived and searchable.
