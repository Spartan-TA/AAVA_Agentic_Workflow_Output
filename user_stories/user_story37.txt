Title: Role-Based Access and Export of Incident Data

User Story:
As an HR or safety administrator, I want to control access to incident data by role and export filtered incident lists so that sensitive information is protected and reporting is efficient.

Acceptance Criteria:
- Scenario: Role-based access to incident data
  Given a user is authenticated
  When they access incident data
  Then only authorized roles (HR, safety, admin) can view or export sensitive details

- Scenario: Export filtered incident list
  Given incidents are recorded
  When an authorized user exports the list with filters (date, department, severity)
  Then only matching incidents are included in the export

Additional Details:
- Export must be available in CSV and PDF
- Access controls must be enforced in API and UI
- All exports must be logged for audit
