Title: SSO and Event Webhooks

User Story: As an IT administrator I want SSO integration and event webhooks So that users can log in with their corporate identity and external systems can react to EMS events

Acceptance Criteria:
Scenario: SSO and webhook event
Given a user is provisioned in the IDP
When they access EMS
Then they can authenticate via SSO and webhooks are triggered for relevant events (e.g., new hire, termination)

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Webhooks must be idempotent and documented in OpenAPI.
