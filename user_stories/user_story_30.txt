Title: Asset Check-In/Check-Out Endpoints
User Story: As a warehouse worker I want to check out and return equipment and PPE so that asset usage and availability are tracked
Acceptance Criteria:
Scenario: Check out asset
Given an asset is available
When I check it out
Then the system records the assignment and updates asset status
Scenario: Return asset
Given I have a checked-out asset
When I return it
Then the system records the return and updates asset status
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Must log time and user for each transaction
