Title: Generate Payroll Export File

User Story: As a payroll administrator I want to generate a payroll export file So that I can upload accurate payroll data to external payroll systems

Acceptance Criteria:
Scenario: Exporting payroll data
Given payroll data for the current period is finalized
When I select the export option and format
Then a payroll export file should be generated and available for download

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Payroll module, data validation
- Notes: Support multiple export formats (CSV, XLSX, API payload).
