Title: Payroll Export File Generation

User Story: As a payroll administrator I want to generate payroll-ready files from approved attendance and leave So that I can efficiently process payroll with external providers

Acceptance Criteria:
Scenario: Successful payroll export
Given all attendance and leave records are approved
When I initiate a payroll export
Then the generated file matches the external provider's schema and totals reconcile with payroll reports

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: E04, E06
- Notes: Must support multiple provider formats and validate schema before delivery
