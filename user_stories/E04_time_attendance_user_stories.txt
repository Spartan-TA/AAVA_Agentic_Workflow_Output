Epic E04: Time & Attendance (Clock In/Out)

1. Title: Implement Clock-In/Clock-Out Endpoints
   User Story: As a worker I want to clock in and out via API So that my work hours are recorded
   Acceptance Criteria:
   Scenario: Successful clock-in
   Given I am authenticated
   When I POST to /attendance/clock-in with my badgeId
   Then my clock-in time is recorded
   Additional Details:
   - Priority: High
   - Story Points: 3
   - Dependencies: E02, E03
   - Notes: Validate badgeId.

2. Title: Calculate Hours Worked Per Shift
   User Story: As a supervisor I want hours worked auto-calculated So that payroll is accurate
   Acceptance Criteria:
   Scenario: Shift hours calculated
   Given a worker clocks in and out
   When I view their attendance record
   Then total hours for the shift are displayed
   Additional Details:
   - Priority: High
   - Story Points: 3
   - Dependencies: Clock-in/out endpoints
   - Notes: Handle overnight shifts.

3. Title: Handle Missed Punches and Corrections
   User Story: As a worker I want to request corrections for missed punches So that my attendance is accurate
   Acceptance Criteria:
   Scenario: Correction workflow
   Given I missed a clock-out
   When I submit a correction request
   Then a supervisor approval task is created
   Additional Details:
   - Priority: Medium
   - Story Points: 5
   - Dependencies: Attendance records
   - Notes: Track correction history.

4. Title: Export Attendance Reports
   User Story: As an HR user I want to export attendance data So that I can process payroll
   Acceptance Criteria:
   Scenario: Export attendance
   Given attendance data exists
   When I request an export
   Then I receive a CSV file with daily totals
   Additional Details:
   - Priority: Medium
   - Story Points: 2
   - Dependencies: Attendance records
   - Notes: Include corrections.
