## E04: Time & Attendance (Clock In/Out)

### User Story 1
- Title: Employee Clock-In Endpoint
- User Story: As a worker, I want to clock in via an endpoint so that my attendance is recorded.
- Acceptance Criteria in Gherkin format:
  Scenario: Clock-in event
  Given a valid employee and location
  When I POST to /attendance/clock-in
  Then my clock-in is recorded with geofence validation
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E02, E03
  * Notes: Geofence is optional.

### User Story 2
- Title: Employee Clock-Out Endpoint
- User Story: As a worker, I want to clock out via an endpoint so that my shift end is recorded.
- Acceptance Criteria in Gherkin format:
  Scenario: Clock-out event
  Given a valid employee and location
  When I POST to /attendance/clock-out
  Then my clock-out is recorded and shift hours are calculated
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E02, E03
  * Notes: Device capture required.

### User Story 3
- Title: Automatic Shift Association
- User Story: As a supervisor, I want clock events automatically associated with scheduled shifts so that reporting is accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Shift association
  Given a clock-in/out event
  When the event is processed
  Then it is linked to the correct shift
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E02, E03
  * Notes: Handles multiple shifts.

### User Story 4
- Title: Missed Punch Correction Workflow
- User Story: As a worker, I want to request corrections for missed punches so that my attendance is accurate.
- Acceptance Criteria in Gherkin format:
  Scenario: Correction request
  Given a missed punch
  When I submit a correction
  Then an approval task is created for my supervisor
- Additional Details:
  * Priority: High
  * Story Points: 3
  * Dependencies: E02, E03
  * Notes: Approval workflow required.

### User Story 5
- Title: Attendance Report Export
- User Story: As an HR user, I want to export attendance reports in CSV format so that payroll processing is simplified.
- Acceptance Criteria in Gherkin format:
  Scenario: Export attendance report
  Given attendance data exists
  When I request a CSV export
  Then the report is generated and downloadable
- Additional Details:
  * Priority: High
  * Story Points: 2
  * Dependencies: E02, E03
  * Notes: Daily totals computed.
