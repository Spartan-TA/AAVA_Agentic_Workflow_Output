### E04: Time & Attendance (Clock In/Out)

#### 1. Clock In/Out Endpoints
User Story: As a warehouse worker I want to clock in and out via API So that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Successful clock-in
Given I am authenticated
When I POST to /attendance/clock-in with valid data
Then my clock-in event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate geofence and device if configured.

#### 2. Calculate Hours Worked per Shift
User Story: As a payroll manager I want the system to calculate hours worked per shift So that payroll is accurate.
Acceptance Criteria:
Scenario: Hours calculated
Given clock-in and clock-out events exist
When I view attendance records
Then total hours worked per shift are displayed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Handle overnight shifts.

#### 3. Missed Punch Correction Workflow
User Story: As a supervisor I want to approve corrections for missed punches So that attendance data is accurate.
Acceptance Criteria:
Scenario: Correction approval
Given a worker submits a correction
When I review the request
Then I can approve or deny the correction, and the record updates accordingly
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Corrections create approval tasks.

#### 4. Export Attendance Reports
User Story: As an HR user I want to export attendance data as CSV So that I can analyze and share records.
Acceptance Criteria:
Scenario: Export attendance
Given attendance data exists
When I request an export
Then a CSV file is generated with all relevant fields
Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03
- Notes: Include filters for date range, department, etc.
