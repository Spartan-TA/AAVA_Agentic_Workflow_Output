Title: SUPERVISOR Role Limited to Team Records

User Story: As a SUPERVISOR I want to access and manage records only for employees on my team So that I can perform my duties without overreaching my authority

Acceptance Criteria:
Scenario: SUPERVISOR accesses team records
Given a user is authenticated as SUPERVISOR
When they access employee or schedule records
Then the system only allows access to records for their assigned team

Scenario: SUPERVISOR attempts to access other teams
Given a user is authenticated as SUPERVISOR
When they attempt to access records outside their team
Then the system returns a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Team assignment must be enforced at the data access layer; test coverage required for all SUPERVISOR endpoints.
