Title: Visualize Workforce Data with Dashboards

User Story:
As an HR manager, I want to visualize workforce data using interactive dashboards so that I can quickly identify trends and make data-driven decisions.

Acceptance Criteria:
Scenario 1: Access dashboard
  Given I have access to the reporting module
  When I open the dashboard
  Then I see visualizations of key workforce metrics (e.g., headcount, turnover, diversity)

Scenario 2: Filter dashboard data
  Given the dashboard is displayed
  When I apply filters (e.g., department, date range)
  Then the visualizations update to reflect the selected criteria

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: Employee data, reporting module
Notes: Dashboards should support export to image or PDF.
