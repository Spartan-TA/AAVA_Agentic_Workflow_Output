[E13] Integration Layer (HRIS/WMS APIs)

Title: Expose JWT/OAuth2-Secured REST APIs
User Story: As an integration developer I want REST APIs secured by JWT/OAuth2 so that external systems can access data safely.
Acceptance Criteria:
Scenario: API Security
Given API endpoints
When accessed with valid JWT/OAuth2 token
Then data is returned securely

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Document authentication flow
