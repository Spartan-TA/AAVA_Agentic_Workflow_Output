Epic E13: Integration Layer (HRIS/WMS APIs)

---

User Story 1: Expose REST APIs for HRIS/WMS
As a developer, I want REST APIs for HRIS and WMS so that master data is synchronized.

Acceptance Criteria:
Scenario: HRIS API
  Given new hire data
  When HRIS calls API
  Then employee is created/updated

Scenario: WMS API
  Given department/location data
  When WMS calls API
  Then data is updated

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: JWT/OAuth2-secured APIs

---

User Story 2: IDP for SSO
As IT, I want IDP integration for SSO so that users have single sign-on.

Acceptance Criteria:
Scenario: SSO login
  Given IDP configuration
  When user logs in
  Then authentication is via SSO

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: SSO supports HRIS users

---

User Story 3: Webhooks for Events
As a developer, I want webhooks for key events so that downstream systems are notified.

Acceptance Criteria:
Scenario: Webhook trigger
  Given a relevant event
  When it occurs
  Then webhook is sent

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02, E03
- Notes: Webhooks are idempotent
