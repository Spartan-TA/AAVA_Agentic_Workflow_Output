Title: Create Employee Record via API

User Story: As an HR manager I want to create employee records with name, badgeId, role, department, shiftGroup, hireDate, and status So that employee data is accurately captured in the system

Acceptance Criteria:
Scenario: Employee creation
Given I have valid employee data
When I submit a create employee API request
Then a new employee record should be stored and retrievable

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Project scaffolding
- Notes: Validate required fields and return success/failure response.
