Title: Scheduled Shift Auto-Flagging for Coverage

User Story:
As a supervisor, I want scheduled shifts to be automatically flagged for coverage when an employee's leave is approved so that I can proactively fill gaps in the schedule.

Acceptance Criteria:
- Scenario: Shift is auto-flagged for coverage
  Given an employee's leave is approved
  When the leave period overlaps with scheduled shifts
  Then those shifts are flagged as needing coverage

- Scenario: Supervisor receives notification
  Given shifts are flagged for coverage
  When the supervisor logs in
  Then a notification or dashboard alert is shown

Additional Details:
- Flagged shifts must be filterable in the scheduling UI
- Notifications must be sent to supervisors responsible for the affected shifts
- All flagging actions must be logged
