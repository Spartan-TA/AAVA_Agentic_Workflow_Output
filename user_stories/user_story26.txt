Title: Update Employee API Endpoint

User Story: As an HR user I want to update employee records via an API So that employee information remains accurate and current

Acceptance Criteria:
Scenario: Employee update
Given an existing employee record
When I PUT or PATCH to /employees/{id} with updated data
Then the employee record is updated and changes are reflected in the system

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee creation API (E02)
- Notes: Validate badgeId uniqueness and support partial updates
