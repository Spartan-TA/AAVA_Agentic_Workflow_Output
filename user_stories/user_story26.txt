Title: Configure Overtime Rules

User Story: As an HR manager I want to configure overtime rules So that employee scheduling complies with labor regulations and company policies

Acceptance Criteria:
Scenario: Setting overtime rules
Given I am on the overtime configuration page
When I define overtime thresholds and rates
Then the system should apply these rules when calculating shift assignments and payroll

Additional Details:
- Priority: High
- Story Points: 4
- Dependencies: Shift Templates, Payroll Export Integration
- Notes: Overtime rules should support daily and weekly limits, and trigger notifications for supervisors.
