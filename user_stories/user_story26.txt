Title: Document Management

User Story: As an HR manager I want to upload, manage, and securely store employee and compliance documents So that records are organized and accessible for audits and operational needs

Acceptance Criteria:
Scenario: Upload document
Given I have a valid document to associate with an employee or incident
When I upload the document
Then it is stored securely and linked to the relevant record

Scenario: Access control
Given documents are stored in the system
When a user with appropriate permissions requests access
Then only authorized users can view or download the document

Additional Details:
- Priority: High
- Story Points: 6
- Dependencies: Employee Master Data, Safety Incidents, Audit Trail
- Notes: Secure storage; access control; supports compliance audits
