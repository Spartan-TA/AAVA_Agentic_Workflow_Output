Title: Employee API Search by Department
User Story: As an HR user I want to search for employees by department via API So that I can view department-specific records
Acceptance Criteria:
Scenario: Search by Department
Given employee records exist
When I GET /employees?department=Finance
Then only employees in the Finance department are returned
Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee CRUD API
- Notes: Support multiple department filters
