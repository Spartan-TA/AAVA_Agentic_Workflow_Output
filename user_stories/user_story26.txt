Title: Certification Document Upload

User Story: As an employee I want to upload certification documents So that my HR record is complete and verifiable

Acceptance Criteria:
Scenario: Upload certification document
  Given I am authenticated
  When I upload a document for a certification
  Then the document should be stored and linked to my certification record
Scenario: View uploaded document
  Given a document is uploaded
  When I view my certification record
  Then I should be able to download or preview the document
Scenario: Delete uploaded document
  Given a document is uploaded
  When I delete it
  Then it should be removed from my record

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Certification module, file storage
- Notes: Support for multiple file formats
