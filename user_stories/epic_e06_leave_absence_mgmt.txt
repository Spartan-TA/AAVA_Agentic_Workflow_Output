EPIC E06: Leave & Absence Management

---

Title: Request Leave (PTO, Sick, Unpaid)

User Story: As an employee I want to request leave So that my time off is tracked and approved

Acceptance Criteria:
Scenario: Leave request
Given I am logged in
When I submit a leave request
Then my supervisor is notified for approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee Master Data, RBAC, Shift & Schedule Management
- Notes: PTO, sick, unpaid supported

---

Title: Approve/Deny Leave Requests

User Story: As a supervisor I want to approve or deny leave requests So that staffing is maintained

Acceptance Criteria:
Scenario: Leave approval
Given a pending request
When I approve or deny it
Then the employee is notified and balances update

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Request Leave
- Notes: Approval workflow

---

Title: Update Accrual Balances

User Story: As an HR user I want leave accrual balances updated automatically So that policies are enforced

Acceptance Criteria:
Scenario: Accrual update
Given a leave is approved
When the balance is recalculated
Then the employee's record reflects the change

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Approve/Deny Leave Requests
- Notes: Policy-driven

---

Title: Exclude Approved Leave from Scheduling

User Story: As a scheduler I want approved leave to auto-flag scheduled shifts So that coverage is planned

Acceptance Criteria:
Scenario: Shift auto-flag
Given approved leave overlaps with scheduled shifts
When I view the schedule
Then affected shifts are flagged for coverage

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: Approve/Deny Leave Requests
- Notes: Export includes flagged shifts

---

Title: Export Approved Leaves

User Story: As an HR user I want to export approved leaves So that reporting is accurate

Acceptance Criteria:
Scenario: Leave export
Given approved leaves exist
When I export the data
Then the file includes all relevant details

Additional Details:
- Priority: Low
- Story Points: 1
- Dependencies: Approve/Deny Leave Requests
- Notes: CSV format
