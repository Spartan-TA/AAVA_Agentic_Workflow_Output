Epic E06: Leave & Absence Management

---

Title: Request Paid Time Off (PTO)

User Story: As an employee I want to request PTO So that my absence is tracked and approved according to policy

Acceptance Criteria:
Scenario: Submitting a PTO request
Given I have available PTO balance
When I submit a request for specific dates
Then the request is routed for approval

Scenario: Insufficient PTO balance
Given my PTO balance is zero
When I submit a request
Then the system denies the request

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: PTO balance displayed to user

---

Title: Approve or Reject Leave Requests

User Story: As a supervisor I want to approve or reject leave requests So that team coverage is maintained

Acceptance Criteria:
Scenario: Approving a leave request
Given a pending request exists
When I approve it
Then the employee's schedule is updated and notification sent

Scenario: Rejecting a leave request
Given a pending request exists
When I reject it
Then the employee is notified with a reason

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05
- Notes: Approval workflow configurable

---

Title: Integrate Leave with Scheduling and Payroll

User Story: As an HR manager I want approved leave to automatically exclude employees from scheduling and payroll calculations So that errors are minimized

Acceptance Criteria:
Scenario: Exclusion from schedule
Given an approved leave
When schedules are generated
Then the employee is excluded from shift assignment

Scenario: Payroll adjustment
Given an approved unpaid leave
When payroll is processed
Then pay is adjusted accordingly

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03, E05
- Notes: Supports PTO, sick, unpaid leave
