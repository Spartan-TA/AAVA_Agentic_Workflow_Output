Title: Employee API Export to JSON
User Story: As a Developer I want to export employee lists to JSON via API So that I can integrate with other applications
Acceptance Criteria:
Scenario: Export to JSON
Given employee records exist
When I GET /employees/export?format=json
Then I receive a JSON file with employee data

- Priority: Medium
- Story Points: 2
- Dependencies: Employee API Bulk Export
- Notes: Support pretty-print and compact formats
