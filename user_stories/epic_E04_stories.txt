EPIC E04 - Time & Attendance (Clock In/Out)

User Story 1: Implement Clock-In/Out Endpoints
As a worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Clock event recorded
Given a valid request
When I POST to /attendance/clock-in or /clock-out
Then the event is saved with timestamp
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Validate input

User Story 2: Associate Clock Events with Shifts
As a system I want to automatically associate clock events with the correct shift So that hours worked are calculated correctly
Acceptance Criteria:
Scenario: Shift association
Given a clock event
When it is processed
Then it is linked to the scheduled shift
Priority: High
Story Points: 2
Dependencies: User Story 1
Notes: Handle overnight shifts

User Story 3: Handle Missed Punches and Corrections
As a supervisor I want to manage missed punches and approve corrections So that attendance is accurate
Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch
When a correction is submitted
Then an approval task is created
Priority: High
Story Points: 2
Dependencies: User Story 1
Notes: Track correction history

User Story 4: Export Attendance Reports
As a payroll user I want to export attendance data as CSV So that payroll processing is simplified
Acceptance Criteria:
Scenario: CSV export
Given attendance records
When I request an export
Then a CSV file is generated
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Include all relevant fields
