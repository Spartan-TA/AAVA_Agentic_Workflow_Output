====================================================================
Epic E04: Time & Attendance (Clock In/Out)
====================================================================

User Story 1:
- Title: Implement Clock-In/Clock-Out Endpoints
- User Story: As a worker, I want to clock in and out via API endpoints so that my attendance is recorded.
- Acceptance Criteria:
  - Given a valid request, When I POST to /attendance/clock-in or /clock-out, Then my event is recorded with timestamp and device info.
  - Given an invalid request, When I clock in/out, Then validation errors are returned.
- Additional Details: Priority: High, Story Points: 5, Dependencies: E02, E03, Notes: Core attendance.

User Story 2:
- Title: Associate Attendance with Shifts and Calculate Hours
- User Story: As a payroll admin, I want attendance events to be linked to scheduled shifts and hours calculated so that payroll is accurate.
- Acceptance Criteria:
  - Given clock-in/out events, When I view attendance, Then hours worked per shift are computed.
  - Given missed punches, When corrections are submitted, Then approval tasks are created.
- Additional Details: Priority: High, Story Points: 5, Dependencies: User Story 1, Notes: Includes corrections workflow.

User Story 3:
- Title: Enforce Geofence Validation on Clock Events
- User Story: As a supervisor, I want clock-in/out to be allowed only within a geofenced area so that attendance is not faked.
- Acceptance Criteria:
  - Given a clock event, When outside the geofence, Then the request is rejected.
  - Given a clock event, When inside the geofence, Then the event is accepted.
- Additional Details: Priority: High, Story Points: 3, Dependencies: User Story 1, Notes: Optional but recommended.

User Story 4:
- Title: Export Attendance Reports
- User Story: As an HR user, I want to export attendance data as CSV so that I can analyze and share records.
- Acceptance Criteria:
  - Given attendance data, When I request an export, Then a CSV file is generated with daily totals.
- Additional Details: Priority: High, Story Points: 2, Dependencies: User Story 2, Notes: For compliance and payroll.
