### E04: Time & Attendance (Clock In/Out)

#### User Story 1
**Title:** Clock-In Endpoint
**User Story:** As a WORKER I want to clock in at the start of my shift So that my attendance is recorded
**Acceptance Criteria (Gherkin):**
```
Given my badgeId and location
When I POST to /attendance/clock-in
Then my clock-in event is recorded with geofence validation

Given invalid location
When I POST to /attendance/clock-in
Then I receive a geofence error
```
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Device capture optional

#### User Story 2
**Title:** Clock-Out Endpoint
**User Story:** As a WORKER I want to clock out at the end of my shift So that my hours are calculated
**Acceptance Criteria (Gherkin):**
```
Given a valid clock-in event
When I POST to /attendance/clock-out
Then my clock-out event is recorded and hours are calculated

Given missing clock-in
When I POST to /attendance/clock-out
Then I receive an error for missed punch
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Handles missed punches

#### User Story 3
**Title:** Attendance Corrections Workflow
**User Story:** As a SUPERVISOR I want to approve corrections for missed punches So that attendance data is accurate
**Acceptance Criteria (Gherkin):**
```
Given a missed punch correction request
When I review and approve
Then the attendance record is updated

Given a denied correction
When I review
Then the record remains unchanged and employee is notified
```
**Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Approval tasks generated

#### User Story 4
**Title:** Attendance Reporting
**User Story:** As an HR I want to export attendance reports So that payroll and compliance needs are met
**Acceptance Criteria (Gherkin):**
```
Given attendance data
When I request an export (CSV)
Then I receive a file with daily totals per employee

Given no data for selected period
When I request an export
Then the file is empty or shows no records
```
**Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Exportable reports
