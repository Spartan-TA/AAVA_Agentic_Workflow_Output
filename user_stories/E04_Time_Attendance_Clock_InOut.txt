[E04] Time & Attendance (Clock In/Out)

Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a warehouse worker I want to clock in and out via the system So that my attendance is accurately recorded.
Acceptance Criteria:
Scenario: Clock-in/out event
Given the worker is logged in
When clocking in or out
Then attendance is recorded with timestamp and device info

Additional Details:
Priority: High
Story Points: 5
Dependencies: E02, E03
Notes: Support geofence validation.

---

Title: Calculate Hours Worked Per Shift
User Story: As a payroll manager I want hours worked per shift to be calculated automatically So that payroll is accurate.
Acceptance Criteria:
Scenario: Shift hours calculation
Given attendance records exist
When daily totals are computed
Then hours worked per shift are available for export

Additional Details:
Priority: High
Story Points: 3
Dependencies: Implement Clock-In/Clock-Out Endpoints
Notes: Handle overnight and split shifts.

Title: Handle Missed Punches and Corrections Workflow
User Story: As a supervisor I want to manage missed punches and corrections So that attendance data is reliable.
Acceptance Criteria:
Scenario: Correction workflow
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for supervisor review

Additional Details:
Priority: Medium
Story Points: 3
Dependencies: Implement Clock-In/Clock-Out Endpoints
Notes: Corrections must be auditable.

Title: Associate Clock Events with Shifts Automatically
User Story: As a worker I want my clock events to be linked to my assigned shift So that attendance is mapped correctly.
Acceptance Criteria:
Scenario: Automatic shift association
Given a clock-in event
When the worker is assigned a shift
Then the event is linked to the correct shift

Additional Details:
Priority: Medium
Story Points: 2
Dependencies: Implement Clock-In/Clock-Out Endpoints, Shift Management
Notes: Handle overlapping shifts.
