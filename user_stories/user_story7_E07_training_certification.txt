**E07: Training & Certification Tracking**

1. Title: Track Employee Certifications
User Story: As a safety manager, I want to track employee certifications and expirations so that only qualified staff are assigned to equipment-sensitive roles.
Acceptance Criteria:
Scenario: Certification Tracking
Given an employee profile
When I add or update certifications
Then expiration dates and status are visible
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Block expired assignments.

2. Title: Alert on Expiring Certifications
User Story: As a supervisor, I want to receive alerts 30 and 7 days before certifications expire so that renewals are timely.
Acceptance Criteria:
Scenario: Expiry Alert
Given a certification nearing expiry
When the date is within alert window
Then an alert is sent to the supervisor and employee
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Support in-app and email alerts.

3. Title: Block Assignment to Unqualified Tasks
User Story: As a scheduler, I want the system to block assignment to tasks requiring certifications if the employee's cert is expired so that compliance is enforced.
Acceptance Criteria:
Scenario: Assignment Block
Given an expired certification
When I assign a task
Then the system prevents the assignment
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Show reason for block.

4. Title: Upload Proof of Certification
User Story: As an employee, I want to upload proof documents for certifications so that records are complete and verifiable.
Acceptance Criteria:
Scenario: Document Upload
Given a valid certification
When I upload a document
Then the file is attached to the employee profile
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Secure storage.
