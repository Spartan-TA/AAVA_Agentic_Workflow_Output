### Epic E07: Training & Certification Tracking

**User Story 1**
Title: Add Certification to Employee
User Story: As an HR, I want to add certifications to employee profiles so that qualifications are tracked.
Acceptance Criteria:
Scenario: Certification addition
Given employee and certification details
When I POST to /certifications
Then the certification is linked to the employee
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Document upload supported.

**User Story 2**
Title: Certification Expiry Alerts
User Story: As a SUPERVISOR, I want alerts for certifications expiring in 30/7 days so that renewals are timely.
Acceptance Criteria:
Scenario: Expiry alert
Given a certification nearing expiry
When the threshold is reached
Then an alert is sent to supervisor and employee
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: In-app and email.

**User Story 3**
Title: Block Unqualified Assignments
User Story: As a SUPERVISOR, I want scheduling checks to block assignment of tasks requiring expired certifications so that safety is ensured.
Acceptance Criteria:
Scenario: Assignment block
Given an expired certification
When I assign a task
Then the system prevents assignment
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Error message shown.

**User Story 4**
Title: Certification Status Visibility
User Story: As a WORKER, I want to view my certification status on my profile so that I know when to renew.
Acceptance Criteria:
Scenario: Status view
Given my profile
When I view certifications
Then status and expiry dates are shown
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Mobile-friendly.

**User Story 5**
Title: Certification Document Upload
User Story: As an HR, I want to upload proof documents for certifications so that compliance is documented.
Acceptance Criteria:
Scenario: Document upload
Given a certification
When I upload a document
Then it is stored and linked to the certification
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Secure storage required.
