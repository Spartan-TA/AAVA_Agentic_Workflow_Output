Title: Generate Payroll-Ready Files

User Story: As a payroll administrator I want to generate payroll-ready files from approved attendance and leave records so that I can ensure accurate and timely payroll processing.

Acceptance Criteria:
Scenario: Exporting payroll file
Given all attendance and leave records are approved for the pay period
When I initiate the payroll export
Then the system should generate a file in the required format and mark the records as exported

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04, E06
- Notes: Exported records should be locked from further edits.
