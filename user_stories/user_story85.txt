Title: Generate Onboarding Tasks for Training and Asset Assignment

User Story: As an HR manager I want onboarding tasks to be generated for required training and asset assignment So that new hires complete all prerequisites before starting work

Acceptance Criteria:
Scenario: Onboarding task generation
Given a new hire is onboarded
When onboarding tasks are generated
Then training and asset assignment tasks are created and tracked until completion

Additional Details:
- Priority: Medium
- Story Points: 4
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Task completion must be reported to HR before start date.
