Title: Define User Roles in System

User Story: As a system administrator I want to define user roles (ADMIN, HR, SUPERVISOR, WORKER) So that access permissions can be managed according to responsibilities

Acceptance Criteria:
Scenario: Role definition
Given the system is initialized
When I configure user roles
Then the roles should be available for assignment and access control

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee domain
- Notes: Document role permissions and hierarchy.
