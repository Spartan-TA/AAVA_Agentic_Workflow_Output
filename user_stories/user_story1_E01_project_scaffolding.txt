### Epic E01: Project Scaffolding & Domain Setup

**User Story 1**
Title: Initialize Spring Boot Project
User Story: As a DEVOPS ENGINEER, I want to initialize a Spring Boot project with Maven so that all modules have a standardized foundation.
Acceptance Criteria:
Scenario: Project setup
Given a clean repository
When I run the build command
Then the project builds and runs on port 8080
Additional Details:
Priority: High
Story Points: 5
Dependencies: None
Notes: README must include build/run steps.
