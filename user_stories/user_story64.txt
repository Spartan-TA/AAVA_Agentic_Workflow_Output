Title: Automated Test Coverage for Audit Logging

User Story:
As a QA engineer, I want automated tests to validate that all sensitive changes are logged so that audit coverage is complete and reliable.

Acceptance Criteria:
- Scenario: Test coverage for all sensitive actions
  Given sensitive actions (employee PII, schedule, approval, payroll) are performed
  When automated tests run
  Then audit log entries are created for each action

- Scenario: Coverage report includes audit logging
  Given the test suite is executed
  When the coverage report is generated
  Then all audit-related code paths are shown as covered

Additional Details:
- Tests must be included in CI pipeline
- Coverage must be at least 90% for audit logging code
- Tests must simulate all user roles
