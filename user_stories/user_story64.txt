Title: Implement Contract Tests for APIs

User Story: As a QA engineer I want to implement contract tests for all public APIs So that integrations remain stable and breaking changes are detected early

Acceptance Criteria:
Scenario: Running contract tests
Given a new API version is deployed
When contract tests are executed
Then all contract expectations are validated and failures are reported

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: API documentation, testing framework
- Notes: Contract tests should run in CI/CD and block releases on failure.
