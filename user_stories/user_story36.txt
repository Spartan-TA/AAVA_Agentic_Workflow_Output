Title: User Manage Notification Preferences

User Story: As a user I want to manage my notification preferences so that I receive important messages in my preferred way

Acceptance Criteria:
Scenario: Updating notification preferences
Given I am logged in as a user
When I update my notification preferences
Then my choices are saved and future notifications are sent accordingly

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User profile, notification module
- Notes: Support for email, SMS, and in-app notifications.
