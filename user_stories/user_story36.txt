Title: Safety Metrics Dashboard Endpoints

User Story:
As a safety manager, I want to access dashboard endpoints showing safety KPIs (incident rates, near-miss trends, resolution times) so that I can monitor and improve warehouse safety.

Acceptance Criteria:
- Scenario: Retrieve safety metrics
  Given incidents and near-misses are recorded
  When the dashboard endpoint is called
  Then current KPIs are returned in the response

- Scenario: Metrics are filterable
  Given dashboard filters (date range, department, severity)
  When the endpoint is called with filters
  Then only matching data is returned

Additional Details:
- Endpoints must be secured and role-based
- Metrics must include incident counts, rates, and average resolution time
- Data must be exportable for BI tools
