### E16 - Mobile Access (PWA)

**User Story 1: Responsive Mobile Views for Core Flows**
- Title: Mobile-Usable Core Flows
- Narrative: As a worker, I want to clock-in/out, view schedules, request leave, and see announcements on mobile so that I can work efficiently.
- Acceptance Criteria:
  ```
  Given a mobile device,
  When accessing core flows,
  Then UI is responsive and usable.
  ```
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Usability.

**User Story 2: Installable PWA Manifest**
- Title: Installable PWA Manifest
- Narrative: As a worker, I want to install the app as a PWA so that I have quick access.
- Acceptance Criteria:
  ```
  Given the app,
  When I install as PWA,
  Then it appears on my device home screen.
  ```
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1
- Notes: Accessibility.

**User Story 3: Offline Queue for Clock Events**
- Title: Offline Queue and Conflict Resolution
- Narrative: As a worker, I want clock events queued offline and resolved on reconnect so that my attendance is not lost.
- Acceptance Criteria:
  ```
  Given offline mode,
  When I clock in/out,
  Then events are queued and synced with conflict resolution on reconnect.
  ```
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1
- Notes: Reliability.

**User Story 4: Lighthouse PWA Score**
- Title: Achieve High Lighthouse PWA Score
- Narrative: As a developer, I want the app to score highly on Lighthouse so that performance and usability are validated.
- Acceptance Criteria:
  ```
  Given the PWA,
  When tested with Lighthouse,
  Then scores meet best practice thresholds.
  ```
- Priority: Medium
- Story Points: 1
- Dependencies: Story 1
- Notes: Quality.
