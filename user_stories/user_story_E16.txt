### E16 - Mobile Access (PWA)

**User Story 1**
- Title: Responsive Views for Core Flows
- User Story: As a worker, I want responsive views for clock-in/out, schedules, leave requests, and announcements so that I can use the app on mobile devices.
- Acceptance Criteria:
  - Given I access the app on mobile,
    When I use core flows,
    Then all features are usable and readable.
- Additional Details: Priority: Medium, Story Points: 3, Dependencies: E04, E05, E06, E12, Notes: Usability.

**User Story 2**
- Title: Installable PWA Manifest
- User Story: As a worker, I want the app to be installable as a PWA so that I can access it offline.
- Acceptance Criteria:
  - Given the manifest is configured,
    When I install the app,
    Then it appears on my device home screen.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E04, E05, E06, E12, Notes: Offline access.

**User Story 3**
- Title: Offline Queue for Clock Events with Conflict Resolution
- User Story: As a worker, I want clock events queued offline and resolved on reconnect so that attendance is not lost.
- Acceptance Criteria:
  - Given I am offline,
    When I clock in/out,
    Then events are queued and submitted when online, with conflicts resolved.
- Additional Details: Priority: Medium, Story Points: 2, Dependencies: E04, E05, E06, E12, Notes: Reliability.
