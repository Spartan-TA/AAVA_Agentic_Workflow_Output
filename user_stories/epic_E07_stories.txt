EPIC E07 - Training & Certification Tracking

User Story 1: Track Employee Certifications
As a safety manager I want to track required certifications, expirations, and renewals for employees So that compliance is maintained
Acceptance Criteria:
Scenario: Certification tracked
Given an employee
When a certification is added
Then expiration and renewal dates are recorded
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Support multiple cert types

User Story 2: Alert on Expiring Certifications
As a supervisor I want alerts for certifications expiring in 30 or 7 days So that renewals are not missed
Acceptance Criteria:
Scenario: Expiry alert sent
Given a certification near expiry
When the threshold is reached
Then an alert is sent to the employee and supervisor
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Configurable alert periods

User Story 3: Block Assignment for Expired Certifications
As a scheduler I want to block assignment to tasks requiring expired certifications So that only qualified staff are assigned
Acceptance Criteria:
Scenario: Assignment blocked
Given an expired certification
When I assign a task
Then the system prevents assignment
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Show reason for block

User Story 4: Upload Proof Documents
As an employee I want to upload proof of certification So that records are complete
Acceptance Criteria:
Scenario: Document uploaded
Given a certification
When I upload a file
Then it is stored and linked to the record
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Support PDF/JPG

User Story 5: Display Certification Status on Profile
As a supervisor I want to see certification status on employee profiles So that I can verify qualifications
Acceptance Criteria:
Scenario: Status visible
Given an employee profile
When I view it
Then all certifications and statuses are displayed
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Show expired/expiring status
