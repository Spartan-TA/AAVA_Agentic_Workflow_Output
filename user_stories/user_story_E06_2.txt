Title: Supervisor Leave Approval Workflow

User Story: As a Supervisor I want to review and approve or reject leave requests from my team so that staffing levels are maintained and absences are properly managed.

Acceptance Criteria:
Scenario: Reviewing a leave request
Given a leave request is pending
When I review the request details and documentation
Then I can approve or reject the request and the employee is notified

Scenario: Audit trail for approvals
Given a leave request is processed
When I approve or reject it
Then an audit log entry is created with decision and timestamp

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Leave module, Audit Trail
- Notes: Approval workflow must support delegation during Supervisor absence.
