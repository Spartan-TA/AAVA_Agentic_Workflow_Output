Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all sensitive changes (employee PII, schedules, approvals, payroll) to be logged centrally so that regulatory and internal audit requirements are met

Acceptance Criteria:
Scenario: Log sensitive change
  Given a create, update, or delete action occurs on sensitive data
  When the action is performed
  Then the actor, timestamp, and before/after values are recorded in an immutable log

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03 (Scheduling)
- Notes: Log must be tamper-evident and exportable
