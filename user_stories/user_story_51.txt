Title: WMS Integration for Department/Location Linking

User Story: As an operations manager I want to link departments and locations from the WMS system so that scheduling and reporting reflect accurate warehouse structure

Acceptance Criteria:
Scenario: Linking WMS departments and locations
Given the WMS connector is configured
When I import department and location data
Then the scheduling system updates its structure to match the WMS

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: WMS API, department/location modules
- Notes: Data mapping must be validated and idempotent
