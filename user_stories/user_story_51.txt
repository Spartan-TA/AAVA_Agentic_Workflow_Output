Title: Request Leave on Mobile

User Story: As an employee I want to request leave using my mobile device So that I can manage time off conveniently

Acceptance Criteria:
Scenario: Submit leave request on mobile
Given I am logged into the mobile app
When I submit a leave request
Then my manager should be notified and the request should appear in their approval queue

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Mobile app, leave management
- Notes: Support multiple leave types and attachments.
