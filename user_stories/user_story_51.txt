Title: Responsive Mobile Views for Clock-In/Out and Schedule

User Story: As a warehouse worker I want to clock in/out and view my schedule from my mobile device so that I can manage my work efficiently on the go.

Acceptance Criteria:
Scenario: Mobile clock-in/out
Given I am logged in on a mobile device
When I access the clock-in/out feature
Then I should be able to record my attendance and view my upcoming shifts in a mobile-optimized interface

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Interface should be PWA and offline-friendly.
