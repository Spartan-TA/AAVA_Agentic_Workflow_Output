Title: Docker Image Build and Registry Push

User Story: As a DevOps engineer I want the CI/CD pipeline to build a Docker image and push it to the registry so that deployments are consistent and versioned

Acceptance Criteria:
Scenario: Building and pushing Docker image
Given the pipeline runs successfully
When the build step completes
Then a tagged Docker image is pushed to the container registry

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Docker, CI/CD pipeline, container registry
- Notes: Image tags must include commit SHA and environment
