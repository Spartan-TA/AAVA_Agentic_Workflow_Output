EPIC E09: Equipment & Asset Assignment

---

Title: Assign Equipment to Employees
User Story: As a supervisor I want to assign equipment (scanners, forklifts, PPE) to employees So that asset usage is tracked
Acceptance Criteria:
Scenario: Assign asset to employee
Given an asset is available
When I assign it to an employee
Then the assignment is recorded and visible in the system

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Asset registry required

---

Title: Track Asset Checkout and Return
User Story: As an employee I want to check out and return assets So that accountability is maintained
Acceptance Criteria:
Scenario: Asset checkout/return
Given an asset is assigned to me
When I check it out or return it
Then the system updates the asset's status and logs the event

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Overdue returns flagged

---

Title: Block Asset Use if Certification Missing
User Story: As a supervisor I want to prevent asset assignment if required certifications are missing So that safety is enforced
Acceptance Criteria:
Scenario: Block unqualified asset assignment
Given an employee lacks a required certification
When I try to assign a restricted asset
Then the system blocks the assignment

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Integrate with certification tracking

---

Title: Maintain Asset Condition State
User Story: As a maintenance tech I want to update the condition of assets So that unsafe equipment is not used
Acceptance Criteria:
Scenario: Update asset condition
Given an asset is damaged or due for maintenance
When I update its condition
Then the status is reflected in the system and assignment is blocked if unsafe

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E07
- Notes: Condition history tracked

---

Title: Report Overdue Asset Returns
User Story: As an asset manager I want to see reports of overdue asset returns So that I can follow up with employees
Acceptance Criteria:
Scenario: Overdue asset report
Given assets are checked out
When the due date passes without return
Then the asset appears in the overdue report

Additional Details:
- Priority: Medium
- Story Points: 1
- Dependencies: E02, E03, E07
- Notes: Report exportable as CSV
