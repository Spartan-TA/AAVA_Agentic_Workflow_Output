### E10: Performance Reviews & Goals

#### 1. Title: Create Performance Review Templates
User Story: As an HR user I want to define review templates with goals and competencies So that reviews are standardized
Acceptance Criteria:
Scenario: Create template
Given template details
When I POST to `/reviews/templates`
Then the template is saved and available for assignment

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Support quarterly/annual cycles

---

#### 2. Title: Assign Reviews to Employees
User Story: As a supervisor I want to assign performance reviews to employees So that feedback is structured
Acceptance Criteria:
Scenario: Assign review
Given a template and employee
When I assign
Then the review is scheduled and visible to both parties

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Notify employee

---

#### 3. Title: Submit and Acknowledge Reviews
User Story: As a supervisor and employee I want to submit and acknowledge reviews So that the process is complete
Acceptance Criteria:
Scenario: Supervisor submits
Given a review is assigned
When the supervisor submits ratings and comments
Then the employee is notified to acknowledge

Scenario: Employee acknowledges
Given a submitted review
When the employee acknowledges
Then the review is marked complete

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03
- Notes: Track status

---

#### 4. Title: Export Reviews to PDF
User Story: As an HR user I want to export completed reviews to PDF So that records are archived
Acceptance Criteria:
Scenario: Export review
Given a completed review
When I export
Then a PDF is generated with all details

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Include signatures

---

#### 5. Title: Immutable Review History
User Story: As an HR user I want review history to be immutable after sign-off So that records are tamper-proof
Acceptance Criteria:
Scenario: Lock review
Given a review is acknowledged
When I attempt to edit
Then the system prevents changes

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Audit changes
