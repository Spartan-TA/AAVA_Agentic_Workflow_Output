### EPIC E04 - Time & Attendance (Clock In/Out)

#### User Story 1
Title: Implement Clock-In Endpoint with Validation

User Story: As a worker I want to clock in via an API endpoint So that my attendance is recorded

Acceptance Criteria:
Scenario: Clock-in event
Given I am scheduled for a shift
When I POST to /attendance/clock-in with my badgeId
Then my clock-in time is recorded and validated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Optionally capture geofence/device info

---

#### User Story 2
Title: Implement Clock-Out Endpoint with Validation

User Story: As a worker I want to clock out via an API endpoint So that my shift is completed

Acceptance Criteria:
Scenario: Clock-out event
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out time is recorded and shift hours calculated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Prevent duplicate clock-outs

---

#### User Story 3
Title: Handle Missed Punches and Corrections Workflow

User Story: As a supervisor I want to manage missed punches and corrections So that attendance records are accurate

Acceptance Criteria:
Scenario: Missed punch correction
Given a missed clock-in/out
When a correction request is submitted
Then an approval task is created for the supervisor

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: User Story 1, User Story 2
- Notes: Corrections are auditable

---

#### User Story 4
Title: Export Attendance Reports as CSV

User Story: As an HR user I want to export attendance reports as CSV So that I can analyze shift data

Acceptance Criteria:
Scenario: Attendance report export
Given attendance data for a period
When I request a CSV export
Then the file is generated with all relevant fields

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: User Story 1, User Story 2
- Notes: Support date range filtering

---

#### User Story 5
Title: Automatic Shift Association for Clock Events

User Story: As a worker I want my clock-in/out events to be automatically associated with my scheduled shift So that my hours are tracked correctly

Acceptance Criteria:
Scenario: Shift association
Given a clock-in event
When the event is recorded
Then it is linked to the correct scheduled shift

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E05
- Notes: Handle overnight shifts
