### Epic E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Implement Clock-In/Clock-Out Endpoints
User Story: As a warehouse worker I want to clock in and out via API So that my attendance is accurately recorded
Acceptance Criteria:
Scenario: Clock-in event
Given I am authenticated
When I POST to /attendance/clock-in
Then my clock-in time is recorded
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Device and optional geofence data captured

**User Story 2**
Title: Calculate Hours Worked Per Shift
User Story: As a payroll specialist I want the system to calculate hours worked per shift So that payroll is accurate
Acceptance Criteria:
Scenario: Shift hours calculation
Given clock-in and clock-out events exist
When I view the attendance report
Then total hours per shift are displayed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Handles overnight and multi-day shifts

**User Story 3**
Title: Handle Missed Punches and Corrections
User Story: As a supervisor I want to approve corrections for missed punches So that attendance records are accurate
Acceptance Criteria:
Scenario: Missed punch correction
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for the supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Corrections workflow must be auditable

**User Story 4**
Title: Export Attendance Reports
User Story: As an HR user I want to export attendance reports in CSV format So that I can analyze attendance data
Acceptance Criteria:
Scenario: Attendance report export
Given attendance data exists
When I request a CSV export
Then the file is generated and downloadable
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Reports must include daily totals and corrections
