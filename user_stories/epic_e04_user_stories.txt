### Epic E04: Time & Attendance (Clock In/Out)

#### User Story 1: Clock-In Endpoint with Validation
- **Title:** Employee Clock-In API
- **User Story:** As a worker, I want to clock in via an endpoint with geofence validation so that my attendance is accurately recorded.
- **Acceptance Criteria:**
  ```
  Scenario: Clock-in with geofence
    Given a worker is within the warehouse geofence
    When they POST to /attendance/clock-in
    Then their clock-in event is recorded
    And if outside geofence, request is rejected
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E02, E03
- **Notes:** Device capture optional.

#### User Story 2: Clock-Out Endpoint and Shift Association
- **Title:** Employee Clock-Out API
- **User Story:** As a worker, I want to clock out so that my worked hours are tracked and associated with the correct shift.
- **Acceptance Criteria:**
  ```
  Scenario: Clock-out and shift association
    Given a worker is clocked in
    When they POST to /attendance/clock-out
    Then their clock-out event is recorded and associated with their shift
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E02, E03
- **Notes:** Automatic shift association.

#### User Story 3: Handle Missed Punches and Corrections
- **Title:** Attendance Correction Workflow
- **User Story:** As a supervisor, I want to approve corrections for missed punches so that attendance records are accurate.
- **Acceptance Criteria:**
  ```
  Scenario: Attendance correction approval
    Given a missed punch is reported
    When a supervisor reviews and approves the correction
    Then the attendance record is updated and audit logged
  ```
- **Priority:** High
- **Story Points:** 3
- **Dependencies:** E02, E03
- **Notes:** Corrections create approval tasks.

#### User Story 4: Attendance Reporting and Export
- **Title:** Attendance Report Export
- **User Story:** As an HR user, I want to export attendance reports to CSV so that payroll processing is streamlined.
- **Acceptance Criteria:**
  ```
  Scenario: Export attendance report
    Given attendance data exists
    When I request a CSV export
    Then the file is generated with daily totals and corrections
  ```
- **Priority:** High
- **Story Points:** 2
- **Dependencies:** E02, E03
- **Notes:** Export includes corrections.
