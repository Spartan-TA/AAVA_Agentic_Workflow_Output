Epic E04: Time & Attendance (Clock In/Out)

---

User Story 4.1: Implement Clock-In/Clock-Out Endpoints

Title: Implement Clock-In/Clock-Out Endpoints

User Story: As a worker, I want to clock in and out via API so that my attendance is accurately recorded.

Acceptance Criteria:

Scenario: Valid clock event is saved
Given a POST to /attendance/clock-in or /clock-out
When valid data is provided
Then the event is saved

Scenario: Invalid clock event fails validation
Given an invalid request (e.g., outside geofence)
When I clock in/out
Then validation fails

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Core attendance.

---

User Story 4.2: Associate Clock Events with Shifts

Title: Associate Clock Events with Shifts

User Story: As a supervisor, I want clock events to be automatically linked to scheduled shifts so that hours worked are tracked.

Acceptance Criteria:

Scenario: Clock event linked to correct shift
Given a clock event
When a shift is scheduled
Then the event is associated with the correct shift

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04.1
- Notes: Accurate payroll.

---

User Story 4.3: Handle Missed Punches and Corrections

Title: Handle Missed Punches and Corrections

User Story: As a worker, I want to request corrections for missed punches so that my attendance is accurate.

Acceptance Criteria:

Scenario: Correction request creates approval task
Given a missed punch
When I submit a correction
Then an approval task is created for my supervisor

Scenario: Attendance updated after approval
Given an approval
When the supervisor approves/denies
Then the attendance record is updated accordingly

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E04.1
- Notes: Compliance.

---

User Story 4.4: Export Attendance Reports

Title: Export Attendance Reports

User Story: As an HR user, I want to export attendance data as CSV so that I can process payroll.

Acceptance Criteria:

Scenario: CSV export generated with daily totals
Given attendance records
When I request an export
Then a CSV file is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04.2
- Notes: Payroll integration.
