EPIC E04 - Time & Attendance (Clock In/Out)

===========================================

User Story 1
------------
Title: Clock-In Endpoint with Validation

User Story: As a worker, I want to clock in via an endpoint with location/device validation so that my attendance is accurately recorded.

Acceptance Criteria:
Scenario: Valid clock-in recorded
  Given a valid badgeId and location
  When I POST to /attendance/clock-in
  Then my clock-in is recorded and validated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Geofence optional.

===========================================

User Story 2
------------
Title: Clock-Out Endpoint and Shift Association

User Story: As a worker, I want to clock out and have my shift automatically associated so that hours worked are tracked.

Acceptance Criteria:
Scenario: Clock-out closes shift and calculates hours
  Given a valid clock-in
  When I POST to /attendance/clock-out
  Then my shift is closed and hours are calculated

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Handles missed punches.

===========================================

User Story 3
------------
Title: Missed Punch Correction Workflow

User Story: As a supervisor, I want to approve corrections for missed punches so that attendance data remains accurate.

Acceptance Criteria:
Scenario: Correction generates approval task
  Given a missed punch
  When a correction is submitted
  Then an approval task is generated for the supervisor

Scenario: Approved correction updates record
  Given supervisor approval
  When correction is accepted
  Then attendance record is updated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Approval workflow.

===========================================

User Story 4
------------
Title: Attendance Reporting and Export

User Story: As an HR user, I want to export attendance reports in CSV format so that payroll processing is streamlined.

Acceptance Criteria:
Scenario: Export attendance data to CSV
  Given attendance data
  When I request an export
  Then a CSV file is generated with daily totals

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Supports payroll integration.
