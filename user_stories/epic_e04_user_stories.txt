# Epic E04: Time & Attendance (Clock In/Out)

## User Story 1: Clock-In Endpoint
- **Title:** Employee Clock-In API
- **User Story:** As a worker, I want to clock in via an endpoint so that my attendance is recorded.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a worker is authenticated
  When they POST to /attendance/clock-in with location/device info
  Then a clock-in event is recorded
  And geofence validation is applied if enabled
  ```
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Device capture optional.

## User Story 2: Clock-Out Endpoint
- **Title:** Employee Clock-Out API
- **User Story:** As a worker, I want to clock out via an endpoint so that my shift end is recorded.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a worker is authenticated
  When they POST to /attendance/clock-out
  Then a clock-out event is recorded
  And hours worked are calculated
  ```
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Validate shift association.

## User Story 3: Missed Punch Correction Workflow
- **Title:** Attendance Correction Requests
- **User Story:** As a worker, I want to request corrections for missed punches so that my attendance is accurate.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a missed punch event
  When worker submits a correction request
  Then a supervisor approval task is created
  And upon approval, attendance is updated
  ```
- **Additional Details:** Priority: High, Story Points: 3, Dependencies: E02, E03, Notes: Track correction history.

## User Story 4: Attendance Reports Export
- **Title:** Export Attendance Reports
- **User Story:** As an HR user, I want to export attendance reports in CSV format so that payroll processing is streamlined.
- **Acceptance Criteria (Gherkin):**
  ```
  Given attendance data exists
  When HR requests a report export
  Then a CSV file is generated with daily totals
  And includes corrections
  ```
- **Additional Details:** Priority: High, Story Points: 2, Dependencies: E02, E03, Notes: Support date range filters.
