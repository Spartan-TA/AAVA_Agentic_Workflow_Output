### Epic E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint
User Story: As a warehouse worker, I want to clock in at the start of my shift so that my working hours are recorded.
Acceptance Criteria:
Scenario: Valid Clock-In
Given I am scheduled for a shift
When I POST to /attendance/clock-in
Then my clock-in event is recorded
And associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee API, RBAC
- Notes: Geofence/device capture optional

**User Story 2**
Title: Clock-Out Endpoint
User Story: As a warehouse worker, I want to clock out at the end of my shift so that my hours are accurately tracked.
Acceptance Criteria:
Scenario: Valid Clock-Out
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out event is recorded
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock-In
- Notes: Shift association required

**User Story 3**
Title: Missed Punch Correction Workflow
User Story: As a supervisor, I want to correct missed punches so that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction Request
Given a missed punch is detected
When a correction is submitted
Then an approval task is created
And upon approval, attendance is updated
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance endpoints
- Notes: Approval workflow required

**User Story 4**
Title: Attendance Report Export
User Story: As a payroll admin, I want to export attendance reports in CSV so that payroll processing is streamlined.
Acceptance Criteria:
Scenario: Export Attendance
Given attendance data exists
When I request a CSV export
Then the file is generated with daily totals
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Attendance data
- Notes: Export format must match payroll needs
