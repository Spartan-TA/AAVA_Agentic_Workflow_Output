EPIC E04 - TIME & ATTENDANCE (CLOCK IN/OUT)

===========================================

Title: Clock In/Out Endpoint

User Story: As a worker I want to clock in and out with device and location capture So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Clock in/out with validation
Given I am at the warehouse with my device
When I POST to /attendance/clock-in or /clock-out
Then my attendance is recorded with geofence and device info

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD, RBAC
- Notes: Validate location and device

---

Title: Calculate Hours Worked Per Shift

User Story: As a payroll processor I want the system to calculate hours worked per shift So that payroll is accurate

Acceptance Criteria:
Scenario: Automatic shift association and calculation
Given clock-in and clock-out events exist
When the system processes attendance
Then daily totals are computed and associated with the correct shift

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock in/out endpoint
- Notes: Handle overnight and split shifts

---

Title: Missed Punches and Corrections Workflow

User Story: As a worker I want to request corrections for missed punches So that my attendance record is accurate

Acceptance Criteria:
Scenario: Correction request and approval
Given I missed a punch
When I submit a correction request
Then an approval task is created for my supervisor

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock in/out endpoint, RBAC
- Notes: Track correction status

---

Title: Attendance Reports Export

User Story: As a supervisor I want to export attendance reports in CSV format So that I can analyze and share attendance data

Acceptance Criteria:
Scenario: Export attendance report
Given attendance data exists
When I request an export
Then I receive a CSV file with attendance details

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Attendance calculation
- Notes: Include filters for date range and employee
