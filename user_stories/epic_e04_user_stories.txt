## Epic E04: Time & Attendance (Clock In/Out)

### User Story 1: Clock-In Endpoint with Validation
**User Story:**  
As a warehouse worker, I want to clock in at the start of my shift so that my attendance is recorded.

**Acceptance Criteria (Gherkin):**
```
Given a valid employee and shift
When I POST to /attendance/clock-in
Then my clock-in event is recorded with timestamp and device info

Given a clock-in outside allowed geofence
When I POST to /attendance/clock-in
Then the request is rejected with an error
```

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: Employee CRUD, RBAC  
Notes: Geofence optional.

---

### User Story 2: Clock-Out Endpoint and Shift Association
**User Story:**  
As a warehouse worker, I want to clock out at the end of my shift so that my hours worked are calculated.

**Acceptance Criteria (Gherkin):**
```
Given a valid clock-in event
When I POST to /attendance/clock-out
Then my clock-out is recorded and hours worked are calculated

Given no prior clock-in
When I POST to /attendance/clock-out
Then the request is rejected with an error
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Clock-in endpoint  
Notes: Automatic shift association.

---

### User Story 3: Handle Missed Punches and Corrections
**User Story:**  
As a supervisor, I want to correct missed punches so that attendance records are accurate.

**Acceptance Criteria (Gherkin):**
```
Given a missed punch is detected
When a correction is submitted
Then an approval task is created for supervisor review

Given a supervisor approves a correction
When the correction is applied
Then the attendance record is updated
```

**Additional Details:**  
Priority: High  
Story Points: 3  
Dependencies: Attendance endpoints  
Notes: Approval workflow.

---

### User Story 4: Attendance Reporting and Export
**User Story:**  
As a payroll specialist, I want to export attendance data so that payroll can be processed.

**Acceptance Criteria (Gherkin):**
```
Given attendance records exist
When I request a report export
Then a CSV file is generated with daily totals per employee
```

**Additional Details:**  
Priority: High  
Story Points: 2  
Dependencies: Attendance endpoints  
Notes: Export format must match payroll requirements.
