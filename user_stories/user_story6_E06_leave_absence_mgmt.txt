## E06: Leave & Absence Management

### Story 1: Request Leave (PTO, Sick, Unpaid)
- **User Story:** As an employee, I want to request different types of leave so that my absences are tracked and approved.
- **Acceptance Criteria (Gherkin):**
  ```
  Scenario: Submit Leave Request
    Given I am logged in
    When I submit a leave request with type and dates
    Then the request is created and pending approval
  ```
- **Priority:** Medium
- **Story Points:** 3
- **Dependencies:** E02, E03, E05
- **Notes:** PTO, sick, unpaid.

### Story 2: Approve or Deny Leave Requests
- **User Story:** As a supervisor, I want to approve or deny leave requests so that staffing is managed.
- **Acceptance Criteria (Gherkin):**
  ```
  Given a leave request is pending
  When I approve or deny it
  Then the employee is notified and the balance is updated
  ```
- **Priority:** Medium
- **Story Points:** 3
- **Dependencies:** E06-1
- **Notes:** Notification required.

### Story 3: Update Leave Accrual Balances
- **User Story:** As an HR user, I want leave balances to update automatically so that accrual policies are enforced.
- **Acceptance Criteria (Gherkin):**
  ```
  Given an approved leave
  When the leave period starts
  Then the employee's leave balance is reduced accordingly
  ```
- **Priority:** Medium
- **Story Points:** 3
- **Dependencies:** E06-2
- **Notes:** Accrual policy configurable.

### Story 4: Exclude Approved Leave from Scheduling and Payroll
- **User Story:** As a scheduler, I want approved leaves to block shift assignments and payroll calculations so that absences are handled correctly.
- **Acceptance Criteria (Gherkin):**
  ```
  Given an employee has approved leave
  When generating schedules or payroll
  Then the leave period is excluded from shift assignments and payroll hours
  ```
- **Priority:** Medium
- **Story Points:** 5
- **Dependencies:** E05, E11
- **Notes:** Integration hooks required.

### Story 5: Export Approved Leave Records
- **User Story:** As an HR user, I want to export approved leave records so that I can report on absences.
- **Acceptance Criteria (Gherkin):**
  ```
  Given approved leave records exist
  When I request an export
  Then a CSV file is generated with leave details
  ```
- **Priority:** Medium
- **Story Points:** 2
- **Dependencies:** E06-3
- **Notes:** Export endpoint.
