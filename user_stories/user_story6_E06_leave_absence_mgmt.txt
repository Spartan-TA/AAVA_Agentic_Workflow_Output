[E06] Leave & Absence Management

Title: Request Leave (PTO, Sick, Unpaid)
User Story: As an employee I want to request leave so that my time off is tracked and approved.
Acceptance Criteria:
Scenario: Leave Request Submission
Given my account
When I submit a leave request
Then the request is recorded and pending approval

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03, E05
- Notes: Support multiple leave types

---

Title: Approve or Deny Leave Requests
User Story: As a supervisor I want to approve or deny leave requests so that staffing is managed.
Acceptance Criteria:
Scenario: Leave Approval Workflow
Given a pending leave request
When I approve or deny the request
Then the employee is notified and balances are updated

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Request Leave
- Notes: Track approval history

- Priority: Medium
- Story Points: 2
