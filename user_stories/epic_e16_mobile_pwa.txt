## User Story 3: Offline Queue for Clock Events
**User Story:**  
As a worker, I want to clock in/out offline and have events sync when online.

**Acceptance Criteria (Gherkin):**  
Given no network  
When I clock in/out  
Then the event is queued and syncs automatically when online

**Additional Details:**  
- Priority: Medium  
- Story Points: 2  
- Dependencies: E16-1  
- Notes: Conflict resolution for duplicate events
