Title: Export Performance Reviews to PDF

User Story: As an HR Manager I want to export finalized performance reviews to PDF so that I can archive and share official review documents securely.

Acceptance Criteria:
Scenario: PDF Export
Given a performance review is finalized
When I click the export to PDF button
Then a PDF file is generated containing all review details and is available for download

Scenario: PDF Format
Given a review contains multiple sections
When exported
Then the PDF preserves formatting, signatures, and timestamps

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: E02, E03
- Notes: PDF export must comply with company branding and data privacy standards.
