Title: Missed Punches and Corrections Workflow

User Story: As a warehouse worker I want to submit corrections for missed clock-in or clock-out events So that my attendance records are accurate and approved by a supervisor

Acceptance Criteria:
Scenario: Submit correction request
  Given I missed a clock-in or clock-out event
  When I submit a correction request
  Then an approval task is created for my supervisor

Scenario: Supervisor approval
  Given a correction request is pending
  When my supervisor reviews and approves the request
  Then my attendance record is updated accordingly

Scenario: Correction audit log
  Given a correction is processed
  When the status changes
  Then an audit entry is generated

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E02, E03
- Notes: Correction workflow must be tracked and exportable.
