Title: Revoke Roles from Users

User Story: As an admin I want to revoke roles from users So that I can immediately restrict access when necessary

Acceptance Criteria:
Scenario: Role revocation
Given I am logged in as an admin
When I remove a role from a user
Then the user should lose all permissions associated with that role

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Role assignment
- Notes: Revocation should be logged for audit purposes
