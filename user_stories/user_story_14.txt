Title: Audit Role Changes

User Story: As a compliance officer I want to audit all changes to user roles So that I can ensure accountability and traceability for access control

Acceptance Criteria:
Scenario: Logging role changes
  Given a user role is created, modified, or deleted
  When the change occurs
  Then an audit log entry should be generated with actor, timestamp, and change details
Scenario: Viewing audit logs
  Given I have compliance permissions
  When I access the audit log dashboard
  Then I should see a list of all role changes with filtering options

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Audit trail module
- Notes: Logs should be tamper-evident and exportable for compliance reviews.
