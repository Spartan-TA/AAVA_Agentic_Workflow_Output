Title: Implement Automated Security Tests

User Story: As a QA engineer I want automated tests for all security rules so that unauthorized access is reliably prevented and security regressions are caught early.

Acceptance Criteria:

Scenario: Test unauthorized access
Given a test suite for security
When tests run for unauthenticated requests
Then all protected endpoints should return 401 Unauthorized
And the tests should cover all API endpoints

Scenario: Test role-based restrictions
Given a test user with WORKER role
When tests attempt to access HR-only endpoints
Then all attempts should return 403 Forbidden
And the tests should verify all role combinations

Scenario: Test row-level security
Given a SUPERVISOR user for Department A
When tests attempt to access Department B employee data
Then access should be denied
And only Department A data should be accessible

Scenario: Security tests in CI pipeline
Given the CI pipeline is configured
When code is pushed to the repository
Then security tests should run automatically
And the build should fail if any security test fails

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: RBAC implementation (E03), Authentication (E03)
- Notes: Use Spring Security Test. Cover positive and negative test cases. Integrate with CI/CD pipeline. Maintain high test coverage for security code.
