Title: Edit Role Permissions

User Story: As an admin I want to edit role permissions So that I can update access controls as needed

Acceptance Criteria:
Scenario: Role permission editing
Given I am viewing a role
When I modify permissions and save changes
Then the role should reflect the updated permissions and users assigned to the role should inherit changes

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Role assignment
- Notes: Log changes for audit
