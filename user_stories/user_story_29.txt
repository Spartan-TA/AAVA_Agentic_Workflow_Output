Title: Track Equipment Return and Condition

User Story: As a warehouse employee I want to return assigned equipment and record its condition so that asset integrity is maintained and accountability is ensured.

Acceptance Criteria:
Scenario: Returning equipment
Given I have checked out equipment
When I return the equipment and specify its condition (e.g., Good, Needs Repair)
Then the system should update the asset's status to 'Available' or 'Maintenance' and log the return event

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Asset condition must be reviewed by supervisor if marked as 'Needs Repair'.
