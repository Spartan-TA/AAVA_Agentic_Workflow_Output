Title: Enforce Row-Level Security

User Story: As a supervisor, I want to access only my team's employee records So that privacy is maintained.

Acceptance Criteria:
Scenario: Row-level access
Given a supervisor user
When the user queries employee data
Then only records for their team are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Row-level constraints enforced
