## User Story 1: CRUD for Asset Registry
**User Story:**  
As an asset manager, I want to create, update, and delete assets (scanners, forklifts, PPE) so that inventory is accurate.

**Acceptance Criteria (Gherkin):**  
Given the asset module  
When I manage assets  
Then changes are saved and visible in the registry

**Additional Details:**  
- Priority: Medium  
- Story Points: 2  
- Dependencies: E02, E03, E07  
- Notes: Asset types configurable

---

## User Story 2: Assign and Track Asset Check-In/Out
**User Story:**  
As a supervisor, I want to assign assets to employees and track check-in/out so that usage is accountable.

**Acceptance Criteria (Gherkin):**  
Given an asset  
When I check it out to an employee  
Then the assignment is logged with timestamp

**Additional Details:**  
- Priority: Medium  
- Story Points: 2  
- Dependencies: E09-1  
- Notes: Overdue returns flagged

---

## User Story 3: Block Asset Use if Certification Missing
**User Story:**  
As a supervisor, I want to prevent asset assignment if required certifications are missing or expired.

**Acceptance Criteria (Gherkin):**  
Given an asset with certification requirement  
When assigning to an employee  
Then the system blocks assignment if cert is invalid

**Additional Details:**  
- Priority: Medium  
- Story Points: 2  
- Dependencies: E09-1, E07  
- Notes: Certification check on assignment

---

## User Story 4: Maintain Asset Condition State
**User Story:**  
As an asset manager, I want to record asset condition at check-in/out so that maintenance needs are tracked.

**Acceptance Criteria (Gherkin):**  
Given an asset transaction  
When I record condition  
Then it is saved and visible in asset history

**Additional Details:**  
- Priority: Low  
- Story Points: 1  
- Dependencies: E09-2  
- Notes: Condition options: Good, Needs Repair, Out of Service

---

## User Story 5: Asset Assignment and Return History
**User Story:**  
As an auditor, I want to view the history of asset assignments and returns per asset and employee.

**Acceptance Criteria (Gherkin):**  
Given an asset or employee  
When I view the history  
Then all check-in/out events are listed with timestamps

**Additional Details:**  
- Priority: Low  
- Story Points: 1  
- Dependencies: E09-2  
- Notes: Exportable as CSV
