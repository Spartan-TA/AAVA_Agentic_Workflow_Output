Title: Secure REST API Exposure for HRIS, WMS, and SSO

User Story: As a system integrator I want to access REST APIs for HRIS, WMS, and SSO so that I can synchronize employee and location data securely

Acceptance Criteria:
Scenario: API access with JWT/OAuth2
  Given I have valid credentials
  When I call the HRIS, WMS, or SSO API endpoint
  Then the request is authenticated and authorized using JWT or OAuth2 and data is returned as per OpenAPI documentation

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02, E03
- Notes: API endpoints must be documented and tested for security compliance.
