Title: Integrate SSO via IDP

User Story: As an IT administrator I want to enable single sign-on (SSO) for users via an identity provider (IDP) so that authentication is streamlined and secure.

Acceptance Criteria:
Scenario: User logs in with SSO
Given SSO is configured with the organization's IDP
When a user attempts to log in
Then the system should authenticate the user via the IDP and grant access if credentials are valid

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02, E03
- Notes: Support SAML and OAuth2-based IDPs.
