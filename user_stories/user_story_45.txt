Title: Centralized Audit Logging

User Story: As a compliance officer I want all system actions to be logged centrally So that audits and investigations are efficient and reliable

Acceptance Criteria:
Scenario: Log system action
Given a user performs an action
When the action is completed
Then the event should be recorded in the centralized audit log with timestamp and user details

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Logging module
- Notes: Support export and retention policies.
