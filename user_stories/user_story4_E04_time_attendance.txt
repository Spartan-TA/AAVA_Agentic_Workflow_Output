### Epic E04: Time & Attendance (Clock In/Out)

**User Story 1**
Title: Clock-In Endpoint
User Story: As a WORKER, I want to clock in via an endpoint so that my attendance is recorded.
Acceptance Criteria:
Scenario: Clock-in
Given my badgeId
When I POST to /attendance/clock-in
Then my clock-in event is recorded and validated
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Geofence/device capture optional.

**User Story 2**
Title: Clock-Out Endpoint
User Story: As a WORKER, I want to clock out via an endpoint so that my shift end is recorded.
Acceptance Criteria:
Scenario: Clock-out
Given I am clocked in
When I POST to /attendance/clock-out
Then my clock-out event is recorded
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Must associate with correct shift.

**User Story 3**
Title: Missed Punch Correction Workflow
User Story: As an HR, I want to handle missed punches and corrections so that attendance records are accurate.
Acceptance Criteria:
Scenario: Correction request
Given a missed punch
When I submit a correction
Then an approval task is created for supervisor
Additional Details:
Priority: High
Story Points: 5
Dependencies: E02, E03
Notes: Approval workflow required.

**User Story 4**
Title: Attendance Reporting
User Story: As a SUPERVISOR, I want daily totals and exportable reports so that I can review team attendance.
Acceptance Criteria:
Scenario: Attendance report
Given attendance data
When I export to CSV
Then daily totals are included
Additional Details:
Priority: High
Story Points: 3
Dependencies: E02, E03
Notes: Export must match payroll needs.

**User Story 5**
Title: Automatic Shift Association
User Story: As a WORKER, I want my clock-in/out events to automatically associate with my scheduled shift so that hours are calculated correctly.
Acceptance Criteria:
Scenario: Shift association
Given my schedule
When I clock in/out
Then events are linked to my shift
Additional Details:
Priority: High
Story Points: 2
Dependencies: E02, E03
Notes: Handles overnight shifts.
