### Epic E04: Time & Attendance (Clock In/Out)

#### 1. Implement Clock-In Endpoint
User Story: As a worker I want to clock in via an endpoint So that my attendance is recorded.
Acceptance Criteria:
Scenario: Successful clock-in
Given I am scheduled for a shift
When I POST to `/attendance/clock-in` with valid data
Then my clock-in event is recorded
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Capture device and optional geofence.

#### 2. Implement Clock-Out Endpoint
User Story: As a worker I want to clock out via an endpoint So that my shift end is recorded.
Acceptance Criteria:
Scenario: Successful clock-out
Given I am clocked in
When I POST to `/attendance/clock-out`
Then my clock-out event is recorded
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock-in endpoint
- Notes: Validate shift association.

#### 3. Calculate Hours Worked per Shift
User Story: As a supervisor I want hours worked per shift to be calculated automatically So that payroll is accurate.
Acceptance Criteria:
Scenario: Hours calculation
Given clock-in and clock-out events
When I view attendance records
Then hours worked are computed per shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Clock-in/out endpoints
- Notes: Handle overnight shifts.

#### 4. Handle Missed Punches and Corrections Workflow
User Story: As a worker I want to request corrections for missed punches So that my attendance is accurate.
Acceptance Criteria:
Scenario: Correction request
Given a missed punch
When I submit a correction
Then an approval task is created for my supervisor
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Attendance endpoints
- Notes: Track correction status.

#### 5. Export Attendance Reports (CSV)
User Story: As a payroll admin I want to export attendance reports in CSV format So that payroll processing is streamlined.
Acceptance Criteria:
Scenario: Attendance report export
Given attendance data exists
When I request a CSV export
Then the file is generated with correct data
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Attendance data
- Notes: Include filters for date/employee.
