**E04: Time & Attendance (Clock In/Out)**

1. Title: Record Clock-In Event
User Story: As a worker, I want to clock in at the start of my shift so that my attendance is accurately tracked.
Acceptance Criteria:
Scenario: Clock-In
Given a valid badgeId and location
When I POST to /attendance/clock-in
Then my clock-in event is recorded and associated with my shift
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Validate geofence if enabled.

2. Title: Record Clock-Out Event
User Story: As a worker, I want to clock out at the end of my shift so that my worked hours are calculated.
Acceptance Criteria:
Scenario: Clock-Out
Given a valid badgeId
When I POST to /attendance/clock-out
Then my clock-out event is recorded and hours are computed
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Handle missed punches.

3. Title: Handle Missed Punches and Corrections
User Story: As a supervisor, I want to approve corrections for missed punches so that attendance records remain accurate.
Acceptance Criteria:
Scenario: Correction Workflow
Given a missed punch
When a correction is submitted
Then an approval task is created and processed
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Story 1
- Notes: Track correction history.

4. Title: Export Attendance Reports
User Story: As a payroll admin, I want to export attendance reports in CSV format so that payroll processing is streamlined.
Acceptance Criteria:
Scenario: Report Export
Given attendance data
When I request an export
Then a CSV file is generated with daily totals
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Story 1
- Notes: Include corrections.
