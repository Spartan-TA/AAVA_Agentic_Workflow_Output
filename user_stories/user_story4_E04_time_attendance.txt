# Epic E04: Time & Attendance (Clock In/Out)

## User Story 1: Clock-In/Clock-Out Endpoints
**Title:** Implement Clock-In/Clock-Out Endpoints  
**Narrative:** As a warehouse worker, I want to clock in and out via API so that my attendance is accurately recorded.  
**Acceptance Criteria (Gherkin):**
```
Given a valid employee
When I POST to /attendance/clock-in or /clock-out
Then my attendance event is recorded
And validation checks are performed
```
**Priority:** High  
**Story Points:** 3  
**Dependencies:** E02, E03  
**Notes:** Capture device and location if available.

---

## User Story 2: Geofence and Device Capture
**Title:** Capture Geofence and Device Info on Clock Events  
**Narrative:** As a supervisor, I want clock events to record device and location so that compliance is ensured.  
**Acceptance Criteria (Gherkin):**
```
Given a clock-in/out event
When geofence and device info are available
Then they are stored with the attendance record
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E04  
**Notes:** Optional for initial release.

---

## User Story 3: Calculate Hours Worked per Shift
**Title:** Calculate Hours Worked per Shift  
**Narrative:** As a payroll manager, I want hours worked to be calculated per shift so that payroll is accurate.  
**Acceptance Criteria (Gherkin):**
```
Given clock-in and clock-out events
When a shift is completed
Then total hours worked are computed and associated with the shift
```
**Priority:** High  
**Story Points:** 3  
**Dependencies:** E04  
**Notes:** Handle overnight shifts.

---

## User Story 4: Handle Missed Punches and Corrections
**Title:** Missed Punches and Corrections Workflow  
**Narrative:** As a worker, I want to request corrections for missed punches so that my attendance is accurate.  
**Acceptance Criteria (Gherkin):**
```
Given a missed punch
When I submit a correction request
Then an approval task is created for my supervisor
When approved, attendance is updated
```
**Priority:** High  
**Story Points:** 3  
**Dependencies:** E04  
**Notes:** Track correction history.

---

## User Story 5: Export Attendance Reports
**Title:** Export Attendance Reports (CSV)  
**Narrative:** As an HR user, I want to export attendance data to CSV so that I can analyze and share records.  
**Acceptance Criteria (Gherkin):**
```
Given attendance data
When I request an export
Then a CSV file is generated with all relevant fields
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E04
