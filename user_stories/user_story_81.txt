Title: Rollback Capability in Deployment Pipeline

User Story: As a release manager I want a tested rollback script in the CI/CD pipeline so that I can quickly revert to a previous version if a deployment fails

Acceptance Criteria:
Scenario: Executing rollback
Given a deployment fails or is rolled back
When I run the rollback script
Then the previous stable version is restored and all services are operational

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: CI/CD pipeline, rollback scripts
- Notes: Rollback must be tested in staging before production
