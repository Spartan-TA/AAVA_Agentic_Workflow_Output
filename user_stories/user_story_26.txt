Title: Incident Investigation Workflow
User Story: As a safety officer I want to manage the workflow for investigating safety incidents so that corrective actions are documented and tracked
Acceptance Criteria:
Scenario: Start investigation
Given an incident is recorded and status is Open
When I assign it for investigation
Then the status changes to Investigating and investigation fields become editable
Scenario: Resolve investigation
Given an incident is Investigating
When corrective actions are documented and investigation is complete
Then the status changes to Resolved and the incident is locked for editing
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Workflow must be auditable
