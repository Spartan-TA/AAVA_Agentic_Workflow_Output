### Epic E20: Self-Service Portal

#### 1. Enable Employee Login to Portal
User Story: As a worker I want to log in to the self-service portal So that I can access my information.
Acceptance Criteria:
Scenario: Portal login
Given I am a registered employee
When I enter credentials
Then I am logged in and see my dashboard
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E02, E03
- Notes: Secure session management.

#### 2. Allow Profile Updates for Allowed Fields
User Story: As a worker I want to update allowed fields in my profile So that my information is current.
Acceptance Criteria:
Scenario: Profile update
Given I am logged in
When I edit allowed fields
Then changes are saved and visible
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Portal login
- Notes: HR approval for sensitive fields.

#### 3. Submit Schedule Swap Requests
User Story: As a worker I want to submit schedule swap requests So that I can manage my shifts.
Acceptance Criteria:
Scenario: Schedule swap request
Given I am assigned a shift
When I request a swap
Then the request is sent to my supervisor for approval
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Portal login, E05
- Notes: Track swap status.
