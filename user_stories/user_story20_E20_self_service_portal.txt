**E20: Self-Service Portal**

1. Title: Employee Self-Service Dashboard
User Story: As an employee, I want a dashboard to view my schedule, attendance, leave balances, and announcements so that I can manage my work life.
Acceptance Criteria:
Scenario: Dashboard Access
Given an authenticated employee
When I log in
Then my personal data is displayed
Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Mobile-friendly.

2. Title: Submit Requests via Portal
User Story: As an employee, I want to submit leave, shift swap, and correction requests via the portal so that my needs are addressed efficiently.
Acceptance Criteria:
Scenario: Request Submission
Given a logged-in employee
When I submit a request
Then it is routed to the appropriate workflow
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1
- Notes: Track request status.

3. Title: View Request Status
User Story: As an employee, I want to view the status of my requests so that I am informed of progress and outcomes.
Acceptance Criteria:
Scenario: Status Tracking
Given submitted requests
When I view my dashboard
Then status and history are displayed
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Story 2
- Notes: Notify on status change.
