# Epic E18: Localization & Multi-Tenant

## User Story 1: Localize UI and Notifications
**Title:** Localize UI and Notifications  
**Narrative:** As a worker, I want the UI and notifications in my preferred language so that I can use the system comfortably.  
**Acceptance Criteria (Gherkin):**
```
Given language preferences
When I set my preferred language
Then UI and notifications are displayed accordingly
```
**Priority:** Medium  
**Story Points:** 3  
**Dependencies:** E12  
**Notes:** Support at least English and Spanish.

---

## User Story 2: Localize Date, Time, and Currency Formats
**Title:** Localize Date, Time, and Currency Formats  
**Narrative:** As a worker, I want dates, times, and currency displayed in my locale so that information is clear.  
**Acceptance Criteria (Gherkin):**
```
Given my locale settings
When I view dates, times, or currency
Then formats match my locale
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E18  
**Notes:** Use standard localization libraries.

---

## User Story 3: Localize Exported Reports
**Title:** Localize Exported Reports  
**Narrative:** As a manager, I want exported reports in my preferred language and format so that sharing is easier.  
**Acceptance Criteria (Gherkin):**
```
Given report exports
When I select a language and format
Then the report is generated accordingly
```
**Priority:** Medium  
**Story Points:** 2  
**Dependencies:** E15, E18  
**Notes:** Support CSV/PDF exports.
