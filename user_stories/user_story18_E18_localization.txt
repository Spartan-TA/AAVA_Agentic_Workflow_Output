[E18] Localization & Multi-Tenant

Title: Support Multiple Languages in UI
User Story: As a warehouse worker I want the UI available in multiple languages so that I can use the system comfortably.
Acceptance Criteria:
Scenario: Language Selection
Given supported languages
When I select a language
Then UI text updates accordingly

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: None
- Notes: Start with English/Spanish

---

Title: Localize Notification and Report Templates
User Story: As a localization manager I want notification and report templates localized so that communications are clear.
Acceptance Criteria:
Scenario: Template Localization
Given templates
When I select a language
Then notifications and reports are generated in that language

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Support Multiple Languages in UI
- Notes: Support dynamic content

Title: Store User Language Preferences
User Story: As a user I want my language preference stored so that I always see the UI in my chosen language.
Acceptance Criteria:
Scenario: Language Preference Storage
Given my user settings
When I change language preference
Then it is saved and applied on login

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Support Multiple Languages in UI
- Notes: Default to English
