Title: Configure User Roles

User Story: As an admin I want to define user roles (ADMIN, HR, SUPERVISOR, WORKER) so that access can be restricted based on responsibilities.

Acceptance Criteria:
Scenario: Role creation
Given I am logged in as ADMIN
When I create or edit a role
Then the role is available for assignment and reflected in the system

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Roles must be persisted and retrievable via API.
