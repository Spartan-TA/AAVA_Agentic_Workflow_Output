Title: E03-1 Implement Role-Based Endpoint Security

User Story:
As a security administrator,
I want all API endpoints to enforce role-based access control (RBAC),
So that only authorized users can access or modify sensitive data and actions.

Acceptance Criteria:
Given an authenticated user with a specific role,
When they call an API endpoint,
Then access is granted or denied based on their assigned permissions.

Given a user with insufficient permissions,
When they attempt to access a restricted endpoint,
Then access is denied with a 403 Forbidden error and no sensitive data is leaked.

Given a change in user role,
When the role is updated,
Then the new permissions take effect immediately for all subsequent API calls.

Additional Details:
- Roles: Admin, HR, Supervisor, Employee, Auditor.
- Permissions matrix must be documented and reviewed.
- Security must be enforced at the API gateway and application layers.
- All access attempts must be logged for audit purposes.
