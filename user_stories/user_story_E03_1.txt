Title: Implement Role-Based Endpoint Security

User Story: As a system administrator I want to enforce role-based access control on all API endpoints so that only authorized users can access or modify sensitive data

Acceptance Criteria:
Scenario: Unauthorized access attempt
Given a user is not authenticated
When they attempt to access a protected endpoint
Then the system returns a 401 Unauthorized response

Scenario: Forbidden action by insufficient role
Given a user is authenticated as a WORKER
When they attempt to access an ADMIN-only endpoint
Then the system returns a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: All endpoints must be annotated with appropriate security roles; automated tests must validate access rules.
