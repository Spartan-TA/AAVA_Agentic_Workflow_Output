Title: Role Creation and Assignment

User Story: As an admin I want to create and assign roles to users so that access permissions are managed securely and efficiently

Acceptance Criteria:
Scenario: Assigning roles to users
Given I am logged in as an admin
When I create a new role and assign it to a user
Then the user should have access only to the permitted functionalities

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER; must be configurable via UI and API.
