Title: Assign Roles to Users

User Story: As an admin I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) to users So that access permissions are enforced according to job responsibilities

Acceptance Criteria:
Scenario: Successful role assignment
Given I am on the user management page
When I select a user and assign a role
Then the user should have access only to the endpoints and data permitted for that role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Role changes should be auditable.
