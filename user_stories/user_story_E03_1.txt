Title: Implement Role Assignment and Endpoint Security

User Story: As an Admin I want to assign roles (ADMIN, HR, SUPERVISOR, WORKER) and secure endpoints/methods so that only authorized users can access sensitive operations and data.

Acceptance Criteria:
Scenario: Role assignment
Given an employee record exists
When I assign a role to the employee
Then the role is stored and reflected in their profile

Scenario: Endpoint security
Given I have a specific role
When I access a protected endpoint
Then access is granted or denied based on my role

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API (E02), Project scaffolding (E01)
- Notes: Security rules must be covered by automated tests.
