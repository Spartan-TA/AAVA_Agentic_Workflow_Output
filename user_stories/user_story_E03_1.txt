Title: Define Role Permissions

User Story: As a System Administrator I want to configure permissions for ADMIN, HR, Supervisor, and Worker roles so that access to system features is securely managed.

Acceptance Criteria:
Scenario: Assigning permissions to roles
Given I am on the role management page
When I select a role and assign specific permissions
Then the role should have access only to the assigned features

Scenario: Restricting access based on role
Given a user is assigned the Worker role
When the user attempts to access an ADMIN-only endpoint
Then access should be denied with an appropriate error message

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Spring Security module
- Notes: Ensure permissions are granular and auditable.
