Title: Shift Template Creation
User Story: As an HR manager I want to create shift templates with rotations and overtime rules So that scheduling is standardized
Acceptance Criteria:
Scenario: Shift template creation
Given I have HR role access
When I create a new shift template
Then it should include rotation and overtime parameters
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee domain, RBAC, Attendance
- Notes: Support multiple shift types

Title: Assign Shifts to Employees
User Story: As a supervisor I want to assign shifts to employees So that work schedules are managed efficiently
Acceptance Criteria:
Scenario: Shift assignment
Given shift templates exist
When I assign a shift to an employee
Then the employee's schedule should be updated and visible
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Shift templates
- Notes: Notify employees of schedule changes
