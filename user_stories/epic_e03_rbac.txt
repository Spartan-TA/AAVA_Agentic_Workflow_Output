### EPIC E03 - Role-Based Access Control (RBAC)

**User Story 1**
Title: Implement Role-Based Endpoint Security

User Story: As a System Administrator I want endpoints secured by role So that only authorized users can access sensitive data

Acceptance Criteria:
Scenario: Unauthorized access
Given a user without proper role
When they access a restricted endpoint
Then the API returns 401 Unauthorized

Scenario: Forbidden action
Given a user with insufficient privileges
When they attempt a forbidden action
Then the API returns 403 Forbidden

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Cover security rules with automated tests

**User Story 2**
Title: Configure API Key/OAuth2 Toggle

User Story: As a System Administrator I want to toggle between API key and OAuth2 authentication So that integration flexibility is maintained

Acceptance Criteria:
Scenario: Authentication toggle
Given the config is set to OAuth2
When I authenticate with OAuth2
Then access is granted per role

Scenario: API key mode
Given the config is set to API key
When I authenticate with API key
Then access is granted per role

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Document configuration steps

**User Story 3**
Title: Enforce Row-Level Security for Supervisors

User Story: As a Supervisor I want to access only my team's records So that privacy and compliance are maintained

Acceptance Criteria:
Scenario: Supervisor access
Given a supervisor logged in
When they GET /employees
Then only employees in their team are returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Map supervisor to team in user profile
