Title: Support Multiple Warehouses with Distinct Policies
User Story: As an operations manager I want to configure multiple warehouses with distinct policies So that each location can operate according to its requirements
Acceptance Criteria:
Scenario: Multi-warehouse configuration
  Given I am an admin
  When I add a new warehouse and set its policies
  Then the system should apply those policies only to that warehouse
Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Warehouse management module
- Notes: Policy types include scheduling, safety, and attendance

Title: Enable Spanish/English UI Localization
User Story: As a warehouse employee I want to use the EMS platform in Spanish or English So that I can interact in my preferred language
Acceptance Criteria:
Scenario: UI localization
  Given I select my language preference
  When I access EMS
  Then the UI should display in the selected language
Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Localization module, UI framework
- Notes: Language toggle available in settings

Title: Assign Employees to Specific Warehouses
User Story: As an HR manager I want to assign employees to specific warehouses So that their schedules and policies are location-specific
Acceptance Criteria:
Scenario: Employee warehouse assignment
  Given multiple warehouses exist
  When I assign an employee to a warehouse
  Then the employee should inherit that warehouse's policies and schedule
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Employee profile, warehouse management
- Notes: Employees may be reassigned as needed
