Title: Capture Device Information on Clock In/Out

User Story: As a system administrator I want to capture device information during clock in/out So that I can audit attendance and detect unauthorized device usage

Acceptance Criteria:
Scenario: Clock in with device capture
  Given I am clocking in using a device
  When I submit a clock-in request
  Then the device ID and type should be recorded with the attendance event
Scenario: Viewing device logs
  Given I am an administrator
  When I review attendance logs
  Then I should see device information for each clock in/out event

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Device registry, attendance endpoint
- Notes: Device information should be included in audit exports.
