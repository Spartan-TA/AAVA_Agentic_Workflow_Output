Title: Request Shift Swap
User Story: As an employee I want to request a shift swap with a colleague So that I can manage personal commitments without disrupting operations
Acceptance Criteria:
Scenario: Shift swap request
Given I am assigned to a shift
When I submit a swap request to a colleague
Then the supervisor should be notified and approve or reject the request
Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Notification module, approval workflow
- Notes: Track swap history for audit.
