Title: Create Recurring Shift Templates

User Story: As an HR manager I want to define recurring shift templates So that I can efficiently schedule employees for regular warehouse operations

Acceptance Criteria:
Scenario: Create a new shift template
Given I have access to the scheduling module
When I define a new recurring shift pattern and save it
Then the template is available for assignment to employees

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee Master Data, RBAC, Time & Attendance
- Notes: Templates should support daily, weekly, and custom recurrence.
