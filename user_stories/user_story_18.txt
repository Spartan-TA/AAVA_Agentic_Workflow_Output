Title: Approve or Deny Leave

User Story: As a manager I want to approve or deny leave requests so that team availability is managed

Acceptance Criteria:
Scenario: Review leave request
Given a leave request is submitted
When I review the request and select approve or deny
Then the employee should be notified of the decision

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Leave management module, Notification module
- Notes: Capture reason for denial.
