Title: SSO Integration via IDP

User Story: As an employee I want to log in using single sign-on (SSO) with my corporate identity provider so that I have seamless and secure access to the system

Acceptance Criteria:
Scenario: Logging in with SSO
Given my account is provisioned in the IDP
When I select the SSO login option
Then I am authenticated via the IDP and granted access to the application

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: IDP integration, authentication module
- Notes: SSO must support SAML and OAuth2 flows
