Title: Send Automated Notifications for Key Events

User Story: As a system I want to send automated notifications for key events (e.g., shift changes, approvals) So that users are kept informed in real time

Acceptance Criteria:
Scenario: Automated notification sending
Given a key event occurs in the system
When the event is triggered
Then the relevant users should receive a notification based on their preferences

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Event triggers, notification preferences
- Notes: Support for event-based notification rules
