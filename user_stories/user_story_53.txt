Title: Automate Onboarding

User Story: As an HR administrator I want onboarding tasks to be automated So that new employees are set up efficiently and consistently

Acceptance Criteria:
Scenario: Automated onboarding
Given a new employee is added
When onboarding is initiated
Then the system should assign tasks, send welcome emails, and provision accounts automatically

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: HRIS, task management, email system
- Notes: Support onboarding checklist and document uploads.
