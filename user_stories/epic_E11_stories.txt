EPIC E11 - Payroll Export Integration

User Story 1: Generate Payroll-Ready Export Files
As a payroll user I want to generate export files from approved attendance and leave So that payroll processing is automated
Acceptance Criteria:
Scenario: Export generated
Given approved records
When I run export
Then a file matching provider schema is created
Priority: High
Story Points: 2
Dependencies: E04, E06
Notes: Support multiple formats

User Story 2: Map Data to External Provider Formats
As a developer I want to map export data to external payroll provider formats So that integration is seamless
Acceptance Criteria:
Scenario: Data mapped
Given export configuration
When I generate a file
Then fields match provider requirements
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Support field mapping

User Story 3: Deliver Export Files Securely
As an admin I want to deliver export files via SFTP or API So that data is transmitted securely
Acceptance Criteria:
Scenario: Secure delivery
Given an export file
When delivery is triggered
Then file is sent securely
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Log all deliveries

User Story 4: Retry Failed Deliveries with Backoff
As a system I want to retry failed deliveries with exponential backoff So that exports are reliably delivered
Acceptance Criteria:
Scenario: Retry on failure
Given a failed delivery
When retry logic runs
Then delivery is retried with backoff
Priority: High
Story Points: 1
Dependencies: User Story 3
Notes: Limit max retries

User Story 5: Audit Log for Every Export
As an auditor I want an audit log for every export So that all actions are traceable
Acceptance Criteria:
Scenario: Export logged
Given an export event
When it completes
Then details are logged with timestamp and user
Priority: High
Story Points: 1
Dependencies: User Story 1
Notes: Include success/failure status
