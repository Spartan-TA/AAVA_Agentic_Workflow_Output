### E17: Onboarding & Offboarding Workflow

#### User Story 1
**Title:** Automated Onboarding from HRIS
**User Story:** As an HR I want new hires provisioned automatically from HRIS So that onboarding is efficient
**Acceptance Criteria (Gherkin):**
```
Given new hire data in HRIS
When sync runs
Then employee account is created and initial schedule assigned

Given missing required data
When onboarding runs
Then errors are logged
```
**Additional Details:** Priority: Medium, Story Points: 3, Dependencies: E02, E03, E05, E07, E09, E13, Notes: Training tasks generated

#### User Story 2
**Title:** Asset Assignment During Onboarding
**User Story:** As a SUPERVISOR I want assets assigned to new hires during onboarding So that equipment is ready on day one
**Acceptance Criteria (Gherkin):**
```
Given new hire onboarding
When asset assignment tasks are generated
Then assets are provisioned and logged

Given missing certification
When assigning assets
Then assignment is blocked
```
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, E07, E09, E13, Notes: Asset workflow

#### User Story 3
**Title:** Automated Offboarding
**User Story:** As an HR I want terminated employees deprovisioned automatically So that access and assets are recovered
**Acceptance Criteria (Gherkin):**
```
Given termination in HRIS
When offboarding runs
Then access is revoked, assets collected, and schedules updated

Given missing asset return
When offboarding completes
Then alert is generated for overdue assets
```
**Additional Details:** Priority: Medium, Story Points: 2, Dependencies: E02, E03, E05, E07, E09, E13, Notes: Deprovision workflow
