Title: Conflict Resolution and Performance for Mobile Clock Events

User Story: As a warehouse worker I want offline clock events to be resolved with the server upon reconnection and the app to perform well so that my attendance is accurate and the app is responsive.

Acceptance Criteria:

Scenario: Conflict resolution for clock events
Given multiple offline clock events are queued
When the app reconnects
Then conflicts are resolved according to business rules and the user is notified of the outcome

Scenario: Mobile app performance
Given large schedules and announcements
When I access the app
Then screens load within 2 seconds and scrolling is smooth

Scenario: Error handling for offline actions
Given an error occurs during sync
When the app reconnects
Then the user is notified and can retry or resolve the issue

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E04, E05, E06, E12
- Notes: Ensures reliability and user satisfaction.
