### E16: Mobile Access (PWA)

**User Story 1**
Title: Mobile Clock-In/Out

User Story: As a WORKER I want to clock in/out from my mobile device So that attendance is convenient.

Acceptance Criteria:
Scenario: Mobile Clock-In
Given mobile access
When I clock in/out
Then the event is recorded as on desktop

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: E04, E05, E06, E12
- Notes: Responsive UI required

---

**User Story 2**
Title: Mobile Shift and Leave Management

User Story: As a WORKER I want to view schedules and request leave from mobile So that I manage my work-life balance easily.

Acceptance Criteria:
Scenario: Mobile Schedule/Leave

Then the actions are available and usable

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: Story 1
