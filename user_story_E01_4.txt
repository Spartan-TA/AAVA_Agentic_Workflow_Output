Title: README Documentation for Project Setup

User Story: As a Developer I want a comprehensive README with build and run instructions So that new team members can quickly set up and contribute to the EMS project

Acceptance Criteria:
Scenario: README Availability
  Given the repository is initialized
  When I open the README file
  Then it should contain build and run steps for the EMS application

Scenario: Module Overview
  Given the README is present
  When I review its contents
  Then it should describe the base package structure and core modules

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Spring Boot project initialization
- Notes: README should be updated with each new module addition
