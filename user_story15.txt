Title: RBAC - Automated Security Test Coverage
User Story: As a QA engineer, I want automated tests to validate all security rules and role-based access so that vulnerabilities are detected early and compliance is maintained.
Acceptance Criteria:
  Given the RBAC system is implemented
  When automated security tests are executed
  Then all unauthorized and forbidden actions are covered and validated
Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: E01, E02
  Notes: Test suite must include coverage for all roles and endpoints.
