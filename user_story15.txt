Title: Implement Clock-In and Clock-Out Endpoints

User Story: As a warehouse worker I want to clock in and out via an API endpoint so that my attendance is accurately recorded for payroll and compliance.

Acceptance Criteria:

Scenario: Clock-in event recorded
Given a valid employee and shift
When I POST to /attendance/clock-in
Then a clock-in event is created with timestamp, device, and geofence data

Scenario: Clock-out event recorded
Given an employee is clocked in
When I POST to /attendance/clock-out
Then a clock-out event is created and hours worked are calculated

Scenario: Invalid clock-in/out rejected
Given invalid or missing employee data
When I POST to /attendance/clock-in or /clock-out
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Foundation for attendance and payroll calculations.
