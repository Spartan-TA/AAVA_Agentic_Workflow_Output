Title: Role-Based Access and Compliance Tests for Audit Logs

User Story: As a compliance officer I want access to audit logs to be restricted by role and validated by automated tests so that sensitive data is protected and compliance is ensured.

Acceptance Criteria:

Scenario: Role-based access enforced
Given a user requests audit log data
When they lack the required role
Then access is denied

Scenario: Automated tests validate coverage
Given audit logging is implemented
When automated tests run
Then all sensitive actions are verified to be logged

Scenario: Audit log access attempts logged
Given users attempt to access audit logs
When I review the audit log
Then all access attempts (success/failure) are recorded

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E03
- Notes: Supports compliance and data security.
