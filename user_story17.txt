Title: Onboarding - Automate New Hire Provisioning

User Story: As an HR I want new hires to be automatically provisioned with accounts, schedules, and training So that onboarding is fast and error-free.

Acceptance Criteria:
Scenario: Automated onboarding
Given a new hire appears from HRIS
When onboarding runs
Then accounts, initial schedule, and required training are created

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Tasks generated for asset assignment

Title: Offboarding - Automate Termination Workflow

User Story: As an HR I want terminated employees to be deprovisioned and assets collected So that access is revoked and assets are returned.

Acceptance Criteria:
Scenario: Automated offboarding
Given an employee is terminated
When offboarding runs
Then access is revoked, assets are collected, and schedules are updated

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E05, E07, E09, E13
- Notes: Updates all related modules
