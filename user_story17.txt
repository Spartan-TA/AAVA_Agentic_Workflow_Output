Title: Enforce Geofence and Device Capture for Clock Events

User Story: As a compliance manager I want clock-in/out events to capture device and location data so that I can ensure employees are on-site and using approved devices.

Acceptance Criteria:

Scenario: Clock event includes geofence data
Given an employee clocks in/out
When the event is recorded
Then the location (latitude/longitude) is stored with the event

Scenario: Clock event includes device ID
Given an employee clocks in/out
When the event is recorded
Then the device ID is stored with the event

Scenario: Out-of-geofence clock-in rejected
Given an employee attempts to clock in outside the allowed area
When the event is submitted
Then the request is rejected with a validation error

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E02, E03
- Notes: Supports fraud prevention and regulatory compliance.
