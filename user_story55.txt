Title: Role-Based Access and Documentation for Payroll Exports

User Story: As a payroll administrator I want payroll export features to be accessible only to authorized roles and documented for audit so that sensitive data is protected and processes are clear.

Acceptance Criteria:

Scenario: Role-based access enforced
Given a user requests payroll export
When they lack the required role
Then access is denied

Scenario: Export process documented
Given payroll export features are implemented
When I review the documentation
Then I see clear instructions and audit requirements

Scenario: Audit log includes access attempts
Given users attempt to access payroll exports
When I review the audit log
Then all access attempts (success/failure) are recorded

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E04, E06
- Notes: Supports compliance and data security.
