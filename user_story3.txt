Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access control so that only authorized users can perform sensitive operations and access protected data.

Acceptance Criteria:
Scenario: Unauthorized access
  Given a user without valid credentials
  When they attempt to access a protected endpoint
  Then the system returns a 401 Unauthorized error

Scenario: Forbidden action
  Given a user with insufficient privileges
  When they attempt to perform an admin-only operation
  Then the system returns a 403 Forbidden error

Scenario: Role assignment and enforcement
  Given users with roles ADMIN, HR, SUPERVISOR, WORKER
  When they access endpoints
  Then permissions are enforced according to their role

Scenario: Security configuration
  Given the system is running
  When API key or OAuth2 is enabled via config
  Then authentication is required for all endpoints

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Security rules must be covered by automated tests. Support method/endpoint and row-level constraints.
