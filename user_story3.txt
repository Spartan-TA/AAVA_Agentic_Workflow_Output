# User Story 3: Set Up Flyway/Liquibase for DB Migrations

**Epic:** E01 - Project Scaffolding & Domain Setup

**Title:** Set Up Flyway/Liquibase for DB Migrations

**User Story:** As a developer, I want to enable Flyway or Liquibase so that database migrations are automated and version-controlled.

**Acceptance Criteria (Gherkin):**
```
Given the project configuration
When I run the migration tool
Then the baseline migration is applied successfully

Given a new migration script
When I deploy the application
Then the database schema updates without errors
```

**Additional Details:**
- Priority: High
- Story Points: 3
- Dependencies: User Story 1
- Notes: Supports DB evolution.
