Title: Enable Actuator Health Endpoint
User Story: As a DevOps engineer, I want to enable the Actuator health endpoint so that system health can be monitored automatically.
Acceptance Criteria:
  - Given the running application, When I access /actuator/health, Then I receive a status of UP if all dependencies are healthy.
  - Given a dependency failure, When I access /actuator/health, Then the status reflects the failure.
Additional Details:
  Priority: High
  Story Points: 1
  Dependencies: Project Scaffolding
  Notes: Required for monitoring and CI/CD.
