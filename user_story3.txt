Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to configure role-based access controls so that sensitive operations and data are restricted to authorized users only.

Acceptance Criteria:
Scenario: Role-based access enforcement
  Given a user with a specific role (ADMIN, HR, SUPERVISOR, WORKER)
  When the user attempts to access protected endpoints or perform restricted actions
  Then unauthorized requests return 401, forbidden actions return 403, and security rules are covered by tests
  And ADMIN can manage all records, SUPERVISOR is limited to their team

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD)
- Notes: Ensure API key/OAuth2 toggle via config; method/endpoint and row-level security must be enforced.
