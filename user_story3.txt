Title: Password Reset

User Story Narrative:
As a user who has forgotten my password, I want to reset it via email so that I can regain access to my account.

Acceptance Criteria (Gherkin):
Given I am on the login page,
When I click "Forgot Password" and enter my email,
Then I receive a password reset link via email,
And I can set a new password.

Additional Details:
- Priority: Medium
- Story Points: 2
- Dependencies: User Registration
- Notes: Password reset link expires in 24 hours.
