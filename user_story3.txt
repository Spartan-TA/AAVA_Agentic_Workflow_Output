Title: Set Up Actuator Health Endpoint

User Story: As a DevOps engineer I want to enable the Actuator health endpoint So that I can monitor application health and automate deployment checks

Acceptance Criteria:

Scenario: Health Endpoint Availability
Given the application is running
When I access /actuator/health
Then the endpoint should return status UP

Scenario: Health Check Failure
Given a critical dependency is unavailable
When I access /actuator/health
Then the endpoint should return status DOWN with details

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Project initialization
- Notes: Endpoint must be secured for internal use only
