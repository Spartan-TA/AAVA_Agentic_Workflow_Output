Title: Enable Spring Boot Actuator for Health and Metrics

User Story: As a DevOps engineer I want to enable Spring Boot Actuator endpoints so that I can monitor application health and metrics in production.

Acceptance Criteria:

Scenario: Health endpoint returns UP
Given the application is running
When I access /actuator/health
Then the endpoint returns status UP

Scenario: Metrics endpoint is available
Given the application is running
When I access /actuator/metrics
Then I receive application metrics data

Scenario: Actuator endpoints are secured
Given the application is running
When an unauthorized user accesses /actuator endpoints
Then access is denied

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: None
- Notes: Required for production monitoring and readiness/liveness probes.
