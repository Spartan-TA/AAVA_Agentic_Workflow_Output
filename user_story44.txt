Title: Asset Usage History and Reporting

User Story: As an asset manager I want to view and export the usage history of assets and employees so that I can analyze asset utilization and investigate issues.

Acceptance Criteria:

Scenario: View asset usage history
Given an asset is assigned and returned multiple times
When I access the asset history endpoint
Then I see a log of all check-in/out events with employee and timestamps

Scenario: View employee asset history
Given an employee has used multiple assets
When I access the employee asset history endpoint
Then I see all assets assigned to the employee with dates

Scenario: Export asset usage report
Given usage history exists
When I request an export
Then I receive a CSV file with all relevant data

Additional Details:
- Priority: Medium
- Story Points: 3
- Dependencies: E02, E03, E07
- Notes: Supports audits and operational analysis.
