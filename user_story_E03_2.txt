Title: Forbidden Action Handling

User Story: As a system administrator I want forbidden actions to return 403 So that users are prevented from performing operations outside their role permissions

Acceptance Criteria:
Scenario: Forbidden action
Given an authenticated user with insufficient privileges
When they attempt to perform a restricted operation
Then the API returns a 403 Forbidden response

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E01, E02
- Notes: Ensure role-based access is enforced for all sensitive endpoints.
