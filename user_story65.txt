Title: Centralized Audit Logging for Sensitive Changes

User Story: As a compliance officer I want all sensitive changes (employee PII, schedules, approvals, payroll) to be logged centrally so that I can meet audit and compliance requirements.

Acceptance Criteria:

Scenario: Sensitive changes logged
Given a create, update, or delete action on sensitive data
When the action occurs
Then an audit entry is created with actor, timestamp, and before/after values

Scenario: Audit log is immutable
Given audit entries exist
When I attempt to modify or delete an entry
Then the system prevents changes to audit records

Scenario: Audit log exportable
Given audit entries exist
When I request an export
Then I receive a CSV file with all relevant audit data

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E03
- Notes: Supports compliance and forensic analysis.
