Title: Block Unqualified Assignments

User Story: As a scheduler I want to prevent assignment of tasks to employees with expired certifications So that safety is ensured

Acceptance Criteria:
Scenario: Assignment validation Given an employee's certification is expired When I try to assign them to a restricted task Then the system blocks the assignment

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Certification tracking
- Notes: Certification status visible on employee profile
