Title: RBAC - API Key/OAuth2 Security Toggle
User Story: As a system administrator, I want to toggle between API key and OAuth2 authentication via configuration so that I can adapt security to organizational requirements.
Acceptance Criteria:
  Given I am an ADMIN
  When I update the authentication method in system configuration
  Then all endpoints enforce the selected method (API key or OAuth2)
Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: E01, E02
  Notes: Configuration changes must be reflected immediately and covered by tests.
