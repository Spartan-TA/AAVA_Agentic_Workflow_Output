Title: Audit Trail & Compliance

User Story: As a compliance officer I want centralized audit logging for sensitive changes so that audit and forensic analysis needs are met and tamper-evident storage is maintained.

Acceptance Criteria:
Scenario: Audit logging and export
  Given a create, update, or delete action on sensitive data
  When the action is performed
  Then the log records actor, timestamp, before/after values, is stored immutably, and can be exported by date/user/entity
  And tests validate coverage

Additional Details:
- Priority: High
- Story Points: 7
- Dependencies: Role Based Access Control (RBAC)
- Notes: Ensure immutable log table and export functionality.
