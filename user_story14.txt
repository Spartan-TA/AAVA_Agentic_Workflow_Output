Title: User Dashboard
User Story: As a logged-in user I want to access a personalized dashboard So that I can see an overview of my activities and relevant content
Acceptance Criteria:
Scenario: View dashboard
  Given I am logged in
  When I navigate to the dashboard
  Then I should see my recent posts, notifications, and recommended content
Additional Details:
  Priority: High
  Story Points: 5
  Dependencies: Authentication module, Content management system, Analytics module
  Notes: Dashboard should be customizable.
