Title: Audit Trail - Log Sensitive Changes

User Story: As an AUDITOR I want all sensitive changes to be logged with actor and timestamp So that compliance is maintained.

Acceptance Criteria:
Scenario: Log employee update
Given a sensitive field is updated
When the change is saved
Then an audit log entry is created with before/after values

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03
- Notes: Immutable log table

Title: Audit Trail - Export Audit Log

User Story: As an ADMIN I want to export audit logs by date, user, or entity So that I can support investigations.

Acceptance Criteria:
Scenario: Export audit log
Given audit log data exists
When I request an export
Then a file is generated with the selected filters

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03
- Notes: Tests validate coverage
