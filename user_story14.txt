Title: Audit and Log Security Events

User Story: As a compliance officer I want all authentication and authorization events to be logged so that I can review access attempts and investigate security incidents.

Acceptance Criteria:

Scenario: Successful logins are logged
Given a user logs in successfully
When authentication is completed
Then the event is logged with user, timestamp, and IP

Scenario: Failed logins are logged
Given a user provides invalid credentials
When authentication fails
Then the event is logged with user, timestamp, and IP

Scenario: Access denials are logged
Given a user attempts a forbidden action
When authorization fails
Then the event is logged with user, endpoint, and reason

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Supports compliance and incident response.
