Title: ADMIN Role Management

User Story: As an ADMIN I want to manage all employee records and system settings So that I can administer the platform and ensure proper configuration

Acceptance Criteria:
Scenario: ADMIN access
Given an authenticated ADMIN user
When they access employee or system management endpoints
Then they can perform all CRUD operations and configuration changes

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: ADMIN role must be able to access all modules and settings.
