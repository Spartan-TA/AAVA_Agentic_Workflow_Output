Title: Enforce Method/Endpoint Security and Row-Level Constraints

User Story: As a supervisor I want to access only the employee records for my team so that I cannot view or modify records outside my responsibility.

Acceptance Criteria:

Scenario: Supervisor limited to team
Given a user with SUPERVISOR role
When they access employee endpoints
Then only employees in their assigned team are visible and editable

Scenario: HR can access all employees
Given a user with HR role
When they access employee endpoints
Then all employee records are accessible

Scenario: Security rules covered by tests
Given the security configuration
When automated tests run
Then all access rules are verified by unit/integration tests

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E01, E02
- Notes: Prevents data leakage and enforces least privilege.
