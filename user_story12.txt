Title: Like Posts
User Story: As a logged-in user I want to like posts So that I can show appreciation for content
Acceptance Criteria:
Scenario: Successful like action
  Given I am viewing a post
  When I click the like button
  Then the like count should increase and the button should show I have liked it
Additional Details:
  Priority: Low
  Story Points: 2
  Dependencies: Authentication module, Database module
  Notes: Allow users to unlike posts.
