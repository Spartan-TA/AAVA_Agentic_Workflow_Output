Title: Enforce Unique Badge ID

User Story: As an HR manager I want the system to enforce unique badge IDs for each employee So that there are no duplicate badge assignments

Acceptance Criteria:
Scenario: Create employee with unique badgeId
Given no employee exists with the badgeId
When I submit a POST request to /employees
Then the employee is created successfully
Scenario: Create employee with duplicate badgeId
Given an employee exists with the badgeId
When I submit a POST request to /employees
Then the request is rejected with a duplicate badgeId error

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee creation
- Notes: BadgeId uniqueness should be enforced at the database and API level.
