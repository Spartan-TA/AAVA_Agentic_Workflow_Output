Title: RBAC - ADMIN Role Management
User Story: As an ADMIN, I want to manage all employee records and system configurations so that I can maintain operational control and compliance.
Acceptance Criteria:
  Given I am authenticated as an ADMIN
  When I access employee management or system configuration endpoints
  Then I am able to perform all CRUD operations
Additional Details:
  Priority: High
  Story Points: 8
  Dependencies: E01, E02
  Notes: ADMIN role must be able to access all records and settings.
