Title: Export Audit Logs by Date/User/Entity and Reporting

User Story: As a compliance officer I want to export audit logs filtered by date, user, or entity and generate reports so that I can investigate incidents and demonstrate compliance.

Acceptance Criteria:

Scenario: Export audit log by date
Given audit entries exist
When I request an export for a date range
Then I receive a CSV file with all relevant entries

Scenario: Export audit log by user or entity
Given audit entries exist
When I request an export for a specific user or entity
Then I receive a CSV file with all relevant entries

Scenario: Generate audit report
Given audit data is available
When I request a report
Then I receive a summary of key audit metrics and trends

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: E03
- Notes: Supports compliance investigations and reporting.
