Title: Attendance Corrections Workflow

User Story: As a supervisor I want to review and approve attendance corrections So that missed punches and errors are properly handled

Acceptance Criteria:
Scenario: Attendance Correction Approval
Given a submitted correction request
When I review and approve or reject it
Then the attendance record is updated and the employee is notified

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Clock in/out event capture
- Notes: Corrections create approval tasks; maintain audit log.
