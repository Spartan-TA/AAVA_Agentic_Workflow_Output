Title: Role-Based Endpoint Security

User Story: As a system administrator I want to enforce role-based access control on endpoints So that only authorized users can perform sensitive actions

Acceptance Criteria:
Scenario: Endpoint access restriction
Given users with different roles
When they access secured endpoints
Then only permitted actions are allowed and unauthorized requests return 401/403

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee CRUD API
- Notes: Roles include ADMIN, HR, SUPERVISOR, WORKER
