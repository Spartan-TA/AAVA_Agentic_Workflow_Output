Title: Retrieve Employee List with Pagination and Filtering

User Story: As an HR manager I want to retrieve a paginated and filtered list of employees So that I can efficiently manage large employee datasets

Acceptance Criteria:
Scenario: Paginated employee list
  Given there are multiple employee records
  When I GET /employees with pagination parameters
  Then the response should contain the correct page of employees

Scenario: Filtered employee list
  Given there are employees in different departments and statuses
  When I GET /employees with filter parameters
  Then only matching employees should be returned

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: Employee creation
- Notes: Support filtering by department, role, status, and shiftGroup
