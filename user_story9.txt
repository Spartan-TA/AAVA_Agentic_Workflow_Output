Title: Clock In/Out Event Capture

User Story: As a WORKER I want to clock in and out using my device So that my attendance is accurately recorded

Acceptance Criteria:
Scenario: Valid Clock In
Given I am within the geofence
When I POST to /attendance/clock-in
Then my clock-in is recorded with device info

Scenario: Missed Punch
Given I missed a clock event
When I submit a correction
Then a supervisor approval task is created

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: Employee CRUD API, Role-Based Endpoint Security
- Notes: Device and location must be captured
