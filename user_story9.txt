Title: RBAC - API Key/OAuth2 Toggle
User Story: As a DevOps engineer, I want to toggle between API key and OAuth2 authentication via configuration so that integration flexibility is maintained.
Acceptance Criteria:
  - Given the config set to API key, When requests include a valid key, Then access is granted.
  - Given the config set to OAuth2, When requests include a valid token, Then access is granted.
Additional Details:
  Priority: High
  Story Points: 2
  Dependencies: RBAC
  Notes: Security rules covered by tests.
