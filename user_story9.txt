Title: Support API Key/OAuth2 Toggle

User Story: As a system admin I want to toggle between API key and OAuth2 authentication via configuration So that I can adapt to different security requirements

Acceptance Criteria:
Scenario: Authentication toggle
Given the system is configured for OAuth2
When I switch to API key mode
Then endpoints require API key authentication

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Security framework
- Notes: Document configuration steps
