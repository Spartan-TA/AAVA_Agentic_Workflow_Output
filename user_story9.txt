Title: Update Employee Record

User Story: As an HR manager I want to update employee details So that I can keep employee information accurate and current

Acceptance Criteria:
Scenario: Successful update
Given an employee record exists
When I submit a PUT or PATCH request with valid changes
Then the employee record is updated
Scenario: Invalid update
Given an employee record exists
When I submit a request with invalid data
Then the request is rejected with validation errors

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee record exists
- Notes: Only allowed fields should be updatable; badgeId must remain unique.
