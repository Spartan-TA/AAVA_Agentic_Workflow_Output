Title: Initialize Spring Boot Project Foundation

User Story: As a backend developer I want to initialize a Spring Boot project with standardized base packages and modules so that future development is consistent and maintainable.

Acceptance Criteria:
Scenario: Project scaffolding
  Given I have cloned the repository
  When I run the build command
  Then the project builds successfully and runs on port 8080
Scenario: Health endpoint
  Given the application is running
  When I access the Actuator health endpoint
  Then it returns status UP
Scenario: Baseline migration
  Given the database is empty
  When I start the application
  Then Flyway/Liquibase runs the baseline migration
Scenario: Documentation
  Given the repository is initialized
  When I open the README
  Then I see clear build and run instructions

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: None
- Notes: Ensure base package structure includes employee, scheduling, attendance, and safety modules.
