Title: Role Based Access Control (RBAC)

User Story: As a system administrator I want to enforce role-based access control so that sensitive operations and data are only accessible to authorized users.

Acceptance Criteria:
Scenario: Enforcing RBAC
Given a set of user roles (ADMIN, HR, SUPERVISOR, WORKER)
When a user attempts to access an endpoint or perform an operation
Then unauthorized requests return 401, forbidden actions return 403, ADMIN can manage all records, SUPERVISOR is limited to their team, and security rules are covered by tests.

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup (E01), Employee Master Data (E02)
- Notes: Support API key/OAuth2 toggle via config and row-level constraints.
