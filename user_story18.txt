Title: Automatic Shift Association and Daily Totals Computation

User Story: As a payroll administrator I want clock-in/out events to be automatically associated with scheduled shifts and daily totals computed so that payroll processing is accurate and efficient.

Acceptance Criteria:

Scenario: Clock events linked to scheduled shift
Given an employee clocks in/out
When the event is recorded
Then it is associated with the employee's scheduled shift for that day

Scenario: Daily totals computed
Given multiple clock-in/out events in a day
When the system processes attendance
Then total hours worked for the day are calculated

Scenario: Overtime flagged
Given an employee exceeds scheduled hours
When daily totals are computed
Then overtime is flagged for review

Additional Details:
- Priority: High
- Story Points: 5
- Dependencies: E02, E03
- Notes: Reduces manual reconciliation for payroll.
