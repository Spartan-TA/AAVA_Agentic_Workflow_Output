Title: Localization

User Story: As a global user I want to use the EMS in my preferred language and region format So that I can understand and interact with the system effectively

Acceptance Criteria:
Scenario: Changing language
Given I access the settings menu
When I select a different language and region
Then the system updates all labels, messages, and formats accordingly

Additional Details:
- Priority: Medium
- Story Points: 5
- Dependencies: UI module, translation files
- Notes: Support for multiple languages and date/time formats
