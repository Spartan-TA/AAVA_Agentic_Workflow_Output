Title: Clock-In Event Capture

User Story: As a warehouse worker I want to clock in using my device So that my attendance and shift start time are recorded accurately

Acceptance Criteria:
Scenario: Clock-in event
Given a valid employee and device
When I submit a clock-in request
Then the system records the event with timestamp and device info

Additional Details:
- Priority: High
- Story Points: 2
- Dependencies: Employee CRUD API, RBAC
- Notes: Optionally capture geofence location
