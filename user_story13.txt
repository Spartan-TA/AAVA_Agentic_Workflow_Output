Title: Support API Key/OAuth2 Toggle via Configuration

User Story: As a DevOps engineer I want to toggle between API key and OAuth2 authentication via configuration so that the system can support different security models in various environments.

Acceptance Criteria:

Scenario: API key authentication enabled
Given the configuration is set to API key mode
When a request is made with a valid API key
Then the request is authenticated and authorized

Scenario: OAuth2 authentication enabled
Given the configuration is set to OAuth2 mode
When a request is made with a valid OAuth2 token
Then the request is authenticated and authorized

Scenario: Invalid credentials rejected
Given either mode is enabled
When a request is made with invalid credentials
Then the request is rejected with 401 Unauthorized

Additional Details:
- Priority: High
- Story Points: 3
- Dependencies: E01, E02
- Notes: Enables flexible integration with internal and external systems.
