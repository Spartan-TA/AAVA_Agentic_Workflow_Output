Title: Integration Layer (HRIS/WMS APIs)
User Story: As a system integrator I want to expose REST APIs and connectors for HRIS, WMS, and SSO so that master data is synchronized and duplicate entry is reduced.
Acceptance Criteria:
Scenario: API and connector integration
Given external HRIS, WMS, and IDP systems
When APIs and connectors are configured
Then JWT/OAuth2-secured APIs are available, HRIS sync job creates/updates employees, WMS link provides department/location, webhooks are idempotent, and APIs are documented in OpenAPI.
Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD), Role Based Access Control (RBAC)
- Notes: Webhooks for events; SSO integration.
