Title: Integration Layer (HRIS/WMS APIs)

User Story: As a system integrator I want to expose REST APIs and connectors for HRIS, WMS, and IDP so that master data is synchronized and duplicate entry is reduced.

Acceptance Criteria:
Scenario: API exposure and synchronization
  Given secured APIs with JWT/OAuth2
  When HRIS sync jobs run or WMS/IDP events occur
  Then employees are created/updated, department/location data is linked, webhooks are idempotent, and APIs are documented in OpenAPI

Additional Details:
- Priority: High
- Story Points: 8
- Dependencies: Project Scaffolding & Domain Setup, Employee Master Data (CRUD), Role Based Access Control (RBAC)
- Notes: SSO and webhooks for events must be supported; ensure idempotency and security.
