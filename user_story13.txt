Title: Provide OpenAPI Schemas with Examples

User Story: As a developer I want OpenAPI schemas for employee CRUD endpoints with example payloads So that API consumers can easily integrate and test

Acceptance Criteria:
Scenario: OpenAPI schema includes all fields
Given employee CRUD endpoints are defined
When I view the OpenAPI documentation
Then all request and response fields are documented
Scenario: Example payloads provided
Given OpenAPI documentation is available
When I view the employee endpoints
Then example request and response payloads are shown

Additional Details:
- Priority: High
- Story Points: 1
- Dependencies: Employee CRUD endpoints
- Notes: Schemas and examples should be kept up to date with any changes to the API.
